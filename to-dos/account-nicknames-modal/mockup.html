Account nicknames: the modal says what each account is, so naming one takes no trip to Mercury

Today a row is an eight-letter id and a box. The owner names an account by opening Mercury, reading that account's transactions and matching them by eye against the ledger. The app holds both halves of that match: the ledger's rows by account, and Mercury's own account list, which the Balance Sheet already reads. Two drawings, then the pick.

B The card: Mercury's own name first, then the ledger's facts

The Balance Sheet already reads Mercury's account list through get-mercury-account-balances, and that list carries each account's id, name and kind. So the modal reads it once when it opens and puts Mercury's name on the card, with a one-press Use this name. The ledger's facts sit under it for the check, and for an account Mercury no longer lists. Unnamed cards first, amber. The latest lines read like Mercury's own screen: date, counterparty, amount.

? Is this the best we can do, are we being straightforward

QuestionAnswer
Does he still open Mercury?Only for an account Mercury no longer lists. For the rest, Mercury's name is on the card. Mercury does not search by account id, so Copy is for the dashboard's address bar and for a note, not a search box.
Why not fill every unnamed account with Mercury's name at once?Because his nicknames are not Mercury's names. Operating is Ops Checking in Mercury. One press per account keeps the choice his and keeps the write path exactly as it is.
Why read Mercury from the modal and not store the names?A table of Mercury account names would be one more thing to sync. The Balance Sheet already reads the list live on every open, and ten accounts is one small call.
Where do the counts come from?From the rows the page already loaded. The Ledger and User Sort load every row, so the counts are the whole ledger. Opened from the Accounting tab, which loads only the unlabeled rows, the card says so and the count is read from the table instead.
What about the last four of the account number?Mercury's own account names carry it, as Mercury Checking ••8103, so the card shows it with no change to the function.
