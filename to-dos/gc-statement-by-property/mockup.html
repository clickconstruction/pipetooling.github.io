Subject: Click Plumbing open balances: Sep 30, 2026

    Four things to settle before this is built

    None of them changes the drawing much. Each changes what the builder writes.

    Job 273 says two things at once

    Today's preview shows three bills on job 273 as owed ($13,420.00, $3,500.00, $665.00) and, on the same rows, “paid in full”. One of the two is wrong. The new layout puts paid and owed side by side, so this has to be right first.

    What counts as one property

    Jobs linked to the same property record group together. A job with no property record falls back to its cleaned-up address, the rule the portal already uses. “Lenox Hill” and “Lenox Hl” only merge when both jobs are linked to the one property.

    How far back the payments list goes

    Drawn as the last 30 days. It could be “since the last statement we sent you” instead, which never shows the same check twice.

    The QR code and “Copy for email”

    The code travels in statements the app sends, the way it does on a bill email. A statement copied into a personal mail program may lose the picture, so that lane keeps the link and the address in words.
