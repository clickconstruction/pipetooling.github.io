Call through Quo: the Call buttons open the Quo app on the company number

Today every Call on Messages is a plain phone link. On a phone it dials from the person's own number and Quo never sees the call. Quo has a link that opens its phone app on a number and dials from the company number. For a desk, Quo's one way is a setting the person makes once. Quo's API cannot place a call for a person. This page draws the recommended option: Quo on phones where the person has a seat, the plain dialer where there is none, a switch per phone, and the thread getting the call from Quo on its own.

On a desk Quo takes a Call press once it is the computer's default for calls. The Quo desktop app must be installed. Mac: open FaceTime, then Settings, then choose Quo under Default for calls. Windows: open Settings, then Default apps, then Choose default apps by protocol, then set TEL to Quo.

Not drawn: the app asks Quo to place the call
Quo's API has no door for this. It reads calls and tells us about them through webhooks. It cannot ring Rosa's seat and then Dana. The one call Quo's API can start is Sona's, its AI agent, at 50 automation credits a call. That is the robot calling, not Rosa.

If Quo adds a door, it is one edge function on the shape of quo-send, and the press works the same on every device. Until then there is nothing to build, and the to-do says so instead of drawing it.
