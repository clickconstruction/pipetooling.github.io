The pick, and is this the best we can do?

C, with one change from the self-review: the who-has-it pill stays in the top right corner at every width (the owner's call of 2026-10-11), shrunk to its avatar and first name, R Rosa, beside Open ▾; the since-when moves to its hover card. The strip then holds Call in Quo, More ▾ and the jobs.

Three ways it could be better, weighed:

  1. Two shapes for the state. Wide keeps Open · Snoozed · Done as a segment; narrow folds it to a pill that opens the three. One shape everywhere would be simpler, but the segment is what the owner picked beside the pill, and the pill names the state in one word where there is no room for three.
  2. The breakpoint is the thread's width, not the window's. With the list and the flow panel open at 1040 px the thread column is about 650 px, so a window rule would miss it. A container query on the thread card (@container (max-width: 640px)) folds the header whenever the column is narrow, whatever the window is.
  3. The stamps lose their weekday at narrow ("Sep 26, 2:14 PM"); wide keeps "Sat, Sep 26". The date is what the court counts from, and the weekday is on the day divider in the thread, so the loss is small; the hover card keeps the full stamp.

Not done: a phone-app header with a ‹ back arrow in the same row as the name (the prototype already shows ‹ Everyone above the card below 860 px; folding it into the name row is a later pass with the phone layout, which is on the plan's open list).
