2. A small card that floats over the table

Pressing the address line opens a card anchored to it. Nothing in the table moves at all. It can keep the full sentence, since it has its own room. It covers the row below while open, and it is one more floating thing on a page that already has several.

3. Edit it in the company window

The table only shows the line. Pressing it opens the company window on About, where the address sits with the company's other facts. The table never grows, and there is one place to change a company. It is two more presses for a quick fix, and you lose sight of the row while you type.
