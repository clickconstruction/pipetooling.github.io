View report asks a small door (portal token + report id) for a five-minute signed link to the stored PDF, the same way signed contract copies open. The file is the exact one that was emailed. Nothing on the portal page itself is a PDF, so the statement stays fast on a phone.

CRules the card follows

Sent reports only
Drafts, unsent reports, and anything the office is still editing never render. A report appears the moment Send succeeds.
Audience follows the bills
A GC link sees reports on the jobs it pays for (as GC). A homeowner link sees the jobs it owns. The merged view dedupes by job, the same rule the statement's bills use.
FAIL is not softened
A failed test shows FAIL in the ledger red and the paper carries the findings. The office already read it before Send — dial A puts a person on every one.
No money, no notes, no tech name
The paper has what the customer should see: the certified result, the licensed master, the method. Field notes for the office stay on the job.
Print keeps it
Print all · one job per page already exists; the inline report line prints on the job's page as a line of text (the button drops, the way PAY ONLINE does).
