? Is this the best we can do?

The first draft of the pick was A's window with B's fixture groups and a Save. The second look found eight things wrong with it. Each is redrawn in the pick below.

  1. She read every row. A row matched by the house's own number needs no eye. The window now opens on the rows that need her, and the ready rows fold to one line a fixture.
  2. A percent explained nothing. The match now says how in words: same Hillcrest number, same model number, or words only. Only the first is ready without her. Words are offered only when every size in the two names agrees.
  3. The house was a dropdown that was already filled in. A wrong house puts 40 prices in the wrong place. The window now opens on a sentence that names the house and its reasons, and it asks when the reasons disagree.
  4. Every fixture made a new assembly. The book would gain one for each fixture on each bid. An assembly with the same items is reused, and a new one is made only when none exists.
  5. A row with no price taught nothing. A kit row has no price of its own, yet it still says which part Hillcrest's number means. Every confirmed row now keeps that number, so the next sheet matches more by itself.
  6. There was no way back. A sheet can now be taken back: each price returns to what it was, unless someone changed it since.
  7. An old sheet could overwrite a newer price. The sheet's date now decides. A price on file that is newer than the sheet stays, and the row says so.
  8. A price said nothing about where it came from. Each filed price now names its sheet, its page and how long the quote is good for.
