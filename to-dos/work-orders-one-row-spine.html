What this buys, and what to ship first

Why the rail and not two chips

  • The sub, the office, the job window and the Person Desk all read one drawing.
  • “No agreement” stops being a status word and becomes a visible gap in the line.
  • The sub’s portal prompt (“Done with the work?”) and the office’s Next column are the two ends of the same step.
  • Filters on both tabs are just rail positions, so the tabs can’t disagree.

Ship first, either way

  • “Needs a work order” reads the sheet’s paid stamp, which is never set — paid-up 892 counts as unpaid. Derive it from items minus payments.
  • It only sees jobs in the Pipeline list — 977, 1004, 931 have sheets but no ledger row, so they never show. Derive it from sheets.
  • The rail kernel already exists (the sheet box draws Draft → Sent → Signed → sheet stages); this is lifting it onto the rows.
