?Is this the best we can do?

What else was weighed, and why it lost.

  • No · Ask “Did it print right?” after every print, so a bad print never becomes “in the mail”. It adds a step to every run for a rare case. Taking back covers it after the fact.
  • No · Only reword Print it again as “print with today’s layout”. That fixes this week, but not “we are not mailing these yet” or “fix a notice first”.
  • No, for now · Take back one envelope in step 3. An envelope can hold several notices, and a notice goes in two envelopes. Taking back one envelope leaves notices half mailed, the state v2.4971 just closed. One job already has Back to ready.
  • No · Drop the printed state. v2.4119 added it so a printed notice cannot vanish between the printer and the record.
  • No · Mark the filed copies “taken back”. Sent copies are append-only by the owner’s rule. They did print, so they stay. The notice’s own line says it was taken back.
  • No · A “Mine only” switch instead of part 3. A switch hides rows and is easy to leave on. A group shows everything in order.
  • Yes · Take back lives in the run window, where the office already goes to finish a run. The Do now row only opens it there.
  • Yes · The run row borrows the GC row’s shape, which Do now already uses for a GC with several ready notices.

For you: should taking back need the leader? Proposed: no. Nothing left the building, and approvals stand, so the leader’s word is not undone.
