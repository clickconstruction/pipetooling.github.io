2. Waiting on you (upgrade 3, proposed)

Today a plan an agent makes lives in the session that made it, so the owner says Apply it in each session. The proposal: an agent may keep a plan on the file. Kept plans gather in one list. The first PR shows the list as words. Apply and Drop come in the next.

What does not change.
  • A kept plan is the same plan with the same hash. Apply runs the dry run again and writes only when it still matches.
  • Only a dev sees the list, as only a dev sees the file.
  • A plan that carries a file's bytes is not kept. It stays in its session.

The owner's calls, with what the train builds in his place

  • Who may press Apply. Built: any dev, as any dev may apply in a session today. The stricter choice is the owner alone.
  • Whether a kept plan expires. Built: it never expires by the clock. It turns stale only when its dry run no longer matches.
  • Whether a session may add a log line without a yes. Built: no. A log line is a plan like any other.
