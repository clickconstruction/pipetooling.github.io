prts.co: tape labels from the Brother printers

The owner will print the labels on a Brother PT-E720BT and a PT-D610BT for boxes that sit in the sun. The design lets the printer's own driver do the work: the app lays the strip out at the tape's size and prints it through the browser's print window, as it prints the sheet labels today. No printer code in the app. Everything here is made up.

The strip, on 24 mm tape

QR on the left with a quiet zone of four modules, the stencil in the largest type that fits, the code and one line of words underneath. Dark on light, since scanners read dark on light. The first strip is at print size; the second is the same strip three times larger so the owner can read it.

The QR drawn here is a stand-in pattern, not a code that scans. The real label draws the code with the library the sheet labels use today. A 21-module code on 24 mm tape scans from arm's length, which is right for a label on a cage's door; the sheet label stays for scanning from across a room.

At the desk: Jobs → Materials → Labels

Two chips above the labels, Sheet and Tape. Tape shows one strip per box with a tick to leave one out, and the press says how many it prints. The first print opens the browser's print window and asks for the printer and the paper once; the browser remembers both, so every print after is two presses.

At the cage: Copy the label code for Brother's phone app

The PT-E720BT prints over Bluetooth from Brother's own phone app, which a web page cannot reach. So the box's screen gets one press that puts the label's code on the clipboard, and the person pastes it into Brother's app as a QR. One press in the app, no integration.

The staging

  1. Now, no build: both printers make a QR from text typed on their keypad. The code is under every sheet label to copy from.
  2. PR 4, XS: Export the labels as a CSV for Brother's desktop editor, and Copy the label code on the phone for Brother's app.
  3. PR 5, S: the Tape format above, printed through the printer's driver from the browser's print window, walked on both printers before it merges.

Not built, on purpose: Brother's b-PAC kit (Windows-only, out of a browser's reach), Web Bluetooth (the printers use classic Bluetooth), USB from the browser (fights the installed driver), a helper program on the office computer (one more thing to keep running).
