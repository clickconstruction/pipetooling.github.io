Price requests, asked to priced — PR 4: Price with robot on the strip + the Needs You card — before and after

Bids → Bid Board → Edit Bid (BP398) → Price requests header (under the Job Plans / CountTooling Plans links); and Dashboard → Needs you card

What changes

Today, once supply-house quotes land on a bid, pricing them means leaving Edit Bid for Pricing to find Price with robot, and a request whose needed-by has passed with nothing in only shows as an amber 'late' note inside that bid's table. The after puts a 'Price with robot · 2 quotes in' button on the Price requests header the moment at least one quote is in (it opens the same modal Pricing does), and adds a Dashboard Needs You card, '3 price requests past their date with nothing in', so overdue requests surface where the office starts its day. Nothing else in the table changes in this PR — the Status column, Call and the paste-a-link box belong to PR 3, so neither artboard draws them.

Assumptions the drawing made

  • The button lands on the Price requests panel header — the README says 'on the table header' and the approved mockup.html draws it there — not on the bid flow strip ('Where this bid is'). BidFlowStrip.tsx was checked: it draws step nodes and doors, no header buttons, so the task's pointer to it was set aside in favour of the mockup.
  • Only PR 4 is drawn. PR 3 (Status column, Call, the paste-a-link box) is unshipped, so both artboards keep today's four columns (Supply house / Requested / Quote link / actions) and today's '+ Add a request' footer wording from v2.3495. Region 1's rows carry identical data in Before and After so the header button is the only difference.
  • Rows: BP398's two real houses as the README describes them today (Click Plumbing Supply sent by app Sep 2, National Wholesale sent outside Sep 10) plus Ferguson (app, Sep 12) and Moore Supply (outside, Sep 12) borrowed from the mockup so the table reaches 2 quotes in. Click's quote is drawn as a plugged vendor-page quote (needed by Sep 9 ✓, viewed Sep 3, Nudge hidden and 'Compare' shown, as showsNudge / actionsCell do once status is quoted); National's is a pasted Drive link. Rep lines, phone, viewed dates and needed-by dates are illustrative, not real BP398 data.
  • The summary line keeps the kernel's current wording ('4 houses · 4 requests · 2 quotes in'); the 'late' part is PR 3's and is not added.
  • With the button present the desk link reads 'Open the desk ↗' as the mockup draws it (today's 'Open the desk on Pricing ↗' stays in the Before). At the modal's 720px the button and link still wrap to a second header line, exactly as the component's flex-wrap header would.
  • The button reuses the table's existing blue button style with a 14px stroke robot glyph, matching the earlier PriceRequestsAfter artboard; the README specifies no icon.
  • The Needs You card is drawn at amber severity (a date has passed, like job-followups and robot-audits) in the revenue-chasing tier alongside price-matrix-ready, so it sorts first among the drawn neighbours by figure. Its detail sentence and the action label 'Open Price requests' are written in the kernel's voice — the README gives only the card's condition ('needed-by passed, nothing in, live bids') and its figure.
  • The three neighbouring cards are real card kinds with their real title/detail/action wording (price-matrix-ready, robot-audits, lost-bids with the '· all trades' scope label) and illustrative figures; BP401 Lakeway Dental, 18 picks, 2 audits, 4 lost bids and $212,400 are not real.
  • The dashboard region is drawn in Cards mode (the toggle's default) at 1040px on the page ground with 24px/40px gutters; Walk-the-list mode is not drawn. Each artboard carries two caption bars so both regions are named.
  • Heights are measured renderings in headless Chrome (1215px / 1349px at 1120 wide) plus 5% slack.
