A run that names its boxes

The ask, 2026-11-15: print stickers that already say G1 to G200, or G78 to G300, so the sticker on the cage is the name painted on it and a scan on site only says what is inside and where. My recommendation: one typed field in the Print stickers window, Names, open on the site's next free name as the Add sheet opens, so the default run is already named. Type a range like G78-300 and the count follows. The name prints large where the number prints today, and the number stays small, since it is the one thing that survives a rename. Because the tape says the box's own name, a range can be put on boxes in one press with no scan, These are on boxes, and the scan only adds what is inside. Second pass of 2026-11-15 folded in: the default run is named, a second run over blank names is held, the number recedes on the screens, and the trade is said.

The short of it

One field, Names

  • Opens on G78, the site's next free name, as Add does. How many says how far.
  • G78-300: the count follows the range. How many goes grey and reads 223.
  • A1-D50: the letter and the number both step. Four rows of fifty.
  • G78B-D: twins at one spot. G1-100C: every spot plain, then B, then C.
  • Clear it and the run is numbered only, as today. That is the exception now.

The parts of the two ends that differ step. The parts that match stay.

The maximum

  • A name is the box rule's: one to three letters, 1 to 999, one letter after. Seven characters at most.
  • Up to four characters print at the full size. Five to seven print smaller, as a long stencil does on a label.
  • A run is 1 to 500 stickers, as today. A range past that is refused with its count.

The trade

  • Call 2 chose a plain number so a leftover sticker works on any site. A named G sticker does not travel to a site painted R.
  • That is the right trade for a site with its names on the paint. A numbered-only run keeps the old way for a crew that wants it.
  • Names make a walk with no scan safe: the tape says the box's name, so nothing can shift. Section 5.

What does not change

  • The number is still one company-wide count, printed small.
  • The code is still cut from the sticker's own id when the run prints.
  • A scan still makes the box's row, with the kind and the place. An unused sticker is still just a sticker.

4 · The rule and the limits the last row is yours to type

A range is two names under the box rule with a dash between, or one name and the count. The parts that differ step. Letters step outside, numbers inside, the letter after innermost.

TypedRead asCountWhy

Why seven characters and not a setting. The maximum is the box rule's, which the site already holds in the database and on every Add sheet. A sticker that could carry a longer name than a box can hold would make a name the scan then refuses. The letter after the number is the second cage at a spot: on the paint there is G24 and G24B, never G24A, so the plain name is the first and B the second. A range from a plain name to a lettered one reads plain, B, C for every spot, and it is the innermost step, so a spot's cages print together.

A twin found on site after a plain run printed: the person scans the plain G78 sticker, the sheet says the site has a G78 already, and It is a different box offers the next twin, Save box G78B, or G78C when G78B stands. The tape then reads G78 for a box named G78B, and a later scan says so. For a twin set known ahead, print G78B-C from the window instead: two stickers that read as the cages do.

Your calls six, my pick first

1 · The number on a named strip

Keep it, printed small before the address. It is the identity the Runs fold, the CSV and a typed scan use, and it still opens the box after a rename.

Or leave it off a named strip and the number lives only in the app. A damaged QR then has nothing to type.

2 · Names the site already has

A notice at print, not a refusal. 77 of these are boxes on this site already. Their stickers go on those boxes. That is the backfill, and it is wanted.

Or refuse the overlap and make the person start the range after the last G.

3 · A grid range

In. A1-D50 is four rows of fifty, printed row by row, for a yard laid out in rows and bays. It costs nothing extra once the parser steps one part.

Or the number alone steps, and a yard in rows prints four runs.

4 · Numbered-only runs

Stay, as the exception. The field opens on the site's next free name, so the default run is named. Clear the field and the run is numbered only, for a crew that wants leftovers that travel.

Or every run is named, and a site with no paint picks a letter before it prints.

5 · A second run over blank names

Hold the press until Print them anyway. Two drawers of the same names is the one mess this can make, and a run printed twice by mistake is how it happens.

Or a notice only, as for names that are boxes already.

6 · These are on boxes

Build it, in the Runs fold, as PR 4. It is the payoff of names: a range placed in one press, the scan left for what is inside.

Or keep the scan as the only way a sticker goes on a box, as the card had it for numbered stickers.

The plan four PRs, one migration

PR 1 · the run carries namesM · migration · push right after the merge A name range on sticker_runs, a nullable box_name on each sticker, mint_sticker_run takes the range under the box rule, names each sticker and refuses nothing, place_sticker names a new box by the sticker's own name when none is typed. The parser as a pure kernel with the table above as its tests, and its SQL twin. The window's two notices read the site's live names and its blank stickers.
PR 2 · the window and the stripM · client The Names field with its read line and the overlap notice, How many following a range, the press Print 223 stickers, G78 to G300, the strip with the name large and the number small, the preview fold drawing the names, the Runs fold's title and the CSV's Name column. The press reads Print stickers.
PR 3 · the first scan and the screensS · client The sheet opens on the sticker's name, a box already here is offered first when the site has that name, a twin found on site is offered the next letter, a later scan of a renamed box says what the tape reads, and the number recedes on the box rows.
PR 4 · These are on boxesM · one function place_sticker_range as the caller: the run's blank stickers in a range, each a new box with its sticker's name, kind and place, a name already a box taking the sticker instead, a sticker already placed left as it is and said. The press in the Runs fold, then on the phone's On site tab.

Not built on purpose: a setting for the longest name, names longer than the box rule allows, a run that makes its boxes at print time, and a name that changes which job a box is on.
