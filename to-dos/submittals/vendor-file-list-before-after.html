After the reader runs (it runs on Assign pages today), a file whose pages name no row and carry no section stamps can say so in the standing column — no page names a row · not a vendor submittal? — with Remove lit. Cheap once the reader runs on drop instead of on open.
  • Ask the robot is gone from the lineIt was a dashed button on the card; on the line there is no room, and the walk's own reader makes it a second opinion. It lives in the fold (the robot's line and Confirm are there), and the walk shows the robot's sure guesses as reads anyway. The calls this drawing makes, and why

  1. A list, not cards. Files are peers with the same four facts; a table-shaped list reads them in one pass. Cards suggest each file is its own little page.
  2. The standing is a sentence plus a bar. The words are exact (57 of 75 on rows · 18 not used); the bar is the shape. A page on two rows turns the bar amber and names itself in red, because Done refuses until it is settled.
  3. Show the pages becomes the chevron. It is a disclosure, not an action; the fold keeps the tap-a-page path exactly as it is, including the robot's chips and Confirm.
  4. Done only once there is something to keep; Remove always, but quiet. Today Remove replaces Done when nothing is on rows. On one line both fit, so Done appears when it means something and Remove never changes place.
  5. The house's name rides with the file name. It is already stored (houseName); after the name is where "which house sent this" is asked.
