Punch list #381 · mock-up · made-up people and tasks

See a person's Task Mode from Review

On Checklist → Review, an opened person card gets one new press. It opens a window that draws that person's Task Mode screen as their phone draws it today, with what is coming up beside it.

"When a user's tasks are expanded, I would like to see an option to imitate that individual, where it opens a modal where I can see what their phone screen would look like in task view which would include their current tasks and their upcoming."

Review, Outstanding by person. The card is open, as in the screenshot. The new press sits beside ＋ Add task for, for the same people who see that press today.

Their screen on the left at phone size, drawn by the same code that draws Today. Coming up sits beside it, because a task is not on a phone before its day.

4. A look is not View as

The app already has a real View as. This window is a different thing, and the press does not use the word imitate for that reason.

This window · a look

You stay signed in as yourself. The window reads the person's tasks with the read the office already has on Review. Nothing is written, no record of an imitation is made, and no press inside it works.

  • Opens in a second, on the page you are on.
  • Shows today, the older open tasks, Waiting For and what is coming up.
  • Cannot mark, note, forward or add as that person.
Settings → View as · a sign-in

Your whole session becomes that person. Every page and every press works as them, and the app writes a record that you did it. You sign back out to be yourself again.

  • Right when the question is what a press does for them.
  • Right when the question is about a page other than tasks.
  • Too much for a look at someone's day.

5. What a look cannot know

These live on the person's own phone, so no window on your screen can read them. The window says so in its side column.

  • Whether Task Mode is switched on. The switch is kept per phone. The window always draws Task Mode.
  • Do first. A task the person lifted into Next is kept on their phone. The window shows the list's own order.
  • How far each task is. Distance needs where the person stands. The window shows the place with no distance.
  • The moment. The window reads when it opens. It does not move when they tick a task a minute later.
