★ Is this the best we can do?

  • Spot 1 first kept the fieldset and pushed the legend inside with CSS. A heading inside a labelled group is simpler, reads the same to a screen reader, and never fights the border.
  • Spot 2 first grew every button everywhere. On a desk the small presses are right, so the rule is one media query for coarse pointers, and it covers the lesson rows and the answer rows too, which the first cut missed.
  • Spot 3 first said "1 of 31 steps". Nobody thinks in steps; they think in lessons, and the final check is the one thing that is not a lesson, so it gets its own chip when passed.
  • Spot 5 first put the due day only on the Dashboard. Saying it once at the moment of the pass is what a person wants to read, and the Dashboard still carries it.
  • Spot 6 first only made the draw skip repeats. That hides the problem; the content test and the rewritten questions remove it.
  • Spot 7 first made Clear a second red button. A chip that states the stamp with a quiet Clear reads as a fact with an undo, not a second alarm.
  • Spot 8 first added a fourth cell. The owner picked three cells in v2.2815; an icon that changes with the lead need keeps that decision and still reads at a glance.
  • Spot 9 first imported the lessons to count them, which would put the lesson text on every Dashboard. A size line in the course's own file keeps the Dashboard light.
