## Why it matters
Hand tools cause about **8%** of workers' compensation cases. Power tools injure more than **1 million** people a year. Pneumatic tools alone send about **37,000** workers to emergency rooms.

## Must know
- A hand tool needs no power source. It suits precision work and soft materials like drywall.
- A power tool runs on electricity, a battery, compressed air, powder or gasoline. It suits hard, dense materials like tile.
- Use every tool only as it was designed. A wrench is not a hammer.
- Electric tools are grounded with a three-prong plug or double-insulated. Use a GFCI, a ground-fault circuit interrupter, in damp conditions.
- A damaged lithium-ion battery comes out of service. Use the original charger and never repair a battery.
- A powder-actuated tool needs a trained, certified operator. A gasoline tool never runs in a basement, pit or other enclosed space. Its exhaust carries carbon monoxide.
- **Kickback** is the sudden backward jump of a tool or workpiece when the blade binds.
- Guards protect the point of operation. A fixed guard is permanent. An interlocking guard stops the tool from running without it.
- Never remove or disable a guard. A faulty guard takes the tool out of service.
- Inspect every tool before each use. Tag out a defective tool and report it.
- Stay out of the line of fire and wear eye and face protection. Dust hits the lungs, noise the ears and vibration the hands.

## Traps
- A battery tool or extra PPE never replaces a missing guard or a misadjusted tool rest. Set the tool up right or stop using it.
- A make-shift handle is wrong. Install the real accessory handle and add a face shield.
- Use a hand tool on soft drywall and a power tool on hard tile.

## Numbers
- **8%** of workers' compensation cases are hand tools
- **1 million** power tool injuries a year
- **37,000** emergency room visits from pneumatic tools

## Check yourself
1. What is the term for sudden and forceful backward movement of a power tool or the material being cut?
- [ ] Pinching
- [ ] Crossflow
- [x] Kickback
- [ ] Reverb
> right: The blade binds and the tool jumps back at you.
> wrong: It is the sudden jump backward when the blade binds. Keep your body out of its path.

2. Which type of guard is designed to shut down the tool if it is not in place?
- [ ] A fixed guard
- [ ] A wheel guard
- [ ] An adjustable guard
- [x] An interlocking guard
> right: The tool will not run without it.
> wrong: A fixed guard is permanent and a wheel guard adjusts. One kind stops the tool from running when it is missing.

3. What should be done if a tool's safety guard is not working properly?
- [ ] Remove the guard
- [x] Take the tool out of service
- [ ] Keep using the tool as it is
- [ ] Ignore it
> right: A faulty guard means the tool does not get used. Tag it and report it.
> wrong: A tool with a faulty guard is tagged, reported and not used until it is fixed.

4. What is a hand tool?
- [ ] A tool that runs on electricity
- [ ] A tool that runs on gasoline
- [x] A tool with no power source
- [ ] A tool that runs on batteries
> right: No cord, no battery, no air, no powder. Your hands do the work.
> wrong: Electricity, gasoline and batteries all power a tool. A hand tool has none of them.
