A customer can have more than one number on file. The send window shows which one a text goes to. When there is a choice, you can switch it and remember the pick.

## Read the To chip

1. Open a thread in [Messages](/messages) and write a text.
2. Press {{button:blue|Send text…}}. The send window opens.
3. Under the tabs, the **To** line names the customer and shows a chip with the number, like *To (830) 555-0190*.

With one number on file the chip is a plain label. Nothing changes for you.

## Switch the number

When the customer has two numbers or more, the chip is a press.

1. Press the chip. A short menu opens.
2. Each number says when it last carried a text, like *last line yesterday* or *no line yet*.
3. A number that sent STOP shows a red {{chip:red|STOP}} mark and cannot be picked.
4. The number the office starred shows *★ usual*.
5. Press a number. The chip and the phone picture now show that number.
6. Press {{button:blue|Send as text}}.

The text goes to the number you picked, this once.

## Make it their usual

The menu ends with a tick, **Make this their usual number**. It is on when the menu opens.

- Leave it on, and the pick is remembered. Every text after goes to that number first.
- Turn it off, and the pick is for this text alone.

When a pick is remembered, the thread shows a gray line, like *Rosa made (830) 555-0190 Dana's usual number.*

:::example The rule the app follows

The usual number comes first. With no usual, the number the thread last carried a text on comes first. With no texts yet, the first number that can still take a text comes first. A number that sent STOP is never first.

:::

## The morning run reads the same rule

The reminders the app sends itself go to the same number the chip would pick. [Today's sends](/dashboard) shows the texts waiting for a press.

## When a customer writes from a new phone

The office names a new number with **Who is this?** in the thread. When the customer already has a number on file, the sheet asks **Make this their usual number**. The old number shows beside the tick. The tick is on when the old number has been quiet for a month. Turn it off to keep the old number as their usual.
