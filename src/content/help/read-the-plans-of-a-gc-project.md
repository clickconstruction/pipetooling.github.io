A GC project's plans come in sets. The plans window opens on the newest set, lists its sheets and sections, and shows what each set changed.

A set is one issue of the plans, such as the bid set or an addendum. A sheet a set took out stays in the list, crossed out. A quote priced on it can still be read. Only devs see the window while the real build goes on.

## Open the plans

1. Open **GC projects** at `/gc` and press {{button:outline|The plans}} on the project's card.
2. Pick a set at the top. The newest one is marked.
3. Pick **Sheets** or **Specs** on the left when the project has a manual.

## Read a sheet

1. Press a sheet in the list. The arrow keys flip sheets.
2. The card shows the sheet and the set that issued it. A mark says when this set changed, added or renamed it.
3. Under the card, **Scope that reads from** names each trade's lines that read the sheet.

A line that names no sheet reads every sheet of its trade, so it shows under each one. A line a set added says which set.

## See what a set took out

1. Pick the set at the top.
2. The sheets it took out sit under **Taken out** at the foot of the list.
3. Press one to read it. The card says which set took it out.

The folder link under the set's note opens its plans in Drive. The sheet's own page comes once the plans are read from the PDF.
