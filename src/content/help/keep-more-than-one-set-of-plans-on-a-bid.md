A bid can carry more than one set of plans. Each set has its own name, memo, date and link. The Bid Board offers them by name.

An addendum comes in after the first set. A permit set replaces the issued set. A GC sends a marked copy. Before, a bid held one link, and the newest set went over the old one. Now each set has its own row.

## Add a set

1. Open the bid. Press the gear on the Bid Board, or {{button:outline|Edit}} on the bid's window.
2. Find **Plan sets** under the plans link in the Plans section.
3. Press {{button:outline|+ Add a set of plans}}.
4. Type the set's **Name**, such as *Addendum 2*.
5. Pick the set's **Date**. Use the date printed on the set.
6. Type a **Memo**. Say what changed or who sent it.
7. Paste the set's Google Drive link under **Link**, or press {{button:outline|Paste a link}}.
8. Press {{button:blue|Save the set}}.

The app reads the link right away. The row then shows the file's name and size. A folder shows how many PDFs it holds, such as *3 PDFs · 42 MB*. A link the app cannot open says why, such as the folder not being shared.

:::example A bid with two sets

*Issued set · Sep 14, 2026 · A-001 to P-601 · 6 PDFs · 88 MB*

*Addendum 1 · Oct 2, 2026 · P-201 and P-401 redrawn, two more floor drains · 2 PDFs · 11 MB*

:::

## Which set the robot reads

The robot reads one set, the one in the **Plans link** box above the list. The Plans panel searches the same set. A set with that link wears {{chip:blue|Robot reads this}}.

1. Press {{button:outline|Robot reads this set}} on another set to switch.
2. The Plans link box takes that set's link.
3. Save the bid as you always do.

## Check or change a set

Press {{button:outline|Check the link}} on a set to read its file name and size again. Press {{button:outline|Open ↗}} to open the set in Drive. Press **×** on a set, then {{button:outline|Remove}}, to take it off the bid. Removing a set never deletes the files in Drive.

## Find a set from the Bid Board

The plans icon in the **Links** column opens a bid's plans. A bid with one set opens that set. A bid with two or more sets opens a window that lists them.

1. Press the plans icon on the bid's row.
2. Read each set's name, date, memo, file name and size.
3. Press {{button:outline|Open ↗}} on the set you want.

Press {{button:outline|Edit bid}} at the bottom of the window to add or change a set.
