The baseline is the plan every measure on the schedule reads against. Start keeps the first one. After a signed change order adds days, take a new baseline from the plan as it stands.

Only devs can set a baseline for now. The rest of the office gets the Schedule window later.

## Set a new baseline

1. Open [GC projects](/gc).
2. Press {{button:outline|Schedule}} on the project's card.
3. Find **The baseline** card under the chart.
4. Press **Set a new baseline**.
5. Keep the name it offers, or type your own.
6. Say why in a few words, like the change order that added days.
7. Press {{button:blue|Take the plan as it stands}}.

The card lists every baseline. Older baselines read **Before**. The newest reads **Now**.

## When a new one is due

The card says **a new one is due** after a signed change order's days go on the schedule. Set one then, so the measures read against the plan you agreed to.
