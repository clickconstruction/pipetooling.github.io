Every bid on the Bid Board shows five icons in the Links column. A blue icon is something the bid has. A grey icon is something it does not have yet.

## Read the five icons

The icons keep one order on every row.

1. The camera is the bid's photos.
2. The folder is the project folder.
3. The page with a picture is the plans.
4. The crosshair is the CountTooling project.
5. The page marked PDF is the bid submission.

Hold the pointer over an icon to read its name.

## Open what a bid has

Press a blue icon. The link opens in a new tab.

A bid with two or more sets of plans shows a number by the plans icon. Press it and pick the set.

## See what a bid is missing

1. Press a grey icon. The **Files** window opens.
2. Find the row with the blue outline. It is the one you pressed.
3. Read the line under its name. It says what the bid does not have.

The window lists all five rows. A row the bid has shows {{button:outline|Open ↗}} and {{button:outline|Change}}. A row it does not have shows {{button:outline|Set the link}}.

## Set a missing link

The row you pressed already has a box open for its link.

1. Paste the link in the box. Or press {{button:outline|Paste}}.
2. Press {{button:blue|Save the link}}.

The row now shows {{button:outline|Open ↗}}. The icon on the board turns blue.

The button stays grey until the box holds a link. A link starts with https:// and has no spaces.

On another row, press {{button:outline|Set the link}} to open its box.

## Change a link that is wrong

1. Press {{button:outline|Change}} on the row. The box opens with the link the bid has now.
2. Paste the right link over it.
3. Press {{button:blue|Save the link}}.

Press {{button:outline|Cancel}} to leave the link as it is.

## Make the project folder

A bid with no project folder can get one from the app.

1. Press the grey folder icon. The **Project folder** box opens.
2. Press {{button:outline|Make the project folder}}.

The app makes the folder in the company's shared Drive. It names the folder for the bid and puts the photo folder inside. The bid's folder link is filled in.

A folder you made by hand works too. Paste its link in the box. Use a Google Drive folder. The bid's photos cannot be filed anywhere else.

## Add a set of plans

1. Press {{button:outline|Add a set}} on the **Plans** row. The plan sets open under it.
2. Press {{button:outline|+ Add a set of plans}}.
3. Fill in the set and press {{button:blue|Save the set}}.
4. Press {{button:outline|Done}}.

The first set on a bid becomes the set the robot reads. See [keep more than one set of plans on a bid](/help/keep-more-than-one-set-of-plans-on-a-bid).

## Open the whole bid

Each box has **Open Edit bid** at the bottom. It opens the bid on that field. Use it to clear a link or to add a second CountTooling project.

## The photos row

The camera always opens the **Files** window, grey or blue. The photos are its first row.

A grey link icon opens the window with the photos folded away. Press {{button:blue|Add photos}} to open them. On a bid with photos the button reads {{button:outline|Show the photos}}.

See [add photos to a bid](/help/add-photos-to-a-bid).

## On a phone

The five icons sit on the bid's card, under the name. They work the same way.
