A job keeps every set of plans it has seen, and says which one it builds from today. Open the job and press the **Documents** tab. The **Plans** section is there.

An updated set often comes in halfway through a job. The crew also marks up the drawings as it builds. Both have a place here.

## Read what the job builds from

**Building from** names the set the job builds from today. The line under it says what kind of set it is, who sent it and the date on the sheets. Press {{button:outline|Open ↗}} to open the set in Drive.

**Older sets** lists every set that came before. **Our as-builts** lists the drawings the crew marked up.

The Job tab's **Open plans** press opens the same set as **Building from**. The app keeps the two the same.

## A job opened from a bid

A job opened from a bid starts with the bid's plans. The set the bid was priced on becomes **Building from** the moment the job is made. Nothing to press.

On a development, the job joins the part that already builds from that set. When no part does, the job gets a part named after itself. The office can fold it into another part later.

The bid keeps its own sets. See [keep more than one set of plans on a bid](/help/keep-more-than-one-set-of-plans-on-a-bid#pin-the-set-the-price-stands-on).

## Add an updated set

1. Press {{button:outline|+ New set}}.
2. Type the set's **Name**, such as *Addendum 2*. The app starts the name for you.
3. Pick the **Kind** and who it is **From**.
4. Pick the **Dated** day. Use the date printed on the sheets.
5. Type a **Memo**. Say who sent the set and where the file is.
6. Under **What changed**, say what moved from the old set. Name the sheets or areas that moved. Say what it means for our work.
7. Paste the set's Drive link under **Link**. You can leave it empty and add it later.
8. Press {{button:blue|Add the set and build from it}}.

The job now builds from the new set. The old one moves under **Older sets**. Press {{button:outline|Add it, keep Issued set current}} instead to add the set without switching.

On a development, the switch writes one line in the site's **History** for every job on the part. The line reads *Plans · the Bunker now builds from Addendum 1, dated Oct 2, 2026 · replaces Issued set · what changed: the riser moved to the north wall*. Nobody types it.

To switch later, press {{button:outline|Build from this set}} on any older set.

## Say what changed on an older set

Each set shows its change line under its memo. The line names the set before it. An older set with no line shows {{button:outline|Write what changed}} to the office. Press it, write what moved from the set before, and press {{button:blue|Save what changed}}. The site's **Plans** look shows the same line between its sets.

## Save the crew's as-built

1. Press {{button:outline|Add our as-built}}.
2. Keep the name or change it.
3. Type a **Memo** that says what the crew changed.
4. Paste the Drive link to the marked sheets.
5. Press {{button:blue|Add the as-built}}.

The as-built lands under **Our as-builts** with the day and who added it. The line says which set it marks up.

## Open a job's plans from the Pipeline

Every row on the **Pipeline** has a plans icon beside the job folder. A job with one set opens it. A job with two or more sets opens a window that lists them.

1. Press the plans icon on the job's row. The number on it counts the sets.
2. Read each set's name, kind and date. The set the job builds from wears {{chip:green|building from}}.
3. Press {{button:outline|Open ↗}} on the set you want.

Press {{button:outline|Open the Documents tab}} at the bottom of the window to add or switch a set. A job with no set yet opens its old plans link from the same icon.

## A job on a site with other plans

A job inside a development builds from one part of the site, such as the Bunker or the Lodge. The first set on the job asks which part. Pick one the site already has, or make a new part named after the job.

When another part of the site has its own set, an amber note says so. A set on another part may touch this job. Press {{button:outline|Open the site’s plans ›}} to see every set on the site.

## Take a set off

Press **×** on a set, then {{button:outline|Remove}}. Removing a set never deletes the files in Drive.
