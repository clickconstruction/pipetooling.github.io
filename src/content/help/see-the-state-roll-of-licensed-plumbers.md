The State roll tab keeps the state's public list of licensed plumbers who live near us. The tab shows when the list was last read and what changed.

The state plumbing board publishes who holds a license. The app reads that list every Monday morning. The app keeps the plumbers who live in our counties. The app also keeps our own team's licenses, wherever they live.

## Who sees it

You see the tab when you hold the Hiring switch. A shared Hiring column does not open it.

## Open it

Go to [Prospects](/prospects?tab=roll). Press **State roll** in the top row.

## What is kept

The top line names the counties the app keeps. Four counts sit under that line.

- Journeymen kept.
- Masters kept. A responsible master counts as a master.
- Tradesmen kept.
- How many of them hold a lapsed license.

Each person's row has a name, a license, its dates, a county and a ZIP. A row has no phone, street address or email. The state does not publish those.

## Read the pulls

A pull is one read of one state file. The app reads four state files for our counties. Each of the four has a card.

:::example One file's card
**Plumbing · journeyman**

Last read: **11/16/26, 6:40 AM**

Kept: **4,010** of the **26,474** in the state's file

That read: **4** new · **31** changed · **9** gone
:::

- **Last read** is the newest read that finished.
- **Kept** is how many rows live in our counties or belong to our own team.
- **New** is a license that was not on the list last week.
- **Changed** is a license that renewed, lapsed, moved or took a new endorsement.
- **Gone** is a license the state took off its list.

## Pull now

The app pulls every Monday morning. You can pull sooner.

Press {{button:outline|Pull 4 files}}. The app reads each file in turn. The press shows which file it is reading.

A file can fail. The state's site may be down. The app goes on to the next file. Then the app lists each file that failed with the reason. A file that failed changes nothing on the roll.

## When a read fails

A card shows red words when its newest read did not finish. The words give the reason. The card still shows the last read that finished.

Press {{button:outline|Pull 4 files}} to try again.
