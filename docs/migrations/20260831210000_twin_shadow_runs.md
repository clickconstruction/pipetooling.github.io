# 20260831210000_twin_shadow_runs

Fleet roadmap Phase 1 (shadow bidding, v2.2539). One row per live bid the twin
shadow-estimates in parallel with the human estimator: `shadow_bid_id` /
`reference_bid_id` (unique — one shadow per reference), `twin_user_id`, `axis`
(confidence-scoreboard classification), `status` `open → locked → scored`,
`locked_total` + `locked_at` (the blind number, recorded pre-send),
`reference_value` / `delta_pct` / `scored_at` (filled by `score_shadows` once the
human bid carries `bid_value` + `bid_date_sent`).

RLS: staff SELECT only; every write goes through twin-mcp (service role) so the
open/lock/score protocol is enforced in one place. Ends with all three fence
appliers (`apply_read_only_write_blocks`, `apply_read_only_stmt_blocks`,
`apply_digital_twin_write_blocks`).
