# 20261103054522_combine_moves_every_row.sql (2026-11-02, a combine moves every row that would go with the source job's delete, punch list #252, v2.6423)

`migrate_job_ledger_costs_and_delete` moved a named list of tables and deleted the source row; `ON DELETE CASCADE` took every other row that named the job, 52 tables on prod's catalog on 2026-11-02. The card `to-dos/combine-rows.md` sorts them into move, merge and let go with a reason each; this file does the move and merge rows that are not money or legal. Those keep today's behaviour until the owner's word, and a second migration restates this body with them.

- **`jobs_ledger_fixture_carries_checklist()`**: 20261102143000's body with one more table, `job_stage_windows`. A stage's window (one row per job and line) names the line and kept the old job through a split or a combine. A trigger and not a line in each door, as the checklists are. The `COMMENT` names it.
- **`job_supply_house_words_stamp()`**: 20261002140000's body with one gate. A write that changes `job_id` and none of `their_balance`, `notice_on`, `said_by`, `note` keeps `noted_by`, `noted_by_name` and `noted_at`; every other write stamps as before.
- **`migrate_job_ledger_costs_and_delete`**: 20261102143000's body, plus six declarations, one refusal before the write block (`work_order_collision`: a sub both jobs hold a live job-anchored order for, since `step_commitments_job_person_live_uniq` allows one and neither should be cancelled by a rule), the caller's name read once for the hours target's stamp, and the moves and merges after the team members, each with its rule in the comment above it. - **The repair**: a stage window on another job than its line takes the line's job, where no window already stands for that job and line.

Additive and idempotent; no table is created, so no fence call. `CREATE OR REPLACE TRIGGER` takes `SHARE ROW EXCLUSIVE` on `jobs_ledger_fixtures` for a moment, as 20261102143000 did. The generated types do not change: the trigger functions are not callable and the combine's signature stands.
