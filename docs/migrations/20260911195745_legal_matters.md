# 20260911195745_legal_matters.sql (2026-09-11, v2.3313)

Legal portal train, PR 2 — the gate between Collections and a law firm.

**Tables** (all RLS on, office-read via `legal_office_can_read()` = dev / master_technician / assistant / controller; no anon access):

- `legal_firms` — the collections law firm(s): name, handling person, email, phone, `contingency_pct` (default 33), `filing_cost` (default 350), `active`. Dev-only INSERT/UPDATE policies (Settings → Jobs & dispatch → Collections law firm).
- `legal_matters` — one row per paying account (`payer_key` unique: `c:<customer uuid>` or `n:<name>`), `customer_id`, `payer_name`, `firm_id`, `stage` (`review` · `referred` · `demand` · `suit` · `judgment` · `settled` · `written_down` · `pulled`), the attorney-ready stamp (`ready_marked_by/at`, `released_at`), `handling_name`, `note_to_firm`, the review request (`review_requested_by/at`, `review_request_note`), `held_overrides` jsonb (`{"<timeline key>": true|false}`), `fees_to_statement`, `closed_at/reason`.
- `legal_matter_jobs` — the Collections jobs a matter spans.
- `legal_matter_entries` — append-only stream: `kind` (`fee` · `cost` · `step` · `question` · `answer` · `payment_received` · `recovery_applied` · `note`), `amount`, `body`, `occurred_on` (default `app_today()`), `meta`, `via_portal`, `acknowledged_at/by`.

**RPCs** (SECURITY DEFINER, EXECUTE revoked from PUBLIC/anon, granted to authenticated; each gates itself):

- `legal_matter_save_review(payer_key, customer_id, payer_name, job_ids, held_overrides?, request_review?, review_note?)` — office: upsert the matter in place (never changes the stage), replace its job set, store held-entry overrides, set or clear the "ask a dev" request.
- `legal_mark_attorney_ready(payer_key, customer_id, payer_name, job_ids, firm_id, handling_name?, note?)` — **dev only**; stage → `referred`, stamps, clears the request, a `step` entry, one `job_activity_events` row (`legal_change`) per job. This IS the release: the firm's portal (PR 3) reads `stage` in the with-firm set.
- `legal_pull_back(matter_id, note?)` — dev only; stage → `review`, release stamps cleared, step entry + activity events.
- `legal_close_matter(matter_id, stage, note?)` — office; `written_down` or `settled`, `closed_at/reason`, step entry.
- `legal_add_entry(matter_id, kind, amount?, body?, occurred_on?, meta?)` — office append.
- `legal_acknowledge_entry(entry_id)` — office; clears a firm entry from Needs You (PR 4).

Ends with both read-only blocks. Additive; no existing table changes. Apply with `supabase db push` after the PR merges; then `npm run gen-types:linked` (the client reads these tables through an untyped client until the types land). No edge function.
