# 20261020010000_bid_tax_rate.sql (2026-10-19, v2.5653)

The sales tax rate lives on the bid (punch list #128, PR 1). Until now the rate was a box on the Takeoffs tab held in React state: 8.25 on every page load, never saved, applied to a row's takeoff material and left out of the bid's cost total. The rate varies by city, so a bid keeps its own; the company default sits in `app_settings` beside the schedule-of-values factor.

## What it does

1. **`bids.tax_rate_pct numeric(6,3) NULL`** with `bids_tax_rate_pct_range` (0 to 100). NULL = the company default. Percent: 8.25 for 8.25%.
2. **`app_settings` `bid_tax_rate_pct_v1`** seeded 8.25 (`ON CONFLICT DO NOTHING`), the Takeoffs box's old constant; dev writes it on Settings → Bid Cover Letter Defaults, every bid reads it.

No table is created, so the three `apply_*` fences are not called. Idempotent: the column is `IF NOT EXISTS`, the constraint is dropped and re-added, the seed is a no-op the second time.

## Release order

Merge the client first: it reads the column through `select('*')` and falls back to the default while the column is absent, and the box's save fails soft with a toast until the push. Then `supabase db push`, then the types regen PR.

## Verify

Read-only on prod after the push: `select value_num from app_settings where key = 'bid_tax_rate_pct_v1'` reads 8.25; `select count(*) from bids where tax_rate_pct is not null` reads 0 until someone types a rate.
