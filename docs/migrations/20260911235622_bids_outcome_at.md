# 20260911235622_bids_outcome_at.sql (2026-09-11, v2.3354)

Adds `bids.outcome_at timestamptz` — the day a bid was decided — for Bids → Bid Costs → **History & forecast** (the time-to-decision panel). A `BEFORE INSERT OR UPDATE OF outcome, outcome_at` trigger (`bids_stamp_outcome_at`) stamps `now()` when `outcome` enters won / lost / started_or_complete, clears it when the outcome leaves those states, keeps the first day across won → started_or_complete (the job-link trigger's flip is not a new decision), and defers to an explicit client write of `outcome_at`. Back-fills from `bid_versions.outcome_at` (earliest per bid; 2 rows on prod).

Additive and idempotent. No read-only blocks needed (no new table). Client reads the column from the next PR on; deploy order does not matter.
