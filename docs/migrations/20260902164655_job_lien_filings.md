# 20260902164655_job_lien_filings.sql (2026-09-02, v2.2645)

Statutory lien instruments from the Lien instruments modal (phases 3+4 of the
Lien Instruments plan): the § 53.056 notice of claim, the § 53.054 affidavit,
and the release of a recorded lien.

- Columns: `job_id` FK → jobs_ledger (CASCADE), `kind` (notice_53_056 /
  affidavit / release_of_record), `invoice_ids uuid[]`, `amount`,
  `months_covered text[]` ('YYYY-MM' furnishing months a notice attests),
  `fields jsonb` (rendered snapshot), `sends jsonb` (per-recipient
  {recipient, method, tracking, sent_on} — the statute names owner AND
  original contractor; a bounded list, so jsonb over a join table),
  `filed_at` / `county` / `recording_number` (affidavit lifecycle),
  `serve_due` (5th day after filing per § 53.055; partial index drives the
  red serve watch) / `served_at`, `created_by`, `voided_at`.
- RLS: same office set as `job_lien_releases` / `job_demand_letters`; insert
  requires `created_by = auth.uid()`; delete dev-only. Ends with both
  read-only-block calls.
- Companion edge fn (deployed separately): `send-lien-filing-email` — emails
  the notice PDF as a courtesy channel; the sends jsonb records it as
  method 'email' with the Resend id as tracking.
- Additive/idempotent; the client fails soft everywhere it reads the table.
  Applied during the v2.2645 merge window; types verified against
  `gen-types:linked`.
