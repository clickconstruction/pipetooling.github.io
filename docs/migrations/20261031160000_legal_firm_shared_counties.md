# 20261031160000_legal_firm_shared_counties.sql (2026-10-31, v2.6227)

Firms and their coverage, PR 3 of four (punch list #222, `to-dos/legal-firm-coverage-zones/README.md`): two firms may cover one county, and one of them is its first call.

- **`legal_firm_counties.first_call`** (boolean, not null, default true): the existing rows, one per county, stay their county's first call. A closed row keeps the value it had.
- **Indexes**: `legal_firm_counties_live_firm_county_uidx` (one live row per firm per county) and `legal_firm_counties_live_first_call_uidx` (at most one live first call per county) are created; `legal_firm_counties_live_county_uidx` (one live row per county, v2.5756) is dropped.
- **`legal_save_county_coverage(p_counties jsonb) → jsonb`**: the one write of the county map. Each item is `{county, firms: [uuid], first_call: uuid|null, was: [uuid]}`. Every item is read before any is written; a refusal (a firm that no longer stands, a first call outside the county's firms, a bad id, an empty save) returns `{error}` and writes nothing; a county whose active firms differ from `was` returns `{error: 'stale', county}` and writes nothing. Then for each county it closes the rows of firms that no longer cover it (a retired firm's leftover row too), inserts the new firms as not first call, and sets the first call: the one named, else the first call that still covers it, else the longest-standing. Dev only (`is_dev()`), never a training account (`is_read_only()`). `SECURITY DEFINER`, granted to `authenticated`, revoked from `anon`.
- **Bed**: `scripts/pgtest-legal-firm-coverage.sh` over `supabase/tests/legal_firm_coverage/20_shared_counties.sql` (a share, a first call moved, a stale save refused, a save with one bad county writing none, the first call leaving a shared county, history kept, a retired firm's row closed, the indexes refusing a second first call and a second live row per firm).

Apply order: **push right after the merge.** The Settings picker, Firms… and the firm window save through `legal_save_county_coverage` from this release on; until the push their save reads *Saving counties needs a database update that is not live yet*. Reads are safe both ways: the client reads `first_call` when it is there and treats a row without it as first call. The `legal-portal` function names its columns and is unchanged.
