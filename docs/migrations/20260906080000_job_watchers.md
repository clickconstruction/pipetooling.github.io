Watchers (PR 6 of the three-party scheduling plan, artifact 3a540149).

- **`job_watchers`** — (job, user): `hear_progress` (default true), `hear_done` (true), `hear_dates` (false), `source` (`manual` | `assigned`), `created_by`, timestamps. `UNIQUE (job_id, user_id)`. Assigned superintendents (`jobs_ledger_team_members` × `users.role = superintendent`) watch by default without a row; a row adds someone or changes what one hears.
- **`job_watcher_notices`** — one row per watcher email, or a folded skip (`sent = false`) when one went out for the same (user, job, kind) inside the hour. Written by the `submit-sub-portal` function.
- **RLS**: `job_watchers` — select for the office set + superintendents + your own rows; insert / update / delete for the office set and for your own row. `job_watcher_notices` — select for the office and your own; no client writes. Both fence appliers run.
