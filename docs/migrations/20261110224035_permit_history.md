# 20261110224035_permit_history.sql (2026-11-10, v2.6873)

Permits: history read further back (punch list #307, the rest of PR 4; `to-dos/bid-permits/`). One column and one read replaced in place.

## What it does

- **`permits.backfilled`** (boolean, not null, default false): true on a row `permit-pull` read back as history, past the day the records started. Every row already held, and every row the nightly pull brings, is false.
- **`research_permits(city, since, residential)`**, same shape, replaced from `20261110090000_permit_skim.sql` with one added condition: a backfilled building permit is not returned. The skim holds every unanswered permit however old, so without this a read back would put two years of old permits on it. Kept, Closed, the ledger, the map and `permit_skim_wait` read through the same function and stay as they were.

A backfilled permit still counts where history is the point: `research_builders` and the builder stats in `research_permits_v2` (a builder's permits in a year), the plumbing pairing, and `bid_site_permits` (a bid's site).
