# 20260902151658_rfq_desk_lane_b

Lane B, the RFQ Desk (v2.2636). Additive columns on `bid_rfqs`:
`sent_email` (who the request emailed), `resend_email_id` (joins the
existing resend-webhook → email_send_log delivery rail), `viewed_at`
(stamped by get-rfq-quote-page on first open — the strong "Viewed"
signal), `last_reminded_at` + `reminder_count` (24h nudge throttle),
`vendor_note` (the sender's one-liner in the email). RLS on bid_rfqs
unchanged.

Also `email_send_log_rfq_select`: email_send_log was dev-only SELECT;
the desk needs delivery state, so this policy opens exactly the rows an
RFQ references to exactly the five cost-side roles (`u.role` is the
`public.user_role` enum — the ANY array must cast, plain text errors
42883). Plus an index on `email_send_log.resend_email_id` for the join.
