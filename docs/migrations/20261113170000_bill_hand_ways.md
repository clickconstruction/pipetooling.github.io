# 20261113170000 — bill_hand_ways (v2.7166)

The list under *How the bill went* in **Say how it went…** on Bills sent becomes the office's own (punch list #340, PR 2; the owner's picks of 2026-11-13). Until now it was four choices in code. This file makes the list a table, seeds it with those four, and lets a sent copy say a bill went another way.

- **`bill_hand_ways`**: one way per row. `key` is the code a record carries in `source_snapshot.how`: never made from the words, never changed. The four first rows keep `handed`, `mailed`, `own_mailbox` and `housecall_pro`; a way the office adds gets `w_` and ten random characters. `label` is the words (1 to 60 characters, trimmed). `sent_how` is what the sent copy's own `how` gets (`hand`, `mail`, `email`, or `other` for a way the office typed). `sort_order` is its place. `retired_at`, `retired_by` and `retired_by_name` say when and by whom it was taken off; the row is never deleted by the office. `created_by`, `created_by_name`, `updated_by` and the two times are the database's.
- **`bill_hand_ways_live_label_key`**: one live way per set of words, whatever the capitals. A way taken off frees its words.
- **`bill_hand_ways_guard()`** (`BEFORE INSERT OR UPDATE`, a definer with an empty search path, never callable by hand): for a signed-in writer it trims the words, makes a new way's key, sets `sent_how` to `other` and appends it at the end, holds `key`, `sent_how` and the made-by stamps still on an update, stamps a retire with now and the person whatever the client sent, and refuses in a sentence a person can read: *That way is already on the list.* (`23505`), *The list is full at 12 ways. Take one off first.* (`23514`, a new way or one brought back), *The list needs one way. Add another before you take this one off.* (`23514`). The checks run under one advisory lock, so two writers wait their turn. A row with no signed-in writer (this file's own four, the service role) is taken as given.
- **Policies**: `bill_hand_ways_select_office`, `_insert_office` and `_update_office` are `is_office_staff()` (dev, master, assistant, controller: the people who open Bills sent). `bill_hand_ways_delete_dev` is `is_dev()`. `anon` holds nothing.
- **`sent_documents_how_known`** gains `other`: dropped and added again `NOT VALID`, then validated, so the lock that blocks writers is short.
- **The four fences** (`apply_read_only_write_blocks`, `apply_read_only_stmt_blocks`, `apply_digital_twin_write_blocks`, `apply_archived_read_blocks`) end the file, so a training-mode account, a twin and an archived caller are held off the new table.
- Idempotent: `IF NOT EXISTS`, `CREATE OR REPLACE`, `DROP … IF EXISTS` then create, and the seed is `ON CONFLICT (key) DO NOTHING`, so a way the office renamed is not put back.

Checked before the PR on a local Postgres 15 with stand-ins for `users`, `auth.uid()`, the two role helpers, `sent_documents` with its old check and the four fence functions as no-ops, the file applied twice in one transaction each. Played as each role: an estimator reads no row and is refused the insert; an assistant's insert gets a made key, `other`, the next place and her name, whatever key, how, place and name the client sent; a second *MAILED* is refused; a controller's rename keeps the key and `sent_how`; a retire is stamped now with his name; a retired way's words are free for another and its return is then refused; the 13th live way and the return of a 13th are refused and a retire makes room; the last way cannot be taken off; the office's delete removes nothing and a dev's does; 61 characters are refused; a sent copy with `how = 'other'` is taken. **Not in that bed:** the real fences and the real `is_office_staff()`; CI's SQL beds apply the file over the whole schema.

Deploy order: **push right after the merge.** The client of the same PR reads the table and falls back to the four ways in code while the read is refused, so the form works in between. No record has `how = 'other'` until a way is added, which the screen cannot do before PR 3.

Rollback: `DROP TABLE IF EXISTS public.bill_hand_ways; DROP FUNCTION IF EXISTS public.bill_hand_ways_guard();`. The form falls back to the four in code. Leave `other` in `sent_documents_how_known` unless no row carries it.
