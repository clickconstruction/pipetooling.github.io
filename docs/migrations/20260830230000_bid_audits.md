# 20260830230000_bid_audits

Adds the audit-loop spine for robot bids (v2.2516, FEEDBACK_LOOP v2):

- `bid_audits`: one per bid (`bid_id` unique), CT quick-link columns
  (`ct_project_id`, `ct_view_url`), `status` `pending|done|digested`,
  lifecycle timestamps.
- `bid_audit_notes`: sectioned threaded notes (`section`, `kind`, `parent_id`),
  digest bookkeeping (`digested_at`, `digest_outcome`).

RLS: staff read (bid-pricing read roles) / write (bid-pricing write roles),
mirroring `bids_rfis`. Restrictive twin lanes: twins never set
`bid_audits.status = 'done'`; twin-authored notes limited to
`kind IN ('question','receipt')`. Ends with `apply_read_only_write_blocks()`,
`apply_read_only_stmt_blocks()`, and `apply_digital_twin_write_blocks()`.

Idempotent (`IF NOT EXISTS` / `CREATE OR REPLACE` / drop-recreate policies);
additive only.
