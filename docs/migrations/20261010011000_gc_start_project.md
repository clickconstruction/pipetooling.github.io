## What it does

**`gc_start_project(project_id, anyway jsonb DEFAULT NULL)`**, `SECURITY INVOKER`, returns the day the job started (`public.app_today()`).

1. **Who may run it.** Before any write it refuses, in words:
   - no sign-in;
   - a training account and a digital twin (`42501`);
   - anyone but a dev, until award's door (call B). `gc_projects` is the office's table, so this refusal is the function's own.
2. **Which jobs can start.** It locks the job's row, then refuses, each naming the job:
   - a job that is not there;
   - a lost one (*Bring it back*);
   - one already started or closed;
   - one still bidding (*We won this*).
3. **Start.** A won job (buyout) goes to building, with `started_on` set to the company's day. It is the first write that moves a project to building. The daily log and the schedule's building-only writes open on it.
4. **Start anyway** (`{reason, missing[]}`) keeps:
   - who pressed it (`started_anyway_by = auth.uid()`);
   - the reason, trimmed;
   - the missing lines as the office's screen listed them, in order, with blanks dropped.

   The database trusts that list (call A): Start signs nothing and moves no money. Anyway with nothing missing is a plain Start. These are refused in words:
   - no reason;
   - a reason over 500 characters;
   - over 60 lines, or a line over 300 characters;
   - a malformed anyway.
5. **What it leaves to others.** It sends nothing: the client tells the trades after it (`gc-trade-email`, kind `start`, B6-c-ii). It writes no baseline: the schedule keeps one at its first plan write after Start (`gc_schedule_keep_start`, dated `started_on`).
6. **Grants.** `PUBLIC` and `anon` are revoked, and `authenticated` is granted.
