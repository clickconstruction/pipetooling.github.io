# 20261030230000_robot_fixtures.sql (2026-10-30, v2.6180)

Robot fixtures, PR 1 of five (punch list #221, `to-dos/robot-fixtures/README.md`): the ground under the window where the estimator takes the robot's fixtures into her count.

- **`bid_fixture_pulls`** — one per read the robot writes with `put_fixtures`: the human bid, the shell, the live run, the set link it read, the CountTooling link, the sheet count, `source` (`robot` · `derived`), `check_summary` (`{agree, conflict, unverifiable}`), `robot_total`, `read_at`. **`bid_fixture_pull_rows`** — tag, name, the schedule row, `count` + `unit`, `per_sheet` (with the robot's pins), `backing` (every plan line that names the tag, with flags), `scope_flag`, `confidence`, `agreement`, `remark`, `ct_pin_ids`, `robot_book_entry`, `robot_unit_price`; the take (`taken_at/by/as`, `taken_count`, `prior_count`, `count_row_id`, `priced_as`, `custom_price_id`); the set-aside (`set_aside_at/by/reason`). SELECT under `can_access_bid_for_pricing(bid_id)`; no write policy — the verb writes with the service role, the RPCs below are SECURITY DEFINER.
- **`bids_count_rows.plan_tag`** (text, null) — the robot's tag on a landed row. **`bid_count_sources.source_kind`** (`counttooling` · `robot`, default `counttooling`). **`twin_shadow_runs.assisted_at`, `assist_kind`, `fixtures_score`**.
- **`robot_progress(uuid[])`** dropped and recreated with `fixtures_at`, `fixtures_found`, `fixtures_sure`, `fixtures_taken`, `fixtures_set_aside`, `assisted_at` added (the return shape changed; the client reads columns by name, so the old client is unaffected).
- **RPCs** for the bid roles, each checking `can_access_bid_for_pricing` on the pull's bid and refusing on a sent bid (*The bid is sent, the count is the record.*): `take_robot_fixtures(p_row_ids uuid[], p_bid_version_id uuid, p_updates jsonb)` (lands added rows on the version with the robot as a count source and the shade's share, applies updates onto her paired rows keeping `prior_count`, prices each added row by her book by name or by the robot's price as a custom price, stamps the run assisted, leaves `[robot fixtures] took N of M` on the ledger), `untake_robot_fixtures(p_pull_id)` (Undo), `set_aside_robot_fixtures(p_row_ids, p_reason)` (removes an added row through the ledger, returns an updated row to her number, keeps `taken_count`), `put_back_robot_fixtures(p_row_ids)` (clears the set-aside; a row she had taken lands again at her number), `price_robot_fixtures(p_bid_id, p_price_book_version_id)` (prices the taken rows that landed before a book was picked).
- **`score_locked_shadows`** — body as v2.4199 plus the fixtures score when the reference bid has a pull: `{found, taken, changed, set_aside, left, reasons, missed}` on the run and a `[robot fixtures SCORE]` line on both ledgers.
