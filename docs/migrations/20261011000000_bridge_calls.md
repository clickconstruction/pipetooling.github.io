# 20261011000000_bridge_calls.sql (2026-10-11, v2.5233)

The Bridge's weekly call, PR 2 of the weakest-link build (`to-dos/bridge-weakest-link/`). One table, `bridge_calls`: one row per call on a pay week (`week_start`), the link named (`link`: one of the five stages or the three resources), the moves with owners (`moves` jsonb: `[{ key, title, who, then }]`), a snapshot of the page's reading at call time (`measures` jsonb: the link's weeks to clear, every stage's weeks, and the numbers behind the moves), and Friday's answer (`outcome` moved / did_not_move, `outcome_at`, `outcome_note`). The newest row for a week is the call. Dev-only RLS through `public.is_dev()`; the three write fences applied.

Apply with `supabase db push` after the PR merges; the client reads the table through `as never` casts until `npm run gen-types:linked` is run, so nothing breaks in either order.
