# 20261031161000_legal_hand_off_counties.sql (2026-10-31, v2.6233)

Firms and their coverage, PR 4 of four (punch list #222, `to-dos/legal-firm-coverage-zones/README.md`): hand counties off from one firm to another in place of replacing the firm everywhere, and retire as its own step.

- **`legal_hand_off_counties(p_from_firm uuid, p_counties text[], p_to_firm uuid default null, p_new_firm jsonb default null, p_retire boolean default false) → jsonb`**: moves the counties named from the giving firm to the receiving firm in one transaction. The giver's row for each county closes (history kept), the receiver covers it (a new row when it did not), and the receiver becomes the county's first call. The receiver is an active firm, or a new one from `p_new_firm` (`name`, `handling_name`, `email`, `phone`, `contingency_pct`, `filing_cost`) added in the same call. With `p_retire` the giver is retired in the same call, only when it covers no county afterwards and holds no live matter. Every check runs before any write: the giver standing, the receiver standing and not the giver, every county one the giver covers now, the retire's conditions. A live matter never moves.
- **`legal_retire_firm(p_firm_id uuid) → jsonb`**: retire as its own step, only when the firm covers no county, holds no live matter, and another firm stands (the desk is never left with no firm; the only firm is replaced, not retired).
- **`legal_retire_firm_now(uuid)`** and **`legal_firm_live_matter_count(uuid)`**: helpers for the two above, revoked from `anon` and `authenticated`. Retiring revokes the firm's portal link and forgets its secret (`legal_portal_link_forget_secrets`), sets `active = false` and `paused_at`, and keeps the history, as `legal_replace_firm` (v2.4712) does. The live-matter stages are `legal_replace_firm`'s.
- Both public functions are dev only (`is_dev()`), never a training account (`is_read_only()`), `SECURITY DEFINER`, granted to `authenticated`.
- **Bed**: `supabase/tests/legal_firm_coverage/30_hand_off.sql` in the `legal-firm-coverage` bed.

Apply order: **push right after the merge.** The firm window's *Hand off counties…* and *Retire* call these functions from this release on; until the push they read *Handing off needs a database update that is not live yet*. `legal_replace_firm` stays: the window still offers Replace for a firm that covers no county (the bridge's stand-in).
