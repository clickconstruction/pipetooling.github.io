# 20260928045522_gc_word_asks.sql (v2.3985)

Punch list #49, step 7 — ask by link.

## Tables

- **`gc_word_asks`** — one live link per `(week_start, owner_user_id)` (partial unique index on `revoked_at IS NULL`): `gc_ids uuid[]`, `token` + `token_hash`, `created_by` / `created_by_name`, `expires_at`, `emailed_at` / `emailed_to`, `opened_at`, `answered_at`, `revoked_at`.
- **`gc_word_ask_answers`** — one row per `(ask_id, gc_customer_id)`: `temperature` (CHECK), `note`, `expected_pay_by`, `no_change`, `answered_at`, `status` (`pending | accepted | dismissed`), `decided_by*`. A shape CHECK refuses an empty answer: `no_change`, or a temperature with a sentence of 8+ characters.

## Access

RLS on both. SELECT: dev · master_technician · assistant · controller · primary. UPDATE on answers: the four office roles, `WITH CHECK (decided_by = auth.uid())`, and a **column grant** limits it to the decision fields. No INSERT or DELETE policy — rows come from `mint_gc_word_ask()` and the `gc-word-ask` edge function (service role).

## Functions

- **`mint_gc_word_ask(p_owner_user_id, p_gc_ids, p_rotate default false)`** → `{ askId, token, expiresAt, createdAt, reused }` or `{ error }`. `SECURITY DEFINER`, office roles. Returns the week's live, unexpired link (bringing its `gc_ids` up to date) or mints one; `p_rotate` revokes first. Unknown GC ids are dropped; none left, or more than 60, is refused. Eight-day life.
- **`revoke_gc_word_ask(p_ask_id)`** → `{ revoked }`. Answers already given stay.

## Also

`gc_statement_round_marks.word_heard_via` CHECK gains `'link'`.

Ends with both read-only block calls (new tables). Idempotent; opens with `SET lock_timeout = '3s'`.

## Tested

On a throwaway local Postgres 15 with the real mark migrations over stub tables, applied twice:

- A helper and a signed-out caller cannot mint; an assistant can. The token is 64 hex characters and its hash matches.
- Minting again reuses the link and updates its GCs; rotate leaves exactly one live link.
- The shape, temperature and status CHECKs refuse bad rows.
- As `authenticated`: a helper reads nothing; an assistant reads, accepts as herself, cannot decide as someone else, cannot change what he said, cannot insert or delete.
- `word_heard_via = 'link'` is accepted on a mark; an unknown value is not.
