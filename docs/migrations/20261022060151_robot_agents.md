# 20261022060151_robot_agents.sql (2026-10-22, v2.5733)

Robot rounds, PR 3 (punch list #142, decision 8): the Console's status rows and the stop. Two SECURITY DEFINER functions; no table changes.

- **`robot_agents()`** — one row per unrevoked key seen in the last seven days (a key is a seat on a Mac): the key's label and age, the robot's name and seat kind, `last_seen_at` (v2.5730's stamp), the stop columns with the stopper's name, the latest non-idle heartbeat with its shape and the bid it names (the shell, and the human bid behind it with its id), whether that shell is still open, today's idle rounds (the collapsed rows' `progress.rounds`, company day), and `recent`: the last five things the robot finished in seven days as JSON (shadows sealed, scored or parked on a plans ask; matrices ready or blocked; submittal tasks; reports), each with the bid's id for a door. Devs and the master only, checked inside. No money column; a scored run's delta is public once scored.
- **`robot_rounds_stop(p_credential_id, p_stop)`** — Stop the rounds (`stopped_at = now()`, `stopped_by = auth.uid()`) or Start again (both null) on one live key; a dev or the master; refuses otherwise. The round reads the columns in the reply to its next heartbeat (`orders: stop`, rounds only).

Additive and idempotent. Push after `20261022052738_twin_heartbeat_progress`; the Console reads fail-soft before the push.
