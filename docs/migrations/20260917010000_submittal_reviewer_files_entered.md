# 20260917010000 — reviewer files and "entered by" (v2.3543, Submittals stage 5b)

`bid_submittals.reviewer_files jsonb NOT NULL DEFAULT '[]'` — the reviewer's redlined PDFs / forwarded emails the office dropped on the revision (`[{ path, name, kind: redline | email, dropped_at, dropped_by, dropped_by_name, person_id, person_name }]`; objects in the `bid-submittals` bucket under `<bid>/<rev>/reviewer/`). On `bid_submittal_items`: `decision_source text NOT NULL DEFAULT 'room'` CHECK room · entered · robot, `decision_entered_by uuid REFERENCES users ON DELETE SET NULL`, `decision_entered_by_name text`. No table, no policy change — the pricing sharers already write both tables on bids they can price; the room's function reads the decision fields it always read. Idempotent (`ADD COLUMN IF NOT EXISTS`, the CHECK guarded by `pg_constraint`). Apply with `bash scripts/db-push.sh` once on `main`.
