# 20261024040000_office_inbox_papers.sql (2026-10-24, v2.5815)

Adds `public.office_inbox_papers`: one row per paper in the office's physical tray that took more than two minutes, the table behind Quickfill's **Physical inbox** station redrawn as a clarify deck (punch list #158). Columns: `title` (≤ 200), `detail` (≤ 2,000), `came_on` (a date, default `app_today()`, the age counts from it), `created_by`, `state` (`open` on the deck · `waiting` · `someday` · `closed`), `outcome` (the press that took it off the deck: `done` · `trash` · `filed` · `task` · `request` · `waiting` · `someday` · `routine`), `outcome_detail` (where filed, whom waiting for, which inbox asked), `follow_up_on` (a waiting paper's check day), `outcome_at` / `outcome_by`, and three links to what a press made, each `ON DELETE SET NULL`: `checklist_item_id`, `dispatch_request_id`, `estimator_request_id`. A check holds `state` to its `outcome` (open ↔ null, waiting ↔ waiting, someday ↔ someday, closed ↔ any press). Indexes on `(state, came_on)` and `outcome_at`; the house `update_updated_at_column()` trigger on update.

RLS is the section marks' gate, `is_dev_or_master_or_assistant()`, for select / insert / update / delete; `authenticated` gets the four grants. The three house calls close it (read-only training mode, the statement trigger, the twin fence).
