# 20260920232141_dev_health_rpcs.sql (2026-09-20, v2.3649)

Four read-only doors for dev-mcp's health checks (`to-dos/mcp-servers.md` PR 5). The freeze monitor (`monitoring.*`), `pg_stat_activity` and `supabase_migrations.schema_migrations` are outside the `public` schema, so PostgREST cannot read them and an edge function cannot run ad-hoc SQL. Each function is `STABLE SECURITY DEFINER`, returns one `jsonb`, raises `42501` unless `public.is_dev()`, and has EXECUTE revoked from `PUBLIC` / `anon` and granted to `authenticated` — so dev-mcp reads it over GET **as the dev**, in a read-only transaction, with no service role:

- `dev_health_sampler_gaps(p_hours int default 24)` — gaps over 90 s between `monitoring.health_checks` rows, the slowest `sample_duration_ms`, and the count over 250 ms (`DB_FREEZE_RUNBOOK.md` Step 2a + the leading indicator). `p_hours` is clamped to 1–336.
- `dev_health_connections()` — the newest `monitoring.connection_samples` sample: total against `max_connections`, by state / wait event, by database role, its age, and the newest `health_checks` row.
- `dev_health_locks()` — live from `pg_stat_activity` + `pg_blocking_pids`: waiters, their blockers (transaction age, how many each blocks), and transactions idle over 60 s. Statement text is cut at 300 characters. It reads; nothing here terminates a backend.
- `dev_migration_ledger_tail(p_n int default 15)` — the applied count and the newest `version, name` rows (clamped to 1–100).

`plpgsql` throughout, so the file applies even where a monitored relation is missing (the call says so). No `CREATE TABLE`, so no read-only fence appliers. Exercised before merge on a throwaway Postgres 15 with stub `monitoring` tables: applied twice (idempotent), refused for a non-dev and for `anon`, run inside `BEGIN TRANSACTION READ ONLY`, and `dev_health_locks` named a real waiter / blocker pair.

Apply order: any. Until it is pushed the four verbs answer PostgREST's "function not found"; after the push, `npm run gen-types:linked` → `node scripts/build-dev-mcp-catalog.mjs` so `find_rpc` / `call_read` list them too (the named verbs do not wait for that).
