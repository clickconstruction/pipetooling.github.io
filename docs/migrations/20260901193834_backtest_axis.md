# 20260901193834 — bids.backtest_axis (v2.2594)

Nullable `text` column on `public.bids`: the dev-assigned confidence axis a
decided bid would feed as a backtest reference. Today an axis exists only once
a run is opened (`twin_run_scores` / `twin_shadow_runs` rows carry it); the
Queue lens's Backtest candidates section (v2.2594) needs one *before* any run
to group candidates by demand, so the operator assigns it from the row's
"assign axis ▾" select.

- Values are free text matching the run tables' axis strings (`small TI`,
  `kitchen/occupied`, …); null = unclassified (renders in the Queue's
  unclassified bucket).
- Additive, idempotent (`ADD COLUMN IF NOT EXISTS`); rides bids' existing RLS
  and the twin write-fence unchanged. No CREATE TABLE — the read-only/twin
  appliers are not required.
- Client reads the column defensively (untyped cast) until the post-push
  `gen-types` run — deploy the client first, push after merge, then regen.
