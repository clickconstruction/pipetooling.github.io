# 20261107090000_doc_history.sql (2026-11-07, v2.6622)

What moved on a document on a person's HR file, for dev-mcp's `get_document_history`, punch list #278 PR 4 ([v2.6622](../recent-features/v2.6622.md)).

- **`dev_doc_history(p_person_id, p_doc_id default null, p_kind default null, p_from default null, p_to default null)`**: `SECURITY DEFINER`, `search_path = public`, raises `42501` unless `auth.uid()` is set **and** `public.is_dev()`. Exactly one of `p_doc_id` (a `person_documents` row on that person) or `p_kind` (`summary` | `narrative`). Returns `{ now, revisions, from, to }`: `now` the row as it stands (`doc_id` | `kind`, title, counsel mark, `updated_at`, `kept_by`, `updated_by` as the user's name, `chars`, `archived_at` or `covered_through`); `revisions` newest first from `person_document_revisions` or `person_file_revisions` (`id`, `replaced_at`, `replaced_by` as a name or the label, `kept_by`, `title`, `counsel_only`, `chars`), without their text.
- With `p_from` (a revision id of this document) and `p_to` (another, or null for the text as it stands), `from` and `to` carry the two texts whole for the edge function to diff — they never reach the agent; a revision that is not this document's is refused.
- EXECUTE revoked from `PUBLIC` and `anon`, granted to `authenticated` (the gate is inside).

No table, so no fence appliers; reads the revisions tables the triggers of `20260824141540` and `20261107040000` fill. Idempotent.
