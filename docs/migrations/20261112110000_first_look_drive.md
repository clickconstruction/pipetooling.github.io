# 20261112110000_first_look_drive.sql (2026-11-12, v2.7001)

First look in Google Drive (punch list #319 PR 2). The photo sweep files what a customer sends into the customer's **Customer supplied photos** folder, and these columns are where it keeps its place. No new table, so no fence call.

## What it does

Every column is nullable with no default, so each `ALTER TABLE … ADD COLUMN IF NOT EXISTS` is a catalog change that rewrites nothing.

- **`first_looks.drive_folder_id`**: the look's own folder in Drive, once the sweep has made it.
- **`first_look_files.drive_file_id`**, **`filed_at`**: the file's copy in Drive and when it got there.
- **`first_look_files.fail_why`**: why the last try did not file it, for the card to say.
- **`first_look_files.drive_tried_at`**: when the sweep last looked at it. A file that cannot file yet goes to the back of the line.
- **`first_look_files.drive_upload_uri`**, **`drive_upload_offset`**: a video's copy in pieces. Drive's address for the upload and how far it has got, cleared when the copy is whole.
- **`first_look_files_to_file_idx`**: a partial index on `(drive_tried_at NULLS FIRST, finished_at)` over finished files not in Drive, which is what the sweep asks for every five minutes.

## Who may do what

Unchanged. The office team reads both tables, so they read the new columns. Only the service role writes them (`photo-save`).

## Release order

Merge, `bash scripts/db-push.sh`, then `supabase functions deploy photo-save`. The thread's card selects `drive_folder_id`, `drive_file_id` and `fail_why`, and reads without them from a database that has not been pushed yet, so nothing breaks in between. A sweep deployed ahead of the push reports the looks pass as failed and files every other source as before.

## Verify

Read-only on prod after the push: `select column_name from information_schema.columns where table_name = 'first_look_files' and column_name in ('drive_file_id','filed_at','fail_why','drive_tried_at','drive_upload_uri','drive_upload_offset')` reads six rows; `select indexname from pg_indexes where indexname = 'first_look_files_to_file_idx'` reads one.
