# 20260902030531_rfq_quotes_store

RFQ Phase 1a store (v2.2629; docs/SUPPLY_HOUSE_RFQ_PLAN.md). Four
tables: `bid_rfqs` (scope jsonb snapshot, bid_version_id, nullable
supply_house_id, token unique for the Phase 2 link lane, status),
`bid_quotes` (rfq_id nullable — paste-back needs no RFQ; source
link/pasted/typed; valid_until; freight_cents; raw_paste provenance),
`bid_quote_lines` (unit_price_each_cents derived truth + price_basis/
basis_qty/basis_price_cents as pasted; cant_supply; alternate_note;
match_confidence; picked for the future PO handoff), and
`supply_house_fixture_prices` (name-keyed last-quoted memory, generated
fixture_key = lower(btrim), unique per house). RLS read+write =
dev/master/assistant/controller/estimator only (vendor costs). Ends
with all three fence appliers.
