# 20260825193140_bid_tab_entries.sql (2026-08-25, v2.2296)

New table `bid_tab_entries` — the FULL bid tab (one row per bidder amount,
ours flagged) behind the paste-capture flow. The four `bids.bid_tab_*`
summary columns (v2.2081) stay authoritative for analytics; a paste save
derives and writes them, entries are the richer layer underneath.

Columns: `bid_id → bids` (CASCADE), `amount numeric NOT NULL`,
`alternate_amount numeric`, `bidder_name text`, `is_ours boolean`,
`created_at`, `created_by → users`. Index on `bid_id`.

RLS mirrors `bid_version_sends`: `can_access_bid_for_pricing(bid_id)` for
SELECT/INSERT/UPDATE/DELETE. Ends with both read-only block calls.

Client fail-soft before push: ladder reads report unavailable (hidden),
paste saves keep the summary and toast that the full list couldn't be stored.
