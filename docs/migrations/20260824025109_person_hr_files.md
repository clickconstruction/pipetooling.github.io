# 20260824025109_person_hr_files.sql (2026-08-23, v2.2220)

HR files (People → HR, dev-only). Two tables keyed on `people.id`: **`person_file_entries`** — the append-only raw log (`entry_date` supplied by client/agent in `APP_CALENDAR_TZ`, `content`, `source` ∈ conversation / payroll_event / incident / review / milestone / job_event, `created_by`); dev SELECT + INSERT policies only — **no UPDATE/DELETE policies by design** (corrections are new entries; break-glass edits are dev SQL). **`person_files`** — the curated docs, `kind IN ('summary','narrative')`, `UNIQUE(person_id, kind)`, dev-manage-all policy; regenerable from the entries. Index `(person_id, entry_date DESC)`. Ends with both read-only blocks. **Apply order:** push before the client PR that reads the tables (tab is dev-only either way).
