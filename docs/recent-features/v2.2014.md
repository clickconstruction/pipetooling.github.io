# v2.2014 — Portal globe modal rework: custom address hero + flat gear (2026-08-21)

PR B of the portal custom-links train (PR A backend: v2.2008). The
owner-approved mockup made real in `CustomerPortalGlobeButton.tsx`.

- **Hero**: `pipetooling.com/p/` + inline-editable slug (prefilled from the
  customer name via `suggestSlugFromName`), "Editable until first shared" on
  the left, advisory guess-meter (⚠ easy / ✓ hard, never blocking) on the
  right. **Copy link** persists the slug (`set_customer_portal_slug`), locks
  it on first copy (`mark_customer_portal_slug_shared`), and copies the short
  URL from `portalShortOrigin.ts`. Preview + live iframe unchanged (token
  URL, so preview works before any slug exists). The As customer / As GC
  toggle is gone — the modal manages the merged `'all'` link.
- **Gear — one flat label-per-row table**: Direct link (truncated token URL +
  Copy; "always works, even while the address changes") · Address (pre-lock:
  🎲 Random tail; post-lock: inline editor + 🎲 + Save behind a
  stale-copies confirm) · Separate views (create `'gc'` / `'customer'`
  scoped links on demand; each shows with Copy + Turn off) · Reset (Rotate
  rotates `'all'`; Turn off revokes `'all'` **and** any active scoped links)
  · History (`buildPortalTimeline`: per-audience link lifecycles merged with
  slug created/changed/locked events).
- **No-silent-revive, extended to the merged world**: active `'all'` →
  active; `'all'` rows all revoked → OFF (even with active scoped links);
  legacy-only rows all revoked → OFF; never-minted or active-legacy-only →
  auto-mint `'all'` (a continuation, not a revival). Kernel:
  `computePortalMainOffCustomerIds` — also powers the red globe via the
  reworked `usePortalOffStates` (`setPortalMainOff`; scoped-link off never
  paints red).
- **Kernels + tests**: new `portalSlug.ts` (normalize / validate / suggest /
  guess-meter / random tail with injectable rng) + tests;
  `portalLinkState.ts` gains the main-off and timeline builders + tests;
  render smokes rewritten (5 scenarios incl. legacy-off and locked-address).
- `defaultAudience` prop removed from the globe button (callers in
  `Customers.tsx` and `jobsStagesRowShared.tsx` updated); regenerated
  `database.ts` after the PR A migrations rode in here.
- Help guide `share-a-customer-their-portal.md` rewritten around the address
  flow, gear rows, and the merged AS GC statement.
