# v2.5451 — Messages: a customer's name opens their messages, and the Dashboard's Customers line is on (2026-10-13)

Residential customers in Messages, R2 PR 3b, the openers (`to-dos/gc-mode/messages/RESIDENTIAL_BUILD_PLAN.md` → R2,
on branch spike/gc-mode), by customer communication helper 9 for the customer communication lead. Stacked on R2 PR 1
(v2.5446, the Messages page) and R2 PR 3a (v2.5437, `contact_for_customer`). No migration.

- **`src/components/messages/MessagesButton.tsx`**: a speech bubble beside a customer's name. A press asks
  `contactForCustomer` for the customer's own contact, which the function finds or makes with the number and address
  on file, runs `onOpen`, then opens `/messages?thread=<contact>`. A refusal shows its words and the page stays. It
  draws only for `canOpenMessages` roles, read through `useOptionalAuth`, so a screen with no sign-in draws nothing and
  the router and toast hooks are asked only when it shows. Its press stops there, so the row or name under it never
  hears it. The name's own press is unchanged everywhere.
