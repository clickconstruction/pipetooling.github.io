# v2.7147 — The Bridge has a Punch list button in its top right corner (2026-11-13)

The owner asked for a button in the top right corner of the Bridge that opens the Punch list. No migration and no edge function change.

## What changed

- `BridgePunchListLink` (`src/components/bridge/BridgePunchListLink.tsx`) is the last press of the header's top row on `/bridge`, after **Refresh**. It is a router link to `PUNCH_LIST_PATH` (`/punch-list`), so a modified click opens the board in a new tab. It is drawn as the header's own quiet press: the outline on the surface that Refresh uses, with a line icon and the words **Punch list**.
- Who sees it: `canOpenPunchList` (`src/lib/todos/punchListAccess.ts`), the same line that gates the page, the gear-menu door and the picks table. That is the owner and a dev, which is also everyone who can open the Bridge (`isOwnerOrDev`). The button reads the Punch list's own gate and not the Bridge's, so the two cannot drift apart if either door changes.
- No count on the button. The page reads no punch list data, and the ask was a plain button.
- `Bridge.tsx` takes one import and one line. Five open pull requests edit that file (#7891 to #7894 and #7948); none of them touches the header's row or the import this one sits under, and a trial merge with each branch is clean.
