# v2.5598 — Training: a drawing under the sentence it explains, starting with the controls ladder and the clearance stack (2026-10-17)

Punch list #116, PR 0 of six (the plan and the mock-up at `to-dos/training-visuals/`, Grace's calls on 2026-10-17: line drawings, all thirty-five). Read as a fourteen-year-old, the OSHA 30 refresher fails where a fact is a shape in space, a thing recognised by sight, a scale, or a motion. This PR is the mechanism with two figures as the proof. No migration; no edge function.

- **The line.** A Must know or Traps item `{{figure:<name>|<caption>}}` draws the named figure under the sentence before it, the caption under the drawing. **`src/lib/training/figures.ts`** (pure): `FIGURE_NAMES` (the registry's names, sorted), `parseFigureItem` (a figure line, or null for a sentence; an unknown name or an empty caption throws with the lesson's key), `lessonItems` (what the page draws), `itemWords` (what the plain-words rules read: the caption).
- **`courseContent.ts`**: `parseLesson` runs every Must know and Traps item through `parseFigureItem`, so a lesson naming a figure the app does not draw fails the content test; `lessonPlainWordsFailures` holds a caption as it holds a sentence. The content version already hashes the raw items, so a figure's name and caption are part of a lesson's words and a changed caption is a changed lesson (v2.5569's rule: a pass stays a pass).
- **`src/components/training/figures/`**: `ControlsLadder.tsx` and `ClearanceStack.tsx`, each an inline SVG (`viewBox` 300 wide, `currentColor` strokes, the theme's tints for fills, the house status colours literal), `figureProps.ts` (`titleId`), `index.ts` (`FIGURES`, name → component). **`TrainingFigure.tsx`**: a `<figure data-training-figure>` with the drawing at the column's width (420 px at most) and a `<figcaption>` whose id is the SVG's `aria-labelledby`. **`Training.tsx`**: `lessonList` draws a figure item with no bullet. The drawings ride in the course page's lazy chunk; the Dashboard's never imports them.
- **Lessons**: 1 (`controls-ladder` under *Controls run from most to least effective*), 8 (`clearance-stack` under *Clearance adds four things to the free fall*).
- **Tests**: `figures.test.ts` (parse, the registry sorted and unique, `FIGURES`' keys equal to `FIGURE_NAMES`), `TrainingFigure.render.test.tsx` (each figure renders as `role="img"` named by its caption), `courseContent.test.ts` (an unknown figure fails the lesson; the real content names every drawn figure at least once), `Training.render.test.tsx` (a figure line draws a figure with its caption and no bullet).
- **Docs**: the guide `take-a-training-course` (one sentence), `PROJECT_DOCUMENTATION.md`'s Training paragraph, the to-do's status.

`npm run build` passes before the merge (a lazy glob broke the build once, v2.5589). Next: PR 1, the space figures 3 to 10 and the lesson 30 site map.
