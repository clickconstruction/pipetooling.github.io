## The one thing that could not move as it was

An unpriced solo bid hides the status band and puts ＋ Add price at the end of the solver line instead (artifact 0a627c7c). The row did that by assigning a render-time variable (`wbSolverEnd.node`) that the solver strip, drawn further down in the same render, then read. A child component renders after its parent, so the strip would never have seen it. The tab now decides the layout first — `cardsRowMode` is `soloUnpriced` — and draws `AddPriceDoorButton` at the solver line from that same answer, before either piece renders.
