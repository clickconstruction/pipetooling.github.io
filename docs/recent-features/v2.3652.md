# v2.3652 — Settings → Company: Defaults for everyone reads as a list, not a squeezed table (2026-09-20)

Owner-reported from a screenshot, 2026-09-20: on Settings → Company the *Setting* column was about 100 px wide, so each description wrapped one or two words per line down a tall ribbon, the three dropdowns floated at the top of a mostly empty row, and at narrower widths *Office roles* sat behind a horizontal scroll.

## The cause

[`SettingsOrgDefaultsSection`](../../src/components/settings/SettingsOrgDefaultsSection.tsx) was an auto-layout `<table>`: a `<select>` cannot shrink below its longest option ("No default (each device decides)", "Gentle — 1.25× the block and 1 h over"), so three select columns took their full width and the browser took all the slack out of the only column that can wrap — the text. The `maxWidth: 320` on that cell caps it; nothing gave it a floor. No width fixes that: three unshrinkable columns beside a text column do not fit the Settings content pane.

## The change

- **One block per setting** (`role="group"`, named by the setting): the label and the hint at full width (75ch), then a grid of three labelled selects — `repeat(auto-fit, minmax(190px, 1fr))`, each select `width: 100%` — so they sit side by side while there is room and stack on a phone. The section is a bordered card with an `h2`, matching **Company documents** above it. `id="settings-org-defaults"` (the Settings-search deep link), every select's `aria-label`, the save path and the toast are unchanged.
- **`orgDefaultOptions`**: the empty option is **"No default"** (was "No default (each device decides)") — the intro sentence and the guide already explain it and already call it that; the closed select no longer clips mid-word.
- Guide `set-defaults-for-everyone.md`: "one small table" / "role column" wording follows the layout; its example stays a table of values.
- Test: `SettingsOrgDefaultsSection.render.test.tsx` — no `<table>`, the anchor id, and per setting a group holding its hint and its three named selects.
- Checked in the browser at 1000 px and at 375 px (no sideways scroll; section 359 px, selects 317 px).
