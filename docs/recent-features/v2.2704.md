# v2.2704 — "Only my bids" on all eight workflow tabs, on by default (2026-09-03)

Owner request: the "Only my bids" toggle (v2.2356 era) sat on Counts / Takeoffs / Labor / Pricing / Cover Letter but not on RFI / Change Order / Lien Release, and started unchecked. Now every workflow tab's no-bid-selected list carries it, and it starts checked.

## Client only — no migration

- `src/pages/Bids.tsx`: the shared `onlyMyBids` state flips to `useState(true)`; `onlyMyBids` / `setOnlyMyBids` / `isMyBid` are threaded into `BidRfiTab`, `BidChangeOrderTab`, and `BidLienReleaseTab` exactly as the other five tabs receive them (one state, so toggling on any tab applies to all eight).
- `BidRfiTab` / `BidChangeOrderTab` / `BidLienReleaseTab`: render `MyBidsToggle` after `BidPickerSortToggle`; the search filter runs over `scoped = onlyMyBids ? bids.filter(isMyBid) : bids`; the empty message becomes "No bids you are the account manager or estimator for." when the scope (not the search) is what emptied the list — same copy as Cover Letter.
- Not persisted: toggling it off lasts for the visit; the next Bids mount starts on again ("selected by default" was the ask). Bid Board / Followup / Unsent-Working are untouched — they are not workflow-tab pickers.

## Docs

- Help guide `find-a-bid-on-the-workflow-tabs.md` → "Narrow it down" describes the default-on behavior and the three added tabs.
- `MyBidsToggle.tsx` header comment lists all eight tabs.
