# v2.3479 — Put a GC on notice: the leader's card, and what the record reads after (2026-09-15)

Client only; no migration, no edge function. PR 3, the last of the *Put a GC on notice* train ([`to-dos/gc-on-notice/`](../../to-dos/gc-on-notice/README.md); PR 0 [v2.3469](./v2.3469.md), PR 1 [v2.3470](./v2.3470.md), PR 2 [v2.3482](./v2.3482.md)). Stacked on `claude/gc-on-notice-2-cover-letter`.

## Why

The mock-up's fourth board: the office prepares Steps 1–3 and sends the set to the leader; the leader should get one card with the reason and the money, not N "approve a lien notice" cards. And once the run is recorded, the GC's row on Customer review should say so.

## What shipped

- **Kernel [`gcOnNotice.ts`](../../src/lib/jobs/gcOnNotice.ts)** (+1 test): `lienDeskBatches(queue, gcNames)` — the awaiting items whose draft carries a `batchReason`, grouped by GC (jobs, dollars, the reason, the earliest deadline), biggest first. [`lienDesk.ts`](../../src/lib/jobs/lienDesk.ts): `LienDeskNeedsYou.leader.batches?` (`LienDeskBatch`); [`useLienDeskData`](../../src/hooks/useLienDeskData.ts) sets it on the summary (light and full reads — the GC names come with the GCs).
- **[`dashboardNeedsYou.ts`](../../src/lib/dashboardNeedsYou.ts)** (+1 case): key **`lien-notice-batch`** — *Approve the run for <GC>* (or *Approve N runs the office prepared*), the claimed total, the count, the reason, the earliest window; the per-notice *Approve N lien notices the office drafted* card counts only what is not in a run. Dashboard's `DashboardPinnedQuickRow` and Quickfill's `QuickfillNeedsYouSection` dispatch the card to `/jobs?tab=stages&gcnotice=<gc id>` — the modal, where Approve all takes the awaiting set and applies the ticks.
- **[`BidBoardCustomerReviewModal`](../../src/components/bids/BidBoardCustomerReviewModal.tsx)**: alongside the terms it reads the sent desk items that carry a batch reason per GC — *on notice since <date> · N* in red — and the *Put on notice…* button reads *the run ›* on such a row.
- **[`useGcOnNoticeData`](../../src/hooks/useGcOnNoticeData.ts)** → `countyByJob` from the property record; Step 1's Property column reads it when the roll was not consulted.
- Guide *send lien notices from the Lien desk* → "A GC in trouble" closes with the leader's card and the after reads; `GLOSSARY.md` names the card.

## The train, closed

Four PRs on top of the Lien desk: the first-notice rule (v2.3469), the modal with its three doors (v2.3470), the cover letter (v2.3482), the leader's card and the record (v2.3479).
