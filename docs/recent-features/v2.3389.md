# v2.3389 — Contract sweep PR 4: filing in the pane, and a file dropped on the row (2026-09-14)

Client only; no migration, no edge function. Sixth PR of the train in [`to-dos/contract-sweep-seen-first/`](../../to-dos/contract-sweep-seen-first/README.md) (PR 0 v2.3384 · PR 0c v2.3385 · PR 1 v2.3386 · PR 2 v2.3387 · PR 3 v2.3388). With it the sweep itself is built; the Drive pass is what remains.

## Why

"It should be easy for the user to upload a contract." Filing was three doors deep (job name → Contract modal → File a signed contract → sheet), and the sweep's own text still called it "upload a paper copy".

## What shipped

- **[`JobContractFileSheet`](../../src/components/jobs/JobContractFileSheet.tsx)** — the v2.2744 sheet extracted from the Contract modal unchanged in behavior (link first, the scan or photo behind *Have a scan or photo instead?*, Signed by / Signed on, **Record as signed** dim until a link or a file is given) with two layouts: `sheet` (a stacked modal — the Contract modal still uses it) and `inline` (a dashed card in the sweep's pane, with a heading such as *File Summit GC's subcontract*). It takes an `initialFile` for the drop path and shows the chosen file's name and size.
- **Kernel [`jobContractFileWrite.ts`](../../src/lib/jobs/jobContractFileWrite.ts)** (+2 tests): `fileSignedJobContract` — the one write for all three doors (a live draft converts in place, else a fresh signed row; the file lands at `<contract_id>/paper.<ext>` in the private bucket; the `recorded` event); `paperUploadPath`; `fileSignedContractReady`. `JOB_CONTRACT_BUCKET` now lives here (the record modal re-exports it).
- **The sweep**: **Already signed? File it** and **File their subcontract** open the sheet in the pane in place of the edit fields; the document dims and the footer reads *Filing replaces the send for this job — nothing goes to the customer*. On **Record as signed** the row leaves the queue, the header says *N filed*, `job-contract-changed` fires for the chips and the Dashboard, and the selection moves to the next row. The record keeps the pane's fields and terms (the edited scope and amount ride along as the document on file).
- **Row drop targets**: dragging a file over a row outlines it with *Drop to file as the signed copy*; dropping a PDF / PNG / JPG selects the row and opens the sheet with the file already attached — one click records it. Other types get a toast. Owner decision 4 ("row drop with no questions") is taken the safe way for now: the drop prefills the sheet rather than filing outright, so a wrong signer or date is one glance away instead of an undo.
- Help guide: "File a signed copy from the sweep".

## Verified

Render smoke (+1: the sheet opens in the pane and the edit fields hide; a dropped file selects the row and lands in the sheet), kernel tests, the Contract modal's filing path unchanged in behavior (it mounts the same sheet; not exercised live in this PR), release-note + guide drift tests, typecheck, lint, theme check.
