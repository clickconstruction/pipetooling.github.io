# v2.3347 — Legal desk: the ⚖ Legal button opens on a fresh page (2026-09-11)

Follow-up to v2.3293 (Legal portal PR 2), found on the first live walk-through.

## Why

`JobsStagesTab` gated the ⚖ Legal button on `collectionsRows.length === 0`. Collections is a lazily loaded tier — its rows arrive when the tier is expanded — so on a fresh Pipeline page the header already read "Collections (8)" from `cacheHeaderStats` while the rows were empty and the button was `disabled`. It worked in dev only because the tier had been expanded first. The desk fetches `NON_PAID_SCOPES` itself when it opens (v2.3293's scope-fetch effect), so the rows were never a real precondition.

## What changed

- The gate reads `collectionsHdr.count === '0'` (the same cached count the header prints) instead of the live rows.
- The button moved into the `#stages-collections` header row (`marginLeft: auto` on desktop) so it sits inline like the Billed tier's Accounts Receivable button rather than on its own line below the header.

No migration, no edge function.
