# v2.4558 — Documents: every email we send outside is kept (2026-10-05)

Step 2 of the Sent copies train ([`docs/SENT_COPIES.md`](../SENT_COPIES.md)) closes: the owner's *"keep the email"*. [v2.4557](v2.4557.md) added the edge helper and the two bill functions; this wires every other function that writes to someone outside the company, the same one hook in each. No migration. **Nineteen functions to redeploy** (listed below).

## The change

Each function files the email after its send — the message as it was read and each attachment — as one `sent_documents` row. A caller of `sendEmailViaResend` passes `options.file`; a function with its own Resend call invokes `fileSentEmailBestEffort`. Where a function stamps a row after sending, the filing runs after the stamp.

What a GC statement gains: `gc_statement_emails` recorded that a statement went and its total, and the page was rebuilt from an RPC over live data, so last month's statement could not be read again as it was. What a test report gains: its PDF was already kept (`job-test-reports`); the email was not.

A statement, a price request, a bid room link and a law-firm notice name no job, so they do not list under a job's *Sent from this job*. Step 4 (the Documents page and the customer page) is where they are found.

## A fix found on the way

`share-job-contract` called `signedRecordId` in three places without importing it (since v2.4186). The paths that rebuild a signed PDF — a signed contract whose stored PDF is missing, and an accepted estimate's signed copy the first time it is opened or shared — threw and answered *Internal error*. The import is added. Found by running `tsc` over the changed functions with a one-line `Deno` shim and reading only the *cannot find name* errors, which is the nearest thing to a type check this machine has for edge code; it reported nothing else.

## The ratchet

`EMAILS_OWED` in [`sentCopiesEmailCoverage.test.ts`](../../src/lib/sent/sentCopiesEmailCoverage.test.ts) is empty. Four functions moved to `NOT_OUTSIDE` with their reasons: `send-workflow-notification` (a notice to a user of the app that something waits for them), `sign-bid-room` and `submit-portal-request` (notices to our own staff), `submit-legal-portal` (an email-address confirmation). A new function that sends mail fails CI until it files or says why not.

## Tests

The ratchet (3). The edge functions have no local type check (no Deno on the authoring machine); the helper was proven live by `test-email`'s self-test in v2.4557, and each function's own wiring is proven by its first live send after the deploy.
