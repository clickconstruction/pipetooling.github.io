# v2.2588 — Lien release history in the release modal (2026-09-01)

Live-testing v2.2582 surfaced a reachability gap: Billed Awaiting Payment rows
have no Bill Customer button, so the Bill Customer strip's View/Void/history
was unreachable exactly where the unconditional follow-up happens.

- `LienReleaseModal` gains an "Issued on this job" box (live releases with
  View / two-click Void, same fail-soft `job_lien_releases` read as the
  strip); voiding fires `onIssued` so the board badge refreshes immediately.
- The `lien-unconditional` Needs You detail now directs to the release button
  on the job's Pipeline row (reachable from every section) instead of
  Bill Customer.

Verified live end-to-end on 2026-09-01: conditional issued on a job with real
applied payments → nudge on Dashboard + Quickfill → unconditional issued from
the release modal (amount prefilled from applied payments) → nudge cleared →
all test rows voided through the new history box.
