# v2.1994 — Bid GC recipients: schema + capture (2026-08-21)

Bid-recipients train PR 1 (estimator ask: "I want to know everyone I sent it to so I can get bid tabs from them all"). Today one bid = one `bids.customer_id`; sending to more GCs meant fake combined customers ("Multiple GC's") that erase the real GCs from every followup queue. This PR adds the model + capture; PR 2 surfaces recipients in the review views.

- **Migration** [`20260821230000_bid_gc_recipients.sql`](../../supabase/migrations/20260821230000_bid_gc_recipients.sql) (see `docs/migrations/`): `bid_gc_recipients` (bid_id, customer_id, source `manual|version`, added_by/at, UNIQUE(bid_id, customer_id)) — the **primary GC is implied, never duplicated**. RLS mirrors the sibling per-bid overlay tables (`can_access_bid_for_pricing` + role list; writes exclude primary/superintendent). Backfills recipients from existing `bid_versions.customer_id` overrides (v2.1159 multi-GC packets) that differ from the bid-level GC. Ends with both read-only block calls.
- **Edit Bid capture** ([`BidGcRecipientsRow`](../../src/components/bids/BidGcRecipientsRow.tsx), mounted in [`BidFormModal`](../../src/components/bids/BidFormModal.tsx)'s People section under the GC contact chips): recipient chips (title reveals manual vs version-synced), **+ Add GC** searchable picker (excludes the primary GC and existing recipients), × to remove (dev/master/assistant-like/estimator). New Bid shows a save-first hint. Self-contained component — loads/writes itself; table name cast until `gen-types` runs post-push, and a failed load hides the row entirely, so a **client deployed ahead of the migration renders the old form, never a crash** (verified live pre-migration: modal opens, row absent, no error).
- **Version sync** ([`BidVersionPicker`](../../src/components/bids/BidVersionPicker.tsx) `submitRename`): saving a version with a GC override upserts that GC as a `source: 'version'` recipient (skipping the bid-level GC; `ignoreDuplicates` so a manual row is never overwritten). Best-effort — a missing table is swallowed (the migration backfill covers those rows).
- **Deploy order**: merge → `supabase db push` → `npm run gen-types:linked` in a follow-up. Help guide `bid-one-project-to-multiple-gcs.md` updated.
