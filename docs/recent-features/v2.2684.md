# v2.2684 — Contract Desk PR 3: paper copies, the signed record, and the contract everywhere the job is (2026-09-03)

Read-backs and the backlog door for the loop shipped in v2.2679 / v2.2681. No migration.

## Client

- **Upload signed copy / record on paper** — the Contract modal's footer gains **Upload signed copy**: who signed, the date, and an optional scan or photo (png / jpg / pdf into the private `job-contract-documents` bucket at `<contract_id>/paper.<ext>`). Records a `signed` row with `signer_mode = 'paper'`, `paper_signed_on`, `recorded_by`; a live draft converts in place. No token, no email — the row simply reads {{chip:green|✍ On file · paper}}. Logs a `recorded` event; the bridge trigger writes `contract_signed`.
- **Signed record modal** [`components/jobs/JobContractRecordModal.tsx`](../../src/components/jobs/JobContractRecordModal.tsx): the document as signed (iframe of the shared HTML, with the drawn signature pulled by signed URL), who / how / when / consent / IP (with the existing map button) / device, **Print / save as PDF**; paper records link the uploaded copy instead. Opened from the modal's history rows and from every strip below.
- **`useJobContractCoverage(job)`** ([`hooks/useJobContractCoverage.ts`](../../src/hooks/useJobContractCoverage.ts)) — single-job coverage through the PR 1 kernel; **`JobContractStrip`** ([`components/jobs/JobContractStrip.tsx`](../../src/components/jobs/JobContractStrip.tsx)) — chip + *Send contract* / *Resend / manage* / *View record*, self-contained (mounts its own modals), `strip` and `inline` variants.
- **Where it shows**: the **Bill Customer** modal (above the lien-release strip), the **View bill** panel (`HostedStripeBillPanel`, top), and the **Job window → Edit** fact rows (a read-only *Contract* row under the customer block via `JobFormEditFactRows.contractJob`).
- **Documents → Jobs**: contracts (sent / signed / voided; drafts stay in the modal) list as child rows under each job like lien releases — template name, rev, chips, the audit line or sent stamp; click opens the signed record.
- **Contract Book** (People → Contracts → Contract library): add/edit forms gain an **Audience** select (Staff packets, default · Customer job-contract terms) — the column PR 1 added, saved with a plain update beside the RPC — and customer entries wear a *Customer contract* chip. The Contract modal's Terms picker lists exactly those.
- Help guide gains "Already signed on paper?", "Where else it shows", and "Your own terms".
