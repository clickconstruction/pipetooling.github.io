# v2.7577 — Tagged task notes: a notice on your phone (2026-11-17)

Punch list #375, PR 4 of six: the push. One edge function taught, and the client calls for it. No migration.

## What is new

- **`notify-note-tag`** takes two more bodies: `{ task_event_id }` for a typed task note, and `{ task_tag_id }` for a No reply needed press on a task tag. It refuses a caller who did not write the note, or who is not the tagged person, and pushes nothing for a note or a press more than fifteen minutes old, as for a job. Its section in `docs/EDGE_FUNCTIONS.md` says so.
- **`words.ts`**: `taskNotePushes` and `taskDonePush`, and `taskTitleWords`, the function's own reader of a task's title. A task sent from a job keeps the job in its title as a token, `{{1:1466 · Cedar Bluff Lofts}} — <task>`. The notice keeps the token's words and drops its braces. The card left this to settle while building: the function cannot import `src/lib`, so the reader is written again there, and `noteTagPush.test.ts` holds it to `taskTitlePlain`.
- **Three pushes**: to the people a task note tags (*Luis tagged you on Sweep the shop bays*, template `task_note_tag`), to the people whose tags the note answered (*Dana answered on Sweep the shop bays*), and to the asker of a tag cleared with no note (*Chris: no reply needed*). A person the answer tags back gets the tag alone.
- **The door** is `/checklist?tab=today` for every role, where the Tagged task notes section is.
- **The client** calls `notifyNoteTag` after any typed note in a task's note box, after an answer from a tagged notes section, and after **No reply needed** on a task tag. The task note box now asks its plain insert for the new row's id, since a note that tags nobody can still answer a tag.
- **`heldKind`** names the new template, so While you were off reads *tagged task note*.

## Not covered yet

A note typed in History's box, on the Roadmap card, in Review's Reopen with comment or on a My Inbox card answers a tag in the database and sends no notice to the asker: those boxes do not call the function. The answer still counts on Checklist for the asker. PR 5 gives History's box and the Roadmap card's box the call.

## Order

The client merges first. Until the deploy, the function on prod answers 400 for `task_event_id` and the call is dropped, so nothing on screen changes. The function goes out with `supabase functions deploy notify-note-tag` right after the merge.
