# v2.1942 — Partnerships: View as Partner lens (2026-08-21)

Owner-approved mockup ("View as Partner" artifact, markers 3–6): an in-place lens on `/partnerships` — engaged, the page shows only what the partner's own account can see; disengaged, the normal dev tabs. Chosen over session-switch impersonation: no navigation, no stashed session, and read-only by construction (the dev session has nothing that can write as the partner).

**DB** (migration `20260821150000_partner_view_as_rpcs.sql`): each partner read RPC splits into an inner payload function taking the partnership id (`partner_summary_payload` / `partner_ledger_payload` / `partner_jobs_payload` / `partner_job_costing_payload`, not client-callable) with two thin resolvers — the unchanged `get_my_partner_*` wrappers (caller via `my_partner_partnership_id()`), and new dev-only `get_partner_*_as(p_partnership_id)` variants that resolve the given partnership through the **same draft/active status gate** (`partner_lens_partnership_id`), so the lens is provably identical to the partner's view, including rendering nothing for paused/ended deals. `acknowledge_partner_statement` stays caller-only. Inner bodies are verbatim moves from `20260820170000`/`20260820200000`.

**Client**: [`DashboardPartnerLedgerSection`](../../src/components/dashboard/DashboardPartnerLedgerSection.tsx) and [`DashboardPartnerJobsSection`](../../src/components/dashboard/DashboardPartnerJobsSection.tsx) gain an `asPartnershipId` prop switching their fetches to the `*_as` RPCs; in lens mode the §9b acknowledge button renders disabled ("the partner sees this button — only they can press it"). [`Partnerships.tsx`](../../src/pages/Partnerships.tsx): "👁 View as {name}" toggle in the partnership header (imitation-chrome amber, resets on roster switch); engaged, the tab bar and dev tabs are replaced by an amber "Partner view" banner, the two partner cards, and a dashed "Hidden with the lens on" strip listing what's filtered. New RPC names hand-added to `src/types/database.ts` (matches the next `gen-types` run). Client is fail-soft until the migration is applied.
