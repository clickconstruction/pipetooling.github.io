## What shipped

- **`src/components/workflow/WorkflowStepLifecycleModals.tsx`** — the six windows' JSX, moved verbatim: delete step (type the name when the step has content), Send Back, Skip, Set Start, Expected dates, Assign. The props keep the page's own names — the window states and their setters, `deleteStepConfirmText`, `assignPersonFilter`, `isStepEmpty`, `roster`, `currentUserName`, and the submit handlers — so the JSX needed no edits.
- **What stays the page's** — every window's state and every submit handler. The stage cards open these windows, so the state follows the cards when they move (the next PR).
- **The Assign filter stays in the page on purpose** — it is cleared on Cancel and on the backdrop, but not after a pick. Moved into the picker it would clear on every open, which it does not today.
- **`src/pages/Workflow.tsx`** — 2,384 → 2,109 lines.
