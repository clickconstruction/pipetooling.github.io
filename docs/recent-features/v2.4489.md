# v2.4489 — AIA G702-G703: the form starts with the right party, project and dates (2026-10-04)

The second piece of the AIA window's refresh, after [v2.4487](v2.4487.md) (the paper preview and the clean download). The owner, 2026-10-04: *"When we bill a GC, who goes in the owner box → GC"*, retainage *"is usually 10%"*, then *"start the prefill fixes"*. Client only: no migration, no edge function.

## What the form filled before

Read on job *Water Sample Test* (customer Heron Construction Group, Click number 1023, no HCP number, no signed contract):

- **APPLICATION NUMBER** held the job's name, on both pages. The bundled workbook had put its own job's name in that box; its `PROJECT:` label sits in a column ten characters wide with no box under it.
- **TO OWNER** was the customer's name over the *job's* address.
- **CONTRACT DATE** was `Tue, Sep 15, 2026, 9:11 AM CDT`: the moment the job row was created. **APPLICATION DATE** was today with `12:00 PM CDT`.
- **PROJECT NO** was empty, because only the HCP number was read.
- **Retainage %** was empty.

## The change

- [`aiaG702G703Template.ts`](../../src/lib/aiaG702G703Template.ts)
  - Three new fields: `g702_h6_project_name`, `g702_h7_project_address`, `g702_h8_project_city_state_zip` (cells H6 / H7 / H8), after CONTRACT DATE in the form.
  - `buildAiaPrefillFromJob(job, issuer, facts?)`: the job's name and split address go to the project block; the owner block takes `facts.ownerName` / `facts.ownerAddress` (falling back to the GC's name on the job row, then the customer's; no address when none was read); the application number is `''`; `g702_n9_contract_date` is `formatAiaDate(facts.contractSignedOn)`; the application date is `formatAiaDate(todayYmdInAppTz())`; the project number is `effectiveJobLedgerNumber(hcp, click)`; retainage is `AIA_DEFAULT_RETAINAGE_PERCENT` (10).
  - `formatAiaDate` (`2026-10-04` → `10/04/2026`), `aiaContractSignedOn(rows)` (the earliest live signed contract; a paper's own date before the moment it was recorded; `signed_at` read as a Central day), `aiaDownloadFilename(jobNumber, applicationNumber?)` (adds `-app-N` when the number is one to four digits).
- [`aiaG702G703PrefillIo.ts`](../../src/lib/aiaG702G703PrefillIo.ts) `loadAiaPrefillFacts(jobId)`: the job's party columns, its `job_contracts` rows, then the payer's `customers` row (`effectiveInvoiceParty(job, null)` → `payerCustomerId`). A read that fails leaves its facts empty.
- [`fillAiaG702G703Workbook.ts`](../../src/lib/fillAiaG702G703Workbook.ts) `placeProjectBlock`: the `PROJECT:` label moves from J5 to H5, where four empty columns run to the application block, and H6:K8 take the owner boxes' style.
- [`AiaG702G703Paper.tsx`](../../src/components/jobs/AiaG702G703Paper.tsx): a PROJECT column between the owner and the application block.
- [`AiaG702G703Modal.tsx`](../../src/components/jobs/AiaG702G703Modal.tsx): reads the facts once per opening beside the issuer; **Reset from job** reuses them; the file name takes the job's number (HCP or Click) and the typed application number.

## Not changed

*WORK COMPLETED THIS PERIOD* still starts at contract × percent complete, which is the total to date, and *DESCRIPTION OF WORK* still starts from the first three fixtures. Both wait for applications the job remembers (the next piece), where previous amounts and the schedule of values come from the job.
