# v2.6240 — Three more server functions pass their own type check again (2026-10-31)

A type-only fix to the edge functions whose `deno check` failed on main: `notify-lien-approval` and `send-report-notification`, found while v2.6217 (punch list #141 PR 5) checked the push senders, and `send-report-email`, which fails the same way as the second. Each failed on one line. No migration and no screen. Nothing behaves differently.

- **`notify-lien-approval`** (TS2339): the `item` the function reads is annotated with the columns its branches share, and the pen-record words read `item.signed_witness_how`, which the annotation did not name. It names it now (`signed_witness_how?: string | null`). Only the pen-record words read it, and they come from a lien notice, whose select already reads the column.
- **`send-report-notification` and `send-report-email`** (TS2589): both hand their service-role client to `readReportSubject` in [`_shared/reportSubject.ts`](../../supabase/functions/_shared/reportSubject.ts), which took it as `ReportSubjectClient`, the structural `.from(table).select(columns).eq('id', id).single()` chain its test fakes. Checking supabase-js's client, whose schema is `any`, against that chain makes TypeScript resolve the client's `eq` over a plain `string` column, and that filter-value type parses column paths past the instantiation limit.
  - Probes against the real client: a chain that stops at `from` or at `select` checks. Any chain that reaches `eq` trips the limit, with a generic `eq`, method syntax or an `unknown` value alike.
- **The fix**, in types alone: `readReportSubject` takes `ReportSubjectDb`, anything with a `from`, and reads it through `ReportSubjectClient` inside with one cast. `ReportSubjectClient` stays the chain the test's fake is typed against, and neither caller changes.
- **Proof**: `deno check` passes on all three (`DENO_NO_PACKAGE_JSON=1 npx -y deno@2.4.3 check --quiet --node-modules-dir=none supabase/functions/<fn>/index.ts`). Both changed files transpile, comments stripped, to the same JavaScript as on main. `reportSubject.test.ts` passes and type-checks.
- **Docs**: one line in each function's `docs/EDGE_FUNCTIONS.md` section.
