# v2.4406 — Pricing: the Add price button sits on one line (2026-10-02)

The owner, on BP403's Pricing tab (a screenshot with the button boxed in red): the *＋ Add price* button "should not be two lines in this expanded view. It unnecessarily increases the size of this section."

## What changed
- [`AddPriceDoorButton`](../../src/components/bids/PricingCardsRow.tsx) broke its label as *Add / price* everywhere. It now reads *＋ Add price* on one line on the two one-row strips that draw it: the solo band (*One GC · one price …*) and the solver line of a bid with no prices yet. A new `stacked` prop keeps the two-line label only beside the tall price cards, where width is what runs out and the button's height changes nothing.
- `PricingCardsRow.render.test.tsx`: the button has no line break by default and has one when stacked.

## Measured live
Headless Playwright on the worktree dev server against prod, BP403 *ZZ Twin LIVSTE* → Pricing, 1500 px wide: the band was **66 px** tall with a 84 × 48 px button, and is **53 px** with a 113 × 35 px button. At a 390 px phone width the band wraps as before and the button stays on one line. No page error.

No migration, no edge function.
