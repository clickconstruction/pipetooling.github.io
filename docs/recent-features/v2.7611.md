# v2.7611 — Lien desk: the pay page and the signing code moved into their own files (2026-11-17)

The eleventh cut of `src/components/jobs/LienDesk.tsx`. No behaviour changes.

**What the map called this cut, and what it is.** The map ranked *the notice context as a hook* here: about 290 lines that would hand 62 names back to the desk. Read closely, that block is the desk's substrate. The item on the pane, its months, the claim, the notice's fields and the effect that resets thirty values when the job changes are read by every notice region. A hook around all of it would move the lines and keep every dependency, with a 60-name interface. So this cut takes the two parts of the block that stand alone, and leaves the rest where the architecture doc always said it must stay.

**`useLienCodeSigner`** (`src/components/jobs/useLienCodeSigner.ts`) holds the leader's signing code on someone else's screen, as it stood: three state values, the effect that reads whether his code is live, and the signer the signature line draws. The desk's one write to it became `refreshCodeStatus()`.

**`useLienDeskPayPage`** (`src/components/jobs/useLienDeskPayPage.ts`) holds the pay page behind a notice, 83 lines as they stood: the job's unpaid bills, the part no sent bill carries and the press that bills it from here, the page as the run prints it, and its lines typed in place. The typed lines' state and the two refs stay in the desk, which clears them when the job changes, and are handed in. The block was contiguous, so its hooks run in the order they ran before.

**The live claim did not move.** `noticeFields`, which always writes the live claim over a stored draft's, stays in the desk untouched.

**Size.** `LienDesk.tsx` went from 3,821 lines to 3,717, and from 81 `useState` calls to 78.

**Proof.** `LienDesk.render.test.tsx` (207 tests) and the page's render test pass with no edit. New: `useLienNoticeHooks.render.test.tsx`, eight tests. The lint warning on the pay line's focus effect moved with it: nine in the desk and one in the hook, ten as before.
