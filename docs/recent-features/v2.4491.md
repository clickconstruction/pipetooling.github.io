# v2.4491 — Job window: a Documents tab with the job's pay applications (2026-10-04)

The owner, 2026-10-04, on applications already sent: *"I would like to be able to upload a Google Docs link to those files, and I would like for them to be able to show up in the job modal. Perhaps we should add a new tab to the job modal called 'Documents' after Job Edit Bill Costs History where this could show up as well."* The link is kept since [v2.4490](v2.4490.md); this is the tab. Client only: no migration, no edge function.

## The change

- [`jobHistoryTab.ts`](../../src/lib/jobs/jobHistoryTab.ts): `JOB_WINDOW_TABS` gains `documents` after `history`, labelled **Documents**; the form pane hides on it as on Job and History.
- [`JobWindowDocumentsTab.tsx`](../../src/components/jobs/JobWindowDocumentsTab.tsx) (new):
  - **Pay applications** — `loadPayApplications(job.id)`; a row per saved application (number · period to · payment due · **Open the file** when it has a link · **Open**), the retainage held as of the last one under the table, **New application** in the heading, a sentence when none is saved.
  - **Job folders** — `jobDocumentFolderLinks(job)` ([`jobDocumentsTab.ts`](../../src/lib/jobs/jobDocumentsTab.ts)): the job folder, plans and pictures links that are set and are web addresses.
  - **Open** and **New application** mount `AiaG702G703Modal` at z-index 1030 (the job window is 1010); closing it reads the list again.
- [`AiaG702G703Modal.tsx`](../../src/components/jobs/AiaG702G703Modal.tsx): `initialApplicationNumber` (open on that saved application when the job has it) and `zIndex` (default 1006, as before).
- [`JobWindowModal.tsx`](../../src/components/jobs/JobWindowModal.tsx): the pane mounts on first visit and stays mounted; while its AIA window is open the form's Escape is held (`externalEscBlocked`), so Escape closes the AIA window and not the job.

The tabbed job window opens only for `isStaffFullJobLedgerDetailRole`, the roles the AIA window opens for, so the tab needs no gate of its own. `primary` is in that set and outside the table's RLS: it sees the tab with no applications.
