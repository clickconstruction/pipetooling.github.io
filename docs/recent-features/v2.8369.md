# v2.8369 — Dashboard: the database can hold the bids you hide on My Bids (2026-11-23)

Step 6 of punch list #426, the migration half. The owner's pick of 2026-11-23: *Hidden follows you* to every device, and his yes the same day to push this migration once its PR merges. Migration `20261123160430_my_bids_hidden_at.sql`, no edge function, no client change.

## What was there

A bid hidden on My Bids was kept in one browser's localStorage. A bid hidden on the phone was back on the desk, and a cleared browser brought every hidden bid back.

## What changed

- `user_bid_notes_read_state` gains **`hidden_at timestamptz`**, nullable. A hidden bid is the person's row with `hidden_at` set; Show again sets it back to null.
- The table's own-row policies already open each row to its person alone, so nobody else can read or set a person's hidden bids.
- A row made only to hold `hidden_at` has null read marks, which both readers of the marks read as no row. A hide changes no unread count, and **Mark read** never clears a hide.
