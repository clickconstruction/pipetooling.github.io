# v2.1923 — Pipeline job-row separators visible in light mode (2026-08-20)

Owner feedback: the lines separating jobs on the Jobs Pipeline board were hardcoded `#e5e7eb` — a bright, crisp line on dark surfaces but nearly invisible on white. New token in [`index.css`](../../src/index.css): `--border-job-row` — #6b7280 (gray-500) in light so the rows read as clearly separated, #e5e7eb in dark (identical to the pre-token hardcode, so dark mode doesn't change). Applied to the job rows in [`JobsStagesTable`](../../src/components/jobs/JobsStagesTable.tsx) (Old view), both row types in [`JobsStagesUnifiedTable`](../../src/components/jobs/JobsStagesUnifiedTable.tsx) (New view job + billed-invoice rows), and the project-banner row in [`jobsStagesRowShared`](../../src/components/jobs/jobsStagesRowShared.tsx) (it carries the separator when a job has a banner beneath it). Verified live in both themes and both views (computed #6b7280 light / #e5e7eb dark). Client-only — no migration.
