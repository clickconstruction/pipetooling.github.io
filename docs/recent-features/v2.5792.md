## Is this the best we can do?

1. **The venue decides; a person only switches when two firms both have a claim**: a dropdown of firms (considered) invites sending Austin's case to San Antonio by habit. The switch exists only on a two-county account and the venue line says which bill decided.
2. **No default firm, with a bridge that ends itself**: the owner's rule stands the moment a county is colored; until then the one firm keeps working and the words say why, so the day the map is drawn is not the day the desk stops releasing.
3. **One placement for the segment and the Map**: the same hook places every job, so the firm the header names is the firm whose county the dot sits in.
4. **Cut**: a county chip on every rail row (the Map shows it better), a per-release firm picker (the switch covers the one honest case), and moving a live matter from the header (a deliberate press on the firm window, per the README).
