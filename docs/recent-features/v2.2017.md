# v2.2017 — Checklist Today: cards + Outstanding rows open the full activity spine (2026-08-21)

Completes the click-anywhere-for-history arc (Manage v2.2010 → Review
v2.2016 → Today): every checklist surface now opens the same shared
`ChecklistItemActivity` panel.

- **`ChecklistItemActivity`** gained `commentInstanceId` (post-target
  override: Today keeps the conversation on the occurrence being looked at,
  instead of the default `commentTargetInstance` pick) and `onPosted`
  (parent callback — Today appends the note to its `eventsByInstance` so the
  💬 badge counts stay honest without a reload).
- **`ChecklistInstanceCard`** gained an optional `fullHistory` prop: the
  title becomes a keyboard-accessible toggle (anchor-guarded so title links
  still navigate) and the open thread renders the shared panel — full item
  history across occurrences — instead of the per-instance event list +
  composer. Without the prop the card is byte-for-byte the old sunlight-pass
  card (render tests cover both modes, 10 passing).
- **`ChecklistOutstandingSection`** rewired: the expanded row body is now the
  shared panel (its old inline per-instance thread + composer deleted);
  props changed (`nameById`/`onPostComment` out; `activityFor`/`onPosted`/
  `setError` in).
- **Today loaders** select `checklist_items.created_at` + `repeat_type` in
  both queries so the panel can show the creation stamp and per-day context.

Help guide `see-a-tasks-full-history-and-notes.md` now names Today as well.
