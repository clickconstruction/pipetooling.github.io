# v2.7227 — Paint a map: start one and find one from the search (2026-11-13)

Punch list #345, PR 6, the first half. The fourth door of the card's first build: the header's search. PR 2 left it out on purpose, because a map started with no job could then be found by nobody. This PR builds the door and the two things that make it safe to open: a map is found by its name, and a map on no job can be given a job.

## What changed

- **Paint a map** in the header's search, under Pages, for every role that has the full box. It opens the start sheet with no job.
- **Pick the job it is for** in that sheet: the app's own job search (`search_jobs_ledger` behind `CostBatchJobPicker`). The map then starts on that job and opens on its address. **Leave it on no job** is the other choice, and the sheet says who can open such a map.
- **Painted maps** as a group in the search: one row for every map the reader can open, found by its name, its words, and the name of its job or development. It is read when the box opens, under the reader's own access. A field role's box, which holds guides and boxes, gains its painted maps too.
- **Put it on a job…** on a saved map that is on no job, for its maker and the office. The database holds the same line: the mover must be able to open the job.

## How it is built

- A door is a link, so a painted map's door is an address: `/dashboard?paintMap=1` and `/dashboard?paintedMap=<id>`. The one host in the Layout reads either key on any page and takes it off the address at once, so a reload or Back does not open the window again. `doors.test.ts` holds the door to the line in the host that reads it.
- `paintedMapSearch.ts`, pure: the addresses, what an address asks for (an id that is not an id asks for nothing), and a map as a door.
- `loadPaintedMapsForSearch` reads the newest 400 maps with their homes in words where the reader can read the home. A helper cannot read the ledger, so a job's name is left out for them and the map is still found by its own name. A failed read is an empty list: the box never breaks on this.

## Is this the best we can do

- **The door waited for its other half.** A start sheet with no job and no way back to the map would have made maps only their maker could reach by luck. With by-name search and **Put it on a job…** a map on no job is a draft, not a lost thing.
- **No new job search.** The picker is the one Move cost uses, over the RPC the header box itself calls. One search to keep right.
- **A field role does not get the Paint a map row.** Its box is kept to guides and what is on its sites, by an earlier decision about the field's day. Its making press is on its own job card, where the person standing on the site is. It does get its maps by name.
