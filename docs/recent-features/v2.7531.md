# v2.7531 — Bids: the server leg to keep a mail's files as a set of plans (2026-11-16)

Punch list #368, PR 1 of four. The card holds the ask, the decision and the mock-up. This PR is the ground under the press: one additive migration and one new edge function, with no screen changed.

## Why

An addendum or a revised spec reaches a bid by mail. Since v2.7479 the tied mail reads on the site's History, but its files stay on the line in Messages while the estimators and the robot read the bid's plans in Drive. The job's press, *Keep this mail as a paper*, takes a job only: a paper sits on a plan part, and a part is owned by a development or a job, never a bid.

## What landed

- **`bid-plan-set-files`**, a new function with two asks. `keep` finds or makes *the bid's project folder › Plans › the set's name* and adds one `bid_plan_sets` row that points at it. `save_attachment` files our copy of one of the mail's files into a set's folder. The rules are `_shared/bidPlanSetFilesRun.ts`, driven by a fake in `src/lib/bids/bidPlanSetFilesRun.test.ts`.
- **`message_attachments.bid_plan_set_id`**, the record that a file was filed into a set. The function writes it as the service role once the file is in the folder. It is per file, so a mail with three files can have two kept, and a later mail can add a sheet to a set an earlier mail made.

## The rules worth knowing

- **Who.** The roles `bid_plan_sets_insert` names: dev, the leaders, the assistants, the controller and the estimator. The test reads the migration and fails when the function's list differs. The bid, the mail, the set and the file are read as the caller, and the set's row is the caller's own insert, so each table's policies decide.
- **Checked first.** Everything an ask carries is checked before anything is made in Drive. A refusal says so in words.
- **One set a name on a bid.** A keep under a name the bid already has a folder for answers that set. A second press makes nothing, and a later mail of the same conversation joins the first one's set.
- **A second try is safe.** A file that landed before its answer got back is found by its name and size. A keep whose row did not save leaves its folder, and the next try takes it.
- **The bid's folder.** The same rule the bid's photos follow: the folder on the bid's link, else one made under the jobs root by the office's pattern. A folder in a personal Drive, or one the app cannot add to, holds the press with the fix.
