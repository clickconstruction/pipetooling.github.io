# v2.1941 — Order-stages modal for roadmap stage numbers (2026-08-20)

Part 2 of the stage-numbers pair (part 1 = v2.1940 badges): the stage order
behind the numbers becomes user-editable.

- **`ChecklistTechTreeOrderStagesModal`** (new): dnd-kit vertical sortable
  list of the roadmap's stages; numbers renumber live during the drag (badge
  = row index + 1), top row is always #1. Rows carry a status meta chip
  (✓ done / "N of M" / 🔒). Portals into `roadmapModalPortalHost` like the
  other tech-tree modals so it works in fullscreen.
- **Toolbar**: `TechTreeRoadmapToolbarActions` gains `onOrderStages` + an
  "Order stages" button (editors only, ≥2 stages) in both the page toolbar
  and the fullscreen overlay.
- **Persistence**: `computeStageOrderUpdates` kernel (in
  `src/lib/roadmapStageNumbers.ts`, + tests) diffs the dragged order against
  stored `sort_index` and returns only changed rows (also normalizes sparse
  indexes to dense 1..N); saved via parallel `checklist_tech_tree_groups`
  updates + reload, mirroring the task-reorder pattern. No migration —
  `sort_index` already existed.
- Help guide: `number-and-order-roadmap-stages` (covers the v2.1940 badges
  too).
