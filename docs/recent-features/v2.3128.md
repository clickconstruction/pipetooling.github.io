## Edit Job → Stages ([`JobFormStagesGroup.tsx`](../../src/components/jobs/JobFormStagesGroup.tsx))

- Mounted above the job details in edit mode (the same form instance as the Bill tab, so it reads the live plan). Collapsed: **Stages · 4 in order · 1 any time · 4 shown to Sample Contracting**. Open: **In order** rows (badge, name, `draw N · $amount`, a standing chip — *passed Sep 4* / *Sep 9 – 10 · 50%* / *Sep 22 – Oct 2* / *no window yet*) then **◆ Any time** rows, each with the **eye** (`role=switch`) that writes `shared_with_gc` through `updateFixtureRow` — saved by the billing autosave like every line-item field. Plain lines don't appear (they are not stages). No grips, no kind switch: **Set stages on Bill →** asks the window to switch regions (`JobFormModal.onRequestRegion`, wired from `JobWindowModal`'s tab state). An amber line notes when the job's share switch is still off.
- **See it as the customer** opens [`JobFormStagesDrawer.tsx`](../../src/components/jobs/JobFormStagesDrawer.tsx): a fixed light (`data-theme="light"`) panel beside the dialog that draws [`PortalStagesCard`](../../src/components/portal/PortalStagesCard.tsx) from `gcView(plan)` — live with every edit. Footer: "Only rows with the eye on; never a sub's name" and **Open the sample portal ↗** (`/portal?t=sample-gc`; the real GC link lands with PR 5's portal rewrite).
- `PortalStagesCard` is the one component both the drawer and (PR 5) the customer portal draw: the *Where the job is* caption, the headline, numbered steps with a green check / filled / hollow dot and a connector, the live step's progress bar, one `askSlot` under the `next` step, **Also on this job** for shared Any rows, the paper palette from `portalTheme.ts`.

## Subs → Work reads the eye

- `SubsStage` carries `kind` and `shared` (from the job's fixtures, which the Jobs page already loads with the two columns). The GC chip ([`WindowTextCell.tsx`](../../src/components/jobs/WindowTextCell.tsx)) reads `stage.shared`: **On Summit's portal ›** (opens the calendar) or a read-only *Not shown · set on Edit*. **Offer to GC**, **Withdraw**, **Take it off their portal** and **Offer several together…** (bundles) are removed from the Work view; the Stages tile queue's "Shown to the GC" tag reads the eye too.
- [`offerNextStage.ts`](../../src/lib/subs/offerNextStage.ts): after a sheet passes, `nextStageToShare` picks the next not-yet-shared **Order** row by line-item order (Any and plain rows never) and either flips its eye (`gc_auto_offer_next`) — mirroring `offered_to_gc` on its window until PR 5 retires that flag — or files the dispatch line (`pending_payload.fixtureId` + `stageWindowId`). It also reads the sheet→job **link** first (the last `job_number` reader from the v2.3065 sweep).
