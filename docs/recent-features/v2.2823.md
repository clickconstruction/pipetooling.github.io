# v2.2823 — Job Summary: Cycle view + stale-open list (2026-09-05)

PR 4 of the Job Summary analysis plan (artifact 9c02d29a), stacked on v2.2821 (Months).

## Client only — no migration

- [`jobSummaryCycle.ts`](../../src/lib/jobs/jobSummaryCycle.ts) (new kernel): `jobCycleRow(row, ledger)` → last field day (ledger `jobs.get(id).lastYmd`, else `last_work_date`), `billYmd` (earliest invoice `billed_at`), `paidYmd` (latest payment `paid_on` once `status === 'paid'` or payments cover the invoiced total), `workToBillDays` / `billToPaidDays` (clamped ≥ 0). `bucketJobCycleByMonth(rows, start, end)` → medians per bill month; `summarizeJobCycle` → medians, whole-cycle median (last field day → paid), slowest / fastest payer (≥ 2 paid jobs on the GC, else customer name, else "Direct"); `staleOpenJobs(jobs, today, minIdleDays, ledger)` → open (not billed/paid) jobs idle ≥ N, longest first; `STALE_OPEN_DAY_OPTIONS` (14 / 21 / 30); `median`, `jobNumberLabel`. Five tests.
- [`jobSummaryLedgerView.ts`](../../src/lib/jobs/jobSummaryLedgerView.ts): `JobSummaryLedgerRowInput.job` grows optional `invoices[].billed_at`, `payments[]`, `status`; view mode `'cycle'`.
- [`JobSummaryCycleView.tsx`](../../src/components/jobs/JobSummaryCycleView.tsx) (new): tiles (Work → bill, Bill → paid, Whole cycle — each with a Compare delta in days where fewer is green; Slowest payer with the fastest underneath; Open jobs with the idle count and contract), the grouped-bar SVG (two bars per bill month on one day axis, 30-day dashed line, bill → paid labels red past 30, hover band + `<title>`), and the stale-open panel (14 / 21 / 30 chips, bar by idle days, row = number · name · GC · lead tech · contract, click → the Jobs view with Show = All and the search set to the job number; runs on every job the page knows, not the Show filter).
- Toolbar: Cycle in the View chips; Show / Compare to apply (`rowsView`), Target does not (`marginView`). Tab: renders the view; `onOpenJob` sets the search + flips the view.
- Help guide: new `see-how-fast-jobs-turn-into-cash.md`.
