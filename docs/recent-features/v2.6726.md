## Read closer than the card

- **The firm sees the hold.** The card lists what the firm reads without naming `keep_out`; it travels, as a line under the documents, because counsel writes settlement letters too and the hold is about anything addressed to the other side, not about the firm.
- **The note stays home.** The office's note is its own words on the proceeding (who took the call, what the inspector said); the select the function runs never names the column.
- **The contact travels as words.** The person's id is traded for the name and the role before the row leaves; the people's reasons never travel (PR 1's rule).
