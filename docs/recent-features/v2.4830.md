# v2.4830 — Lien desk: a last day of work set by hand moves the Deadlines too (2026-10-07)

Client only. Grace, on the live desk: *J663 has updated date of 7/6/26 as last date on site, but after it was changed the overdue did not update.* Job 663 (Knight Contracting, Taylor) has no clock sessions and was created 2026-03-10; the office set `lien_last_work_on = 2026-07-06` at 19:24 UTC. The Lien window and the notice list took July (v2.4676 taught the four lien RPCs the hand-set month), but the Deadlines view still listed the job under Overdue as *notice not sent by Jun 15* — March's date.

## Why

The Deadlines rows, the Billed row's clock and the lien watch nudge come from [`buildLienPayRunway`](../../src/lib/jobs/lienPayRunway.ts), fed by `useBilledLienClocks` and the board's job row. v2.4676 changed the SQL readers and the desk's own builders; the runway still took `job.last_work_date` and fell back to `created_at`, so a day set by hand never reached it.

## What changed

- **`LienRunwayInput.handLastWorkYmd`** — the day set by hand counts first, in the order `lienLastWorkDay` keeps (hand → clock hours → creation day). `LienPayRunway.datedByHand` says so; `datedFromCreation` is false then; `basisYmd` is the hand day; the hover's basis reads *July 2026, last day set by hand* (`LAST_DAY_SET_BY_HAND_WORDS`). The work months from the sessions still ride as earlier owed months, so a hand day after the hours extends the months as the SQL does.
- **The Pipeline's `lienRunwayFor`** passes `job.lien_last_work_on` (the board selects `*`, so the column was already on the row), and the Deadlines rows' `lastWorkYmd` prefers it.
- **`useLienWatchNudge`** selects the column and prefers it, so the Dashboard's lien reminders count from the same day.

For 663 that means: July's § 53.056 notice on a commercial property is due the 15th of the third month after — **Oct 15**, eight days away — so the job leaves Overdue for *This month*, and its lien date is Nov 16. The notice itself is still to send.

## Tests

`lienPayRunway.test.ts` (+1): 663's case (hand over creation, the dates, the words, `datedByHand`), a hand day after the hours (August last, July still owed), a blank or junk hand day changing nothing.

## Live

Dev server against prod after the change: the Deadlines view listed 663 under This month with the notice owed by Oct 15, no longer under Overdue.
