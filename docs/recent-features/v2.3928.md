## What the tests pin

- The wording, word for word: the not-coming-in flow says "Removed N schedule block(s) **for the day**."; the NCNS flow says "Removed N schedule block(s)." — they differed before and still do.
- A day that already had time off warns instead of confirming, still clears the blocks, and says nothing about the salary sync.
- When the NCNS day-off marking fails, the incident is still confirmed first and the warning says which one is on record.
- The blocks that would not go are always the last toast.
