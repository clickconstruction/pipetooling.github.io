# v2.3694 — Lien desk: change the notice’s wording on the paper itself (2026-09-22)

Client only; no migration, no edge function. Mock-up: the Claude artifact *Edit Where You Read* (second pass, shaded boxes). Approved as drawn.

## Why

The owner, on the *WORDING · STANDARD* row: *"I don't like this title and it does not make sense to me"* — then: *"instead of having the fill-ins be there, have them editable on the page. This would reduce the duplication."* The row held the same four values the paper showed, under a name that suggested the letter's prose and a tier. The paper is what the office reads; typing where you read removes the copy and the name.

## What shipped

- **The paper HTML takes marks** ([`lienFilingDocuments.ts`](../../src/lib/jobsDocuments/lienFilingDocuments.ts)): `filingDocHtml(blocks, { marks })` — a `typed` value sits in a shaded box (`data-editable="yes"`, `data-field-text` around the text, `data-changed` with a *changed from the job's wording · Back* sub-line carrying `data-reset`), a `locked` one in a grey dotted box, a `derived` one gets only a `title` saying where it is filled from. `buildLienNoticeBlocks(f, extras, { ghostOptional })` emits the blank optional party line as a `ghost` block the desk shows dashed (*+ add one — left off the paper until you type*). Print and PDF pass no options and are unchanged.
- **The desk** ([`LienDeskModal.tsx`](../../src/components/jobs/LienDeskModal.tsx)): the Wording section is gone; a slim row keeps the legend (*a shaded box is yours to change — click it, on the paper*; locked: *pull it back to a draft*) and *Preview in a new window ↗*. A click on the paper is delegated: a `data-reset` button puts that value back; a shaded value opens an `<input>` positioned over the value's own box (its rect and computed font), Enter/blur commits into `wordingEdits`, Esc drops it; a locked value answers with a toast. The preview window's *Change ›* message opens the value on the paper instead of the old row. The page label carries `wordingLineText` — now *1 value changed by Taunya* — and the leader's card reads *… from the job's wording — the notice below carries it*.
- The preview window keeps its own editable side list (v2.3660 was the owner's ask); both write the same edits.
- Guide *send lien notices from the Lien desk* → "Change it on the paper".

## Verified

- `LienDeskModal` render tests: the four shaded values in order, a derived value's title, the ghost; click → box → Enter keeps → label counts → Esc drops → Back resets; the ghost typed becomes real; the preview's message opens the value on the paper; locked once awaiting approval. Preview and release-note suites; lint; typecheck.
