# v2.3213 — Bids on a map: pin clustering, off by default, a per-device toggle (2026-09-09)

Client only — no migration, no new dependency. Owner ask after v2.3209: "offer clustering, but it should be toggleable"; decision: **default off**.

## What changed

- **Kernel** [`src/lib/map/clusterPins.ts`](../../src/lib/map/clusterPins.ts) (+5 tests): `clusterPins(pins, zoom, { cellPx = 44, ringPriority })` projects every pin to Web-Mercator world pixels at the map's zoom (`projectToWorldPx`, 256-px tiles — the projection both canvases use) and buckets them on a grid; a cell with two or more pins becomes one `PinCluster` at the members' mean position (majority `color`; `ringColor` = the first entry of `ringPriority` any member wears, so red beats amber), singletons stay pins. `clusterBounds` (what a click frames), `clusterRadiusPx` (12–22 px, log₂ of the count), `clusterLabel` (`99+`).
- **Both shared canvases** learn `cluster?: boolean` and `clusterRingPriority?: string[]`:
  - [`PinsMapCanvas.tsx`](../../src/components/map/PinsMapCanvas.tsx) (Leaflet): a `ZoomTracker` (`useMapEvents({ zoomend })`) feeds the zoom; clusters render as `Marker`s with a `divIcon` disc (count, majority color, 3-px ring shadow); click → `fitBounds` of the members (`maxZoom` 17).
  - [`PinsMapGoogleCanvas.tsx`](../../src/components/map/PinsMapGoogleCanvas.tsx): `useMapZoom` listens to `zoom_changed`; clusters are circle `Marker`s (`scale` = radius, the ring as a 4-px stroke) with a white bold `label`; click → `fitBounds` then cap at zoom 17 on `idle`. The selected-pin info window only considers single pins.
  - The Dashboard jobs map (`DashboardJobsMapCanvas` / `…GoogleCanvas`) shares the files but passes no `cluster` prop — unchanged.
- **The toggle** ([`BidBoardMapCard.tsx`](../../src/components/bids/BidBoardMapCard.tsx)): a **Cluster** / **Clustered ✓** link between the section chips and Fit all (shown when the map has more than one pin), `aria-pressed`, per-device via `readBidBoardMapClustered` / `writeBidBoardMapClustered` (`pipetooling_bid_board_map_cluster`, [`bidBoardMap.ts`](../../src/lib/bids/bidBoardMap.ts)). The card passes `CLUSTER_RING_PRIORITY = [overdue, soon]` from `BID_BOARD_MAP_DUE_RING_COLOR`. Clusters recompute from whatever pins are visible, so the section chips, the rail's distance buckets and the v2.3208 Play tour compose with it.
