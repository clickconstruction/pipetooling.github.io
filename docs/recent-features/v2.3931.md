## What changed in `src/pages/Bids.tsx`

4,963 → 4,666 lines. Behavior-preserving: the same pills, labels, tooltips, badges and order for every role; `selectBidsTab` and the tab state stay in the page. The DOM of each bar is what it was (the pills are still direct children of the bar).

## Left, on purpose

The Followup bar keeps its own role rule (`role !== 'superintendent'`) instead of reading `bidsTabOpenFor`. A Followup lens can be entered by state alone — the Bid Board's Last contact door sets the tab without the URL — so the router's gates never ran for it, and a primary who arrives that way sees the six pills as before. Closing that door is its own change, flagged separately; this PR moves code and changes nothing a person sees.
