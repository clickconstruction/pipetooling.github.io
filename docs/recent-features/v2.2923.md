6. **G12** — `start-here-in-the-office.md` is for assistant/controller, who cannot invite; the new-hire section therefore says "created by a dev" and what to ask for. If assistants should be able to invite field roles themselves, that is an ACCESS_CONTROL decision, not a guide fix.
