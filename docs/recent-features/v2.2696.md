# v2.2696 — Signed job contracts: the PDF, attached to the customer's email and filed with the job (2026-09-03)

The last open thread from the Contract Desk build (v2.2679 → v2.2693): the customer's confirmation carried a link but no document.

- **Shared PDF builder** [`supabase/functions/_shared/jobContractPdf.ts`](../../supabase/functions/_shared/jobContractPdf.ts) on pdf-lib (passed in, so the Deno function imports it from esm.sh and the vitest parity test [`src/lib/jobs/jobContractPdf.test.ts`](../../src/lib/jobs/jobContractPdf.test.ts) runs the same file on the `pdf-lib` devDependency): Letter pages with the letterhead, heading + job facts, scope bullets, not-included / dates, the contract amount and payment line, the terms (html / markdown flattened to text by `contractBodyToPlainText`), and the signature block — the drawn PNG when there is one, else the printed name in italic — over the audit line; page-count + license footer on every page. Word-wrap and page breaks are hand-rolled (no HTML renderer in Deno).
- **`sign-job-contract`** builds the PDF right after the signature commits, stores it at `<contract_id>/signed.pdf` in the private bucket (sets `signed_pdf_path`), and attaches it to the customer's confirmation (`Signed-agreement-J<n>.pdf`, Resend attachments); the email copy says the PDF is attached and the link still works. PDF failure never fails the signature — the email then carries the link only.
- **`get-job-contract`** returns `signed_pdf_url` (1-hour signed URL); the customer page shows **Download signed PDF** on the signed record (right after signing it points to the email until a reload). **`JobContractRecordModal`** gains **Download signed PDF** beside Print.
- `_shared/resendSendEmail.ts` accepts `attachments` (the lien-release precedent's payload shape).
- Help guide: "emails them a copy" → the PDF is attached.

Deploy after merge: `supabase functions deploy sign-job-contract get-job-contract`. Needs the `job-contract-documents` bucket for the stored copy; without it the attachment still goes out and only the download buttons stay hidden.
