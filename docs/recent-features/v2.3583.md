# v2.3583 — Sign-in: ClickPlumbing.com as letters made of pipe (2026-09-18)

The owner, 2026-09-18, on `/signin`: *"I think it would be really cool if we made clickplumbing dot com have letters that look like pipes."* Six mock-up rounds the same day (`to-dos/login-pipe-lettering-before-after.html`, PRs #3382 · #3384 · #3387) converged on the pick: *"let's just do this old title"* — the round-3 design with the thicker wheels. Flat white blocky pipe, square corners, a plain white flange across every open tip, a thick red handwheel on each i and on the period, the title's existing soft shadow.

## Kernel — [`src/lib/pipeWordmark.ts`](../../src/lib/pipeWordmark.ts)

Fourteen glyphs on a 100-unit cap height (`C l i c k P u m b n g o .` and a space), each an advance width and square-cornered polylines. `pipeFreeTips` finds every run end no other run touches (within 0.6 of the stroke); those get a flange (1.9× the stroke across, 0.45× thick, pulled half its thickness back into the run) or, on the glyph's marked tip, a valve stem and a handwheel (ring 0.42× the stroke, four spokes, a hub). `buildPipeWord(word)` returns one path string plus flange and wheel geometry and a viewBox, or `null` when a character has no glyph. 6 tests, including the title's counts: 3 wheels, 31 flanges.

## Component — [`src/components/PipeWordmark.tsx`](../../src/components/PipeWordmark.tsx)

`<PipeWordmark word className style accent />`: an SVG `role="img"` named by the word; pipe and flanges in `currentColor`, wheels in the accent (`#d21f1f`, a saturated action color, literal by convention). A word with a missing glyph renders as plain text. Render smoke: the title's three wheels, the fallback, and the layout wiring.

## Where it landed — [`AuthPublicLandingLayout.tsx`](../../src/components/AuthPublicLandingLayout.tsx)

The h1 link renders the wordmark when the title is drawable, with the word kept in a visually hidden span; the link's `aria-label` is unchanged. Every page on the layout gets it — sign-in, the estimate and contract accept pages (default title "Click Plumbing", drawable thanks to the space glyph). CSS in `authPublicLanding.css`: `.auth-public-landing__title-mark` at `min(540px, 100%)` → 420 → 300 px at the existing 768 / 480 breakpoints, 220 px in the compact hero, wearing the same `drop-shadow` the text title had as `text-shadow`.

No help guide: the flow is unchanged, only the title's drawing. No migration, no edge function.
