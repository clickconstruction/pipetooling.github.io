# v2.2103 — Call session bid tabs + ask prompts (2026-08-22)

Stage 1 of the Followup one-queue direction (owner-approved mockup): the call
session — the surface that best matches real life — becomes a full collector.
Purely additive; both the old By builder lens and the upcoming Call queue
share it.

- **Kernel `builderCallSession.ts`**: `CallSessionBidDecision` gains optional
  `tab` (BidTabValues) + `bidValue`; a tab alone marks the bid touched;
  `buildCallSessionWrites` emits `bidTabUpdates` patches and folds
  `bidTabNoteLine` into the bid's entry note ("Still pending. Bid tab
  recorded — low $230,000 · … . deciding friday"). New pure
  `callSessionAskPrompt`: never-contacted-since-sending → "ask: did our
  number land? can we get the bid tab?"; contacted but no tab after 21 days →
  "ask: can we get the bid tab?"; else null. +6 tests (17 total in file).
- **`BuilderCallSessionModal`**: "Bid tab…" pill per bid toggles the shared
  `BidTabCapturePanel` inline (buffered into the decision — nothing hits the
  network until End call & save, matching the session's one-save model); a
  green "bid tab noted — …(saved with End call)" line shows the buffer; bids
  with a tab already on file show a muted "bid tab on file — …" line so
  nobody asks twice; the ask prompt renders italic in each bid's header row;
  save() applies `bidTabUpdates`.
