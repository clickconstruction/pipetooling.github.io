# v2.2804 — Contract Forms PR 9: the DWC-83 (Texas workers' comp joint agreement) and a PDF-repair hint (2026-09-05)

The third live form, and the second two-party one, this time for subs.

- **`docs/forms/dwc083-2021-10.schema.json`** — Texas DWC Form 083 (Rev. 10/21), *Joint agreement to affirm independent relationship for certain building and construction workers*. 28 boxes, 20 office. **Signer (the sub, Part 3)**: name (prefilled), federal tax ID (sensitive text — EIN or SSN), address, email (prefilled), the item-19 affirmation as a required exactly-one group (help text says Click uses the joint agreement), signature and date on page 3. **Office (Parts 1–2)**: the Part 1 agreement-type group (exactly one, required), items 1–7 for the employer-employee variant under *rarely needed*, hiring contractor name and address as constants (Click Plumbing, LLC · 5501 Balcones Drive), Click's federal tax ID and email as required office boxes, the item-12 affirmation group, the withhold / not-withhold pair under *rarely needed*, the hiring contractor's signature and date on page 2. The PDF has no fillable fields, so every box is drawn at coordinates derived from `pdftotext -bbox-layout` label positions; the preview confirmed all three pages.
- **The TDI PDF's cross-reference table is broken** ("Expected instance of PDFDict, but got instance of undefined" from pdf-lib). Re-saving it with poppler (`pdftocairo -pdf dwc83.pdf dwc83-clean.pdf`) produces a clean copy the studio and the fill executor load; that copy is the template. **Form Studio** now says so when a PDF fails to load ("Re-save it — Print to PDF, or `pdftocairo -pdf in.pdf out.pdf` — and try again") instead of surfacing the parser error alone.
- Published into the **Subs** packet as **DWC-83 Workers' comp agreement** (audience sub, paperwork type other). No migration, no function change.
