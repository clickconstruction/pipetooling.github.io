# v2.2155 — Pipeline aging / no-line filters load every scope (2026-08-23)

Found while testing Quickfill → Jobs Cleanup on production: "Chase the 90+ tail — $42,049 · 3 bills" → **Show 90+** landed on a Billed list of **2** bills ($15.2k). The card's numbers come from the company-wide lean stats spine; the board's filtered list comes from the scoped jobs cache (v2.1824 scoped first paint), and a billed line whose job is Working/Waiting routes into Billed only once that scope is loaded (the same rule the chase modal and the all-scopes effect already honor). With Working collapsed on the device, ATI Schertz 650's $26,800 / 154d bill was missing. The Pipeline's own card button had the same gap.

- [`JobsStagesTab.tsx`](../../src/components/jobs/JobsStagesTab.tsx): `stagesHasActiveDisplayFilter` now includes `Boolean(billedAgingFilter)` — applying the 30–90 / 90+ / no-line filter (card button, header chip, or `?stagesMove=chase90|fixDates`) triggers the existing `NON_PAID_SCOPES` fetch, so the filtered list shows every matching bill. One-line client fix; no migration.
