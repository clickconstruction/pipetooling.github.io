# v2.3362 — Bills also go to, follow-up: each copy carries its own statement link, and the send history says who was copied (2026-09-12)

Migration `20260912050224_stripe_email_sends_copy_emails.sql` ([`docs/migrations/20260912050224_stripe_email_sends_copy_emails.md`](../migrations/20260912050224_stripe_email_sends_copy_emails.md)); edge function `send-stripe-invoice` changed (**push, then redeploy**). The two pieces of the approved proposal that v2.3358 / v2.3359 deferred.

## What shipped

- **A statement link per recipient.** `sendBillCopies` in [`send-stripe-invoice`](../../supabase/functions/send-stripe-invoice/index.ts) resolves whose portal each copy address belongs to with the same who-pays rule the create function used (`effectiveInvoiceParty` → `payerCustomerId`): the payer's contact persons get the **payer's** portal (the address the Stripe footer already carries), the other party — the GC on a customer-pays job, the customer on a GC-pays job — gets **its own**, a one-off address gets none. Links come from `loadPortalReturnUrl(admin, id, origin, { paid: false })` — the shared resolver gained a `paid` option (v2.3362) so a copy email carries a plain statement link, not the receipt-landing `?paid=1` the Stripe footer uses; every lookup fails soft to "no link". [`stripeBillCopyEmail.ts`](../../supabase/functions/_shared/stripeBillCopyEmail.ts) prints *See your statement any time at …* in text and HTML when a link is present (+1 test).
- **Copies on the send history.** `jobs_ledger_invoice_stripe_email_sends.copy_emails text[]` — the addresses this send actually reached (null when none). The function now sends the copies first and writes the log row after, carrying `copies.sent`. The Send Email invoice confirm ([`StripeInvoiceSendFromStripeButton`](../../src/components/jobs/StripeInvoiceSendFromStripeButton.tsx), also on the Stages *Last activity* cell) selects `sent_at, copy_emails` and prints *· copies to a@…, b@…* after each send's time.
- Help: `send-a-bill-to-more-than-one-person` says both. `EDGE_FUNCTIONS.md` → send-stripe-invoice.
