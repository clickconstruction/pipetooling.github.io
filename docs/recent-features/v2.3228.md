# v2.3228 — One landing style: the amber "here it is" highlights become the blue landing ring (2026-09-10)

Client only; no migration.

## Why

v2.3216 gave the bid flow doors a blue ring that scrolls, focuses, and fades. Three older "here it is" moments still painted their own amber: the Edit Bid form's focus on Project Name / GC / Bid value (inline outline + cream background, restored by a timer), the Bid Board's deep-linked row and phone card (amber tint + outline while highlighted), and Builder Review's deep-linked customer card. Two styles for one meaning.

## What shipped

- **Edit Bid focus** (`Bids.tsx` `pendingBidFormFocus` effect): calls `landOnElement` — scroll, focus, the `.bid-flow-landing` ring — then selects the input's text as before. The inline amber styling and its restore timer are gone.
- **Bid Board deep-link row + card** (`BidsBidBoardTab.tsx`): `className={BID_FLOW_LANDING_CLASS}` while the row is the highlighted one, instead of the amber tint/outline spread. The ring fades over 3 s like every other landing; the row's own highlighted state still drives the scroll.
- **Builder Review deep-linked customer** (`BidsBuilderReviewTab.tsx`): same class swap.
- No raw amber hexes remain on those three surfaces. Other amber (due-soon chips, the pricing calculator's armed state) is status colour, not a landing, and stays.
