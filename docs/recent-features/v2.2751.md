# v2.2751 — Needs you "Issue release" opens the cleared-releases queue (2026-09-04)

**Why.** The `lien-unconditional` Needs You item (v2.2582) navigated to
`/jobs?tab=stages` — the Pipeline board with no pointer to which job, and the
release button to hunt for on each row. The owner asked for a modal listing
the jobs; a deep look showed the Job window (View · Edit · Bill) cannot issue
a lien release at all (no lien panel on the Bill tab; Bill Customer is only
reachable from Ready-to-Bill rows), so a job list alone would have been a
dead end. The queue issues the follow-up itself.

**What.** `DashboardLienReleaseQueueModal` (new, `src/components/dashboard/`):
one row per cleared conditional release still owed its unconditional version —
job number + name (opens the Job window via `useJobDetailModal`), customer +
address, the release amount and issue date, the covered-line count, the
clearing payment ("Check #4471 · $408.00 applied", cleared date), an
**Issue unconditional** button (loads the job with `fetchJobWithDetailsById`
and opens `LienReleaseModal` preset to `unconditional_progress` on the first
covered line — the Bill Customer strip's exact move), and **View release**
(snapshot re-render, signature included when signed). Footer totals the
money and jobs; rows sort oldest-cleared first; empty state reads "Nothing
waiting". Overlay z-index 1000 so the Job window (1010), Bill Customer (1020)
and the release window (1100) stack above it. Escape closes the queue unless
the release window is up. Narrow viewports stack each row into a card with a
full-width button.

**Wiring.** `useLienReleasesOwedNudge` now returns `{ owed, queue, refetch }`
— same three-query load (releases → payments on the covered lines → the owed
jobs' identity) building both the count and the rows from
`buildLienUnconditionalQueue`, so the card figure and the list can't
disagree. `DashboardPinnedQuickRow` and `QuickfillNeedsYouSection` open the
modal for `lien-unconditional` (was `navigate('/jobs?tab=stages')`) and pass
`refetch` as `onChanged` — `LienReleaseModal.onIssued` fires it, the row
drops, the card count falls. The card's detail text now says "Open the list".

**Kernel.** `src/lib/jobs/lienReleaseTracking.ts`: `computeLienUnconditionalOwed`
refactored onto a shared `owedLienReleasesByJob` core; new
`buildLienUnconditionalQueue`, `appliedByInvoiceIdFromPayments`,
`lienQueuePaymentLabel` (+5 tests incl. a parity test against the roll-up).
Render smoke `DashboardLienReleaseQueueModal.render.test.tsx`.

Help: `give-a-customer-a-lien-release.md` (follow-through example) and
`needs-you-card.md` (where the actions go). No migration, no edge function.
