# v2.8447 — Bills sent: the list's spreadsheet file is named for its chip (2026-11-24)

One fault of the Bills sent page found on the live test of 2026-11-24 (punch list #422, problem 12, its second half). No migration, no edge function.

## What was wrong

**Download CSV** on By day sent saves what the list shows, so a chip or a search narrows the file. The file was named `bills-sent-2026-11-24.csv` whatever it held. By day paid's file already names its chip. Two files saved a minute apart, one whole and one under **Not paid**, could not be told apart by name.

## What changed

`billsSentCsvFileName(todayYmd, route, typed)` names the chip in the chip's own words and marks a search:

- the whole list: `bills-sent-2026-11-24.csv`
- under **Not paid**: `bills-sent-2026-11-24-not-paid.csv`
- under **Email** with a search typed: `bills-sent-2026-11-24-email-search.csv`

The searched words are not put in the name, since they may be a customer's. The guide says how the file is named.

## Tests

`billsSent.test.ts`: the whole list, five chips and a search with and without a chip. `BillsSentLedger.render.test.tsx`: the file saved under **Statement** ends in `-statement.csv`. Both failed before the change with the bare name.
