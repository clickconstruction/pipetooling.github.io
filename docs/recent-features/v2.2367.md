# v2.2367 — Pricing resolve lifecycle: loading/error states instead of a false empty Workbench (2026-08-26)

Estimator report (Wendi): used the board's new price-tag jump (v2.2360) into
Pricing on BP384 and saw the Workbench "needs Counts, an active Pricing, and a
cost estimate" setup message plus a "not sent · one packet" Send-to strip — read
it as her working version being deleted. The data was intact; the tab renders
before `bid_versions` / pricing copies arrive, and until v2.2367 it had no way
to say "still loading". A *failed* versions fetch was worse: `loadBidVersions`
swallowed the error and returned `[]`, so the bid painted as unsplit-and-empty
until a full page reload.

- New kernel `src/lib/bids/pricingResolve.ts` (+ tests): `PricingResolveState`
  (`idle | loading | ready | error`, tagged with the bid it talks about),
  `beginPricingResolve` / `settlePricingResolve` (late settles for a bid the
  user left are ignored), and `pricingResolvePanel(state, bidId)` →
  `skeleton | error | content`. `skeleton` also covers the first paint after a
  bid/tab switch, before the resolve effect has run.
- `useBidPricingEngine.ts` — the per-bid pricing resolve effect begins/settles
  the state; `loadBidVersions` / `loadBidPricings` now return `null` on fetch
  failure (state untouched) so the effect can settle to `error`; a failed run
  never stamps `pricingBidIdRef`, so `retryPricingResolve` (a retry tick in the
  effect deps) re-enters the full bid-changed path. `ready` lands only after
  `loadPricingDataForBid` + assignments finish — the aborted-first-run case
  settles from the re-run (see the v2.1763 comment in the effect).
- `BidsPricingTab.tsx` — new required props `resolvePanel` / `onRetryResolve`.
  The New-view Workbench renders a spinner + shimmer rows while `skeleton`, and
  a "Couldn't load this bid's packets and prices… Your versions are safe." panel
  with Retry on `error`; the permanent empty state can only render on `content`.
- `BidVersionPicker.tsx` — optional `resolvePanel` prop (passed from the Pricing
  and Cover Letter tab sites): shimmer ghost chips while loading, an error chip
  on failure — never the unsplit "one packet" claim from a not-yet-loaded list.
- `index.css` — `.bid-resolve-shimmer` / `.bid-resolve-spinner` (reuses the
  `dashboard-skeleton-pulse` keyframes; `prefers-reduced-motion` disables both).
- Help guide `price-a-bid-with-the-workbench.md`: troubleshooting note.
