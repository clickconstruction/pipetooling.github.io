## Client

- **Nudge kernel** [`lib/jobs/jobContractNudge.ts`](../../src/lib/jobs/jobContractNudge.ts) (+3 tests): over every non-paid job (owner decision 2), the PR 1 coverage kernel splits **missing** (none or draft; count + revenue total) from **stale** (sent ≥ 7 days, unsigned; count + oldest). Hook [`hooks/useJobContractsNudge.ts`](../../src/hooks/useJobContractsNudge.ts): three scans, null while loading, zero on error, refreshes on `job-contract-changed`.
- **Needs You** (`dashboardNeedsYou.ts`): `contract-missing` (amber, tier 40 beside job follow-ups — "14 live jobs have no contract on file · $186k of work" → *Start the sweep*) and `contract-stale` (amber, tier 50 — "3 contracts have been out for signature a week" → *See them*). `DashboardPinnedQuickRow` gathers the nudge for the office set and routes the actions to `/jobs?tab=stages&contractSweep=1` and `/jobs?tab=stages&contract=sent`.
- **Contract sweep** [`components/jobs/JobsContractSweepModal.tsx`](../../src/components/jobs/JobsContractSweepModal.tsx): every loaded live job without an agreement, Working first — job, address, stage, amount, customer; an email input prefilled from the job (red when invalid); **Send** per row, **Send all N ready** (two-click confirm) for every row with a valid email, **Fix email** (opens Edit Job) otherwise; the terms picker in the footer applies to the whole sweep; the job name opens the full Contract modal for careful edits or a paper upload. Rows leave the list as they send.
- **Quick send** [`lib/jobs/jobContractQuickSend.ts`](../../src/lib/jobs/jobContractQuickSend.ts): reuses a live draft/sent row or mints a draft from the job's own facts (fixtures → scope, revenue → amount, chosen template or built-in terms), then calls `send-job-contract` — one call per row, never a second live contract.
- **Pipeline**: the ⋯ tools menu gains **Contract sweep…** (with "N without" in amber); opening the sweep loads every non-paid scope like an active filter; `?contractSweep=1` opens it on arrival.
- Help guide gains "Clear the backlog".
