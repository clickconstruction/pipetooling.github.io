## What changed

- **Reader** [`houseFileParts.ts`](../../src/lib/submittals/houseFileParts.ts): `readHouseFile(pageTexts)` finds the printed job line (`rawCommonHeader`), the tags from the divider pages, and groups the cut sheet pages into parts by the `Maker | MODEL` stamp (a page with no stamp continues the part before it; a page with no text stays inside its run); each part's model and description come from its divider line (`dividerLine`: the model as the divider prints it — "PROPH40 T2 RH400" — and the words up to its start page), else the contents. Null for a file with no stamped job line.
- **Beside the rows** — `matchFileToRows`: a tag lands on the rows that carry it (`tagSet` reads "WC-1 & WC-2", "WC-1, WC-2" and "WC 1&2" alike; a combined tag lands on each split row); a tag no row carries looks for the row whose parts share the most models (MB-1 → the mop sink row, to rename); `pairParts`: the same model first, then the same kind of part (`partRole` from the divider's words, then the page's first words), then a shared model start of four characters, then the last one on each side (trim aside). `planFileApply` turns the review's choices into writes: a file part in place of a row part rewrites that part (another model keeps the takeoff's name as `priced_label` and drops the catalog link; the same model keeps both), a file part beside nothing is a new part, a row part the file does not carry is kept as order only or comes off, the file's parts first in file order, each on the GC's submittal with its own pages; the row's sheet is every page they use (`sheet_source: 'house'`).
- **The door** — **Read its parts…** on a vendor file's line (`SubmittalSheetStrip` `onReadParts`; it leads when the file is sectioned, sits beside Assign pages on an unread file, and is gone on a file the reader found no sections in).
- **The review** — [`SubmittalHouseFileModal`](../../src/components/bids/SubmittalHouseFileModal.tsx): the counts, *Bought from* (the file's house; written on the file record), one card per tag — use it or not, where it lands (*→ LAV-2*, *→ the row 12" DEEP MOP SINK, by its parts* with *call it MB-1*, *no row yet* with *add it as a row*), each file part with its pages, *the same* / *in place of* / *not priced* and a select for what it takes the place of, and the row's parts the file does not carry with *Keep, order only* / *Take off*. Stacks on a phone.
- **Per-part sheets** — `PackageRowInput.partSheets` + `packageSheets(plan)` in [`submittalPackage.ts`](../../src/lib/submittals/submittalPackage.ts): a row whose parts carry their own pages (and whose pages they are — a later walk on the row wins) lays out each part's pages in part order, stamped with the part's name. **Done with this file** remaps the parts' pages with the trim; **Remove** shifts their file index.
- **Rows and Edit** — each part shows its pages; a part from the file in a priced part's place reads *… in place of the priced … · say why with Edit*, and Edit takes the reason on the part (`PartDraft.reason_note`).
