# v2.2819 — Work Orders tab, PR 2: the board and the assembler (2026-09-05)

Second of three PRs for the **Work Orders tab** (PR 1: [v2.2814](./v2.2814.md)). Jobs gains a **Work Orders** tab between Team Labor and Sub Labor (`?tab=work_orders`, `?wo=<id>` deep-links one order), and the work order is assembled like a bid cover letter with a live preview.

- **Board** — [`JobsWorkOrdersTab.tsx`](../../src/components/jobs/JobsWorkOrdersTab.tsx): every non-cancelled `step_commitments` row, labelled by job (`job_id`, else the sheet's job number, else the snapshot's `facts.jobLabel`, else the sheet / project-step name); filter chips All · Drafts · Awaiting signature · Signed · Declined · Expired (counts from `workOrderBoardBucket`) + search over WO number / sub / job. A **Needs a work order** panel lists jobs whose unpaid sheets have no live or signed order (`jobsNeedingWorkOrder`), each with *Draft a work order…* pre-anchored to the job. Row actions by bucket: drafts → *Set a price… / Edit*, *Discard* (status `cancelled`); awaiting/expired → *View*, *Nudge* (re-sends `notifySheetWorkOrderOffered` with `work_order_id`), *Signed on paper* (status `accepted`; job-anchored rows without a sheet then call `create_sheet_for_work_order`), *Withdraw* (back to draft); signed → *View*, *Print*; declined → *Re-offer…*, *Print*. Refreshes on the `work-order-changed` event.
- **Assembler** — [`WorkOrderAssemblerModal.tsx`](../../src/components/jobs/WorkOrderAssemblerModal.tsx): three steps. *Job* (the dispatch job picker over the shared jobs cache). *Sub* (roster chips from `people` kind `sub`, inline *Add sub*). *Scope and terms*: library scope for the trade (`sub_scope_items`), the linked bid's per-stage lines (`bidScopeLines` over the latest bid version's counts) and typed lines for this job, exclusions, price with the bid's sub-labor hint (`bidSubLaborTotals`), retainage, window, offer expiry, bond, special provisions, references (Contract library docs for subs + pay schedule + insurance/COI), acknowledgements — all rendered live by [`WorkOrderDocumentView.tsx`](../../src/components/jobs/WorkOrderDocumentView.tsx) (light paper) from `buildWorkOrderDocument`. *Save draft* keeps an unpriced draft (`amount NULL`); *Send for signature* requires a price, mints `record_id` via `next_work_order_record_id`, freezes the snapshot with `facts` (issuer from `users.name` + role title) and notifies the sub. Sent / signed orders open read-only as *The signed document*; declined ones reopen for a re-offer. *Print / PDF* opens `renderWorkOrderDocumentHtml` in a new window.
- **Portal signature creates the sheet** — [`submit-sub-portal`](../EDGE_FUNCTIONS.md#submit-sub-portal) `accept_offer`: for a job-anchored order with no `labor_job_id`, the signature stamps first, then the service role calls `create_sheet_for_work_order`; the dispatch note carries `laborJobId` (the created sheet) and `jobId`.
- **Notifications** — `notifySheetWorkOrderOffered` takes `laborJobId` *or* `workOrderId`; [`send-workflow-notification`](../EDGE_FUNCTIONS.md#send-workflow-notification) accepts `work_order_id` as a third anchor (validation + push tag).
- Shared helper `lib/subPortal/resolveSubPortalUrl.ts` (custom short link → newest live token → mint) used by the assembler and the board.
- `database.ts` regenerated from the linked project after PR 1's migration landed (`step_commitments.amount` nullable on Insert/Update; the two new RPCs).
- Guides: new [assemble a sub work order](../../src/content/help/assemble-a-sub-work-order.md); [send a sub a work order from a sheet](../../src/content/help/send-a-sub-a-work-order-from-a-sheet.md) points at the tab.

- Migration [`20260905063000_create_sheet_for_work_order_claims`](../migrations/20260905063000_create_sheet_for_work_order_claims.md): the RPC's service-role gate now reads the JSON `request.jwt.claims` (the legacy `request.jwt.claim.role` GUC is no longer set by PostgREST) — the first live portal signature stamped but created no sheet.

Deploy: `send-workflow-notification`, `submit-sub-portal`; `supabase db push` for the claims fix.
