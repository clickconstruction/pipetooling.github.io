# v2.2992 — Test-gap audit, pass 15: the contract HTML sanitizer gets its first tests, and a pass-cap bypass is closed (2026-09-07)

Follow-up to v2.2991, which named this kernel next. One kernel fix plus tests; no client markup, migration or edge-function change.

## Why this one

`sanitizeContractSigningHtml.ts` (130 lines) is the allowlist sanitizer between staff-entered HTML and `dangerouslySetInnerHTML`: contract bodies on the public signing page and the Contract Book preview (`ContractBodyDisplay`, `ContractBookPreview`), markdown contract bodies after `marked`, the help guides (`helpGuideHtml`) and HR documents (`hrDocMarkdown`). It had no test of its own; the HR-doc and help-guide suites only touched it in passing.

## What the tests found

**The cleanup loop could run out of passes.** It removed or unwrapped **one** element per pass and stopped after 200 passes. Any body with more than 200 tags outside the allowlist left whatever came after them untouched, and the attribute pass only strips `on*` handlers from allowlisted tags, so an `<img onerror>` behind 250 `<font>` wrappers survived into the rendered page. Staff author these bodies, so the exposure was a careless or copied paste rather than a hostile customer, but a sanitizer with a size limit is not a sanitizer. The loop now handles every element in the snapshot per pass (skipping ones detached with a removed ancestor); one pass settles any input and the second only confirms nothing changed. The 200-pass cap stays as a backstop.

Also pinned, unchanged: a bare `<td>` outside a table is dropped by the HTML parser before the sanitizer sees it, so table cells are only preserved inside a table.

## What shipped

- **`sanitizeContractSigningHtml.test.ts`** (9, jsdom) — the contract vocabulary round-trips unchanged; http(s) links kept, `rel="noopener noreferrer"` added to a bare `target="_blank"` and an existing `rel` respected; blank input; scripts, styles, frames, objects, forms and their controls, meta/link/base, svg and math removed with their contents; unknown tags unwrapped to their text (section, font, s, code, h5, img, video); every attribute but `href`/`target`/`rel`/`colspan`/`rowspan` stripped, including upper-case `ONCLICK`; `javascript:`, `data:`, `mailto:`, relative and protocol-relative hrefs dropped; nested forbidden and unknown tags reached; and the 250-wrapper case above.
- **`sanitizeContractSigningHtml.fallback.test.ts`** (1, node) — without a DOM the sanitizer strips to text, dropping script and style bodies whole.
- **`sanitizeContractSigningHtml.ts`** — the loop fix described above.
