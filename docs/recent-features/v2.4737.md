# v2.4737 — Cover Letter: what you type in the three boxes stays with the bid (2026-10-06)

Punch list #73, PR 0a ([`to-dos/bid-history`](../../to-dos/bid-history/README.md)): the first of the three "stop the losses at the source" fixes. The Cover Letter tab's *Additional inclusions*, *Exclusions and scope* and *Terms and warranty* boxes were React state only (`coverLetter*ByBid` in `Bids.tsx`): typed, printed on the letter, never written anywhere, so a reload emptied them — one of the two silent ways Wendi's work on the SpaceX bid could vanish. Migration `20261007060000_bids_cover_letter_texts.sql` ([doc](../migrations/20261007060000_bids_cover_letter_texts.md)); no edge function.

## The change

- **Three columns on `bids`**: `cover_letter_inclusions`, `cover_letter_exclusions`, `cover_letter_terms` (null = nobody typed; a string is what was typed). The ledger keeps them: `bid_changes_bid_columns()` redefined whole with the three, the `bids` trigger's `UPDATE OF` list rebuilt in place.
- **The tab** ([`BidsCoverLetterTab.tsx`](../../src/components/bids/BidsCoverLetterTab.tsx)): on opening a bid, the saved texts seed a box nobody has typed in this session (a typed box keeps its text, as the alternates' wording does); a change writes back after 800 ms, only the boxes that moved, through the same refused-write guard as the rest of the tab. The fallback order is unchanged: typed → the org default → the built-in wording.
- `src/types/database.ts` carries the three columns by hand until the regen after the push.

## Tests

`BidsCoverLetterTab.letterTexts.render.test.tsx`: the saved exclusions show in the box and reach the room's wording; typing inclusions writes the one column after the pause; a box typed before the read keeps its text. `bidChangesCapture.test.ts` (12) holds the column list.
