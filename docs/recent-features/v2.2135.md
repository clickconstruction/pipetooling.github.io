# v2.2135 — Help guide: add a stage and its tasks to a roadmap (2026-08-22)

Owner asked "how do I add a stage and sub tasks in this view?" on Roadmap → Map. The five
existing roadmap guides covered create/rename/share, numbering, staffing, the task card and
the Timeline — none explained the two add affordances the Map already has.

- New guide [`add-a-stage-and-its-tasks-to-a-roadmap.md`](../../src/content/help/add-a-stage-and-its-tasks-to-a-roadmap.md)
  (category Office, editor roles, order 42): stage via the toolbar *Add a roadmap group*
  button or by dragging a node's right-edge connector dot into empty canvas (pre-wired
  prerequisite, `onPrereqConnectEnd` → `linkFromGroup` modal); tasks via the per-node
  **+** (*Add task to this group*) → title + optional assignees; expand with › / Show all;
  cross-links to the numbering and staffing guides. Docs-only — no code change.
