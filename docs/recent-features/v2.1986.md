  request — {Customer}: …", details in `pending_payload`

  existing `notify-dispatch-request` push fan-out. Attribution
  (`from_user_id` NOT NULL): `app_settings.portal_requests_from_user_id`
  when set, else the link's minter, else the first dev.

  fn deploys at merge. Dedicated notification stream (email CC list) is the
  next car.
