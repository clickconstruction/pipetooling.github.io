# v2.2229 — Section tools menu reads the header's Capable of Being Billed total (2026-08-24)

The jump-bar Section tools menu (Jobs → Pipeline) computed its "Capable of Being Billed: $X" label from `capableToBillTotalFromWorking(stagesBoardLists.working)` directly — but under the scoped-load model (v2.1824) that list is empty until the Working section's scope is fetched, so with Working collapsed the menu showed $0 while the section header (which falls back to the lean `cacheHeaderStats.capableToBill` stats) showed the real total. Seen live 2026-08-24 ($0 vs $2,608).

Fix: `JobsStagesTab.tsx` hoists a single `capableDisplay` const (live list when the working scope is merged, header stats otherwise, `…` while stats load) and both the Working section header and `buildStagesSectionToolsMenu`'s `capableToBillTotalFormatted` input render it. Kernel unchanged; `stagesSectionToolsMenu.test.ts` gains a passthrough case for the `…` loading value.
