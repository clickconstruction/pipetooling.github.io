# v2.4038 — Pricing's quote windows say why a save or a load failed (2026-09-28)

Client only; no migration, no edge function. Two fixes the quote-window smokes found (v2.4022), across six windows: the Division 22 audit, the Supply house list, the RFQ desk, compose, Plug in quotes and Plug in the schedule.

## A refused save kept its reason to itself

Each window did `if (error) throw error` with the error supabase-js returns, then showed `err instanceof Error ? err.message : '<generic line>'`. That error is a plain object parsed from the response, never an `Error`, so every refusal read the same — "Could not save the rule.", "Could not save the quote." — and Plug in the schedule showed "Could not save: [object Object]". A permission refusal and a broken constraint looked alike.

Every write now goes through the repo's `checkSupabaseError` (or `databaseErrorFromResult`), and every catch through `formatErrorMessage` — the same path the rest of the app uses. A refusal reads "You don't have permission to save the rule."; any other server answer reads "Failed to save the rule: <the server's words>".

## A failed load looked like an empty list

- **Compose** — a supply house read that failed showed "No supply house matches that." It now says why, with **Retry**, and Preview stays off. The bid's trade read, which had no error handling at all, falls back to listing every house. The read also re-runs if the bid changes while the window is open.
- **The RFQ desk** — a failed read showed "No price requests on this bid yet" beside a toast. It now says why in place of the list, with **Retry**. A failed delivery read (`email_send_log`) no longer passes silently: the desk says a bounced request may show as sent.
- **Plug in the schedule** — a failed read looked like "Nothing on the bid yet", and a paste-and-save could then replace saved rows the estimator never saw (the save upserts on bid and tag). It now says why, with **Retry**, and **Match to tags**, **+ Add a tag by hand** and **Save** stay off until the read succeeds.
- **The Supply house list** and **Plug in quotes** — a supply house list that did not load left an empty picker with no word; each now says so.

## Tests

Across the six smoke files, 7 added and 3 rewritten (62 cases): a refusal shows the permission sentence; another server answer shows the server's words; each failed load shows its reason, and Retry reads again; the schedule keeps its three controls off until the read lands. All ten fail on the old components.
