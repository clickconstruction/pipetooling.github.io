# v2.3785 — The Pipeline strip ticks the days that were worked (2026-09-23)

PR 2 of the two-week strip (v2.3752 drew booked days only): the past cells now carry the answer. Client only, no migration.

## The change

- **[`stagesWorkedDays.ts`](../../src/lib/stagesWorkedDays.ts)** (new, tested) — `fetchStagesWeekSoFarForJobs(jobIds, fromYmd, todayYmd)`: two batched reads for the board's job ids, chunked by 200 like the upcoming-schedule read — `clock_sessions` (`job_ledger_id, work_date, users(name)`, `work_date ≥` this week's Monday, `approved_at` set, `revoked_at` null) and `job_schedule_blocks` (`job_id, work_date` from Monday up to yesterday — the upcoming read starts at today, so without this a past block is invisible and a slipped day could never draw hollow). `groupStagesWorkedDays` folds sessions into one entry per job-day with the names of who clocked (sorted, deduped); `groupStagesPastBookedDays` + `mergeStagesWeekSoFar` give one `StagesWeekSoFar { worked, bookedYmds }` per job. Hours are not summed here — the row's ◷ line owns that math.
- **[`stagesScheduleStrip.ts`](../../src/lib/jobs/stagesScheduleStrip.ts)** — `buildTwoWeekStrip` takes `workedYmds`; a cell gains `worked` (approved session that day) and `missed` (booked, before today, nobody clocked). Today's booked cell is never "missed" — the day is not over. A worked weekend day appears as a cell even when it was never booked. `workedInWindow` joins the counts.
- **[`jobsStagesRowShared.tsx`](../../src/components/jobs/jobsStagesRowShared.tsx)** — `StagesRowRenderContext.stagesWorkedByJobId`; `renderStagesScheduleStripCells` draws ✓ in a green `isWorked` cell and a hollow, slashed `isMissed` cell, and the strip's title adds one clause per such day: *M 09-21 ✓ Malachi, Tristen · T 09-22 booked, nobody clocked*.
- **[`JobsStagesTab.tsx`](../../src/components/jobs/JobsStagesTab.tsx)** — `stagesWorkedByJobId` state and an effect keyed on the same id set as the upcoming read (`stagesUpcomingIdsKey`, held until the list has loaded), from `stripWeekStartYmd(today)`. Threaded as a prop through [`JobsStagesTable`](../../src/components/jobs/JobsStagesTable.tsx), [`JobsStagesUnifiedTable`](../../src/components/jobs/JobsStagesUnifiedTable.tsx) and [`JobsStagesCardList`](../../src/components/jobs/JobsStagesCardList.tsx) (which shares the table's props type) into their row contexts.
- **[`index.css`](../../src/index.css)** — `.stagesStripCells i.isWorked` (green, ✓) and `.isMissed` (surface fill, link-blue border, a diagonal rule).
- **Guide** *see what days a job is on people's calendars* — the strip paragraph now describes the three cell states.

## Cost

Two more small requests per board load (the office roles already read `clock_sessions` for the man-hours line, and `job_schedule_blocks` for the NEXT line). The map is keyed on the board's id set, so a scope merge or an enrichment patch that re-mints `jobs` without changing which jobs are on the board does not refetch.
