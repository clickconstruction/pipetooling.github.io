# v2.4511 — Bids: Hide robots, just below Only my bids (2026-10-04)

Client only; no migration, no edge function. The owner, on the Submittals bid list: "we should have an additional checkbox just below [Only my bids] that says hide robots and that would hide all of the ZZ bids."

## What it does

- **Hide robots** is a second checkbox in the row above the bid picker, on all nine workflow tabs (Counts, Takeoffs, Labor, Pricing, Cover Letter, Submittals, RFI, Change Order, Lien Release). Ticked, every bid whose project name starts with the word `ZZ` leaves every group of the list: the twins' `ZZ Twin …` and `ZZ Shadow …` bids and the office's `ZZ Test …` bids alike, as asked ("all of the ZZ bids"). The headings' counts follow.
- **It shows only while Only my bids is off** (the owner's follow-up: "only appear when a user has deselected only my bids"), stacked under it. With Only my bids on the switch is not on the page and hides nothing — no filter works out of sight.
- **It is ticked when it shows** (the owner: "selected by default when a user deselects only my bids"). The first look at everyone's bids is the people's bids. Unticked, it stays unticked: the choice is kept per browser (`localStorage` `bidPickerHideRobots`, off only on a stored `0`), one for every tab, like the sort view and the folds.
- **A line under the list** says *12 ZZ bids hidden.* with **Show them**, which unticks the switch. When a list holds nothing but ZZ bids the line stands alone, so the person is never left with an empty page and no reason. It filters while searching too; the line says why a ZZ match is missing.
- **A bid marked by you or for you is never hidden** — a mark is how someone hands over a robot's bid to look at, and Only my bids keeps it for the same reason.

## How it is built

- [`src/lib/bids/bidPickerRobots.ts`](../../src/lib/bids/bidPickerRobots.ts) — the kernel: `isZzBidName`, `splitRobotBids(bids, hide, keep)`, `hiddenRobotsWords`, `normalizeHideRobots`. The rule reads the name only; the Bid Board's People / Robots scope (`bidBoardScope.isRobotBid`, estimator or creator is a twin) is untouched.
- [`HideRobotsToggle.tsx`](../../src/components/bids/HideRobotsToggle.tsx) — the switch and its module store, the same shape as `BidPickerSortToggle`, holding two facts: the tick (`setHideRobotBids`) and whether the switch is on the page (`setHideRobotsOffered`, set by the search row from `onlyMyBids` in a layout effect, so the list never paints a frame behind). `useHideRobotBids` — what the list reads — is true only for both.
- [`MyBidsToggle.tsx`](../../src/components/bids/MyBidsToggle.tsx) — its look is now `BidPickerCheckToggle`, shared by both. Alone, Only my bids keeps its size; stacked, both are `compact` so the pair is 47px beside the 42px search box.
- [`BidPickerSearchRow.tsx`](../../src/components/bids/BidPickerSearchRow.tsx) stacks the two; [`BidPickerStandardList.tsx`](../../src/components/bids/BidPickerStandardList.tsx) hides the bids before the Marked filter and draws the line. No tab changed: both pieces are already shared by the nine.
