# v2.3319 — Legal portal PR 3: the firm's portal, read side (2026-09-11)

Migration `20260911202259_legal_portal_links.sql` ([`docs/migrations/20260911202259_legal_portal_links.md`](../migrations/20260911202259_legal_portal_links.md)); **new edge function `legal-portal`** (`verify_jwt = false` in `config.toml`; deploy after the push). Stacked on v2.3313 (PR 2). Third of five.

## Why

PR 2 stored the release; nothing showed it to a firm. The firm needs the packet the office curated, from the same records by the same rules, with the office's held-back decisions applied before anything leaves.

## What shipped

- **Link spine** — `legal_portal_links` (firm-keyed, token only, one active per firm), `mint_legal_portal_link` / `revoke_legal_portal_link`, `public_page_views.surface` + `legal_portal`. [`LegalPortalLinkButton`](../../src/components/jobs/legal/LegalPortalLinkButton.tsx) on the desk header (create · copy · preview with the uncounted office flag · rotate · turn off; never mints on open).
- **[`legal-portal`](../../supabase/functions/legal-portal/index.ts)** — resolves the token (raw + sha256 fallback, revoked → 404), counts the view (`publicViewDecision`), and returns the firm, Click's particulars (`app_settings.legal_particulars_v1`) and every matter with `stage IN (referred, demand, suit, judgment)`: jobs with invoices and payments, the customer, contact persons, property record, contracts (signed PDFs as one-hour signed URLs from `job-contract-documents`), accepted estimates, demand letters, lien filings, promises + promise records, chase touches, contact history, reports (with template names), clock sessions, thread notes, and the matter's entries. **Held entries are dropped server-side** with the desk's rule (before the first bill unless shared; after it unless held; keys `contact:` / `promise:` / `call:` / `note:`); a held collections note is blanked on the job. `sharedOverrides` carries only the pre-bill entries the office shared, so the kernel shows them as going.
- **[`legalPortalPayload.ts`](../../src/lib/legal/legalPortalPayload.ts)** — defensive parse + `buildMatterPacket` (contract coverage → payer account → `buildLegalPacket` with the firm's fee model), so the firm's page and the desk run one kernel.
- **[`LegalPortal`](../../src/pages/LegalPortal.tsx)** at `/legal?t=<token>` (static import, public, `data-theme="light"` on the customer-statement paper): matters rail, the matter card with theory and total demand (balance + the firm's fee/cost entries), five tabs, exhibits with PDF links, Print packet (the same print builder), Click's particulars, what-you-get / what-is-next.
- **Settings → Jobs & dispatch → Collections law firm** gains *Click's particulars for filing* (one `app_settings` JSON key).
- Help guide `share-your-attorney-their-portal`; EDGE_FUNCTIONS section; ACCESS_CONTROL.
