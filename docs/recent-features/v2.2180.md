# v2.2180 — Vehicles: Insurance card with the per-vehicle cost (2026-08-23)

Owner: "I would like to be able to specify how much the insurance costs per vehicle … it does not seem easy when I go to People → Vehicles and click on a vehicle." Mockup approved as built: https://claude.ai/code/artifact/6faa5cc0-c1a0-4e22-96da-463797976464. The figure already existed (`vehicles.weekly_insurance_cost` — printed on pay stubs via `buildPayStubHtml`, summed into the fleet facts line) but was only editable inside the Edit modal under the VIN, detached from the plan status you actually look at.

- **Insurance card** ([`PeopleVehiclesTab.tsx`](../../src/components/people/PeopleVehiclesTab.tsx), under the odometer card, same anatomy): left = plan status (`planName · since date` with **Change plan** / **Take off**, or amber **Not on insurance** with **Add to plan** — the action-row "Insurance" button is gone, its job lives here) + the cost line `$59.35/wk · ≈ $257/mo · $3,086/yr` (off a plan: `$0.00/wk while off a plan · last cost $X/wk`; none: "no cost set — type what the carrier charges for this vehicle"); right = amount input + unit `<select>` (/ wk · / mo · / yr, default **mo**), a live "saved as $X / wk" preview, **Save cost** (Enter saves). `saveInsuranceCost` updates `vehicles.weekly_insurance_cost` and patches the local list in place.
- **Kernel** [`vehicleInsuranceCost.ts`](../../src/lib/vehicleInsuranceCost.ts) (+ tests): `weeklyInsuranceCostFromInput` (mo × 12 ÷ 52, yr ÷ 52, cents), `insuranceCostViews`, `formatInsuranceCostLine`, `effectiveWeeklyInsuranceCost` (D5: $0 while off a plan, cost kept), `insurancePlanTotals` (priced vs unpriced).
- **Fleet total** (`weeklyTotal` → `fleetFactsLine` "$X/wk ins+reg") now counts insurance only for vehicles currently on a plan (D5) + registration for all.
- **Insurance plans modal**: each vehicle row shows `$X/wk` (amber **no cost set** when 0), the name is a link that closes the modal and opens the vehicle; a **Plan total** line (with "N of M priced" when some are missing) sums per wk / mo / yr.
- **Edit modal**: the Insurance input is removed ("Weekly cost ($)" keeps Registration); `upsertVehicle` no longer writes `weekly_insurance_cost` (new vehicles insert 0). One place to set it.
- Verified live (desktop + 375px): 2019 F250 on Abraham Insurance — card, /mo preview ("$257/mo → saved as $59.31 / wk"), round-trip save; plans modal totals (Abraham $59.35/wk; Geico 1 of 4 priced, $8.22/wk). Help: `manage-company-vehicles.md` (new "The Insurance card on a vehicle" section; Edit sentence updated; plan totals).

Client-only; no migration (D1 — cost stays per vehicle; D4 — no cost history yet).
