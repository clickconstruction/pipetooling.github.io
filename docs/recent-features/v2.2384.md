# v2.2384 — The price book drawer: one door, collapsed books, stage/combined (2026-08-27)

Owner request, iterated twice on a playable prototype before approval. The
Pricing tab's price book existed in two places (the context strip above the
Workbench + a collapsed "▶ Price book" editor at the page bottom) and the
bottom editor carried a "This version's prices" mode the owner confirmed
was added by mistake and never used.

All in `src/components/bids/BidsPricingTab.tsx`:

- **The strip chip is the one door**: "PRICE BOOK — WENDI · 111 entries ▸"
  is now a button opening a fixed right **drawer** beside the table. The
  basement section is deleted, along with its pricings/templates toggle
  (`templatesMode` prop dropped — the drawer edits the shared template
  catalog only; a local `const templatesMode = true` keeps the panel
  machinery on the templates path). Dead code removed:
  `addPricingMenuItemStyle`, `openAddBlankPricing`, `openClonePricing`,
  `panelVersions`, `canEditPanelEntries`, `priceBookSectionOpen`.
- **Collapsed book row**: just the active book (★) with a ›; expanded
  shows every template + ‹ + Add book + ✎ rename. Picking a book runs the
  existing `onSelectPriceBookTemplate` (clone-or-reuse switch of the bid's
  active pricing) — which already persists the pick as the user's
  per-service-type default — and the drawer surfaces that:
  "Your default for new bids: WENDI ✓". New prop
  `defaultPriceBookTemplateId` (already exposed by `useBidPricingEngine`)
  threads in for the label.
- **Combined ⇄ Stage price**: table columns flip between one Price
  (total_price) and Rough In / Top Out / Trim Set (zeros as dim —, hover
  the fixture for the combined total). The entry form follows the mode:
  in Combined it shows a single **Price** input bound to Rough In (the
  form's auto-total keeps total = ri+to+ts), so **a price added or edited
  in Combined lands in Rough In** — the owner's rule, enforced where it
  can't be dodged.
- Esc/✕ close; search + Add entry unchanged from the old panel (same
  `savePricingEntry` path, fixture-type datalist and all).

Verified live on the dev server (ZZ Test bid): chip opens the drawer with
all 111 real WENDI entries; collapse/expand; Stage columns with — zeros
and combined-total hover; search filter; Combined-mode form showing the
single Price field + note; full book switch to Default (bid re-pointed,
strip → "Default · 99 entries", default persisted) and back to WENDI.

Help guide `price-a-bid-with-the-workbench.md` gained "The price book
drawer" section.
