## What changed

- **Kernel** `src/lib/bids/countsImportReview.ts`: `reviewCountsImport({ incoming, existing, alternateTags, importAlternateGroups, scope })` sorts a paste against the rows on the bid into `changed` (same name and group, a different count or page), `added`, `missing`, `same`, plus `pairs` — a missing row and an added row with the same count where the name or the group held, offered as *renamed* or *moved*. Pairing is exact name + group (trimmed, case-insensitive), the identity CountTooling exports; a name with no exact pair falls back to a name-only pair when unique on both sides within the same alternate scope (carries a group change and the rows imported before v2.4188 lifted groups); a key carried twice on either side pairs with nothing and is flagged (`ambiguousAdded` / `ambiguousMissing`). No fuzzy matching: the labor and price books match by exact name. `defaultCountsImportChoices` (update all, add all, remove all only when `scope === 'all'`, no pair accepted), `buildCountsImportWritePlan` (an accepted pair becomes one update and leaves the delete and insert lists), `describeCountsImportWritePlan` / `describeCountsImportApplied` for the footer and the toast.
- **Parser** `parseCountsImportText.ts` returns `scope`: `'all'` when the `--- Counts, <project> · … ---` heading says *every sheet*, `'partial'` for any other Counts heading, `'unknown'` without one (a hand-typed paste).
- **Undo** `countsImportUndo.ts`: the plan carries `restoreRows` (each updated row's old values) and `reinsertRows` (each removed row whole, re-inserted under its old id — bare, since its parts and prices cascaded); `describeImportUndo` words the toast.
- **Modal** `CountsImportReviewModal.tsx`: the four piles, a bucket switch first (Update all / Leave as is, Add all / Skip all, Remove all / Keep all) and a tick per row second, only the moved field drawn as old → new (a count up in green, down in red), what hangs off each row beside it (*6 parts · priced · stays*, or *lost on remove* in red), the proposals at the head of Missing with a **Same row, renamed / moved** button, Same folded with *Show them*, the scope sentence under Missing saying why it chose, the footer summary and **Apply N changes**.
- **Tab** `BidsCountsTab.tsx`: both doors (clipboard and paste box) go through `importParsedCounts` — an empty sheet appends as before (one click, same toast); a sheet with rows is reviewed; a paste that matches row for row says *All N rows match this bid exactly. Nothing to import.* and writes nothing. `loadCountRowAttachedWork` counts `bids_takeoff_rough_part_lines` and reads `bid_pricing_assignments` / `bid_count_row_custom_prices` per row (non-fatal). `applyCountsReview` runs updates first (they keep every row keyed on the id), then inserts, then deletes, then the source link and the alternate tags, and the toast's Undo covers all of it.
