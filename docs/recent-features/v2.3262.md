# v2.3262 — The customer portal globe on the Job tab (2026-09-10)

Client only; no migration, no edge function. Owner: "I would like to add a link to the customer portal of the customer on this page, right now it is on the edit page I want it on the job page too." Mockup (three placements, A chosen): https://claude.ai/code/artifact/8162038d-c4f6-4f22-8fbe-0df1a609630a.

## What shipped

- **`DetailJobModalCustomerPanel`** (the Job tab's customer block, `DetailJobModal.tsx`) takes `customerId` and renders `CustomerPortalGlobeButton` (size 15) right after the customer's name — the same component, modal, colours and red-when-off state as the Edit tab's Customer fact row and the Pipeline rows, in the same relative place: next to the name it belongs to. The globe gates itself to office roles and renders nothing for the rest; a click stops propagation so the pane's row handlers don't fire. Drive and Pictures stay on the right (job files, not the customer).
- **The id had to be fetched.** The pane's limited `jobs_ledger` select carried `customer_name` but not `customer_id`; the select and `LimitedJobDetailSnapshot` gain `customer_id` (optional — the placeholder shape built from an assigned-job row reads it loosely).
- Rejected placements from the mockup: a third "🌐 customer portal" chip beside phone/email (the other chips act directly; the globe would look unlike everywhere else) and the header icon row (job actions, already five icons on a phone).
- Help: *share a customer their portal* names both tabs of the job window.
- Test: `DetailJobModalCustomerPanel.render.test.tsx` (globe with an id + name; none without either).
