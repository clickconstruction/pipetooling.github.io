# v2.4700 — Lien desk: offer a discount if they pay before the lien (2026-10-07)

PR 1 of 2 for the pay offer: the partner's idea, by way of the owner (2026-10-06): *when we go send out that notice, we can send out a notice that if paid before we lien, 10% off the bill via the QR codes.* Mock-up: artifact R4bc77o273n1kJE1fAdsCY — the switch on the approval, the pay page as the owner reads it, the scanned code on three days, the office after, and the critique (a printed day instead of *before we lien*; per bill, paid in full; the ledger written down only when paid, so the affidavit always swears the full balance; the GC's envelope stays the form and invoices; leader only). The approve buttons write the offer first (`setLienDeskItemOffer`, `lienPayOfferIo.ts`) and refuse while the day has a problem.
