# v2.4940 — GC mode: a new set of plans emails the companies asked to quote (New project's step 7) (2026-10-08)

New project's step 7 (`to-dos/gc-mode/NEW_PROJECT_REAL_BUILD.md` on branch `spike/gc-mode`, step 7 as amended 2026-10-07): when a new set of plans goes on a GC project, each company asked to quote hears once, through the Portal lane's one sender to a trade company, `gc-trade-email` (P3-a, v2.4936), with kind `plans`. No function and no migration of its own.

- `src/lib/gc/setEmail.ts` (pure): `setEmailRecipients` (while we bid, every ask not declined, one entry per company with its trades in the project's order, the ones the set touches first; once the job is ours only the awarded asks, so nobody until B6), `setEmailKey` (`<projectId>:plans:<rev>`, so a retry never sends twice), `setEmailWords` (the portal's own plans message in the company's language, without the greeting: the set is out, the sheets it names, the company's lines it touches, the lines it adds by trade, whether it changes their trade, and while we bid the day the quote is due, `questionsCloseOn`), `setSendRows` and `setEmailSummary`.
- `gcIo.ts`: `loadSetEmailParties` reads the asks and the companies; `sendSetEmails` sends one `sendGcTradeEmail` per company in parallel with `tradeMailLang`, treats `noEmail` as skipped and says any other refusal with `gcTradeEmailRefusal`, then upserts `gc_plan_set_sends` (`set_id`, `company_id`, `touched`, `email_send_log_id` as it comes back) for each company it reached.
- The new-plans window gains step 3, **Who hears it**: the companies, each marked *it changes their trade* or *for their records*, and **Email them when the set goes on** (unticked until the owner names an inbox for real sends, call 3), shown only to `canSendGcTradeEmail` — a dev until the portal's door; everyone else sees *Emails to the companies go out once the portal opens.* Issue puts the set on, then sends; if a send fails the window stays open with the summary and **Try again**, which sends only to those.
- Guide `issue-a-new-set-of-plans` gains *Who hears it*. No real send goes out until the owner names an inbox for the test company (call 3).
