# v2.6857 — Permits: every count says how far back it can see (punch list #307) (2026-11-10)

The owner, on #307's mock-up panel headed *Permits Ridgeway Builders pulled*: *it is permits Ridgeway Builders pulled we can see, just saying they pulled would be an overstatement.* The live tab had the same fault. The pull holds San Antonio's permits from the day its first run read back to (2026-08-26), and four lines said *this year*, *in the last year* or *the last 365 days* over those ten weeks, and said a name *pulled* them. Before and after: `to-dos/bid-permits/before-after-live-words.html`.

## What changed

- **`src/lib/research/permitReach.ts`** (new, pure, `permitReach.test.ts`): `recordsReach(recordsStartYmd, todayYmd, days)` is the first day a count covers and whether the records reach the whole window; `reachWords` is the tail a count ends on (*since Aug 26*, with the year when it is another year, *in the last year* once the records reach one, null when the start is not known); `permitsColumnWords`, `theirPermitsTitle` and `recordsStartLine` are the Builders page's column, the sheet's title and the line over the list.
- **`permitResearchIo.loadRecordsStart(city)`**: the earliest `permit_pulls.since` among the runs that ran clean. **`usePermitRecordsStart`** reads it once per screen; a failed read leaves the lines saying *we can see* with no span, which is still true.
- **`permitPublic.builderWords(lines, reach)`**: *This name is on 3 other permits we can see since Aug 26.* It took a number of days and said *This name pulled 3 other permits in the last 365 days.*
- **`permitBuilders.builderLine(row, reach)`** on the skim card: *4 permits since Aug 26. 2 have no plumber yet.* (*this year* before). **`builderCountWords`** (new) is the same count on the Builders phone row and the builder's sheet.
- **`PermitBuilders`**: the line over the list (*San Antonio's records here start Aug 26. Every count is what we can see since then.*), shown only while the records are shorter than a year; the column reads *Permits since Aug 26* in place of *Permits, 12 mo*; the sheet's count and its *Their permits since Aug 26* title.
- **`WhoPulledItSheet`**, **`PermitSkimDeck`**: read the reach and hand it to the two sentences.
- Guide `research-permits-for-work-to-bid` (Know the builders, Their other permits) and `docs/PROJECT_DOCUMENTATION.md`.

## Not changed

No migration, no function. The counts themselves: `research_builders` and `research_permits_v2` still count a year back, which today is every row on hand. The card's title *Who pulled it* stays, the owner's own phrase for the question. Saying *the name the city lists* on every screen waits for the bid’s permit lines (#307).
