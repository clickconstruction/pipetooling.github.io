# v2.2356 — Sort the bid list on workflow tabs (2026-08-26)

The no-bid-selected picker on the 8 bid workflow tabs (Counts, Takeoffs,
Labor, Pricing, Cover Letter, RFI, Change Order, Lien Release) rendered in
fetch order — `bid_due_date` desc **nulls first** (`Bids.tsx` `loadBids`),
so undated bids floated to the top in arbitrary order and the list read as
random. Estimator request: navigable ordering, default bid number desc.

- **Kernel** `src/lib/bidPickerSort.ts` (+tests): `BidPickerSortView` =
  `number | due | sent | value`; `sortBidsForPicker` — number: numeric
  desc from the first digit run of `bid_number` (302 > 39), unnumbered
  last; due: soonest first, undated last; sent: most recent first
  (timestamps normalized to date), unsent last; value: largest first,
  null last. All non-number views tie-break by number desc; stable `id`.
- **`BidPickerSortToggle.tsx`** (new): segmented control in the search
  row's unused width + `useBidPickerSortView` — module store via
  `useSyncExternalStore`, persisted to localStorage `bidPickerSortView`,
  shared by all tabs (switching on one reorders all).
- **`BidPickerStandardList`** sorts internally from the store; hosts keep
  passing filtered-unsorted arrays. Bid Board / Followup / Unsent-Working
  orderings untouched.
- Search rows: the 5 toggle tabs gained the control between search and
  MyBidsToggle (+ `flexWrap`); RFI / Change Order / Lien Release inputs
  wrapped in the same flex row.
- Help guide: `find-a-bid-on-the-workflow-tabs.md`.
