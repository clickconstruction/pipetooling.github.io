# v2.3061 — `toLocaleDateString('en-CA')` as a date source: swept, and guarded (2026-09-07)

Mechanical sweep (merges alone). Client only; no migration or edge-function change.

## Why

119 call sites in 41 files took `YYYY-MM-DD` from `d.toLocaleDateString('en-CA')`. Browsers render `en-CA` that way; Node 20 / ICU 72 renders it `MM/DD/YYYY`, and `dateUtils.ts`, `checklistDueDates.ts` and `payStubPayments.ts` already carried the warning after v2.2980 hit it in a test. Any of those strings that reaches a `date` column or a string comparison was one ICU update away from breaking, and the class kept regrowing because nothing checked for it.

## What the sweep did (script-driven, one rule per shape)

- **`new Date().toLocaleDateString('en-CA')`** — "today" — became **`todayYmdInAppTz()`**: the one company-calendar today the time-and-zones doctrine already requires (`npm run check:timezone` rule 2 forbids the UTC spelling of the same thing).
- **Every other receiver** (`start`, `d`, `new Date(y, m, d)`, `new Date(ms + 864e5)` …) became **`localCalendarDayKey(<receiver>)`**, a new `dateUtils` helper that returns the device's own calendar day from the Date's parts. This is exactly what browsers returned before, so derived dates, week ranges, day lists and form defaults do not move — deliberately not the company-calendar key, which would shift a day for a device east of Central at local midnight.
- Left alone on purpose: the Workflow page's `toLocaleDateString('en-CA', { timeZone: APP_CALENDAR_TZ })`, which already pins the zone (the hazard is the unpinned, no-options form), and the three comments that describe the hazard.
- Imports follow usage; two multi-line import blocks needed the inserted line moved below their closer (found by `tsc`, fixed by hand).

## The guard

`scripts/check-app-calendar-tz.mjs` rule 5: any `.toLocaleDateString('en-CA')` with no options outside `dateUtils.ts` and test files fails CI, naming the file and line and the two helpers. Probed with a throwaway file before removing it. `docs/TIME_AND_ZONES.md` lists the rule.

## Tests

`dateUtils.localDay.test.ts` (3): zero-padding and local parts, agreement with `en-CA`'s labelled parts on any ICU, the invalid-Date case. The 47 suites under the touched directories pass (253 tests, including the People, Checklist, Materials and Quickfill render smokes); `tsc -b` and eslint clean.
