# v2.3211 — Bid flow hairline: one gap width, so the ten ticks read as evenly spaced (2026-09-09)

Client only; no migration.

## What was wrong

v2.3206 made the Bid Board hairline ten equal ticks but kept a wider gap wherever the poster's phase changes. With ten steps in eight phases (Intake, Ask, Intake, Count, Build, Build, Review, Letter, Letter, Send) that is seven wide gaps and two narrow ones, so almost every gap was the "special" one and the bar looked unevenly spaced — the opposite of what the wider gap was meant to say.

## What shipped

- `BidFlowStrip` hairline: every tick is `flex: 1` and the container's single `gap` is the only spacing. No per-tick margin. The phases are still shown where there is room to label them — the full strip on an opened row and the workflow tabs.
- `phaseBreakAfter` stays for the (unused) compact-dots variant.
- Help guide `see-where-a-bid-is-in-the-flow.md`: "evenly spaced" replaces "with a wider gap where a phase changes".
