# v2.2761 — GC Review: Mark sent with channel + note, and a send history (2026-09-04)

Owner ask, from the GC Review modal: "I love how I can certify and it updates, but sometimes I send them via a direct message (text) for example. How could add a manual mark sent and a note where we preserve who sent it and the note and the date for posterity?" Mockup approved (mark-sent form with channel chips + note, the sent chip carrying the channel, a send-history popover behind the last-sent pill).

**DB** (migration `20260904172530_gc_statement_round_mark_channel_note.sql`): `gc_statement_round_marks` gains `channel text` (CHECK `email | text | call | in_person | other`, NULL on pre-existing rows = they were emails) and `note text`. Additive, idempotent, no new table. The one-row-per-(week, GC) rule stays: past weeks' rows are the history; a second mark in the same week replaces that week's row; undo still deletes. Types hand-aligned to the generator shape (regenerate after push to confirm).

**Kernel** ([`gcStatementRounds.ts`](../../src/lib/jobs/gcStatementRounds.ts), +4 tests): `StatementSendChannel` + `STATEMENT_SEND_CHANNELS` (value/label), `isStatementSendChannel`, `sendChannelLabel` (null/unknown → Email), `describeRoundMark` (tooltip: who · when · how, plus the note). `RoundMarkRow` carries `channel` and `note`; `mergeMarksIntoLastSent` is unchanged — a text-message mark counts like an email (tested). IO ([`gcStatementRoundIo.ts`](../../src/lib/gcStatementRoundIo.ts)): marks select the two new columns; `upsertGcStatementRoundMark` takes `channel` + `note` (trimmed, empty → NULL); new `listGcStatementSentHistory(gcId)` — sent marks newest first, fail-soft.

**UI**:
- [`GcStatementMarkSentForm.tsx`](../../src/components/jobs/GcStatementMarkSentForm.tsx) (new, render-tested): channel chips (radio group), a note input (300 chars), a "Stamps Malachi · Sep 4 · text" line, Cancel / **Save mark**. The parent owns the write.
- [`GcStatementSendHistoryModal.tsx`](../../src/components/jobs/GcStatementSendHistoryModal.tsx) (new): the posterity view — When / How / Who / Note table per GC; footer notes the latest app-sent email when there is one.
- [`JobsGcReviewModal.tsx`](../../src/components/jobs/JobsGcReviewModal.tsx): **Sent it ✓** in the round overlay opens the form inline (Email preselected) instead of writing immediately; `markRound` takes `{ channel, note }` and returns success so forms close only on a saved write. **Share → Mark sent…** (certifier roles, GC grouping) opens the form in its own dialog with Text preselected — any GC, any amount, GCs under the round threshold included. The rounds-panel chip reads `sent ✓ Thu by Malachi · text ✎` (pencil = has a note; hover shows the full description). The header's last-sent pill is now a button: it appends the channel when this week's mark is what it shows, and opens the send history.

**Help guide** [`run-your-gc-statement-round`](../../src/content/help/run-your-gc-statement-round.md): the form step, a "Sent it another way?" section, and the send-history section.
