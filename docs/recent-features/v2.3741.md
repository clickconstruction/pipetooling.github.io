# v2.3741 — Auto-reload PR 2: the idle moment, and what "unsaved" means (2026-09-22)

PR 2 of the auto-reload train ([v2.3740](v2.3740.md) is PR 1; PR 3 is reload-safe drafts). Client only, no migration.

## The change

- **[`unsavedWork.ts`](../../src/lib/unsavedWork.ts)** (+3 tests) — the two signals the gate reads. **Holds**: `holdUnsavedWork(label)` → release; `unsavedHoldCount()`; subscribers. **In-flight writes**: `wrapFetchCountingWrites(fetch)` counts every non-GET / HEAD / OPTIONS request between send and response — the Supabase client wraps its fetch with it (outside the row-cap tripwire), so a reload never lands mid-POST, where the person could not tell whether the save went through. RPC reads (POST) count too for the length of the call; harmless.
- **[`useHoldsUnsavedWork.ts`](../../src/hooks/useHoldsUnsavedWork.ts)** — `useHoldsUnsavedWork(dirty || saving, 'Legal firm settings')`. Tagged: `LegalFirmSettingsBlock`, `SubPortalPaySettingsBlock`, `SubSheetPortalFieldsBox`, `FormStudioEditor` — the inline editors with a `dirty` flag and no dialog around them (modals are already covered by the open-dialog guard; the Edit Bid and job form autosaves are covered by the in-flight count). The signing forms get theirs in PR 3, which rewrites them anyway.
- **[`autoReload.ts`](../../src/lib/autoReload.ts)** — the snapshot carries `unsavedHolds`, `inFlightWrites`, `hiddenForMs`, `idleForMs`; the **idle** moment reloads when the tab has been hidden ≥ 5 min (`IDLE_HIDDEN_MIN_MS`) or visible and untouched ≥ 30 min (`IDLE_VISIBLE_MIN_MS`). +2 tests.
- **[`UpdatePrompt.tsx`](../../src/components/UpdatePrompt.tsx)** (+3 render tests) — while an update waits: a `visibilitychange` to hidden arms a 5 min + 1 s timer that reloads while hidden (hidden-tab timers are throttled, so it is generous, and coming back checks again at once); a minute interval checks the visible-idle rule against the last pointerdown / keydown / touchstart / wheel.
- Help guide and `TROUBLESHOOTING.md` amended.
