# v2.5673 — Accounts payable: an aging cell opens onto the invoices behind it (2026-10-20)

Client only; no migration, no edge function. Punch list **#132** PR 1 of 3
(`to-dos/ap-aging-cell-invoices/`, mock-up beside it). The owner's ask, 2026-10-20, with a
screenshot of the aging map: *"I would like to be able to click on a cell and have it show me
the invoices that make up that cell in a modal."* Build approved the same day on the
recommended defaults — every money cell clicks, read-only plus the View links and the house
door in this PR, job names fetched on open.

## What shipped

- **Kernel** [`supplyHouseAging.ts`](../../src/lib/supplyHouseAging.ts): `invoicesForAgingCell(unpaidInvoices, houseId | null, cell, todayYmd)` —
  the same routing `buildSupplyHouseAgingMatrix` uses, so the modal's rows always sum to the
  cell; `cell` is a bucket key, `'owed'` or `'credits'` (`AgingCellKey`), `houseId` null reads
  the footer row. Plus `agingCellTitle(cell)` for the modal's words. Tests pin the invariant
  for every cell of a seeded book: bucket cells, Owed, Credits, the footer row, sort order
  (oldest due first, no-due-date last), and that a dated credit never leaves its column.
- **The fetch widened, still one select** — [`SupplyHousesTab`](../../src/components/SupplyHousesTab.tsx)'s
  summary read adds `id, invoice_number, purchase_order_number, invoice_date, link,
  credits_invoice_id` to the columns it already pulled; `agingUnpaidInvoices` carries the full
  `AgingInvoiceRow` through to the modal. No new query for the matrix.
- **Every money cell is a door** (`agingCellDoorProps`): the six bucket cells, Credits open,
  the Owed column, and the whole footer row — `role="button"`, focusable, Enter or Space
  opens, the click stops the row's own open-the-house click, a dash stays a dash. The phone
  bars (under 640px) are unchanged.
- **The modal** reuses the expanded house's vocabulary: the invoice row shape (number with the
  v2.5035 credit-pairing line, PO #, dates, the "Nd past due" chip, the Job acct chip, the
  View link), the sticky header/panel styles, body scroll lock. The footer's cell total always
  equals the cell (same kernel, same rows); with *Mark job-account invoices* on it adds the
  job-account subtotal; **Open <house> ›** is the existing `openHouseFromAging`. A footer-row
  modal groups by house in the matrix's own order.
- **Jobs on open** — one `supply_house_invoice_job_allocations` read for just the listed
  invoice ids, then `get_jobs_ledger_by_ids` for the names; fetched once per open, cleared on
  close.
- **Guide**: *mark supply-house bills paid* gains "See the bills inside an aging cell".
