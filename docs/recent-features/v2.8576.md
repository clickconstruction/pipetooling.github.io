## 1. The reason's words

**Seen.** The one real row's reason read *Address not found — OpenStreetMap (Nominatim) HTTP 403; no match from Google; no match from US Census*. A plain reader met a service's name and *HTTP 403*.

**The cause.** `mapGeocodeErrorMessage` (`src/lib/map/geocodeErrorMessage.ts`) put its own words, a dash, and the look-up's `detail` as it came. The detail is the services' own account of the look-up: which one answered what, a status code, a reply that would not parse. The *HTTP 403* words are old. That service is no longer asked (v2.8512), and a miss kept before then holds them until its address is asked again. A live look-up can still carry a status code in its detail when Google or the Census fails.

**The mend**, at the drawing, so every kept row and every screen mend at once:

- The detail is never drawn.
- Each code reads as whole sentences, written to `plainWords.ts`'s rules. A miss reads *No map service could find this address.* A service that failed reads *A map service had a problem and did not place this address. Try again in a minute.* The Google codes say what Google did and, for a setup fault, that a developer needs to look.
- A code the file does not know reads *The map services could not place this address.* Before, it drew the code itself.
- One thing in a detail is worth a person's read, and is said in plain words without the point: a service that placed the address outside the lower 48 states, which the app refuses. The line reads *A map service placed this address outside the lower 48 states. Check the city, the state and the ZIP.*

The raw detail is still in the function's answer and in the kept miss's row, for a developer.

**Where the line draws.** All read, none changed but through the kernel: the Bid Board's sheet (`bidBoardMissingAddresses.ts`), the Map page's list and its **Try again** (`useMapPageData.ts`, `MapAddressSheet.tsx`, `unplacedMemory.ts`), `MapGeocodeReviewModal.tsx`, Quickfill's schedule (`QuickfillScheduleSection.tsx`), `HomeMapWindow.tsx`, and the two Settings kernels for the office address and the map's default view. Each draws the line alone or after its own sentence, so whole sentences fit all of them.
