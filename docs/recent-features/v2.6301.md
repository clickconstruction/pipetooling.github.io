# v2.6301 — Pipeline rows: a Job folder icon opens the job’s Documents tab (2026-11-01)

The owner's ask after punch list #236 landed every job's files in one Drive folder: a quick door from the Pipeline to a job's files, without hunting for the job window's Documents tab. Client only, no migration and no function. A spike (branch `claude/spike-pipeline-folder-icon`, never merged) drew it first; the owner approved the shape and this PR is the spike made real.

- **One icon, two presses.** `StagesJobFolderButton` (`StagesRowActionButtons.tsx`, one component per row icon as the file keeps) sits right after Share in both desktop clusters (`JobsStagesTable.tsx` for Waiting/Working, `StagesUnifiedJobRow.tsx` for the billing stages). A click opens the job window on its Documents tab, where the job's folders are listed with *Open in Drive* beside each; a ⌘-click (Ctrl on Windows) opens the job's own folder in Drive through `openInExternalBrowser`. The tab, not Drive, is the plain press because a job's folder may not exist yet (the sweep makes it within ten minutes) and the tab says so; Drive-direct would be a dead end there.
- **Amber or grey, never dead.** `#d97706` when `jobs_ledger.google_drive_link` is set, `var(--text-muted)` when it is not; the grey icon still opens the tab, and a ⌘-click without a folder opens the tab too. The title says which.
- **The phone cards.** Both ⋯ sheets (`JobsStagesCardList.tsx`) gain a *Job folder* line after Share job, with a *not made yet* badge while the folder is missing.
- **The door.** `openEdit`'s options on the Pipeline (`Jobs.tsx`, `JobsStagesTab.tsx`, both tables) take `initialTab: 'documents'`, and the two `initialTab` unions the Job window already honoured (`OpenEditJobOptions`, `JobWindowEditOpenOptions`) widen to include `'documents'`. No new modal, no new state.
- Tests: `StagesRowActionButtons.render.test.tsx` (click → tab, ⌘-click → Drive, grey without a folder), `JobsStagesTable.render.test.tsx` (every row carries it, the colours, the press lands on Documents), `JobsStagesCardList.render.test.tsx` (the sheet's line, its badge, the press). Guides: *ready to bill pipeline* names the sheet's line; *job window tabs* says the icon opens the Documents tab.
