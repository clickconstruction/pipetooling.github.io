# v2.2467 — Typed dollar amounts that ARE one segment now bill as that segment (2026-08-28)

Taunya's third report on job 978 (after v2.2446/2464): her rebuilt $1,980 invoice's Stripe
preview listed BOTH line items, prorated — "CHANGE ORDER: Deep cleaning of 2 systems $1,080 +
HVAC to spec $900". Diagnosis (confirmed via the Bill tab's hatched "covered" chip): the draft
was a **dollar carve** — typed into the New Invoice box — and since v2.1133 only segment-created
invoices link fixtures; unlinked invoices deliberately fall back to whole-job proration
(`fixturesForInvoiceBill` client-side, `scopeFixturesToInvoice` in the edge functions).

**The fix.** New kernel `exactSingleSegmentMatchForAmount` in
`src/lib/jobs/jobSegmentsCoverage.ts` (unit-tested): given the fixtures, the dollar-coverage
model, and the typed cents, it returns the single still-billable segment whose **remaining net**
(gross minus waterfall coverage) equals the amount exactly — or null on zero or multiple matches
(never guess; a wrong link would misstate what the customer is paying for). Riders aren't
fixtures, so rider-sized amounts never match. `createInvoice()` in `JobFormModal.tsx` runs the
check after its `flushBillingAutosave()` (same DB-consistency contract as the segment path) and,
on a match, links the new invoice via the same `sequence_order`-position UPDATE the segment path
uses, mirrors the link into local fixtures state, and toasts `Billed as "<segment>"`. A failed
link UPDATE is soft — the invoice stands as a plain dollar carve (pre-fix behavior) with an
error toast saying the bill will prorate.

Unchanged on purpose:
- The **full-remainder → Bill Customer redirect** still wins first (typing the whole remainder
  on an RTB job opens Bill Customer on the primary bundle; on single-line jobs proration is a
  single line anyway, and the one-click flow is better).
- The **Pipeline partial-invoice modal** (JobsStagesTab) still creates unlinked carves — board
  rows don't carry the segment-coverage model; candidate follow-up if reports point there.
- **Remainder-bundle proration** (the auto draft bills all lines scaled) — the deeper fix is
  composing remainder bills from uncovered segments; scoped separately (see the memory note).
