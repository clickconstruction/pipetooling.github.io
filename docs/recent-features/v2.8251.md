# v2.8251 — View as: the server refuses the last seen mark too (2026-11-21)

v2.8176 stopped the client sending the app activity heartbeat while View as is on, and left a question: could the server refuse it by itself? Taunya's answer on 2026-11-21 was to build it. A migration only: no client change and no function deploy.

## What changed

- **`session_opened_by_imitation()`** (new): whether the calling session was opened by Imitate or View as. The session those open carries the person's own JWT, but the token's `amr` claim says it signed in by a magic link and when, and `user_imitations` (v2.6290) holds every imitation. A magic-link sign-in from 1 minute before an imitation of the same person to 2 minutes after it is one.
- **`bump_user_app_activity()`** returns early for such a session. It writes no last seen time and no app time, on the day's row or the page's.

Migration `20261122021600_imitated_session_holds_app_activity.sql`; its doc is `docs/migrations/20261122021600_imitated_session_holds_app_activity.md`.

## Why the window is minutes

`gmail-mine` asks the same question and reads back 24 hours, the life of a link, because a wrong pass there shows a person's mail. A wrong hold here would cost a real person their own activity for the life of a session, and the sign-in page offers an emailed link. The page verifies View as's link at once, so minutes cover it. Any claim the function cannot read answers false.

## Only the heartbeat

The ask was for both saves v2.8176 named. The salary sync is left as it is, and that is a finding, not an oversight: the server cannot tell the clock button's own sync from the sync after a pressed save, which can be for another day; a press in View as saves as that person by design; and the rows the sync writes are the ones the server's own schedule writes. The client holds the two syncs nobody presses for (v2.8176, v2.8246).

## Tests

A new SQL bed, `imitated-session` (`scripts/pgtest-imitated-session.sh`, `supabase/tests/imitated_session/`): a password session, a link verified seconds and ninety seconds after an imitation, a person's own link ten minutes later, an imitation of someone else, claims that cannot be read, and the heartbeat's rows after each.
