# v2.4610 — Downloads come from the app itself, so Safari asks once (2026-10-05)

Client only; no migration, no edge function. The owner, with a screenshot of Safari's sheet: *Do you want to allow downloads from "clicktooling.com" and "yewfzhbofbbyvkvtaatw.supabase.co"?* "When I go to download a file sometimes my browser will say the following."

## Why it asked

A save handed the browser a signed link straight into the storage host, opened in a new tab. Safari treats that as a download from two sites and asks about both; a slow click could also fall foul of the popup blocker. The CSV exports never asked, because they build the file in the page and save it from the app's own address.

## What changed

- **One helper, [`src/lib/storageSave.ts`](../../src/lib/storageSave.ts)**: `saveFromStorage(bucket, path, name)` reads the stored file into the page and saves it through a hidden link from the app's own address (`saveBlobAs`); `openOrSaveFromStorage` opens a file the browser can show (`browserCanShow`: PDF, pictures, text, HTML) in its own tab through a short signed link, inside the click, and saves one it cannot (a workbook, a forwarded `.eml`).
- **Switched to it**: the vendor file's *Save PDF* (v2.4579) and the stored package's *open it* / *Open package* (the package just built is saved from its own bytes, read once); a reviewer's file (a redlined PDF opens, a forwarded email is saved); a sent copy's kept file on the Documents page (a pay application workbook is saved, a PDF opens); an HR file's attachment; the row's cut sheet (already a blob, now through the same helper). A field photo on Quickfill's handover opens full size instead of forcing a download.
- **Not changed**: links that open a PDF or a picture to look at (test reports, contracts, signatures, form templates) never asked, and still open in a tab.

## Trade-off

The file arrives in the page before the save starts, so a large vendor PDF shows nothing for a second or two and holds memory briefly. For what this app serves that is fine; a very large file would want a streamed download, which this does not do.

## Tests and checks

`storageSave.test.ts` (4, new). `BidsSubmittalsTab.render.test.tsx`: the two package cases now assert the saved file and no signed link, and a new case saves a vendor file under its own name with no new tab. Lint, the theme check and the typecheck of the changed files pass locally. Not clicked in Safari: the sheet is Safari's own, and whether it stays quiet is proven only by the first save after this ships.
