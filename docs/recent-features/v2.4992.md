## The guard rails

- The hook owns no mode. It opens and shuts the window through the modes hook's `leaveModesFor('openAddBlock')` and `leaveModesFor('closeAddBlock')`, and never touches a flag.
- The window and the modes end each other: a placement shuts the window, and the window ends the modes.
  - So the modes hook comes first, and reaches the window's closer through a bridge.
  - The bridge is a ref the page fills right after the window's hook.
  - The modes hook only calls it from event handlers, so it is always filled by then.
- The hook returns read-only state, the three intents (`openAddBlock`, `closeAdd`, `closeAddBlockWindow`) and the window's props. The window's own field setters travel inside those props.

## Tests

  - it opens through the mode rule, with the day's blocks in time order and their titles

- Saving:
  - the fields and the timeline's drafts go out with the save
  - a save that lands says so, shuts the window through the rule and reloads the board quietly
  - a refused save keeps the window open with the reason
  - saving shows while the write is out
- Shutting:
  - Cancel goes through the rule, and clears the timeline and drafts itself
  - the modes' closer shuts the window and takes the error with it
