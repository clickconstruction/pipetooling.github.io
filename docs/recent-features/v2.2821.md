# v2.2821 — Job Summary: Months view (2026-09-05)

PR 3 of the Job Summary analysis plan (artifact 9c02d29a), stacked on v2.2820.

## Client only — no migration

- [`jobSummaryMonths.ts`](../../src/lib/jobs/jobSummaryMonths.ts) (new kernel): `bucketJobSummaryByMonth({ rows, ledger, bookBy, startYmd, endYmd })` → `JobSummaryMonthsSeries` (`months[]` with jobs, revenue, labor, subs, parts, `overheadUsd` = that month's whole pool from `ledger.days` (null without a ledger), `unallocatedUsd` (pool on days with no field hours), field hours, true profit, true margin; `totals`; `best`; `unplacedJobs` / `unplacedRevenueUsd`). **work** booking spreads each visible row over months by its hours per month in the ledger (`days[].byJob`), rows with no hours in the window set aside; **bill** booking places each row whole by `last_bill_date` month, unbilled / out-of-window rows set aside. `monthsBetween`, `monthLabel`. Four tests.
- [`jobSummaryLedgerView.ts`](../../src/lib/jobs/jobSummaryLedgerView.ts): view mode `'months'` + option; pref `monthsBookBy: 'work' | 'bill'` (default work).
- [`useJobSummaryView.ts`](../../src/hooks/useJobSummaryView.ts): the compare bundle now carries the compare window's `rows` and `ledger`, so views can rebuild their own series for the delta (Months does).
- [`JobSummaryMonthsView.tsx`](../../src/components/jobs/JobSummaryMonthsView.tsx) (new): tiles (True profit with margin + Compare deltas + target tone, Revenue with per-month average, Best month, Overhead with the unallocated part, Under target months or Field hours), the stacked-bar SVG (labor / subs / parts / overhead / profit; loss red above revenue; dashed target tick per bar at revenue × (1 − target); hover band + `<title>` split; year on the first tick and each January), legend, booking footnote with the set-aside count. Money-gated like the Jobs tiles: without money, plain revenue bars.
- [`JobSummaryLedgerToolbar.tsx`](../../src/components/jobs/JobSummaryLedgerToolbar.tsx): Months in the View chips; **Book by** control on Months; Show / Compare to / Target now show on both row-driven views (Jobs, Months) via `rowsView`. [`JobsJobSummaryTab.tsx`](../../src/components/jobs/JobsJobSummaryTab.tsx): renders the view.
- Help guide: new `see-profit-by-month-on-job-summary.md`.
