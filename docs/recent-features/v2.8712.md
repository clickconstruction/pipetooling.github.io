**Read.** `OfflineRetryPanel.tsx` makes one automatic try for each `online` event the browser raises, for a read alone, up to three. `offlineRecoveryState` (`src/lib/offlineRecoveryState.ts`) wrote the line's words from one fact, whether another automatic try is allowed, and not from whether one is under way. So when the one try of a return of the signal failed, which a try made the instant the network changes easily does, the line went on reading *trying again…* with nothing being tried, until the signal dropped and came back.

**The mend.** The words follow the try.

- `offlineRecoveryState` takes one more fact, `autoTrySpent`: the automatic try for this return of the signal was made, and its wait is over with the failure still standing. Then the line reads *Back online, but this did not load. Tap Retry to try again.*, and no further try is made by itself for that return.
- `OfflineRetryPanel.tsx` keeps which return of the signal its last automatic try was for. Eight seconds after that try (`AUTO_TRY_WAIT_MS`), with the failure still there and no read under way that the caller reports, the try is spent.
- A new `online` event is a new return: the screen tries by itself again and says so again, as before, up to the cap of three.

**What does not change.** A write never tried by itself, and its lines are as they were. The first automatic try is made at once, as before. A read that lands clears the line, as before. **Retry** is on the line throughout.

**Not done.** No second automatic try is made for one return of the signal. A timed second try would be a change to how every crew screen behaves on a poor signal, and it was not asked.

**The guide.** `what-no-connection-means` gains one step: if the try does not load the screen, the line says so after a few seconds, and **Retry** is the press.

**Tests.** The kernel: a spent try reads the new words and allows no automatic try, a try not spent still says *trying again…*, a write's line is untouched. The panel, with the clock driven by the test: the line says *trying again…* for eight seconds, then the new words with one try made, and a second `online` event tries again.
