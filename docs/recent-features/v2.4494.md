# v2.4494 — AIA G702-G703: a later application says when it no longer matches (2026-10-04)

The owner, 2026-10-04, asked whether a later application should flag that an earlier one changed after it went out: *"A later application should flag that it no longer matches what went out but should not be blocking so a reason can be given."* One migration (`20261004170429_job_pay_applications_carry_reason.sql`, one column), no edge function.

## The change

- **Kernel** [`aiaPayApplications.ts`](../../src/lib/aiaPayApplications.ts)
  - `CARRIED_AMOUNT_KEYS` / `carriedAmountsFrom(previous)` — the four amounts an application gives the next: its work to date (previous work), its line 6 (previous certificates), its change order additions and deductions (the previous months). `carryForwardPayApplication` now reads them from here.
  - `carryMismatch(values, applicationNumber, list)` — null when the application has none before it or its four amounts equal what that one gives today; otherwise the earlier application's number and each difference (`here`, `fromPrevious`).
  - `withCarriedAmounts(values, previous)` — the form with the earlier application's amounts as it gives them today.
  - `payApplicationWriteFromForm(…, carryReason?)` writes `carry_reason` only when it is passed; `SavedPayApplication.carryReason` reads it.
- **IO** [`aiaPayApplicationsIo.ts`](../../src/lib/aiaPayApplicationsIo.ts): the read and the write name `carry_reason`; on `42703` (a database without the column) each goes again without it.
- **Window** [`AiaG702G703Modal.tsx`](../../src/components/jobs/AiaG702G703Modal.tsx): an amber block above the link when the open form does not match — *This application does not match application 1.*, a line per amount (*… $19,400.00 here, $21,000.00 from application 1.*), *You can still save it and generate it.*, **Use application 1's amounts**, and **WHY IT STAYS AS IT IS**. Save and Generate work either way. The reason is sent when there is one, or to clear one that was there; taking the amounts clears it. A saved application that does not match carries ⚠ on its chip.
- **Documents tab** [`JobWindowDocumentsTab.tsx`](../../src/components/jobs/JobWindowDocumentsTab.tsx): under such a row, *⚠ No longer matches application 1.* with *Kept as it is: …* or *No reason given yet.*

The flag follows the chain one step at a time: when application 1 changes, 2 is flagged; 3 is flagged once 2 takes the new amounts, since 3 was saved from 2 as 2 stood.
