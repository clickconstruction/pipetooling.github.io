# v2.8021 — Lien desk: a scanned divider shows the mailed day beside the number box on a phone (2026-11-19)

## Why

v2.7964 put a code on each divider of the copies to mail. A lien opened from one says which day its first number records, because the first number ticks **Mailed** with the **Mailed on** day at once. That line was drawn at the top of the lien's card, above the document number line.

The landing centres the envelope the code named. On a phone the original contractor's envelope is the second of two, each with a number box and three receipt presses, so the line sat about 400 points above the box. Walked at 375 points wide after v2.7964 went live: with the contractor's box centred the line was off the top of the screen. A code is scanned on a phone, so the reader it was written for never saw it.

## What changed

- The line is drawn inside the envelope the code named, as that envelope's first row (`numberInput` in `LienServeWindow.tsx`, `data-lien-serve-code-day`). The landing centres that envelope, so the line and the box are on the screen together.
- A code that names an envelope the lien does not draw says it on the lien's first envelope.
- The words are the same (`LIEN_SERVE_NUMBERS_WORDS.codeDay`), and so is when they show: a landing from a divider's code, while the lien is not mailed.

## Tests

`LienServeWindow.render.test.tsx`: the line is inside the envelope the code named.

The pane was hidden, where a smooth scroll does not run, so the envelope was centred by an instant scroll for the measure. Not checked: a real phone's camera on a printed page.
