# v2.8634 — Lien desk: Out the door, the run's third card (2026-11-26)

Punch list #362 (`to-dos/lien-to-do-one-run/README.md`), step 8, *mail and file*: the checklist's third card, as far as the run's own record allows. Client only: no migration, no edge function. It stands on v2.8631 (the strip counts what the press prints) and v2.8593 (an affidavit has a printed fact).

## What it does

- **A card, *Out the door*, under the print**, drawn once a paper of the run has printed (`buildLienRunOut`, `src/lib/jobs/lienRunOut.ts`). Before that the strip's third step says what waits, as before.
- **Mail.** The run's printed notices still to mail, counted, with the run window's own press, *Enter mail numbers · N* (`LIEN_RUN_ACT.record`), which opens the window on recording: that is where the envelopes' numbers are typed or scanned.
- **File.** The run's printed affidavits still to file, a stop a clerk: by county as the batch lies in the stack (the rule of `lienAffidavitClerkOrder`), each line with *Record the filing ›*, which opens the job in the Lien window on its affidavit tab, where the filing is recorded once the clerk stamps it. A paper whose county is not on it is last, under *County not named on the paper*.
- **The tally.** *Printed N · N to mail · N to file · N left out · N changed since printed*, each value marked and drawn through `ValueSentence`; a zero is left out.
- **The strip's third step, with the print's facts known, counts the printed affidavits as to file**; the unprinted ones are step 2's (*for the notary*). Before the prints are read, and for a viewer with no one print, the strip is as built: `lienGetItRightWithFacts` takes `null` for that.
- The desk hands the component three doors: the run window on recording, the job's Lien window on its affidavit tab, and each printed affidavit's county from the papers the batch would print.

## What it does not do, and why

- **No *mailed a of b*, no *filed c of d*.** A mailed notice and a filed affidavit leave the run, which is the papers still to send or file (`lienRunPapers`), so what was done in this run would need a record of the run that nothing keeps. Keeping one is a migration and the owner's call; the card says what is left instead.
- **No line for the copies owed to each owner after a filing.** That is the liens' fourth step, drawn and not approved (punch list #366, counsel's).
