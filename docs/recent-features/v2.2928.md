# v2.2928 — Subs pick their start inside the window (2026-09-06)

PR 2 of the three-party scheduling train (prototype: artifact 3a540149). Stacked on v2.2927 (the Subs tab and stage windows).

## The pick

- Migration [`20260906050000_step_commitment_picks.sql`](../migrations/20260906050000_step_commitment_picks.md): `step_commitments.work_days`, `picked_start/end`, `picked_at`, `picked_by`.
- Shared kernel [`supabase/functions/_shared/subPick.ts`](../../supabase/functions/_shared/subPick.ts) (tested from `src/lib/subPortal/subPick.test.ts`): `pickWindowFor(order)` (the stage window, else the order's proposed span, else null), `evaluatePick({ window, start, end, todayYmd })` → ok / `outside` / `past` / `weekend` / `order` / `malformed`, `pickEndFromStart(start, workDays)` (weekday math), `pickableStarts(window, workDays, today)` (only starts whose end still fits), `canChangePick` / `pickChangeDeadline` (the day before the start), `pickProblemMessage`.
- **`submit-sub-portal`**: `accept_offer` takes `pickedStart` / `pickedEnd`; an order with a window refuses to sign without a start inside it (400 with the kernel's sentence); on success writes `picked_*` (`picked_by: 'sub'`), mirrors the start onto `people_labor_jobs.job_date` and the span onto a step-anchored order's `scheduled_start/end_date`, and the accepted dispatch note carries the dates. New kinds: **`pick_dates`** (signed order, inside the window, only until the day before the current start; refuses office-set dates with "call us") and **`cant_do_dates`** (rate-limited; dispatch note `sub_dates_askback` with the window and an optional note).
- **`sub-portal`**: offers carry `window` (from `job_stage_windows` via `stage_window_id`, else the proposed span) and `workDays`; signed sheet orders carry `dates` — `{ commitmentId, start, end, window, workDays, changeUntil }` (`agreementDates` in `_shared/subPortalStatement.ts`; `attachSheetAgreements` takes `todayYmd`).

## The portal

- [`SubPortalDatePicker`](../../src/components/subPortal/SubPortalDatePicker.tsx): the window's weeks, weekdays only, dead outside the window / before today / where the end would not fit; tap a start and the working days fill to the end; a legend.
- Offer card: "Pick your start day" with the window sentence and "It takes about N working days"; Sign to accept is inert until a start is picked and carries it; the accepted line reads "✓ Accepted for Sep 22 – Sep 23"; **Can't do any of these days** → an optional note → `cant_do_dates` → "the office will offer other days".
- Sheet card: **Your dates** chip and span; "You can move this inside … until …" with **Change** (the same calendar → `pick_dates` → "✓ Moved"), "Too close to move it here" once the deadline passes, "Set by the office" when there is no window.
- Strings in `subPortalI18n.ts` (en / es); the demo fixture shows a picked sheet and an offer with a window.
