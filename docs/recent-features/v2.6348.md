# v2.6348 — The edge drift check stops flagging every function when one more joins the shared kernels (2026-11-02)

`scripts/edge-kernels.mjs` writes `supabase/functions/_shared/gcKernels/`, the copy of `src`'s kernels the edge runs, and until now it wrote the whole of `IMPORTERS` into every file's header: *Imported by ar-returned-checks, bridge-weekly-sheet, …, walk*. A function joining `IMPORTERS` changed that line in all 233 files, and `check:edge-drift` compares each function's bundle byte for byte, so every importer read as behind until it was redeployed. After `gmail-mine` joined (v2.6275) the report on 2026-11-02 named 26 functions, none running code that differed from main beyond that line and code it never calls. A report that flags a comment can hide the one function that is really behind, so the list comes out of the copy. A generator change, a test and the regenerate: no migration, no screen.

## Change

- **The headers name the generator, not the functions.** Each copied file's second line now reads *The functions that import the copy are IMPORTERS in that script (the schedule's PR 14b)*, and the index's first line says the same. Nothing the generator writes reads `IMPORTERS` any more, so a function joining or leaving it changes no file under `supabase/functions/` and no deployed bundle. `IMPORTERS` stays where it was, the one list of them, and its doc comment says why it stays out of the copy.
- **The regenerate.** `npm run gen:edge-kernels` rewrote that one line in each of the 233 files (232 copied files and the index): one line out and one in each, nothing else. A mechanical sweep: on a rebase conflict in the copy, take main's files and run the generator again.

## Tests

- `src/lib/gc/edgeKernels.test.ts`, new: *names no importer, so a function joining IMPORTERS changes no file in the copy and no deployed bundle* pushes a made-up function onto `IMPORTERS`, regenerates, and fails on any file that differs from the first generate. Main's generator fails it with all 233 files changed.
- *names as its importers exactly the functions whose bundles reach it* keeps its check of `IMPORTERS` against the bundles and drops its check that every file carries the list.
- `node scripts/edge-kernels.mjs --check` and `npm run check:edge-bundles` (all 173 functions link) pass.

## Docs

`docs/EDGE_FUNCTIONS.md`'s paragraph on the copy is amended in place: its list of importers, fifteen of the thirty, becomes a pointer to `IMPORTERS`, with a sentence on why the headers no longer name them.

## Deploy
