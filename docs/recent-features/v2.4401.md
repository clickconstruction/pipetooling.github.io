# v2.4401 — 44 more windows say they are windows (2026-10-02)

Client only: no migration, no edge function. PR 4a of the owner's ask "stop background scroll on all modals across the app" ([v2.4399](v2.4399.md), [v2.4400](v2.4400.md)): the mechanical sweep, merged alone. Script-driven — on a rebase conflict re-run [`scripts/codemods/dialog-role-sweep.mjs`](../../scripts/codemods/dialog-role-sweep.mjs), never hand-resolve.

## Why

Since v2.4400 the scroll lock holds the page behind a panel that declares itself modal (`aria-modal="true"`) at any size; a layer with no such panel still has to cover 90% of the screen. So a window is safest when its panel says what it is — and that is also what a screen reader announces. The v2.2188 sweep tagged 120 panels, but it skipped a whole file as soon as one `role="dialog"` was in it, so a file with one marked window hid every unmarked one beside it, and nothing stopped a new unmarked window from merging.

## What changed

- **The codemod reads one backdrop at a time**, with the TypeScript compiler instead of a regex over the file. A backdrop is an element whose inline style literal has `position: 'fixed'`, `inset: 0` and an `rgba(…)` background. It is declared when it, or anything drawn inside it in the same file, carries `aria-modal`, `role="dialog"` / `"alertdialog"` or `data-page-scroll`. Otherwise the first element inside it that is not a `<style>` gets `role="dialog" aria-modal="true"` when it is a plain element; a component there is left alone (its own file is read on its own). The v2.2188 SKIP list is unchanged.
- **The sweep**: 44 panels in 28 files — the Workflow step and line-item windows (11), People → Contracts (3), People's invite and delete confirms (3), Bill Customer's two send windows, the Stages confirm windows (7), the Bids delete and version windows, Checklist's forward window, the takeoff's add-assembly window, Draft payroll, Record a pay stub payment, and the rest listed by `git show --stat`. No backdrop needed the fallback of tagging itself.
- **CI holds it** (`npm run check:dialog-role`, in `ci.yml` and `deploy.yml`): the same script with `--check` exits 1 and prints the fix when a dim full-screen backdrop has no declared panel.

## Verified

`npm run typecheck`, `npm test` (2139 files), `check:nested-windows` (436 backdrops, 0 findings), `check:backdrop-click`, `check:workflow-parity` (13 commands) all pass after the sweep; `--check` reports 0 on the swept tree. No render test broke on a second `dialog` role.

## Not done

- A backdrop whose style is not an inline literal (a shared style object, a CSS class) is not read; nor is one built from `top/left/right/bottom` instead of `inset: 0` (the Lien desk, already marked). The lock's 90% rule still covers those.
