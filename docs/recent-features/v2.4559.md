# v2.4559 — Documents: printed lien papers are kept (2026-10-05)

Step 3 of the Sent copies train ([`docs/SENT_COPIES.md`](../SENT_COPIES.md)) begins: the owner's *"printing counts as sending"*, surface by surface off `PRINTS_OWED`. This is the lien surface. Client only: no migration, no edge function.

## The change

Each print goes through `printAndFile` ([`sentCopiesIo.ts`](../../src/lib/sent/sentCopiesIo.ts)), which prints as before and files the page as it printed.

| Where | Kind | Filed on |
|---|---|---|
| `LienDeskRunModal` — **Print the packet** | `lien_notice_packet` | every job in the run (a combined notice's parts included) |
| `LienFilingTabs` — **Print** on the notice, the affidavit, the release of record | `lien_notice_53_056`, `lien_affidavit`, `lien_release_of_record` | the job |
| `LienReleaseModal` — **Print** | `lien_release` | the job, the release as its source; the title says when it printed unsigned |
| `LienDeskModal` — the Timeline's **Print** (counsel's grid) | `lien_grid` | every job in the grid |
| `GcOnNoticeModal` — **Print the grid ↗** | `lien_grid` | every job in the grid, and the GC |
| `LegalDeskModal` — **Print** the packet | `legal_packet` | the packet's jobs and its payer |

New helper `printWhenReadyAndFile(build, filing)`: for a page that needs a moment to build (a signed waiver reads its stored ink first), it files the page that printed. The run window's envelope faces stay a plain print: they are addresses, not a paper anyone reads.

`PRINTS_OWED` drops six (17 left).
