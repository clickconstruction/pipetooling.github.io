# v2.2176 — Phone overflow sweep: Vehicles detail + Customers list (2026-08-23)

Owner sent a phone screenshot of People → Vehicles with the page shifted off the left edge. Reproduced at 375px (Chrome mobile emulation): opening a vehicle grew the layout viewport to 509px. Root cause + fix, then a sweep of the main routes with a DOM probe (any element whose right edge passes the screen and isn't inside an `overflow-x: auto` scroller; plus `innerWidth`/`scrollWidth`).

- **Vehicles detail** ([`PeopleVehiclesTab.tsx`](../../src/components/people/PeopleVehiclesTab.tsx)): the Ledger filter row (All · Odometer · Service · Problems · Holders · Insurance · Value) was a 485px `nowrap` flex row → `flexWrap: 'wrap'`. Ledger rows gain `flexWrap: 'wrap'` with the label at `flex: 1 1 160px`, so on a phone the description takes its own line instead of wrapping one word per line between the fixed date / chip / value columns. Desktop unchanged.
- **Customers list** ([`Customers.tsx`](../../src/pages/Customers.tsx) + [`index.css`](../../src/index.css) `@media (max-width: 640px)`): the row's signal chips + `CustomerMoneyRail` (3 × 86px) sat beside the name block and ran to x=519. The row container now wraps; the phone rule for `.customers-projects-bids-links` changes from a right-aligned column to `flex: 1 1 100%` (chips + rail drop under the name as one left-aligned wrapping row). Desktop rule untouched.
- **Swept clean at 375px**: /dashboard, /jobs (stages, sub_sheet_ledger, billing), /quickfill, /schedule-dispatch, /customers + /customers/:id (jobs, invoices, feed), /bids, /estimates, /projects, /prospects, /checklist, /materials, /settings, /partnerships, /people (hours, vehicles list + detail).
