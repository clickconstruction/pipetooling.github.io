# v2.1939 — Partner ledger: offset-inclusive settle-up headline (2026-08-21)

Owner-approved mockup ("View as Partner" artifact, markers 1–2): the Ledger tab's headline balance excluded pending offsets, so a partner with $967.60 posted and $1,304.88 in unattached back-charges read as being owed money when settling up would actually mean **he owes the company $337.28**.

Kernel [`partnerLedgerJournal.ts`](../../src/lib/partnerLedger/partnerLedgerJournal.ts) grows `netPosition(postedBalance, pendingNet)` and `pendingOffsetSignedAmount(offset)` (charges −, profit shares/credits +; 3 new tests). [`PartnershipLedgerTab.tsx`](../../src/components/partnerships/PartnershipLedgerTab.tsx): headline = net position (red when negative) with "posted · pending" components beside it, and the pending offsets render as an itemized "Pending — not yet on a statement" block (description, date, signed amount, newest first) above the journal — the journal's running-balance column stays posted-only truth. [`DashboardPartnerLedgerSection.tsx`](../../src/components/dashboard/DashboardPartnerLedgerSection.tsx): the partner's open-week card adds a "with pending charges: … waiting for the next statement" line fed by the same kernel, so the office and the partner quote the same number (`get_my_partner_summary` already carried `pending_offsets` — no RPC change). Help guide `see-your-partner-ledger` documents the new line. Client-only — no migration.
