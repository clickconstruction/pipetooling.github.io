# v2.2503 — Robot-ready CountTooling: plan-fetch, PDF-bearing imports, review closure, per-twin CT creds, CT guide (2026-08-30)

The "robot army" train (owner directive 2026-08-30): make upload and drawing by agents
seamless in CountTooling before resuming M5. Five pieces, all deployed and live-probed
the same day; closes pipeline Waves **3.5** and **3.6** and most of the STG-3 seam
(docs/ESTIMATOR_TWIN_PIPELINE_PLAN.md).

- **CT-1 · `plan-fetch` (PT edge fn, new)**: streams a bid's plan set (the Drive file in
  `bids.plans_link`) via the SA token — `GET ?bid=b403`, twin-token (assignment is the
  grant) or staff JWT; `verify_jwt = false` (in-function auth). CT's `import-takeoff`
  gained `pdf_url`/`pdf_headers`: fetches the PDF server-side, magic-byte + 50 MB checks,
  pdf-lib page count (out-of-range page indexes rejected by name; pages padded to the
  PDF), stores at the app's `<uid>/<project>/document.pdf` path, stamps `pdf_path`.
  E2E-verified: the 55-page 36 MB LIVSTE set landed under twin marks in one call;
  re-import replaced (1 storage object). Contract: CT `TAKEOFF_IMPORT.md`.
- **CT-2 · changes-requested** (CT migration `project_review_changes`, applied): review
  status gains `'changes'` + `review_note`; `set_project_review_status(p_note)`; Bid
  Board "Request changes…" with note. Probes: twin `ready` ok; twin `changes` refused.
- **CT-3 · review state to the twin**: CT `manage-user` verb `twin_projects`;
  `get_work_state` gains `ct_takeoff` (projects + review status/note over the bridge,
  fail-soft) — a sent-back takeoff is a resumable fact. Replaces the `not_yet_in_v1` note.
- **CT-4 · per-twin CT credentials** (CT migration `twin_credentials`, applied): CT
  `twin-login` accepts `X-Twin-Token` verified against locally mirrored hashes (a token
  mints only its own twin); twin-mcp syncs the hash on each CT mint (best-effort) and
  falls back to the fleet secret on 401. Independent per-app revocation; PT-side revoke
  still cuts twin-mcp entirely.
- **CT-5 · the CT guide**: `docs/twins/COUNTTOOLING_BID_GUIDE.md`, bundled by the briefs
  generator and served as twin-mcp tool **`get_ct_guide`** — access, the full
  plans→import→review→counts loop, contracts, hard limits.
