## Decisions

- **A function, not a `DO` block**, so the bed can take lines away, put the office's own in the way and run the seed again, and so a dev can rerun it by hand if a line is ever deleted outright. The editor only removes, which keeps the words on the row and so keeps the line out, as the card asks.
- **A shortcut the office already gave away leaves the whole starter line out**, not a line without its word: a starter line is its shortcut.
- **The words compared lowercased and trimmed**, not by id: the card's rule is *a starter line that repeats a saved one is left out*, and a retyped capital is the same line to the office.
