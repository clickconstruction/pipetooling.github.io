# v2.2324 — Invoice payment history becomes the ledger box (2026-08-26)

Owner-approved mockup: claude.ai/code/artifact/6fe60553-5845-4db1-b80f-7edf69357214.
Extends the portal ledger grammar (v2.2318–v2.2322) to every invoice surface.

- `physicalInvoiceLineItems.ts`:
  - `PhysicalInvoicePaymentHistoryRow` reshaped to `{ label, amountFormatted }`
    — label is "Paid Dec 17, 2025" (+ " · method" only when the method says
    something; generic/blank drops the suffix via the portal kernel's
    `portalPaymentMethodLabel`). Weekday removed from payment dates
    (v2.2313's " · Wed" — dropped to match the portal; flagged as an open
    question on the mockup and defaulted to consistency).
  - `PhysicalInvoicePaymentTotals` gains `billedFormatted` (the document's
    own amount — the ledger's opening line). `totalPaidFormatted` kept for
    any future use but no renderer shows it now.
- Renderers (all three from the one kernel):
  - Email bodies (`physicalInvoiceDocument.ts`): HTML box = Billed row,
    green "− $x" credit per payment, red Balance due / green Paid in full;
    Total paid row removed. Text bodies get the same shape via a new shared
    `paymentHistoryTextLines` (both layouts).
  - `PhysicalInvoicePreview.tsx`: same rows in the boxed card.
  - `physicalInvoicePdf.ts` `drawPaymentHistory`: Billed line, green credit
    rows ("- $x" — ASCII minus for font safety), rule, red/green closing.
- Kernel tests updated: label shape, generic-method drop, billedFormatted.
