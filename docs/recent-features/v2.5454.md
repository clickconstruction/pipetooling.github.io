# v2.5454 — Lien desk: the run mails its envelopes through Docsmit, after a review of each one (Docsmit train, PR 5b) (2026-10-13)

PR 5b of the Docsmit train (`docs/DOCSMIT_LIEN_RUN_PLAN.md`, *The run window* and *Review before it mails*): the first screen on the train. It leans on 5a's rules (v2.5384), PR 4's window page (v2.5382), the functions (v2.5381) and the table (v2.5379); the help guide's *Sending the run* gains the paragraph *Mail it through Docsmit*.

**The door** (`LienDeskRunModal.tsx`): `useDocsmitSettings` (new hook, `src/hooks/useDocsmitSettings.ts`) reads the `docsmit_*` switches; the button **Mail through Docsmit · N envelopes ▸** (`run-docsmit`) sits beside Print the packet once a dev saved the connection (a `docsmit_env` row), while not paused and before anything printed. `docsmitRunDoor` dims it with the why when every certified address is short. A strip above the cards (`run-docsmit-send-by`) carries `docsmitSendByStrip` for the run's tightest month on the residential clock, red once past.

**Prepare** (`src/lib/mail/runDocsmitIo.ts`, `prepareDocsmitRun`): per clean certified envelope, a short code; the owner's copy built with the window block and the code (`buildRunNoticePdf` with `window`, the QR pointing at the job's first payable bill's pay page with `?m=CODE`); every copy inside merged (`mergePdfBlobs`), counted (`pdfPageCount`, new beside the merge), the envelope picked by sheets; the PDF to the private bucket at `mail/<code>.pdf`; `mail-send-docsmit` `prepare`. An envelope that cannot go is held with its reason (a short address, too many sheets, the bucket, CASS, the function) and the rest carry on; the balance comes back with the price.

**The review** (`DocsmitReviewModal.tsx`): one envelope at a time with the face (the send type, the recipient in the window, where Docsmit's label goes, the address as checked, the code and the price), the PDF Docsmit holds in a frame, the held envelopes on the left with their reasons, the price line against the balance at the foot (`docsmitPriceWords`; short disables the button), the send-by strip, and the one button **Mail these N envelopes ▸**. Arrow keys walk the envelopes; Esc closes. Two render smokes.

**The send** (`sendDocsmitRun`, `docsmitRecipientPatches`): the function's answer in order; each copy inside a mailed envelope carries `via`, `pieceId` and `pieceStatus` on its `RunRecipient` (`lienDeskRun.ts`), so `recipientMailed` counts it, its card reads *mailed through Docsmit · number coming* (or the number once it is known) with the tracking box locked, Envelope faces skip it, and the record keeps `via` / `piece_id` on the filing's `sends[]`. After the record, `linkMailPiecesToFilings` writes the filing ids into each piece's `source_ids` so the hourly poll can write the number back. When nothing is left for paper, the run is sealed and the foot moves to recording. A refusal mid-batch (credit short) holds the rest with the function's line.

**The lanes and the paper** (6b, in the same release): a Docsmit envelope has its own lane, *Docsmit*, with no Printed stage (`runLaneOfEnvelope`, `RunLane` gains `docsmit`); it is postmarked the moment the service takes it, it leaves the live checklist, the printed packet and the envelope faces, and the print button counts the paper envelopes only. Left for 6b: the office's own packet preview passes no pieces.

**Tests**: `runDocsmitIo.test.ts` (3, the pipeline over a fake bucket, function and PDF builder), `DocsmitReviewModal.render.test.tsx` (2), two in `LienDeskRunModal.render.test.tsx` (the door, the review, the send; no door until set up or while paused, dim when every address is short).
