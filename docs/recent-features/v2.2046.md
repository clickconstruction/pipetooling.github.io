# v2.2046 — Roadmap Plan: per-task slot bars on stage cards (2026-08-21)

Extends the Timeline's per-task successive bars (v2.2042) to the Plan view,
per owner request ("on the Plan view do the same thing").

- **`PlanTaskSlotBar`** (in-file component in `ChecklistRoadmapPlanView.tsx`):
  a flex row of equal slots, one per task in task order — done green in true
  position, first open task amber-ringed ("next up"), rest outlined; locked
  variant dashed. Each slot is a button (tap → `onOpenTask`) with a
  "N.M title — state" tooltip. Flex layout, not the Timeline's lane
  fractions — Plan has no wave axis, so `taskSlotRects` isn't needed here.
- **Now cards**: the bar sits between the stage header and the "feeds" line.
  It always renders the FULL stage task list and hides while an
  assigned/unstaffed focus lens is active — a lens-filtered bar would
  misstate progress under the "limited view" banner.
- **Up next rows**: the same bar, dashed, on a full-width line under the
  lock hint. (Farm 1 currently has no up-next stages with tasks — its locked
  stages are milestones — so this path is data-starved live but trivial.)
- Header progress bar and Goals feeder bars stay solid: the header spans 88
  tasks (slots would be mush) and feeders aggregate across stages — different
  unit than one stage's tasks.

Verified live on Farm 1: 89 slot buttons across the 17 Now cards;
"Cut trail" reads done / next up / remaining.

Help: `read-the-roadmap-timeline.md` documents the slot grammar; the Plan
section of `staff-and-discuss-roadmap-tasks.md` gains a line.
