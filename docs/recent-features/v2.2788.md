# v2.2788 — Contract Forms PR 1: schema, kernel, PDF executor, agent scripts (2026-09-04)

Groundwork for **Contract Forms**: a Contract Book entry that is an uploaded PDF with dev-placed entry boxes, which the signer fills as the real page (the W-9 first). Nothing user-visible yet. Plan: `docs/CONTRACT_FORMS_PLAN.md`; spec + agent workflow: `docs/CONTRACT_FORMS.md`.

- **Kernel** `supabase/functions/_shared/formSchema.ts` (re-exported by `src/lib/forms/formSchema.ts`): `FormSchema` v1 (boxes of type text / digits / checkbox / signature / date / constant with rect, order, bilingual label + help, required, sensitive, advanced, `bind` / `bindSegments`, mask, group, oneOf, prefill, sample; exactly-one groups; one-of sets), `validateFormSchema`, `validateFormValues`, `applyPrefill`, `askedBoxes`, `splitFormValuesForStorage` (sensitive → last-four hints), `buildFillPlan` → `FillOp[]`, `draftSchemaFromPdfFields`, masks, geometry.
- **Executor** `supabase/functions/_shared/fillFormPdf.ts` (re-exported by `src/lib/forms/fillFormPdf.ts`): `readPdfFields` (pages + AcroForm fields with rects) and `fillFormPdf` (bind by name, draw unbound with auto-shrink, typed signature in Great Vibes via fontkit or Times Italic fallback, PNG signatures, flatten by default, unknown binds returned as `skipped`). pdf-lib is injected (the `jobContractPdf.ts` pattern) so Deno, browser, and vitest share the file. New dependency `@pdf-lib/fontkit`.
- **Migration** `20260904220000_contract_form_templates.sql`: `contract_form_templates`, `contract_template_documents.form_template_id`, `person_contract_documents.form_template_id / form_values / form_hints / form_pdf_storage_path / form_source`, `contract_form_pdf_opens`, trigger `set_form_template_on_write`. Buckets `contract-form-templates` / `contract-form-pdfs` out-of-band (SQL in the spec).
- **Agent scripts** (vite-node): `npm run forms:inspect`, `forms:draft`, `forms:preview -- … --png --boxes`. An agent handed a PDF can inspect its fields, draft the schema, edit labels, and render the filled page to PNG for the owner before anything is imported into the studio.
- **Tests** `src/lib/forms/formSchema.test.ts`, `src/lib/forms/fillFormPdf.test.ts` — the latter runs against the real IRS W-9 fixture `src/test/fixtures/fw9-2024-03.pdf`: 23 fields read, draft → fill → values read back unflattened → flatten leaves zero fields.
- `public/fonts/GreatVibes-Regular.ttf` (+ OFL) added; `**/fonts/**` excluded from the service-worker precache.
