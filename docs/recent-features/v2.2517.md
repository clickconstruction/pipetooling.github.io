# v2.2517 — Audits tab: review robot bids in one place (2026-08-30)

The human side of the audit loop (FEEDBACK_LOOP v2; schema in v2.2516). New `audits`
tab on the Bids page, gated like Robot Board (renders only when `bid_audits` rows
exist; label carries the pending count via `useBidAuditsPendingCount`).

- `src/components/bids/BidsAuditsTab.tsx` — self-loading card list: quick links
  (`ct_view_url` new-tab + `/bids?tab=counts&bidId=…` new-tab), twin questions with
  inline answers (`kind='answer'`, `parent_id` threading), five sectioned note
  composers, receipts rendered under their notes with the digest-outcome label,
  Finish audit (status → `done`, ledger stamp) and Reopen. Digested history is
  collapsed behind a toggle. Ships ahead of gen-types via the untyped-client +
  missing-table-guard pattern (BidRfiQueue).
- `src/lib/bids/bidAudits.ts` — kernel: `threadAuditNotes` (questions↔answers,
  notes↔receipts, fixed section order), `computeAuditDraftTotal` (selected-version
  scoping, override-wins), `sortAuditsForTab`, section/outcome labels. Unit tests in
  `bidAudits.test.ts`; render smokes in `BidsAuditsTab.render.test.tsx`.
- Help guide `audit-a-robot-bid` (Bids category).
