# v2.7950 — Materials on site: the answer window says when each press was made (2026-11-19)

A fix to the answer window of the By person look (v2.7834, the fifth PR of the on-site tracking train). Client only, no migration, no edge function.

## Why

The train was tried live on a ZZ test job on 2026-11-19. Two uses of one elbow from one box, a minute apart, one with a note and one with none, read the same in the window: *Used · ZZ test elbow · −1*, the box and the person. Each row of the window has its own answer, so a dev could not tell which answer went on which press. The window lists the picked presses in the list's order, newest first, which was the only clue.

## What landed

- **The day and minute on every press.** [`PressAnswerWindow.tsx`](../../src/components/materials/PressAnswerWindow.tsx) writes each press's day and time before its box and person, like *Thu, Nov 19, 1:26 PM · ZZ1 · ZZ Test yard · Sam R.*, and its note under it in italics when it has one (a delivery's paper stands in for a note, as on the list). The answer's select names the time too, so each one is told apart by its label.
- **The way back shows the same.** `AnswerWithdrawWindow` (Let the press stand, Take the mark off) draws the press with its day, time and note.
- **One set of time words.** `actStampWords` in [`sitePersonActs.ts`](../../src/lib/materials/sitePersonActs.ts) is the day and minute on the device's own clock. The look's *last press* line read it from a copy inside `SitePeopleView.tsx`, which is gone.

## Tests

- `sitePersonActs.test.ts`: two presses a minute apart read apart, and a time that is not one reads as nothing.
- `SitePeopleView.render.test.tsx`: two look-alike uses, one with a note, each show their own time in the window, the note shows on its press alone, and the two selects carry different labels. With the old row put back, that case fails by name and the other fifteen pass.

## Guide

[answer a press on site that should not stand](../../src/content/help/answer-a-press-on-site-that-should-not-stand.md) says each press in the window shows when it was made and its note.
