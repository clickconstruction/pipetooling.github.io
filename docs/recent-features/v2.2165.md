# v2.2165 — Statement link in the partner nav (2026-08-23)

Follow-up to v2.2157 (Partner statement page). Owner asked what a nav link would look like,
then "build it". Mockup: claude.ai/code/artifact/ce0fea26-810a-4430-99e4-2f543932cc8b

- **[`PartnerStatementNavLink`](../../src/components/partner/PartnerStatementNavLink.tsx)** — a
  lucide `Receipt` glyph in the header strip beside the home icon (`variant="icon"`, same
  `iconLinkStyle` / underline-when-active as Dashboard) and a labeled row in the ☰ menu
  (`variant="row"`). While last week's statement is unacknowledged the icon carries a 7px amber
  dot and the row an amber **sign-off waiting** tag — the same fact as the Dashboard card's
  nudge. Render smoke covers both variants.
- **[`useIsPartner(role)`](../../src/hooks/useIsPartner.ts)** — one `get_my_partner_summary`
  call per session for roles that can be partners (field + estimating roles; never dev /
  master / office), cached in `sessionStorage` for 10 minutes
  ([`partnerNavStatus.ts`](../../src/lib/partnerLedger/partnerNavStatus.ts) holds the pure
  status + cache parsing, tested). `invalidatePartnerNavStatus()` drops the cache and fires a
  window event so mounted hooks refetch — the statement page calls it after an acknowledge, so
  the dot clears without a reload.
- **Placement in `Layout.tsx`:** the mobile header strip (after the Dashboard icon), the general
  nav branch, and the estimator nav branch (desktop header + ☰ dropdown rows). Not a fifth
  bottom tab — the job-mode bar is shared dispatch chrome.
- **Found while verifying (imitating Bryan read-only):** Bryan's account is an **`estimator`**,
  not a subcontractor — so v2.2157's `/my-statement` allowlisting (sub-like only) would have
  bounced him off his own Dashboard card. Fixed here: `/my-statement` added to
  `estimatorAllowedPaths` in `layoutRouteAccess.ts`; the hook's eligibility is "any role that
  can be a partner" (`roleCanBePartner`); help guide `see-your-partner-ledger.md` now lists
  `estimator` in its roles and mentions the icon; `ACCESS_CONTROL.md` row corrected.
- Verified live as Bryan (dev imitation, no actions taken): icon with dot beside the home icon,
  Dashboard "Your statement" card, `/my-statement` opens with his own Acknowledge button; exited
  imitation. Client-only — no migration.
