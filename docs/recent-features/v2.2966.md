# v2.2966 — No split without a clock session: the People → Hours editors link sessions too (2026-09-06)

Follow-up to v2.2962 (Crew Jobs / Bids). Owner: "Apply the same rule to the other four surfaces." Of the four candidates, two only **read** `people_crew_jobs` (Quickfill's Unassigned field time section and `draftPayrollPersonBreakdown`); the two writers were `HoursUnassignedModal` (People → Hours → "Assign … to jobs or bids") and `PeopleHoursDayAuditModal` (People → Hours and Quickfill → day audit). Client only — no migration, no edge function.

## What shipped

- **Shared write** [`src/lib/linkClockSessionsToPick.ts`](../../src/lib/linkClockSessionsToPick.ts): `linkClockSessionsToPick(ids, pick)` — the one `UPDATE clock_sessions … .select('id')` behind all three surfaces (CrewJobsBlock refactored onto it) — and `partialLinkMessage` for the RLS short-count toasts.
- **Kernel** [`crewAssignSessionLinkPlan.ts`](../../src/lib/crewAssignSessionLinkPlan.ts) (+6 tests, 14 total): `classifyDayLinkSessions` works from raw session rows (skips open / rejected / revoked; splits **approved** unlinked from **pending** unlinked), `dayLinkState` → the same `no-clock | link | locked` as the Crew Jobs cell, `dayLinkSuccessMessage` says when the split waits on approval.
- **`HoursUnassignedModal`** (People → Hours): loads the range's sessions once (`user_id` + `work_date` window, live rows only). **Common Jobs**, **Recent jobs & bids** and the search each link the selected day's unlinked sessions immediately; the draft chips, percent inputs, × and **Accept** are gone. `unassignedDays` now also requires a closed session that day; the rest are listed as **Skipped — no clock session: …** (salaried flat-8 days with no punch, mostly). **Split day…** opens the shared day editor (`zIndex` 1200 clears the modal's 1001). Approved links reload the list (`reloadTick`) so the day drops out; pending links show the "updates on approval" toast.
- **`PeopleHoursDayAuditModal`**: the manual Assignments editor and **Save crew** are gone. Edit mode shows the split read-only (with the overhead badge), **+ Link N sessions (H h)** when any closed session is unlinked (approved or pending), **manual · no clock** + **Clear** for a legacy row on a day with no session, and the existing per-session **Assign** popover, **↺ Re-sync from clock**, **Add session** and clock split modal for finer control. The view-mode CTA reads the same label and only appears in the `link` state; a no-clock day says so.
- **Render test** `HoursUnassignedModal.render.test.tsx` (table-aware supabase stub): the no-clock day is skipped and only the session day is offered; a search pick issues exactly one `clock_sessions` update `{ job_ledger_id, bid_id: null }` for the unlinked ids and no crew-table write. Writing it exposed that the modal's day-range walker used `toLocaleDateString('en-CA')`, which small-ICU runtimes render as `9/5/2026`; it now walks with `ymdAddDays` (locale-proof). The modal could not be opened against live data — every Correct day back to Aug 2 is already assigned.
- Guides: `put-clocked-hours-on-the-right-job` gains "The same rule on People → Hours"; the `quickfill` People Hours bullet and `match-clock-sessions` cross-link it.

## Deliberately unchanged

`QuickfillUnassignedFieldTimeSection` and `draftPayrollPersonBreakdown` (readers). The per-session `AssignSessionJobPopover` (already session-first). The RLS gap for un-adopted controllers (v2.2962 owner decision) — both modals surface it with the same warning toast.

A salaried day with no punch appears in the **Skipped** line, not the day picker.
