# v2.3623 — Punch list: the board is rendered at build time; nothing generated is committed (2026-09-19)

## Why

Since v2.3558 the board was a committed module (`src/content/punchList.generated.ts`) plus an index table spliced into `to-dos/README.md`, both re-rendered by `npm run check:todo-drift -- --fix` and checked in CI. Every PR that touched a to-do carried fresh copies of both, so two such PRs conflicted on them whenever one landed first. On 2026-09-19 main re-rendered the board eleven times and five open PRs had to be re-resolved three times each. The owner's call: sort it for good.

## The change

- **The board is a virtual module.** [`vite.config.ts`](../../vite.config.ts) `todoBoardPlugin` serves `virtual:punch-list` — the same module text as before, rendered from `to-dos/` by [`scripts/todos/readTodos.ts`](../../scripts/todos/readTodos.ts) `renderTodoBoardModule` at build and in dev (any change under `to-dos/` reloads it). A build refuses broken to-dos with the same errors CI reports; the dev server logs them and serves what parsed. [`PunchList.tsx`](../../src/pages/PunchList.tsx) imports it (typed in `src/vite-env.d.ts`); `src/content/punchList.generated.ts` is deleted.
- **The README index is gone.** `to-dos/README.md` keeps the conventions and the closed-sweep notes; the open list is the board itself (gear menu → Punch list), and on GitHub the folder listing is the index. [`todoBoard.ts`](../../src/lib/todos/todoBoard.ts) drops the index renderers and `renderViews`; `findDrift` becomes `findTodoProblems` (a to-do that does not parse, a duplicate slug, a version that never shipped — the two out-of-date findings have nothing to compare any more). 53 kernel tests.
- **`npm run check:todos`** ([`scripts/check-todos.ts`](../../scripts/check-todos.ts), replacing `check:todo-drift`; no `--fix`): every to-do parses, cites shipped versions only, and the board renders. Both workflows run it. `AGENTS.md`, `docs/PROJECT_DOCUMENTATION.md` and the to-dos README say so.

## What does not change

The to-do files, their front matter, the mock-ups beside them (still served at `/to-dos/…` by `todoMockupsPlugin`), the board page and its role gate. The stamp on the board (*validated <date> at v2.NNNN*) is now the build's date and the newest fragment version.

## Verified

Typecheck, lint, the `todos` and `punchList` suites, `npm run check:todos` (28 to-dos, 26 open items), `vite build` (the virtual module in the bundle). Dev server: `/punch-list` renders the same rows as before, and editing a to-do reloads the page.
