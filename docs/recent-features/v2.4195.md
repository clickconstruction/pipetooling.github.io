# v2.4195 — Cover Letter and Bid Board: the alternate priced in addition to the proposal (2026-09-29)

The alternates train, PR 5 of 5 (after [v2.4194](v2.4194.md)). No migration, no edge function. The owner's picks: the Bid value is the base with a *+$ alt* chip; the letter says *add $X (with it, $Y)* under a heading that says *in addition to*, so it cannot be read as the in-lieu-of block a version alternate prints; two or more alternates just add lines.

## What changed

- **The kernel** — [`coverLetterAddAlternates.ts`](../../src/lib/bids/coverLetterAddAlternates.ts): `splitLetterTotalsByAlternate(rows, countRows, tags)` (the letter's revenue and fixture list as the base and each alternate, by the Count Sheet's scope), `offeredAddAlternates` (every alternate unless its `groups[key].offered` is false), `buildAddAlternatesBlock` (*Alternate 1 — Break room: add $2,717 (with it, $13,241.00)* with the alternate's fixtures under it, or the estimator's own wording), `stampAddAlternateAmounts` and `boardAlternateAddOn`.
- **`bids.cover_letter_alt_texts` grows a `groups` map** (`parseCoverLetterAltTexts`), keyed `group:<normalized tag>`: `offered` and the `amount` the letter last stamped on a send. The wording lives in `sections` under the same key, so the preview's click-to-edit works unchanged. No schema change — the column is jsonb.
- **The letter** ([`bidDocuments/coverLetter.ts`](../../src/lib/bidDocuments/coverLetter.ts), a last `addAlternatesBlock` argument on both builders): the block prints after the in-lieu-of block, in the HTML and the text. [`useBidPricingRows`](../../src/hooks/useBidPricingRows.ts) hands the tab `coverLetterPricingRows.byAlternate`; in [`BidsCoverLetterTab`](../../src/components/bids/BidsCoverLetterTab.tsx) the proposed amount and the fixtures list become the **base** (an unticked alternate stays priced into them), the block follows the headline (a custom amount included), and a GC packet's section drops its offered alternates the same way so the same-page letter's total is the base too.
- **Step 1, under *In this cover letter*** (`data-testid="cover-letter-add-alternates"`): one row per alternate — an **Offer** checkbox, the group with its ALT mark, *adds $X*, and ✎ the wording (the same editor the in-lieu-of alternates use; *Reset* returns to *Alternate N — <group>*). Unticked reads *priced into the proposal*.
- **A send stamps the add-ons**: *Mark sent today* and the bid room's first link (both paths) write each offered alternate's amount into `groups[key].amount` and clear an unticked one's, beside the Bid value they already stamp — which is the base, because the headline is.
- **The Bid Board**: the value cell and the expanded strip's *Bid* wear **+$2.7k alt** with a hover naming each alternate; the value itself stays the base (the owner's pick).

## Decided here

- **The proposed amount is the base only while an alternate is offered.** Untick every alternate and the letter is exactly what it was before this train.
- **Multi-version letters**: each version's section prices its own base; the add-on block covers the active version's alternates. A version alternate (in lieu of) and a with-and-without alternate can share a letter — two headings, two meanings.
