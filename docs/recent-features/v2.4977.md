# v2.4977 — Lien desk: the run saves its addresses for a certified mail label service (2026-10-08)

Client only. Grace, after the run paper (v2.4971): *is there a way for us to make something that the machine at the post office can scan to make entry easier when an assistant goes to a kiosk to do the certified mail?* The kiosk scans nothing of ours; the answer that removes the kiosk is to print the Certified Mail label, with the electronic return receipt, at the desk through a USPS-licensed label service. Grace: *Do 1* — open an account with such a service and run from it. The brief for the office is the doc *Certified mail labels in-house* (https://claude.ai/code/artifact/f108adb9-ff42-43c3-9710-98dab1ac0077): the pick (Certified Mail Labels, no monthly fee, about $10.19 a letter with the signature record), the account steps, the first run, counsel's question and the cost per run. This PR is the app's part of step 1.

## What changed

- **Kernel [`lienRunLabels.ts`](../../src/lib/jobs/lienRunLabels.ts)** (pure): `runLabelRows(mailing)` — one row per envelope that goes out on paper (certified mail or traceable courier; held, email and hand envelopes left out), numbered as the sheet is, the address through `runAddressLines` with `splitCityStateZip` on the last line (*SAN ANTONIO, TX 78230* → city, state, ZIP; a line of another shape stays the city), the reference *Envelope 3 · 898, 813*. `runLabelCsv(rows)` writes the vendor's columns (`Company, Name, Address Line 1, Address Line 2, City, State, Zip, Phone, Reference`), a BOM, CRLF, `csvEscapeField` on every field. `runLabelFilename`, `runLabelSavedWords`.
- **The run window**: **Addresses for the labels** beside *Envelope faces* (`run-label-addresses`) saves `certified-labels_<day>.csv` through the same blob-and-anchor path the Counts CSV uses, and toasts how many addresses went. Nothing is filed: the labels the service prints are the record.
- Guide [`send-lien-notices-from-the-lien-desk`](../../src/content/help/send-lien-notices-from-the-lien-desk.md) → *Labels instead of the counter*.

## Not done

- Reading the vendor's batch report back into the run (the tracking numbers), and buying the labels through the vendor's API from the run, are the next two pieces the brief names; they wait on the first real batch and counsel's yes on the electronic return receipt.
