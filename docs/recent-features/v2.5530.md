# v2.5530 — Lien desk: Esc closes the run window, and it no longer closes over unsaved work (2026-10-14)

Found in the live check of v2.5522 on 2026-10-14: all three In the mail doors open `LienDeskRunModal`, and only its header × (or a click outside) closed it, against the standing ask that big windows close on Esc. Three adversarial review rounds shaped the rule: the run now closes on Esc or a click outside only while nothing in it changed since it opened, and both wait on a signature pane. No migration, no edge function.

- **`src/lib/jobs/lienRunEscape.ts`** (new kernel): `runEscapeAction({ busy, overlayOpen, signing, takeBackOpen, moreOpen, hold })` → `ignore` (a write in flight; the preview or the Docsmit review, which close on Esc themselves) · `wait-signing` · `close-take-back` · `close-more` · `hold` · `close`. `runHoldSinceOpen(opened, current, extras)` → `docsmit` (a copy went through Docsmit in this sitting and is not recorded) · `typed` (a tracking number differs from the one it opened with, padding ignored) · `changed` (a send method, a courtesy tick — unset reads as off — a notice the run did not open with, Combine while it still joins something, Mailed on against the day the run opened, a Saved copy line, a box ticked on an envelope still on the checklist). Docsmit's piece fields count only through a send that went, so a batch that failed or stopped holds nothing · null. It compares only the notices still in the run, so a partial record leaves its recorded ones out, and it leaves signatures out because signing saves at once. `runHoldWords` gives the toast.
- **`LienDeskRunModal.tsx`**: a window keydown listener in the modal stack (`useModalStackEntry`), skipped when `defaultPrevented` or not topmost. The children stand it aside explicitly because the preview and the Docsmit review listen on window too and the Docsmit one only calls `stopPropagation`, which does not stop a sibling window listener. A signature pane counts only while it is on screen (its envelope still held with a leader and a viewer): signing one envelope frees its twin, whose pane unmounts with `penOpen`/`signOpen` still set, and a raw flag would have left Esc dead. The backdrop click goes through the same hold and the same signature wait (a pen stroke released past the panel's edge is also a backdrop click). Docsmit's prepare and send count as a write in flight, and its review counts as open only while it is drawn. The run snapshots what it opened with, and the day, in refs, since the desk rebuilds `initial` every render and recomputes today. Checklist ticks are keyed by the envelope's key, not its number, so a partial record (which renumbers the envelopes left) neither shows a recorded envelope's ticks on another nor holds over them; a take-back clears them. The take-back question counts as a layer only while it is drawn (it needs a printed item). A Docsmit review closed while it mailed goes back to idle when the send lands, instead of an undrawn `review` stage that left the Mail through Docsmit door dead (older than this change, from v2.5454); the send's toast still says what went.
- **Tests**: `lienRunEscape.test.ts` (+4: the action ladder, every hold, Docsmit's priority, a failed or stopped batch and a send made before the run opened, a partial record), `LienDeskRunModal.render.test.tsx` (+11: More, the preview, a typed number and a click outside; a send method and Mailed on; the take-back question; a signature pane and its stale twin; a Docsmit send held on Esc and a click outside; the review closed mid-send; a click outside over a signature pane; midnight; ticks after a partial record; Combine after a partial record takes its pair out; a take-back opener with nothing printed; the Docsmit door after a mid-send close). Each guard's case fails with the guard removed.
