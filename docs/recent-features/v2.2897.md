# v2.2897 — Dirty guards, topmost-only Escape, import Undo, Close-link confirm + Reopen (2026-09-05)

Journey-map Phase 4, Tier-2 #42 (cluster C42, "writes with no confirm, discards with no guard" — J1-F2 J1-N1 J8-F3 J11-F3 J12-F2 J17-F4 J18-F10). Eight small guards in one PR; no migration, no edge-function change. J13-F2 (Won/Lost roll-up) is deliberately left to #20.

## Kernels (all unit-tested)

- `src/lib/jobs/newJobDraftDirty.ts` — `newJobDraftIsDirty(form, initialSnapshot)`: content-only key over the New Job sheet (trimmed text, rows with user content with ids dropped, sorted team ids). `initial` is captured once init finishes (and re-captured after a bid prefill lands), so the suggested C#, default trade, project customer or imported bid never count as dirt. With no snapshot it falls back to `newJobFormHasBlockingContent` minus the auto-picked trade.
- `src/lib/modalStack.ts` + `src/hooks/useModalStackEntry.ts` — module-level stack of open modals; `registerModal / unregisterModal / isTopmostModal`. The hook registers on mount (skippable via `active=false` for embedded use) and returns `isTopmost()` for the Escape handler.
- `src/lib/bids/countsImportUndo.ts` — `importUndoPlan({ insertedIds, sourceLinkBefore, sourceLinkWritten })` → `{ deleteRowIds, restoreSourceLink }`: de-duplicated inserted ids only; the link restore is present only when the import actually changed it (`to: null` when the bid had none). `importUndoIsEmpty` guards the toast.
- `src/lib/jobs/crewPnlSubRate.ts` — `subRateSaveDecision(raw, current)` → `keep | invalid | save(value)`: empty or unchanged = keep (never a NULL write), ≤0 / NaN = invalid.
- `src/lib/rfq/rfqDesk.ts` — `rfqReopenStatus({ hasQuote })` → `quoted` when a quote is on file, else `sent`.

## Surfaces

1. **New Job dirty guard** — `JobFormModal.tsx` `closeForm()` now awaits `confirmDiscardNewJobIfDirty()` first (new mode only): house confirm "Discard this job?" / "Keep editing", danger style. Covers Cancel, Escape and backdrop, which all route through `closeForm`. The post-create close sets `newJobSkipDiscardGuardRef` so a saved job never prompts. One prompt at a time — a second Escape while it's up is ignored.
2. **Topmost-only Escape** — `JobFormModal` (non-embedded) and `BidWindowModal` register with the modal stack and act on Escape only when topmost, so closing New Job opened from a bid leaves the Edit Bid window open. Embedded (Job window) mode does not register — the shell owns Escape there. Other overlays keep their `escBlocked` gating unchanged.
3. **Crew P&L sub rate** (`JobsCrewPnlTab.tsx`) — label is now "Org-wide sub rate (applies everywhere) $/hr"; blur no longer saves. A "Save for everyone" button appears once the draft differs; Enter saves, Escape clears the draft. Empty never writes (the old path wrote NULL → $50 default). Save success/failure toasts.
4. **Import Undo** (`BidsCountsTab.tsx`) — `insertCountRows` returns the inserted ids (`.select('id').single()` per insert); `persistCountSourceLink` returns the link it wrote or null. Both import lanes (clipboard button + paste box) show `showActionToast(msg, { label: 'Undo' }, { durationMs: 10000 })`; Undo deletes the ids in 200-id chunks and restores `bids.count_tooling_plans_link` per the plan, then refreshes. `Toast.tsx` gains an optional `action` button; `ToastContext` gains `showActionToast`.
5. **RFQ Close link** (`RfqDeskModal.tsx`) — confirm ("Close this quote link?" naming the house, "You can reopen it from the closed list below"). The closed-requests footer now lists each request with a **Reopen link** button; reopen writes `status: sent` (or `quoted` when `bid_quotes.rfq_id` matches). The quotes select adds `rfq_id`.
6. **Send to customer** (`Estimates.tsx` `EstimateDetail` send) — one confirm naming the recipient: "Send to <email>?" (title "Send to customer?" / "Send for signature?" for change orders). Rail decision 1's $0 soft gate folds into the same ask (" The total is $0.00." + "Send anyway"). `createDraft` untouched (#14d).
7. **Dispatch Settings** (`DispatchSettingsModal.tsx`) — decision: keep the live per-row editors live (swim lanes + office schedule write for everyone on each change) and say so. A note above those sections reads "save as you go"; once either section has written during this open, the footer's Cancel gains a tooltip and an inline "Lane / office-schedule changes already saved." so Cancel is never read as undo.
8. **Telemetry** — `recordNavClick(userId, role, 'discard_guard_shown', <surface>)` with surfaces `new_job`, `counts_import_undo`, `rfq_close_link`, `estimate_send` (rows in `ui_nav_clicks`).
