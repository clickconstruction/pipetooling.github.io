# v2.1971 — Story cards 2×2 on phones (2026-08-21)

Follow-up to the v2.1966 money-move card grid: the money STORY cards'
auto-fit minimum drops 215px → `min(160px, 100%)`, so phones (≥~360px) show
the four cards 2×2 instead of a full-width stack; wide screens still cap at
4-across (only four cards exist). The Waiting card's age-bar label row gains
`flexWrap: wrap` so "under 30d …" / "90+ …" stack instead of colliding at
half width. Measured live: 375px → 2×2 (175px cards, no internal overflow) ·
768px → 4-across (was 3+1) · 1680px → 4-across unchanged; no horizontal
page overflow at any width.
