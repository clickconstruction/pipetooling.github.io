# v2.6188 — The robot's fixtures, yours to take: a window on the Counts tab (2026-10-31)

Punch list #221 (`to-dos/robot-fixtures/README.md`), PR 3 of five, the first surface: the window, the Counts tab door, the shade, Set aside and Put back, Undo. The ground is v2.6180 (the tables, `put_fixtures`, the five RPCs), the kernels v2.6181.

## What is new on a bid

- **The door.** Once the robot's run is sealed (`buildRobotStage(...).fixturesOpen` over `robot_progress()`), the Counts head draws **Robot fixtures · N** beside *Import from /Tooling* — N the rows not yet on her count and not set aside. No robot read, no button.
- **The window** (`RobotFixturesWindow.tsx`, full screen on a phone): the set line (sheets, when, found, sure, the robot's total), then the kernel's buckets — New (sure rows ticked; a *by others* / *existing* / *alternate* row and a *want a look* row unticked), On your count (Update keeps her parts and prices; starts on Keep mine), Same, On your count from the robot, Set aside — each row opening into the plan text that backs it with the robot's check, the sheets it counted on and its price each. **Add N fixtures** names its count and its foot the price (`fixtureButtonWords`); dead at nothing ticked.
- **Landing** is `take_robot_fixtures`: the rows land on the active version with the robot as a `bid_count_sources` row, so the shade is the share (`robotFixtureShade.ts`): blue tint and a rule at the left in List, By plan page and By group; the *From* pill reads **Robot**, or **Robot 2 → yours 3** once she changed the count; `plan_tag` carries the tag. The toast offers **Undo** for ten seconds (`untake_robot_fixtures`; the run stays assisted).
- **Set aside, never delete.** A robot row's trash can reads **Set aside**; the window's rows take a reason from six chips; the fold line under the sheet lists the set-aside rows ghosted with **Put back**, which lands a row again at her number.
- **The price.** Her book prices a landed row by name; where it has none the RPC lands the robot's unit price as the row's custom price. The Pricing tab's chip, reference and *Price N robot rows* door, the Robot status sheet's door, Open sheet into the Plans panel and the stage strip are the next PRs.
