# v2.3428 — Job Summary: the Days tiles carry the same since-then delta strip as Timeline (2026-09-14)

Client only; no migration, no edge function. Item 7 of [`to-dos/job-summary-follow-ups.md`](../../to-dos/job-summary-follow-ups.md) — v2.2817 promised deltas on Days and Timeline; Timeline got its strip with *As of* (v2.2807), Days never did.

## What shipped

- **Shared strip** [`JobRunDeltaStrip.tsx`](../../src/components/jobs/JobRunDeltaStrip.tsx): the `DeltaStrip` that lived inside `JobSummaryTimelineView.tsx` moved out unchanged (same pills, same three band colors, `data-job-run-delta-strip`); Timeline renders it exactly as before under a rewound chart.
- **Kernel** [`jobDaysDelta.ts`](../../src/lib/jobs/jobDaysDelta.ts): `jobDaysDeltaJumps(dayCount)` — the week chips (1 wk … 8 wk, from `JOB_RUN_AS_OF_JUMPS`) that fit inside the window, never *today*; `jobDaysDeltaSince({ ledger, statusByJob, todayYmd, daysBack })` → `{ asOfYmd, delta }` or null — merges the page's status list over the ledger's snapshot, builds today's status spans (`buildStatusSpans`) and counts with `jobRunDeltaSince`; the as-of day clamps to the window's first day like the Timeline slider. Five tests.
- **Days view** [`JobSummaryDaysView.tsx`](../../src/components/jobs/JobSummaryDaysView.tsx): new optional props `statusByJob` + `todayYmd` (the tab passes the same values Timeline gets); a row under the tiles with the strip and the week chips (`aria-label="Since"`, default **1 wk**; a chip the window cannot offer falls back to the first one). Nothing else on Days moved. New render smoke `JobSummaryDaysView.render.test.tsx`.
- Guide *see how many jobs ran each day*: a **Since a week ago** section.

## Not built

Compare-to delta lines under the Days tiles (workdays / hours vs the prior window) — Days reads the ledger directly and has no compare ledger; the strip is the since-then counts v2.2807 defined.

## Verified

Kernel + render suites, drift tests, typecheck, lint, theme check.
