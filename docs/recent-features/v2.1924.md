# v2.1924 — Billed expected-payment chips (2026-08-20)

Answers Master Technician Malachi's "when should we expect payment?" directly
on the board, so assistants self-serve instead of asking. Part 1 of the
expected-payment train (part 2: payment-forecast modal; part 3: promised
dates).

- Every invoice-bearing row in **Jobs → Pipeline → Billed Awaiting Payment**
  (desktop table + mobile cards) renders an expected-payment chip in its
  action stack: expected date = the row's bill reference date (billed_at,
  falling back to est. bill date — `printBilledRowReferenceDate`'s exact
  precedence) + the customer's median days-to-pay.
- Three states: blue "Expect pay ~Sep 8 · pays in ~35d" (on track), red
  "12d past expected · pays in ~35d" (today is past the customer's own norm —
  the follow-up trigger), muted-outline "company avg" fallback when the
  customer has fewer than 3 measurable payments in the window.
- Migration [`20260821100000_billed_customer_pay_speeds.sql`](../migrations/20260821100000_billed_customer_pay_speeds.md):
  new `get_billed_customer_pay_speeds()` RPC — the set-based mirror of the
  Customer profile modal's "pays in ~N days" rule
  (`customerProfileStats.customerDaysToPay`, v2.1322): median billed_at→paid_on
  gap per customer over invoice-linked payments in the last 12 months, plus a
  company-wide median. Gate = the board's billed-money roles (dev / master /
  assistant-like / primary); others get NULL and rows stay chipless.
- New kernel `src/lib/jobs/billedExpectedPay.ts` (+13 tests): RPC payload
  parse, reference-date precedence, date math, sample-threshold fallback,
  chip label/state. Chip component `BilledExpectedPayChip.tsx`; render smoke
  extended in `JobsStagesUnifiedTable.render.test.tsx`.
- Wiring: `JobsStagesTab` fetches the RPC once (hazmat-lookup fail-soft
  posture — an error or missing function leaves rows chipless) and passes a
  `billedExpectedPayChip` row-renderer prop to the billed section's
  `JobsStagesUnifiedTable` / `JobsStagesUnifiedCardList`.
- Help guide: `src/content/help/see-when-a-customer-will-pay.md` (new).
