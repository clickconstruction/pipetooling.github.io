# v2.3658 — Lien desk: the owner the roll found reads like the envelope (2026-09-20)

Client only; no migration, no edge function. Follows v2.3657 (the gates as numbered steps) — this is the detail block under gate 1.

## Why

The owner, from a screenshot of job 883: *"I find the way the address wraps to not be super great and the 'mail to %' is kind of confusing. And I imagine the last two lines could be on one line."* The roll returns the mailing address as one string, and the districts write "care of" as a leading `%` — `% SABRA HEALTH CARE REIT INC 18500 VON KARMAN AVE STE 550, IRVINE, CA 92612`. The desk printed it raw after *mail to*, title-cased whole (hence "Irvine, Ca"), in a sentence that wrapped wherever the pane ended; the buttons, then the chip + provenance + CAD link, took two more lines. Mocked up in the session.

## What shipped

- **Kernel** — [`rollMailingLines.ts`](../../src/lib/jobs/rollMailingLines.ts): `rollMailingLines(raw)` → `{ careOf, lines }`. A leading `%`, `C/O` or `ATTN` starts the care-of name, which ends at the street number or a PO box (a number inside the name — *7-Eleven Inc* — is not a street number); the rest splits into street line(s) and `City, ST ZIP` with the state upper-case. **Display only**: what *Use* saves is untouched. Any shape it does not recognise falls back to the roll's own string on one line — it never rearranges on a guess. 6 tests.
- **[`LienDeskOwnerPane.tsx`](../../src/components/jobs/LienDeskOwnerPane.tsx)** — the found state is an `<address>` block (owner in bold, *c/o …* muted — from the string, else the roll's `nameCare` via `careOfLine` — then the lines, each ellipsized rather than wrapped) with **Use this owner** and *Find the owner ›* beside it. One caption line above carries *Found on the roll*, the district and year, and *Check this parcel on <county> CAD ↗*. Below, `mail-elsewhere` is a plain sentence; `landlord`, `public` and `homestead` stay chips.
- **Layout** — `.lienOwnerRoll*` in [`index.css`](../../src/index.css); it sits inside the `.lienGates` container, so the same 560px container query drops the actions under the address in a narrow pane.
- Guide *send lien notices from the Lien desk* → "Needs the owner" describes the envelope and the c/o line.

## Not changed — worth a decision

*Use* still saves the roll's string as-is, so the notice itself is addressed `% SABRA HEALTH CARE REIT INC 18500 …` on one line. `%` is a postal convention the carrier understands; whether the saved address should be cleaned to match what the desk now shows is the owner's call.
