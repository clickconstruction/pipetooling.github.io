# v2.7199 — Materials on site: press a box's name to edit it, and move it in the same window (2026-11-13)

The owner's ask of 2026-11-13, looking at Jobs → Materials: click a box to edit its name and its details, quickly. v2.7179 built **Edit** with the name, the kind and the where line. This adds the two things the ask goes past it on.

## What changed

- **A box's name opens the window** on Jobs → Materials (`JobsMaterialsTab.tsx`). The name in a box's heading is a press with a dotted underline. **Edit** beside **Label** stays. Unsorted's name is plain words, since Unsorted is not edited.
- **Which place on site** in the Edit window (`EditBoxForm.tsx`, so the phone's sheet has it too): the job's places as chips, the box's own pressed, and a field for a new place.
- **The rules** (`editBox.ts`, pure): `boxPlaceChange` reads the place draft. A typed place wins over a picked one, a typed name the job already has is that place, and the box's own place is no change. `editBoxPlan` judges the fields and the place together, so the press is live when either changed and a refusal of either is said in words. `savedBoxWords` adds where the box stands now.
- **The write**: the fields through `editContainer` as before, then the move through `addPlace` and `moveContainer`, the same two the phone's **Move box** uses, so a `job_container_moves` row is kept with who moved it. Each goes through the outbox.

## Not here

- **The site view** (`?site=`) still opens a box by its link to the job's page. It has no Edit of its own.
- **A part's name or count** is not in this window. A count is **Correct…** on the line, and two spellings of one part are joined by **Same part?** on the site view.

No migration, no function. Stacked on v2.7179 (#7995), which is in the merge queue.
