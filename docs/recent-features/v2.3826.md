# v2.3826 — Put a GC on notice shows each owner their property's bills (2026-09-25)

Punch list #45, PR 3 (`to-dos/owner-portal-property-view/`): a GC run sends a notice to every owner, so the owners' portals should show those owners their property's bills when the run is approved. Client only, no migration.

## The change

- **Kernel** (`gcOnNoticeSteps.ts`): `GcNoticeChangeKey` gains `'owners'`. `gcNoticeChanges` takes `ownerJobs` and, when it is above 0, adds *Show each owner their property's bills* — *Owners' portals: their own bills only → their property's bills too*. The words are true whatever the portals show today, and the flip is idempotent.
- **IO** (`ownerBillShareIo.ts`): `shareBillsWithOwnersOfJobs(jobIds)` takes the run's jobs to each job's whole property (`ownerShareScope`, one load per property and owner), then writes `ownerShareWrites(…, true)` once. It returns the number of owners.
- **Window** (`GcOnNoticeModal.tsx`):
  - The tick defaults on. `ownerJobs` counts the run's jobs whose customer is not the GC.
  - On approval (*Approve all*, or the spoken word) it applies with the other ticks, and the toast adds *N owners see their property's bills*.
  - A failure is its own error toast, so the approval still stands.
- **Guide**: *send lien notices from the Lien desk* → step 4 describes the fourth tick.

## Tests

`gcOnNoticeSteps.test.ts` (+1: the fourth tick present with owners and absent without), `GcOnNoticeModal.render.test.tsx` (the step bar reads *4 changes*; the change list names the tick).
