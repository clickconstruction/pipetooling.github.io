# v2.3304 — Test reports PR 5: the portal's inline line, the standing card, and the signed-link door (2026-09-11)

Edge functions **`customer-portal`** (changed — redeploy) and **`open-test-report-pdf`** (new — deploy; `verify_jwt = false`); no migration. Stacked on v2.3303 (PR 4). Last PR of the train in [`to-dos/test-reports/README.md`](../../to-dos/test-reports/README.md); the owner said "showing them in the portal is a good idea" on 2026-09-11 and picked both placements from `mockup-portal.html`.

## What shipped

- **`customer-portal` payload `testReports[]`**: the company's SENT `job_test_reports` across the jobs the link already lists (owner, GC, or both per audience) — `id, jobId, jobNumber, jobLabel, jobAddress, reportLabel, title, result, testDateYmd, certifierName, certifierLicense, sentAt`, newest test first, 100 cap. Never drafts; never money, notes or the tech. The sample fixtures (`token=sample` / `sample-gc`) carry two GC rows and one homeowner row.
- **[`open-test-report-pdf`](../../supabase/functions/open-test-report-pdf/index.ts)** — `GET ?t=<portal token>&r=<report id>` → 302 to a **five-minute signed link** on the private `job-test-reports` bucket (`LINK_SECONDS = 300`, the signed-contract-copy pattern) with a download name like *Sewer Pre-Test Hydrostatic Report - 112 Seidel St - 2026-09-10.pdf*. Resolves the token exactly as `customer-portal` does (raw, then the v1 sha256 hash; revoked → 404); the report must be `sent` with a stored file and sit on a job the link's company pays for (owner / GC per audience). Sample tokens get a plain 404 line.
- **Client**: `parsePortalTestReports` in `portalPayload.ts` (+2 tests); on the statement a **Test report** line between each job's band and its bills (matched by job number, else address) — *Sewer Pre-Test Hydrostatic · PASS · September 10, 2026 · certified by Malachi Whites (#RMP41130)* with an outlined **View report** (screen-only; prints as text) — and a **Test reports** card after *Your agreements* listing every sent report, paid jobs included. Sample rows render a disabled button.

## Verified

Payload tests; typecheck · lint · theme check. After deploy: the sample GC statement (Settings → What customers see) shows the inline line and the card; on a real GC link with a sent report the button opens the PDF and the link dies after five minutes; a revoked link gets the inactive message; a draft never appears.
