# v2.2404 — Own-takeoff alternates in the Workbench (2026-08-27)

Wendi: "we need the ability to assign an alternate takeoff to the alternate
bid, so that the materials that correspond to it are calculated in the
margin." Every price option shares its version's ONE takeoff, so an
in-lieu-of alternate that changes materials showed a margin costed on the
wrong parts. Design approved on the Own-Takeoff Alternates canvas.

**No schema change** — an alternate that changes materials IS a same-GC bid
version marked `is_alternate` (versions own counts + takeoff since v2.2132;
the letter already prints version-alternates). This PR is the UX bridge:

- **＋ Add price door**: new teal choice **"Alternate with its own takeoff"**
  → name modal → `create_bid_version` (clone-all pricing, v2.2395; unsplit
  bids go through `split_bid_into_versions`), then stamps
  `is_alternate + include_in_submission` and the active version's
  `customer_id`, reloads versions (`reloadBidVersions` prop + the picker's
  reload event), and switches the Workbench onto the new alternate
  (`onSwitchBidVersion` prop → engine `switchActiveVersion`).
- **Alternate cards in the price-options row** (`sameGcAlternateVersions`
  kernel): same-GC `is_alternate` versions render as 📐-chipped cards beside
  the active version's price options — revenue is the ★ priced on ITS count
  rows (the Map modal's pattern), margin from `alternateCardNumbers`:
  bid-wide cost with ITS pre-tax materials swapped in (labor + direct costs
  stay bid-shared, the existing versions model). The materials line shows
  the "vs base" delta and an **open its takeoff →** jump (switch + Takeoffs).
- **Materials per version** are real for the 'rough' (unit-price) materials
  model (`sumRoughLinesPreTaxWithCount` on the version's own rough lines);
  'exact'-model POs are bid-wide (the documented shared-PO caveat), so those
  cards say "Materials · shared POs" and keep today's shared-cost margin.
- The row now scopes price-option cards to the ACTIVE version's pricings
  (falls back to the unscoped list when scoping would empty it) — it is
  titled "what this GC receives", and alternate versions join it as cards.

Kernel `src/lib/bids/ownTakeoffAlternates.ts` (+9 tests). Verified live on
test bid BP398: created "PEX in lieu of copper", cut a part price on its own
takeoff, and the base's row showed the alternate at 55% (its materials,
−$445.30 vs base) beside the untouched 54% base.

Help guide `price-a-bid-with-the-workbench.md` updated (GCs/prices section +
door copy).
