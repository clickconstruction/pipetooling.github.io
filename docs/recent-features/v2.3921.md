# v2.3921 — Workflow: how dates, day counts and money are printed has tests (2026-09-27)

Client only; no migration, no edge function, no screen change. Punch list **#46** row 9 (`to-dos/decomposition-queue.md`): the Workflow map's step 3, first of three PRs — the module-level helpers (`docs/WORKFLOW_PAGE_ARCHITECTURE.md` → "Module-level pure helpers"). Built on v2.3916 (step 2).

## What shipped

- **`src/lib/workflow/workflowFormat.ts`** — `formatDatetime`, `formatDateShort` (both pinned to `APP_CALENDAR_TZ`), `daysOpen`, `daysBetween`, `formatAmount` (accounting parentheses), `formatScheduledDateShort` (read at noon), `expectedDueState`. Moved verbatim, with two additions for the tests: `daysOpen` takes `now` and `expectedDueState` takes `todayYmd` as a last argument, each defaulting to the clock as before.
- **`src/lib/workflow/stepStatusStyle.ts`** — `getStepStatusStyle`. `projectsForecastColors.ts` still mirrors it with its own table; its header comment points at the new file, and a test pins the one colour the two share literally (the in-progress orange).
- **`src/utils/dateUtils.ts`** gains `ymdFromDateLike` and `ymdDaysBetween`, moved verbatim from the page.
- **`ymdAddDays`: the page's own copy gave way to the `dateUtils` export** — the one the Forecast stage modal already used for the same start / end / length linkage. A test runs the page's old rule beside it over month ends, a leap day, both daylight-saving weekends, negative and fractional lengths, and the blank string: identical. They differ only on a value neither can read (`junk`): the page's returned blank, `dateUtils` hands the value back. The expected-dates window feeds it a date field's value or the first ten characters of a date column, so that case is not reachable.
- **`src/pages/Workflow.tsx`** imports all of them; its module scope holds no helpers now. 4,276 → 4,188 lines.
- The private copies of the ymd helpers elsewhere (`ymdDaysBetween` in three Forecast files, `ymdAddDays` in four `lib/jobs` / `lib/people` files) are left for a separate pass, as the map says.
