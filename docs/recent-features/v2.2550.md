# v2.2550 — The Late chip: derived lateness on the dispatch board (2026-08-31)

Owner-approved from "The Late Chip" mockup review (options A + D). Lateness is
**computed, never filed**: first non-rejected clock-in vs the day's earliest
scheduled block start, in APP_CALENDAR_TZ.

- **New kernel `src/lib/scheduleLateness.ts`** (+9 tests):
  `computeLatenessByCell(blocks, sessions)` → per-cell map keyed like
  `userTimeOffByCell`. Rules: 15-min grace (`LATE_GRACE_MINUTES`, no entry
  inside it), labels rounded to 5 min ("Late 2h 15m"), the `title` receipt
  keeps the exact figure ("Scheduled 8:00 AM (J996) · First clock-in 10:17 AM
  · 2h 17m late (shown after 15m grace)"). No clock-in → no entry (that's the
  NCNS/call-out family's territory). Also `fetchClockInsForUsersInRange`
  (RLS-filtered — viewers without session read access just see no chips).
- **`ScheduleDispatchLateChip`**: amber informational pill (◔ glyph
  distinguishes it from the "off" chip), never interactive — nothing is filed
  so there's nothing to undo. Suppressed whenever the cell has a time-off/NCNS
  chip (one status per cell).
- **Hub People views** (`ScheduleDispatchHubPage` → `ScheduleDispatchHub`,
  both panel instances): new week-scoped clock-ins fetch beside the time-off
  refresh; blocks come from `hubWeekBlocks` (NOT the job-scoped `blocks`
  state — first live run caught that; the job-label for the receipt is the
  hub job title's leading segment).
- **Deliberately not on the job-week grid** (`ScheduleDispatchJobWeek`): it
  only loads ONE job's blocks, so "earliest scheduled start" would be wrong
  by construction there. Needs an all-jobs blocks fetch for its people first.
- Salaried caveat (documented in the review): auto-materialized sessions start
  at schedule time, so salaried people never chip.
- Verified live against prod data: two genuine Monday lates rendered with
  correct receipts (2h 55m and 2h 10m).
- Help guide `schedule-dispatch.md` + mockups artifact "The Late Chip" hold
  the design rationale. Part 2 (People-side attendance ledger, options E+F)
  ships separately.
