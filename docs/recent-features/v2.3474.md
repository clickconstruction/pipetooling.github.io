# v2.3474 — Lien instruments letterhead: a return address, not a footnote (2026-09-15)

Client only. The owner circled the top-right of the demand letter preview: the sender's bare first name on the first line, the two-line Settings address flattened into one string and re-wrapped in front of the ZIP, "phone · email" wrapping with a dangling dot, all in 7.5-pt grey.

## What changed

- **Contact column is line for line** — `letterheadContactLines(address, phone, email)` in [`demandLetter.ts`](../../src/lib/jobsDocuments/demandLetter.ts) splits the issuer address on its newlines and adds phone and email as their own lines (blanks dropped). Both letterheads take it: the demand letter's `senderBlock` and `filingLetterheadFromIssuer()` in [`lienFilingDocuments.ts`](../../src/lib/jobsDocuments/lienFilingDocuments.ts) (the § 53.056 notice, the affidavit and the release of record).
- **The sender's name comes off the letterhead** — it already signs the letter (`signature` block); a bare first name beside the company address read as a stray word.
- **The column never wraps** — `flex: 0 0 auto; white-space: nowrap` on the right column, `align-items: flex-start` on the row, in all three HTML renderers (the modal preview in [`LienInstrumentsModal.tsx`](../../src/components/jobs/LienInstrumentsModal.tsx), `buildDemandLetterEmailHtml`, `filingDocHtml`). Type 0.74em → 0.8em and `#7a756c` → `#5f5a52` (`HTML_CONTACT`); the jsPDF renderers match at 8 pt / `CONTACT` ink with a 3.7 mm line pitch.
