# v2.1970 — Roadmap rename + scrollable Checklist tab header (2026-08-21)

Two user requests from phone screenshots.

- **Rename roadmap** (there was no way before): `✎ Rename roadmap…`
  sentinel option in the picker (`ChecklistTechTreeRoadmapBar`, editors with
  a selection) → `handleRenameRoadmap` in the tab (promptDialog pre-filled,
  `checklist_tech_tree_roadmaps.title` update, `loadRoadmaps()`); RLS's
  existing editor UPDATE policy covers it. New help guide
  `create-rename-and-share-a-roadmap`.
- **Checklist tab header**: the wrapping flex row becomes
  `.checklist-tab-bar` — a one-row `.checklist-tab-strip`
  (`overflow-x: auto`, hidden scrollbar) with the `Checklist` title
  absolutely positioned top-right (`pointer-events: none`, gradient fade so
  tabs slide underneath). The active pill auto-scrolls into view
  (`data-active` + effect). Replaces the v2.1952 wrap approach.
- **Mobile toolbar**: `.roadmap-bar-label` ("Roadmap") hidden under 480px.
