# v2.3055 — Sub sheets link to jobs by id: `people_labor_jobs.job_ledger_id` (2026-09-07)

Owner request after the Team board shipped ("Help me add a sheet to job ID link"). Sheets carried only `job_number` (free text, `varchar(10)`), and ~30 readers matched it to `jobs_ledger.hcp_number` with three different rules; six of them also knew the click number, the rest did not.

- **Migration** [`20260907120000_sub_sheet_job_ledger_id.sql`](../migrations/20260907120000_sub_sheet_job_ledger_id.md): the column + index, `resolve_job_ledger_id_by_number(text)`, the BEFORE trigger that keeps link and number in step for number-only writers, the back-fill, `create_sheet_for_work_order` writing the id, and the stage → activity trigger + `superintendent_can_access_sub_work_order` reading the link first.
- **Writers** ([`JobsSubLaborFormModal`](../../src/components/jobs/JobsSubLaborFormModal.tsx)): New sheet inserts `job_ledger_id: laborPickedJobId`; Save on an existing sheet writes it only when a job is picked or the number resolved (a legacy number that resolves to nothing leaves the link alone — the trigger follows a changed number); the edit-mode instant pick writes `job.id`. [`JobsSubsWorkView.linkSheetToJob`](../../src/components/jobs/JobsSubsWorkView.tsx) writes the id plus the *effective* number (`subLaborJobNumberForStorage`), fixing the click-only job that used to write an empty number and bounce straight back to Unlinked.
- **Reader** [`fetchTeamBoardWeek`](../../src/lib/fetchTeamBoardWeek.ts): selects `job_ledger_id` with a `jobs_ledger!people_labor_jobs_job_ledger_id_fkey(...)` embed, notes the label from it, and uses the link before the HCP map — a sheet on a job with no sessions or blocks that week now sits on that job's row instead of a `sheet:` row. Test: linked-by-id fixture (`sh4`) + its label.
- **Types**: `job_ledger_id` + the FK relationship hand-typed in `src/types/database.ts`; regenerate after push.
- **Follow-ups**: the full reader/writer census with the conversion order lives in [`to-dos/sub-sheet-job-link-followups.md`](../../to-dos/sub-sheet-job-link-followups.md).
- Docs: GLOSSARY entry; guide `manage-subs-end-to-end`. **Deploy**: merge → `supabase db push` (client first is fine: the old client ignores the column and the trigger links what it writes).
