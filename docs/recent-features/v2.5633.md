# v2.5633 — A bill sent through Stripe shows in the Pipeline row's activity box (2026-10-19)

The owner, on the Michael Palmer row: the Stripe line under the name says *Email sent Thu 3:40 PM (52d)*, but the activity box beside it never shows that the bill went out. It never did: the box (`jobActivityBoxFeed.ts`) is the job's conversational trail and kept only notes and reports, leaving every event as "timeline texture" for the expanded views. A bill emailed to the customer is conversation, so it comes in. No migration; no edge function.

- **What the job already keeps**: the activity trigger (`20260608010000_job_activity_events.sql`) writes one `invoice_sent` event per bill when `jobs_ledger_invoices.sent_to_customer_at` is first stamped (`detail.channel: 'stripe'` for Stripe's email, the actor off the row when a signed-in person sent it), and the backfill's `invoice_stripe_email_sent` holds the older sends. The expanded views (`jobActivityLine.ts`) drew them as *Sent* and *Emailed* events all along; `useJobThreadNotes` already merges them into the job's activity, with realtime on inserts.
- **The feed** (`buildJobActivityBoxFeed`): an event of either kind (`SENT_EVENT_TYPES`) becomes a `sent` entry at its time, body from `sentLineBody` (*Bill emailed through Stripe*, *Bill emailed to the customer*, *Bill sent to the customer*, the channel from the detail or the summary's parentheses), author the actor's name or *The app* (`SENT_BY_APP`, since Stripe's send runs as the service role). It takes no number (`number: null`), so the notes' numbers never shift. Other events stay out.
- **The box** (`JobsStagesActivityBox.tsx`): a `sent` entry draws a small *Sent* tag in the report's blue in place of the number, aria *A bill sent to the customer*, `data-activity-entry-kind="sent"`; See all's count includes it.
- **One line per bill**: the trigger logs the first send only, so a resend refreshes the row's Stripe line (`sent_to_customer_at`) and adds no second line to the trail; Palmer's trail shows the Aug 27 send, the row's line a later resend.
- **Tests**: `jobActivityBoxFeed.test.ts` (the unnumbered line in its place, the sender off the row, the channel words) and the box's smoke (the tag, the numbers held, a payment event still out).
