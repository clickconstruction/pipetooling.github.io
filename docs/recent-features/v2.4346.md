# v2.4346 — Merge a duplicate from the desk, and restore an archived login from People (2026-10-01)

PR D1 of the *Account on the desk* train (canvas `UC4ZYvy8qDy3XLsz41TCM3`). Stacked on PR C ([v2.4344](v2.4344.md)). The merge itself needs the fix in [v2.4345](v2.4345.md) (`merge_user_accounts` named a dropped table and refused every merge since 2026-07-15). Client only.

## What was left

After PR B the desk held every per-person account control except merge, and the only list of archived logins with *Restore* was inside the Active Accounts window. Both kept that window alive.

## The change

- **[`lib/people/accountMerge.ts`](../../src/lib/people/accountMerge.ts)** (4 tests): the window's two merge paths lifted out unchanged. `previewAccountMerge` / `runAccountMerge` call `merge-users` (dry run, then the merge). `previewExternalMerge` / `runExternalMerge` fold a subcontractor's roster row with no login through the combine-people engine, or link it as the account's roster entry when the account has none. The Active Accounts window now calls the same functions, so there is one copy.
- **[`MergeDuplicateDialog`](../../src/components/personDesk/sections/MergeDuplicateDialog.tsx)**, from the desk's Status row (dev; the function is dev only): the person whose desk it is is always kept. *The duplicate* lists the accounts `eligibleAbsorbCandidates` allows (same role, archived or never signed in), plus a sub's roster rows with no login, never samples or twins; *Why isn't an account listed?* gives each left-out account its rule; **Preview merge** shows *What would move*; **Merge into <name>** asks once more.
- **People → Users → Archived** ([`PeopleUsersTab`](../../src/components/people/PeopleUsersTab.tsx)): for viewers who may archive (dev, controller, pay-approved leader; `canArchiveAccount`), a **Logins** list of archived accounts (no samples or twins) with **Restore** (`restore-user`), above the roster rows. The toolbar's count includes them; the roster reloads after a restore (`reloadRoster`).
- Guides: *merge two user accounts into one* (the desk first), *archive and restore user accounts* (Restore from People → Users → Archived).
