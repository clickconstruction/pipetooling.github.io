# v2.2732 — Preview the bid-room email from Settings (2026-09-03)

**Why.** The bid-room link email got its letterhead design in v2.2729; the owner wants to see it without sending one. Settings → Email templates & testing already has the **Outbound email catalog** — every email the app sends — so that's where previews belong.

**What.** Catalog rows can now carry a `preview` (sample-data renderer). The **Bid room link / proposal to GC** row shows a **Preview** button that opens the letter in a new tab, rendered with a sample project and three options, the brand banner from this origin, and **the viewer as the signer** (name, phone, email from their user row — the real send is signed by whoever presses send). Its subject example and "Revised … (rev N)" variant are updated to match.

**How.** App-side twin `src/lib/bids/bidRoomLinkEmail.ts` of the Edge builder (app code must not import `_shared`); `bidRoomLinkEmail.sharedParity.test.ts` asserts byte-identical subject/text/html/replyTo across three cases, so the two cannot drift silently. Sample data + renderer in `bidRoomLinkEmailPreview.ts`; `EmailCatalogEntry.preview` + `EmailCatalogPreviewContext` in `emailCatalog.ts`; the section fetches the viewer's users row and opens a Blob URL (the template "Open as email" pattern). Any other fixed-design email can add a preview the same way.
