# v2.7954 — Messages: a Drive link's preview picture is not a file to keep (2026-11-19)

Punch list #368, a follow-up to v2.7556. Client only: no migration and no function.

## The wrinkle

When a person pastes a Google Drive link into a mail, Gmail draws a picture of the link and puts it inside the mail as a file. It sits on the mail's line in Messages as a file like any other. On a job's mail whose only content was the link, **Keep this mail as a paper** showed, with nothing to keep.

A read of prod on 2026-11-19 found six such pictures on five job emails, and on all five it was the only file, beside the link itself. Every name had one shape: a long Google key, then `=w1200-h630-p.png`. No other file of any kind had an `=` in its name.

## The rule

`isInlinePicture` (`src/lib/bids/bidMailSet.ts`) now knows two names, each by the name alone:

- the signature's picture of v2.7556: *image*, up to four digits, and a picture's extension;
- Gmail's picture of a Drive link: a key of twenty or more letters, digits, dashes and underscores, then `=w<digits>-h<digits>`, any `-<part>` after it, and a picture's extension at the end of the name.

The key must be one unbroken run from the start of the name, so a name a person typed is still a file: one with a space, one with a short word before the `=`, one that is a PDF. A photo (*IMG_1893.jpeg*), a screenshot and *image001.pdf* are still files. Other Google size marks (`=s220`, `=w1200` alone) are not in the rule: prod holds none, and a rule that hides a real file costs more than a press that shows once too often.

Nothing else changed. Every caller already asked `isInlinePicture`:

- **No press** on a mail that carries nothing else: `bidMailState` answers `none`, the mail window's count leaves it out (`useEmailViewerThreadSlots`, so the job's **Keep this mail as a paper** and the bid's **Keep its files on the bid…** follow), the Development page's History line draws no *Keep its file…* (`mailLines`), and the list under the bid's Plan sets leaves the mail out (`bidMailLines`).
- **Unticked** beside a real file in the bid's form (`bidMailDraft`). A person can still tick it.

The picture is still on the mail's line, where it opens as before.

## Not in this change

- My email's reader offers **Keep this mail as a paper** on every mail tagged to a job, with or without a file. That is its own rule and it stands.
- A mail kept as a paper takes all its files into the paper's folder, a signature's picture or a preview picture among them. That was so before this change.

## Tests

Every name in them is made up.
