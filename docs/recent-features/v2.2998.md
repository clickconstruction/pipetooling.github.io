# v2.2998 — Takeoffs: a hop between views keeps the fixture you are on (2026-09-07)

Owner ask after the pill rename (v2.2990): "the flip will not carry the fixture — how do I make it feel seamless?" Before this, switching Old / One at a time / Sheet unmounted the view; One at a time re-anchored on the first uncosted fixture and the sheet opened at the top. Client only — no migration, no edge function.

## What shipped

- **Kernel** [`takeoffHop.ts`](../../src/lib/bids/takeoffHop.ts) (+9 tests): `pickHopRow(rows, touchedId, headerBottom)` — the touched row while it is still on the bid, else the first row whose top edge sits at or below the app chrome (`TAKEOFF_HOP_HEADER_PX`), else the last row scrolled past; `rowIdFromTakeoffTableTarget(target)` — the fixture a click or focus inside the shared line table belongs to (only a fixture's first `<tr>` carries `takeoff-row-<id>`, so it walks back over the sortable line rows).
- **Tab** ([`BidsTakeoffTab.tsx`](../../src/components/bids/BidsTakeoffTab.tsx)): `takeoffTouchedRowId`, set by a capture-phase pointer-down / focus handler on the shared table's `<tbody>` (so Old, One at a time and Sheet all report it) and by One at a time's focus changes; remembered per bid in a session ref, so reopening a bid lands where you left it. `switchTakeoffView` (pills and both hop buttons) now picks the hop row, then reuses the v2.2784 machinery: `viewFocusRequest` (One at a time focuses it, Sheet drops its filter) plus a second `usePendingRowFlash` that scrolls the sheet to the row and flashes it. Hops *into* One at a time do not flash — the rail highlight is the cue.
- **One at a time** ([`TakeoffFocusView.tsx`](../../src/components/bids/TakeoffFocusView.tsx)): `preferredFocusId` seeds the initial focus and the per-bid anchor; `onFocusChange` reports the focused fixture up. The strip is no longer `compact` — the same tiles as the sheet, so the top of the card is pixel-stable across a hop.
- [`usePendingRowFlash`](../../src/hooks/usePendingRowFlash.ts) takes an optional `nonce` so the same row can be flashed twice in a row (hop away and back).
- Smoke: One at a time → **Sheet view** mounts the cost rail; the two guides say the hop keeps the fixture.

Deliberately not carried: Sheet's All / Uncosted / $0 filter (it drops on a hop so the row can be found), the per-fixture unit-cost toggle, scroll position as a pixel value, and One at a time's Remember tick (it is a per-fixture decision; a hop mid-fixture clears it — tick it again on return).
