# v2.2595 — Fix: light theme's `--border` token eaten by an unclosed CSS comment (2026-09-01)

Root-caused while building the Who-owes-what bill cards (v2.2596): the neutral
age chip's new `1px solid var(--border)` outline rendered as **no border at
all** in light mode. `getComputedStyle(document.documentElement)
.getPropertyValue('--border')` returned an empty string while every sibling
token (`--border-strong`, `--surface`, …) resolved fine.

**Cause** (`src/index.css`, shipped 2026-07-12 in the token-set codemod, PR
#244): the section comment above the border tokens contained the literal text
`(border*/outline)`. The `*/` inside that word pair **terminates the CSS
comment early**; the parser then error-recovers through the garbage that
follows — which contains an unbalanced `(` — and consumes the next declaration
looking for the closing paren. The casualty was exactly one line:

```css
--border: #cfd4db;
```

So for six weeks light mode had **no `--border` definition at all**. Every
`border: 1px solid var(--border)` shorthand became invalid-at-computed-value
→ all longhands reset to initial → **no border rendered** (and longhand
`border-color: var(--border)` fell back to `currentColor`). Dark mode was
unaffected — its `--border: #374151` lives in a separate, well-formed block.
This is very likely why the owner twice darkened border tokens on 2026-08-23
(v2.2192, v2.2203, "light-mode lines too faint to separate sections"): the
lines weren't faint, the ones using `--border` were gone.

**Fix**: reword the comment so no star-slash sequence appears inside it, and
leave a NOTE in place warning against reintroducing one. No token values
changed — light mode simply gets the borders it was always supposed to have
(`#cfd4db`, the value the owner picked in v2.2203).

**Verification**: live probe in dev — `--border` now computes to `#cfd4db` on
the root; the Who-owes-what modal's row separators and card outlines render
again; the served stylesheet's rule walk shows the light-theme `--border`
declaration present.

Files: `src/index.css` (comment reword only).
