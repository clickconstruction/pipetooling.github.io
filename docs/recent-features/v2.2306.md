# v2.2306 — Pricing: Margin mode on by default (2026-08-25)

Owner request. The v2.1772 Margin mode toggle (`BidsPricingTab`, per-device
`localStorage` key `bidPricingMarginMode_v1`) defaulted OFF when the key was
unset. The initializer flips to `!== '0'`: unset (and storage-blocked) devices
now start with Margin mode ON; a device that explicitly toggled it off
(stored `'0'`) stays off, and `'1'` devices are unchanged. Verified live in
dev: cleared key → 14 per-row margin chips render and the checkbox is
checked; toggling off stores `'0'` and persists. One line — no migration.
