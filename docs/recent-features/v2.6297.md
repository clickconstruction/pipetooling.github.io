# v2.6297 — Plan sets by part: the ground (punch list #239, PR 1) (2026-11-01)

Migration only, no client change; one new punch-list card. The owner's two cases, 2026-11-01, after the read-out of the Gray Fox development's Plans look: *on a project they often get an updated set halfway through, or make their own as-builts and want to save them with the build.* The read-out found that a bid carries set rows (v2.6168) but a job holds one link, that nothing carries a set from a bid to the job it becomes, that two sets were current at once for two buildings, and that ten jobs read *on an older set* with no door to move them. The owner picked option D of four: a set belongs to a **part** of a site, each part has one set it builds from, a job names its part and follows it, a bid pins what it was priced on, and an as-built is ours, on the job, marking up the set it built from.
