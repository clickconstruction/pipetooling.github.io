# v2.3245 — Nudge a vendor from the bid's price-requests table (2026-09-10)

Client only. No migration or edge-function change.

## Why

The price-requests design (v2.3175) said the desk's actions — Nudge, Compare, Copy link — would be reachable from each row of the Edit Bid table. Compare and Copy link shipped; Nudge was left as a "Desk" link because its preview-then-send flow lived inside `RfqDeskModal`. The owner asked for it on the table too.

## What shipped

- **[`RfqNudge.tsx`](../../src/components/bids/RfqNudge.tsx)** (new): `useRfqNudge({ onSent })` — preview via `send-rfq-email` `mode: 'preview'`, send via `mode: 'remind'`, toasts, a per-request busy id — and `RfqNudgePreview`, the "This is the exact reminder — nothing sends until you say so" panel with Cancel / Send this nudge. One flow, two doors.
- **Pricing desk** (`RfqDeskModal`) now uses the hook and the panel; its `act()` keeps resend / close / reopen only.
- **Edit Bid → Price requests**: app-sent rows that are still open and have an email show **Nudge** beside Copy link and Desk. The kernel's `nudgeStateFor` applies the desk's own `canNudge` rule (no email → copy the link instead; already quoted; closed; nudged in the last 24h; sent outside the app) so the two surfaces can never disagree, and `showsNudge` decides whether the button appears at all. The preview panel opens under the row; after a send the table reloads and the request's meta line reads *nudged ×N*. The row's select gains `last_reminded_at` and `reminder_count`.
- Kernel tests pin both helpers.
