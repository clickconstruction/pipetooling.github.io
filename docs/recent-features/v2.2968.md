# v2.2968 — Help-guide audit, pass 2: bold labels and navigation paths against the components, one regression of my own undone (2026-09-06)

Follow-up to v2.2957 (categories, tokens, links, roles, routes). This pass read the guides' **bold UI labels** (1,934 label-like phrases across 239 guides) and their **"A → B → C" navigation paths** against the source, segment by segment. Content only; no code.

## What was wrong, now fixed

- **`clear-the-hours-approvals-backlog` — v2.2957 got this one backwards.** The queue-wide button in the hours approvals modal really is `Approve everything · N · Nh` (and `Approve flagged` with the Flagged-only filter on); the `Approve all N · Nh` label I substituted in v2.2957 is the *per-person* button further down. The guide's original text was right and is restored.
- **`schedule-a-sub-across-every-surface`** pointed at "Settings → My email schedule → Job watches"; the section is titled **Jobs you watch** (the watch guide already had it right).

## Found sound

- Every navigation path resolves: Materials → PO Builder, Edit Bid → Win / Loss, Bid Board → GC lines, Settings → Emails & reports → Signed agreements, Settings → Estimate customer experience defaults, People → Licenses / Pay → Employment / Paperwork → Contracts, Jobs → Subs → Pay, Projects → Forecast → Subs, Roadmap → Plan, Settings → Catalogs → Duplicates.
- Of the 111 bold phrases with no verbatim match, all but the two above are sample data (names, job numbers, dollar amounts, dates), prose concepts the guide defines ("State chips", "Per-step work order", "$ marker rows"), slash-joined option lists that exist as separate labels (Phone / Text / Email, Deck / List), or CountTooling's own buttons (Set scale, Export anyway).

## Lesson recorded

A label search must match the *same* control the guide describes, not the nearest string. The `Approve …` family in that modal has three members (week, per person, whole queue); the v2.2957 fix matched the wrong one. The checker now prints the guide sentence next to each miss so the next pass reads context before editing.
