# v2.3336 — Bid Costs refresh PR 1: the Pursuit ledger (2026-09-11)

Client only. Owner pick after the 2026-09-11 review of Bids → Bid Costs (three mockups: A Pursuit ledger, B Cost to win, C Bid vs actual — "build A, B, and C, dollars for dev/master/controller, keep card charges"). This is A.

## What changed

- **Kernel** [`src/lib/bids/bidPursuit.ts`](../../src/lib/bids/bidPursuit.ts) (tests beside it): `buildPursuitRows` folds the board's five sections to four outcomes (won = won + started_or_complete; archived unsent bids drop), reads the estimator (object or one-element array), the GC (customer else builder), the bid value (agreed wins), and sums clocked labor + card charges + materials into one pursuit cost with `$ per $1k bid`. `pursuitRowsInWindow` (90 d / year / all on the sent date, else created) and `filterPursuitRows` (outcome chips, hide-empties, hide-robots, estimator, GC, search). `pursuitSummary` (spend, hours, per bid, won / lost / open value, hit rate by value, spend on lost and its share), `pursuitByEstimator` / `pursuitByGc` / `pursuitByOutcome`. Robot bids = project names starting `ZZ Twin` / `ZZ Shadow`. Role gates `canSeeBidCosts` (dev, master_technician, controller, assistant, estimator) and `canSeeBidCostDollars` (dev, master_technician, controller) live here too.
- **Tab** [`BidsBidCostsTab.tsx`](../../src/components/bids/BidsBidCostsTab.tsx) rewritten: four tiles, the window segment, outcome chips with counts, two checkboxes (bids with no time · robot bids), search, one table with a totals row, an estimator rail (click = filter) and a by-outcome rail. `showDollars=false` hides every wage-derived column and tile and reads hours instead. Row click still selects the bid across the workflow tabs.
- **Gates** in [`Bids.tsx`](../../src/pages/Bids.tsx) (redirect, tab button, render) and [`BidPreviewModal.tsx`](../../src/components/bids/BidPreviewModal.tsx) (Scope chips) go through `canSeeBidCosts`; primaries and superintendents are unchanged.
- **Card-charge sign** — [`bidAssignedCosts.ts`](../../src/lib/bids/bidAssignedCosts.ts) reads Mercury allocations by absolute amount, the way the job side does (`fetchJobMaterialsCostSnapshot`): the bank signs a debit negative, so the old "Parts $-37.99" was a $37.99 charge subtracting from labor.
- **hh:mm** — [`format.ts`](../../src/lib/format.ts) `decimalHoursToHhMm` rounds to whole minutes before splitting, so 5.9999 h reads 6:00, never 5:60 (seen on prod for Wendi on UTSA and William on Republic Trails).
- Dropped: the Plan Pages column (field retired from the bid form), the Account Man column (GC now sits under the bid), the five stacked tables, and the blurb's escaped `→` arrows.

## Verified

Dev against prod, signed in as dev: the tab opens on the year window with 87 bids carrying time, robot rows folded; totals match the old tab's sums; the card-charge row (2903 Ticonderoga) reads +$37.99; estimator rail click filters the table. Unit tests 29, lint, theme check, `tsc -b` clean.
