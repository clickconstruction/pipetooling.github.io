# v2.8187 — Document builder: the database can keep every open of a link (2026-11-21)

Punch list #404. Taunya asked on 2026-11-21 for every link to track when it is opened, by whom, and whether that person has an account with us. For someone with no account she asked for the address the open came from, or what can be told about the device. This is the database's part alone, so it can be pushed before any code names it.

## What it adds

One table, `document_builder_link_opens`: a row each time a Document builder link is opened.

- `viewer` says who it was, as the app's public pages tell them apart: someone outside, a signed-in teammate, or the office's preview.
- `user_id` is the account, for someone signed in.
- `client_ip`, `user_agent` and `device` are for someone with no account: the address the request came from, the browser's name for itself, and a few details the page reports (language, time zone, screen, platform).
- `revision` is the revision the open was shown.

Only the edge function writes it, with the service role. A dev reads it. The link's own count, first open and last open stay as they are.

It also adds one column, `document_builder_links.ended_why`: whether a link ended because a dev switched it off, because a new one replaced it, or because the last send of its sheet was taken off a page. Taunya's call the same day was that a sheet's link closes with the last trade, and the next send has to tell that from a link a dev switched off.

The rule itself is here too, as a trigger on `document_builder_sends`: when a sheet is taken off the last trade's page, the sheet's link ends with `last_send_off`. While any trade still has the sheet the link stays. This is the one part that changes what a press does from the push on. The tab's words for it follow in the next release.

## What it does not do

- Nothing writes an open's row yet, and no screen reads one. Both come with the function and the desk in the next PR, after this file is pushed.
- It makes no script-made fingerprint. The device is what the browser reports in the open, held to 2,000 characters.
- No job clears a row. How long an address is kept is not set here.
