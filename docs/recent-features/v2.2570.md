# v2.2570 — Bill-apply chips for unapplied payments (2026-09-01)

Owner-approved mockup variants A + C
(https://claude.ai/code/artifact/5d277a33-fd35-4cac-b42f-280cdf5dc2c7). Every
payment flagged "not applied to a bill" sits on a job with 2+ open bills by
construction (v2.2240 auto-links the single-bill case), so the old fix path —
warning link → details fold → terse dropdown — hid exactly the choice it was
demanding.

- **New kernel `src/lib/jobs/paymentBillMatching.ts`** (`billChoicesForPayment`,
  8 tests): per-payment bill choices with live remaining balance (bill amount
  minus payments applied in the current form state, excluding the payment being
  placed), amount-match detection to the cent, and sort order match-first then
  oldest-sent. Match is highlight/ordering only — never an auto-apply.
- **A — inline chips** (`JobFormPaymentsTable`): the warning row becomes the
  picker — "⚠ Which bill does this $9,440.00 pay?" + one tappable chip per open
  bill (`$X bill · sent <date>` / `$Y left`, green `matches this payment`
  accent). One tap sets `invoice_id`. "Keep as job payment" collapses the chips
  to a compact "⚠ Not applied — pick bill" pill for the session (the row stays
  flagged — deliberate-unassigned is view-level only).
- **C — match bar + panel**: with **2+** unapplied payments, a section-level
  amber bar ("N payments aren't applied … don't count toward pay speed yet")
  replaces per-row noise (rows shrink to the compact pill, which opens the
  panel) and "Match payments…" opens an inline panel — one row per payment with
  its chips; balances recompute as you assign because chips read the live form
  state.
- Applied rows' fold summary upgraded: `✓ pays the $4,720.00 bill · sent Aug
  27, 2026` (was `applies to $4,720.00 bill`). The details-fold "Applies to"
  select is unchanged (keyboard path).
- Help guide `see-when-a-customer-will-pay.md` updated. Render smokes extended
  (chips order/apply/keep, bar+panel, applied summary).
- Client-only; no schema or edge-function changes — `paymentInvoiceLinking.ts`
  still decides who's flagged.
