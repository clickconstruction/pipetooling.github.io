# v2.2628 — Supply House RFQ plan (2026-09-01)

Docs-only: `docs/SUPPLY_HOUSE_RFQ_PLAN.md` (+ README index row) — the
phased build plan distilled from the 2026-09-01 design exploration
("Supply House Pricing Requests" canvas, artboards 6–7) and its deep
review. Key commitments: unit-price-centric quotes with snapshot/drift
handling; name-keyed price memory (`supply_house_fixture_prices`)
instead of over-promised cost/price-book writes; three intake lanes
(link / pasted / typed) on one store; honest coverage-aware compare with
a cost-side baseline (never the sale price book); lane B (system-sent
RFQ desk) explicitly deferred. Phases: 1a migration+kernels, 1b Plug-in
modal + compare panel, 2 quote-link lane (edge functions + mobile
vendor page), 3 price-memory surfacing; deferred list includes PO
Generator handoff and apply-to-costs.
