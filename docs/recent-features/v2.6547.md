# v2.6547 — By theme: read an HR file one theme at a time, open each item in a window over the list, and print or copy the theme for counsel (2026-11-05)

Punch list #269, PR T3. The marks (v2.6546) put a theme on the record; the investigation is reading one theme whole, in order, each item opened without losing the place in the list. The owner's words: "investigate all the evidence that makes up a theme and isolate the view for a user to a particular theme, and on that page click on some evidence to look at the greater detail in a modal without leaving that place in the page." No migration.

## What changed

- `supabase/functions/_shared/legalThemes.ts`: `ThemeLine` and `ThemeItem`, `themeItems` (the theme's items from the lines and the marks, oldest first or strongest first — by a document before their own words before firsthand before relayed, the ungraded last — narrowed to the items with a file, one grade or the proposed), `themeItemsHeadWords`, `itemKickerWords`, `nearbyLines` and `themeListText` (the theme as a plain-text list for counsel).
- `src/components/people/personFile/PersonThemesView.tsx`: the view — the theme chips with counts, the definition and counsel's words, the two count cards, Show and Order, the item list, Print this theme (`printHtmlInNewWindow`, light theme) and Copy as a list for counsel (the clipboard), and the **item window** over the list: kicker, body, files through the panel's chips, every theme on it with Keep and Take it off…, the nearby lines, Open on the Timeline, Previous / Next, ← → and Escape.
- `PersonFilePanel.tsx`: the **By theme** tab (drawn for a dev once the catalog has a theme, with the count of things marked), `openOnTimeline` (every filter off, the line scrolled to and lit for a moment), and the pick kept with the address's theme first. `PeopleHrTab.tsx`: `?theme=<id>` opens the file on that theme, and a pick writes it back with `replace`, so a link reopens the same isolated view.
- The guide *keep private employee files* gains *Read the record by theme*; `HR_FILES.md` → Themes on the record carries the view.
