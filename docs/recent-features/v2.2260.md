# v2.2260 — Actuals vs estimates (2026-08-25)

Closes the loop on the cost lens (v2.2250/v2.2258): what we guessed vs what it
really took, captured without ever asking the person who did the work.

## Data

Migration `20260825012232_checklist_cost_actuals.sql`: `checklist_item_costs`
gains `actual_hours` (CHECK > 0), `actual_recorded_by_user_id`,
`actual_recorded_at`. Same dev/controller RLS. **Deploy order matters**: the
client's estimate select reads `actual_hours`, so the migration must be applied
before (or with) the client deploy. Kernel additions in
`checklistCostEstimate.ts` (+tests): `actualDollars`, `estimateRelativeBands`
(bands derived from the estimate — ~half / as-estimated / ×1.5 / ×2, snapped
to half-hours), `estimateAccuracy` (hours-weighted), `estimateAccuracyByPerson`,
`formatMultiplier`, `ACCURACY_MIN_COUNT = 5`. Store: `writeChecklistCostActual`
(estimate upserts never touch actual columns).

## Capture (the one design rule: the doer is never asked)

- **Sign-off queue** (`ChecklistReviewInboxSection`): costed rows grow an
  `est $100 · 2h` chip + "Took about" band buttons for dev/controller.
  One tap records; tapping the selected band clears; **an untouched sign-off
  records nothing** (no silent "as estimated" — rubber-stamped data would fake
  ×1.0 calibration). Sign-off itself is unchanged and never blocks. Queue rows
  carry a `costKey` (`checklistReviewQueue.ts`, bridge-aware).
- **After the fact**: the cost modal on any estimated task has an "Actually
  took" section (same bands + free input + clear) — the correction and
  late-entry path.

## Read side (ships now, self-gating at ≥5 actuals)

- **Truth tag** beside the gold chip: "was $200 · ×2" red over / green under
  (`ChecklistCostButton`); tap to correct.
- **Hint** while composing an estimate: "📐 Estimates have really run ×1.6
  (11 with actuals) — 2h may be closer to 3h ($150)" — advice, never
  autocorrect; hidden inside ±15% of true.
- **Calibration strip** under the Review sign-off fold: overall multiplier +
  top-3 per-person, one line, dev/controller only.

Help guide *put a cost estimate on a task* updated with the actuals flow.
