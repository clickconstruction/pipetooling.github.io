# v2.1972 — Pin Mode gates the page pin footer (2026-08-21)

Owner request: the page-bottom pin footer (Pin / Pin bid / Pin for… / full-screen strip in [`Layout.tsx`](../../src/components/Layout.tsx)) now renders only while **Pin Mode** is on — a new gear-menu toggle alongside Job/Dispatch/Farm Mode. New [`pinModeToggle.ts`](../../src/lib/pinModeToggle.ts) + [`usePinModeEnabled`](../../src/hooks/usePinModeEnabled.ts) mirror the Farm Mode pattern exactly (per-user localStorage key `pin_mode_<userId>`, off by default, cross-tab sync via storage event + same-tab `pin_mode_changed` event). Existing pins are untouched: the Dashboard quick bar, pin navigation, and Settings management don't gate on the mode — only the footer's visibility does. Gear row checkbox uses indigo (#6366f1) to match the pin button's accent. New help guide `pin-mode.md`; `settings-basics.md` cross-links it. Verified live: footer absent by default, appears on toggle-on, disappears + key removed on toggle-off. Client-only — no migration.
