# v2.5073 — Lien desk: preview the courtesy email before the run is recorded (2026-10-09)

The ask of 2026-10-09: on the Record the mailing window, after *Courtesy PDF to javier@spcrgv.com, emailed when the run is recorded*, a button that opens in a new tab and shows what that email looks like. The same day: the email ends with *For questions call the office: 512 360 0599*.

## What changed

- **The door** ([`LienDeskRunModal`](../../src/components/jobs/LienDeskRunModal.tsx)): the courtesy line ends with **Preview the email ›** (`run-courtesy-preview-<n>`).
  - It sits outside the tick's label, so pressing it never flips the box. Its hover: *Opens in a new tab, as <email> would get it. Nothing is sent.*
  - It waits while the window reads the bills the PDF carries (*Preview the email · reading the bills…*). `enclosuresRead` turns on once the first read ends and stays on, as the record uses what is read.
  - `previewCourtesy` opens the tab inside the click (`openHtmlWindowWhenReady`), which reads *Loading the page…* while the PDF builds. A blocked popup toasts.
- **The kernel** [`lienRunCourtesyPreview.ts`](../../src/lib/jobs/lienRunCourtesyPreview.ts):
  - `runCourtesyEmails(env)` lists what the envelope's tick sends: one email per original contractor's copy with an email on file, in packet order. Never an owner's, and none when the envelope itself goes by email.
  - `runCourtesyPreviewHtml` draws the tab. A strip says nothing has been sent and when it goes, or, unticked, that it will not go. Then each email: the subject, From (`COMPANY_EMAIL_FROM_LABEL`), To, *when the run is recorded*, the body as sent, and the PDF in a frame with *Open it in its own tab ›*. Several emails are numbered *Email 1 of 2*. Every value is escaped.
- **One body for both** [`_shared/lienFilingEmail.ts`](../../supabase/functions/_shared/lienFilingEmail.ts): `lienFilingEmailHtml` (the paragraph `send-lien-filing-email` wrote inline) and `lienFilingAttachmentName` (its file-name clean). The function imports both.
- **One PDF for both** (`lienDeskRunIo.ts`): `buildRunNoticePdf` is the half of the send that stacks the copy's PDF: the form, the release, the pay page, the unpaid bills. The send and the preview both call it.
- **The words** (`runCourtesyEmailWords`, `lienDeskRun.ts`): the text ends *For questions call the office: (512) 360-0599*. The number is `PORTAL_COMPANY.phone`, the letterhead's, so it changes in one place; the app's other customer emails print it the same way. A blank number leaves the line off.
- **Guide** [`send-lien-notices-from-the-lien-desk`](../../src/content/help/send-lien-notices-from-the-lien-desk.md): **The courtesy email.** under *Sending the run*.
