# v2.4743 — Lien desk: the Skip button is gone (2026-10-07)

Client only. The owner (2026-10-06), on the draft footer's *Skip Jul + Aug…*: *why would anyone choose to announce they decided not to lien some months?* … *remove it.*

## Why

Skip wrote a `missed` row with a `skipReason` before the window closed, so the desk stopped offering those months. Nothing went outside the company, and nothing was waived in law: only the window closing loses the right. Hold (the master's, with the desk asking again before the deadline) and Note it as missed (after the window closes) already cover waiting and the record, so Skip was an irreversible control next to Save draft whose only gain was a shorter To draft pile.

## What changed

- `LienDeskModal`: the footer's Skip link, its reason row (`skipOpen`, `skipReason`, *Skip these months*) and the `skip` handler are gone. *Already mailed? Record it…* keeps the `.lienFootSkip` style.
- `lienDeskIo.ts`: `skipLienDeskItem` removed (no other caller).
- Kept: old skips still read back. `lienMonthHistory` / `lienMonthGrid` read `fields.skipReason`, and `LienDeskMonths` draws the yellow *skipped* chip with who and why.

## Tests

- `LienDeskModal.render.test.tsx`: the ready-footer smoke now pins that no Skip button is offered.

## Docs

- Guide *send lien notices from the Lien desk*: *Skipping a month* becomes *A month nobody sends*; the roles list drops skip; `docs/LIEN_DESK_ARCHITECTURE.md`.
