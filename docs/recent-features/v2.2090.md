# v2.2090 — Roadmap Timeline what-if dial (ghost flag on the calendar) (2026-08-22)

Follow-up to v2.2089 (calendar header from observed pace). Owner wanted the interactive what-if back; the old slider's sin wasn't existing but being **unanchored** (arbitrary default, persisted per browser, fantasy dates styled as fact). The dial returns fixed:

- **Kernel** (`src/lib/roadmapCalendar.ts`): `CalendarBand` gains `horizonStart`; new `bandFraction(band, date)` places any date on the band as a clamped fraction (+ tests).
- **View** (`ChecklistRoadmapTimelineView.tsx`):
  - `whatIf` state — **ephemeral, never persisted** (the old `roadmap_timeline_pace_v1` persistence is what let a what-if masquerade as truth). Slider (1–20) defaults to the observed pace, rounded/clamped; a `▲ you` tick sits on the track at the real pace (clamped into range); `clear` resets to null.
  - Active dial renders a **dashed blue ghost line** on the calendar labeled `what-if ≈ Mon` (label side-flips past 80%; position via `bandFraction`, pinned at 0.985 beyond the horizon), and the caption appends `· what-if N/week ≈ Mon` in link-blue. The solid 🎯 real-pace flag/caption never move.
  - **No-pace roadmaps** (no completions yet): the dial alone stretches the band months and draws the only flag — dashed, captioned "no completions yet, so this is only the dial". Restores exploratory dates for brand-new roadmaps without faking authority.
- Help guide `read-the-roadmap-timeline.md`: "The what-if dial" section added.
