# v2.7223 — Paint a map: share it with a link (2026-11-13)

Punch list #345, PR 4. A painted map is mostly for people who have never been to the job: a customer, a delivery driver, another trade. None of them has a login. This PR is the link they open.

## What changed

- **Share** on a saved map with something on it, for whoever painted the map and for the office. It opens **Share this map** (`PaintedMapShareSheet`).
- **Make a link** asks the `painted-map-link` edge function for a ten-letter code. The sheet shows the address, `/way/<code>`, and three ways to hand it over: **Copy the link**, **Send it another way…** (the phone's own share sheet, shown only where the browser has one) and **Show a code to scan**, for someone standing beside you.
- **The sheet says what the reader gets before the link goes anywhere**: the name, the lines, and the places with their words and photos; not who painted it, not when, and nothing else about the job.
- **The page** `/way/<code>` (`PaintedWay`, outside the Layout, light, on the portal's paper): the company's name, the map's name and words, the lines and numbered places on the same canvas the app draws, each place with its words and its photo, each line's length with its give or take, and **Directions to the start**.
- **Show where I am** on the page puts the reader's own dot on the map and says where they stand: *You are at the start*, *You are on the painted line*, or *The start is 350 ft east of you*. It is asked for on a press, it is worked on the reader's phone, and it is sent nowhere. The page says so under the dot, every time.
- **End this link now**, behind a confirm that names the act. A link also ends by itself ninety days after it was made. An ended link, an expired one and a wrong code read the same: *This map is no longer shared. Ask whoever sent it for a new link.*
- **The sheet says whether a link is out**, since when, and how many times it was opened. Not by whom and not from where: the table keeps a count and two times.
- **What customers see** (Settings) gains a step, *A painted map*, that opens `/way/sample`: a made-up map that reads no link, table or function.
- The guide `paint-a-map` gains **Share a map**.

## How it is held

- **`painted_map_links`** (`docs/migrations/20261114010000_painted_map_links.md`) keeps a link's SHA-256 and never its code. Whoever reads the map reads the row; nobody signed in writes one.
- **`painted-map-link`** (`docs/EDGE_FUNCTIONS.md`) is the only door for a signed-out reader. It answers with what `sharedPaintedMap` builds, field by field, and a test holds the list: a new column on a map, a line or a place reaches the page only when somebody adds it there on purpose. No job, no development, no address, no name, no date, no storage path.
- **A photo** is served by the function for a place on the link's map and nothing else. The page never receives a signed storage address.
- **Making and ending a link** is checked in the function against the caller's own RLS: they must read the map and be its maker or the office. An archived account, an account in training and a twin are refused.
- **Wrong codes** are counted through the estimate link's guard, and the twenty-first in an hour from one connection is told to wait.

## Is this the best we can do

- **The code is kept as a hash, so a link can be read only on the device that made it.** The card drew the link sitting on the map for anyone in the office to copy again. That needs the code in a table, where a backup or a careless query hands out every customer's way in. The sheet instead remembers the link on the device that made it, says so when it meets a link made elsewhere, and makes another on a press. Several links a map are fine: each ends by itself.
- **Show where I am frames the reader and the map together.** The first build slid the map onto the reader's dot, as the painter's own walk does, and the headless walk showed a blue dot on an empty field with the line pushed off the screen. A reader is looking for the line, so the picture now zooms to hold both, and frames again when the dot walks out of it. Past about a mile and a quarter the picture stays on the map and the words say how far the start is.
- **A link that was just made vanished.** The sheet forgot a remembered link once no link of the map was open, and it judged that against the list read before the press. The render test caught it; the list is now read before the new link is shown.
- **No gate codes.** A link carries whatever is on the map to whoever holds it. The place sheet has said since PR 2 not to put a code on a map, and the guide says it again beside Share.
- **Ninety days, not seven.** First look's link lives a week because it asks for photos once. A way in is used by every delivery until the house is done.

## Not in this PR

- **Text it…** from the company's number. The phone's own share sheet already texts from the sender's phone. Texting from the company line means a new moment in `TellCustomerSheet`, and it comes with the rest of *Sending it beyond the app*: a picture, a page to print with its code, Save as PDF and File it on the job's Drive folder.
- `.kml` and `.gpx` files, a task's place carrying the map, and the layer on the Map page: later PRs of the train.
