## Is this the best we can do?

1. **One map, drawn once**: the lens is the picker's component with a flag, not a second drawing — zoom, pan, labels, the dots, the county file and the hues are the same code, so the two never disagree about where a case is or whose county it sits in.
2. **A view, not a window**: the map needs the room the rail and the account use, and it is the same desk; a case tapped there lands under Accounts on that account, with nothing to close.
3. **The firm's dollars where the firm's name is**: the legend row is the firm's counties, cases and money in one line, the number PR 4 hands the firm's portal.
4. **Cut**: the stage filter (the key under the map is enough while the desk holds a dozen cases), pins for the jobs of a closed matter (off the map, as on the picker), and a deep link to the Map (the desk opens on an account; the Map is one press away).
