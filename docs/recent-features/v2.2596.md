# v2.2596 — Who owes what: bill cards with job address + scoped line items (2026-09-01)

Owner request on the Waiting on Customers → "Who owes what" modal (v2.1929):
"I would like to see the address and line items." Built from three mockups
(canvas artboards A/B/C); the owner picked **Option C — bill cards**, plus the
neutral-chip visibility fix flagged during mockup review.

## What changed

`BilledByCustomerBreakdownModal`: expanding a customer group no longer renders
per-bill table rows — it renders one `colspan=4` row holding a stack of
**cards**, one per bill:

- Header: job name (600 weight) + subline `jobNumber · <pin icon> address`
  (`stripTrailingZip`, same as the Dashboard AR modal); amount +
  age chip stacked top-right.
- Line items: `label` / `$amount` rows in the Dashboard-AR idiom
  (12px, `--text-700`, `formatCurrency`). Labels **wrap**
  (`overflowWrap: anywhere`) instead of nowrap-ellipsis — a nowrap span's
  min-content inside the auto-layout table widened the table past the modal
  (hit live with a long narrative fixture name).
- Footer: "View on board" button (existing outline-blue style) → same `onOpenBill` jump.

## Kernel (`billedByCustomerBreakdown.ts`)

`BilledBreakdownBill` gains `jobAddress` (trimmed `jobs_ledger.job_address`)
and `lineItems: ArLineItem[]`:

- Scoping reuses **`fixturesForInvoiceBill`** (`invoiceScopedFixtures.ts`, the
  bill-composition rule): the invoice's linked fixtures, else the primary
  bundle's exact-sum unlinked set.
- **Whole-job-proration fallback is suppressed** for invoice rows: when no
  fixture belongs to the invoice (and it isn't the bundle's unlinked-only
  case), `lineItems` is empty — listing the whole job's lines at real prices
  under a partial bill oversold what the bill asks for (live example: a
  $13,420 partial showing $56,200 of lines). Job-shell rows list all billable
  lines.
- Formatting extracted to `arLineItemFromFixture` in `arModalLineItems.ts`
  (shared with `buildArLineItemsByJob`; billable rule unchanged: non-empty
  name AND count × unit > 0; `×N` suffix above 1).

No new fetches: Stages board rows already batch-load `fixtures`
(`enrichJobsLedgerPrimaryRows`) and carry `job_address`.

## Chip fix

`ageChip` neutral (<30d) chips were invisible as pills — `--bg-subtle` on
`--bg-subtle` rows. All chips now carry a transparent 1px base border
(constant height); the neutral one gets `1px solid var(--border)`. (Rendering
this surfaced the light-mode `--border` token bug fixed separately in
v2.2595.)

Tests: `billedByCustomerBreakdown.test.ts` — address passthrough, linked-only
scoping + `×N` labels + non-billable drops, bundle exact-sum vs job-shell,
suppressed whole-job fallback. Help guide `read-the-pipeline-money-view.md`
updated.
