# v2.4512 — Pipeline: a stage bar that stays with you, and colored section headers (2026-10-04)

Client only; no migration, no edge function. The owner's read of Jobs → Pipeline: the headers for Waiting, Working, Ready to Bill and Billed Awaiting Payment do not stand out, and there is no easy way to jump between them while scrolling. One mock-up, picked the same day.

## What changed

- **The stage bar.** [`JobsStagesJumpStrip.tsx`](../../src/components/jobs/JobsStagesJumpStrip.tsx) was a centered row of underlined links with arrows between them, which scrolled away with the page. It is now a bar of segments — dot, name, then *count · $total* — that owns the whole row (the ☰ tools menu as `leading`, the *Back to board* pill as `trailing`), sticks to the top of the window (`.stagesStageBar`, under the page's tab strip where that strip sticks), and lights the segment of the section being scrolled through (`aria-current="location"`). The aria-labels are unchanged (*Jump to Working, 29 jobs*). An empty section stays in place, greyed; Collections still shows only while it has rows.
- **Where you are.** Kernel [`stagesStageBar.ts`](../../src/lib/jobs/stagesStageBar.ts): `stagesActiveSection` picks the last header, in board order, whose top has reached the line under the bar; the component measures on scroll, one read per animation frame.
- **Where a jump lands.** The bar writes `--stages-jump-offset` (its own height + what sits above it + 8 px) on the document; `.stagesSectionBand` reads it as `scroll-margin-top`, so `focusStagesSection`'s `scrollIntoView` puts the header just under the bar instead of behind it.
- **The dollars.** `jumpStripTotals` in [`JobsStagesTab.tsx`](../../src/components/jobs/JobsStagesTab.tsx) runs the headers' own `stagesSectionHeader` (live once the scope is merged or a search is on, the stats layer before that, "…" before either), so the bar and the header never disagree.
- **The section headers.** All six are `.stagesSectionBand`: a 4 px bar and a light tint in the section's color (`STAGE_BAND_COLOR` — the map pins' `jobsLedgerStatusDotColor`, red for Collections, green for Paid in Full). `StagesSectionBandTitle` draws the name, the count in a pill and the dollars; the header used to read *Working (29) - $391.8k*. Everything else on each header (the schedule pills, the aging chips, the section buttons) is where it was.
- **Phones.** The phone board never drew this strip (`JobsStagesPhoneStrip` is its own) and hides the section headers; nothing changes there.
