# v2.2085 — Bid-tab Learn panel + Workbench win-odds (2026-08-22)

The payoff half of the v2.2081 bid-tab capture (owner picked mockup Variant B +
the calibration-strip feed-forward). Two surfaces, one kernel.

- **Kernel `src/lib/bidLossLearn.ts`** (+9 tests): from lost bids with recorded
  tabs — % over the low (`overLowPct`, null when at/below the low), median +
  p25/p75, delta buckets (0–5/5–10/10–20/20+), rank-from-the-bottom buckets
  (#1 shown only when it happened), per-quarter medians (last 6 with data),
  per-GC rollup sorted closest-first with read chips
  (`razor`/`close`/`mid`/`far`, thresholds 4/8/12), low-bid-loss counter
  ("we were the low bid and still lost"), All/12mo/6mo window slicing.
- **`BidLossLearnPanel.tsx`** — "Why we lose on price — what the tabs say",
  rendered under the Why we lost reason rollup: hero median + honest coverage
  line ("tabs on N of M lost bids"), three CSS mini-charts (delta histogram,
  rank landing, quarterly trend — the last two hide until they have data),
  per-GC table, time pills, and a first-run empty state pointing at both
  capture doors. Scopes with the lens's existing "bids by" estimator select.
- **Workbench calibration strip** (`BidsPricingTab.tsx`): amber ▽ marks at
  `marginPctToMatchTabLow(bid_tab_low, est_cost)` for every recorded tab in
  the trade (excluding the bid being priced), a legend entry, and a win-odds
  line — "At X%, this number would have matched or beaten the low on A of B
  recorded tabs" (`countTabsMatchedOrBeaten`, half-point tolerance like the
  strip's other counts) — plus this GC's needed range when ≥2 of their tabs
  are on file. Strip helpers live in `bidTabCapture.ts`.
- **Migration `20260822143810_bid_pricing_history_tab_low`** — the RPC returns
  `bid_tab_low` + `customer_id` (pass-through; DROP + CREATE since the return
  type changes). Client guards make both optional, so either deploy order is
  safe. See `docs/migrations/20260822143810_bid_pricing_history_tab_low.md`.
- Help guides: workbench guide documents the strip + tab marks;
  `follow-up-with-builders.md` already covers capture.
