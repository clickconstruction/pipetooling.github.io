# v2.6526 — Every stint a returner worked shows on their desk, and tenure counts from the day back (punch list #256, PR 5) (2026-11-04)

Punch list #256's fifth PR (`to-dos/bring-back-a-teammate/`), the last before the Away note train. PR 2 (v2.6481) kept every stint in `employment_stints` with the roster row's pair as the current one; PR 3 (v2.6523) opens a new stint on Bring back. This PR is the readers: the owner's call 1 of 2026-11-03, tenure from the day back, with the earlier stints in view.

## What changed

- **The kernel** `src/lib/people/employmentStints.ts` (`employmentStints.test.ts`): `stintRows` (the desk's lines, newest first, each closed stint with its length and the away gap between two stints, nothing for one stint), `stintRange`, `earlierStintsLine` (*before: Mar 4, 2024 to Nov 3, 2026*), `spanWords`, `tenureLabel` (moved from the HR tab, unchanged), `inAnyStint`.
- **The desk's Employment row** (`PersonDeskPaySection`) reads `employment_stints` and lists the rows under the pair when there is more than one.
- **People → HR** and **People → Pay → Employment** read the selected person's stints and name the earlier ones after the tenure (*started Nov 5, 2029 · 0m · before: Mar 4, 2024 to Nov 3, 2026*; *These dates are the current stint. They were here before: …*). Both already counted tenure from `people.start_date`, the current stint, as does `list_team_member_start_dates` for the Reflect card; nothing there changed.
- **The salary clamp** (`salariedPayrollDays.ts`): `SalariedPayrollWindow.stints`, loaded with the window; with two or more stints a day pays when it falls inside any of them, so a first-stint week regenerated after the return is not clamped to zero by the current pair (the review note on the card). One stint leaves the pair as the clamp. The server-side sync (`salary_sync_one_user_clock_sessions`) still clamps to the current pair; it makes sessions for today and upcoming days, which are always in the current stint, so a migration is left for the day a past week must be regenerated server-side.
- **Guides**: `manage-employment` and `bring-back-a-teammate` say what the stints mean for tenure and pay.
