# v2.2154 — Price options per GC (Bids by GC, G1) (2026-08-23)

Owner's model (stated 2026-08-23): **versions = a packet for one GC; varied pricing = what you send that GC.** Proposal: claude.ai/code/artifact/a2878573-eb4d-47d9-abaf-e4cbd942a811; approved prototype: claude.ai/code/artifact/ce7e9a39-5bfb-4ba3-88d2-42abfe991a9f. G1 is client-only.

- **Workbench (`BidsPricingTab.tsx`)**: structure bar reads "This GC — {GC}" (version's `customer_id` name, else the bid's GC; `gcNamesById` fetched per bid) / "Price options — what {GC} receives" / labor & cost shared. Scenario cards gain a third state: **★ base** (the version's ★, now resolved from `bid_versions.starred_price_book_version_id` first — `customerFacingPricingId`), **offered · alternate** (`price_book_versions.include_in_submission` on a non-★ scenario), or not offered. Buttons: **Offer as alternate / Don't offer** (`setScenarioOffered`) and **☆ Make base** (renamed confirm; making base clears the scenario's offered flag). The door's "Another price point" opens a modal — name (default "Alternate N"), start-from scenario, "offer right away" — `createPriceOption` (replaces `duplicateWorkbenchScenario`'s "X copy"). A version with no scenarios shows **"No prices yet for {GC}"** with **Copy {other GC}'s base price** (clone of that version's ★ via `cloneTemplateIntoBidAndActivate`).
- **Kernel `coverLetterVersionBundle.ts`**: `planLetterSections` adds each included version's offered non-★ scenarios as alternate sections ("{version} · {scenario}", `offeredPricingId`), priced on that version's counts (+1 test).
- **Cover Letter (New)**: **one tab per GC** (versions grouped by effective GC; tab shows sent state); the list is that GC's versions with, under each, its non-★ prices as checkboxes = offered; summary "{GC}: base $X + N alternates"; **Mark sent to {GC}** stamps only that GC's bids and is disabled until it has a base price; the letter preview follows the selected GC (packets). Old's GC pills hide in New. `toggleVersionInclude` now mirrors only the ★ scenario's flag (other scenarios' flags = offered).

Verified live on BP364 (Take 5 Beaumont — GC Southern Post Construction; versions SPC w/o prices and BURD & ASSOCIATES): bar copy; SPC gate with "Copy Burd & Assoc.'s base price"; "Another price" → "Sharpened" created from BURD, offered, card tag + letter alternate section + per-GC tab row; un-offer/re-offer; Mark sent per GC (SPC disabled). Test scenario deleted afterwards. Next: G2 (GC-grouped picker + "+ Another GC…"), G3 (per-GC outcome, board rows), G4 (words).
