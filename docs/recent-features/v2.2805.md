# v2.2805 — Contract Forms PR 10: forms Click authors itself — Direct Deposit Authorization and the four Texas statutory lien waivers (2026-09-05)

The first forms that are not somebody else's PDF: Click writes them, and the generator writes the PDF and the schema together so the two can never disagree.

- **`npm run forms:author`** (`scripts/forms/author/`): `lib.ts` is a small page model on pdf-lib — letterhead, title, wrapped paragraphs, labelled field rows, inline checkbox rows, signature blocks — that records every box it draws into a `FormSchema`. `company.ts` holds the company block printed on every authored form (change it, re-run, re-upload). Outputs are committed under `docs/forms/authored/` so the exact PDF a person signed can always be re-created.
- **Direct Deposit Authorization** (`direct-deposit-authorization.pdf` + schema, 14 boxes): employee name and phone (prefilled), bank name and city, **routing number** (nine-digit mask) and **account number** as sensitive boxes that live only in the signed PDF, account type (checking / savings, exactly one), how much to deposit (entire net pay / fixed amount, exactly one; the amount box and a notes box under *rarely needed*), the authorization paragraph, and the employee's signature + date. English and Español labels.
- **Texas statutory lien waivers** (`lien-waiver-{conditional,unconditional}-{progress,final}.pdf` + schemas, 10–13 boxes each): Tex. Prop. Code **§ 53.284(b)–(e)** reproduced verbatim (pulled from the statute text, added by Acts 2011, 82nd Leg., R.S., Ch. 271 (H.B. 1456), Sec. 3, eff. January 1, 2012), each statutory blank a box with its parenthetical caption under the underline. Written for a **subcontractor signing to Click**: the maker of the check and the person the signer contracted with are constants (Click Plumbing, LLC); the payee and company name prefill from the roster; project, job no., owner, location, job description, amount, and title are typed; signature + date. On the unconditional forms the statutory **notice** is printed in bold at 11 pt and nothing on the page is set larger, as (c)(1) / (e)(1) require. A `paragraphWithBlanks` renderer wraps statutory text around unbreakable blanks.
- **Not yet published.** These are Click's own wording (deposit) and a statutory text (waivers) the owner asked to review first; publishing is the studio's normal import (deposit → All Teammates; waivers → a packet with no assignees so they are sent one-off per payment).
- **Follow-up noted**: per-job facts on a waiver (project, amount, owner) are typed by the sub today. A send-time prefill (the office types the facts when sending; stored as initial values) would make waivers exact — the same need the I-9's first-day date has.
