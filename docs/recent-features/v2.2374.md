# v2.2374 — The package map: every GC, version, and price in one tree (2026-08-26)

Estimator request (Wendi): "click at any time and see a map or a tree of the
GC's versions and prices." The structure of a multi-GC bid (packets →
versions → price options) was only visible in fragments — the Send to strip
names packets, the price tray shows one packet at a time, and the ⓘ popover
explains the concept with no data.

- **Kernel** `src/lib/bids/bidPackageMap.ts` (+tests):
  - `computeSharedBidCost` — the Pricing tab's totalCost formula as a pure
    function (materials + labor + driving + estimator + team labor + travel +
    the five direct-cost segments); null (→ margins hidden) with no estimate.
  - `buildPackageMap` — assembles the tree from bid_versions +
    price_book_versions via `groupVersionsByGc`: per version, its ★
    (starred_price_book_version_id) leads, then its stamped options;
    status = base / alternate (include_in_submission) / private; margins
    against the shared cost; pricings no version claims land in an
    "unattached" group instead of vanishing; unsplit bids synthesize one
    implicit version with the ★ from bids.selected_price_book_version_id.
- **`BidPackageMapModal.tsx`** (new): read-only tree modal. Fetches the bid's
  pricings, sends, counts, assignments, custom prices, hides, and entries,
  and computes revenue per price with the cover-letter kernel
  (`computeBidPricingRows` on the version's own counts) so numbers match what
  each GC receives. GC lines carry sent date/value and won/lost; "viewing"
  chips mark the current version/price. Esc/backdrop/Close all close.
- **`BidVersionPicker`**: new optional `onOpenMap` renders the 🗺 Map button
  at the strip's end (all four strip tabs: Counts, Takeoffs, Pricing, Cover
  Letter).
- **`Bids.tsx`**: `openPackageMap` (loads Pricing data for the bid when its
  cost isn't in state, so margins fill in), `packageMapSharedCost`, and
  `openPriceFromPackageMap` — click-through VIEWS the price via
  `setSelectedPricingVersionId` (session-only; never
  `saveBidSelectedPriceBookVersion`, which would move the ★), switching
  version/tab first as needed.
- Help guide `price-a-bid-with-the-workbench.md`: Map paragraph.

The map only reads and navigates — no re-star, no sends, no edits.
