# v2.7968 — Tests and two help guides drop the last lone words from live records (2026-11-19)

v2.7961 swapped every whole value that matched a live record: a full name, a full job name, a full street address. A single word from such a value could still sit alone in a test under another phrase, such as a builder's surname as a made-up job's name, or a real street's name beside a different house number. A count after that merge found 23 such words. Fourteen of them are distinctive, and this takes those out.

## What changed

- **Fourteen words in 24 files**: ten surnames or company names and four street names, in 20 test files and two SQL scenarios, and in two help guides (`follow-up-with-builders`, `job-work-story`).
- Each word takes the same invented word v2.7961 gave it, read from that commit's own diff, so a name reads the same in every test.
- Two variables in `versionStar.test.ts` that were named for a builder are renamed with it.
- One expectation that quotes a button's glued text was edited to match.

## Left as is

- **Nine common words**: a street name used with other house numbers, and common surnames. Alone they name nobody.
- Everything v2.7961 left: git history, docs, to-do cards, release notes, code comments and migrations.

## Checks

`npm test` (the whole suite), `npx eslint` on the changed files. The two SQL scenarios need Docker and were not run here; each changes one job name that nothing else in its bed reads.
