# v2.2746 — Timeline: a weekly roll-up (2026-09-04)

PR 2 of the approved Timeline plan. A **Daily | Weekly** switch on Jobs → Job Summary → Timeline: weekly buckets the same runs into Monday-keyed company-calendar weeks and stacks each week as **carried over** (the job's run began before the week) versus **new this week**, so the daily churn averages out into one number per week.

## Client only — no migration

- **Kernel** [`lib/jobs/jobRunningTimeline.ts`](../../src/lib/jobs/jobRunningTimeline.ts) (+3 tests): `mondayOfYmd`, `bucketRunningWeekly(rows, days, today)` → weeks clipped to the window (a partial first/last week keeps its real start/end), each with `carried` / `fresh` / `total` / `jobIds`; a job counts once per week however many segments fall inside, and "carried" follows the job's first run day (a paused-and-resumed job is carried, not new); peak week, current week, mean per week.
- **Prefs** [`jobSummaryLedgerView.ts`](../../src/lib/jobs/jobSummaryLedgerView.ts): `timelineGranularity` (`daily` default | `weekly`), persisted with the view prefs.
- **View** [`JobSummaryTimelineView.tsx`](../../src/components/jobs/JobSummaryTimelineView.tsx): the switch sits before Color by; weekly draws one bar per week (carried blue at the bottom, new cyan on top), month ticks, today's week marked, peak labelled "week of …", per-week tooltips; the 7-day average and Color by hide (the bands are carried/new); tiles read "Running this week" / "Average per week" / "Peak week". The bars panel stays daily.
