# v2.7056 — Bills sent: print the list or save it as a spreadsheet (2026-11-12)

Punch list #327, PR 5 (the screen's own print and file; the block in the Monday Bridge email waits for the Bridge spike, #318). The list is for looking. The accountant and counsel need it as paper or as a file.

## What changed

- **The kernel** (`src/lib/billing/billsSent.ts`, 36 tests in all):
  - `billsSentCsv(lines, gaps)`: one row a send, in the order given, under `BILLS_SENT_CSV_HEAD` (Date, Time, Bill, Job, For, Amount, In the day total, To, Address or number, Copy to, How it went, Sent by, Send of this bill, Arrived, Paid, Note), then the bills with no send on record. The date is the company's calendar day, the amount a plain number so a column adds, and *In the day total* says which rows the screen's totals count. A cell that opens like a formula is led with an apostrophe, so a spreadsheet shows it and does not run it. Fields are quoted by `escapeCsvField`.
  - `billsSentListHtml(days, gaps, { printedAtIso, shownWords })`: the page to print, the open gaps first, then each day with its count and total and each line's words, every word escaped.
  - `billsSentCsvFileName(todayYmd)`: `bills-sent-2026-11-12.csv`.
- **The screen**: **Print** and **Download CSV** above the tiles. Both take what the list shows: the lines the chip and the search box leave, with the open bills of the strip when the strip is showing. The page's first line says what it holds (*Statement.*, *All · "larkfield".*). Neither press draws when nothing is shown. The file is saved from the app's own address (`saveBlobAs`) with a byte order mark.
- **The guide** gains *Print the list or save it as a spreadsheet*.

## Not changed

- Nothing is written, and neither press files a sent copy: both are our own reading of the record (`NOT_A_SEND`, as the record's print).
- No email. A block for the Monday Bridge email is the second half of this step and waits for #318.
