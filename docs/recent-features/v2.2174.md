on (creating a bid counts too). Analysis found every bids policy treats `primary` as an
office role ("role IN (…, primary) → all rows"), so a primary saw every bid in their service
types.

  `.or(estimator_id|account_manager_id|created_by = me)` so the board filters on purpose (RLS
