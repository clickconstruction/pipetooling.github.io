# v2.2003 — Cover letter: numeric amount on its own line (2026-08-21)

Owner request (from the cover-letter preview): the numeric figure trailed the spelled-out amount at the end of the sentence — "…in the amount of: FIFTY EIGHT THOUSAND EIGHT HUNDRED TWENTY ONE 98/100 DOLLARS ($58,821.98)". Both builders in [`coverLetter.ts`](../../src/lib/bidDocuments/coverLetter.ts) now break before the parenthesized figure: `buildCoverLetterHtml` renders `<strong>words</strong><br/><strong>($N)</strong>` and `buildCoverLetterText` emits `($N)` as its own line, so the preview, clipboard copy, and approval PDF (`approvalPdf.ts` renders the text lines verbatim) all match. Snapshot + assertion updates in `coverLetter.test.ts`. Verified live on the Cover Letter tab preview. Client-only — no migration.
