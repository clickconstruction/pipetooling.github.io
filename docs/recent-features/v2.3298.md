## Why

PR 1 made the paper; this makes it a thing on the job. The Stages row's orange wrench opened plumbingtooling.com with the customer in the URL and nothing came back. Now it opens a modal that already knows the job, saves the report on the job, and prints the PDF — the same door, the office's muscle memory intact.
