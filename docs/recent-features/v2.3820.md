# v2.3820 — A fact sheet for any big file, ahead of breaking it up (2026-09-25)

Step 0 of `docs/PAGE_DECOMPOSITION_PLAYBOOK.md` — map the surface before extracting anything — was done by reading the whole file (a 5,000-line component is ~65k tokens) and hand-counting its hooks. `scripts/map-surface.mjs` does the counting: it parses the file with the TypeScript compiler (no type checker, no network) and prints the facts half of a map, so an agent reads a ~5k-token sheet and opens only the line ranges that decide a question. The hand-written `docs/*_ARCHITECTURE.md` maps keep the judgment — seams, ownership, order, risk.

## The command

- `npm run map -- <file> …` — the fact sheet: module-scope declarations; per component (and per `use*` hook) every `useState` with **who reads it and who writes it** (effects, handlers, memos, derived locals, render branches, by name or `branch@<line>`), refs, context, custom hooks, effects with deps, memos, handlers with size / setters called / handlers called / data touched, derived locals ≥8 lines, JSX `if` blocks, and the render's conditional blocks ≥12 lines nested one level; tables (`.from`), RPCs (`.rpc`), edge functions (`functions.invoke`) and storage buckets per unit; the file's local imports and every file that imports it. A plain function ≥150 lines (a loader, a builder, twin-mcp's `callTool`) gets an outline of its inner functions and `switch` cases. `--json` gives the same facts as data; `--out <dir>` writes one `<name>.facts.md` per file.
- `npm run map -- --routes` — `src/App.tsx`'s routes: path → component → file → lines (lazy imports resolved).
- `npm run map -- --triage [--min 1500]` — every source file over the threshold, the map that covers it and how many commits have touched the file since the map last changed (STALE ≥ 5). Pairing reads a map's `covers:` front-matter list first, then the playbook's inventory table, then the map's header.

Fact sheets are generated on demand and never committed — they would conflict on every edit to the file.

## Where it is written down

The playbook's Step 0 now starts from the fact sheet and asks every map to carry `covers:` and `mapped_at:` in its front matter.
