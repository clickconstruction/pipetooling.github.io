# v2.7188 — Phone sheets stay on screen when the keyboard comes up (2026-11-13)

Punch list #348, PR 2 of 4. v2.7155 made the three task windows follow the part of the page that shows when an iPhone's keyboard slides the page. Three more sheets were pinned to the page the same way.

## What changed

- **`src/lib/visibleBand.ts`**, new, pure: `visibleBand({ height, offsetTop })` gives the band a window pinned to the screen should fill, `{ top, height }` in the page's own px, or null where the browser cannot say. It is the rule `taskWindowPhoneFrame` already used, lifted out of the tasks folder so other windows can read it. `taskWindowPhoneFrame` now calls it, and `VisualViewportBox` lives beside it.
- **Where is it?** (`TaskPlaceSheet`). Its backdrop was `inset: 0`. It is now `top: band.top; height: band.height`, so the sheet fills what shows. Its map asked for a floor of 220 px, which with a keyboard up left no room for the name and **Use this place**. The map is now `flex: 1 1 220px` with a floor of 60, so it gives way first.
- **`PhoneSheet`** (the windows inside a Messages thread: the message window, Who is this?, the job picker, the ⋯ menu). On a phone its backdrop was `top: 0` and as tall as the visual viewport. It now starts at `band.top`, so a slide no longer lifts the sheet's foot off the keyboard.
- **The dispatch job picker** (`ScheduleDispatchAssignJobPickerModal`). On a phone its card is docked to the top and as tall as the room the keyboard leaves. It now also takes `marginTop: band.top`.
- **`useVisualViewportHeight` is removed.** It heard the visual viewport's resize and not its scroll. Every window that read it now reads `useVisualViewportBox`.

## Walked

iOS Simulator, iPhone 17 Pro, iOS 26.4, Safari, the on-screen keyboard up, nothing saved. No picture is kept here: the sheet shows a real place from above, and this repo is public.

- **Where is it?** With the keyboard on the place's name: the title, Cancel, a strip of the map with its ring, **Use where I am**, the name and **Use this place** are all on screen. With the keyboard away the map takes its full height again and the ring is still centred.

## Not walked

Their change is the same two numbers the place sheet and the task windows use.
