# v2.6638 — Settings → Jobs & billing: each Billing and money card reads its live value on its folded row (punch list #261, PR 3) (2026-11-07)

Call 4 of `to-dos/settings-jobs-billing-tidy/`, the owner's answer 2026-11-07: **yes, the money cards show their live value on the folded row**. PR 1 (v2.6516) drew every card's static line of what it sets; PR 2 (v2.6631) folded every card. This PR makes the seven cards under *Billing and money* read their value while folded, so the tab answers *what do we charge?* without a press.

## What changed

- **The kernel** (`src/lib/settings/jobsBillingValueLines.ts`, new, pure): one short line per card from what it stores, each blank state in words. Rates charged by crew — *$285 master with a helper · $185 a tech alone* (the owner's two rows; when either is blank the first two rows set stand in; *No rate set yet*). Markup on materials — *18% over cost* / *At cost, no markup set*. Turnaway Trip Charges — *$95 client not home · $75 site not ready* (a blank amount left out; *No amount set*). Default labor rate — *$75 an hour* / *No default*. Job Book — *14 line items* / *No line items yet*. GC jobs · pay by card — *On* / *Off*, only `'true'` on, as the switch reads it. GC jobs · the trades' cut-off — *6 days before bill day*, the default when the row is missing or out of range, as Bill day reads it. `jobsBillingValueKeysFor(slugs)` names the `app_settings` keys one select reads for the cards a role sees; `moneyWords` draws whole dollars bare and cents only when there are some.
- **The read** (`src/hooks/useJobsBillingValueLines.ts`, new): the page's one select of those keys (`key, value_num, value_text`) and, when the role sees Job Book, a head count of `job_book_entries`; on mount and again on `refresh`. A read that fails leaves the lines as they were, since the card itself names the failure when opened. It never writes: every card keeps its own save.
- **The fold header** (`SettingsFoldCard`): `valueLine` is drawn in place of the static line only while the card is folded (`data-fold-line="value"`, in the base text colour so the number reads), the static line while open or until the value is read (`"static"`); `onFold` fires when the header press closes the card. `SettingsJobsBillingGroups` takes `valueLines` and `onCardFold`; `Settings.tsx` wires `useJobsBillingValueLines(myRole)` to both, so the value saved inside a card is on its row the moment the card closes.
- **Guide**: `settings-basics` says a Billing and money card shows its value on its folded row, and its example reads *14 line items*, *On*, *6 days before bill day*.
- **Docs**: `docs/SETTINGS_TABS_ARCHITECTURE.md` § 3; the card records PR 3 and what is left.
