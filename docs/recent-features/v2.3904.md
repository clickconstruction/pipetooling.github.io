- **Six query stubs** — the `Promise.resolve({ data: [] })` stand-ins for the reports RPC, the two checklist reads and the three windowed lifetime reads. The labor read keeps its own "no linked jobs" stub.
- **The empty all-time labor rows** the flag substituted for the person's own.

- **The optional `reqId`** — only the flagged call left it out, so it is required and the stale-response guard loses its `undefined` test.
