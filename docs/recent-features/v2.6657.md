# v2.6657 — The estimate text carries a shorter link (2026-11-07)

Punch list #281 (`to-dos/short-estimate-link/README.md`), PR 1 of three. The owner's ask of 2026-11-07, on the text the Tell the customer sheet sends with an estimate: *Robert, this is Robert with Click Plumbing. Your estimate for ZZ Test press answers walk is ready, $1.00. Open it to approve the option you want: https://clicktooling.com/estimate/accept?t=<64 hex>* — the link should be much shorter, and should look like it came from Click Plumbing.

## What changed

- **The text's link is the share link** (`share_estimate_link`, #127's second link to an estimate), minted by the sheet after the email goes: 32 characters of token against the email's 64, the same accept page, the same powers (open, approve an option, decline) and the same 14 days, through `_shared/estimateTokenLookup.ts`, which reads either hash. The link goes from 107 characters to 75; the whole text in the owner's example from 253 to 221. The email keeps its button and its own long link, and the remail path (`findEstimateAcceptUrl`) is unchanged.
- **A mint that fails falls back to the email's own link** (`src/lib/tellCustomer/estimateTextLink.ts`, pure, with its tests): the email went, so the text goes either way.
- `TellCustomerIo.shareEstimateLink` (through `estimateLinkIo.ts`), `TellEstimate.estimateId` from the Estimates page, the sheet's smoke for the short link and the fallback. The already-went band's words and the guide *send an estimate and turn it into a job* say what Send the link again retires now: the old emailed link, while a link texted before keeps working for its 14 days.

## Not in this PR

- The walk kit's own driver (`src/lib/walk/walkDriver*.ts`) still texts the email's long link; it is a separate path from the sheet.
- PR 2 (a 10 to 12 character code with a guess guard, a migration) and PR 3 (the link on a Click Plumbing host through a Cloudflare rule) are planned on the card. `/q/<code>` is taken by the supply house quote page, so PR 3 lands on `/estimate/accept?t=<code>` or a new short route, not `/q/`.

No migration, no function deploy. A walk should send an estimate from the sheet on a ZZ Test estimate and check the text's link is 75 characters, opens the accept page, and approves an option; then Send the link again and check the new text's link opens while the first text's still does.
