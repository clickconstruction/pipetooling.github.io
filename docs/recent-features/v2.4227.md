# v2.4227 — The home-screen icon is drawn at the size the phone asks for, in heavier ink (2026-09-30)

Punch list #67, PR 1 (items 1 and 2 of `to-dos/app-icon-glass.md`). Static assets + the generator + `index.html`; no app code, no migration, no edge function. The owner, 2026-09-29, after v2.4158 centred the mark: "the saved icon on the dashboard still looks rough … I want this to look great." The served file was right; iOS 26 composites Liquid Glass over every flat web-clip icon, and the tile was downsampled 5.7× by the phone and inked in `#161617`, which the glass lifted to grey.

## What shipped

- **Exact-size renders** — `scripts/generate-app-icon.mjs` renders `SIZES = [1024, 180, 167, 152, 120]` from `favicon.svg` with the same Chromium, one page per size (no downsampling anywhere: the SVG is rasterised at the target size). `index.html` links the four with `sizes="180x180"` … `sizes="120x120"` and keeps the unsized `/apple-touch-icon.png` (1024) last as the fallback — the help share-card shell (`helpShareCard.ts`) and the portal link shell Worker point at that name and are unchanged.
- **Heavier art for the touch icon only** — two more guarded string rewrites beside `SVG_MARK_TRANSFORM`: `SVG_INK` (`fill="#161617"`, the gear body and hub) becomes `#000000`, and `SVG_WRENCH_FILL` (the wrench path's yellow) gains `stroke="#e8c547" stroke-width="20" stroke-linejoin="round"` in the wrench's own 512-unit space (≈19 px on the 1024 tile, ≈3 px at 180). The generator throws when `favicon.svg` no longer carries any of the three needles. The favicon and the CountTooling / Takeoff Tooling marks keep `#161617` and the plain wrench.
- The `favicon.svg` header comment names the five files.

## To see it

After the deploy: `curl -s https://clicktooling.com/ | grep apple-touch-icon` lists the five links, and each `/apple-touch-icon-<size>.png` answers 200. On a phone that already has the icon: remove it, Add to Home Screen again, and photograph it next to a native icon with Reduce Transparency off — that photo is what decides item 3 (the dark tile), the owner's call.
