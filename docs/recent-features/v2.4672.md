# v2.4672 — Lien desk: the pile titles stay on screen as the Notices list scrolls (2026-10-06)

Client only; no migration, no edge function. The owner (2026-10-05): *I would like the titles [Send the run · 11, Needs the owner · 3, To draft · 10, Awaiting approval · 1, Ready to send · 11, Missed · 3] to stack up on the top and bottom as they are passed and become available so they are always visible and scroll with the items the user scrolls past. If the user clicks on one I would like it to feel reactive, like the user scrolls to that section.* Mock-up: artifact Hf8t3PstkfofBLjbM41HcP — a first pass, its critique (the chips and the titles said the same thing twice; five bars eat a short list; Send the run is not a pile; which pile am I in), and the refined shape built here.

## What changed

- **The Notices list** (`LienDeskModal` `list`): `pilesShown` is the piles with rows, in order. Each draws a `.lienPileHead` (30 px, `position: sticky`) as a sibling of its rows' wrapper (`data-lien-pile-rows`), with `top: i·30` and `bottom: (n-1-i)·30`, so the browser stacks passed titles at the top and holds coming ones at the bottom with no scroll listener. The title is a button (`.lienPileHeadBtn`) with the pile's label and count (`counts[p]`, the rows when narrowed); `scrollToPile` scrolls the list so the pile's first row sits under the stack (`smooth`); `relightPiles`, on the list's scroll, marks the pile whose rows cross the line under the top stack (`data-on="yes"`, a blue bar at the left).
- **Ready to send carries the run**: its title has the *Send the run · N* door (office, a count above zero) — the act for that pile, where the reader reaches it.
- **The pile chip row is gone** from the Notices title bar: the titles do its work. `pile` still narrows the list (deep links, the Do now doors), and a narrowed list's title offers *show every pile*.

## Tests

- `LienDeskModal.render.test.tsx`: one sticky title per pile with its count and its place, no second button naming the pile, a press scrolls the list and lights the title, a narrowed list offers *show every pile* and widens on it.
