## Tests

12 cases added to `src/lib/scheduleDispatch/multiCellAdd.test.ts` (19 in the file; it mocks `./supabase`, so it runs with no environment set). They pin the map's quirk #7:

- Every block is 08:00–16:00 with no note, on the job or — through a `bid:` anchor — on the bid.
- Each block gets a group of its own; the selection is not linked together.
- A cell whose person already has something in the window is skipped, not failed; a block that only touches the window is not an overlap.
- A cell that cannot be read, written or parsed is counted as failed and the rest still run.
- The cells are worked one at a time, in selection order — read, then write, then the next cell.
