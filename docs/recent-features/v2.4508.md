# v2.4508 — AIA G702-G703: name the applications you save (2026-10-04)

The owner, 2026-10-04, pointing at **APPLICATIONS ON THIS JOB**: *"I would like to be able to rename the versions that I save, if that is not already an option."* It was not: a saved application showed as its number, period and payment due. One migration (`20261004233954_job_pay_applications_name.sql`, one column), no edge function.

## The change

- **Column** `job_pay_applications.name` (text, default `''`, at most 80 characters).
- **Kernel** [`aiaPayApplications.ts`](../../src/lib/aiaPayApplications.ts): `SavedPayApplication.name`; `cleanPayApplicationName` (one line, single spaces, trimmed, cut at `PAY_APPLICATION_NAME_MAX`); `payApplicationWriteFromForm(…, name?)` writes the column only when a name is passed, like the reason; `payApplicationLabel` puts the name after the number (`1 · Sent to the GC · 09/30/2026 · $17,460.00 due`).
- **IO** [`aiaPayApplicationsIo.ts`](../../src/lib/aiaPayApplicationsIo.ts): a fourth column set with `name` on top; a database without the column is read and written without it.
- **Window**: a **NAME** box above the link. It is part of the unsaved check, saved by Save and by Generate, loaded with a saved application, and empty on a new one (the next application does not inherit the last one's name). Clearing it and saving writes the empty name.
- **Documents tab**: the name beside the application's number.

The name is the office's note. Nothing prints it.
