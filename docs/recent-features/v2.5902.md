# v2.5902 — The search box opens a page, a tab, a window or a Settings card by name (2026-10-26)

Punch list #181, PR 2 of 4 (`to-dos/go-anywhere/README.md`, the owner's "build it all" of 2026-10-26). The header's box read four kinds of row and nothing else; a Settings card was three presses and a scroll away, the Legal desk a gavel you had to know. Now the box draws the doors of v2.5900's index under today's rows.

## What shipped

- **`HeaderGlobalSearch.tsx`**: the provider reads `useAuth` for the role and the two per-person flags, builds the `DoorViewer` (Farm Mode comes from `Layout` as a prop) and keeps `doorsFor(viewer)` in a memo; `searchDoors(query, doors, { only })` runs synchronously on every keystroke, so a door row never waits on the 300 ms data debounce. The nav layer draws `DoorGroupRows` under today's rows inside the same `listbox`, each row continuing the option index, so ↑ ↓, `aria-activedescendant` and a screen reader see one list. The first row is lit when nothing is chosen (`active`), so Enter alone opens the best match. Tab and Shift+Tab land on the next and previous group's first row through `nextGroupStart`; with one group Tab does what Tab does. A group's **N more ▸** sets `onlyGroup`, which draws that kind whole with **All kinds** to come back. A typed `>` narrows to places and keeps the data search off the server. A door opens by `navigate(door.to)`, is remembered through `rememberDoor`, and records a `ui_nav_clicks` row with control `go_anywhere_door` and the door's id as the target, which a later PR can read to seed the empty box by role.
- **Recent** (`src/lib/search/recentDoors.ts`): the last eight doors opened on this device, per person, in `localStorage` the way Messages keeps its Show lens; read back against the viewer's doors, so a door the role can no longer open never draws. Shown when the box opens with nothing typed.
- **The words** (`GO_ANYWHERE_WORDS` in `doors.ts`): the placeholder *Jobs, bids, customers, pages, settings…*, the no-matches line that says what the box looks in, the keys line said once under the rows on a desk and never on a phone, *a window* beside a window's row.
- **The field lookup is untouched**: helpers and subs keep their jobs-only card and its own words. Estimators, primaries and superintendents still have no box; PR 4 is the owner's call.
- **Guide**: `global-search` gains *Open a page or a setting from the same box*.

## Tests
