# v2.2284 — Locked goal stages: unlock-chain modal + jump-and-highlight (2026-08-25)

Requested with mockup ("Locked Stage Chain" artifact): tapping a locked stage
in Checklist → Review → Goals explains what stands between it and unlocking.

- **Kernel `lockedStagePrerequisiteChain`** (roadmapBridge.ts, unit-tested):
  walks incoming edges upward from the locked stage, skipping complete
  ancestors (their chains no longer matter), never listing the stage as its
  own prerequisite on cycles. Returns entries in curated stage order with the
  list's 1-based numbers and `direct` flags.
- **Trigger**: the 🔒 chip becomes tappable (dotted underline, role=button;
  stopPropagation keeps the row's task-unfold intact); locked rows with no
  tasks — previously disabled — now open the modal on row tap.
- **Modal**: "N · title / 🔒 Locked — these stages have to finish first:" —
  each prerequisite with number, title, progress, amber "unlocks it" tag on
  direct blockers, and a → jump cue.
- **Jump**: closes the modal, expands the folded locked tail
  (`setShowAllLockedStages`), scrolls the stage row to center (instant, in a
  post-render effect — smooth scrolling stalls in rAF-less webviews and the
  80ms-timeout version raced React's re-render), and flashes a 2.6s blue
  outline via `highlightStageId`.
- New `goalEdges` loader state feeds the kernel; rows get
  `id="goal-stage-<groupId>"` anchors.
- Help guide `review-my-teams-completed-tasks` gains the bullet.
- Verified live against Farm 1: stage 2's chain correctly showed stages 1 +
  35 as direct blockers and 31–34 behind stage 1; jumping to 31 centered it.
