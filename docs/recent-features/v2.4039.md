# v2.4039 — Copies of a bill carry the QR code to the recipient's statement too (2026-09-28)

v2.4020 gave the payer's bill email a QR code to their statement; the copies (`stripe_bill_copy`, one per address on `copy_emails`) still ended with the statement as a bare link. Now every email about a bill draws the statement the same way.

## One card — `_shared/portalAccountCard.ts`

`portalAccountCardHtml(portalUrl, qrImgSrc)` is the "Your account, any time" card that was inline in `stripeBillEmail.ts`: the code (120 px, linked) beside the address in words, `''` without a statement, no `<img>` and no "Scan the code" without an image. `portalAddressInWords` and the inline-image constants move with it (`PORTAL_QR_CONTENT_ID`, `PORTAL_QR_FILENAME`, `PORTAL_QR_DISPLAY_PX`, `PORTAL_ADDRESS_MAX_CHARS` — formerly `BILL_EMAIL_*`). `buildStripeBillEmail`'s output is unchanged.

## The copy — `_shared/stripeBillCopyEmail.ts`

- `qrImgSrc?: string | null` joins the input. The line *See your statement any time at <url>* in the HTML becomes the card; the plain-text line is unchanged.
- The closing line read *<payer> was billed directly by Stripe*, which stopped being true with v2.4020. It reads *<payer> was sent the bill directly.*

## The function — `send-stripe-invoice`

`sendBillCopies`, live branch only: a copy whose address has a statement (`portalByEmail` — the payer's contact persons get the payer's, the other party gets its own; v2.3362) gets `qrMatrix` + `qrPngBytes` of that statement as an inline attachment (`content_id: 'portal-qr'`) and `qrImgSrc: 'cid:portal-qr'`. Each statement's code is drawn once per send (`qrByPortal`) — at most two. A one-off address has no statement and gets no attachment. A test-mode bill's single copy (v2.4024) carries no statement, so no code. No new short address is assigned here: the payer's was assigned by the bill email a moment earlier, and the other party's statement keeps whatever address it has (a token address reads *Open your statement*; its code still scans).

## Tests

`portalAccountCard.test.ts` (7: the card with and without a code, a token address, no statement, escaping, the address in words — moved from `stripeBillEmail.test.ts`), two new cases in `stripeBillCopyEmail.test.ts` (the card and code on a copy with a statement, none on a one-off) and the corrected closing line.
