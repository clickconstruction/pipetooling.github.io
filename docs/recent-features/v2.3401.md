# v2.3401 — Edit Job → Property record: add the job address as a property from the row (2026-09-14)

Client only; no migration, no edge function.

## Why

Owner, 2026-09-14, on Jobs → Pipeline → Edit Job (J890, RMC- Dudley Mason, 628 Terrell Rd): "I need to enter the legal address and the only option I have is the customer address because we put the GC in the customer row." The Property record picker (v2.2638) lists the job customer's and GC's `customer_addresses` rows; a builder entered as the customer has only its office on file, so the job site — the property the lien paperwork is about — had no row to link and no home for its county, legal description and owner of record. The only way in was Edit customer → Properties → *Add as property* (v2.3009), two doors away from the job.

## What shipped

- **[`JobFormPropertyAddSheet`](../../src/components/jobs/JobFormPropertyAddSheet.tsx)**: Edit customer's property sheet (`CustomerPropertySheet`, v2.3009) prefilled with the job address — the record panel runs the parcel lookup as it opens — and on **Add property** inserts the `customer_addresses` row on the job's customer (the GC only when the job has no customer), sequenced after the customer's existing properties, **never as the primary** (the ★ row mirrors `customers.address` by trigger, and a job site is not the customer's address). The new row is handed back to the shell.
- **[`JobFormEditFactRows`](../../src/components/jobs/JobFormEditFactRows.tsx)** → Property record: when the job address is not linked and no saved property matches it, the editor offers **+ Add 628 Terrell Rd as a property on RMC- Dudley Mason** under the picker (or in place of the old "add one on the customer's Edit form" line when the customer has no properties yet), with one line saying why. Cancel folds the sheet. The collapsed row reads *not linked* whenever the job has a customer, not only when candidates exist.
- **[`JobFormModal`](../../src/components/jobs/JobFormModal.tsx)**: `onPropertyAdded` appends the row to the picker's candidates and sets `customerAddressId`, so the identity autosave slice writes `jobs_ledger.customer_address_id` the way a picker choice does.
- **Kernel**: `payloadFromDraft` moved from `CustomerPropertiesSection` into [`propertyDraft.ts`](../../src/lib/customers/propertyDraft.ts) (+2 tests) so both writers trim the draft the same way.
- Guide *give a customer a lien release*: the "Why bother?" panel names the new door.

## Verified

Render smoke (+3: the offer and the prefilled sheet, a matching property is offered to link instead, the no-properties case), the draft kernel tests, release-note + guide drift tests, typecheck, lint, theme check.
