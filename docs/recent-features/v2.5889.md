# v2.5889 — The Bridge centers its round buttons (2026-10-26)

The owner's look at `/bridge` on 2026-10-26 flagged the glyphs sitting off-center in their circles: the **?** on the rule line (`BridgeRule.tsx`) and on *Everything else waits* (`BridgeWaits.tsx`), and the **×** on *What to deal with first* (`BridgeOrderModal.tsx`), the three card panels (`BridgeProfitPanel.tsx`, `BridgeOwedPanel.tsx`, `BridgeHoursPanel.tsx`) and the Collect desk (`BridgeCollectDesk.tsx`).

Two causes:

- Every one of the seven buttons was a fixed-size `<button>` relying on the browser's native text centering, which the user-agent padding skews. Each now centers its glyph itself: `display: inline-flex`, `alignItems`/`justifyContent: center`, `padding: 0`.
- The rule line's **?** had a second bug: its style object set `font: 'inherit'` *after* `fontSize: '0.8rem'` and `lineHeight: 1` — React applies style keys in order, so the shorthand reset both and the glyph drew at the line's own size. The shorthand now comes first, as the other six buttons already had it.

No behavior change; the Bridge's render smokes pass unchanged. Dev-only surface: no help guide, no migration, no edge function.
