## What shipped

- **`src/pages/Workflow.tsx`** — nine handlers call `src/lib/projectsForecastStageLineItems.ts` instead of talking to Supabase themselves: `loadFinalizedPOs`, `loadSupplyHouseInvoices`, `loadPODetails`, `loadInvoiceDetails`, `addPOToStep`, `addInvoiceToStep`, `saveLineItem`, `importLineItemsFromPaste`, `deleteLineItem`. Each is a thin wrapper now: call the lib, send a returned error to `setError`, and on a write close the window and reload. 3,917 → 3,689 lines.
- **`reloadAfterLineItemWrite()`** — the reload the five writers each spelled out (`refreshSteps()`, then `loadLineItemsForSteps` for dev / master / assistant-like / superintendent) is one inner function.
- **`importPastedLineItems(stepId, text, existing)`** is new in the lib — the page's paste import, moved: parse, number the rows on from the step's last line item, one INSERT. 4 tests.
- The page's state for the pickers and the two detail windows is typed with the lib's `AvailablePOOption`, `AvailableInvoiceOption`, `PODetail`, `InvoiceDetail` — the same shapes it declared inline.

## Compared handler by handler

The map recorded the lib as a copy of the page with one known difference. Read side by side before the switch:

| Handler | Difference |
|---|---|
| `saveLineItem` | the failed-insert message: page "Failed to insert line item: …", lib "Failed to add line item: …". **The page now shows the lib's.** Payloads identical. |
| `loadPODetails` | the page selected `*` from `purchase_orders` and used `name`; the lib selects `id, name`. Same result. |
| `loadPODetails`, `loadInvoiceDetails` | the lib also answers "Not found" for a row that comes back empty with no error; `.single()` raises an error in that case, so the page never saw it. |
| `loadFinalizedPOs`, `loadSupplyHouseInvoices` | a failed read is logged with the error's message, where the page logged the error object. What each does to its list is kept: a failed PO read leaves the list in hand, a failed invoice read empties it. |
| `addPOToStep`, `addInvoiceToStep`, `deleteLineItem` | none — same reads, same rows written, same messages, the credit-memo refusal (v2.3501) included. |

What stays the page's: the dev / master gate on the two picker reads, `setError(null)` before an attach, which window closes, the invoice search cleared after an attach, the clipboard read, and the reload.
