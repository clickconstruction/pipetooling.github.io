# v2.2330 — Front doors for /tally and /accounts-receivable; recovery posture documented (2026-08-26)

CX-audit Phase 2 (Journey Atlas findings F4–F5): two recurring-chore pages had
no nav entry point, and the sign-in screen's lack of a reset link kept
resurfacing as a gap.

- **Gear menu → Job Parts Tally** (`Layout.tsx`): all roles, hidden in Farm
  Mode, placed above Calendar; wrench icon matches the Dashboard tally square.
  `/tally` was in every role's allowlist but reachable only via the Dashboard
  tally row and the pre-clock-out modal.
- **Gear menu → Accounts Receivable**: staff only (dev / master_technician /
  assistant-like — same gate as Banking, placed right after it); deposit-tray
  icon. Previously reachable only via the unallocated-deposits banners.
- **Both paths are now pinnable**: added to `PINNABLE_PATHS` + `PATH_TO_LABEL`
  in `pinnedTabs.ts` ("Job Parts Tally" / "Accounts Receivable").
- **Fourth stale role-path copy removed**: `pinnedTabs.ts` had its own
  `getAllowedPathsForRole`/`filterPinnedByRole` (missed by v2.2325, which
  caught the other three). `filterPinnedByRole` now lives in `pinnedTabs.ts`
  backed by `isPathAllowedForRole`, and `dashboardPinnedRow.ts` re-exports it —
  `getMergedFilteredPins` (Settings pin management) now filters through the
  kernel like everything else.
- **Password recovery is contact-the-office on purpose** (owner decision,
  2026-08-26): no "Forgot password?" link gets added to sign-in. `/reset-password`
  stays functional for office-directed use. Documented in a comment at the
  footnote in `SignIn.tsx` so the "gap" isn't re-fixed by accident.
- Help guides: `sort-card-purchases-to-jobs` and `ready-to-bill-pipeline` now
  say where the tally / AR pages live.
- Tests: `pinnedTabs.test.ts` +2 (pinnable front doors, kernel-backed role filter).
