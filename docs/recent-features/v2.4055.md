# v2.4055 — Takeoffs: look a part up on Google from its line (2026-09-28)

Client only; no migration, no edge function. Owner ask 2026-09-28: estimators were copying part names out of the takeoff sheet into Google, one tab per part (the screenshot had eleven). Mock-up artifact `LX74wJB1oRMjhLnvo2yQ4S`; the owner picked "in line with the text, at the end of the text line" and "the whole name as written" over "just the part number after PN:".

## What shipped

- **`src/lib/bids/partSearchUrl.ts`** (pure, 8 tests) — `partSearchQuery` (trim + collapse whitespace), `partSearchUrl` (`https://www.google.com/search?q=…` through `URLSearchParams`, null for an empty name), `splitTrailingWord` (head + last word, so the icon can be bound to the last word).
- **`TakeoffPartSearchLink`** (`src/components/bids/TakeoffPartSearchLink.tsx`, render test) — a real `<a target="_blank" rel="noopener noreferrer">` (middle-click, ⌘-click and "open in new tab" all work; `stopPropagation` on click and pointerdown so the row's touched-row capture and the fixture's click do not fire), `aria-label="Search Google for <name>"`, class `.takeoff-part-search` in `index.css` (faint at rest, blue on `--bg-blue-200` on hover/focus, hidden under `@media print`). `PartNameWithSearch` renders the name with the icon inside a `white-space: nowrap` span around the last word, so a wrapped name carries the icon down with it.
- **`TakeoffPartSearchIcon`** (`src/components/icons/`) — 13px magnifier, `currentColor`.
- **`SortableRoughPartLineRow.tsx`** — assembly bundle part rows render `<PartNameWithSearch name={bp.name} />` in place of the bare name; a single part line's name `<input>` is wrapped in a relative box with the link absolutely placed at its right end, shown only while a part is picked and the picker is not open for that line (`paddingRight` widens to make room). One component serves both Sheet and One at a time (`renderLinesTable`), so both views got it at once.
- Help guide `look-up-a-part-on-google.md`.

## Decided here

- **Whole name, not the PN.** Google already picks the maker and part number out of a supply-house description; the PN-only variant stays a one-line change in the kernel if it is ever wanted.
- **Google, hard-coded.** No setting; the kernel is the one place to change the engine or add a supply-house search later.
- **Not on fixtures or assembly names** — those are the estimator's own labels.
