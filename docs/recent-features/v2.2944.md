# v2.2944 — Field job lookup: the search icon for subs and helpers, read-only (2026-09-06)

Journey map **Tier 5 X1** (J28-F2 stumble, cluster C18 — "Field roles have no job lookup"), the first PR of the Tier 5 train (`pipetooling-journey-map` → `docs/journeys/_TIER5-TRAIN.md`, T5-01; Will's call 2026-09-06: build). Client only — no migration, no edge function.

## The problem

A helper on site who needs job 878's address had one route: open Clock In, search the picker, read the row, cancel. Four taps, one of them a punch button they must not press. The header search that answers this for the office was gated to dev / master / assistant-like (`Layout.tsx` `headerSearchEligible`), while the Clock In picker had already proven that `search_jobs_ledger` (SECURITY DEFINER, v2.2902's escaped + numerically ordered version) reaches helpers and subcontractors. The door was the only missing piece.

## What shipped

- **Kernel** [`src/lib/fieldJobLookup.ts`](../../src/lib/fieldJobLookup.ts) (+9 tests): `officeHeaderSearchEligible` (the old rule, unchanged), `fieldJobLookupEligible` (helpers + subcontractor, off in Farm Mode; superintendent / primary / estimator stay out — X6 walks those roles first), `headerSearchEligibleForRole` (the union Layout mounts on), `directionsUrlForAddress` (Google Maps directions link), `officeTelHref` (E.164 `tel:` from the `PORTAL_COMPANY.phone` constant), `buildFieldJobLookupCard`.
- **Layout**: `headerSearchEligible` now comes from the kernel; a `fieldJobLookup` flag rides into the provider.
- **`HeaderGlobalSearchProvider` field mode** (`fieldLookup` prop): searches **jobs only** (no bids / estimates / customers RPCs, no service-type load), **never fetches job evidence** (that path is money mode and stays office-only), and selecting a job opens a **read-only card** (`FieldJobLookupCardModal`: number · name · address · trade, Directions, Call office, Close, "Read only. To start work on it, use the Clock In button.") instead of the Job Detail window. Button title / dialog label / placeholder read "Find a job" in field mode. Office mode is byte-for-byte the previous behaviour.
- **Guide** `find-a-job-address-from-the-field` (Field Work, subcontractor + helpers) + a pointer in `start-here-as-a-sub`.
