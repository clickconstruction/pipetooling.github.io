## Decisions

- **The held line counts what a press found, not a standing read.** Knowing whether the app can write in a pasted folder takes a Drive look per job (the check reads the folder, its parents, its drive and its children), so the tab does not run it on every open; **Check N pasted folders** runs it on the office's word, with the count as it goes, and the amber line reads the run. The photo sweep's own row still names a folder it could not file to.
- **The root moves in two presses.** Check first, then *Move the jobs root here* behind a confirm window, since every new job folder goes under it from then on; the function checks again before it writes, so a folder that lost its sharing between the two is still refused.
- **The order of pieces is remove-and-add.** A × on each chip and a tray of the rest make any order in two presses; arrows on every chip were more to read than the names are worth.
- **The as-needed choice saves now and is honored in PR 3.** The press makes every folder up front until then; the fragment of PR 3 says when the choice took effect.
