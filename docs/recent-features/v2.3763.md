# v2.3763 — Lien filings keep a link to the saved copy (2026-09-23)

Punch list **#35** (`to-dos/lien-notice-sent-by-hand/`), PR 1 of 3. One migration (five additive columns), no edge function.

## Why

Taunya mailed a § 53.056 notice on 2026-09-22 — one paper for jobs 273, 858 and 866 at 9703 Lenox Hl — and the app never learned of it. The filings table had no row for any notice, ever, and even a recorded filing had nowhere to point at the PDF. The owner's ask: *"add fields where it is clarified when things like this are sent, even if they're just plain text fields with a Google Drive link to the file in question."* This PR is the field; PR 2 is the record-after-the-fact door; PR 3 the combined notice.

## The change

- **Migration [`20260923210000_lien_filings_document_link.sql`](../migrations/20260923210000_lien_filings_document_link.md)** — `document_url`, `document_note` on `job_lien_filings`, plus `packet_id`, `by_hand`, `printed_claim` for PRs 2–3 (one push serves the stream). Defaults on every column.
- **Kernel [`lienFilingDocumentLink.ts`](../../src/lib/jobs/lienFilingDocumentLink.ts)** (3 tests): `normalizeDocumentUrl` (http(s) as typed, a bare host gets a scheme, a note is not a link), `documentHostWord` (Drive / Dropbox / OneDrive / the host), `documentLinkWords` (*Saved copy · Drive — the scan*), `filingDocumentPayload` — keys only when they carry a value, so a client deployed before the push still records (a link typed in that window fails to save until the push lands; `clear: true` for the row editor).
- **The run** — [`lienDeskRun.ts`](../../src/lib/jobs/lienDeskRun.ts) `runFilingPayload(…, document)`, [`lienDeskRunIo.ts`](../../src/lib/jobs/lienDeskRunIo.ts) `recordLienDeskRun(…, { document })`, and a *Saved copy* row (link + note) in [`LienDeskRunModal.tsx`](../../src/components/jobs/LienDeskRunModal.tsx)'s footer — one link for the packet, carried on every notice's record (render smoke).
- **The Lien window** — [`LienFilingTabs.tsx`](../../src/components/jobs/LienFilingTabs.tsx): the same row on the notice-sends, affidavit-filing and release record steps (`insertFiling` and `recordNoticeSends` spread the payload); *Filings on this job* rows show *Saved copy · Drive ›* with *change*, or *link the saved copy*, and an inline editor updates the row after the fact.
- **The Legal desk** — [`legalPacket.ts`](../../src/lib/legal/legalPacket.ts) `LegalFilingLine.documentUrl`; the filings table gains a *Copy* column (*open ›*).
- Guides *send lien notices from the Lien desk* (Sending the run, step 3) and *file a lien and never miss its deadlines* (Step 1); GLOSSARY → Lien desk.
