# v2.7650 — Tell the dev: the ground for a note from any page (2026-11-17)

Punch list #380, PR 1 of six: the ground. One migration, `20261117235000_help_feedback_page_notes.sql`, and five kernels with their tests in `src/lib/tellTheDev/`. No screen calls any of it yet. The migration's detail is in `docs/migrations/20261117235000_help_feedback_page_notes.md`.

## Why the same table

The app already has a box that reaches the dev: `HelpGuideFeedbackForm` under each Help guide, the `help_feedback` table, the `notify-help-feedback` push and the inbox on the Dashboard and in the Checklist's review. It has taken no notes since July, because it sits on a page few people open. The wrench is that box moved to where the trouble is, so the table is widened and nothing is built beside it.

## What is new

- **`help_feedback` widened**: `kind` (`guide`, `want`, `confusing`, `broken`), `page_key`, `page_path` and `context`. `guide_slug` is no longer required. A `confusing` or `broken` note may have no words. No new table, so no fence call.
- **`starts.ts`**: the three starts of the box, the note as it is kept (`noteBody`), and what may be sent with its reason (`canSendNote`).
- **`noteContext.ts`**: the state that goes with a note (`buildNoteContext`), the address with any pass dropped (`notePagePath`), the rows the box lists before the press (`noteContextLines`), the inbox's chips, and the tolerant reader (`parseNoteContext`).
- **`trouble.ts`**: a short memory, in the tab alone, of the error lines shown and the calls the server refused, and the fetch wrapper that feeds it.
- **`fixMode.ts`**: the gear menu's switch, per person per device, on until switched off.
- **`brief.ts`**: a note as a brief for a coding session, by role and never by name.

## Two rules worth knowing

- **A lost signal is not a note.** The owner's rule. The outbox keeps the press and sends it later, so `isLostSignalLine` keeps the no-connection line out of the memory, a call that throws is never remembered, and `errorLineOffersNote` gives that line no press.
- **No picture of the screen.** A note is words and numbers the app already holds, each listed to the sender before the press.
