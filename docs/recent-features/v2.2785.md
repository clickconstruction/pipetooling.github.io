# v2.2785 — Sub work orders from sheets, PR 1: schema + kernel (2026-09-04)

First of five PRs in the owner-approved **Sub Work Orders** train (proposal artifact 7984c992, modeled on a GC's subcontractor work order packet): send a scoped, priced, signed work order to a sub straight from their Sub Labor sheet, built from a scope library kept once, referencing the Contract Book's General Conditions by version date, and visible on the portal, the Subs row and the Person tab. Owner decisions: the amount is **fixed at send** (sheet edits afterwards show drift, never move the signed number).

No visible change in this PR.
