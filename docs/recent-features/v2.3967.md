## Why

## Found on the way (not changed)

- The label loader reads twice on every mount: the reset effect also runs on mount and hands the loader a new empty map, which restarts it. The first read is cancelled.
- A salary prefetch cancelled in flight never finishes: if the day is re-read while the prefetch is waiting, the run is cancelled, the day's key is already spent, and the editor reads *Loading sessions…* until the day or the person changes. It needs a second fetch of an empty day inside the prefetch's round trip.
