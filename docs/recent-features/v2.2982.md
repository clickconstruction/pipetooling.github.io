# v2.2982 — Test-gap audit, pass 10: the cost-estimate page builder and the shared HTML-doc primitives get their first tests (2026-09-06)

Follow-up to v2.2980, which named the cost-estimate page builder next. Tests only — no kernel, client, migration or edge-function change.

## Why these

`bidDocuments/costEstimatePage.ts` (235 lines) is the last untested file in the bid-documents folder: it assembles the Labor / cost-estimate print page — the labor rows and totals, the rough-model materials list (or the three stage POs under the exact model), and the full cost math (labor × rate, driving trips × mileage × distance, estimator cost, travel) — then hands the model to the HTML builders, which already have their own tests. `htmlDoc.ts` is the folder's shared `escapeHtml` / `addressLines` / print-window primitive, used by every document builder, and had none.

## What shipped

- **`costEstimatePage.test.ts`** (10) — the builders and the print side-effect are recorders, the Supabase client is the chainable stand-in, and the labor / cost / takeoff helpers are real. **Rough model**: reads the active version's rough lines (`is bid_version_id null` for the unsplit Base, `eq` for a version), resolves part names and bundle names (`<template> (bundle)`, `Assembly (bundle)` when the template is gone, an id prefix for an unknown part), groups lines per count row in `count_row_id` then `sequence_order` order, sums materials with the real count-multiplier helper or prefers a supplied rough-in total, and hands over the cost block — 10 h × $85, 40 mi at the $0.70 default with 2 h per trip → 5 trips → $140, estimator 2 rows × $15, travel 2 × 1 × $150, grand total; loose parsing of rate / mileage / hours-per-trip and a null distance; no parts → no parts query; an empty labor list → null totals; a nameless bid → "Bid — Labor". **Exact model**: one `purchase_order_items` read per stage that has a PO (ordered by `sequence_order`), item mapping with the "—" part fallback and template name, PO names from the list or "—", stage totals with nulls as 0, a PO read error contributing no items, and `null` / anything-but-rough treated as exact with the $10-per-row estimator default and no travel. **Sub sheets and PO prints**: stage, bid name and parsed rate per sheet; the review vs supply-house variant.
- **`htmlDoc.test.ts`** (4) — the five escapes, first-comma address split, and the print window's write → close → focus → print → close-after-print sequence, with a blocked popup as a quiet no-op.

All 14 passed on the first run.
