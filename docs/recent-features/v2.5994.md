# v2.5994 — An email to someone nobody has named reads as an address on Went out, not a number (2026-10-27)

Wendi tested the Messages page on 2026-10-27 by emailing herself from the app. The address had no phone on it and
nobody had named it, and the row under **Went out** read *A number nobody has named · don't believe the hype · 3:00 PM*.
Her word: "Perhaps change this to 'client nobody has named', since this is an email lead with no number attached to
it." The thread's own header already said it right (`unnamedWords`, v2.5541: an address when the contact has only
addresses); the lanes' rows had one fixed fallback. Her other four findings are punch list #205
(`to-dos/messages-estimator-mailbox/README.md`).

## What changed

- **One rule for a line's unnamed sender** (`unnamedOnLine` in
  [`contacts/names.ts`](../../src/lib/contacts/names.ts), beside `unnamedWords`): the channel the line went on
  decides the words. An email reads *An address nobody has named*; a text, a call, or a line with no channel reads
  *A number nobody has named*, the lanes' default. It reads through `unnamedWords`, so the two never drift. The edge
  copy of the kernel is regenerated (`npm run gen:edge-kernels`; nothing on the edge calls the new function yet).
- **Went out** ([`wentOut.ts`](../../src/lib/messages/wentOut.ts)'s `rowOf`), **Waiting on them**
  ([`waitingOnThem.ts`](../../src/lib/messages/waitingOnThem.ts)) and **the search's hits**
  ([`searchLines.ts`](../../src/lib/messages/searchLines.ts)) name an unnamed person by their line's channel instead of
  the fixed *A number nobody has named*. A customer's own thread still reads the customer's name first, whatever the
  channel.
- The guide [answer everyone waiting on us from one page](../../src/content/help/answer-everyone-waiting-on-us-from-one-page.md)
  says it in the Went out paragraph.

Left as they were: the week strip's Needs a reply waits (`weekStrip.ts`) read a queue row that carries no channel, and
Quickfill's texts ledger names texts alone, so *a number* is right there.
