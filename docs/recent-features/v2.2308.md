# v2.2308 — Stage focus: click a card, see feeders and unlocks (2026-08-25)

Owner ask: clicking a card should highlight it, with the preceding and
following cards highlighted differently.

## Implementation (`ChecklistTechTreeTab` + `GroupNode`, UI-only)

- `focusGroupId` state; `focusNeighbors` memo derives direct upstream
  (edges into the stage) and downstream (edges out) sets from `flowEdgeList`.
- Node data gains `focusRole: 'selected' | 'upstream' | 'downstream' |
  'dimmed' | null`. GroupNode rings: selected = strong blue (with lift
  shadow), upstream = amber, downstream = green; dimmed = 0.35 opacity.
  Ring precedence stays drop-target > just-added > focus > search outline,
  and the search spotlight suppresses focus visuals while active.
- Edge styling in the edges effect: wires into the focus go amber 2.5px,
  out go green, unrelated fade to 0.2 opacity.
- `onNodeClick` toggles focus (ignores clicks on `li/button/input/a` so task
  rows keep opening their card); `onPaneClick` and Esc clear; a
  pointer-events-none legend pill (leads in / selected / unlocks next · tap
  canvas to clear) floats bottom-center only while focused.

## Verification (live, Farm 1)

Clicking "Eat Natural Food": selected ring on it; amber on its six feeders
(Front Kitchen, Pigs Saluter, Goat/Cow/Rabbit slaughter, Stable Scheduled
Farming); green on Host Events + Start on Farm 2; 54 stages dimmed; wires
tinted. Pane click, second click, and Esc all clear. Guide section added.
