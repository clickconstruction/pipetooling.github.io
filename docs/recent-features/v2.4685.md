# v2.4685 — Submittals: a supply house has a usual lead time, so the log gets its dates without typing one on every part (2026-10-06)

Migration `20261006230000_supply_houses_default_lead_time_days.sql` (`docs/migrations/20261006230000_supply_houses_default_lead_time_days.md`, **push owed**); no edge function. Punch list #89, item 2: BP375 read *43 parts have no lead time*, and order-by dates, the answer-by day and the calendar all hang on lead times; the only ways in were per part or **Set…** on all 43.

## What changed

- `supply_houses.default_lead_time_days` — the house's usual lead time, set on the supply house form (**Usual lead time**, a text box that takes *3 wk* or *10 days* through `parseLeadTime`; `SupplyHouseForm` + `useSupplyHouseEditor`).
- `procurementItemsFrom` (`lib/submittals/procurementLogIo.ts`) reads `default_lead_time_days` with the house names it already fetches, and `leadOf(own, houseId)` fills a null lead time from the part's house (a row with no parts from its own). A typed number wins; the row's roll-up still comes before the house. Every reader of the log — the steps, order-by dates, the calendar, *Before you can order* — gets the dates through that one seam.
- `SubmittalPartsEditor`: the empty lead-time box's placeholder is the usual (*3 wk · National Wholesale's usual*), and the box is no longer flagged as owed. `BidsSubmittalsTab` loads the column with the houses it hands the editor.
- Guide *build a submittal package* and the Glossary's supply-house fields.
- **Before the push** the new client still works: both selects retry without the column when it is missing (the Materials tab's legacy-fallback pattern), and the house form sends `default_lead_time_days` only when it changed (the v2.3423 pattern), so an untouched save keeps working.

**Measured first (the card asked):** on 2026-10-06 only two bids carry parts (BP375, BP398: 73 parts), and the `manufacturer` / `model` columns are empty on 70 of them — the words live in `label`. So a per-product memory (*2 wk, as last time*) has nothing to remember yet; the house default carries the load and the memory is deferred.
