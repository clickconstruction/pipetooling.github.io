# v2.4553 — Submittals: larger fold arrows on the steps (2026-10-05)

Client only; no migration, no edge function. The owner, on the Submittals road: "next to each of the titles is a up and down carrot, these are hard to read and should be larger".

## What changed

- The fold control after each step's title (`RoadSection`) was a `▴` / `▾` character at 0.75rem in the faintest text colour: about five pixels of triangle. It is a 14 px chevron now, drawn as an SVG with a 2.25 stroke in `--text-700`, inside its own 24 × 24 button with a border. Up while the step is open, down while it is folded.
- Nothing else about the control changed: the same `aria-label` (*Fold step N* / *Unfold step N*), the same tooltip, the same test id.

## Tests and checks

`SubmittalRoadSection.render.test.tsx`: the folded case reads the button's size and that the chevron points down; the open case that it points up. Checked in the app on BP375: eight buttons, 24 × 24, each pointing the way its step is.
