## What the tests found

Nothing wrong. Contracts now pinned that were only implied:

- Detection asks for a 3-day window, manual-involved pairs only and 500 results unless told otherwise, and maps each RPC row into two lite transactions plus `manualInvolved` and a numeric `daysApart`; a null result is an empty list.
- The excluded list is every transaction marked as a duplicate, newest posted first with nulls last, capped at 500, each carrying its keeper.
- Mark, clear and dismiss go through their RPCs with the ids; any failure throws to the caller.
