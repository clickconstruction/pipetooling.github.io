# v2.2508 — Registration gate + snap/follow tracers + layered-canvas imports (2026-08-30)

Owner caught the M6 trace floating off the linework by overlay; this set makes that
class of failure mechanically impossible to ship and easy to review.

- **Registration gate** (`scripts/placement-engine/registration.ts` + kernel
  `registrationScore`, tested): renders traced pages to grayscale (pdftoppm PGM) and
  scores every run's samples against the ink (±3 px); failures name the worst floating
  gap in RAW px. Proved itself immediately: 11/14 of the original M6 runs failed
  (waste main 10.4% on-ink). Dash-broken styles cap below 100% — thresholds are
  style-aware (75 for —W—/dash-dot, 95+ for solid).
- **`snap.ts`** (vertex → nearest ink) and **`follow.ts`** (walks the ink from an
  anchor, emitting the true path with jogs — the v1 tracer core). Plus the scanline
  method (dark-pixel row/column probes) for locating each system's true position.
  Learned the hard way and documented: **walls masquerade as runs** — a followed path
  needs system-identity confirmation.
- **Re-trace landed**: every surviving run ≥75% (four at 94–100%); the fake CW "east
  wing" (a wall) removed with an on-sheet RFI — east-wing water honestly untraced
  rather than plausibly wrong. 48 counters + 9 registered runs on the project.
- **Layered canvases**: kernel `applyDefaultCanvases` + CT `import-takeoff` groups
  annotations into per-page canvases (Fixtures / one per system / Fittings; `Main`
  back-compat). Live-verified: LIVSTE P201 = 5 layers, P200 = 2 — reviewers toggle
  layers over the plan with the existing canvas switcher / Show-all / Hide-marks.
  CT halves on `feat/robot-pdf-intake` (contract updated in TAKEOFF_IMPORT.md).
- PLACEMENT.md gains the registration workflow; missions table gains the M6-v2 row
  with the stumbles (topology-DPI floats, dash duty cycles, wall mimicry).
