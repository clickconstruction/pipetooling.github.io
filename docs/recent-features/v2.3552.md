# v2.3552 — Submittals stage 6c: the package filed in Drive (2026-09-17)

Client + one migration (`20260917030000_bid_submittals_drive.sql`) + a new edge function (`file-submittal-package`) + `drive-intake` refactored to shared helpers. PR 6c — the last of [`to-dos/submittals/STAGES-5-6-BUILD.md`](../../to-dos/submittals/STAGES-5-6-BUILD.md).

## What shipped

- **Shared helpers** — `supabase/functions/_shared/driveUpload.ts`: `googleAccessToken` (service-account JWT bearer, optional delegation), `findOrCreateFolder`, `findExistingFile`, `uploadFromUrl` (reuse-or-upload by name), `driveFileIdFromUrl`, `driveFolderIdFromUrl` — lifted out of `drive-intake`, which now imports them (no behavior change there).
- **Names** — `_shared/submittalDriveNames.ts` (+3 twin tests): the job folder named as drive-intake names it (`jobFolderName`), `Submittals` under it, the file `Rev N · YYYY-MM-DD.pdf` on the shared date in the company calendar (`packageFileName`), and `isFileable` (shared · superseded · reviewed with a built package; never a draft).
- **`file-submittal-package`** — `POST { submittal_id }` with a staff JWT (a pricing sharer on the bid through `can_access_bid_for_pricing`, or an estimating role): reads the revision, the bid's `drive_link` (the folder drive-intake made) or finds/creates the same-named folder under `DRIVE_JOBS_FOLDER_ID`, finds/creates `Submittals`, mints a 10-minute signed link to the package and uploads it (a same-name file is reused), then stamps `drive_file_id / drive_file_url / drive_filed_at` on the revision and `bids.drive_link` when the bid had none. 503 `not_configured` without the Drive secrets, 409 `not_fileable` for a draft, 502 with the folder link when Google refuses (the quota note points at `DRIVE_IMPERSONATE_USER`).
- **Share files it** — `SubmittalShareModal` invokes the function fire-and-forget after the revision flips shared. **The tab** reads *filed in Drive ↗* on the revision line, or offers **File in Drive** on a shared revision not yet filed (`fileInDrive`).
- Docs: `EDGE_FUNCTIONS.md` (the new function; drive-intake's helpers note), the migration doc, `build-a-submittal-package.md` → "Share it" gains the Drive line, `BIDS_SYSTEM.md`.
