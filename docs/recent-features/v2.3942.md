# v2.3942 — GC Review: print every unpaid invoice for a GC (2026-09-27)

Client only; no migration, no edge function. Owner ask: in Jobs → Stages → GC Review, an option to print all the unpaid invoices for a GC from the GC's Share menu.

## What shipped

- **Share → Print unpaid invoices** on every GC (and development) group in `JobsGcReviewModal.tsx`, under **Print**. It opens one PDF in a new tab: the app's own invoice document (the one View bill builds) for every bill on that group's statement, in the statement's row order. The item reads *Building invoices…* and every group's item is disabled while one PDF builds, so a second click cannot open a second tab.
- **`src/lib/jobs/gcUnpaidInvoicePrint.ts`** (pure):
  - `planGcUnpaidInvoicePrint(group, stageRows)` → `{ targets, rowsWithoutBill }`. A statement row finds its board row by `gcReviewRowKey` (now exported from `gcReviewRollup.ts`, which `toReviewRow` reads); an `invoice`, `job_with_merged_billed` or `job_with_primary_rtb` row names its bill, a `job` row (a balance with no bill line) is counted and has nothing to print; one bill is never listed twice.
  - `gcUnpaidInvoiceDocs(targets, jobsById)` → `{ docs, noLongerUnpaid, failed }`, from the jobs as re-read. A bill prints only while it is `billed` with money open by the board's own rule (`invoiceOpenRemainingOnJob`), so what prints is what the statement counts; a part-paid bill prints. A job that could not be read is `failed`, never "paid".
  - `gcUnpaidInvoicePrintSummary(gcName, counts)` → the toast: how many printed, and each reason a row was left out.
- **`src/lib/jobs/gcUnpaidInvoicePrintIo.ts`** — `openGcUnpaidInvoicesPdfInNewTab`: opens the tab before any await (the pop-up rule `openBilledInvoicePdf.ts` follows), reads the jobs five at a time through `fetchJobWithDetailsById`, builds each PDF with `buildPhysicalInvoicePdfBlob` and joins them with `mergePdfBlobs`. Nothing is written.
- It follows the view: with **Include Collections** ticked the Collections bills are in the PDF. The **Not billed to a GC** bucket keeps its one print icon; it has no Share menu.
- Help guide `track-a-general-contractor-on-a-job` has the new section; `GC_REVIEW_MODAL_ARCHITECTURE.md` names the item, the read and the test file. The map's line numbers and census stay as of its `mapped_at`.
