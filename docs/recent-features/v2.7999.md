# v2.7999 — dev-mcp: the per-version notes move out of the function, 46 KB off its upload (2026-11-19)

A mechanical change with no change to what runs. No server version bump, no migration. Found while building punch list #315's seat verbs.

## What was wrong

`supabase functions deploy` uploads every file a function imports and refuses 5 MB. `npm run check:edge-bundles` holds each upload under 4.5 MB. `dev-mcp` stood at 4.47 MB on main after v2.7976, 33 KB under the ceiling, and the next seat change of #315 alone adds 38 KB. One more verb pair from any session would have failed CI.

The top of `supabase/functions/dev-mcp/index.ts` carried a note for every server version since 0.17.0: what the version added and why. They are comments, and they weighed 46 KB of the upload. The same history is in `docs/EDGE_FUNCTIONS.md` → dev-mcp, a note a version.

## What changed

- The notes moved, word for word, to `docs/dev-mcp/SERVER_NOTES.md`, oldest first, a paragraph a note.
- `index.ts` keeps the description of the door and the counts paragraph, and points at the file.
- **A new server version writes its note at the end of that file**, never as a comment in `index.ts`. `docs/dev-mcp/README.md` → Extending it says so.
- `src/lib/devMcp/devMcpServerNotes.test.ts` holds the rule: no version note in the function's header, a note in the file for the version the server answers with, and a header under 12,000 characters.
- `devMcpTrips.test.ts` pinned one moved note, and now reads it from the file.
- `docs/README.md` lists the file.

`dev-mcp` uploads 4.42 MB.

## How it was done

By a script, so a rebase re-runs it and no marker is resolved by hand. It takes every comment line between the first version note and `const SERVER_VERSION`, refuses to run when a line in that stretch is not a comment, and appends the paragraphs to the file. A second run moves nothing.

## For a seat change in flight

A branch that adds a `// 0.NNN.0 (…)` note to `index.ts` will fail `devMcpServerNotes.test.ts` once it has this change. Move the note to the end of `docs/dev-mcp/SERVER_NOTES.md`.

## Not done here

This buys about four verb pairs. The lasting weight is the tool descriptions in `index.ts` (218 KB), the generated catalog (409 KB) and `devMcpWrites.ts` (145 KB). Splitting the seat is a change of its own, for whoever owns it.

## Checked

- The seat's test files pass. `check:edge-bundles` links all functions.
- The function is not redeployed by this change alone: what runs is the same. The next seat deploy uploads the lighter file.
