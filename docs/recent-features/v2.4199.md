# v2.4199 — The robot's reference is the whole bid, alternate included (2026-09-30)

Alternates round two, PR 5 (after [v2.4198](v2.4198.md)). One migration (`20260930020000_score_locked_shadows_alternates.sql`, [doc](../migrations/20260930020000_score_locked_shadows_alternates.md)); redeploy `twin-mcp` (v1.4.4). Since v2.4195 `bids.bid_value` is the **base** of a bid that offers a with-and-without alternate, but the twin imports and prices every row — the alternate's included — so its locked total is the whole, and scoring it against the base read as an overshoot of exactly the alternate's price.

## What changed

- **One kernel for every reader** — [`_shared/referenceWhole.ts`](../../supabase/functions/_shared/referenceWhole.ts): `referenceWhole(bid_value, cover_letter_alt_texts)` = the base plus every `groups[key].amount` whose `offered` is not false (named from the letter's wording, else the group tag), `referenceWholeValue` (the drop-in for `Number(bid_value)`) and `referenceWholeLabel` (*(base $10,524 + Break room $2,717)*). Tests in `src/lib/twins/referenceWhole.test.ts`.
- **twin-mcp `score_shadows` and `score_backtest`** select `cover_letter_alt_texts`, score against the whole, print the parts on the scorecard line, and return `human_base` / `base` + `add_ons` beside the value. Version 1.4.4.
- **`score_locked_shadows`** (the DB trigger path on send / best effort / lock): the sent reference is `bid_value + Σ offered add-ons`, summed in SQL from the jsonb; the best-effort branch is untouched. Body otherwise verbatim from the v2.3234 definition.
- **The best-effort card** records the whole: the letter's headline plus the offered alternates' add-ons ([`BidsCoverLetterTab`](../../src/components/bids/BidsCoverLetterTab.tsx) `bestEffortAmount`), so the blind comparison and the sent comparison are the same number.
- **The Robot Board** ([`robotMirror.ts`](../../src/lib/bids/robotMirror.ts) `wholeOf`): the *ours* fallback when no `reference_value` is stored, the shell-without-a-run number, the best-effort gap and the moved-off summary all read the whole; [`useBidRobotLayer`](../../src/hooks/useBidRobotLayer.ts) does the same for the gap note at send.

## Deploy

Client first (the card and the board), then `supabase db push`, then `supabase functions deploy twin-mcp`.
