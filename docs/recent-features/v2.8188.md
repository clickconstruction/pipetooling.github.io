# v2.8188 — Painted maps: a place says what is buried, takes a full description, and its presses are big (2026-11-21)

Punch list #413, step 1: Taunya's three changes to the card, on the sheet every place is set from. She asked for them on 2026-11-21 before the build: *deciding what is buried there*, *an open-ended description*, and *that custom button, needs to be easy to click*.

## Why

A place on a painted map said what it was with a small chip, and carried one line of words. The card's plan is for a crew to keep a spot from a photo: a cleanout, a shutoff, a buried line. A plumber marking a buried line has to say what is buried, how deep and which way it runs, and has to do it standing in a yard with a phone in one hand.

## What ships

**Big presses.** The kinds under **What is here?** were chips 36 px tall. They are presses two to a row and 56 px tall. **Add this place** is 56 px tall too.

**What is buried.** A new kind, **Buried line**. Pressing it opens **What is buried?** with six answers: Water, Sewer, Gas, Electric, Irrigation and Cable. Each answer is a kind of its own (`buried_water`, `buried_sewer`, `buried_gas`, `buried_electric`, `buried_irrigation`, `buried_cable`), which the table's check already allows. The place is named for it, such as *Buried sewer line*, and its mark is drawn in the color a locator paints on the ground: blue, green, yellow, red, purple and orange (`BURIED_COLORS`). A second press on an answer takes it off and leaves a buried line. A second press on **Buried line** takes the kind off.

**Something else.** One press the full width of the sheet, **＋ Something else**, for a place on no list. It takes the mark off, clears a name a press gave, and hands the name box the keyboard under **What is it?**. Under **What is buried?** the same press keeps the place a buried line and asks what is buried.

**Describe it.** The one-line box, *A word for whoever comes next*, is **Describe it**: a box that grows, up to the 4,000 characters the table has held since v2.8186. The words keep their lines.

- A list of places, the key under a picture and a text about one place show the short form: the sentences that fit in 160 characters, or the words that fit, with a mark that says it was cut (`shortPlaceWords`).
- In a list, **Read it all** opens the whole description and **Show less** folds it (`PaintedPlaceWords`), on the map's window and on the shared page.
- A printed page, a shared link and a file for another map carry it whole.

## An older build

A phone still on the build before this one draws a buried line's dot as the plain numbered dot, which is the kinds file's own rule for a kind it does not know. It cuts a long description at 160 characters when it reads it, and writes back only what it was shown if that person then saves the place. That window is the minutes between this deploy and the phone's next reload.
