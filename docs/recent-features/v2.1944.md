# v2.1944 — CO cost chips add inline lines directly (2026-08-20)

Owner feedback: after tapping "+ Added work" on a change order you first had to fill a separate prompt panel and press its "Add line" button. Now the chips append an inline-editable line immediately (one line per chip tap, focus lands on the new line's label) and the chips row stays below the list for the next line — the guided prompt panel is removed.

- [`Estimates.tsx`](../../src/pages/Estimates.tsx): `openCoPrompt`/`submitCoPrompt`/`coPromptDraft` replaced by `addCoLine(mode)` (appends `emptyDraftLine()`, credit mode prefills `CO_CREDIT_LABEL_PREFIX`); prompt panel JSX deleted; empty-state/chips-row conditions simplified to `lines.length === 0`.
- **Credit sign without the prompt**: new kernel predicate [`isCoCreditLine`](../../src/lib/coCostLinePrompt.ts) (stored price negative, or label leading with the word "Credit" — the chip's prefill convention). The CO unit-price input shows credit lines as a magnitude, stores it negative (red text, tooltip says the amount is credited back), so the v2.1829 allowNegative rails and the customer document's signed math are unchanged.
- Kernel slimmed: the dead prompt machinery (`emptyCoCostPromptDraft`, `validateCoCostPromptDraft`, `coCostPromptConsequence`, …) is deleted from `coCostLinePrompt.ts`; tests rewritten around `isCoCreditLine`.
- Help guide [`write-a-change-order.md`](../../src/content/help/write-a-change-order.md) updated to the one-tap flow.

Client-only — no migration.
