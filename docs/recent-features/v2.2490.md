# v2.2490 — Needs You: GC weekly item + done notice (banner migration 4/6) (2026-08-29)

Fourth v2.2339 follow-up: `DashboardGcReviewWeeklyBanner`'s due state (v2.1984)
folds into the Needs You card. Stacked on v2.2489.

- **New hook `src/hooks/useGcReviewWeekNudge.ts`**: fetches
  `fetchGcReviewWeekStatus(gcReviewWeekStartYmd())`; exposes `loaded` so the
  banner's onCount seam can still report 0 on error (Quickfill's station
  count would otherwise stay in loading).
- **Kernel**: inputs `gcReviewEnabled/Status/Nudge/IsWednesday`; item
  `gc-review-weekly` (amber, kicker "Wednesday ritual", action "Open GC
  Review" → `/jobs?tab=stages&gcReview=1`) only when the nudge state is
  `due`. The nudge state and weekday are **computed by the parent**
  (`gcReviewNudgeState` takes `now` — calling it in the kernel would make the
  builder clock-dependent and its tests day-of-week-flaky).
- **Done state stays visible**: the green rest-of-Wednesday confirmation is
  extracted as exported `GcReviewWeekDoneNotice` (same file); the Dashboard
  quick row renders it directly from the hook's status when state is `done` —
  a "needs you" list is the wrong home for a well-done note.
- **Quickfill**: `gcReviewEnabled: false` (dedicated GC weekly station,
  v2.2347); the banner survives there, now hook-backed.
- Tests: 2 new kernel tests (due copy + figure math, done/hidden/gate).
  Help guide updated.
