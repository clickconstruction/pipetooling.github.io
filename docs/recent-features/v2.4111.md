# v2.4111 — Lien timeline: consecutive closed notice months fold into one stacked node (2026-09-29)

Client only; no migration, no edge function. Mock-up: board 8 of the runway canvas (*The strip's repeats fold into one*). The owner, reading a Dudley Mason job on the Lien desk with four red *§ 53.056 · window closed · noted* nodes in a row: *when there are multiple windows closed, perhaps instead of repeating the same thing four times we can figure out a better way to show it once.*

## What changed

- **`src/lib/jobs/lienTimeline.ts`** — `foldClosedNoticeSteps(steps)` runs on the built steps before `todayIndex` (which now counts the folded strip; `next` and `waitingOn` read the unfolded steps as before). Two or more **consecutive** notice steps in state `missed` whose words start *window closed* become one step: `kind: 'notice'`, key `notice-fold:<from>:<to>`, label *§ 53.056 · May–Aug*, `dateWords` *4 windows closed*, `words` *all noted* · *3 noted · 1 to note* · *window closed* (when the reader cannot know, the Lien window without desk items), `date` the last month's deadline, `move: null`, and `fold: { steps, count, noted, unnoted, unknown, fromMonthKey, toMonthKey }` with the folded steps kept whole. A single closed month stays as it was; a month *skipped on purpose*, a sent month or an open one breaks the run. The type gains `LienTimelineFold` and `fold?` on the step. 4 tests.
- **`src/components/jobs/LienTimelineStrip.tsx`** — a folded step draws as three overlapping discs (the fold reads before any word) with a count badge; its words paint the *N to note* fragment amber; *show the months ›* under it (row and list layouts) fans a tray open beneath the strip — one cell per month: label, *closed <day>*, who noted it or *not noted* in amber. The hover on the node lists the months. The mini row draws the stacked node and no door. The **Windows** view still writes one *closed … it was open …* line per folded month. 2 render tests.
- Guide *send lien notices from the Lien desk*: the strip's missed-month bullet.

**Not done:** the mock-up's *$4,120 no longer lienable* — the timeline's months carry no dollars; the cost joins when they do.
