# v2.5806 — Banking: the Account nicknames window says what each Mercury account is (2026-10-23)

Punch list #155 (`to-dos/account-nicknames-modal/`, built the day it was asked). The owner, with the modal open on `/banking?tab=ledger&product=mercury`: *"This modal is extremely hard to use because my method for naming accounts relies on seeing the transactions and going into Mercury and matching them. Would you be able to help me improve this modal where this becomes more possible. Please come up with a mock-up and then ask yourself is this the best we can do, and then build the result and present it to me with screenshots."* A row was an eight-letter id, a Nickname box, Save and Clear, so he matched transactions by eye between Mercury and the ledger. Two of the ten accounts had no nickname.

**What was checked first.** `mercury_transactions.raw` is Mercury's transaction object (`_shared/mercuryTransaction.ts`): it carries `accountId` and nothing else about the account. `sync-mercury-transactions` reads `/transactions` only and never Mercury's `/accounts`. `get-mercury-account-balances` (the Balance Sheet's cash line, the Bridge) does read `/accounts` and returns each account's id, name, kind and balances, archived accounts filtered out, the same ids the transactions carry. It does not pass the account number on, and need not: Mercury's names carry the last four (*Mercury Checking ••8103*).

- **Kernel** `src/lib/banking/accountFacts.ts` (tests beside it, a 400-row ledger over four accounts): `buildAccountFacts(rows)` gives each account its count, first and last date (`posted_at`, else `created_at`), money in and out to the cent, the three counterparties that recur most (case-insensitive, a row with none under *No counterparty*) and the four newest lines; `orderAccountsForNaming` puts the unnamed first, busiest first, then the named by nickname; `formatMercuryAccountKind` says *Checking* for Mercury's `mercury`; `indexMercuryAccounts` keys Mercury's list by id.
- **The modal** (`BankingAccountNicknamesModal.tsx`, render smoke beside it): one card per account. An unnamed card is amber with *No nickname yet*. *Mercury calls it* **name** · kind · balance comes from Mercury's account list, read once per open through `loadMercuryCash` (the Bridge's reader of `get-mercury-account-balances`), with **Use this name** putting the name in the box; an account Mercury no longer lists says *Not on Mercury's account list*. The full id with **Copy** (the clipboard, else the text selected). The facts and the newest lines from the kernel; *No transactions yet in the ledger* for an empty account. **Show in ledger** closes the modal with the Ledger's account filter set. Save on Enter. Save, Clear and the empty-box rule unchanged; the write is the same `mercury_account_nicknames` upsert and delete; dev only. Theme tokens, light and dark, phone width.
- **The page** (`Banking.tsx`): the modal gets the rows the page holds and whether they are the whole ledger (`nicknameFactsRowsComplete`: the master list loaded and not capped at 15,000). Opened from the Accounting tab or the Card Review tab, which do not load the master list, the modal says so and the page reads each account's exact count with one `head: true` count query per account (`nicknameExactCounts`), no row fetch. The door sets `accountFilter` and the Ledger tab.
