# v2.3841 — Bids → Pricing: every price option card shows its real total (2026-09-25)

The `wbScenarioRevenue` note of [`BIDS_PRICING_LABOR_TABS_ARCHITECTURE.md`](../BIDS_PRICING_LABOR_TABS_ARCHITECTURE.md) (the scenario pricing adapter, copy 2 of 4), found by the 2026-09-25 map sweep. Client only, no migration.

## The bug

`loadBidPricings` loads the price scenarios of **every** bid version (per-GC variant), and the workbench effect in [`BidsPricingTab.tsx`](../../src/components/bids/BidsPricingTab.tsx) priced each of them against `pricingCountRows` — the **active** version's count rows. Count rows are per version with their own ids (`20260823034820_count_rows_per_version.sql`), so another version's scenario matched none of them and came out \$0.

On the normal path the cards are scoped to the active version, so the wrong numbers were computed but never shown. The legacy fallback shows them: when the active version owns no scenario (`scoped` empty → `owned = all`, a legacy pointer), every other version's card read \$0 — no margin, no "offered" badge, never eligible as the *Copy prices from* source. The same class of bug v2.3685 fixed for Share / print / CSV in `packageRowsFromInputs`.

## The change

- New kernel [`lib/bids/scenarioCardRevenues.ts`](../../src/lib/bids/scenarioCardRevenues.ts) — `scenarioCardRevenues(...)`: each scenario prices on its own bid version's rows (the on-screen rows when it is the active version, else the rows supplied for its version; a version with no rows supplied is left out, so its card reads "not priced" rather than a wrong \$0) — the own-rows rule of the tab's `loadScenarioInputs`.
- The effect fetches the bid's other versions' count rows (`id, fixture, count, bid_version_id`, one query, only when a scenario of another version exists), groups them by version and calls the kernel. It also re-runs when the active version changes.

## Verified

- `scenarioCardRevenues.test.ts` (5): the active scenario on the on-screen rows; another version's scenario on its own rows (the \$0 case); a version with no rows left out; a legacy unversioned bid; a scenario's own custom price counted and another's ignored.
