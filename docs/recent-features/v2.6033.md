# v2.6033 — Push me: the line reads "Pushed every day" in one case (2026-10-28)

The fix is in `pushHoursLine` (`src/lib/messages/pushHours.ts`): the one capitalised word drops its first letter there, and the office card keeps its line. The two tests that pinned the old words now pin *Pushed every day, 6:00 AM to 8:00 PM.* No migration, no function.

The walk itself (the dev's account, on the worktree dev server against prod, 2026-10-28 ~18:00Z): the press on **Push me only at these hours** saved at once, the row read back after a reload, **Push me any time** cleared it, and a reload read any time again, so nothing was left on the account.
