# v2.5428 — Messages: a place for two inboxes and two numbers, behind the scenes (2026-10-12)

Residential R6 (two boxes, two numbers, one inbox), PR 1 of 4: the migration `20261014003000_messages_two_boxes.sql`
(`docs/migrations/20261014003000_messages_two_boxes.md`), after the kernel (`src/lib/messages/boxes.ts`, v2.5418). No
edge function and no screen; the lead pushes the migration by hand after merge, at a quiet moment. Next: the reader
(`gmail-sync` reads two boxes by `mailbox`), compose and sort (`mailboxFor`, `fromNumberFor`), and `quo-webhook`
stamping the box from Quo's to-number and writing `stopScope`, after #5452.

- **`messages.mailbox`** (`team` or `bids`): the box a call, text or email came through, null on a note, an event or a
  portal line. Backfilled from `gmail_id` (bids) and `quo_id` (team). `quo_write_line` and `email_write_line` carry it,
  and default to today's one box while the functions send none.
- **`contact_channels.opted_out_by_box`**: a STOP per box, since a carrier's STOP is per number pair. No entry reads
  `opted_out_at`, which stops every box. `contacts_fold` keeps a STOP to either box through
  `contact_channels_keep_stops`, a guarded definer, since the fold runs as the office and nobody signed in writes a STOP.
- **`app_settings` `messages_boxes_v1`**: each box's address, number and Quo id, shipped empty so no address is in the
  repo; team@ or office@ is the owner's answer typed into Settings. The functions fall back to today's secrets while a
  field is empty. The owner or a dev changes it.
- **`gmail_sync_state`**: one row per box, keyed by `mailbox`. The old `id` stays `true` on the bids row alone so the
  deployed `gmail-sync` keeps finding it; no team row yet, since Settings' **Read bids@** card reads one row.
- **The bed**: `npm run test:pg:messages-email` gains `25_two_boxes_before.sql` and `30_two_boxes.sql`, in CI's SQL
  beds workflow.

Open for the owner (none blocks this SQL): team@ or office@; whether it is a real Workspace user or a group or alias;
the second Quo number for bids; counsel on whether a STOP to one number must silence the other.
