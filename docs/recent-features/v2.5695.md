# v2.5695 — Estimates: the Tell the customer sheet shows its receipt after the send (2026-10-20)

PR 4 of punch list #139 (`to-dos/press-always-answers/README.md`; PRs 1–3 are v2.5681, v2.5683, v2.5686), from the live walk the night the train merged. The walk found the root of Taunya's report, which the train's PR 1 had narrowed but not closed: **the receipt never showed after a successful estimate send, for anyone, since v2.5594.** No migration; no edge function change.

- **The measurement**: a read-only observer on the sent page (the owner pressing the send, the agent reading) logged the sheet's title through the press — *Tell ZZ* → **null** → *Tell the customer* → *Tell ZZ* → **null** → *Tell the customer* (the page badge flipping to Sent in the same tick) → *Tell ZZ*; the receipt never rendered. The sheet was unmounted twice: once by `saveDraft()`'s reload before the send, once by the refresh after it. Both go through `load()`, which starts with `setLoading(true)`, and the detail render returns a bare *Loading…* tree while `loading` is true — so the whole page, sheet included, unmounts, and `setView('receipt')` lands on a dead instance while a fresh sheet draws the Tell view. No band, no receipt, the same green button: exactly the screenshot.
- **The fix** (`src/pages/Estimates.tsx`): `load({ refresh: true })` keeps the loaded page up and swaps the row in when the read lands (the flag only flips on a cold load); the send path uses it, and its pre-send save is `saveDraft({ skipReload: true })` — the one refresh after the send re-seeds the editor. And the sheet now renders above the loading early-return, first in both trees and keyed, so no future refresh can unmount it either.
- **Why the smokes missed it**: the sheet's smoke hands it a fake `sendEmail` that never touches the page; the page has no render smoke of its own. The guard is structural (the sheet outside the early return); the live walk's observer is the check.

**Not in this PR**: the resend-from-the-page button (`resendCustomerLink`) still refreshes through a blanking `load()`; it opens no sheet, so nothing is lost, and it can take `refresh: true` with the next touch.
