# v2.6999 — First look: the ask from a thread and the card above its lines (2026-11-12)

Punch list #319, PR 1 of the train (`to-dos/show-us-the-problem/README.md`). The spike (v2.6981) proved the page and the upload for the owner and the developers. This opens the ask to the office team, on a person's thread.

**One change from the card's plan.** PR 1 was planned with no link, fed only by texted pictures, because the page did not exist yet. The spike put the page on main, so the ask carries the link from the first day, on the app's own address. The short address and the light page are still PR 4.

- **The ask.** `/show`, `/photo` or `/video` in the reply box leads the `/` list with the app's own line (`showAskLine` in `src/lib/firstLook/ask.ts`, an app line as a stage's are, never counted as a press). A pick puts it in with the sender's name and the blank `{show}`, and `mint_first_look` makes the look for that thread and answers its code once. The blank takes the link when it is back, as `{rate}` does, so the send waits on the link (`SHOW_ASK_WORDS.making`) and a mint that fails leaves the blank, which holds the send. `{show}` is in the blanks' table, so a team line may hold it. The line is in Spanish for a person who reads Spanish, and it ends with the way round the page: reply to the text with the photos.
- **The card.** `FirstLookCards` (`src/components/firstLook/`) fills the thread's `aboveLines` slot through `useFirstLookThreadSlots`. One card a look that is not closed: who asked and when, where it stands (`lookStanding`), the page's files drawn from a signed address, the pictures and videos the person sent in since the ask (`textedSince`, off the thread's own lines), their words, and the presses. The newest look still taking files always draws. An older one draws only while it holds something. The rules are `src/lib/firstLook/card.ts`.
- **The presses.** Start an estimate and Book a visit run the lead's doors for a lead and skip the convert for a customer. A number nobody named gets neither and is told to name them. Ask again and Ask for more ask the thread's own reply box through `askBus.ts`. Close the look asks first.
- **The stamps.** `stamp_first_look` marks a look looked at the first time the office sees files on it, and closed.
- **The send is the customer's line.** `first-look`'s `send` now writes the thread's line as theirs (`channel 'portal'`, `direction 'in'`), as a word from their portal page is. So the thread goes to Needs a reply, the header counts it and the reply push's sweep reaches whoever has it. It was an event line from the app in the spike.
- **A file the browser cannot draw** (an iPhone's HEIC in Chrome, a video it cannot play) becomes a named chip with Open, in place of a broken picture or an empty player.
