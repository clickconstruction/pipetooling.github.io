# v2.1952 — Checklist mobile viewport fix (2026-08-21)

On 375px phones the Checklist page rendered zoomed out: `window.innerWidth` reported ~624px against a 375px visual viewport, so mobile browsers shrank the whole page to fit. The width-forcer was the page's tab header row in [`Checklist.tsx`](../../src/pages/Checklist.tsx) — a nowrap flex row of the five tab buttons (Today/History/Review/Manage/Roadmap) plus the right-aligned `Checklist` h1, whose combined content width (624px) expanded the layout viewport. (The fixed bottom nav was a red herring — `left:0; right:0` follows the viewport, it doesn't force it.)

Fix: `flexWrap: 'wrap'` on the header row, matching the Prospects/Partnerships tab-row convention. Desktop is unchanged (one line); at 375px the tabs wrap to two rows with the title below, and all five Checklist tabs (Review folds expanded included) now hold `document.scrollWidth === 375`. Client-only, one-line change — no migration.
