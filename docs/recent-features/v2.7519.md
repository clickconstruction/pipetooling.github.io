# v2.7519 — Print labels: a card says which boxes are not printed yet (2026-11-16)

PR 2 of 2, the screens, over the column v2.7518 added (`job_containers.label_printed_at`, [its page](../migrations/20261117110000_box_label_printed.md)). **Must not merge before that migration is pushed**: the store names the column in the read of every box.

## The mark is written

In the labels window ([`LabelsPrintModal.tsx`](../../src/components/materials/LabelsPrintModal.tsx)), through `markLabelsPrinted` in the store: one press a job, a row a box, drawn at once and sent and kept for want of signal as every other change to a box is.

- **Straight to the P-touch**: when the run ends, however it ends, every box whose last strip came out is marked (`boxesWhoseLabelWent`). A box part way through its copies is not. A run the printer stopped marks what came out.
- **Through the print window**, tape or paper: the boxes the window was opened on are marked when it closes (`afterprint`). The app cannot see the paper, so a cancelled print window marks them too.
- **A line under the run** says how many boxes had no mark before and now do, *12 boxes are now marked as labelled. Did they not print?*, with **Take the mark off 12 boxes**, which clears those alone. A box that was marked before a reprint keeps its mark.
- **Mark N boxes as labelled**, a quiet press beside the CSV export: for a label from the CSV or made by hand. It counts the ticked boxes with no mark and is gone when there are none.
- **A test strip marks nothing.**

## The mark is read

[`labelMark.ts`](../../src/lib/materials/labelMark.ts), pure and tested, read by the cards' kernel `printLabelsJobs.ts`.

- A box is **not printed yet** when it was made since `LABEL_MARK_SINCE`, has no mark and wears no sticker (`notPrintedIds`). A sticker is a label.
- **A box made before the mark began is not counted.** It reads unmarked whether or not it wears a label, and nothing can tell the two apart. `LABEL_MARK_SINCE` is midnight of 2026-11-17 in the app's time zone.
- On a card: an amber chip *5 not printed yet*, the door **The 5 not printed yet** where **The N new** was, and a green chip *Every box is labelled* when each box has a mark or a sticker (`everyBoxLabelled`). A job with boxes waiting sorts ahead of one with none.
- The count waits for the read of the stickers. If that read fails the count stands on the mark alone.
- **Gone**: the chip *N added this week*, the door **The N new**, `addedLatelyIds`, `LABEL_NEW_DAYS` and the clock the window handed the kernel.

## Not built

- **A renamed box keeps its mark**, though a label that prints its new name has not gone out.
- The mark shows on the *Which job?* cards alone: not on a box's row, its window or the phone.
- The labels window has no pick of its own for the boxes not printed yet. The card's door is the way in.
- Nobody is named: the column holds when, not who.
