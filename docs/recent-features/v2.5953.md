## Is this the best we can do?

Every press is the surface's own control, reached through a prop where the opener lives one level up (`onOpenBill`, `onSchedule`, `onClearFilter`, `onNewJob`, `onManagePeople`, `onPreviousWeek`, `onShowAll`). One page link: the bank transfer details point editors at Settings → Company, the panel's own door before. Three sentences carry no press because none fits: *No jobs in Working match the filters.* (the board's five filter chips each have their own ×, and Hide groups is a saved per-device choice an empty group should not clear; one *Clear the filters* on the command bar would let a later PR name it here), the deposit list's All with nothing in it (Refresh from Mercury lives on Banking, which is controller and up), and the Scatter view's thin-margin table (the window is the toolbar's, above it). Words that would read better in the owner's voice: *Nothing in Waiting needs you.* for a group that is simply empty (the README's suggestion, kept), the statement history's *each word logged in GC Review*, and the Paid in Full group's *No jobs in Paid in Full yet.* The Subs work board's filter press has no assertion yet: its smoke runs against an empty board.
