## What shipped

- **`src/components/my-time-day-editor/MyTimeDayTimelineBody.tsx`** (new) — a verbatim move of the modal's `myTimeDayTimelineScroll` box. It holds:
  - an Off clock strip for each gap
  - each cluster's overlap warning, and its `MyTimeDayClusterVisual` or `MyTimeDayClusterForm` with the ~30-prop bundle
  - the + Add session tail with its gate

  The timeline memos only it read move with it: `timelineItems`, `daySpanMs` and `totalDur`. Every prop keeps the shell's name, so the JSX is unchanged but for its indent. The prop types come from the two hooks' return types and the Visual editor's props.
- **`myTimeDayEditorDatetime.ts`** — `formatDurationMs` moves here from the modal, verbatim. The gap strips and the modal's clocked subtitle both use it.
- **`DashboardMyTimeDayEditorModal.tsx`** — renders `<MyTimeDayTimelineBody>` where the box stood. 1,695 → 1,511 lines; the nine imports it no longer uses are gone, among them `Fragment` and the two cluster editors.

## Tests (+5)

- `MyTimeDayTimelineBody.render.test.tsx`, with the real Visual and Form editors:
  - **Visual:** an Off clock strip for an hour's gap and one strip per cluster. Each strip registers in `stripRefs` under its cluster id. It hands its pointer and key events to the shell with that id and that cluster's sessions; passing the whole day instead fails it.
  - **Form:** the same clusters with a Split per segment, and no strips.
  - **Loading:** *Loading editor…* until every cluster is seeded.
  - **Reject session:** offered only while punch actions are allowed and nothing is saving. Dropping `allowPunchTimeActions` from the gate fails it. The editors hide it while saving as well.
  - **+ Add session:** opens with the computed defaults and is disabled while saving. It hides for a parent's sessions, a load, the sign-in wait, the prior-week gate, no punch actions and an uneditable day.
