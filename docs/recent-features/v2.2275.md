# v2.2275 — Team review: due pill + Upcoming reviews modal + short role labels (2026-08-25)

Three requests on Prospects → Hiring → Review (`TeamReviewSection`), mockup at
the "Team Reviews Due" artifact:

- **Due count up front**: the small "N due" text squeezed into the deck-nav row
  moves to a tappable pill beside "Your average" — orange `● N due ›` when
  reviews are owed, green `✓ Caught up · next in Nd ›` otherwise (so the
  schedule stays one tap away either way). The old nav-row chip is removed.
- **Upcoming reviews modal**: tapping the pill lists everyone by when their
  next review comes due — "Due now" group (never reviewed / overdue) first,
  then "Coming up" with `in Nd · Aug 29` and each person's last-review date.
  Tapping a person jumps the rate deck to their card. Backed by new kernel
  fn **`upcomingReviewSchedule`** in `src/lib/prospects/teamReviewDue.ts`
  (same last-save math as `overdueReviewSubjects`, so `dueInDays <= 0` agrees
  exactly with the due set; unit-tested).
- **Short role labels**: the person picker, card chips, and modal use
  `guideLensRoleLabel` ("Master", "Sub", "Helper" — the glossary's spoken
  names) instead of `displayLabelForUserRole`'s raw slugs
  ("Master_technician"), which wrapped on phone-width pickers.
- Help guide `team-prospects` updated for the pill + modal.
