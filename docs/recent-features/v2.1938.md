# v2.1938 — Section-header buttons onto the quiet tier (2026-08-20)

Three Pipeline section-header buttons predated the v2.1311 quiet-action-tier
pass and never got migrated: **Ready to Bill notifications**, the Paid
section's **Chart**, and **Paid In Full notifications** — 32px tall with a
`--border-strong` border, 0.8125rem/600 labels, and 1rem icons, sitting one
row away from the 28px tier (GC Review / Accounts Receivable / Share/Print /
Chart / Payment forecast / Paid notifications).

- All three now use the shared `billedHeaderActionStyle` (28px, hairline
  `--border`, muted 0.75rem/500, icon at label size). Accounts Receivable
  keeps its designed one-shade-stronger emphasis + badge, unchanged. The ⋯
  Pipeline-tools icon by the search bar stays 32px — icon-only menu trigger,
  different context.
- Capitalization sweep: "Paid **In** Full notifications" → "Paid **in** Full
  notifications" (matching the section title) in the button, the section
  tools-menu label (`stagesSectionToolsMenu.ts`), the Settings email-streams
  pointer, and the `ready-to-bill-pipeline` help guide.
  `releaseNotesArchive.ts` is frozen and keeps the old spelling.
- Verified in-browser: every header action measures 28px / 12px / weight 500.
