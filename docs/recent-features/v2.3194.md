# v2.3194 — Fix: the stage picker never loaded (detached `supabase.rpc`) (2026-09-09)

Client only. Found while taking the v2.3192 screenshots: [`NewReportModal`](../../src/components/NewReportModal.tsx) called the two untyped RPCs through `const rpc = supabase.rpc as unknown as (…)` — a **detached** method, so `this` was undefined inside supabase-js and the call threw before any request left the browser. The `catch` did exactly what it was designed for (fall back to the plain slider), which is why the "fallback verified live" note in v2.3192 was really this bug. Both call sites now use `supabase.rpc.bind(supabase)`. Verified with the RPC mocked at the network layer: the picker renders, Done ✓ on Rough-in reads *60% of the job · was 46% · Rough-in 100% × 35% = 35 pts*, Top-out at 50% reads *54% · 8 pts*. No other change. Release note `v2.3194.ts`.
