# v2.5475 — Lien desk: a price the mail service will not quote no longer holds an envelope, behind the scenes (Docsmit train, fix) (2026-10-13)

Found while walking the owner through Docsmit's API reference before the first Tracksmit run. `GET /messages/{id}/priceCheck` wants `certify`, `months` and `sendType` (SR | NSR) or answers 400, and its answer is `netPrice` with `details.total` as "$ 2.49", not `price`; v2.5381's client sent no query and read the wrong keys, and `prepare` marked the piece failed when the call threw.

**`_shared/docsmitClient.ts`** `priceCheck`: the three query fields ride along; `netPrice`, then `price` / `cost` / `total` / `amount`, then `details.total` / `details.netPrice` (money strings parsed); a 400 or an unknown shape gives null. **`mail-send-docsmit`** `prepare`: a priceCheck that fails never holds the envelope; the piece stays `prepared` with no price (the run's price line reads *not priced yet*) and the raw answer rides on the `message_made` event. The send's 402 remains the real word on credit. One more handler test.
