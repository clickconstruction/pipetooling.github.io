## `src/lib/people/reviewLoaderQueries.ts`

Moved verbatim from the top of `PeopleReviewTab.tsx`, now exported, with 14 tests where there were none:

- **`throwIfQueryError(results, label)`** — a failed query in a wave throws a `DatabaseError` naming the load; stub results with no `error` key pass.
- **`paged(makePage, label)`** — pages a read past PostgREST's silent 1,000-row cap and hands back `{ data, error: null }`; a failed page rejects, never an empty result.
- **`laborRowJobId(row)`** — a sheet row's job is its link, or null.
- **`fetchJobStatusesByIds(ids)`** — `jobs_ledger.status` by id, chunked and paged; no ids asks nothing; a failed read is an empty map and a console warning, so a finished job reads as not finished rather than the load failing.

`PeopleReviewTab.tsx` imports the four and drops its copies and the `DatabaseError` import only they used. 4,091 → 4,034 lines.
