# v2.4143 — Submittals: Assign pages — walk the vendor PDF, one page at a time, the answer pre-filled (2026-09-29)

The owner, on the cut-sheet strip (2026-09-29): "specifying what pages go into the cut sheet per fixture is very hard in this current method, it needs to be intuitive" — and proposed a full-screen walk: the page on one side, the fixture lines on the other, click one and it moves to the next, undo, a picker along the bottom. Before this the strip asked the question from the wrong side — find pages for a row among 75 stamp-sized thumbnails, then type `3-4` — so the hunt was the work. The drawing (before / the walk / the owner's call) and its reasoning are in `to-dos/submittals/assign-pages-before-after.html`. The owner's call on the first draft: **every page is reviewed** — the package is submitted to the customer — so the draft's "check only the unread pages" exit was dropped; the reader still pre-fills, but Done unlocks at N of N seen.

## The kernel — [`assignPagesWalk.ts`](../../src/lib/submittals/assignPagesWalk.ts) (10 tests)

- `rowModels` / `walkRowsFrom`: the strings that name a row on a page — the submitted model whole and its model-like tokens (four characters with a digit: `Z1700 500 OV`, `Z1700`, not `ET`), the specified model, the label's model tokens — normalized like page text (`normalizeText`: upper-case, non-alphanumerics to one space, padded for token boundaries).
- `readPages(texts, rows)`: per page, the row whose longest model is on it (ties → the earlier row), else a tag with a digit in it (`WC-1`, never `FD`); a page naming four or more rows is the **index**; under 20 characters of text (a scan, a blank) reads nothing. `readsFromGuesses` folds the robot's *sure* `file_cut_sheets` guesses in as tag reads.
- `suggestFor(page, decisions, reads, rows)`: **kept** (already on a row) → **read** → **continue** (the row the page before is on) → **next** (the first row in order with no page after the last row placed; the PDF follows the schedule) → none.
- `decide` / `clearDecision` / `pagesByItem` / `runStart` / `nextUndecided`; `walkSummary` (placed, skipped, undecided, seen, rows with nothing, `done` = every page seen **and** decided), `walkProgressText`, `doneButtonText` (*Done — 23 of 75 seen* → *Done — put 61 pages on rows*).
- `initialDecisions(items, fileIndex)`: what the rows already hold in this file, kept and still seen. `decisionsToWrites`: only the rows whose pages in this file changed — a row that had pages in another file moves here (a row's sheet lives in one file), a row that had pages here and now has none is cleared.
- `findPagesForRow`: the pages whose text names the row. `rowColor`: the strip's palette by row order.

## The modal — [`SubmittalAssignPagesModal.tsx`](../../src/components/bids/SubmittalAssignPagesModal.tsx) (2 render smokes)

- Opens the file once (`openPdf` in [`pdfThumbnails.ts`](../../src/lib/submittals/pdfThumbnails.ts): the page count, `renderPage(page, width)`, `pageText(page)`), then draws every page's thumbnail and reads its text in order (the header says *reading…* until done); the page at reading size (760 px) is drawn when reached and kept.
- Left: the banner (green when read or kept, amber when continuing or next, grey when nothing to suggest — *Looks like WHA-500 · its model number is on the page* · *WHA-500 continues · same as page 21–22* · *Next in the schedule: WC-1* · *Looks like the index — not a cut sheet*), the page counter, the page. Right: the rows in order with their color, label and pages in this file (*p. 21–22*, *no sheet yet* in amber for a row that wants one), the suggested row lit; a *find its pages* line under a row with nothing once the text is read. Bottom: every page as a strip — the row's color bar, hatched for not-a-sheet, grey for undecided, dim for not seen, the run's tag at its first page; click to jump.
- Keys on the focused dialog: **Space** (and Enter with no filter) takes the suggestion and moves on; **Enter** with a filter picks the first match; **X** skips; **← →** move without deciding; **Backspace** undoes the last pick (or deletes a filter character); **Escape** clears the filter, else Cancel; any other character types into the filter (tag, label or model). Cancel with unwritten picks asks first.
- **Done** (`decisionsToWrites` → the tab's `applyAssignWrites`: `writeItemPages` per changed row, then the rows reload) is disabled until `summary.done`. The strip's header gains **Assign pages…** (`SubmittalSheetStrip` prop `onAssignPages`); the tab passes the file's bytes (`downloadFile`) and the robot's guesses for the file.
