## What shipped

- **`scripts/one-company-policy-sweep.py`** (new; Python 3.11 + `pglast`): replays every migration in order to find the *live* definition of each RLS policy, selects the permissive ones whose `USING` / `WITH CHECK` still compare `master_user_id = auth.uid()` or consult `master_assistants` / `master_shares` (or their helpers) inline, and emits `DROP POLICY IF EXISTS` + `CREATE POLICY` with the same name / command / roles / expression wrapped as `public.is_office_staff() OR (<old>)`. It refuses restrictive policies and skips `users` and `master_shares`. Self-checks that its output parses. Re-run it on a rebase conflict; never hand-edit the output.
- **The migration** ([doc](../migrations/20260906200000_one_company_policy_sweep.md)): 135 policies on 47 tables. Office roles pass outright; superintendent / primary / estimator / field / customer-side branches are byte-identical.

## Finding recorded

`sync_company_access_grants()` (v2.921, 2026-07-22) already adopts every live office user under every dev/master and shares every master pair, so the ~52 RPC gates that still read `master_assistants` / `master_shares` inline already say yes to the whole office.
