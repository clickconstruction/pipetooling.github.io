# v2.2752 — File a signed contract: typing a link keeps the box open (2026-09-04)

Follow-up to v2.2744. The "File a signed contract" sheet flipped from the link input to the green "Google Doc linked" line as soon as the text became a valid URL (`https://d` already qualifies), so anyone **typing** a link lost the input after nine characters and the rest of the keystrokes went to the page — where `/` opens the Person Desk sheet.

- The green line now appears only when the link is **committed**: on paste, Enter, or leaving the field. Typing keeps the input mounted.
- `change` clears both the link and the committed flag; the non-Google note also waits for the commit.
- `Record as signed` still enables the moment the text is an `https` link.

Files: `src/components/jobs/JobContractModal.tsx` (`paperLinkCommitted` state).
