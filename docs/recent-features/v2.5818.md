# v2.5818 — Quickfill Physical inbox: the clarify deck (2026-10-24)

Punch list #158, PR 2 of the build (the table and the kernel were v2.5815). The station that held one free box retyped every morning is now GTD's inbox step as a card: one paper per row, one press per paper, the count the undecided paper with its age.

- **The deck** ([`QuickfillPhysicalInboxSection.tsx`](../../src/components/quickfill/QuickfillPhysicalInboxSection.tsx), rewritten): the intro line (*A paper that takes two minutes is done, not typed…*), an add line (Enter or **Add**, the title through `normalizePaperTitle`, dated today in the app's calendar), the words line (*5 undecided · oldest 66 d*, or *Nothing undecided · The tray is clear.* in green), then one card per open paper oldest first: the title, the age chip (`PHYSICAL_INBOX_PAPER_AGE`: grey, amber from two days, red from a week), who typed it, and the presses **Done** · **Trash** · **File it ▾** (an inline *Where?* with the five usual places as buttons and a box for any other) · **Task** · **Ask ▾** (*Ask dispatch* · *Ask estimating*). A press writes `pressPatch` through the hook and leaves a green line (*Filed · The cabinet · New insurance cards, 6 trucks*) with **Undo**, which writes `BACK_ON_DECK_PATCH`. Task and Ask show by the header's own role gates (Task for dev, master, assistant-like, primary and estimator; Ask without primary).
- **The three windows hand back what they made**: `ChecklistAddModalContext.onSaved` now receives the new item's id, `DispatchTaskPreset` and the new `EstimatorTaskPreset` carry `titleSeed` and `onCreated(id)`, and the modals call them after their insert. The deck opens each with the paper's title filled in and decides the paper only once the task or request exists, so a cancelled window leaves the paper on the deck. The link lands on the row (`checklist_item_id`, `dispatch_request_id`, `estimator_request_id`).
- **The reads and writes** ([`useOfficeInboxPapers.ts`](../../src/hooks/useOfficeInboxPapers.ts)): the open, waiting and someday rows plus the ones decided in the last three days, through an `OfficeInboxIo` seam the render smokes replace with an in-memory list.
- **The metric and the mark**: `useReportQuickfillSectionMetric('physical-inbox', undecidedCount)`, so the header's count, the Roller's *left with work*, the round's row and the mark's `outstanding_count` all read the same number. The station left `QUICKFILL_NOTE_FIRST_SECTIONS` (`round.ts`) and the page's registry block uses the wrapper's own Mark: the round's and the Roller's **Looked** button marks it like any other station, and the history's note column stays empty for this station until the auto-note ships. The banner reads *Has every paper in the tray been decided?*
- **The banner**: the default question is *Has every paper in the tray been decided?* A dev had saved the old default, *Can I get to the bottom of the pile?*, as this station's banner, and a saved banner wins, so the live page kept asking the old question. `isRetiredQuickfillSectionBanner` (`sectionBanners.ts`, `RETIRED_QUICKFILL_SECTION_BANNERS`, the Texts station's v2.5816 rule under the same names, tested) reads a saved banner that is only a retired default as no banner; any other words a dev saved still win, and no app setting was edited.
- **Honest failures**: the hook throws a real `Error` with the server's words and code (`serverError`), so the deck's line reads *Could not read the papers · <reason>* with **Retry** and every toast names the reason; while the read is in flight or has failed the station reports no count, so the header and the Roller never read *0 open* over a pile nobody could see.
- **Words**: a new guide *clear the physical inbox*; the Quickfill guide's station line and its two sentences on note-first stations. `docs/QUICKFILL_ARCHITECTURE.md`, `docs/GLOSSARY.md`, `docs/PROJECT_DOCUMENTATION.md`, `docs/ACCESS_CONTROL.md` amended.
- **Tests**: `sectionBanners.physicalInbox.test.ts` (the retired default), and 8 render smokes (`QuickfillPhysicalInboxSection.render.test.tsx`): the empty deck, the papers oldest first with ages, the add line, Done and Undo, File it with a place, Task through a real `ChecklistAddModalProvider` with the paper leaving on save, Ask hidden for a primary, a failed read with Retry.
