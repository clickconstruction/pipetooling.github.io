# v2.6324 — The Development page on a phone: the walk's two fixes are held by tests (2026-11-01)

Punch list #208 ([`to-dos/developments/README.md`](../../to-dos/developments/README.md)), the last code on the card. Tests and docs only: no change to the page, no migration, no edge function.

## What this is

The owner's walk of the real site's Development page on 2026-10-30 left two phone wrinkles on the card: the five count tiles sat two a row with the sixth cell blank, and the History composer's *Note* chip wrapped onto a line of its own. Both were fixed the same day as [v2.6182](v2.6182.md) (#6585), and [v2.6199](v2.6199.md) (#6603) took the Show chips' wrap with them, but the card's `next` still listed them and nothing pinned either fix. This PR pins them and amends the card.

## The pin

`src/pages/DevelopmentPage.phone.render.test.tsx` renders the whole page, not the two components alone, with the window 375 wide: `matchMedia` answers every `(max-width: …)` / `(min-width: …)` query as a 375-pixel screen would, so the page's own `useMatchMedia(DEVELOPMENT_PHONE_QUERY)` decides `phone` and hands it down, and the test holds the wiring as well as the shape.

- **The tiles**: the counts grid is `repeat(2, minmax(0, 1fr))`; five tiles, the first four in their own cells and the fifth, *Open on bills*, carrying `data-spans` and `gridColumn: 1 / -1`; the cells taken come to an even number, so no cell is blank. An estimator's three tiles read the same way, the third spanning.
- **The Source chips**: *Write a line* opens the composer; the *Source* radiogroup is a grid of `repeat(3, minmax(0, 1fr))` at full width, its six radios the six sources in order, *Note* a direct child centered in its cell.
- **The control at 1280**: five columns, nothing spans, and the radiogroup is the desk's inline wrapping row.

The fetch is mocked at its seam (`fetchDevelopmentPage`), as the door test does; the rows are made up.
