# v2.1969 — Partnerships mobile layout (2026-08-21)

Owner-approved mockup ("Partnerships on Mobile" artifact): the page kept its desktop two-column grid at phone width — the detail pane was a sliver, the six tabs stacked vertically, and the View-as button rendered as a tall box. [`Partnerships.tsx`](../../src/pages/Partnerships.tsx) now uses `useIsMobile()` (the app's 640px hook): the grid collapses to one column with the roster rendered as a horizontally scrolling **chip strip** (name + status chip, "+ New" at the end; the add form is hoisted into a shared `addForm` so both layouts reuse it), the detail **header stacks** (name full-width, status chip + lens button beneath at natural size), and the **tab bar is one line always** (`nowrap` + `overflowX: auto`, hidden scrollbar, `flex: none` tabs) — which desktop also gets, harmlessly. Tab content already flex-wraps/overflow-scrolls once it has full width. Client-only — no migration.
