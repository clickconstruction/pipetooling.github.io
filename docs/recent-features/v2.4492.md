# v2.4492 — Submittals: every window that takes typing asks before it closes (2026-10-04)

The follow-on to [v2.4479](v2.4479.md), which guarded the Edit window, *Their answer* and *Choose from the takeoff* and listed the rest under *Not done here*. The owner, 2026-10-04: "Guard the remaining windows against a stray click". Client only: no migration, no edge function.

## What changed

The same guard ([`useLeaveGuard`](../../src/hooks/useLeaveGuard.ts) + `LeaveQuestion`): nothing changed, the window closes at once; something changed, *Leave without saving?* shows inside the window above its buttons; Esc asks the same way.

| Window | What counts as typed | The question says |
|---|---|---|
| The schedule window ([`PlugInScheduleModal`](../../src/components/bids/PlugInScheduleModal.tsx), also opened from Pricing) | text in the paste box; a tag matched, changed or removed | *The schedule you typed is not saved yet.* |
| Share ([`SubmittalShareModal`](../../src/components/bids/SubmittalShareModal.tsx)) | a name or an email on any person | *The people you typed are not on the room yet.* |
| They approved all of it ([`SubmittalApproveAllDialog`](../../src/components/bids/SubmittalApproveAllDialog.tsx)) | who, the day or the note differs from how it opened | *Their approval is not recorded yet.* |
| What the house's file says ([`SubmittalHouseFileModal`](../../src/components/bids/SubmittalHouseFileModal.tsx)) | a choice or the house differs from how it opened | *Your choices for this file are not applied yet.* |

Three windows hold no typing and get Esc only (`dirty: false`): *Refresh from the takeoff* and *Make it a part* ([`SubmittalRefreshModals`](../../src/components/bids/SubmittalRefreshModals.tsx)), the × question ([`SubmittalTakeOffDialog`](../../src/components/bids/SubmittalTakeOffDialog.tsx)) and *When can a row split* ([`SplitRuleModal`](../../src/components/bids/SplitRuleModal.tsx)). While a write runs each window holds, as before.

The schedule window is mounted closed on Pricing, so its guard is paused until it opens: a closed window must not answer Esc.

Already guarded, untouched: *Assign pages* (its own question since v2.4143) and *See what the GC sees* (read only).
