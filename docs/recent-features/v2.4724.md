# v2.4724 — Edit Job: fill in the property record without leaving the job (2026-10-06)

Client only; no migration, no edge function. Assistant Taunya, by way of the owner (2026-10-06, a screenshot of Edit Job's Property record row on job 838 beside the Guadalupe AD page for 1200 Ilka Rd with its legal description selected): *would like to be able to add in legal description to this view.* The row said it fed the county, the legal description and the owner of record, but held only the link picker and the property kind; the fields lived on Edit customer → Properties. Mock-up and critique: artifact Bsj4EUwejWemaSiwz5Stkj. The first draft put the record panel open inside the row; the critique moved it into the shared window from v2.4719, because Edit Job saves the job on close while the record belongs to the property and is shared, and two saves in one row blur which one wrote what.

## What changed

- **Edit Job's Property record row** (`JobFormEditFactRows`): with a linked record, a *What the lien papers read* block lists the county, the legal description, the owner (name, else company) and the mailing address, each blank as a red *Missing*, and **Fill in the record** (*Change the record* once whole) opens `LienPaperPropertyWindow` at z 1150 on the first blank. A save hands the row back through `onOwnerConfirmed`, which merges it into the candidates, so the block redraws at once.
- **`LienPaperPropertyWindow`**: `loadAddressId` reads the whole `customer_addresses` row before it draws (Edit Job's candidates are a slim copy, and a draft built from one would blank the parcel id, source and note on save); `zIndex`; `onClose(saved, row)`; registered on the modal stack (`useModalStackEntry`) like `LienPaperGcWindow`, so the window underneath leaves Esc alone; errors through `formatErrorMessage`.
- **`CustomerPropertyRecordPanel`** takes `pasteFirst`: the paste box opens when the lookup finds no parcel, or on open when a looked-up row still lacks its legal description or owner. A paste whose exemptions are hidden says so (*not shown on the page, so the homestead tick is left as it is*).
- **`parseCadPagePaste`** (`lib/customers/cadPagePaste.ts`), three misreads on a BIS esearch page found on Guadalupe 63117: *Owner ID: 257443* was taken as the owner (`NOT_A_LABEL` now skips it), *% Ownership: 100.0%* ran into the mailing address (a label may start with `%`), and *For privacy reasons not all exemptions are shown online* read as no homestead (now `unknown`). A mailing address's lines join with a comma.
- **The Lien desk's affidavit pane** (`LienDeskAffidavitPane` `onFixProperty`): a red owner or legal gate's door reads **Fill in the record ›** for office roles and opens the window over the desk (`paneFix` in `LienDeskModal`); other roles keep *Property record ›* to Edit Job.
- `draftFromRow` moved from `CustomerPropertiesSection` to `lib/customers/propertyDraft.ts` in v2.4719 and is shared.
