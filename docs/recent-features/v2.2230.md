# v2.2230 — People → HR: markdown docs, section jump list, explicit coverage (2026-08-24)

UI half of the HR files v2 train (DB half: v2.2228).

- **Markdown rendering**: Summary and Narrative now render as markdown
  (`src/lib/people/hrDocMarkdown.ts` — `marked` + the contract-signing
  sanitizer, same trusted pipeline as help guides; `.hr-doc-body` theme-token
  styles in `src/index.css`). Agent and docs can share one format.

  nav derived from ATX headings (`extractHrDocHeadings`, fence-aware,
  de-duplicated slugs; ids injected post-sanitize since the sanitizer strips
  attributes).

  `person_files.covered_through` (v2.2228) over `updated_at` inference;
  falls back for pre-column rows. New kernel tests cover both paths.
- **Provenance surfaced**: docs show "Maintained by <author_label>" and a
  "covers through <date>" chip; raw entries logged by the agent show its
  label instead of the bare "agent".
