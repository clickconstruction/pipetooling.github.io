# v2.5639 — A job's box opens its quick replies with every line (2026-10-19)

Found while showing the owner where quick replies show up (punch list #126): from a Pipeline row's speech bubble or a job's window, Text and Email opened the strip on its own (v2.5629) with only the app's line for the job's stage, *For this stage 1 · 1 for customers*, until something else read the lines (a `/` in the box since v2.5637, or opening the strip by hand). No migration; no edge function.

- **The cause** (`reply/ReplyBox.tsx`): the strip was drawn open for `openStrip` (a job's box, unless the person folded it by hand), but `useQuickReplies` read the team's lines only for the strip remembered open on this computer (`stripOpen`), *Find a reply* or a `/` word. A job's box that opened on its own read nothing.
- **The fix**: one `stripShown` (the remembered open, or a job's box not folded by hand) both draws the strip open and asks for its lines, so the lines are read once as the strip appears. A strip folded by hand still reads nothing until it is opened.
- **Tests**: `ReplyBox.jobStrip.render.test.tsx` (a job's box reads the lines once and shows them under the stage's line; folded by hand it reads nothing), failing on the old read and passing on the new. The reply box and job box smokes still pass.
- **Where**: the Pipeline row's customer sheet and the job window's Note · Text · Email; a person's thread on Messages was never affected.
