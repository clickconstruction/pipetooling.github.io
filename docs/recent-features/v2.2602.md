# v2.2602 — Crew Day dashboard section (2026-09-01)

New Dashboard section answering "what jobs was everyone on and what did they do today" — built for superintendents (the promotion-driven request that started the stack) and equally useful to office roles.

- **RPC** `get_crew_day_payload(p_day date)` (migration `20260901215024_crew_day_payload.sql`, SECURITY DEFINER): one company-calendar day of clock sessions (non-revoked/rejected, `work_date` match), schedule blocks, job-anchored field reports (Chicago-day `created_at`), and `% complete` thread notes, plus name/label rows for the people and jobs involved. Role scoping inside the function: dev/master_technician/assistant/controller get company-wide rows; superintendent gets only rows anchored to jobs passing the `superintendent_report_job_anchor_allowed` predicate (project via `can_access_project_row`, or team membership), with job-less rows dropped; all other roles get `{'error':'forbidden'}`. No pay data in the payload.
- **Kernel** `src/lib/crewDay.ts` (17 tests with the render smokes): `buildCrewDayView` groups rows per person per job, totals hours (open sessions count up to load time), and derives the three flags — `scheduled_no_clock` (blocks but zero sessions), `unscheduled_work` (session on a job no block names), `no_report` (closed session, zero reports; open-only days don't flag). Plus `crewDayPctFromNoteBody`, `crewDayReportExcerpt` (skips `data:` signature strokes), formatters, and `isCrewDayRole`.
- **Section** `src/components/dashboard/DashboardCrewDaySection.tsx` (+ render smokes): summary chips (people/jobs/hours/reports/flags), ◀ ▶ day navigation (future disabled), per-person cards with amber/red flag rails, report excerpts, % movement (first note baseline → current `jobs_ledger.pct_complete`), "Show all N people" beyond 8. Fail-soft on load errors. Self-gates on `isCrewDayRole`; mounted above each of the three `myInboxCard` role positions in `Dashboard.tsx`; SectionDock anchor `dash-crew-day`.
- Help guide: `src/content/help/see-what-your-crews-did-today.md`.
- The `crew_day` email stream (same payload shape, end-of-day send) ships separately.
