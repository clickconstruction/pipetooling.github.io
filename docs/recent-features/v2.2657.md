# v2.2657 — Job Accounts: job titles open the job window in place (2026-09-02)

Follow-up to v2.2652 (owner request from live testing): on **Materials → Job
Accounts**, the job title (`JNNN · name`) in each row and the expanded
statement's link (relabeled **Open job**) now open the global job window —
Job / Edit / Bill tabs — via `useJobFormModal().openEditJob(jobId, { onSaved })`
(the same `JobFormModalContext` opener Dashboard/Map/Schedule use), instead of
navigating to `/jobs?tab=stages&edit=<id>`. Navigation remains only as the
fallback when the provider is absent. `onSaved` reloads the tab so billing
edits made in the window refresh the money-flow numbers.

Mechanics in `MaterialsJobAccountsTab.tsx`: the row header `<button>` became a
`role="button"` div (keyboard toggle preserved via Enter/Space on the header
itself) because the now-clickable title (`role="link"`, underlined with
`--border-strong`, `stopPropagation`) can't legally nest inside a button.
Clicking anywhere else on the row still toggles expansion.
