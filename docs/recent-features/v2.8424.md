# v2.8424 — Bills sent: an email with no answer says how long it has been (2026-11-23)

Found on the Bills sent walk of 2026-11-23 (punch list #422). No migration, no edge function.

## What was wrong

When the mail service's last word on an email was *sent*, the line read *Sent. Their mail server has not answered yet.* It read that on the day of the send and five weeks later alike. On the walk, an open bill sent that morning to an address whose domain looked mistyped read the same words as a line from October to the same address.

## What changed

- `arrivalOf` is told today and whether the bill is still open. For `BILLS_SENT_NO_ANSWER_DAYS` (2) the words are as before. After that: *Sent. No answer from their mail server in 14 days.*
- On a bill still open the line adds *Check the address.* A paid bill, a statement and a pay application get the count alone.
- The tone stays quiet, never red, and the send does not join **Did not arrive**: a word the mail service failed to pass on is silence too.
- `billsSentLines(input, { todayYmd })` takes the day. A caller that names none gets the old words, so the print and the spreadsheet, which read the lines the page built, say the same as the screen.

## Tests

`billsSent.test.ts`: the same day and the next, two days, fourteen days on an open bill, fourteen days on a paid bill.
