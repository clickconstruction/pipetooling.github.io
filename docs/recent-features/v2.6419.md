# v2.6419 — A link to People → Writeups opens on Writeups (2026-11-02)

The first of the four findings the People → Paperwork design spike left (v2.6392 → *Left*): `/people?tab=writeups` opened cold by a dev bounced to Users. The URL router effect in `src/pages/People.tsx` gated Writeups on `canAccessContracts` alone, and every flag `usePeopleAccess` returns starts false while the role is read, so the first render's pass through the effect saw a dev with no Contracts access and moved the URL. The pay-group gate on the same effect has waited for `accessResolved` since v2.2882; the Writeups branch, written later, did not. Client only: no migration, no function change.

- **The gate.** The Writeups branch now reads `accessResolved && tab === 'writeups' && !canAccessContracts`, the pay tabs' shape. Before the flags land the tab is set and the render site, already gated on the flag, waits; once they land a role without Contracts access is bounced to Users as before, and a dev stays.
- **The smoke** `src/pages/People.writeupsColdLink.render.test.tsx` renders the People page at `/people?tab=writeups` with a table-aware stub whose `users` read answers a tick late, as the server does: the first paint keeps the URL on Writeups, the role lands, the Writeups heading draws and the Writeups tab is the selected one. A second case opens the same link as a helper and lands on Users once the role has been read. The first case failed on main before the change.
- **Not changed.** The Overhead gate on the same effect reads `canAccessOverheadTab`, which comes from `useAuth`'s role, not from `usePeopleAccess`, so it has no such race; the Activity gate already waits for `activityAccessResolved`.
- **Docs.** `PEOPLE_TABS_ARCHITECTURE.md` → the URL router row and the access section name the Writeups gate as waiting with the pay group.

## Verified

The smoke (2 tests) and narrow tsc clean. On the dev server as the dev, a cold `/people?tab=writeups` landed on Users before the change and on Writeups after it, with Paperwork and Writeups the selected tabs.
