# v2.3302 — Burn against the bid, PR 4: the bid side — Bid Board chips and the New-Job carry box (2026-09-11)

Client only (reads `job_budgets` / the v2.3297 RPCs). Rung 4 of [`to-dos/burn-against-the-bid/`](../../to-dos/burn-against-the-bid/README.md).

## What shipped

- [`bidBoardBudgetChips.ts`](../../src/lib/bids/bidBoardBudgetChips.ts) (+4 tests): `bidEstimateStatus` (costed · hours only · none, off `cost_estimates.labor_rate` and the labor rows through `laborRowHours`), `bidMatchValue` (agreed value over bid value), `valueMatchForBid` (an unlinked job within $1), `isWonOutcome`.
- [`useBidBoardBudgetChips`](../../src/hooks/useBidBoardBudgetChips.ts): two reads for the whole board — `jobs_ledger` by the won bids' values with `bid_id IS NULL`, and `cost_estimates` with their labor rows — never one per row; re-runs on the board's job-index bump.
- **Bid Board** ([`BidsBidBoardTab`](../../src/components/bids/BidsBidBoardTab.tsx) Links column, won rows, job-link roles): *J1007 matches by value · Link* (amber) when an unlinked job carries the bid's value; the estimate chip *costed · 47 h* (green) / *hours only · 36 h* (amber) / *no cost estimate · Cost it →* (red, opens the bid's Labor tab). **Link** ([`Bids.tsx`](../../src/pages/Bids.tsx) `linkJobToBidFromBoard`) confirms, calls `snapshot_job_budget_from_bid`, toasts, and bumps the board's job index so the J#### chip appears.
- **New Job from a bid** ([`JobFormHeaderRow`](../../src/components/jobs/JobFormHeaderRow.tsx), [`JobFormModal`](../../src/components/jobs/JobFormModal.tsx)): *carry the bid's estimate as the budget* beside the Bid link, on by default; after the insert the modal calls `snapshot_job_budget_from_bid` (best effort — the job is already saved; a failure is an info toast).
