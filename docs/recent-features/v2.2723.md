# v2.2723 — Bank-category tags, PR 3: tag-driven cost lines on Review + Job Summary, tag merge (2026-09-03)

Stacked on #2457 (v2.2718). No migration. Replaces the hard-wired Fuel slice (v2.2700 / v2.2708) with lines driven by each tag's `show_as_cost_line` switch.

## Kernel

- [`lib/mercuryTagSplit.ts`](../../src/lib/mercuryTagSplit.ts) (+tests) replaces `lib/mercuryFuelSplit.ts`: `costLineTags(lookups)` — cost-line tags in manager order; `sumTagChargesByJob(rows, labelIdByTxId, categoryByTxId, lookups)` → job → tag → $ using `categoryTagForCharge` (the charge's accounting label's tag wins, else its bank category's tag). Refunds are abs'd the same way card charges are.
- [`lib/people/derivePersonTeamSummary.ts`](../../src/lib/people/derivePersonTeamSummary.ts): `TeamReviewUnion.fuelChargesByJobId` → `tagChargesByJobId` (+ `costLineTags`); each net-job row carries `tagCosts`, each person row `allocatedByTag: Record<tagId, $>` (same cost-ratio share as parts). `allocatedFuel` is gone from `TeamSummaryBreakdown`.
- [`lib/people/reviewRanked.ts`](../../src/lib/people/reviewRanked.ts): `buildReviewVerdict(rows, prior, costLineTags)` returns `byTag` and composes one segment per cost-line tag (`key: tag:<id>`, tag color + icon) between "Parts, subs & labor" and overhead labor; `buildReviewPersonMath(b, { partsRate, costLineTags })` writes one drawer line per tag and slices them out of Parts & job purchases (+1 test).

## Client

- **Review** ([`PeopleReviewTab.tsx`](../../src/components/people/PeopleReviewTab.tsx)): the union loader takes the tag lookups (`useCategoryTags`), fetches label assignments by tx (`fetchLabelIdByTxId`) + bank categories, and files card charges by tag. Verdict strip colors tag segments with `CATEGORY_TAG_INK[color]`.
- **Jobs → Job Summary** ([`useJobsMercuryAllocations.ts`](../../src/hooks/useJobsMercuryAllocations.ts), [`Jobs.tsx`](../../src/pages/Jobs.tsx), [`JobsJobSummaryTab.tsx`](../../src/components/jobs/JobsJobSummaryTab.tsx)): `mercuryFuelChargesByJobId` → `mercuryTagChargesByJobId` + `costLineTags`; a row's `fuelCost` becomes `costLines[]` (icon, name, color, $), each clamped so the lines never exceed the counted card charges; the Parts cell and the breakdown header render one sub-line per tag.
- **Merge** ([`categoryTagsData.ts`](../../src/lib/banking/categoryTagsData.ts) `mergeCategoryTags(sourceId, targetId)`): moves members via `tag_id` update, repoints rules whose `bankTag.tagId` named the source (fresh category snapshot from the target), deletes the source; the manager's editor gains a **Merge into…** select + button that lands on the target afterwards.
