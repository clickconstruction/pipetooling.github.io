# v2.4622 — Legal portal: a hidden form box can no longer swallow the firm's entries (2026-10-05)

Item 28 of punch list #85 ([`to-dos/legal-portal-firm-ready/`](../../to-dos/legal-portal-firm-ready/README.md)). No migration. One edge function changed: **`submit-legal-portal` must be redeployed** after merge. Mockup: `mockup-28-honeypot.html` beside the card.

## The defect

The portal's fee form and its *Add a person at the firm* form each drew a hidden `<input name="website">`. The page's `act` builds its body from React state and never sent the field. `submit-legal-portal` answered `{ ok: true }` and wrote nothing when the field was filled. So the trap caught nobody: a bot posting to the function does not draw the form and leaves the field out. Wiring it, the obvious fix, would have been worse. A browser or password manager that fills every text box would make a fee, a step or a payment answer *Saved* and vanish.

## What changed

- [`submit-legal-portal`](../../supabase/functions/submit-legal-portal/index.ts): the `body.website` check is gone; the header comment lists the guards that hold (the link is the key, length caps, the matter must be the firm's and with the firm, 30 matter acts per firm per hour, twelve people). A body that still carries `website`, from a tab opened before the deploy, is saved like any other.
- [`LegalPortal.tsx`](../../src/pages/LegalPortal.tsx): both hidden inputs are gone.
- [`EDGE_FUNCTIONS.md`](../EDGE_FUNCTIONS.md#submit-legal-portal): a v2.4622 note and the *Guards* line amended.

## Is this the best we can do?

- **Wire it instead?** No. A honeypot earns its keep on a public form anyone can find. This page sits behind a private link, so a bot must hold the link first, and one that does can skip the box. A person whose password manager autofills would lose real acts.
- **Keep it, but answer "Could not save" instead of pretending?** Still no. The autofill case then shows an error the firm cannot fix, because the box is invisible.
- **Is the rate limit enough alone?** For matter acts, yes: 30 an hour per firm. The people acts are capped at twelve people per firm. *Resend the confirmation* has no cap of its own; that belongs with item 18 (acts a firm can trust) and is not added here.

## Tests
