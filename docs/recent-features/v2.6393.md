- **The setting.** `drive_people_folder_id` in `app_settings` (`DRIVE_PEOPLE_FOLDER_ID_KEY` in `_shared/whereFilesGo.ts`, `APP_SETTINGS_KEY_DRIVE_PEOPLE_FOLDER_ID` on the client, `peopleFolderId` on `DriveSettings`, read with the five others by `readDriveSettings`). `job-drive-folders`' `settings` answer gains `people: { id, url, ok, words, folder } | null`; `set.people` is checked like the company folder (`people_unwritable`) and **refused inside the Jobs drive** (`people_in_jobs_drive`, `PEOPLE_IN_JOBS_DRIVE_WORDS`: the pasted folder's Shared Drive name against the jobs root's).
- **The card.** Documents → Where files go gets **The People folder** after the company folder (`PeopleCard` in `DocumentsWhereFilesGo.tsx`; kernel `peopleCardWords`, `WhereFilesGoPeople`, `NO_PEOPLE_FOLDER_YET_WORDS`, `PEOPLE_FOLDER_IN_JOBS_DRIVE_WORDS` in `whereFilesGoTab.ts`; `set.people` in `whereFilesGoIo.ts`): the folder's name, path and Shared Drive, a warning when that drive is the jobs root's, Paste · Check · **Use this folder for the people's files**; a pasted folder in the Jobs drive is told before the press.
- **The function** `hr-evidence-drive` (`EDGE_FUNCTIONS.md`): `POST { evidence_id }` with a dev's session (the function checks `is_dev()` itself; `verify_jwt = false`) files one record; `POST {}` with `X-Cron-Secret` sweeps the records with a file not yet filed, oldest first, twenty a run. Under the People folder it finds or makes *<Person's name>* then *<YYYY-MM-DD · title>* (`findOrCreateFolder`), uploads each staged file's bytes from the `hr-files` bucket under its own name (`freeName` adds *(2)*), stamps `drive_file_id` / `drive_url` / `filed_at` per file and the record's folder, `filed_at` on the record once every file is in; no People folder set, a Drive refusal or a staged copy that did not read is written as `fail_why`. The bucket copy stays.
- **The cron** `hr-evidence-drive`, `6,16,26,36,46,56 * * * *`, six past the folder sweep's slot, while a record waits.
- **Docs**: `EDGE_FUNCTIONS.md` (the new section; job-drive-folders' `people`), `DRIVE_INTAKE_SETUP.md` → *The people's files*, `GLOSSARY.md` → Where files go, the guide *set where a job's files go* → *Set the People folder*.
