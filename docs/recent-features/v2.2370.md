# v2.2370 — Cover letter alternates on one page (2026-08-26)

Wendi's request: "need ability to have alternates on the same generated cover
letter page." The New-view letter rendered every alternate as its own COMPLETE
cover letter (own address block, proposal paragraph, full inclusions, terms,
signature) concatenated with forced page breaks — a 2-alternate packet printed
as two competing multi-page proposals, and an all-alternates packet's letter
total read $0.00 (BP364 was the reproduction).

- **Kernel** `src/lib/bids/coverLetterSamePage.ts` (+tests):
  `planSamePageLetter(sections)` → headline (base sections; or the FIRST
  alternate when the packet has no base) + alternates list; merges headline
  fixture rows (counts summed per fixture, first-seen order). Returns null
  when there's nothing to combine (<2 sections or no alternates — multi-base
  packets keep the per-section document). `formatAlternateDelta` → "reduced
  $5,287" / "added $4,100" (whole dollars unless real cents; null when no
  headline or zero). `buildAlternatesBlock(plan, texts, fmt, editable)` merges
  saved wording over auto labels. `parseCoverLetterAltTexts` +
  `altSectionKey` (versionId or versionId:offeredPricingId).
- **`coverLetter.ts`**: `buildCoverLetterHtml` / `buildCoverLetterText` take an
  optional trailing `alternatesBlock` — rendered between the proposed amount
  and the plan date in the letter's own idiom (bold heading, 5-space bullets,
  `• <b>label</b>: <b>$X</b> (reduced $Y)` + optional note line). Omitted →
  output byte-identical to before (asserted). `editKey` wraps label/note in
  `data-cl-edit` spans — preview only, never on clipboard/print HTML.
- **`BidsCoverLetterTab.tsx`**: "Alternates in the letter" segmented control
  (Same page / Separate pages; localStorage `bids_cover_letter_alts_layout_v1`,
  default same-page; shown only when the GC packet has alternates). Same-page
  composes ONE letter per GC packet; Separate pages is the pre-2370 combined
  document, now with edited labels as section headings. Preview renders an
  editable twin (`previewCoverLetterHtml`); clicking dashed `[data-cl-edit]`
  text opens an inline editor card (label + note, Save/Cancel/Reset to auto)
  saving to `bids.cover_letter_alt_texts` (migration `20260826225633`,
  additive jsonb). All-alternates packets: the studio total pill shows the
  letter amount ("letter amount · ★ alternate leads") instead of $0.00, and
  Apply to Bid Value writes it; Mark sent / board value rules untouched.
- Old view untouched; per-GC packet separation untouched.
