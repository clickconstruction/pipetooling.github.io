# v2.4094 — A field write-up's Dispatch request closes itself when the office sends the estimate (2026-09-28)

Edge function only (`send-estimate-to-customer`, redeployed after merge); no migration, no client change. The last of the three v2.2293 deferrals: the wizard files a `review_field_estimate` Dispatch request for the office to finish the draft, and the office's send left it open until someone pressed Dismiss.

## What changed

- **`send-estimate-to-customer`** — after a first send's estimate UPDATE succeeds (never on a resend), the function closes the open `dispatch_requests` row for this estimate: `pending_action = 'review_field_estimate'`, `status = 'open'`, `pending_payload` containing `{ estimate_id }` (PostgREST `contains` on the jsonb) → `status = closed`, `closed_at` now, `closed_by_user_id` = the sender, `closed_note` *Sent to the customer* — the same fields the inbox's own close writes, so the row reads like a hand-closed one (time, who, the note in quotes). Best-effort: a failure is logged and the request stays for Dismiss; the send itself is never affected.
- `docs/EDGE_FUNCTIONS.md` → send-estimate-to-customer, a *Field write-up request* paragraph.
