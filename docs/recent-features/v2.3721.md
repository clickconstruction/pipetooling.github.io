# v2.3721 — Digital twins: a fresh robot key walks through claude.ai, Claude Desktop and the phone (2026-09-22)

The twin half of [v2.3686](./v2.3686.md), and the last XS item on [`to-dos/mcp-servers.md`](../../to-dos/mcp-servers.md) before PR 6: Path 0 of the sign-in spike (Claude's *Request headers* option on a custom connector) is confirmed on the owner's account, so a twin key can be used from claude.ai, Desktop and the phone with no `mcp-remote`, no Node and no Terminal. Client only; no migration, no edge function.

## The change

- **[`TwinFreshKeyPanel`](../../src/components/settings/TwinFreshKeyPanel.tsx)** (new) — the card a fresh twin key is shown on, lifted out of `DigitalTwinsPanel` so it can be rendered alone in a test. Three ways, plainest first: *To run <robot> from claude.ai, Claude Desktop or your phone* — Customize → Connectors → Add custom connector, named after the robot, the `/twin` address, No sign-in, Request headers → `authorization` → **Copy header value**, then the Console's kickoff in a new incognito chat; *Claude Desktop without a Request headers section* — Copy Desktop setup command, Terminal, Copy key when the silent prompt asks, quit and reopen, and next time *Set up on this Mac*; and the Claude Code handoff (`TWIN_HARNESS.md`, Robots → Console). The card links the Desktop guide. The connector is named after the robot because one connector holds one key, and a key is one seat.
- **[`mcpKeyPrefixes.ts`](../../supabase/functions/_shared/mcpKeyPrefixes.ts)** — `mcpConnectorHeader(key)` (`Bearer <key>`) is the one rule for both audiences; `devMcpConnectorHeader` in `devMcpKeys.ts` is now that function.
- **Guide *run the robot estimator from Claude Desktop*** — a new section *From claude.ai or your phone — no Terminal*, and an example panel on one connector per robot. Keywords gain claude.ai, phone, custom connector, request headers, header value.
- **[`TwinFreshKeyPanel.render.test.tsx`](../../src/components/settings/TwinFreshKeyPanel.render.test.tsx)** — the key is shown once, the header value copied is `Bearer <key>`, the Desktop command copied never carries the key, the guide link. It is the test that found [v2.3716](./v2.3716.md).
