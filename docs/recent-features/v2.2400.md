# v2.2400 — Margin-breakdown jump chips land on the fixture's row (2026-08-27)

Wendi (mockup approved on the Breakdown Jump-to-Row canvas): clicking
# Counts / 📐 Takeoffs / 🛠 Labor in the Pricing tab's Margin breakdown should
open that tab AND bring you to that fixture's row, flashed for a moment — the
Jobs → Pipeline follow idiom.

- **Kernel** `src/lib/bids/bidTabRowJump.ts` (7 tests): per-tab landing DOM ids
  (`counts-row-<id>`, `takeoff-row-<id>`, `labor-hours-row-<encoded name>`),
  the `BreakdownJumpTarget` shape, and the per-tab miss toast copy. Counts and
  Takeoffs land by `count_row_id`; Labor lands by normalized fixture name —
  the same key the breakdown's own labor number is derived with.
- **Hook** `src/hooks/usePendingRowFlash.ts`: given a target DOM id, polls the
  DOM (150ms, 5s cap — destination data loads async after the tab switch),
  then `scrollIntoView` center + a ~2s flash; reports handled(found) exactly
  once. DOM polling keeps it agnostic to each tab's data pipeline.
- **Wiring**: `PricingBreakdownRow` carries `countRowId`; the chips call a new
  optional `onNavigateBidToTabRow`; `Bids.tsx` stores the pending target and
  hands it to `BidsCountsTab` / `BidsTakeoffTab` / `BidsLaborTab`
  (`rowJump` + `onRowJumpHandled`). Each tab flashes with its native tint —
  Counts reuses its green `highlight` (CountRow/sheet rows), Takeoffs tints
  the fixture's whole cluster blue (classic mappings table, rough part-line
  rows via `SortableRoughPartLineRow`, and both empty-state rows), Labor tints
  the HOURS row blue. Miss → tab opens + info toast ("No labor row for X yet…").
