# v2.4939 — GC mode: asking a trade partner to quote sends the email, for a dev (2026-10-08)

The Board's B4-a, switched to the Portal lane's sender (P3-a, v2.4936, `gc-trade-email`, deployed 2026-10-08). With **Email the invitations now** ticked, the Ask window's **Ask N companies** emails each new ask's invitation. The tick starts off until the owner names an inbox (call 3). Guide: `ask-trade-partners-for-a-quote`.

- **`src/lib/gc/askEmail.ts`** (pure):
  - `inviteEmailRequest` draws a new ask's invitation as the window draws it (`inviteMessage`, then the Portal's `inviteEmailLines`): kind `invite`, key `<invite id>:invite` (a repeat sends nothing), the project, the language and the subject.
  - `inviteAsks` sends each one in turn and says what line each ask gets: *Invitation emailed.* (how `email`, so Follow up counts the contact), or the refusal's office words from `gcTradeEmailRefusal` (a `note`). A repeat (`already`) leaves no second line. Without a sender, each ask gets the note that a dev sends it.
- **`askGcCompanies`** (gcIo) keeps `gc_invite_companies`, then takes an optional sender and writes the lines `inviteAsks` returns. It returns each ask's outcome.
- **`GcProjects`** passes the sender only when the press had the tick on and `canSendGcTradeEmail(role)` (dev until the trade-wave door), with `tradeMailLang` for the company's language (English while Spanish is held).
- **`GcAskCompanies`**:
  - **Email the invitations now**, a tick only someone who can send sees, **off by default** (the lead's hard stop, as step 7's: the test company's contacts carry example.com addresses, so a press with it on would send; the owner's call 3 flips the default). A render case pins it off.
  - The footer reads *Each company gets this invitation by email now, with its portal link.* with the tick on, *The asks are saved without an email. Tick Email the invitations now to send them.* with it off, and *The asks are saved. A dev sends the invitation emails while GC mode is built.* for anyone else.
  - When an invitation does not go out, the window lists each with its reason and closes on **Done**, not before.
- **No real send yet**: the lead's rule stands until the owner names an inbox for the checks (call 3). The live walk, below, answered every write from the page itself.
