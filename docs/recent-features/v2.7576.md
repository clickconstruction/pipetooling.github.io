# v2.7576 — Tag a teammate in a task note, with a count on Checklist (2026-11-17)

Punch list #375, PR 3 of six: where a task tag lands, and the @ opened to the team. Client only: no migration, no edge function. It reads `note_tags_mine` and calls `task_note_tag_done` and `task_note_tags_seen`, all on prod since v2.7570.

## What a person sees

- **The count on Checklist.** `ChecklistTagsBadge`, the Jobs pill's look, on the Checklist icon in the bar, on the word in the phone's gear menu and on the gear button itself, and on the word in Task Mode. It is the reader's own number of task tags: the task notes that tagged them and still wait, plus the answers to their own task tags they have not seen. The number above Jobs is now job tags alone.
- **Tagged task notes, at the top of Today.** The Pipeline's section with `variant="today"`: each tag is a card with the task's title as plain words, the day row's date, the note with the reader's chip, an answer box and **No reply needed**. The title is a door only when the task is on the page. It draws nothing while nothing waits and nothing was asked.
- **Task Mode holds job tags too**, since no other page is open there (`kinds="both"`, and the count on its Checklist word counts both).
- **The Needs you line counts both kinds.** Its kicker is now **Tagged notes**, its title says how many job notes and how many task notes, and its window lists both, oldest first. A task's title there opens `/checklist?tab=today&task=<day row>`, and Today shows the task when it is on that page.
- **Review's board** says `waiting on Dana` beside a row's note count and on the person's line (`useOpenTaskTagNames`).
- **Has left.** An open tag on an archived person reads *has left* under You asked, on jobs too. It waited forever before.
- **The @ is open.** `canTagInTaskNotes` now answers for the seven roles `canTagInJobNotes` does. v2.7574 held it to a dev.

## How it stays in step

One read per tab, as before: `useMyNoteTags`, now over `note_tags_mine()`, feeds the Jobs count, the Checklist count, both sections, the window and the Needs you line. Each list takes its own kind with `tagsOfKind`. Seen stays one mark for each kind: a list marks only the kinds it shows, so a job answer still counts above Jobs after Today has been open.

## Picks made while building

- **The window's task door.** The card did not say where a task tag's title leads from the Dashboard. It opens the Checklist at Today with `?task=`, and Today shows the task if it is there. A task on an older day opens Today and nothing more.
- **A task handed away.** The person who gave it away still sees the tagged note. Their answer box has no @, and a typed answer is refused by the thread's own read rule, since they can no longer open the task. **No reply needed** works. The guide says so.
