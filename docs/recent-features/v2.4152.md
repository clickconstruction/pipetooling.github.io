## Design calls

- **One scale for everyone.** The runway draws each job on its own scale (today → 1.2× its farthest date); the calendar's whole point is that the flags line up, so the axis is built once from every date on the board and each row's marks are positioned by `axis.pct`.
- **The to-do reads the columns, not the rows.** The first sentence is the first future column with a notice owed; "to RMC" when one GC, "across N GCs" otherwise; the third is the next column after it. Kinds come between because setting a kind can move a flag a month.
- **A GC row shows counts, not dots.** The open question — one pay dot for the group — is PR D's, with the pen.
- **Rows stay honest before the clock sessions land**: `months` is null until then and the runway's one flag stands in, so the first paint is never wrong, only less detailed.
