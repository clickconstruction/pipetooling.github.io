# v2.3957 — GC Review: the word is filed under whoever said it (2026-09-27)

Client only. Step 2b of punch list **#49** (`to-dos/gc-review-one-operator/`); the columns are migration `20260928032427` (v2.3954). The client works before and after that migration is applied.

## What shipped

- **`GcStatementMarkSentForm`** — given `actorId` + `wordSources`, a contact asks **Whose word is this?** (a select, the GC's account man preselected via `defaultWordSourceId`; "Mine — I talked to {GC}" for the person typing). When the source is someone else the channel row reads *How did you hear it from Malachi?* and offers Email; the stamp line reads "Stamps Malachi's word — entered by Taunya". The payload gains `wordFrom` and `heardVia`. Without the new props the form is as it was.
- **`mergeRoundMarkWrite`** (`lib/jobs/gcWorklist.ts`) writes the word's six columns: from, heard via, entered by, and `word_at`. A plain send names no source. A send that keeps an earlier word keeps that word's source and day; a word from before the columns is taken as its marker's.
- **`lib/jobs/gcStatementRounds.ts`** — `markWordFrom`, `markWordByline` ("Malachi — entered by Taunya"), `markWordAt`; `describeRoundMark` names the source on a word, and beside the read on a statement.
- **Every display of a read follows the source:** the GC header's temperature pill and its tooltip, the worklist row's last word, the Temperature board's *Now* and last word (`temperatureBoard.ts` sorts reads by the word's own day), What went out (*Who* on a word; `wordBy` beside the temperature on a statement).
- **`lib/gcStatementRoundIo.ts`** — reads ask for the word columns and fall back to the old column list when the database answers "no such column" (`isMissingColumnError`); a write that fails the same way is retried without them (`withoutWordColumns`). The answer is remembered for the session.
- `acted_by` is unchanged: RLS still pins it to the person signed in.
- **Not yet:** the round email's "last word — by" still reads `acted_by_name` (the payload function is reworked in step 6).
