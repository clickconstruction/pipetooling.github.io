# v2.3709 — Contract sweep: one look in Drive for the whole office (2026-09-22)

Item 3 of [`to-dos/contract-sweep-refresh`](../../to-dos/contract-sweep-refresh/README.md) (#28), taken up on the owner's *"let's build it, asking ourselves is this the best we can do"* — the one open engineering piece after the four drawn pieces shipped (v2.3703 / v2.3706 / v2.3707). Migration `20260922040000_drive_contract_scans.sql`; edge function `drive-contract-scan` changed.

## What was wrong

v2.3669 made the sweep run the Drive pass by itself on open. The scan (`drive-contract-scan`) lists the contract-looking files in the jobs Shared Drive and walks each one's folders up to its job folder — 66 s for 123 files and 273 folders when measured — and the only cache was a 15-minute one **in the browser tab**. So every person, every reload and every new tab paid the minute again, watching *checking Drive…*; and the ⋯ menu's *Look in Drive for signed contracts…* window ran a second, separate scan of its own. The walk was also sequential: one folder lookup after another.

## The change

- **`drive_contract_scans`** ([migration doc](../migrations/20260922040000_drive_contract_scans.md)): one row (`scope = 'contracts'`) holding the last scan's `files`, its `stats` (`job_folders`, `scanned`, `unattributed`, `folder_lookups`, `took_ms`) and `scanned_at` / `scanned_by`. RLS on, no policies — the service role is the only reader and writer.
- **`drive-contract-scan`**: body `{}` answers from the kept row with `cached: true` while it is younger than an hour; `{ force: true }` reads Drive now. A fresh scan is upserted into the row before it is returned (a failed keep is logged, never an error to the caller). The folder walk runs through `mapPool` eight files wide, and the metadata cache holds the lookup **in flight**, so eight files under one unknown folder ask Drive once. Every answer carries `cached` and `scanned_at`. Deployed before merge. [`EDGE_FUNCTIONS.md`](../EDGE_FUNCTIONS.md#drive-contract-scan).
- **[`driveContractScanCache.ts`](../../src/lib/jobs/driveContractScanCache.ts)**: the tab's 15-minute copy stays; `held()` gives the scan's own stamp and counts, `refresh()` asks the function to scan again (and a second asker joins the refresh in flight). Test: the stamp, the force flag, the join.
- **[`DriveContractsFoundModal`](../../src/components/jobs/DriveContractsFoundModal.tsx)** (⋯ → *Look in Drive for signed contracts…*) reads the scan the sweep already holds instead of invoking its own; its summary line says *Drive read 12m ago · read it again*.
- **The sweep's ⋯ item** says when Drive was read (*The jobs Shared Drive, read 12m ago — file what is already signed…*).
- The to-do's item 3 is answered; its `next` narrows to the week of watching the finds. Guide *get a job contract signed* says the office shares one reading.
