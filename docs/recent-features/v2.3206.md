# v2.3206 — Bid flow: ten equal ticks on the board, and the opened-row strip fits its row (2026-09-09)

Client only. Two things Grace saw on the live board an hour after v2.3200 shipped.

- **"Why are these not all the same size?"** The board hairline drew one segment per *phase*, so Build (Takeoffs + Price) and Letter (Cover letter + PDF filed) were twice as long as the rest — a deliberate mockup choice that reads as inconsistency on a real row. It is now **ten equal ticks, one per step**, with a 4px gap where the phase changes. Each tick maps one-to-one onto the opened row's nodes. [`BidFlowStrip.tsx`](../../src/components/bids/BidFlowStrip.tsx) `hairline`; the phase roll-up (`bidFlowSegments`) stays in the kernel for the tooltips and any future use.
- **"When I expand a bid it is not showing up like the mock-up."** The full strip's grid still reserved **twelve** columns from the twelve-step prototype, so with ten steps the phases spread across the whole row and Cover letter / PDF filed / Sent fell off the right edge behind the scroll. The grid now sizes to `flow.steps.length` columns, with a min of 62px and a max of 88px per step, so the strip is the compact card the mockup showed and never wider than ~880px.

Help: `see-where-a-bid-is-in-the-flow.md` (the board paragraph now says ten ticks). Release note `v2.3206.ts`.
