# v2.2708 — Job Summary fuel sub-line, shared fuel classifier (2026-09-03)

Owner-directed follow-up to v2.2700 ("label fuel as fuel"): the same split on Jobs → Job Summary. Stacked on the v2.2700 branch.

## Client only — no migration

- **Kernel** [`lib/mercuryFuelSplit.ts`](../../src/lib/mercuryFuelSplit.ts) (+2 tests): `isFuelCardCharge(bucket, category)` — the Banking `fuel_gas` accounting label wins; a transaction with **no** label falls back to bank category `FuelAndGas`; any other label means not fuel. `sumFuelChargesByJob(rows, bucketByTxId, categoryByTxId)` sums |amount| per job over allocation rows. People → Review's union loader now calls this kernel instead of its inline copy, so the two surfaces cannot disagree on what is fuel.
- **Hook** `useJobsMercuryAllocations`: the card-charge effect also fetches `mercury_transactions.mercury_category` for the transaction ids (chunked) and exposes `mercuryFuelChargesByJobId`, computed over the rows that count (internal transfers already excluded).
- **Page** `Jobs.tsx` `jobSummaryData`: `fuelCost = min(cardCharges − cardChargesLinkedToInvoices, fuel)` so the slice never exceeds the card charges that survive the v2.2692 invoice-link de-dup; new `JobSummaryRow.fuelCost`.
- **Tab** `JobsJobSummaryTab`: the Parts Cost cell shows a muted "fuel $X" line when > 0 (title explains the rule); the expanded cost breakdown's "Parts Cost" summary repeats "· fuel $X". Parts Cost, gross and margin are unchanged.
- Verified live as dev on Job Summary.
