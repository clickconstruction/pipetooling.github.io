# v2.2815 — Users status column: the icon rail wide, hours counter + "Needs you" pill narrow (2026-09-04)

PR 3 of 4 for the People → Users status column (owner pick, artifact 747a0b27). PR 1 (v2.2809) built the needs model, PR 2 (v2.2810) gave the Desk section doors; this draws the column.

- **`UsersTabStatusColumn.tsx`** (render-tested): `UsersRailCells` — three fixed 54 px cells, Hours · Paper · Acct, with inline SVG glyphs (no emoji), a count, and a tone: slate for hours (a queue, never amber), amber/red for paperwork and the roster gap, muted/blue for facts, faint for empty. `UsersRailHeader` names the columns once above the first group. `UsersNeedsPill` — the same hours cell beside a "Needs you · N" pill (counted needs only; "Clear" when none) that unfolds one line per need with a verb button; facts list too, outlined.
- **Doors**: every cell and verb calls `openDesk(section)` → `personDesk.open({ …, section })` (PR 2), so a chip lands on Hours & approvals, Paperwork, Access, Portal or Push. Viewers who can't open the Desk see the same cells as plain spans with tooltips.
- **`UsersTabRow`** renders the column from `rail.rowNeeds` by the row's existing `narrowViewport` flag (640 px); the loose signal chips, the signing chip and the `no push` chip retire (a caller without needs still gets the old chips). `signingLight` / `pushOn` / `showPush` props are gone — the kernel already folded them in.
- Help guide "add someone to the roster" re-reads the row for both widths.
- **Not in this cut:** verbs open the Desk section rather than the flow directly (Approve → the Hours section's Open approvals is one more tap); bulk actions from the fold-out.
