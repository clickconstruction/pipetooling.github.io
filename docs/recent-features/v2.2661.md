# v2.2661 — Lien paperwork letterhead restyle (2026-09-02)

Owner-approved mockup ("Lien Filing Restyle" artifact) after seeing the bare
§ 53.056 notice PDF land in their inbox. The statutory wording is untouched
everywhere — § 53.056(a-2) requires "substantially" the prescribed form, and
this is letterhead-and-typography dressing only.

- **`lienFilingDocuments.ts`** (shared renderer → notice, affidavit, release
  of record all inherit): new `letterhead` / `refstrip` / `deliveryRecord`
  block kinds behind an optional `FilingDocExtras` param on the three
  builders; `filingLetterheadFromIssuer` folds the invoice-issuer settings
  (company, `licenseLine`, address, phone · email) into the letterhead;
  `filingDocFooter` gives each instrument its statute citation. The formLine
  render became a form grid — muted sans label column, bold serif values on
  ruled lines (blank = honest blank). Signature blocks moved right-aligned;
  the notice gained a claimant signature line, and its "party with whom
  claimant contracted if different" line is now omitted when blank (owner
  decision mid-build — the line only applies when someone other than the
  original contractor hired us). The PDF stamps a footer rule + citation +
  `Page n of N` on every page.
- **`LienFilingTabs`**: passes issuer letterhead + Job #/work month/date ref
  strip into preview/print/PDF/email; the recorded-row View re-render adds a
  **Delivery record** box built from the row's `sends` (recipient, method,
  tracking, date). The in-app preview switched from the text twin to the
  HTML walker so it matches the printed page.
- **`demandLetter.ts`**: `senderBlock` restructured to
  company/licenseLine/contactLines (renderers updated incl. the modal's
  inline preview); new optional `businessLicense` field prefilled from
  `issuer.licenseLine`; PDF letterhead + per-page footer.
- **`lienWaiverRelease.ts`** (light touch — signed forms): company-name
  letterhead line + rule on print/PDF, per-page footer with the form title.
  Stored signed PDFs are untouched; only fresh renders pick up the look.

Kernel-only restyle — no schema, no edge functions; 5 new
lienFilingDocuments tests (extras ordering, letterhead helper, escaping,
footers, no-extras compatibility).
