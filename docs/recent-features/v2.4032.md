# v2.4032 — My Time day editor: changing only the notes keeps approved hours approved — `segmentsAreTheRowsUnchanged` (2026-09-28)

Client only; no migration, no edge function. **Payroll fix.** From the map's quirk 27 (found by the tests of [v2.4021](v2.4021.md)); punch list **#46** row 10. Stacked on [v2.4023](v2.4023.md).

## The bug

A block of several contiguous clock rows on the same job and origin opens with one part per row. Editing only the notes and pressing Save went down the ladder's homogeneous branch to `split_*_clock_session_cluster`. That RPC deletes the rows and inserts new ones, and for an approved closed row it first calls `people_hours_subtract_approved_hours` — so a notes-only edit took the block's approved hours out of payroll until a lead approved them again. The approved-hours confirm warned about exactly that, correctly.

## The fix

- **`segmentsAreTheRowsUnchanged(c, split, nowMs)`** in [`lib/myTimeDaySavePlan.ts`](../../src/lib/myTimeDaySavePlan.ts): one part per row, each starting and ending where its row does (an open last row's end is the running clock and is not compared), and any job chosen for a part is its row's own (`orderedSegmentsFollowTheirRows`).
- **The ladder** (`lib/myTimeDayPersist.ts`) checks it for a block of several rows before the split / replace branches, and writes one `UPDATE clock_sessions SET notes` per row. No trigger on `clock_sessions` touches approval on a notes update.
- **`noteOnlyApprovedSafe`** (`lib/myTimeDayEditorDirty.ts`) returns true for the same shape, so the approved-hours confirm no longer shows for a notes-only edit of a multi-row block.
- A moved seam, a job chosen that is not the row's own, or a block merged into one part saves as before.

## Verified

- `myTimeDayPersist.test.ts`: the test that pinned the RPC call now pins note updates, plus an open last row, a chosen job and a moved seam (71 tests).
- `myTimeDayEditorDirty.test.ts`: the multi-row approval cases (24 tests).
- The 285 tests of the day editor's libs and components; eslint; `npm test` in full; typecheck.
- Not checked by hand in the app.
