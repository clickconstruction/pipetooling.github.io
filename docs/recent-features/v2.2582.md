# v2.2582 — Lien release tracking: Bill Customer strip + cleared-payment nudge (2026-09-01)

Phase 2 of the lien tooling proposal (phase 1 = v2.2579): generated releases
become records the app can act on.

- **Migration `20260901180007_job_lien_releases.sql`** — one row per generated
  document (`invoice_ids` snapshot, `form_type`, `amount`, `through_date`,
  `fields` jsonb of the rendered document, `voided_at`). Office-set RLS; see
  `docs/migrations/20260901180007_job_lien_releases.md`.
- **Modal records issues** — `LienReleaseModal` gains "Save & mark issued"
  (INSERT + snapshot; footer button turns green "Issued ✓"), an `onIssued`
  callback, and an `initialFormType` prop for the unconditional follow-up.
- **Board badge** — `JobsStagesTab` loads `lienReleaseJobIds` (same fail-soft
  pattern as `hazmatFeeJobIds`); rows with a live release wear a blue box on
  the release button; mobile card sheet shows the 'live' badge.
- **Bill Customer strip** — `BillCustomerLienReleaseStrip` (new, self-contained
  I/O) mounted in `SendRecordInvoiceModal` under the bill-to banner: lists live
  releases with clearance ("check not cleared yet" / "payment cleared" from
  `jobs_ledger_payments` matched to the release's `invoice_ids`), View
  (re-renders the snapshot in a preview window), two-click Void, "+ New
  release", and "Issue unconditional" on cleared conditionals (opens the
  release modal preset to unconditional-progress on the covered lines).
- **Needs You nudge** — kernel `computeLienUnconditionalOwed` +
  `useLienReleasesOwedNudge` roll up cleared-but-unfollowed conditionals
  company-wide; new `lien-unconditional` item (blue, received-money tier 20)
  on the Dashboard card and the Quickfill Needs You section, action →
  `/jobs?tab=stages`.
- **Kernels + tests**: `src/lib/jobs/lienReleaseTracking.ts` (14 tests:
  clearance matching, owed-follow-up settlement incl. voided/other-line
  unconditionals, company roll-up), needs-you builder tests extended.

Types: `src/types/database.ts` regenerated after `supabase db push` during the
merge window.
