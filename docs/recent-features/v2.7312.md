## The picks

- **The client sends the list, the database checks the list.** The range parser has one home, on the client, where the read line under the field needs it; the database holds what it can check on the list itself. Two parsers would drift on the shorthand.
- **The old call shape is dropped, not kept beside the new.** `mint_sticker_run(uuid, integer, integer)` and a four-argument twin with a default would leave PostgREST to choose on every call; one function with the default answers both.
- **The name is a promise, never the box's label.** `box_stickers.box_name` is what the tape reads; `job_containers.label` is the box's name, and a rename leaves the sticker's as printed, so a later scan can say *This sticker reads G78. The box is now G80.* (PR 9).
