## What shipped

- **Heading anchors for every guide** — [`helpGuideAnchors.ts`](../../src/lib/helpGuideAnchors.ts): the guide sanitizer strips `id`s, so `GuideBrowser` stamps `id = headingAnchor(text)` on the rendered article's `h2` / `h3` and scrolls to `location.hash` after render; `helpGuideHref(slug, headingText)` builds `/help?g=<slug>#<anchor>`. 3 tests.
- **`LIEN_RULE_CITES`** — [`lienRuleCites.ts`](../../src/lib/jobs/lienRuleCites.ts): section → the guide heading that explains it (§ 53.003 · 53.056 · 53.081 · 53.052 · 53.152 · 38.001/38.002 · Rule 185 · § 392 · 28.004 · 302.002 · 31.04 · 27.031, residential, delivery); `lienRuleHref(cite)`; `LIEN_RULES_DOOR` names where each surface's door lands. The test reads the guide file and fails if any entry no longer matches a real `##` heading — the guide and the doors cannot drift apart.
- **The doors** — [`LienRulesDoor.tsx`](../../src/components/jobs/LienRulesDoor.tsx), a plain link in a new tab so the desk or window stays open: on the Lien desk header beside the Notices / Affidavits switch (→ § 53.056, or § 53.052 on the affidavit view); on the Lien window's tab row, right-aligned (demand → attorney's fees and presentment; notice → § 53.056; affidavit → § 53.052; release of record → releases and waivers).
- **The basis lines are links** — the demand letter's interest switches print *Prop. Code § 28.004 — …* / *Fin. Code § 302.002 — …*; the `toggle` helper takes an `extraHref` and those two open their rows.
- The guide's intro names the doors.
