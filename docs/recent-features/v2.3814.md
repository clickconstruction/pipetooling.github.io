## How they are made

- [`src/lib/pipeWordmark.ts`](../../src/lib/pipeWordmark.ts) gains `pipeWordSvg(word, { color, accent, width })` — the standalone SVG string (`xmlns`, `<title>`, the same path, flanges and wheels the component draws), or `null` for an undrawable word. 1 test.
- [`scripts/pipe-wordmark-assets.ts`](../../scripts/pipe-wordmark-assets.ts) (`npm run brand:pipe-wordmark`) writes the SVGs and renders the PNGs with Playwright's Chromium from the same string (`omitBackground` for the transparent ones). Re-run after any glyph change and commit the output.
