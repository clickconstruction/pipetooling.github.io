# v2.7413 — Painted maps: the server can keep who opened a map's link (2026-11-15)

Punch list #345, the link that asks who is looking, step B. The table came in v2.7411. This is the `painted-map-link` function's side. The page that asks for a name is step C.

## What changed

- **`way.open`**: the page's new way to open a map. With no name known for this device on this link, the answer is the map's name and who sent it, and nothing else of the map. With a name, the answer is the map, and one visit is kept or counted again.
- **`way.here`**: where the reader is, sent only after they press **Show where I am** on a page that says the company will see it. The first point once, then the latest. Never a trail, and never more often than every twenty seconds.
- **A signed-in teammate types nothing.** Their session names them from their account. An account that has left types a name as a stranger does.
- **The old way in still answers.** The plain `GET` the live page uses returns the map as before, so nothing breaks between this deploy and the new page. Step E closes it.

## What is kept per visit

The name as typed and tidied. The id the page keeps on that phone. The device in two words (*iPhone · Safari*), the browser's own description, the screen, the language, the time zone and the address the call came from. When, and how many times.

## How it is built

- Pure, in `_shared/paintedMapLink.ts` and mirrored to the app (+5 tests): `paintedMapVisitorName`, `paintedMapDeviceId`, `paintedMapDeviceWords`, `paintedMapVisitPoint`, `paintedMapVisitPointColumns`.
- `openLink` is the one read of a code for the `GET` and both new actions: a wrong code is a counted miss, and an ended or expired link answers as a wrong code does.
- The log lines say that a visit or a place was kept. Never the name, the device or the address.

## Is this the best we can do

- **A name can be anything.** The function refuses only what nobody could be called: nothing, or marks alone.
- **The device id is the page's word.** Someone who clears their browser, or writes their own call, is a new device. That is the limit of a web page, said on the card.
- **The gate is soft until step E.** Someone who knows the function's address and a link's code can still read the map with the old `GET`. Closing it now would break every page already open on a phone.
