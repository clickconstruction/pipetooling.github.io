# v2.6252 — The adopt window names each version on the preview (2026-10-31)

Feature, no migration, no edge function. In the ZZ Test dry run of 2026-10-31 for the Gun Dog adopts (punch list #208) the version came out named *source 2026-10-31*, the suggestion, because the name field sits on the pick row beside the tick and was never seen; the preview step, where a person reads *B572 … becomes …*, printed the name as a word.

## Change

- `AdoptBidModal`: the preview step draws each version's name as a field (the same `names` state the pick row writes, so either step's typing is what `adopt_bid_as_version` gets as `p_name`), disabled while adopting; both fields carry the label *Name of the version from B<n>*. The failed-adopt line reads *Press Adopt to try again, or change the name here first.*
- `AdoptBidModal.render.test.tsx`: the preview's field shows the pick row's value, and the name typed on the preview is what the function receives.
- The guide *bid one project to multiple GCs* says to name each version on the preview before pressing Adopt.
