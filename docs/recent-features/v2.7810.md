# v2.7810 — Time on the site map of boxes (2026-11-18)

Punch list #395, step 5 of 7. `OnSiteMap` is its own Leaflet map, not a map of dots on the shared canvas, so it takes the pieces and not the frame: `useMapTime`, `MapViewControl` and `MapTimeRow`.

## What changed

- **Where it shows.** Job → Materials' site map, Tally → On site's map sheet and **Where is it?** The component offers Time by itself whenever it is being looked at, so no caller changed.
- **Time moves nothing here.** The map is already close on the site. Time swaps the tile layer, today's photograph or an older one, and the map stays as the person left it. The spot the archive is asked about is the pin the map opened on, or else where it opened, and the row calls it *this site*.
- **Never while placing.** A pin dropped on an older photograph lands where the ground no longer is. The press and the row are absent while `placing` is set, and placing that begins while Time is on turns Time off first. A `still` map has no press at all, as before.
- **Room for the row.** A map of a set height keeps its height and the row adds below it. A map that fills its parent (`height="100%"`, the sheets) gives the row its room and the sheet does not grow.
- **The presses.** The map's own Satellite and Streets buttons become the shared `MapViewControl`, 34 px tall on a phone.
- **The credit** on today's photograph reads Esri, Vantor, as Esri's own page does.
