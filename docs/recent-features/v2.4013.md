## What shipped

- **`src/lib/bids/directCostHandlers.ts`** — `directCostHandlersByKind(client, { costEstimateId, setError, tables })` gives the direct-cost list its `add` / `update` / `remove` for each of the five tables; `directCostHandlersFor` is one table's three. `BidsLaborTab` carried fifteen handlers — the same three, five times over.
- **The model is unchanged, and written down in tests:** a field edit changes state only (the tab's autosave writes it); an add waits for the cost estimate, inserts a blank row after the highest order on the list and appends what the database returns; a remove drops the row from the list first and then deletes it — a failed delete says so and does not put the row back (the map's quirk 9).
- **The failure words are the ones each table had:** "equipment row", "permit row", "subcontractor row", "waste row", and plain "row" for Other.
- **`laborTotalFromInputs`** in `src/lib/bids/laborTabCostSummaries.ts` — the line under the hours table (Σ row hours × the labor rate box; an empty or unparseable rate is 0).
