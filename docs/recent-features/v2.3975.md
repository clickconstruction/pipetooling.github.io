Built on v2.3972 (the handlers onto the lib).

## What shipped

- **`src/components/workflow/WorkflowLineItemModals.tsx`** — the six windows' JSX, moved verbatim, one small component per window: `DeleteLineItemConfirm`, `EditLineItemWindow`, `AddPurchaseOrderPicker`, `AddInvoicePicker`, `PurchaseOrderDetailWindow`, `InvoiceDetailWindow`. Each is mounted only while its window is open.
- **What stays the page's** — which window is open and what it holds (eight state values: the stage cards open the windows and read the pickers' lists for button visibility), the 200ms effect that fills the pickers, and every handler. The component gets each as a prop and hands every action back: 21 props. They follow the cards when the cards move (the map's step 10).
- **What moved with the windows** — the two state values only the windows used:
  - the invoice picker's search text. The page cleared it by hand on Cancel and after a successful attach; it is now a `useState` inside the picker, which is unmounted when the picker closes, so it is blank on every open the same way.
  - the clipboard import's busy flag, with `importLineItemsFromClipboard` (clear the page's error, read the clipboard, hand the text to the page's `importLineItemsFromPaste`, send a refused clipboard to the page's error line).
- **One mount** — in the page the windows sat in three places among its other modals. All are `position: fixed` at `zIndex: 10` and only one is open at a time, so their order in the document does not show.
- **`src/pages/Workflow.tsx`** — 3,689 → 3,367 lines; 47 → 45 `useState`.
