# v2.7907 — The font shorthand sweep: 201 styles draw at their own size and weight (2026-11-19)

v2.7902 fixed one style, the chips of `PermitPlaceList`. This is the sweep of the rest. No migration, no edge function, no new page.

## What was wrong

`font: 'inherit'` in an inline style is the whole-font shorthand. React sets a style's properties in the order the object holds them. A `fontSize`, a `fontWeight` or a `lineHeight` that comes before the shorthand is reset the moment the shorthand lands. The press drew at the page's size and weight, not its own. A later render that changed the weight set that one property, which is why a chip turned bold only after its first press.

`src/index.css` already gives every `input`, `select`, `textarea` and `button` the page's font. So the shorthand added nothing on a press but the family.

The app writes `font: 'inherit'` about 2,500 times. Most are harmless: the shorthand comes first and the size follows it. 201 were not.

## What changed

`scripts/codemods/font-shorthand-sweep.mjs` rewrote 200 styles in 144 files. In 199 the change is one word: `font: 'inherit'` became `fontFamily: 'inherit'`. In one the shorthand was dropped, and one more style was changed by hand (both below). The diff holds nothing else in `src/` but a test.

- **The order it reads** is the order the finished object holds its keys. A key written twice keeps its first place, as a JavaScript object does. So `{ ...circle, font: 'inherit', fontSize: '0.625rem' }` is caught when `circle` already holds a `fontSize`: the size keeps `circle`'s place, ahead of the shorthand (`PropertyKindBadge`).
- **It follows a spread**: a style by name from the same file or a file it imports, a style a function returns, every style of a map read by key, and both branches of a condition. Three of the 200 were found this way.
- **A style that wrote a `fontFamily` before the shorthand** has the shorthand dropped, so the family it wrote holds. One did: the amount box in `ApplyPicksToCostsModal` spreads the modal's monospace style and now draws in it, with `tabular-nums`, as the numbers beside it do.
- **Left alone:** a shorthand with no longhand before it, and any `font` whose value is not `'inherit'`.
- **By hand, one:** `LienDeskNextUp.tsx` spreads a `style` parameter and then the shorthand. One caller passes `fontWeight: 700`, which the shorthand reset. A parameter is not something the codemod can read. On a rebase, re-run the codemod and make this one change again.
- **Listed, not changed, one:** `QuickfillLastMarkedDoor.tsx` spreads a `style` prop before the shorthand. Its callers pass no weight and it sets the size again after the shorthand, so it draws right.

`npm run check:font-shorthand` runs the codemod with `--check` in CI and fails a PR that writes a new one. `CLAUDE.md` carries the rule.
