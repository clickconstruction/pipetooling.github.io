# v2.2533 — Audits tab: requested stamp carries time-of-day + relative age (2026-08-31)

Owner request (reviewing the audit queue): the card stamp showed only the date
(`requested 2026-08-30`). It now renders via a pure kernel helper,
`formatAuditRequestedStamp(iso, now?)` in `src/lib/bids/bidAudits.ts`:
`requested Aug 30, 2:14 PM · 19h ago` — relative part rolls minutes → hours
(under 48h) → days, unit-tested in `bidAudits.test.ts` (bad-timestamp fallback
keeps the old date slice). Consumer: `BidsAuditsTab.tsx` card header.
