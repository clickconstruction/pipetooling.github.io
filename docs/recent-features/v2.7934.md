# v2.7934 — Robots: an assistant can set who the robots are graded against (2026-11-19)

A new pair on `dev-mcp` (server 0.110.0, 135 write verbs, 82 naming no RPC, 186 tools): **`plan_calibration_standard`** → **`apply_calibration_standard`**. The owner, 2026-11-19: "Please build the reference metadata and the calibration standard".

## Why

The audit of what an agent can stand up alone listed the calibration standard beside the rung. A shadow scored against a standard's sent bid counts toward Gate B. Against anyone else it is practice. Setting the flag was a press on the ★ Calibration standard card at Settings → System → Digital twins.

## What it does

It makes the panel's own write (`DigitalTwinsPanel.setCalibrationStandard`): `calibration_standard` on a person's `users` row.

- `calibration = { person, standard }`. The person is a users.id. `standard` is `true` or `false`.
- The flag is a person's. A twin is refused.

## The plan

- It reads the person, every standard, and the scored shadow runs that name the person as teacher, as the dev.
- It answers the standards before and after.
- It counts the scored runs that would move into or out of the gate, by axis. An assisted run is counted apart, since it never counts either way.
- It warns when no standard would be left. Gate B cannot be met then.
- It warns when a new standard would stand beside another. This door adds. It does not replace.
- The hash commits to all of it. A standard set or lifted since the plan refuses the apply.

## Who may be made one

The panel's own rule: an estimating role, not a twin, not archived. The rule moved to `supabase/functions/_shared/twinTeachers.ts` (`canBeCalibrationStandard`), and `src/lib/twinTeachers.ts` re-exports it. The panel itself did not change. A flag already set can always be lifted.

## The write

One PATCH on the person's row, as the dev under the users table's dev update policy. It is held to the flag as the plan read it. For a new standard it is also held to a live row that is not a twin. The reply says `changed` and the standards as they stand.

No score is rewritten. `score_shadows` and the Scoreboard's gate math read the flag the next time either runs.
