# v2.5915 — The search box finds a guide by its question, and the punch list by its number (2026-10-26)

Punch list #181, PR 3 of 4 (`to-dos/go-anywhere/README.md`). The box of v2.5902 drew pages and Settings cards; a task typed in a person's own words, *send a lien notice*, still found nothing. The 438 guide titles are tasks in plain words, so they become the Guides group; a guide is reading, not going, so the ones about one page carry **Go there**.

## What shipped

- **The sources load on the first open** (`HeaderGlobalSearch.tsx`): the guides come from `import('../lib/helpGuideRegistry')` and, for a viewer `canOpenPunchList` admits, the board from `import('virtual:punch-list')`, both Vite-only modules the kernel takes through `DoorSources`. They load once per session and never for a role that cannot open them, so a helper's phone never fetches the board.
- **Guides** (`guideDoors` in `doors.ts`): a door per guide, its title the label, `Guide · <category>` the where line, the `keywords:` its words, gated by `guideIsRelevantForRole`. The match strips a leading *how do I* and a trailing *?*, as the Help page does, and reads the title and the keywords, never the body, so the long tail stays on `/help` and *the* finds the three best. `?` narrows to guides.
- **`where:`** in a guide's front matter (`HelpGuide.where`, `helpGuides.ts`): the app link the guide is about. The box's row gains **Go there →** (`Door.also`), whose press opens that link and records the click as `<door id>#there`. Seeded once by a script from two sources, the directory's *Go here when…* lines (71 guides) and, for the rest, the first in-app link in the guide's body (45 more), 116 in all; `doors.test.ts` holds every `where` to a route `src/App.tsx` serves, so a renamed page fails CI. The other 322 guides gain theirs as they are touched.
- **The punch list** (`todoDoors`): for the owner and the developers, `#126 Quick replies by keyboard…` with `Punch list · <group>` under it, landing on `/punch-list#n126`. `#` narrows to the board; `# 126` finds it by number, since `#` is a word start.
- **The Lien desk is a door**: the seeding surfaced `?liendesk=1`, which `stagesDeepLinks.ts` already reads, so the desk joins the windows with the directory's lien words. The README's claim that the desk had no link was wrong.
- **Words**: the placeholder and the no-matches line name guides; the keys line says `> places`, `? guides`, `# punch list`. The guide `global-search` says the same.
