Owner request (design: "Division 22 Ledger" canvas artboards 6–7): choose what
goes in the copy, and see/fix uncoded names before sending. "Copy fixtures for
text" (Share ▾) now opens `PrepareFixtureCopyModal` instead of copying blind:

  (`22 3x/22 4x` = Fixtures & equipment, other coded = Pipe & fittings, tail

  amber strip with this bid's unmatched names + inline Pin / No code (same
  exact-rule pins as the audit, AUDIT_PIN_PRIORITY); row filter; All/None;
  two-pane live preview; footer "Copying N of M items"; Copy button
  autofocused so Enter still ships the whole list in one keystroke.
  Ledger load failure → Retry + "Copy the flat list anyway".
- Selection/scope are per-copy state, never persisted; pins are shared-ledger.
- The old inline `copyFixtureCountsForText` handler in `BidsPricingTab` is
  deleted — the modal owns the flow.
