# v2.2801 — Contract Forms PR 6: Enter from paper (2026-09-05)

The last piece of the Contract Forms train (plan: `docs/CONTRACT_FORMS_PLAN.md`; mockup picked by the owner 2026-09-04). A staff member keys a sub's handwritten form (a W-9) into the same boxes the sub would fill on the signing page, attaches the scan, and files it as signed on paper. The row ends up like a portal signing — signed, values + last-four hints, flattened PDF, compliance pill green — with `form_source = 'paper'`, the scan filed as the source, and who keyed it.

- **Door**: People → Contracts → person row → **+ Add document** → a third choice, **Enter from paper** (shown once the library has a published form). `PeopleContractsTab` mounts `ContractFormPaperEntryModal` (`src/components/contracts/formFill/`).
- **Modal**: the pages that carry boxes rendered with `PdfPageCanvas` + the signer's `FormFillOverlay` (desktop scale, no lens, no signature preview), roster-name prefill, a "the paper" card (photo / PDF up to 8 MB, JPG / PNG / WEBP / HEIC / PDF), "signed on the paper" (printed name + date), the attestation checkbox, a progress line with the required boxes still blank, **File as signed on paper**, and **Skip the boxes, just file the scan** (requires the scan). Blanks never block.
- **Kernel** `src/lib/forms/formPaperEntry.ts` (+ tests): `missingRequired` (required boxes / exactly-one groups / one-of sets left empty, once each, in order), `checkScanFile`, `buildPaperEntryRequest` (drops values when boxes are skipped), `paperEntryBlockers`, `keyableBoxes`.
- **New edge function `contract-form-paper-entry`** (`verify_jwt = false`, JWT checked in the body): `prepare` returns the schema + a 15-minute template URL; `file` validates (known keys only, scan type / size, attestation, date), fills + flattens the template with **no signature drawn** (the date box gets the date on the paper), uploads `<id>/signed.pdf` and `<id>/source.<ext>` to `contract-form-pdfs`, and inserts the signed person copy (`form_source = 'paper'`, `form_keyed_by_user_id`, `applied_contract_template_document_id` → trigger stamps `doc_type`; `note` records a skipped-boxes filing). Gate: dev, master, assistant, controller (the roles that may insert person copies).
- **`open-contract-form-pdf`** learns `which: 'scan'` — same gate, same `contract_form_pdf_opens` log, download name suffixed "(paper)".
- **Record modal**: paper entries show "Signed on paper on … by …; the signature is on the scan", the required boxes left blank, **Open the filled PDF** and **Open the paper scan**; a skipped-boxes filing says the scan is the record.
- **Migration** `20260905010500_contract_form_paper_entry.sql`: `form_scan_storage_path`, `form_keyed_by_user_id`.
- Guide `enter-a-paper-form.md` (office roles). `EDGE_FUNCTIONS.md` (new section + TOC, open-fn variant), `ACCESS_CONTROL.md`, spec + plan updated.
- **New-revision flow** (also on PR 6's list) needed no new code: the studio's **Replace PDF…** keeps every box and **Import PDF fields** adds only fields not yet bound; `forms:preview` reports unresolved binds as `skipped`. Documented in `CONTRACT_FORMS.md`.
