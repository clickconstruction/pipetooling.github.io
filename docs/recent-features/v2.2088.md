# v2.2088 — Settings reorganization: zoned tabs by page (mockup A) (2026-08-22)

Mockup (Current + A/B/C) → **A** built: zones + page-named tabs + per-tab "shows on:" hints.

- **Kernel** [`settingsGroups.ts`](../../src/lib/settingsGroups.ts) (+ tests): `getZonedSettingsGroups(role)` — zones `you / company / system / help`, labels, and `pagesHint` per group. **All existing group ids survive** (deep links + search keep working); `settings-company` is the one new id. Default landing tab is now **Your account** (first group) instead of the push log. Role reach preserved and pinned by tests — notably `settings-jobs` stays visible to master/assistant-like because Job Book was.
- **Tab bar** ([`Settings.tsx`](../../src/pages/Settings.tsx) `SettingsTabBar`): zone rows with small caps labels ("You", "Company — by page", "System", "Help"), flex-wrap instead of horizontal scroll. Group titles + hint lines come from the kernel via a lookup (one source of truth); `SettingsGroup`'s existing `description` slot renders the hint.
- **Moves** (all self-contained blocks — one JSX line each): Job Book + Stripe/physical invoice footers + issuer + Bill-Customer memo → `settings-jobs` ("Jobs & billing"); bid cover letter → `settings-catalogs` ("Bids & materials"); company documents (from Your account) + office address + map default view → new `settings-company`; Team review cadence → `settings-people`; Easter eggs → `settings-templates` ("Email templates & testing"); `settings-recent-push` relabeled "Activity logs". Removed from their old hosts (`SettingsTemplatesTab`, `SettingsDashboardTab`) with pointer comments.
- **Search index** updated for every moved entry + new entries (invoice footers, memo, office address, map view, review cadence); Company documents corrected to `settings-company`.
- **Help guides**: 14 guides' tab references updated to the new names; `settings-basics.md` describes the zones.
- Gotcha fixed en route: replacing a conditional's only child with a JSX comment leaves `{cond && ({/* */})}` — an object child that crashes the tab (caught live, fixed by removing the whole conditional).
