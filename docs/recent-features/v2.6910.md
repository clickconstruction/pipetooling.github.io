# v2.6910 — A text from a box label reaches the Messages page (punch list #294) (2026-11-10)

v2.6874 gave the signed-out box page **Text the office**, addressed to the letterhead's number (`PORTAL_COMPANY.phone`), and left one question for the owner: does that line take texts. His answer: it is a Google Voice number that goes to his email, and the other office numbers take texts that a user sees in the app. So a text about a cage was reaching nobody on the Messages page.

## What changed

- **`supabase/functions/_shared/boxPage.ts`**: `boxPageOfficePhone(candidates)`, the first number that is there (`boxPage.test.ts`).
- **`box-read`**: `officePhone(admin)` reads Settings → Phone and texts' boxes (`app_settings` `messages_boxes_v1`, through `parseBoxSettings` and `boxSetting` in the copied kernel `gcKernels/lib/messages/boxes.ts`) and hands the kernel, in order, the **team** box's number, the `QUO_COMPANY_PHONE` secret that box falls back to, and the letterhead's number. The team box is the one for customers, leads and subs; bids@ is the GC side's trades. A settings read that fails falls back to the letterhead, so the page never loses the row. Both the box's answer (`office.phone`) and a retired label's 410 (`phone`) use it. One small read rides the box's own `Promise.all`.
- **`scripts/edge-kernels.mjs`**: `box-read` joins `IMPORTERS`, since its bundle now reaches the copied kernels (`edgeKernels.test.ts` checks the list against the bundles).
- `docs/EDGE_FUNCTIONS.md` (box-read's response and secrets), `docs/ACCESS_CONTROL.md`, `docs/MATERIALS_ON_SITE_ARCHITECTURE.md`, the card.

## Not changed

The page: it draws whatever number the function answers, so no client code moved. The payload's shape. The privacy line: the number is the company's own line, never a person's. Nothing signed out writes; the text is still the phone's own Messages.

## Deploy

`supabase functions deploy box-read` after the merge. Until then the page keeps the letterhead's number.

## Verify

After the deploy, `box-read?code=<a ZZ cage's code>&preview=1` answers `office.phone` as the team line Settings shows. Scan a ZZ cage signed out, press Text the office and send: the text shows on the Messages page.
