# v2.2288 — Pay speeds receipts name their jobs (2026-08-25)

Owner feedback: the receipt chips under a customer (`(+24) 07/21–08/14`)
showed the gap but not *which job* — and they wanted tap-to-open job detail.

- **Migration `20260825160000`** (details in `docs/migrations/`): RPC v7 —
  each receipt jsonb gains `jobId`/`jobName`/`address` from the
  `jobs_ledger` join that was already in the query.
- **Client**: `PayReceipt` type + parser carry the job fields (null on
  pre-v7 payloads — fail-soft). `receiptChip` became `receiptRow`: one
  payment per line — gap badge, billed–paid dates, job name · address,
  chevron; clickable rows call the new `onOpenJobDetail` prop, threaded
  `JobsStagesTab → BilledPaymentForecastModal → PaySpeedsBreakdownModal`
  (both modals close, then `jobDetailModal.openJobDetail({ jobId })`).
  Jobless receipts render dates only, unclickable.
- **Removed**: the "+ Weekly hygiene task" checklist-preset link on the Data
  health strip (owner request; `useChecklistAddModal` usage dropped).
