- **`_shared/driveJobFolder.ts`** (lifted by cut 10, #5627) takes the rest of drive-link's Drive work: `halfInside` (whether a file's parents reach the job's folder, and which half), `driveFileMeta`, `driveMedia` (Drive's `alt=media` answer, which the open door streams), `driveFileBytes` (the bytes whole, refused past a cap by Drive's own length or as they come) and `makeDriveLink` (a `drive_links` row by the link's SHA-256, refusing a file outside the job's folder or a Team only folder). drive-link calls them in place of its own copies, with the same answers and the same words.
- **`_shared/driveLink.ts`** takes `bytesOfBase64`, a file from this computer, which `messages-email` reads too.
- **`_shared/messagesEmailFiles.ts`** (new, pure): `parseEmailFiles` reads the files the app asks to send, each from the job's Drive, a file that came in, a sent copy's file, a paper the app makes, or this computer. One that does not fit refuses the whole list. A paper other than our contract goes only as its portal page (the lead, 2026-10-13), and a sent copy's path never climbs out of its bucket. `carryRefusal` and `carryWords` hold the function to the app's limits, `emailLinkLines` writes the lines under the words as a text's are, and `outCopyPath` names a file kept with the line under `out/`.
