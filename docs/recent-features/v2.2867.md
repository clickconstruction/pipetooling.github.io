## The board — [`JobsWorkOrdersTab.tsx`](../../src/components/jobs/JobsWorkOrdersTab.tsx) rewritten on one kernel

[`src/lib/subWorkOrders/workOrderBoardRows.ts`](../../src/lib/subWorkOrders/workOrderBoardRows.ts) — `buildWorkOrderBoard({ sheets, assigneesBySheetId, roster, commitments, jobs, todayYmd, orderLabels })` (11 tests) → `{ rows, groups, counts, tiles }`:

- **Rows are sheets.** A roster-sub sheet (`isRosterSubSheet`, v2.2865) is a row when money is open on it, it was never priced, or any agreement (draft / sent / signed / declined) sits behind it. **Paid-up sheets with no order are history** and stay off the board; **crew pay sheets never appear** (change 7 — the "Subs only" toggle from the approved mock is gone; there is nothing to toggle).
- **Coverage** per sheet: orders anchored to the sheet (`labor_job_id`) plus job-anchored orders (`job_id`, no sheet) which cover every sheet on that job; `buildJobWorkOrderCoverage` picks the one the rail reads. An order with no sheet at all (a job- or step-anchored draft / offer / decline on a job with no sheet rows) becomes its own `order:<id>` row so an agreement in flight is never invisible; unanchored ones take the snapshot / step label the component knows (`orderLabels`).
- Each row carries `agreed / paid / open / unpriced` (`subLaborJobBalance`), its `rail` (`buildSheetRail`), its `next` (`sheetNextAction`), `group` (rail group), `notInPipeline`, `recordId`, `sheetDate`. Sorted group → rail position → open money → job number.
- **Tiles** (change 1): `handshakeUsd` / `handshakeCount` (open money on no-agreement rows), `offersOut`, `signedThisMonth`. **Search** (`workOrderBoardRowMatches`): sub, job number, customer/label, address, WO number. **Filters** (change 2) are the four rail groups with counts — `WORK_ORDER_BOARD_FILTERS`; `workOrderBoardFilterFromParam` maps the v2.2819 `?wof=` words (`drafts` → Drafted, `awaiting` → Sent, `declined` / `expired` → No agreement) so the Needs You link still lands.

The component keeps its actions (withdraw, discard, signed on paper, nudge, print, the assembler, the `?wo=` deep link) and adds:

- **Groups in the table** (change 5): *Working with no agreement* (header in the gap red when non-empty) · *Drafted* · *Sent* · *Signed* — Signed collapsed by default with `Show N ▾`; empty groups say what would appear there. The amber "Needs a work order" panel is gone: it *is* the first group.
- **Next column with the button first** (change 4): `draft` → assembler on the sheet (`laborJobId` + sheet total), `price` / `send` / `reoffer` → the order, `nudge` → the existing reminder; secondary actions follow by state, then **Sheet ›** (change 6, new prop `onOpenSheet` — `Jobs.tsx` opens the Sub Labor editor via `subLaborFormRef.openEdit`, and now loads `laborJobs` on this tab too) and the **WO number ›** door to the record.
- **Not in Pipeline** (change 3): amber tag + **Link to a job…** (the assembler's `ScheduleDispatchAssignJobPickerModal` + `subLaborAssignPickerRows`; confirm → `people_labor_jobs.job_number := job.hcp_number` → reload) + **New job…** (opens the New Job form with a toast: give it the sheet's number and the sheet links itself).
- **Phone** (change 8): `useIsNarrowScreen` swaps the table for cards — job, sub, the three money figures, the compact rail on its own line, Next + the button, secondary actions.
