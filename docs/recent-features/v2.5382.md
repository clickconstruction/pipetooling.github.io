PR 4 of the Docsmit train (`docs/DOCSMIT_LIEN_RUN_PLAN.md`, *The window envelope* and *The owner read it*). Docsmit mails a US-Letter PDF tri-folded in a double-window #10, so the owner's page 1 (counsel's cover letter) must show the recipient where the lower window falls. Nothing on screen calls it yet; the run window (PR 5) will.

**`src/lib/mail/windowEnvelope.ts`** — the zone (`WINDOW_ZONE_MM`, the standard #10 double-window geometry on a tri-folded page: 22 mm from the left, 48 mm from the top, 95 × 30 mm; the first Tracksmit run is read on paper and the numbers amended here if it is off), `windowAddressLines` (the company or the person, the street, a suite, *City, ST ZIP*), `mailShortCode` (eight characters, no 0/O/1/I), `mailOpenUrl` / `mailOpenDisplay` (the bill's pay page with `?m=CODE`), `mailOpenCodeFrom` (the pay page reads the code off its own address), `WINDOW_QR_CAPTION`. Three tests.

**Two block kinds** (`lienFilingDocuments.ts`): `windowAddress` (drawn at the zone whatever the cursor says, the letter resumes under it; the HTML preview shows a dashed box where the window falls) and `qrLink` (a 22 mm code at the margin, the caption and the link in words beside it; a dashed square when there is no image). HTML, text and PDF renderers; the PDF test holds the code's image under the zone.

**The cover letter** (`lienDeskRun.ts`): `CoverPageInput.window` (`CoverWindow`: the lines and the code) and `coverWindowBlocks`; `runCoverNoteBlocks` puts the two blocks right after the letterhead on both the letter and the note path. `buildRunNoticePdf` (`lienDeskRunIo.ts`) takes `opts.window` for the owner's copy only. A copy printed here passes nothing and prints as before.
