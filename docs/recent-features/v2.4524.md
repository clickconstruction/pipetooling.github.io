# v2.4524 — Pipeline: line icons in the ☰ tools menu (2026-10-04)

Client only; no migration, no edge function. After the Lien desk's gavel went on the stage bar (v2.4520) the owner asked for icons across the ☰ Section tools menu, picked one per row from three choices each in a mock-up, and chose one color.

## What changed

- **The picks** (`icon` on each item in [`stagesSectionToolsMenu.ts`](../../src/lib/jobs/stagesSectionToolsMenu.ts), now a name — `StagesToolGlyph` — where it was an emoji character): Lien desk `gavel` · Recently added `history` · Stage moves this week `route` · Weekly money movement `cash` · Capable of Being Billed `file-dollar` · the three notification rows `bell` · GC Review `building` · Accounts Receivable `bank` · Share / Print `share` · the two Chart rows `chart-bar` · Payment forecast `calendar-bars`. `icon` is required now; GC Review used to leave it out for the view's hard hat.
- **The drawing.** [`StagesToolsMenuGlyph.tsx`](../../src/components/jobs/StagesToolsMenuGlyph.tsx) (new) maps a name to its `lucide-react` icon at 16 px, in `var(--text-muted)`. The gavel is `StagesGavelGlyph` in the orange the bar's shortcut and the row's Lien window button wear. The library has no page-with-a-dollar, so `file-dollar` is drawn there to the library's grid and weight.
- **Not changed:** the rows, their order, their gates, their badges, and the section headers' own buttons (*GC Review*, *Accounts Receivable*, *Share / Print*, *Chart*, *Payment forecast*, the notification buttons), which still wear their earlier marks. The GC hard hat stays everywhere else it is used.

## Tests

`stagesSectionToolsMenu.test.ts`: the whole key → icon table is pinned (was a spot-check of emoji). `JobsStagesSectionToolsMenu.render.test.tsx` (+1): every row draws an icon, the gavel in its orange, the rest in the one color.
