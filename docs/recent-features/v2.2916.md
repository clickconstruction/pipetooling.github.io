# v2.2916 — Roadmap is its own page; Farm Mode says where you are and how to leave (2026-09-05)

Journey-map Tier-2 #41 (J30-1 / N4 / adj-2 / adj-4, cluster C61 "two products on one page"). The daily checklist and the owner's roadmap planner shared `/checklist`: "dev-only Roadmap" was a **client lens** (`canSeeRoadmapTab = role === 'dev' && !farm`) over data RLS lets dev / master / assistant-like / primary read and edit (`is_checklist_tech_tree_staff_or_primary()`), so the office saw the roadmap's GOALS strip on Review and could edit roadmap tasks from the Where-this-fits sheet without any door to the roadmap itself; the owner's farm roadmap card ranked 50 inside the company's worst-first Needs-You stack (`dashboardNeedsYou.ts` had no roadmap `kind`); Farm Mode had no on-page state or exit (the only signal was inside the gear menu) and left the `/` Person quick sheet reachable.

**Client only — no migration, no edge function.** Telemetry: one new `ui_nav_clicks.control` value, `farm_mode_exit` (target = the path the person was on).
