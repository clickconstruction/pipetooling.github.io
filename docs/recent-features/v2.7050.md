# v2.7050 — Farm Mode is now Task Mode (2026-11-12)

Grace, 2026-11-12, looking at the gear menu: "farm mode is really task mode. Right now farm mode was labeled farm mode because there were people on our team whose job was to be farmhands and do tasks. It really should be task mode."

## Is the new name true?

Yes. The mode turns the app into one page, the Checklist, with two tabs: Today, the tasks handed to you for the day, and History, the ones you finished. The header keeps **＋ Task**. Nothing in it was ever about a farm except who used it first. "Task Mode" says what a person gets. "Farm Mode" said who it was built for, and a helper in the shop had no reason to think it was for them.

The one thing the name still does not say is that the rest of the app goes away. The gear row's tip now says it before the press: *Turn Task Mode on. This device shows only your checklist.* and, while it is on, *Turn Task Mode off. The full app comes back.* (`taskModeToggleTip`). A tip is a hover, so a phone never sees it. The strip's Exit is what a phone has, and it was already there.

## What a person reads

- **The gear menu's row** and the phone dock's More sheet row: Task Mode. Same place in the list, same lime check, same press.
- **The green strip** above the checklist: *☑ Task Mode · Exit*. The wheat mark is gone, since the new name made it the odd one out. Its screen-reader names and its tip say Task Mode.
- **The guide** is `task-mode.md`, *use Task Mode to see only my checklist*. Its examples are a shop's as well as a farm's now, it keeps `farm mode` as a search word, and one paragraph says the mode had another name until November 2026. Three other guides name the mode in a sentence each (`pin-mode`, `plan-the-roadmap`, `find-a-job-address-from-the-field`).

## Old links

A guide's slug is its file's name, so renaming the file would have broken every address a person had saved. `src/lib/helpGuideFormerSlugs.ts` is the new home for a renamed guide's old name, one row each, `farm-mode → task-mode` the first:

- `/help?g=farm-mode`, `/settings?tab=settings-guides&g=farm-mode` and a `/help/farm-mode` link inside a guide open the Task Mode guide. `GuideBrowser` reads the slug through `currentHelpGuideSlug`, counts the open under the new slug and rewrites the address, so the address a person copies next carries the name that lasts.
- `/g/farm-mode/`, the share page, is written by the build again beside `/g/task-mode/`: the same page, with the new card and the new address in its tags.
- Settings → Usage folds the old slug's opens into the new guide's row (`guideOpens`), so the guide is not counted as two, one of them never opened again.

The mode has no route or query parameter of its own. It is a switch on the device, and it sends every path to `/checklist`.

## What kept the old word, on purpose

- **Three stored names** in `taskModeToggle.ts`: the saved key `farm_mode_<user>` in the browser, the same-tab event `farm_mode_changed`, and the usage ledger's control `farm_mode_exit`. Renaming the key would have switched the mode off on every tablet that has it on, and a second key to read beside it would be code kept for a name's sake. A test holds the key. No migration, no database name touched.
- **The farm itself.** The mode was named for the farm crew, and the farm is still a real thing in the app. Not renamed, and listed here so the call can be made apart from this one:
  - Partnerships (`/partnerships`, a dev's page): the deal's **Farm work** rate, *logged, unpaid, farm food credit*, and its **Farm job** picker, the job whose hours price at the farm rate. A partner's ledger draws a *Farm · N h* line for the week, *no cash, farm food credit*. The columns are `farm_rate` and `farm_job_ledger_id`.
  - People → Contracts: the document name box's placeholder, *e.g. Farm Work Agreement*.
  - Guides: a crew tag named **Farm crew** in two examples (`give-someone-a-task`, `add-a-stage-and-its-tasks-to-a-roadmap`) and a roadmap named **Farm 1** in three (`plan-the-roadmap`, `see-what-to-do-next-on-a-roadmap`, `see-where-a-task-fits-in-its-roadmap`). Both are names a person typed, shown as examples.
  - There is no "farmhand" anywhere, in one word or two: no role, no person kind, no label on People, no pay category by that name. The roles are the ones in `userRoles.ts`. The only pay words that say farm are the partnership's two above.
- **History**: release notes, `docs/recent-features/` and the frozen aggregators still say Farm Mode. The Glossary's Task Mode entry opens by saying the mode was Farm Mode until this version.

## In the code

One pass, `scripts/codemods/farm-mode-to-task-mode.mjs` (`--check` says what is left): four files renamed (`taskModeToggle.ts` and its test, `useTaskModeEnabled.ts`, `TaskModeChip.tsx`) and every `farmMode…` name and every *Farm Mode* in 35 files: 25 of code, the four among them, three guides and seven docs. The script lists its files by name, never by glob, because `farm` in the partner ledger means the farm. On a rebase conflict, take main's side and run it again.

By hand: the tip and the header note in `taskModeToggle.ts`, the strip's mark, the guide, the old-slug kernel and its three readers (`GuideBrowser.tsx`, `usageDashboard.ts`, `vite.config.ts`), the Glossary's entry, a line in `docs/HELP_SHARE_CARDS.md` and a clause in `CLAUDE.md`'s guide rule.
