# v2.2397 — Assign-search match highlighting + Similar/Exact toggle (2026-08-27)

Wendi: "i want exact matching as an option", highlighted matching characters in
the dropdowns, and a corner toggle "between similar pricing and exact match
pricing". Mockup reviewed and approved on the Price Book Search Matching
design canvas before building.

Kernel (`src/lib/bids/priceBookAssignSearch.ts`):

- New `searchPriceBookEntries(entries, getName, search, mode, cap)` —
  `mode: 'similar' | 'exact'`. Similar is the original any-word ranking
  (all-words first → most hits → A→Z); Exact keeps only entries containing
  EVERY search word (same ranking within). Each match carries merged
  `[start, end)` highlight ranges for every matched word occurrence, and the
  result reports `unmatchedWords` (words no entry contains), `matchedWords`,
  and `similarCount` (for the exact-empty escape). `filterPriceBookEntries`
  is now a thin similar-mode wrapper — existing call sites/tests unchanged.

UI (`BidsPricingTab.tsx`, both assign dropdowns — Old view "Search or
assign…" and the Workbench "assign…"):

- Matched characters render highlighted (`--bg-blue-200` / `--text-blue-700`)
  — the reason a row is listed is visible, including "2IN" hiding inside
  "1 1/2IN".
- Dropdown header: match count on the left ("34 similar · best match first" /
  "0 exact matches · contains all 3 words"), Similar|Exact segmented toggle
  top-right. Mode is per-device (`bidPricingAssignMatchMode_v1`), shared by
  both dropdowns.
- Amber strip when a word matches nothing in the book (Similar mode) names
  the dead word and what IS matching.
- Exact-mode empty state: "Nothing contains all of …" + a one-tap
  "Show N similar" (switches mode) — Old view keeps its "+ Add … to Price
  Book" button below.
- The Workbench dropdown is uncapped now (was top-12) — the header count is
  honest and the list scrolls; min width up 15rem → 20rem for the header.

Help guide `price-a-bid-with-the-workbench.md` "Price from the book" updated.
