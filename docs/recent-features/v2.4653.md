# v2.4653 — Lien desk: set the last day of work by hand (2026-10-06)

Migration `20261006120000_lien_last_work_day` (`docs/migrations/20261006120000_lien_last_work_day.md`); no edge function. The owner (2026-10-05): *sometimes I see "dated from the job's creation with no clocked hours" but I can remember the day the work was done. I just don't want to go back and edit hours because they've already been applied. How can I make it easy to manually mark the last day work was done? I would like to be able to do this for any job in the lien desk.* Mock-up: artifact 4FRV1hzreC6UNUSfRNjxLR — a first pass (a date box on the creation-dated row), its critique (a date with no name and no reason is a liability; it only shows once the app guessed wrong; the day must change everything at once; it must never touch the hours), and the refined line built here.

## What changed

- **The day lives on the job.** Four columns on `jobs_ledger` (`lien_last_work_on`, `_note`, `_set_at`, `_set_by`), beside the contract-end day. The four lien readers take its month as `month_source = 'hand'`: it replaces the creation-month fallback, and on a job with sessions it extends the months when the sessions do not reach it. See the migration doc.
- **Kernel** `src/lib/jobs/lienLastWorkDay.ts`: `lienLastWorkDay(job)` (hand → hours → creation → none, with the words for each), `lienLastWorkDayProblem` (a bad day, a future day, a day before the last approved session), `lienLastWorkDayPatch` / `LIEN_LAST_WORK_CLEAR`, `lienLastWorkSourceLine` (*set by hand · Robert · Oct 6*), `LAST_DAY_SET_BY_HAND_WORDS`. `lienDesk.ts`: `LienMonthSource` gains `'hand'`, `monthSetByHand`, `LienDeskMonth.byHand`, `LienDeskEntry.datedByHand`; `lienDeskAffidavits.ts`: `lastMonthByHand`; the timeline's LAST WORK node reads *last day set by hand* (`LienTimelineInput.lastMonthByHand`, set by both desk builders; the window builder also lets a hand-set day later than the sessions become the last month).
- **The line** `LienLastWorkDayLine`: the day, the source chip (blue from hours, amber from creation, green by hand with who and when), the reason, *Change ›* → a date box and a reason box, *Save the day*, *Back to clock hours* / *Back to the job's creation day*, and the words *Clock hours and pay are not changed*. Above the Months card on the desk (`LienDeskMonths` `lastWork`, office only) and in Edit Job's lien row (`JobFormLienContractRow`). A save writes the job and the caller re-reads (`onChanged` on the desk; a tick in Edit Job).
- **Lands before the push safely:** `fetchLienClockColumns` falls back to the four old columns when the new ones are not there yet; the Edit Job row reads them in a second, best-effort select.
