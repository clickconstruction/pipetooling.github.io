# v2.7541 — Checklist: a task that has a map opens it from the card (2026-11-16)

Punch list #369, step B3 of the Task Mode train (tool 8, first half), stacked on B2 (v2.7539). The owner asked, after the first mock-up: "the same way they can add a note or a photo, they can also draw a map? I think that on top of drawing a map they should also be able to leave a point on the map." No migration, no edge function.

## What changed

- **🗺 Map**, a lit pill on a card of Today whose task has a painted map (`MAP_PRESS_LABEL`, `taskMapIdOf`). It sits beside **＋ Note** and **📷 Photo**.
- **A press opens the map's own window** (`openPaintedMap`). That window opens on **Draw a line**, **Walk or drive a line** and **＋ Place**, so adding to the map is one more press. A place is a point with a name, words and a photo.
- **Which map:** the way in to the task's place when it has one, else the map picked for the task by itself. The card already drew them in that order.

## Why this half needs nothing new

Whoever reads a task reads its map, and whoever reads a map may add a line or a place to it (v2.7340). The card showed the map only once it was opened, behind **Open the map**. This step puts the door on the card's face.

## Not in this PR

- **A task with no map has no press.** The person doing a task may not write the task, so a map they paint cannot be put on it from the phone yet. Step C2 adds that, on a function from the ground migration (C1).

- `todayPage.test.ts` (35), `ChecklistInstanceCard.fresh.render.test.tsx` (18): the press on a task with a map, the way in winning over the task's own map, and no press on a task with none.
