# v2.3473 — Supply house invoice form: scrollable panel + compact rows (2026-09-15)

Client only. Taunya reported the Add / Edit Invoice modal on Materials → Supply Houses could not scroll, so on her screen the bottom of the form (Due Date, Link, Save) was unreachable.

## Cause

The dialog panel in [`SupplyHousesTab.tsx`](../../src/components/SupplyHousesTab.tsx) had no `maxHeight` / `overflow`, inside a `position: fixed` overlay that centers it vertically. The form grew past a short viewport once the **On job account** block landed (v2.2669) and its open-account / amber-nudge lines followed (v2.3160+); a centered panel taller than the viewport clips both ends and neither the page nor the panel scrolls.

## What changed

- **Panel is the scroller** — the v2.990 sticky-modal pattern from [`stickyModalHeaderStyle.ts`](../../src/lib/stickyModalHeaderStyle.ts): `maxHeight: min(90vh, 100%)` + `overflow: auto`, `stickyModalPanelStyle(560)`, a pinned title bar (title · house name · × close via `STICKY_MODAL_CLOSE_BUTTON_STYLE`), safe-area padding on the overlay, and `useBodyScrollLock(invoiceFormOpen)` so the page behind stays frozen.
- **Compact rows** — Purchase Order # · Invoice Date · Amount share one grid row (`1.2fr 1fr 1fr`); Due Date · Link (URL) share another (`1fr 2fr`). Both collapse to one column under the existing `useNarrowViewport640` flag (`narrowAging`), so a 375px phone stacks as before. Inputs gained `boxSizing: 'border-box'` so `width: 100%` fits the grid cells.
- Panel widened 480 → 560 to give the three-across row room; `minWidth: 320` replaced by the helper's `width: min(560px, 100%)`.

Live-verified on the local preview (Ferguson → Add Invoice, cancelled without saving): desktop fits with no scroll; 375×812 scrolls with the title bar pinned and Cancel / Save reachable.
