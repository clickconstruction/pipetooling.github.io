Deleted tags render as a dashed "deleted tag · categories" chip.
- **Rule form** ([`AccountingRuleFormModal.tsx`](../../src/components/banking/AccountingRuleFormModal.tsx)): a **Tag** fieldset of chips (single select; hidden tags stay pickable when already chosen) writes `bankTag: { tagId, categories: <live members> }`; the note names the categories it covers. The v2.2700 raw Bank category box stays underneath, labelled as the fallback.
