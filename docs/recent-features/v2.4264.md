# v2.4264 — Bid Board: the Bid column reads at a glance (2026-09-30)

Grace, from the Bid Board on a desktop (2026-09-30): "I don't like how small these numbers are and when a number is 4 digits I would like to see a ','." The cell read *452k* and *15813k* at 11px — the smallest type on the row, under a heading the same size as the figure. No migration, no edge function.

## What shipped

- **The Bid cell** (`BidsBidBoardTab.tsx`, the desktop table's `<td>`) is drawn at `0.9375rem` / weight 600 — the estimator name's size — with `tabular-nums` so the figures line up down the column and `nowrap` so a value never breaks around its alternate chip. The empty-value red `$` button and the *+$ alt* / *alt ?* chips keep their own sizes; only the figure grew. The phone card and the collapsed one-line row are unchanged.
- **A comma every three digits** in both thousands formatters (`src/lib/bids/bidFormatting.ts`): `formatBidValueShort` — *15813k* → *15,813k*, *1240k* → *1,240k* — and `formatCompactCurrency` — *$15813k* → *$15,813k*, *$1,240.5k*. The grouping is one private helper, `groupThousands`, applied to the already-rounded string so each formatter's rounding rule is untouched. `formatCompactCurrency`'s other readers pick the comma up with it: the Followup tab's *Bid Size* line, the followup export, the proposal PDF's *Bid Size*. Kernel tests +2 cases (`bidFormatting.test.ts`).
- Left as they were, by choice: the local copies of the compact style in `BidSubmissionFollowupExpandableDetails.tsx` and `Documents.tsx` — different surfaces, no ask on them.
