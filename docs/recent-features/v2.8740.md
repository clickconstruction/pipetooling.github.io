- Guide: *release a filed lien after it is paid* → Release a lien with money still open. `docs/ACCESS_CONTROL.md` takes its line.

## The server

Still the screen alone. The database half of the answer, refusing an early release from anyone but the three, is the database lane's own migration and is not in this PR. Until it lands, a release is an insert the office's policy takes whatever its reason says.

## What it does not do

- No release already saved is changed or reread. A release an assistant saved with a reason before today stands as it is.
- A paid job, cash, a cleared check and confirmed funds hold nothing, so nothing changes for anyone there.
