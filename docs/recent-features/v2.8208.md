# v2.8208 — Painted maps: the page a link opens is ready for Google Maps (2026-11-21)

Step 4 of punch list [#387](../../to-dos/painted-maps-on-google.md), all of it but its switch. Taunya asked for step 4 on 2026-11-21. Client only: no migration and no function. **Nothing on a screen changes.**

## Why it stops at the switch

The rule that picks the map under a painted map (`paintedMapProvider.ts`) keeps the public page `/way` off Google until a look at Google's billing console says yes, since every outside reader's open is a map Google counts. A test holds that line and says it comes out with that yes and with nothing else. This change leaves the line and the test as they are.

What the look can already read from the app's own tables, on 2026-11-21:

| Read | Answer |
|---|---|
| Links to a painted map ever made (`painted_map_links`) | 0 |
| Opens of `/way` ever kept (`painted_map_link_visits`) | 0 |

So the page adds no map to Google's count today, and each link sent later adds one for each open. Google's own console was not read for this change: it needs a sign-in this session does not have. The card has the last reading, from 2026-11-20.

## What was built

- **A reader and the line together** (`src/lib/paintedMap/frameMe.ts`, new). The page asks its canvas to keep a reader's dot and the whole map in the picture (`frameMe`). The Leaflet canvas has done it through Leaflet's own fit. Google's map has no fit that stops where the photograph is sharp, so the rule is now a kernel with the Leaflet canvas's own numbers: the first reading frames everything with the reader, and after that the map moves only when the dot comes within the outer 8% of the picture or leaves it. `PaintedMapGoogleCanvas` asks it on each reading and reads its box as it is now. An area is never framed as a spot.
- **A light page.** `/way` wears the portal's light paper whatever the app's theme, and Google's map followed the app's stamp. The Google canvas takes `light`, and `PaintedMapCanvas` hands it for the public page alone, so Google's road map and its buttons are light there at night too.
- **The page's ask.** `PaintedWay` tells its canvas where it is and what it is for (`screen: 'way'`, `use: 'looking'`). The page decides nothing: the one rule does.

After this, the yes is one word in `PAINTED_GOOGLE_REACH` (`'way'`), the one line of the test that holds it, and the guide's sentence that says the page is not on Google yet.
