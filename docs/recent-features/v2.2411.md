# v2.2411 — Bid Board "sent 1/2" badge on multi-GC bids (2026-08-27)

The follow-through deferred from v2.2407 (per-GC sent, Option A): the board row
now carries the per-GC send roll-up at a glance.

- New pure kernel `perGcSentSummary(packets)` in `gcPackets.ts` (+5 tests):
  counts REAL packets only (shared-letter recipients ride the bid and don't
  count); returns null when the badge would be noise — fewer than two real
  packets, or nothing sent yet (an all-unsent multi-GC bid already sits in
  Unsent/Working).
- `BidsBidBoardTab` renders the pill under the project name in both row
  layouts (desktop table cell + the stacked layout), above the existing
  per-GC lines: amber `sent 1/2` while letters are still out (tooltip
  "1 of 2 GC letters not sent yet"), green `sent 2/2 ✓` when complete. Uses
  the `gcPacketsByBid` data the board already loads — zero new queries.

Verified in the local app against real board rows (placement/tooltip checked
with the zero-sent guard temporarily lifted so all-unsent multi-GC bids
rendered the pill; guard restored before commit). No schema changes.
