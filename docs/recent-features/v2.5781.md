# v2.5781 — Lien desk: a white edge on the progress bar in Record the mailing (2026-10-23)

The owner, with a screenshot of the desk's header: "In the lien desk, I would like a white border around the green-like showing Record the mailing so it is easier to see." The tiny two-color bar inside the blue primary door (green for sealed, amber for waiting; v2.4982/85, v2.5522) had almost no contrast against the blue.

- **The change** ([`index.css`](../../src/index.css), `.lienRunDoorBar`): `box-shadow: 0 0 0 1px currentColor`. The door's text is white in both themes (inline `color: #fff` on the blue `#2563eb`), so the ring is white in light and dark with no token to pick. A box-shadow, not a border, so the bar stays 56 × 7 and nothing else in the header moves.
- **Checked live** as the dev on a local preview, light and dark: the ring reads as a bar on the blue in both; dark mode's lighter green (`rgb(74, 222, 128)`) sits well inside it.

## Is this the best we can do?

A border alone, or a border plus a darker track? The track (`--bg-muted`) only shows when the bar is part-way, and the ring already frames it, so a darker track would add a second color to a 7 px bar for no gain at a glance. The ring is the whole change.
