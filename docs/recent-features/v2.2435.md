# v2.2435 — CT↔PT user bridge, Phase 2: ct-bridge proxy + call sites (2026-08-28)

The wires over the Phase-1 join key (`v2.2434`). All CT legs are fail-soft: a CountTooling
failure never blocks the PipeTooling action; it surfaces as a toast / `ct_bridge` response
field / the CT-seat-missing chip, and the weekly audit (Phase 3) catches anything left.

- **New edge function `ct-bridge`**: dev-gated proxy; the app's only door to CT's
  `manage-user`. Allowlisted verbs forwarded with the bridge secret (never in the
  browser); every act logged to the function log (no audit table in v1 — locked
  decision). Secrets `CT_MANAGE_USER_URL` + `CT_MANAGE_USER_SECRET` (already set).
- **`archive-user` / `restore-user`** now mirror the retirement/restore to CT
  **server-side** via new `_shared/ctBridge.ts` (`forwardCtSeatState`) when
  `counttooling_user_id` is set — the headline win: offboarding closes both apps. The
  outcome rides a `ct_bridge` field in the response ('ok' / 'skipped: …' / 'failed: …').
- **Twin mint** (`DigitalTwinsPanel`) creates the CT seat over the bridge (CT fleet email
  `twin-estimator-<n>@twins.counttooling.local`, twin-flagged) and stores the uuid; the
  CT-seat-missing chip gains a **link** retry button — which doubles as the backfill for
  twin-estimator-1 (its seat was created during Phase-1 smoke; link fills the join key).
- **Rung toggle**: note-and-skip — CT has no read-only concept; nothing forwards, nothing
  drifts (documented in code).
- **Active Accounts**: edit mode shows **CT seat ✓** (tooltip carries the CT uuid) or a
  **Create CountTooling seat** button (manual, on demand — CT is an estimator tool;
  locked decision). Hook additions in `useActiveAccountsManagement` (fail-soft cast
  queries).
- **Backfill one-shot** (Digital twins → Connect card): walks unarchived PT users,
  `lookup`s each unlinked email on CT, fills `counttooling_user_id` for matches; summary
  toast. Twin-fleet emails are skipped (their CT seats live on the CT fleet domain).
- Deploy after merge: `supabase functions deploy ct-bridge archive-user restore-user`.
