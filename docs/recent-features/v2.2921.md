- `MONEYFILL_QUEUE_LABELS` carries a `sub-sheets` label with no fetcher or section on the page — the header's "N of M queues" can never include it. Harmless; noted so the queue count in the guide stays unnumbered.
- `run-your-gc-statement-round.md` had contradicted itself since v2.2761 (personal-only opening vs. app-sent lanes later in the same guide) — fixed here, but the "never emails" phrasing may also live in UI copy (`JobsGcReviewModal` intro); not audited in this PR.
