# v2.7304 — Print blank stickers: what the stickers will look like (2026-11-14)

Punch list #329 (`to-dos/stickers-before-boxes/README.md`), a fold on PR 2's window (v2.7272). Client only: no migration, no edge function. The owner asked on 2026-11-14, looking at the window on job 224: "this page should be able to show a user what labels will be printed in an expandable section at the bottom so the user can see exactly what they will look like".

## What changed

- **`src/lib/materials/stickerPreview.ts`**, pure, 15 tests: `previewNumbers` (the run's numbers from where the last run ended, as the foot line reads it; the first run from 0001), `previewStrip` (the strip a minted sticker prints, `stickerStrip`'s shape, with `STICKER_SAMPLE_CODE` where the sticker's own will go: eight zeros, so the QR has the same squares and the address the same width), `stickerPreview` (the first six strips in the order they print, each sticker's copies together, 1 1 2 2 3 3; with Show all the stickers after them once each up to `STICKER_PREVIEW_MAX_STICKERS`, 200), the words (`previewHeadWords` *6 strips of 200 stickers, 0003 to 0008.*, `previewMoreWords` *and 194 more, to 0202*, `showAllLabel` *Show all 200*, `previewCappedWords`, the code line *The numbers are the run’s. Each sticker’s code is given when the run prints.*, the test strip's line).
- **`StickerPreviewFold.tsx`**: the fold, **What the stickers will look like**, at the foot of the window's ask above its presses, closed until this device leaves it open (`readStickerPreviewOpen` / `writeStickerPreviewOpen` in `labelPrefs.ts`, beside the tape width and the copies). Opened, every strip goes through `TapeStripBitmap` and `tapeStripCanvas.ts`, the drawing the P-touch gets, at the window's tape width (128 dots across 24 mm, 112 across 18), so the preview and the tape agree. The rest draws at half height (`TapeStripBitmap` takes a `height`). The test strip is drawn under its own line. With no count the database would take, the fold says what fills it; while the last run is read, it says so.
- **`PrintStickersModal.tsx`** mounts the fold at the ask stage, hidden on paper with the window's other chrome.
- The site guide's **Print blank stickers** gains the fold; the map's office Labels paragraph names it; this note.

## The picks

- **The numbers are real, the code is a sample.** The window has never shown the run's range ahead of the press (v2.7272: a range read before the mint's lock could be another session's), and still does not promise it: the fold draws the numbers as the foot line already reads them, and one line says the code comes with the run. The sample code is eight zeros rather than a made-up code that could be mistaken for a sticker's own.
- **Six strips at full size, the rest at half.** Six show the copies order and fit a phone's screen; Show all draws each remaining sticker once, since a copy is the same strip, and stops at 200 with its words. Every strip is one canvas drawn at the printer's dots; 200 draw in well under a second on a desk.
- **The fold is on the ask only.** Once a run is minted the strips themselves are on the page, with their real codes.
