# v2.2319 — Data health drill-down declutter + inline bill dates (2026-08-25)

Owner-approved mockup (round four, https://claude.ai/code/artifact/a19a555f-23c2-4cf8-a5fa-0db41fc8ddb8):
less repeated text, the dates the medians measure surfaced, "unlinked"
retired, and missing bill dates fixable in place.

- **Migration `20260826040000`** (details in `docs/migrations/`):
  `get_pay_speed_transactions` **v4** — each payment row also carries
  `invoiceId`, letting the client split the old "unlinked" bucket and target
  the inline date write.
- **Rows**: date column is now **billed → paid** (the pair the medians use),
  labeled once by a small column header; the sent date moved to the hover
  title. Row headers run two lines — customer · job, full address beneath,
  never truncated. Actions align to the top line.
- **Words**: chips name the actual problem — `no bill` (payment on no bill)
  vs `no bill date` (on a bill missing its date; kernel `missingInfoLabel`,
  fail-soft to `no bill` on pre-v4 payloads). Filter pill: **Missing info**.
  The Pay speeds strip says "payments missing info".
- **Inline bill dates**: `no bill date` rows and every Undated-bills row get
  a dashed "＋ add date" button (dev + master, same gate as Exclude) → an
  MM/DD/YY field that auto-slashes and hugs the typed width (new kernel
  `src/lib/jobs/billDateEntry.ts`: format/parse/width + `billedAtIsoFromYmd`
  pinning 18:00 UTC so the Chicago date matches in CST and CDT). Save
  updates `jobs_ledger_invoices.billed_at` directly (existing RLS) and
  refreshes the list + medians; Enter saves, Esc cancels. No "same as paid"
  shortcut on purpose — fabricated same-day pairs are what quarantine
  distrusts.
- **Panels**: the all-caps headers are gone; unlinked context items carry a
  small italic "job's items — payment isn't on a bill" tag; empty case is a
  right-aligned "No line items recorded." Bill total: own line only with 2+
  items (or a single item ≠ bill amount), label right beside the number;
  single matching item carries the label inline; zero items, no total.
- Tests: `billDateEntry.test.ts`, kernel split-label cases, rewritten render
  suite (inline save asserts the `billed_at` write + refetch).
