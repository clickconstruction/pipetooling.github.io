# v2.2645 — Lien Filing Desk: § 53.056 notice + affidavit + deadline clock (2026-09-02)

Lien Instruments phases 3+4 (mockup: "Lien Filing Desk" artifact; built via the
owner's think → mockup → self-review → revise → build loop). Owner decisions
folded mid-build: notices SEND from the app (email as a courtesy channel beside
the recorded certified mail), and § 31.04 gates on zero payments instead of an
attorney hold.

- **Migration `20260902164655_job_lien_filings.sql`** — one row per instrument:
  kind (notice_53_056 / affidavit / release_of_record), amount, months_covered
  (the 'YYYY-MM' furnishing months a notice attests), fields jsonb snapshot,
  `sends` jsonb (per-recipient {recipient, method, tracking, sent_on} — the
  statute names owner AND original contractor), filed_at/county/
  recording_number, serve_due (partial-indexed watch) /served_at, void-not-
  delete, office RLS + both read-only blocks.
- **Kernels** (13 new tests): `lienFilingDocuments.ts` — the § 53.056(a-2)
  form VERBATIM, the ¶1–¶10 affidavit per § 53.054 (¶9 sworn-notices included
  only when true) with notarial block, the release-of-record naming the
  recorded instrument; one shared block-walker for HTML/text/print/PDF.
  `lienDeadlines.ts` — `statutoryFifteenth` / notice (2nd/3rd mo) / filing
  (3rd/4th mo) / `serveDueForFiling` (5th day) with § 53.003 weekend rolls;
  `computeJobLienClock` (keys on the LAST work month — honest approximation,
  stated in the UI); `assessLienWatch` (notice windows ≤14d on unpaid ≥$500
  sub jobs with no covering notice; filing windows ≤21d once noticed/original;
  serve-by from 3 days out, never dropping until served).
- **`LienFilingTabs`** in the Lien instruments modal: role banner (GC = sub),
  notice with per-recipient record-sends (email method invokes the new
  **`send-lien-filing-email`** edge fn — user-JWT, RLS-gated by job access,
  Resend + PDF attachment — and stores `resend:<id>` as tracking); affidavit
  readiness gate (owner+mailing / county+legal / notice recorded / homestead
  hard-stop with § 53.254 explanation; month-coverage mismatch is a warning);
  Record filing (county/recording#/date → serve_due) and Record service;
  conditional Release-of-record tab prefilled from the filed row; filings
  history with View (snapshot re-render) / two-click Void. Clock in the modal
  header on every tab.
- **Watches**: `useLienWatchNudge` + three Needs You keys — `lien-serve-copy`
  (red, tier 10), `lien-notice-window`, `lien-file-window` (amber, tier 40) —
  on Dashboard and Quickfill.
- **Demand tab**: § 31.04 checkbox enabled only when paymentsReceived = 0
  (owner rule 2026-09-02), with a field clamp so it can never ride a letter
  for a partially-paid job.

Types hand-authored to generator shape, verified against `gen-types:linked`;
edge fn deployed via `supabase functions deploy send-lien-filing-email`.
