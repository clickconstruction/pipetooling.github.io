# v2.2013 — Pricing Workbench: view/★ split, structure bar, solver truth (2026-08-21)

Implements Mockup 1 of the 2026-08-21 Workbench-clarity review (estimator confusion on versions vs scenarios; mockup artifact in the session's arc memory). All in the New (Workbench) pricing view; the Old grid is untouched.

**View/★ split** ([`BidsPricingTab.tsx`](../../src/components/bids/BidsPricingTab.tsx)): scenario cards are now view-only (`viewWorkbenchScenario` — sets `selectedPricingVersionId` + entries, no persist, discards any solver preview). The bid's saved `selected_price_book_version_id` is surfaced as the ★ "Customer sees this" chip; `makeScenarioCustomerFacing` (confirm dialog quoting the revenue) is the only path that persists it. Duplicate views the clone instead of activating it. [`deriveActivePricingId`](../../src/lib/bids/pickActiveVersion.ts) now prefers the saved id among a version's (or an unsplit bid's) several pricings — previously the ★ silently reverted to the first pricing on reload (+2 tests). Entering the Cover Letter tab re-aligns the working pricing to the saved ★ (new effect in [`useBidPricingEngine.ts`](../../src/hooks/useBidPricingEngine.ts)) so viewing never changes what the letter shows.

**Structure bar**: names the active Version ("its own takeoff & counts", falls back to "Current" for unsplit bids) beside "Price scenarios in this version — same counts, different sell prices" with the ★ explanation. Empty scenarios get a "No prices yet" chip + `copyPricesIntoViewedScenario` (computes the source's per-row prices via `computeBidPricingRows`, writes through `writeUnitPriceOverrideRow`).

**Solver surfaces** (the target math itself landed in v2.2011 — both modes treat targets as whole-bid; this PR keeps that semantics and adds a `uncostedFixedRevenue` output + 1 test to [`pricingWorkbenchSolver.ts`](../../src/lib/bids/pricingWorkbenchSolver.ts)): the target input keeps its value, gains a Solve button and a visible "Target $X → previewing $Y" echo (replacing v2.2011's toast); the slider is labeled "Blended margin — whole bid (solver moves the N costed rows)". The margins-overstated warning became a banner inside the solver box with a "Show these N rows" filter (`wbShowNoCostOnly`, mutually exclusive with the unpriced filter). The preview summary strip goes amber-dashed and names the scenario ("Previewing 8 changed prices on Default", "Apply to Default").

New `bidVersions` prop threaded from `Bids.tsx`. Help guide `price-a-bid-with-the-workbench.md` gains the "Versions, scenarios, and the star" section. Verified live on BP298 (★ stayed put across views; target 150,000 → $150,016.77 preview). Client-only — no migration.
