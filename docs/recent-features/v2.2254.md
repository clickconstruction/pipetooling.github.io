# v2.2254 — Pay speeds breakdown restacks on mobile (2026-08-24)

Owner feedback: the v2.2022/v2.2233 modal was unreadable on a phone — the
5-column ROW_GRID compressed and the full-width SVGs scaled their 10px text
to ~5px.

- `PaySpeedsBreakdownModal` now uses `useIsMobile()` (≤640px, reactive):
  - Sheet: `calc(100vw - 0.75rem)` wide, `94vh` tall, tighter padding.
  - Ranked rows: two-line cards — caret + segment tag + name + median, then
    `N pmts · $X open` + the speed bar (flex-filled). Column header hidden.
  - Thin-history rows: one line, `N pmts · $X` right-aligned.
  - Charts (Dot/Bucket): unchanged SVGs inside `overflow-x: auto` at
    `minWidth: 560` — legible size behind sideways swipe (house convention:
    wide content scrolls in its own container).
- Desktop rendering byte-identical; receipts panels already wrapped.
- Render tests: matchMedia stub added to both pay-speed test files (jsdom has
  none) + a narrow-mode restack assertion.
