# v2.4952 — Bids: Past values shows a cell's earlier values under it (2026-10-08)

Punch list #73, PR 3 ([`to-dos/bid-history`](../../to-dos/bid-history/README.md)): the switch on the cells. PR 2 (v2.4948) reads a bid's history in a window; this puts the past where the value is typed. Migration `20261009090000_latest_bid_cell_history.sql` ([doc](../migrations/20261009090000_latest_bid_cell_history.md)); no edge function.

## The change

- **`latest_bid_cell_history`**, SECURITY INVOKER: for the four numbers people type on a bid, each cell's two newest earlier values and its count of changes, keyed the way each tab finds its cell (`price:<count row>:<pricing>`, `count:<count row>`, `takeoff:<line>:<column>`, `labor:<row>:<column>`). Both places a typed price lives (the custom price, and the override on a book pick) are one price history. Each removed row's last value comes keyed by its name, for the label fallback. It reads the ledger only, never the delete archive.
- **The kernel** [`bidCellHistory.ts`](../../src/lib/bids/bidCellHistory.ts): the key builders (they match the SQL), the index, and the words under a cell: *$9,800 · Ann · Tue*, at most two lines, newest first, and *+N more*. A row with no past of its own borrows its name's (*an earlier Lav-1 row · $9,800 · removed Wed*, in italics): a re-import makes new rows with new ids, which is Wendi's case. Takeoff lines have no name fallback, since one part sits on many count rows.
- **The switch** ([`useBidHistoryCells.ts`](../../src/hooks/useBidHistoryCells.ts)): **Past values on/off** beside the History door on every bid tab's title. Off by default, remembered on the device, and one flip turns all four tabs (a window event). `BidCellHistoryProvider` in `Bids.tsx` reads once for the bid on screen while it is on, and again when the window comes back to the front. Off, nothing is read.
- **The lines** ([`BidCellPast.tsx`](../../src/components/bids/BidCellPast.tsx)): under the Workbench price (`BidsPricingTab`), the count (`BidsCountsTab`), the takeoff quantity and unit price (`SortableRoughPartLineRow`) and each stage's hours (`BidsLaborNewView`). A cell with no past draws nothing, so rows keep their height. *+N more* opens the History window searched on the row (`BidHistoryWindow` takes `initialSearch`).
- **Captions**: an Edit Bid action no default column names now reads by the columns it touched (*Edit Bid · active version*), not a bare *Edit Bid*.

## Not in this PR
