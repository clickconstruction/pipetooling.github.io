# v2.3214 — "Bids the map can't place": each row names the bid's stage (Unsent · Pending · Won · Started · Lost) (2026-09-10)

Client only; no migration.

## Why

The sheet (v2.3205) listed 52 bids with only a coloured dot for the Bid Board section each one sits in — the label lived in the dot's tooltip. Deciding whether an address is worth typing depends on that stage: a lost bid from spring does not need a pin, an unsent one due tomorrow does. Grace: "I would like to include the stage the bid is in, such as lost or unsent."

## What shipped

- `BidBoardMissingAddressesModal`: the dot becomes a small uppercase chip in the section's marker colour — dot + word (`UNSENT`, `PENDING`, `WON`, `STARTED`, `LOST`) — at the start of every row, from the same `BID_BOARD_MAP_SECTION_LABEL` / `_COLOR` the legend uses, so the sheet and the map never disagree. Tooltip says what the word is.
- Render test asserts the chip text on the unplaced row; help guide `see-your-bids-on-a-map.md` mentions the stage on each row.
