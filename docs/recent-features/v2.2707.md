# v2.2707 — Counts / Pricing / Cover Letter: the Old views retire (2026-09-03)

Owner call, same shape as v2.1895 (Cover Letter studio), v2.2012 (Pipeline), and v2.2215 (Health): "We have now moved everyone off the old into the new — remove the Old buttons." The **Old / New** pills beside the bid name, their per-device localStorage reads, and every Old branch are removed from the three tabs; the New views render directly on bid selection.

## Client only — no migration, no edge functions

- **Counts** ([`BidsCountsTab.tsx`](../../src/components/bids/BidsCountsTab.tsx)): the `countsView` state / `bids_counts_view_v2` read and both header pill rows go; the classic drag-sortable table (v2.1909's Old) is deleted. The Count Sheet already reorders, edits in place, and exports CSV; the one Old-only door — **Clear all counts** — moves into the sheet's bottom row (grid: spacer · Export as .csv · Clear all), wired to the same `ClearAllCountsModal`. Orphans removed with it: `lastMovedId`, `addingCountRow`, `countsTableRef`, and the now-unreferenced [`CountRow.tsx`](../../src/components/bids/CountRow.tsx) (`SortableCountRow`) and [`NewCountRow.tsx`](../../src/components/bids/NewCountRow.tsx) files.
- **Pricing** ([`BidsPricingTab.tsx`](../../src/components/bids/BidsPricingTab.tsx), 6,550 → ~5,630 lines): the `pricingView` state / `bids_pricing_view_v2` read, the pills, the Old-only **View: Cost Model / Price Model** toggle, and the ~750-line classic grid (price-book `<select>` that cloned a template into a scenario, "Apply Matching Price Book Entries", Margin mode column, per-row 📌 fixed-price / omit-from-submission toggles, unit-cost trigger icon) are deleted. The Workbench's `?` help door is unwrapped from its `pricingView === 'new'` guard; the three Workbench effects (scenario revenue, win/loss history, same-GC alternates) drop their view gates. `viewModel` is pinned to `'price'` for the engine. Orphans removed: `pricingViewModel`, `marginRowMode` + `toggleMarginRowMode` (the `bidPricingMarginMode_v1` key is abandoned in place), `unitPriceEditValues`, `savingPricingAssignment`, `togglePricingAssignmentFixedPrice`, `togglePricingRowOmitFromSubmission`, `MARGIN_FLAG_COLOR`, the `GenerateUnitCostTriggerIcon` import, and the `onNavigateToLabor` / `onNavigateToLaborDirectCosts` props (dropped from the type and from the `Bids.tsx` mount). The Workbench's own price-book drawer (v2.2444), assign search, and fill-from-book cover the retired grid's book workflow.
- **Cover Letter** ([`BidsCoverLetterTab.tsx`](../../src/components/bids/BidsCoverLetterTab.tsx)): Old here was a bundling *mode* (checked price scenarios, one letter each), not a layout. The `coverLetterView` state / `bids_cover_letter_view_v1` key, the pills, and every `=== 'old'` branch go: the plan effect always uses `planLetterSections` / `planUnsplitLetterSections`; `gcPackets` bundles from one priced section; section labels always use `sectionLabel`; same-page alternates and the layout toggle no longer check the view; step 1's Old-only **Versions in this submission** scenario checklist and the Old-only multi-GC packet pill row are deleted with their handlers (`toggleSubmissionInclude`, `reorderSubmission`, `studioPillStyle`). The scenario-flag mirroring in `toggleVersionInclude` stays — Pricing's "On their letter" chips still read it.
- Stale localStorage keys (`bids_counts_view_v2`, `bids_pricing_view_v2`, `bids_cover_letter_view_v1`) are abandoned in place (Cover Letter precedent) — a device that remembered Old just lands on the new view.
