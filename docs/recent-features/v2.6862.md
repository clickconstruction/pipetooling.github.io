# v2.6862 — Box labels: the QR now opens the box on an iPhone (punch list #304) (2026-11-10)

The owner printed the first strip off the Brother PT-D610BT and scanned it. His iPhone's camera opened a Google search for `PRTS.CO/B/B365B514`; pasting the same words into the address bar opened the box. A test image whose QR carried `HTTPS://PRTS.CO/B/B365B514` opened the box from the camera.

## The cause

`boxUrl` has made the QR's text with no scheme since v2.6039, on the belief written beside it that *the phone's camera opens a bare address*. That let the code be a 21-module square. An iPhone's camera reads a bare address in capitals as words and offers a web search. Nobody had scanned a printed label with a camera until this strip; the earlier checks read the box through its address.

## What changed

- **`lib/materials/labels.ts`**: `BOX_LINK_SCHEME`; `boxUrl` is `HTTPS://PRTS.CO/B/<CODE>`, still all capitals so the QR packs it as letters. 26 characters is a version-2, 25-module code. `boxClipboardWords` (Copy the label code) carries the scheme too.
- Everything that draws or exports the code reads `boxUrl`, so the sheet label, the tape strip, the manifest and the CSV's QR column change with it.
- The guide says what an old label does and what to do.
- `scripts/cloudflare/prts-co-redirect.md`, `MATERIALS_ON_SITE_ARCHITECTURE.md` and `EDGE_FUNCTIONS.md` name the new text. The comments in `supabase/functions/_shared/boxPage.ts` and `box-read/index.ts` still name the old text; they are left alone so no function needs a deploy for a comment.

## What it does not fix

**Every label already printed carries the old code.** On an iPhone it opens a search. It needs printing again; until then its eight characters typed into **Scan a label** open the box. Android was not tried.

## Tests

`labels.test.ts` holds the scheme, that the text parses as a web address whose path is `/b/<code>`, and that it and the clipboard words stay inside a 25-module code's 38 characters. `labelsCsv.test.ts` holds the CSV's QR column.

## Walked

The owner's iPhone, 2026-11-10: the old text searched, the new text opened box ZZ1. The new text was read from a test image drawn with the app's QR library, not from the app's own window.
