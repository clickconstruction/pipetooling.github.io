# v2.2072 — Personal statement rounds (2026-08-22)

Owner-approved mockup (revised from the auto-email draft: "the app plans and tracks; a person sends"). Every GC ≥ $10,000 outstanding joins a weekly round assigned to a sender; each GC releases only once certified this week (`gc_review_certifications`); the sender emails from their own inbox and marks **Sent it**. Nothing auto-emails.

**DB** (migration `20260822013000_gc_statement_rounds.sql`, applied via db push while this PR merged): `customers.statement_sender_user_id` (standing sender; NULL = derive from the GC's jobs' Account Man) + **`gc_statement_round_marks`** (one `sent`/`skipped` row per week+GC, unique, upsertable; office RLS mirroring `gc_review_certifications`; both read-only sweeps). Types regenerated.

**Kernel** ([`gcStatementRounds.ts`](../../src/lib/jobs/gcStatementRounds.ts), 6 tests): `GC_ROUND_THRESHOLD` ($10k, constant for v1), `buildStatementRound` (state ladder: mark > certify-gate — changed-since-certified re-holds > sender > ready), `summarizeStatementRound` (held totals, current user's queue, per-sender progress), `deriveGcAccountMen` (mode per GC), `mergeMarksIntoLastSent` (personal sends count like app sends). IO in [`gcStatementRoundIo.ts`](../../src/lib/gcStatementRoundIo.ts) (fail-soft reads, upsert/delete mark, sender assignment).

**GC Review** ([`JobsGcReviewModal.tsx`](../../src/components/jobs/JobsGcReviewModal.tsx)): a **Weekly statement rounds** panel (GC-grouped regardless of the Group-by pill) — per-sender progress header, chip ladder (*certify to release → in X's round → sent ✓ day by name / skipped*), inline **assign** (writes the standing sender), click a sent/skipped chip to **undo**. **Start round** opens the one-at-a-time overlay: group stats + cert stamp, recipient, last-sent, Preview / Copy for email (existing builders), **Sent it ✓** / Skip. Personal marks merge into the last-sent pills and the week-progress strip.

**Pipeline cards** ([`PipelineOverview.tsx`](../../src/components/jobs/PipelineOverview.tsx) + [`JobsStagesTab.tsx`](../../src/components/jobs/JobsStagesTab.tsx)): 🔏 *N statement rounds wait on sign-off — $X* (amber, certifier roles, opens GC Review) and 📬 *Your statement round — N GCs, $X* (blue, opens GC Review straight into the round overlay via `startInRound`). First-paint data rides the **lean stats spine** — `LEAN_STATS_JOB_COLUMNS` gains `gc_customer_id` and lean rows carry an id-only `gcCustomer` stub — then refines when full billed rows merge (same lean-first pattern as the chase card).
