# v2.2373 — Workbench: typed prices save on blur; preview stash goes localStorage (2026-08-26)

Estimator feedback (Wendi, day-of follow-up to v2.2354): "having to apply every
price I change… and it does not actually 'wait here if you leave' like
promised." Both halves verified live:

1. Hand-typed prices went through the same preview→Apply gate as solver
   results — the Old view has always written typed prices straight to the bid
   on blur, so the Workbench added an Apply click per edit with no extra
   safety.
2. v2.2354's stash was sessionStorage — survives navigation and reloads, but
   dies with the tab. Closing the laptop for the day or opening the bid in a
   second tab is exactly the "leave" an estimator means.

Changes:

- **Typed prices save themselves** (`BidsPricingTab`): the Workbench sale-price
  input keeps a raw draft while focused (`wbPriceDrafts` — live totals still
  recompute from the draft), then Enter/blur commits via the existing
  `writeUnitPriceOverrideRow` + `loadBidPricingAssignments` (the same write
  Apply uses). Empty/invalid/≤0 or unchanged input reverts silently; Escape
  reverts. A brief green **saved ✓** tag replaces the amber preview treatment;
  `savingUnitPriceOverride` disables the field mid-write. A typed save also
  removes that row from any pending solver preview so a later Apply can't
  overwrite it.
- **Preview stash → localStorage** (`workbenchPreviewStash.ts`): key bumped to
  `bids_wb_preview_v2:<pricingVersionId>`, payload now
  `{ prices, at }` (written-at epoch ms). v1 sessionStorage keys are ignored
  and age out with their tabs. `readPreviewStash` returns the envelope;
  `writePreviewStash` takes `at` explicitly (kernel stays clock-free for
  tests).
- **Restored-age chip**: when the restore effect brings back a stash older
  than an hour, the strip shows *solve from Tue 4:12 PM — restored*
  (`formatRestoredStamp`; date form after 6 days). A fresh Solve clears it.
- **Copy**: strip caption is now "N solver price(s) previewed — saved only
  when you Apply · waits on this device"; the preview tag tooltip, (i) modal
  "Previews & saving" section, Workbench tour step, and the help guide
  (`price-a-bid-with-the-workbench.md`) all tell the same story — typed saves
  instantly, solver previews wait on this device.

Tests: `workbenchPreviewStash.test.ts` reworked for the v2 envelope (missing
`at` tolerated as 0, v1 shape unreadable, non-finite prices dropped, throwing
storage swallowed).
