# v2.4520 — Pipeline: the Lien desk is one click away on the stage bar (2026-10-04)

Client only; no migration, no edge function. The owner's ask: an icon just right of Collections on the stage bar that opens the Lien desk, with the desk's row left in the ☰ menu. Four icons were offered (stopwatch, gavel, sealed notice, scales); the owner picked the gavel.

## What changed

- **The shortcut.** `StagesLienDeskShortcut` in [`JobsStagesJumpStrip.tsx`](../../src/components/jobs/JobsStagesJumpStrip.tsx): a 2 rem button with the orange gavel and, while `lienDeskCount > 0`, the amber count badge the menu row carries. It calls the same `setLienDesk({ jobId: null })` as the menu's *Lien desk* row and the Collections header's button. [`JobsStagesTab.tsx`](../../src/components/jobs/JobsStagesTab.tsx) hands it in only for `lienDeskEligible` roles (`isStagesOfficeRole`), the roles the desk's data already loads for.
- **Where it sits.** The bar takes a new `tail` slot. With a tail, the last stage and the tail share that stage's place in the bar (`.stagesStageSegTail`), centered together, so the gavel hugs Collections. While Collections has no rows and is not drawn, it rides beside Billed Awaiting Payment.
- **One gavel.** The row's Lien window button drew the gavel inline; it is now `StagesGavelGlyph` in [`StagesRowActionButtons.tsx`](../../src/components/jobs/StagesRowActionButtons.tsx), drawn by both. Same path, same orange.
- The ☰ menu's *Lien desk* row, the Collections header's button and the money card are untouched.

## Tests
