# v2.2267 — Drag tasks between stages on the Map (2026-08-25)

Cross-stage drag-and-drop in the Map's task-edit (reorder) mode. The kernel
already supported cross-group row drops (`computeTaskReorderUpdates` writes
`group_id` + `sort_index`); this ships the missing UI half. UI-only — no
migration.

## Kernel (`src/lib/techTreeTaskOrder.ts`)

- New whole-box droppable id family: `techTreeGroupDropId(groupId)`
  (`__group__<gid>`) + `is`/`from` helpers, alongside the existing
  `__empty__` ids.
- `computeTaskReorderUpdates` handles a group-drop over id: append to the end
  of the target stage; dropping on the task's own box moves it to the end.
  Tests cover cross-group append, own-group to-end, unknown-task no-op.

## Map UI

- Gear reposition (polish on v2.2266): the stage-settings ⚙ moved out of the
  right-edge button stack (which overflowed short/collapsed cards) into the
  badge row, bottom-left — 20 px inline button rendered for editors; the
  badge row now renders whenever the viewer can edit.

- `ChecklistTechTreeGroupNode`: the whole node is a `useDroppable` box in
  reorder mode. Blue ring (`box-shadow`) while it is the drop target (row or
  box); dashed end slot "Move here — becomes N.M" when a *foreign* task
  hovers the box itself — works on collapsed boxes too. Dragged source row
  ghosts to 35%.
- `ChecklistTechTreeTab`: `DragOverlay` (portal, z 10035) carries the row —
  grip + number chip + title, slight tilt — so it no longer slides underneath
  neighboring nodes mid-drag. New custom `CollisionDetection`:
  `pointerWithin`, rows win over boxes; a gap between rows inside the *own*
  stage snaps to the nearest row (no "move to end" flash); empty canvas
  returns no target, so releasing there is a no-op (previously
  `closestCenter` could snap a canvas drop to the nearest faraway row).
- Order-stages modal keeps its own isolated `DndContext` — unaffected.

Semantics on arrival: assignees/notes/history ride along; numbers renumber on
both sides; the target stage's in-order/parallel rule re-applies via the
normal sync (a task landing mid-chain in a sequential stage returns to
⏳ Coming up).

Live-verified on prod (throwaway TEST DRAG A/B stages): box-drop moved a task
to the other stage's end (renumbered, waiting label re-applied), row-drop
inserted at the exact spot on the way back, Escape canceled a held drag,
mid-drag frame showed overlay + ring + end slot; stages deleted after, zero
orphan rows.
