# v2.2360 — Bid Board jump icons for every workflow tab (2026-08-26)

Estimator request (Wendi): only Counts had a one-click jump from the board;
Takeoffs / Labor / Pricing / Cover Letter meant opening the bid, then the tab.

- `BidsBidBoardTab.tsx` — `renderBidBoardBidNumberCluster` now renders five
  jump icons in tab-strip order (Counts cube, Takeoffs ruler, Labor hard hat,
  Pricing tag, Cover Letter envelope; new 640-viewbox paths in
  `BID_BOARD_ICON_PATHS`, list in `BID_BOARD_JUMP_TABS`). Same affordance as
  the old Counts button: muted gray, blue on hover, `title` tooltip, 18px.
  Desktop table rows and phone cards share the cluster, so both get all five.
- Prop change: `onOpenCounts(bid)` → `onOpenBidTab(bid, tab)` with
  `BidBoardJumpTabKey = 'counts' | 'takeoffs' | 'labor' | 'pricing' |
  'cover-letter'`; `Bids.tsx` wires it to the existing
  `selectBidAndSyncUrl(bid, tab)`.
- New `canSeePricingTabs` prop (false for superintendents) hides the Pricing
  and Cover Letter jumps for roles whose tab strip hides those tabs — the
  URL-effect guard would have bounced them anyway; now the icons don't tease.
- RFI / Change Order / Lien Release deliberately stay off the board.
- Help guide `read-the-bid-board.md` "Read a row" updated.
