# v2.4569 — Bill Customer: View shows a signed lien release with its signature (2026-10-05)

Client only; no migration, no edge function. Row 24 of the lien defects card (punch list #83, [`to-dos/lien-defects.md`](../../to-dos/lien-defects.md)). Stacked on v2.4564 (the same file).

## The defect

[`BillCustomerLienReleaseStrip.tsx`](../../src/components/jobs/BillCustomerLienReleaseStrip.tsx) rebuilt the page for **View** from its own copy of the snapshot mapping and passed no signature, so a signed release opened unsigned here and signed everywhere else (the Release of Lien window, the Dashboard queue, Documents). Its **Void** wrote `voided_at` alone; the Release of Lien window also writes `voided_by`.

## The fix

- **View** uses the shared mapping (`lienReleaseSnapshotToWaiverFields`) and the ink stored at signing (`lienReleaseRowSignatureWithInk`), opened through `openHtmlWindowWhenReady` because the ink is read first.
- **Void** writes `voided_by` with the signed-in user.

## Tests

`BillCustomerLienReleaseStrip.render.test.tsx` (2, new): View asks for the row's signature and draws the page with it; Void's update carries `voided_by`.
