# v2.7528 — Liens: one scan of a whole stack is split into a PDF for each lien (2026-11-16)

Punch list #366, the second half of several scans at once. v2.7524 took many files, one a lien. The owner's steer of 2026-11-16 had a second clause: "if they are all for one person a user may scan a whole stack". Client only: no migration, no edge function.

## What changed

- **The office says it is a stack, never the app.** A picked PDF's pages are counted (`lienScanPageCount`). One with more than one page gets a line, *This file has 12 pages.*, and the press *It holds several liens: split it ›*. Until then it is one file for one lien, as before, since one lien's affidavit can run to two sheets.
- **`src/lib/jobs/lienScanStack.ts`** (new, pure). Each page has a rule: in order, a lien by hand, *Same lien as the page before*, or *Not an affidavit*. `lienScanStackResolve` applies them top to bottom: a page in order takes the next lien nobody has, so marking page 2 as a receipt moves the pages after it up by one; a lien picked by hand anywhere in the stack, or held by another file in the window, is stepped over; a receipt between two sheets does not break a run. `lienScanStackPieces` hands the plan of v2.7524 one piece for each lien that gets pages, and one for each page left with no lien, which the plan holds.
- **`lienScanStackIo.ts`** (new): `cutLienScanPages` cuts one lien's pages into a PDF of their own with `pdf-lib`, in the browser, when its turn comes in the save. The stack itself is never uploaded, so the folder's 10 MB limit is each lien's piece and never the stack's. `saveLienScans` now takes a file or a function that makes one, and checks the true size once the piece is cut.
- **`LienScanBatchWindow.tsx`**: a split stack draws a tile a page, with its picture (`PdfPageCanvas`, the Form Studio's), a list for its rule, and the lien it goes to with that lien's recording number in bold, to read against the clerk's stamp. A picture opens that page full size. *Keep it as one file* undoes the split.
- **After a save where one lien fails**, the stack is frozen as it stood for that press: saved pages read *Saved* and go nowhere again, and every other page keeps the lien it had, by hand. Without that, the liens that just got their scan leave the list and the in-order pages behind them would slide onto other liens.
