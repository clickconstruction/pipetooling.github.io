# v2.2697 — Bid room signal hygiene: the auto-Lost is named, the telemetry is throttled (2026-09-03)

Two findings from the owner's "did we make any mistakes?" review of the Bid Room and
Estimate Options trains.

**The auto-Lost blast radius was silent.** When a GC signs, the outcome kernel also marks
the bid's other sent, unanswered packets Lost (the staff-kernel rule, owner decision 2). The
staff email said only *"Packet marked Won."* — an external party's click had just flipped
other GCs' outcomes and nobody was told which. Now: `sign-bid-room` resolves the auto-lost
packets' GC names (null `customer_id` = the bid's own GC via `bids.customer_id`), writes them
into the `signed` room event (`metadata.auto_lost_gcs`, plus `bid_outcome_set`), and the
email appends *"Also marked Lost — sent, unanswered: PlanHub, MERIT. (Open the bid to
change any of these.)"*

**Two public write endpoints had no throttle.** `log-estimate-option-view` and the room's
POST (`option_viewed`) are deliberately best-effort — always 200 — which also let anyone
holding a link insert without bound (a replaying mail scanner, a forwarded link, a stuck
tab) and litter the activity feed the office reads. New `_shared/publicEventThrottle.ts`
(+5 tests on the pure decision): the identical event (subject, option, IP) inside 30 s is a
duplicate; more than 60 events from one IP on one subject in 10 min is a loop. Both drop
silently, still 200. Sized so a human can't trip it — 4 options re-tapped every 30 s for
seven straight minutes would — and a loop trips it in seconds. A failed count records
rather than blocks. Also closed: the room POST accepted any `optionKey` string; it now
validates against the room's current revision like the estimate endpoint always did.

Not changed here, flagged in the same review: room `room_view` GETs have no scanner
protection (mail-security pre-fetches will show as "opened") and the room token is stored
plaintext where estimates hash theirs — both worth their own decisions.

**Deploy after merge**: `supabase functions deploy sign-bid-room get-bid-proposal-room
log-estimate-option-view`.
