# v2.4588 — Lien desk: three views instead of six tabs (2026-10-05)

Client only; no migration, no edge function. PR 5 of 5 for punch list #82 ([`to-dos/lien-desk-next-up/`](../../to-dos/lien-desk-next-up/README.md)), built on the owner's yes of 2026-10-05. Stacked on PR 4.

## What changed

- **The header's row is three views**: *Next up · N*, *Calendar*, *All paper · N* (the notices, affidavits and retainage notices not yet sent or filed). Before, it was six tabs in one row.
- **All paper carries a second row**: *Notices · Affidavits · Retainage · Timeline*, with the counts and hints the tabs had. Each opens the list, pane and footers it always did. All paper reopens on the list last used there (`lastPaperKind`).
- **Nothing underneath moved.** `kind` in [`LienDeskModal.tsx`](../../src/components/jobs/LienDeskModal.tsx) keeps its six values, so the bodies, the pile filters, the run button, the doors and the deep links are untouched. `kind=affidavit` and `kind=timeline` land on their lists with All paper lit; a Next up row's button does the same.
