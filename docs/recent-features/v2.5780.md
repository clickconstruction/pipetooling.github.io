## Is this the best we can do?

1. **The same control, the same memory**: no new toggle; the desk joins the Lien desk, Put a GC on notice and Accounts Receivable on the one hook, so a fix there is a fix here.
2. **Two failures, two lines**: the old line was true for one of them and a lie for the other. The desk now says which, and the one that can be fixed by waiting fixes itself.
3. **Retries that stop**: three, spaced out, then the office's own press — a desk that cannot read never hammers the gateway.
4. **Cut**: a per-user full-screen preference (every other modal keeps it per browser; the desk is no different), a toast on each retry (the line already says it), and a retry for the *missing* state (the migration is not applied; retrying cannot change that).
