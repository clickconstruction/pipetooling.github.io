# v2.1966 — Money moves card grid (2026-08-21)

The Today's Money Opportunities rows spanned the full page width on desktop,
leaving a desert of empty space between each claim and its action button.
They now render as a responsive card grid inside the same bordered container:
`repeat(auto-fit, minmax(min(300px, 100%), 1fr))` — the story cards' auto-fit
pattern, with the `min(300px, 100%)` guard against ultra-narrow overflow.

- Each move is a mini-card: icon + claim, muted why (flex:1 so buttons align
  across a row), pill action bottom-right. `chase-90` keeps its red tint plus
  a story-card-style red left edge.
- Measured at all viewports: 1680px → 4 across · 1280px → 3 + 1 wrapped ·
  768px → 2×2 · 375px → single column, no horizontal overflow anywhere.
- The v2.1961 Fix-ups strip stays as the card's full-width footer beneath the
  grid; empty-queue and header states unchanged.
