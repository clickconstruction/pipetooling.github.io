# v2.7938 — Documents: the Contract library opens from the Agreements tab (2026-11-19)

Punch list #376, the second train, PR 3 of three: the Contract library from the tab. With this the train is whole. No migration and no edge function change.

## What is new

- **Contract library**, a quiet press beside **Send a paper** (`src/components/documents/AgreementsContractLibrary.tsx`). It mounts `ContractLibraryModal`, the window People → Contracts opens, in place. The Search tab does not carry it.
- **Send to…** on a paper in the library starts **Send a paper** at the person step for that paper (`startOn`). The library stays open under the picker, as on People.
- **The paper step points at it.** The line under the papers, and the empty Book's press, open the library in place. They used to send the reader to People.
- The library is read when the door opens and again after each save, so the window shows what it just changed. The list reads again too.
