# v2.4571 — Put a GC on notice: the leader approves what the office wrote (2026-10-05)

Client only; no migration, no edge function. Rows 3, 12, 17 and 21 of the lien defects card (punch list #83, [`to-dos/lien-defects.md`](../../to-dos/lien-defects.md)): the four in [`GcOnNoticeModal.tsx`](../../src/components/jobs/GcOnNoticeModal.tsx). Stacked on v2.4558 (the same file).

## Row 3 — the office's edits were overwritten

**Send all N to the leader** saves a draft per ready job with the letter, the reason and the note as the office set them, and submits it. A job awaiting approval still reads as *ready* (`readinessOf`), so the leader's **Approve all** runs the same loop over it: `saveLienDeskDraft` with the item's id, from his window's state. That state was seeded from `defaultGcNoticeCoverLetter` and the first reason every time the data landed, never from the saved drafts. So his approval wrote the standard letter and *GC is not paying its subs* over what the office had sent him, and what he read before approving was not what the office wrote.

The fix is in the seed, so what he sees is what is saved:

- [`gcOnNotice.ts`](../../src/lib/jobs/gcOnNotice.ts): `parseGcNoticeBatchReason` reads a stored reason back into the reason and the note; `gcNoticeSavedRun(jobs, kindOf)` reads the drafts **awaiting approval** that carry a batch reason and returns the reason, the note, each property kind's letter as saved, and whether a letter was included.
- The window's seed effect lays that over the defaults. A kind with no saved letter keeps counsel's default; a reason in older wording keeps the default reason.

Not recovered: the four ticks. They are applied at approval and never stored, so the leader's window still opens with all four on. The *GC is not answering* tick is not stored either; a run sent with it saves that letter on every job, so each kind's letter comes back as that text.

## Rows 12, 17, 21

- **Row 12.** *Bill the finished work first ›* on an unbilled job was drawn only when the host passed `onOpenCapableList`, and no host did. It now opens that job on its Bill tab through the door the window already has (`onOpenEditJob(jobId, 'bill')`); the unused prop is gone.
- **Row 17.** The scroll spy tracked four step keys of five, so *The grid* never lit. `STEP_KEYS` has all five; the grid is the last section, so the bottom of the scroll is it.
- **Row 21.** The box read *Also change, when the run is recorded*. The standing rule, the terms, the Legal desk matter and the owners' bills change in `approveAll`, at approval. The label says *when the notices are approved*.
