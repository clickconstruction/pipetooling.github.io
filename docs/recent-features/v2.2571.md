# v2.2571 — Dashboard AR modal: Customers view (2026-09-01)

Owner-approved mockup Variant A (https://claude.ai/code/artifact/881b39ae-3777-4377-af49-bbd685704ccb):
the AR drill-down regrouped by the customer you'd call, judged against their own
pay speed instead of a flat aging clock. PR B (call sheet: chase pills + call
card) follows on the same view's `rowBadge`/`expansionFooter` slots.

- **Kernel `src/lib/arCustomerRollup.ts`** (unit-tested): groups the AR bucket's
  own `FinancialItem`s by `customerId` — totals can never disagree with the card —
  and mirrors `moneyWaiting.ts` semantics: baseline = own 12-mo median at
  `PAY_SPEED_MIN_SAMPLES`, else company; `billWaitTone` per bill; past-pace when
  the oldest bill exceeds the baseline. Degrades without pay-speed data
  (`hasPace: false` → no lens, neutral tones, biggest-first).
- **`DashboardArCustomersView.tsx`**: Money-waiting visual language (per-bill
  tone bar, "169d waiting · usually ~35d", Res/Comm tag, `CustomerPortalGlobeButton`),
  Slowest-first/Biggest sorts, pace-lens filter chips, on-pace group row,
  Collections group at the bottom, bills expansion reusing the Bills view's
  address + line-items markup (line items open by default). `rowBadge` /
  `expansionFooter` props are PR-B extension slots.
- **`ItemsModal` (DashboardFinancialsSection)**: AR-only Customers|Bills toggle
  (default Customers) in both the desktop dialog and the phone sheet; fail-soft
  `get_billed_customer_pay_speeds` fetch on open; header count becomes
  "N customers · M bills"; Bills view unchanged.
- **Data**: `FinancialItem`/`FinancialJobRow` gain `customerId`/`customerName`;
  the financials jobs fetch selects `customer_id, customer_name`. No schema or
  RPC changes.
- Help guide `drill-into-the-dashboard-money-cards.md` gains the Customers-view
  section.
