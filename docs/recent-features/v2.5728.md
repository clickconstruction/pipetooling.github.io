# v2.5728 — Messages: the walk kit is quiet to people (2026-10-22)

Punch list #142 (the walk kit) PR 6, README decision 6: a reply on ZZ Walk would otherwise push the whole office, the assign rule could hand the thread to a real person, and the 9 AM morning run could nudge it. While `walk_kit_v1` names a contact, three things leave it alone. Nothing changes while no kit is set up.

- **The push** (`src/lib/messages/notifyPlan.ts`, mirrored): `NotifyPlanInput` gains `kit` (the kit's contact) and `devs` (the real dev accounts). A line in on the kit's contact makes one `message_reply` to the devs, due at the line, never dropped for an answer: never the holder, never the office's wait push, never the after-hours push. The sent record still holds it to one push per line, and the thirty-minute late rule still applies. `_shared/messagesReplyPush.ts` reads the kit once per run (`_shared/walkKit.ts`, PR 1's loader) and passes the devs from the users it already reads.
- **The assign rule** (`src/lib/followUp/assignSeats.ts` `whoGetsIt`, mirrored): a `walkKit` flag answers nobody before the seats, so a test thread is never handed to a person. The client's New lane does not read the kit; the flag is for the server's reads and for any later caller that knows the kit.
- **The morning run** (`src/lib/flows/nudgeRunInputs.ts` `nudgeRunReads`, mirrored, and `messages-nudge-dispatch`): `walkKitContactId` leaves that contact out of everyone's flow entirely, not even as unread, and the office's morning texts on it are not sent. The run reads the kit once per run. Customers are not in the run yet (their page cannot be read as the service role), so today this holds for the day they join.
- **Tests**: `notifyPlan.test.ts` (the devs alone at once, after hours too, nothing with no dev or twice or late, nobody else's line changes), `assignSeats.test.ts` and `assignRule.test.ts` (nobody for the kit), `nudgeRunInputs.test.ts` (left out, not unread; read as any other with no kit).
- **Docs**: `EDGE_FUNCTIONS.md` § messages-notify and § messages-nudge-dispatch; `MESSAGES_ARCHITECTURE.md` (push, the rule, the morning run). The edge copy regenerated (`npm run gen:edge-kernels`).
