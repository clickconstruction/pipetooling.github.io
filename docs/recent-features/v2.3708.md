# v2.3708 — Punch list: every row has a number (2026-09-22)

The owner, after the 2026-09-21 sweep of the board: *"in the Punchlist give every item a number I can reference going forward … I would like this to look like a column."* Client only, no migration.

## What was wrong

A row on the Punch list (`/punch-list`) could only be named by its title or its slug — a sentence in a note, a folder name in a request. Nothing short and stable pointed at one item, and the 2026-09-21 sweep's hand-off notes were already reaching for one.

## The change

- **`number:` in every to-do's front matter** — a required field beside `name:`. Given once, when the to-do is written, from the next free number; never reused, so a retired to-do's number retires with it and "#16" always means the same work. The 29 to-dos on main were numbered in the order their files first appeared on main (#1 `crew-pnl-and-wheels` … #29 `people-spine-residuals`); the next to-do takes #30.
- **The kernel** ([`todoBoard.ts`](../../src/lib/todos/todoBoard.ts)): `TodoMeta.number` / `BoardItem.number`; `readTodoDoc` refuses a missing number or one that is not a whole number from 1 up; `findTodoProblems` gains `duplicate_number` (an error that names both files and the next free number); `nextTodoNumber`; `renderFrontMatter` writes the field after `name`.
- **`npm run check:todos`** ends its OK line with *Next free number: #N* — what a new to-do takes.
- **The page** ([`PunchList.tsx`](../../src/pages/PunchList.tsx)): a number column between the group stripe and the row — `#16` in bold mono, a link to the row's own anchor (`/punch-list#n16`); `data-number` on the row; the footer says what the number is for. On a phone the column stays beside the stacked row.
- Docs: [`to-dos/README.md`](../../to-dos/README.md) (the front-matter block, the Add step), the guide *work the punch list of unfinished projects*, `PROJECT_DOCUMENTATION.md`'s route line. Also in this PR: `person-identity-phase-e.md` stops pointing at the retired `people-spine/` folder (its PR 4 was already in place since July, v2.3702).

## Verified

- `src/lib/todos` tests (the number round-trips, the four bad shapes are refused, the duplicate finding names both files and #17, `nextTodoNumber`), `releaseNotes`, `helpGuideContent`; `npm run typecheck`; eslint on the touched files; `npm run check:todos` (29 to-dos, next free #30).
- Live on the worktree's dev server: the column renders on every group, `#n16` scrolls to Put a GC on notice, the phone layout keeps the number beside the stripe.

## Next
