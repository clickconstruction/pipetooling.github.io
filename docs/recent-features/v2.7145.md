# v2.7145 — Bills sent: a record made by hand keeps the words it was made with (punch list #340, PR 1) (2026-11-13)

Punch list #340, PR 1. The owner picked Option B (the chips) for letting the office add to and edit the list under *How the bill went*. Before the list can change, a record has to stop depending on it. Until now a by-hand record kept a code for its way (`handed`, `mailed`, …) and the screen looked the words up each time it drew, so a way renamed or taken off the list would have reworded every older line.

## What changed

- **The kernel** (`src/lib/billing/billsSent.ts`, 43 tests in all):
  - `byHandFiling` writes the words of the way picked into `source_snapshot.how_label`, beside the code in `how`.
  - `byHandWordsOf(copy)` is the one reader: the record's own `how_label` first, then the list's words for its code (every record made before this release), then *Recorded by hand*. `billsSentLines` takes a by-hand line's `routeWords` from it, so the pill on the line, the search, the bill's record and its print, **Print** and the CSV all follow.
  - A code on no list reads its kept words. Before, it read *Recorded by hand*.
- **The docs**: `docs/SENT_COPIES.md` and the glossary's *Recorded by hand* say the words are kept. Card #340 records the pick and this step.

## Not changed

- No table, policy, function or migration: `source_snapshot` is checked only for being an object.
- The four ways, the form and every line on the screen read as they did. A record made before this release has no `how_label` and reads the list's words for its code, as before.
- The column `how` still gets `hand`, `mail` or `email`. The value `other` for a way the office types arrives with the list's own table, in PR 2, in the same release as the check that allows it.
