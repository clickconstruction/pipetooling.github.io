# v2.2049 — Timeline: titles extend to their bar + numbers on every bar (2026-08-21)

Owner's red-pencil iteration on the v2.2042 waterfall: task titles were
truncating at the 200px rail while the lane sat empty, and bars were
anonymous rectangles.

- **Title-to-bar extension**: in expanded stages the rail keeps just the task
  number; the title becomes a lane-anchored button reaching *backwards* into
  the rail via `calc(64px - var(--roadmap-timeline-rail-w))`, width-capped at
  `calc(var(--roadmap-timeline-rail-w) - 64px + pct(slot.left - gap))` — so
  every row's title starts at the same x and can never collide with its own
  bar. First-slot tasks keep today's rail room (~136px); later tasks gain a
  slot's worth per step (verified live: 136 → 208 → … → 506px on Drill a
  well). Long titles ellipsize at their bar. Assignees moved from the rail
  into a gray flex-none suffix on the title.
- **`--roadmap-timeline-rail-w`** (index.css): the rail's 200px / 52px-mobile
  width became a CSS variable so the overlay's calc tracks both breakpoints;
  the `.roadmap-timeline-rail` rule now reads it.
- **Numbers on bars**: waterfall bars render their task number centered
  (done bars keep ✓); the stage's segmented-bar slots render the number when
  the slot is ≥ 3.5% of the lane (narrow slots keep the hover tooltip only,
  never clipped digits).

No geometry, projection, or interaction changes otherwise; both the title
and the bar still open the task card.
