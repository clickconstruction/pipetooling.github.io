# v2.2957 — Help-guide audit: six categories instead of fourteen, and two button labels that had drifted (2026-09-06)

Third audit of the Plan B series (RLS coverage v2.2954, docs drift v2.2956). Client content + one test; no migration, no edge function.

## What was checked

A checker over all 239 guides in `src/content/help/`: every `(?g=slug)` cross-link resolves, every `{{gif:…}}` file exists in `public/help/`, every `{{icon:…}}` name is known, every `roles:` value is a real role (or `all`), every `` `/route` `` mention is a mounted route, and every `{{button|…}}` / `{{chip|…}}` label was searched for in `src/`. The four guides untouched since July were re-read against their components.

## What was wrong, now fixed

- **Fourteen category strings for six categories.** The Guides browser groups by the literal `category:` value, A–Z, so "Field" sat beside "Field Work", "Jobs" and "Scheduling" beside "Jobs & Scheduling", "Bids" beside "Bids & Estimating", "Money" and lowercase "banking" beside "Billing & Money", and "Settings" / lowercase "people" stood alone — 13 guides in eight stray sections. All 13 now carry the canonical category, and `helpGuideContent.test.ts` exports `HELP_GUIDE_CATEGORIES` and fails CI on any other value (add a category there deliberately, never by typo).
- **`clear-the-hours-approvals-backlog`** showed a green "Approve everything · 120 · 622h" button; the queue modal's button reads "Approve all 120 · 622h".
- **`ready-to-bill-pipeline`** named a "Send Stripe invoice" button; the Bill Customer modal's button is "Create Stripe invoice".

## Found sound

- 0 broken cross-links, 0 missing recordings, 0 unknown icons or roles, 0 unmounted routes.
- The 112 guides whose chip / button labels do not appear verbatim in `src/` are all sample data by design (names, dates, dollar amounts, counts in the mock UI); the stricter pass reduced them to template labels that exist in code with interpolation ("View all {n} in Pipeline →", "Show all {n} pages →", "Split into {n} bills").
- The four July guides (`dark-mode`, `email-reports-to-people`, `find-assemblies-that-include-a-part`, `find-duplicate-customers`) still match their surfaces — "Auto (dark 8pm–4am)", "Report email recipients", "In N assemblies" / "Add as bundle", "Show similar" all present.

## Verify

Settings → Guides (or `/help`): the left rail shows exactly six sections — Getting Started, Office, Billing & Money, Bids & Estimating, Jobs & Scheduling, Field Work — and a sub sees "Field Work" guides that used to sit under "Field". `npx vitest run src/lib/helpGuideContent.test.ts` passes; change any guide's category to "Field" and it fails naming the guide.
