# v2.2379 — Workbench ghost previews, per-row veto, and solving money cells (2026-08-27)

Owner request, prototyped and approved as an interactive artifact before
building (same session as v2.2377). Three changes to the Pricing Workbench
(`src/components/bids/BidsPricingTab.tsx`):

## Ghost previews (replaces the in-place amber preview)

- A solve no longer writes its result INTO the price input. Each proposal
  renders as a purple `$X →` button LEFT of the input; the input keeps the
  saved price (struck through while a live proposal covers it) and only
  changes on Apply. The amber "preview" tag and amber input styling are
  gone; the summary card outline went amber → purple.
- Row Revenue/Profit/Margin cells stay on the SAVED price during a preview
  (prototype-approved semantics); the strip totals (`effUnit`) still read
  the pending solve, minus clicked-off rows.

## Per-row veto

- Clicking a ghost toggles `wbPreviewVeto` (functional update — rapid
  clicks on different ghosts can't lose one): red ✕ state, excluded from
  `applyWorkbenchPreview`, excluded from eff totals, counted out of the
  `Apply N` button (disabled at 0 with an explanatory title), and noted in
  the strip ("N clicked off — their prices hold").
- Vetoes persist across re-solves and stash with the preview:
  `workbenchPreviewStash` payload gained an optional `vetoed: string[]`
  (backward compatible — pre-v2.2379 stashes read as no vetoes; vetoes for
  rows the preview no longer covers are dropped on read/write).
- Typing a price on a previewed row still saves immediately and now clears
  that row's veto along with its preview entry. `commitWorkbenchTypedPrice`'s
  no-change baseline is the SAVED price now (the field no longer shows the
  preview).

## Revenue / Profit / Margin as inputs

- New kernel `src/lib/bids/workbenchCellSolve.ts` (unit-tested):
  `impliedUnitPrice(field, raw, count, rowCost)` — revenue ÷ count,
  (cost + profit) ÷ count, cost ÷ (1 − margin) ÷ count, margin capped
  below 95%, cents-rounded; `cellEditSeed` opens the editor with the
  cell's current number.
- Each keystroke converts to a unit price in `wbPriceDrafts`, so the price
  cell and live totals follow for free; Enter/blur commits through the
  existing `commitWorkbenchTypedPrice` save path (same *saved ✓* tag);
  Esc abandons. Profit/Margin cells render only on costed rows.
- All four money cells share one quiet style (`wbCellStyle`): dashed
  underline, transparent background — the price input's lone box is gone.

Verified live on the dev server against a real bid (SAISD — 50 costed
rows): solve → 50 ghosts, veto/restore/re-solve persistence, stash
restore across reload, margin-cell live solving, Esc leaving zero network
writes, Discard clearing everything.

Help guide updated: `src/content/help/price-a-bid-with-the-workbench.md`
(preview section rewritten, veto + editable-cells sections added).
