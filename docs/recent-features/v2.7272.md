## The picks

- **The numbers are given when the run is minted, not shown before.** The card's press reads *Print 200 sets, 0101 to 0300*, but the sequence is read only by the mint trigger under a lock, and a second session minting at the same moment would make a range shown ahead a lie. The ask says where the last run the caller can see ended, the press names the count, and the run's title and the CSV carry the range once it exists. After the mint the press reads the range.
- **The press mints and prints in one.** The strips print as soon as they are drawn, so the one press does what it says. A run whose print fails is still on the screen with its press, and the fold has it for ever: nothing is lost with the strips.
- **A test strip mints nothing.** It prints 0000 with the bare address, so a scan of it opens Scan a label and no code is spent on a test.
- **Over USB the press is Connect the P-touch until a printer is connected**, as the labels window has it: a mint with no printer would spend numbers on nothing.
