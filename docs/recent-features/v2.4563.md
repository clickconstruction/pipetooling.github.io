# v2.4563 — Lien window: a saved copy link typed while recording is kept (2026-10-05)

Client only; no migration, no edge function. Row 2 of the lien defects card (punch list #83, `to-dos/lien-defects.md` on PR #4528).

## The defect

`LienFilingTabs` keeps the record step's *Saved copy* link and note in `docUrl` / `docNote`. `insertFiling` (the affidavit filing and the release of record) and `recordNoticeSends` (the § 53.056 notice) read both inside `useCallback`s whose dependency lists left them out. Typing in either box re-rendered the tab and handed back the callback made before the typing, so the insert ran `filingDocumentPayload({ url: '', note: '' })` and wrote neither column. The notice path kept the link only when a send field was changed after the link was typed. Adding the link later from the Filings list always worked: that path has its own state.

## The fix

- [`LienFilingTabs.tsx`](../../src/components/jobs/LienFilingTabs.tsx): `docUrl` and `docNote` join both dependency lists.

Nothing is backfilled: a record made before this has no link to recover.

Both fail without the change.
