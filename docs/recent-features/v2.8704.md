# v2.8704 — Usage: the job form's Edit tab counts which row is opened (2026-11-27)

Punch list #190 (`to-dos/usage-paths/README.md`), PR 3's first step. The read of 2026-11-27 could not say whether the Edit tab's **Team** row is pressed, because no press on the Edit tab is recorded. It did say that *Open the Edit tab* is half of every press on a Pipeline row. Taunya's answer on 2026-11-27, relayed by the managing session: a recorder first, and read again in three weeks. Client only. No migration, no edge function, nothing owed after the merge.

**What is counted.** `JobFormFactRow` writes one row to `ui_nav_clicks` each time a row's editor is opened: control `job-edit-row`, target the row's name (`#Team`, `#Account man`, `#Customer`). The row's body and its pencil are the same press, so both count, once. Closing an editor writes nothing. A read-only row has no press. Every row of the Edit tab is drawn by that one component, so every row is counted: the people, the folders, the customer block, the property, the GC, the plans, the contract rows, the pay calendar and the charging row.

**Why not a marker.** PR 1's markers (`data-navtrack` with `data-navbuttons`) record every labelled button inside a container. Over the Edit tab that would count the presses inside an open editor too, and the Team picker's buttons are people. So the row counts itself at the one place it opens.

**Names never reach the ledger.** Two labels carry a name or an address (*Show <the other party>*, *Property kind for <address>*). The target is made by `jobEditRowTarget`, which reads the label by the rule a button's name is read by since v2.5904 (`navNameFromWords`, split out of `navButtonName`): a capitalised word the app does not own ends the name with `…`, and *for* cuts it. Five of the app's own words joined the list so the rows read whole: Charging, Our, Pay, Show, Sub.

**As whom.** The signed-in viewer the auth provider installs (`navClickViewer.ts`), as PR 1's presses are. Signed out, or in a render smoke that mocks the auth hook, nothing is written.

**Where it reads.** Settings → System → Usage names the control **Edit tab row** (`controlLabel`).

**The next read.** On or after 2026-12-18, three weeks on: the count of `#Team` opens against the other rows, by role. That read decides PR 3, the crew chip's **+**.

**Tests.** `navClickTelemetry.test.ts` (every row's label reads whole, the two labels with a name are cut), `navClickViewer.test.ts` (recorded as the viewer, nothing signed out), `JobFormFactRow.render.test.tsx` (the pencil and the body count once, closing and the editor's own buttons count nothing, a read-only row counts nothing), `usageDashboard.test.ts`.
