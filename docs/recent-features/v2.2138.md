# v2.2138 — Next up, phase 2: ⚡ on the Map and a Dashboard "needs a name" nudge (2026-08-22)

Carries the v2.2129 shortlist to where people actually look. Client-only, no migration.

Threshold `ROADMAP_NUDGE_MIN_COUNT = 3`; up to three roadmaps per card. Tapping opens `/checklist?tab=roadmap&roadmap=<id>&view=plan`.
