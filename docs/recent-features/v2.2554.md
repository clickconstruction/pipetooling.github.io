# v2.2554 — twin auto-scorecard kernel (T4) (2026-08-31)

Census Toolkit Plan tool T4: `src/lib/twinScorecard.ts` (unit-tested kernel)
+ `scripts/twin-census/scorecard.ts` (vite-node CLI). At every backtest/shadow
unseal the twin now runs a mechanical line-compare instead of a hand one:

- **Row parser** for human-typed `bids_count_rows` names — fixture tags
  (`SK-1`, `WC-1A`, bare `IMB`/`EWH`), footage rows (`ft of 3/4in DHW`,
  mixed-fraction sizes like `2 1/2 gas 90`), fittings, prose.
- **Scope-match check** (PLACEMENT.md rule, adopted after BT-15's void):
  reference fixture tags vs the fetched set's tag census; `fail` (<50% of ≥3
  tags found) exits nonzero — a failing run must not be scored.
- **Scorecard**: per-tag count deltas, fixture accuracy, per-system footage
  ratios (waste/vent/water/gas/storm/demo), unmatched rows both directions.

Tests use the real BT-16 (pass) and BT-15 (fail) row shapes. Feeds the
confidence scoreboard a counts dimension alongside `score_shadows` dollars.
