# v2.4531 — Lien desk Calendar: the job number opens the job (2026-10-05)

Client only; no migration, no edge function. The owner, on the desk's Calendar: there was nowhere to click to open the job's own window, the one with History and Edit. Make the job number on the left open it.

## What changed

- **The number is its own button.** `JobNumber` in [`LienDeskCalendarTab.tsx`](../../src/components/jobs/LienDeskCalendarTab.tsx): with a door (`onOpenJobWindow`) it is a `<button>` that opens the job and stops the click there; with none it is the plain chip it was. Hover underlines it; the tooltip reads *Open the job: its history, its bills and Edit*.
- **The rest of the row is unchanged in what it does.** The label cell was one big button holding the number. It is now a `div` that takes the click for the Lien window, with the name as its button (the keyboard stop) and the address line inside the same click area. The marks on the axis open the Lien window as before. The phone list's row is rebuilt the same way.
- **Wiring.** [`LienDeskModal.tsx`](../../src/components/jobs/LienDeskModal.tsx) takes `onOpenJob` and hands it to the Calendar tab; [`JobsStagesTab.tsx`](../../src/components/jobs/JobsStagesTab.tsx) passes `jobDetailModal.openJobDetail({ jobId, onEditJobSaved: refetchLienDesk })`, the call *Put a GC on notice* already used. The Job window (z 1010) draws over the desk (780), which stays open, so closing it lands back on the Calendar; a saved edit refreshes the desk.
- Only the Calendar tab's rows. The Notices, Affidavits and Timeline lists select a job on a click and are not changed.

## Tests

`LienDeskCalendarTab.render.test.tsx` (+2): the number opens the job and not the Lien window, the name and the address line still open the Lien window, the same on a phone; with no door the number is plain. Row lookups in the file read the number's text instead of a button named after it. Seen in the dev preview on the live desk: number 273 opened the Job window over the desk, closing it left the desk on Calendar, and the row's name still opened the Lien window. Nothing was written.
