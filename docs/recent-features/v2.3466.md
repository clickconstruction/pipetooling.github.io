# v2.3466 — Submittals stage 2b: the Submittals tab (2026-09-14)

Client only (reads the v2.3465 tables; no migration, no edge function). Stage 2's second PR ([`to-dos/submittals/README.md`](../../to-dos/submittals/README.md) → PR 2b): the tab after Cover Letter that is a *lens* on the product decisions made on the Pricing compare — rows are built from the picks, never typed.

## What shipped

- **[`BidsSubmittalsTab`](../../src/components/bids/BidsSubmittalsTab.tsx)** — `Bids.tsx` gains `'submittals'` (union, `BIDS_TABS`, the superintendent redirect list, the button after Cover Letter inside the same `!superintendent && !primary` block, the mount with `selectedBidForPricing`; deep link `?tab=submittals&bidId=`); `EGG_BIDS_TABS` lists it. The standard bid picker when no bid is selected. Selected: the title with preview, *N tags on the schedule · N picked lines* with a door to Pricing, then:
  - **No revision** → a card: what Rev 1 is built from, two amber warnings (no schedule / no picks), **Build Rev 1 from the picks** (inserts `bid_submittals` rev 1 + the rows).
  - **Revision strip** (chips `Rev N · status · date`), the actions — **Rebuild rows from picks** (draft; the draft's own rows are the carry source so edits survive an unchanged product), **Drop a vendor PDF** (stored once at `<bid>/<rev>/<index>.pdf`, page count via pdf-lib, appended to `source_files`), **Delete draft** (newest draft only), **New revision** (confirm names the diff; inserts rev N+1 with the newest revision's `source_files`, rows built with `previous`; an unshared draft turns *superseded*).
  - **Six tiles** (`revisionTiles`), the revision line (`describeRevision`), the vendor files strip, and the table: Tag · Specified · Submitted · Status chip · Reason (*say why* in amber when owed) · Lead time · Sheet (*✓ p.1–2* + file, or *sheet needed*) · **Since Rev N-1** (`changeNoteFor` against the carried-from item, loaded from the previous revision) · Edit.
- **[`SubmittalItemEditDialog`](../../src/components/bids/SubmittalItemEditDialog.tsx)** — status (all seven), the reason chips + note for an alternate or design change, the lead time (presets or typed), the sheet as a vendor file + typed page range (`parsePageRange`, bounded by the file's page count). Save writes the item row.
- **Kernels** (`src/lib/submittals/`, all tested): [`buildSubmittalRows.ts`](../../src/lib/submittals/buildSubmittalRows.ts) (the parked draft, finished: a near-match label no longer reads as the specified unit; tag order is locale-aware; `changeNoteFor` exported), [`submittalRevision.ts`](../../src/lib/submittals/submittalRevision.ts) (`parseSourceFiles` / `serializeSourceFiles`, `itemToPrevious`, `draftToItemInsert`, `revisionTiles`, `describeRevision`, `describeRevisionChip`, `parsePageRange` / `formatPages`, `needsSheet`, the bucket name), [`picksFromQuotes.ts`](../../src/lib/submittals/picksFromQuotes.ts) (latest quote per house → one pick per fixture; a kit reads its `kit` line, any line of the cell carries the annotation), [`trimPdf.ts`](../../src/lib/submittals/trimPdf.ts) (`pageCount` used here; the trim itself waits for stage 3).
- **[`ProductStatusChip`](../../src/components/bids/ProductStatusChip.tsx)** extracted from the compare modal and shared.
- **Guide**: new [`build-a-submittal-package.md`](../../src/content/help/build-a-submittal-package.md). **Docs**: `BIDS_SYSTEM.md` → "Submittals Tab" + the schema section; `ACCESS_CONTROL.md` matrix row; `GLOSSARY.md`.
