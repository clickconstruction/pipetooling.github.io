# v2.1946 — Plan lists sort by stage number (2026-08-21)

Part 3 of the stage-numbers train (v2.1940 badges, v2.1941 Order-stages
modal): with the order user-draggable, the Plan view now reads in it.

- `planNowStages`, `planUpNextStages`, and `goalMilestones`
  (`src/lib/roadmapPlanView.ts`) drop their re-sorts (momentum / title /
  feeder-fraction) and keep the caller's `groups` order — the roadmap's
  `sort_index` stage order — so rows read #1, #2, #3… matching their badges.
- Momentum ordering (v2.1913) retired deliberately: the manual order is now
  the one source of "what comes first", and progress still shows on each
  row's done-count pill. Regression test pins stage-order-beats-momentum.
- Help guide `number-and-order-roadmap-stages` updated to describe the
  ordered lists.
