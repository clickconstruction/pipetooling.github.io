# v2.2693 — Contract modal: "Link copied" instead of "Sent to" when nothing was emailed (2026-09-03)

Live-test finding from the Contract Desk build (v2.2681): Copy link and Sign in person mint the link through `send-job-contract` in `link` mode, which stamps `sent_at` / `recipient_email` exactly like an email send — so the amber strip then read *"✉ Sent … to palmer@…"* although no email had gone out.

- `JobContractModal` now reads the live row's latest `job_contract_events` `sent` event (`metadata.channel`). `link` → *"🔗 Link copied Sep 3 — nothing emailed yet to palmer@…"* and the strip's first button becomes the primary **Send by email**; `email` → the existing *"✉ Sent … to …"* with **Resend email**.
- No schema change — the channel already rode on the event; the row keeps one `last_sent_at` for both.
