# v2.7295 — A Dashboard test no longer fails every evening (2026-11-14)

`src/lib/dashboardNeedsYou.test.ts` › *a closed window whose affidavit can still be filed reads send the late notice by <day>, not gone* (v2.7273, punch list #335 row 4) failed on main from 6 PM Central on 2026-11-14, and every merge-queue build behind it failed with it (the queue dropped #8133 for it).

## Why

The test built its days with `new Date()` plus N, read back through `toISOString()` — a UTC date. The card counts *in N days* from `todayYmdInAppTz()`, the app's Central day. After 6 PM Central the UTC date is already tomorrow, so the test's "17 days ahead" was 18 days from the card's today and the exact title `· in 17 days` read `· in 18 days`. The older lien card test beside it (v2.3704) had dodged the same gap with a range in its pattern (`in 2[234] days`); row 4 matched exactly. The app is right; the test was not.

## The change

Row 4's three days (17, 23 and 5 ahead) come from `addDaysYmd(todayYmdInAppTz(), n)`, the same today the card counts from, so the title reads the same at any hour. The older test's ranges are left as they are.
