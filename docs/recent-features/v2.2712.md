## Edge function `share-job-contract` (new — deploy after the migration; see `docs/EDGE_FUNCTIONS.md`)

- Staff JWT in-body; rows read through the caller's RLS. `contract_id` → the stored signed PDF (rebuilt once from the frozen row and stored when an older signature predates it; paper records send the uploaded copy). `estimate_id` (+ `job_id` for bid-room proposals) → an acceptance PDF built once from the frozen option / line items / terms / acceptor fields with the shared `buildJobContractPdf` and cached at `job-contract-documents/estimates/<id>/signed.pdf`.
- `mode: 'email'` sends to up to ten addresses (first To, rest CC; reply-to = the sender; optional note; the durable link for contracts) with the PDF attached; logs a `shared` contract event and a `contract_shared` job-activity row (`summary: "Signed agreement emailed to …"`). `mode: 'pdf_url'` returns a 1-hour signed URL instead.
