# v2.4074 — Bids: the Bid window's trade switch is its own piece (2026-09-28)

Client only; no migration, no edge function, no screen change. Punch list **#51** (`to-dos/bids-edit-controller.md`), PR 3 of 5 — the first move of the Edit Bid controller out of `src/pages/Bids.tsx`.

## What is new

- **`src/hooks/useBidTradeSwitch.ts`** (13-case hook test) — the Bid window's Service Type switch, moved verbatim: the same customer's other bids for the same project, grouped by trade; copying the bid into another trade (`duplicate_bid_to_service_type`) and what each answer does to the window; opening a sibling that already exists, in hand or after a reload. The pending autosave is flushed before every way out of the bid. The page hands in the doors it needs: flush, close the window, open a bid, reload, pick a trade.
- **`src/lib/bids/tradeSwitchSiblings.ts`** (7 tests) — the grouping: a sibling counts when its project name matches, trimmed and case-folded; an empty name matches nothing.

## What changed in `src/pages/Bids.tsx`

3,343 → 3,259 lines. The siblings state leaves with the handlers; the "is the switch window open" flag stays (only the render reads it). Behavior-preserving.

## Verified

- The page smokes before and after (`Bids.render.test.tsx`, 38 cases, including #51 PR 2's *Edit Bid writes*; `Bids.followupDoors.render.test.tsx`, 14).
- Five deliberate breaks of the hook — the copy or the open skipping the flush, *saving* left on, the copy aimed at the bid's own trade, the sibling read not excluding the bid — each caught.
- Live on a local dev server (production data): a bid's Service Type switch opened, sent exactly the sibling read above and offered Duplicate / Copy to Electrical / Copy to HVAC; Escape and the window's ✕ closed it; nothing was written.
- eslint; typecheck; `npm test` in full.
