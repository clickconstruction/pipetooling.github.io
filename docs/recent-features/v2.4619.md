# v2.4619 — Records for an owner: download the packet as a PDF (2026-10-06)

Client only; no migration, no edge function. The owner's ask on seeing the window (2026-10-05): *I like Print the packet; I would also like a download button.*

## What changed

- [`ownerRecordsPdf.ts`](../../src/lib/jobs/ownerRecordsPdf.ts): `ownerPacketPdfModel` is the pure mirror of `ownerPacketHtml` — the cover note's lines, the summary table, each job's bills, payments, open lines and totals, in the print's order and words; `ownerPacketPdfBlob` draws it with jsPDF (letter, Helvetica, the cover on its own page, the statement with a four-column summary and two-column job tables, page breaks); `ownerPacketPdfFilename` names the file for the property and the day.
- [`LienOwnerRecordsModal.tsx`](../../src/components/jobs/LienOwnerRecordsModal.tsx): **Download the packet** beside **Print the packet**. It asks first while the wording is a draft (as Print does), saves the file through `saveBlobAs`, and files the PDF as a sent copy with `how: 'download'` (v2.4554 kept prints; the `download` way already existed).
- Guide *give an owner our records for their property*: the button, and that a download is kept like a print.
