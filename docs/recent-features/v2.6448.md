# v2.6448 — Charges by crew, PR 4: the Edit Job row *Charging the customer*, the directory and the glossary (punch list #254) (2026-11-03)

The train's loose ends. PR 1 (v2.6441) put the job's rule and markup in `jobs_ledger`; PR 3 (v2.6445) gave the Charges window a strip that writes them; the card's artboard B drew the same choice at the foot of the Edit Job form, so the office sets a job's rule where it sets the job's other facts, without opening the Job Summary.

## What changed

- **The row** (`src/components/jobs/JobFormChargingRow.tsx`, a `JobFormFactRow` last in `JobFormEditFactRows.tsx` on an existing job): collapsed it reads the rule with its rate and the markup in force (*the crew on each day, from the rate card · materials 25% over cost, the company’s markup*); open, **Charge this job’s labor as** (the crew on each day, each shape throughout with its rate, a flat rate), the flat-rate box awake only under the flat rule, **Markup on materials** with the company's figure as the placeholder, and the note that the Charges window writes the same facts. Written straight to the job as you pick through `saveJobChargeRule`, never through the autosave slice; a read that fails names its reason with Try again.
- **The words** (`src/lib/charges/jobChargingWords.ts`): `jobChargeRuleWordsWithRate`, `jobMarkupWords`, `jobChargingValueWords`, with tests.
- **The directory** (`docs/twins/APP_DIRECTORY.md`): the rate card and the standings under Settings; the Charges and Premium columns and the Charges window, the Statement of charges and this row under Jobs.
- **The glossary**: the *Crew-day and the rate card by crew* entry names where a job's rule is set.

## Decisions

- **One door, two places.** The row and the Charges window write the same four columns; neither keeps its own copy.
- **No new gate.** Whoever may edit the job may set its rule, as with the lien facts beside it; the rate card itself stays in Settings.

## Test

Dev server, `/dev-login?as=1`, a job's window → **Edit** → the last row **Charging the customer**: pick *a tech alone throughout*, the collapsed value follows; open the Job Summary's Charges window on the same job and the strip reads the same rule.
