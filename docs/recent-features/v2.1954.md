# v2.1954 — Task card Enter-to-save hardening (2026-08-21)

Follow-up to v2.1949: the inline title editor and note composer relied on a
`keydown.key === 'Enter'` match alone.

- Both are now real `<form>`s (submit buttons + `onSubmit`), so implicit
  submission covers software keyboards' go/send keys — plus an explicit
  Enter `onKeyDown` path that `preventDefault()`s before saving, so
  environments where the key's default action doesn't run still save and
  the two paths can never double-fire (`titleSaving`/`posting` guards
  stand behind them regardless).
- Verified live: Enter renamed a prod task and renamed it back.
