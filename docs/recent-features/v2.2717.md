# v2.2717 — Person Desk PR 4: doors everywhere and the quick sheet (2026-09-03)

Fourth Person Desk PR (train: v2.2701, v2.2706, v2.2710, v2.2713). A mechanical sweep — merged alone per the house rule — plus the proposal's variant C as a third door into the same drawer. No migration; no new permissions.

## Client only

- **`PersonNameDoor`** [`components/personDesk/PersonNameDoor.tsx`](../../src/components/personDesk/PersonNameDoor.tsx): renders a name as a Desk opener (dotted underline, stops row-click propagation) when the provider is mounted and `canOpenPersonDesk(role)`; otherwise the given `fallback` or a plain span. Takes whichever key the surface has: `userId`, `personId`, or just `payName`.
- **Open by pay name**: `PersonDeskOpenArgs.payName` + the loader resolves a unique active `users.name` first (the pay identity), else a unique active `people.name`; an unresolvable name errors in the drawer with a pointer to People → Users. Name-keyed surfaces (the Hours grid, Contracts) open through this path.
- **Sites swept** (eight): Hours grid person cell (`PeopleHoursGrid`, pay name + the grid's own users lookup), clock sessions card and table name cells (`ClockSessionsTable`), Dashboard My Team ledger tables (both), Crew Day person cards, the Dashboard clock strip name (Desk for office roles; the User Review button stays the fallback for team leads), Contracts person rows (the row still expands; the name opens the desk), the approvals queue person header.
- **Quick sheet** [`components/personDesk/PersonQuickSheet.tsx`](../../src/components/personDesk/PersonQuickSheet.tsx) (mounted from Layout): `/` outside a typing surface opens a search over active accounts and unlinked roster rows (name or email; arrows + Enter; Esc closes) and Enter opens the Desk. Office roles only. The header's job/bid search is untouched and never bound `/`.
- Verified live as dev: `/` → "tau" → Enter opens Taunya's desk; dotted doors present on the Dashboard (clock strip, Crew Day, My Team).
