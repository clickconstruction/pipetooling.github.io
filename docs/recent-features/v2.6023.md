# v2.6023 — GC mode: Paste rows into a schedule template from a spreadsheet (2026-10-28)

PR 4 of punch list #204 (`to-dos/schedule-builder/README.md`, the mock-up's D), on the editor of PR 3 (v2.6022). The
list the owner saw was a spreadsheet; this takes it as pasted.

## The kernel (`schedule/templatePaste.ts`, new)

- `readPastedRows(text, existing)` reads the paste line by line on the import kernel's pattern (`import.ts`): a tab
  between the columns phase, row, who, days, waits on, gap and milestone (`PASTE_COLUMNS`); a heading line that
  repeats them is skipped; a blank phase takes the line before it; who is Us for ours, Office or blank for the
  office's, anything else a trade (`whoFromWords`); days a whole number of one or more, one for a milestone whatever
  the cell says; the gap a whole number; a milestone marked yes, y, x, a tick, true, 1 or the word. A line with no
  tab, no phase above it, no row name, bad days or a bad gap is held with why, by its line number. Once every row is
  read, a wait names a pasted row by its label (or *Who · label*), else one of the draft's rows by the name a wait
  writes (`findRow`), else it is dropped and said.
- `pasteWords(reading)`: *Read 50 rows in 8 phases, 6 of them dates to meet.*, *3 lines could not be read.* with a
  line each, and *Line 30 waits on Slab pour, which no row is called. It starts on the start day.* Every sentence
  keeps to `plainWords.ts`.
- `applyPaste(draft, reading)`: a phase the draft has by name takes its rows at its end, the other phases are added
  in the paste's order, and the waits are written by the names the rows have then (`rowRef`, qualified when two
  rows share a name).

## The box (`GcTemplatesPage.tsx`)

**Paste rows** on the list opens a new template with the box up; in the editor it opens the box under the toolbar:
the intro (`PASTE_INTRO`), a textarea, the reading's words as typed, and **Add N rows** (`countedLabel`, dead at
none) beside Cancel. Add puts the rows on the draft and closes the box; the save stays the editor's.
