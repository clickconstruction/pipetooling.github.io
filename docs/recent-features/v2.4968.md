# v2.4968 — People: the Hours grid's manual-draft editor is a hook and a window (2026-10-08)

Client only; no migration, no edge function, no screen change. Punch list **#46** row 6 (`to-dos/decomposition-queue.md`): the last of the smaller cuts the PEOPLE_TABS map's step 8 names (`docs/PEOPLE_TABS_ARCHITECTURE.md`). The others were the merge-duplicates banner (v2.4945), the Teams + Due summaries (v2.4953) and the sessions section's filtered lists (v2.4965).

## What shipped

- **`src/hooks/usePeopleHoursManualDraftEditor.ts`** (new) — the window's state (`hoursManualDraftEditor`, its type now `PeopleHoursManualDraftEditorState`) and the grid's opener `openManualHoursDraftFromBlur`, verbatim from `People.tsx`. The opener runs when hours are typed into a grid cell or the day sheet:
  - no account for the roster name: save to the grid only
  - an open session that day: the plain day editor
  - closed sessions: scaled to the typed total
  - an empty day: one draft session

  Inputs: `users`, the pending and approved sessions, `prefixMap`, `saveHours`, `showToast` and `setHoursMyTimeEditor`.
- **`src/components/people/PeopleHoursManualDraftEditor.tsx`** (new) — the window, verbatim: the day editor over the seeded sessions, and its save syncing `people_hours`. A draft-only day is cleared. When real sessions were scaled, the cell gets the day's approved closed sum, read back, or is cleared if that read fails. Then both reloads run, followed by the in-place job / time patches and close. Every prop keeps the page's name, so the JSX is unchanged.
- **`People.tsx`** — calls the hook after `usePeopleHoursData`, whose sessions and `saveHours` it reads, and mounts the window where it stood. The hook has state and no effect, so its later place in the hook order changes nothing. 3,207 → 3,050 lines. The imports only the window used are gone: the draft and scale kernels, `withSupabaseRetry` and `DayEditorSession`.

## Tests (+11)

- `usePeopleHoursManualDraftEditor.render.test.tsx` (new, 5), on the real scale and draft kernels:
  - no account saves to the grid only, with a toast
  - an open session opens the plain day editor
  - closed sessions are scaled to the typed total in clock-in order, keeping their ids and leaving a rejected one out (each keeps the 36 s floor, then the rest splits 3 : 1)
  - an empty day gets one draft session of the typed hours
  - a date the draft cannot be built for says so

  Skipping the open-session check fails it.
- `PeopleHoursManualDraftEditor.render.test.tsx` (new, 6), with the day editor as a probe:
  - nothing is drawn until a day is opened, and the editor's props come from the seed
  - a draft-only save clears the cell and reloads
  - a scaled save writes the approved closed sum read back with the four filters (counting unapproved rows fails it)
  - a failed read clears the cell
  - job and time patches land in place, and the linked reloads and Close work
