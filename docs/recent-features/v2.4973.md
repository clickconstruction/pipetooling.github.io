# v2.4973 — My Time day editor: Reject session is the one call, and the fallback is gone (2026-10-08)

Client only. No migration, no edge function, no screen change. This follows up punch list **#46** row 10: v2.4964 kept the old two requests as a fallback until `20261009170000_reject_clock_session.sql` was pushed. It is pushed now and the types are current (#5021), so the fallback goes.

## What changed

- **`src/lib/rejectClockSession.ts`**: `rejectClockSession(sessionId)` makes the one typed `reject_clock_session` call through `withSupabaseRetry`. Gone with the fallback:
  - the two requests: the `clock_sessions` `UPDATE`, then `recompute_people_hours_after_session_edit`
  - `isMissingRejectFunction` and `RejectClockSessionPath`
  - the `rejectedBy` argument, since the function writes `auth.uid()` itself
  - the `as never` casts, now that the generated types have the function
- **`DashboardMyTimeDayEditorModal.tsx`**: `confirmRejectSession` calls `rejectClockSession(session.id)`, and `authUserId` leaves its dependency list. Everything around the call is unchanged.
- A missing function is now an error like any other. The dialog shows it and stays open, and nothing is written.
