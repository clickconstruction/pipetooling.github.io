# v2.3502 — Supply house credits, step 3: the gate opens (2026-09-16)

Migration only, plus the types regen. **No client change.** Third of four PRs from [`to-dos/supply-house-credits/README.md`](../../to-dos/supply-house-credits/README.md).

Migration [`20260916120000_supply_house_document_kind.sql`](../migrations/20260916120000_supply_house_document_kind.md) — `supply_house_invoices.document_kind` (`invoice` default, or `credit`), and `supply_house_invoices_amount_check` replaced so an invoice keeps `amount >= 0` and only a credit may be negative.

It lands on its own, ahead of the form, for one reason: if the client shipped first there would be a window where picking Credit failed against a database that still refused negatives. The reverse order has no window at all, because the old client never sends `document_kind` and its inserts default to `invoice` under the rule it already obeyed.

Pre-flighted read-only against prod: all 466 existing rows pass the new constraint under the default, and the one row at `$0.00` still passes.
