# v2.2008 — Portal merged statement + custom addresses, backend (2026-08-21)

PR A of the portal custom-links train (design: the owner-approved "Custom
Portal Links" mockup; spec: "Portal Custom Links Plan" artifact). Backend +
statement rendering only — the globe modal rework is PR B.

- **Merged audience `'all'`** (migration `20260821233000`): the
  `customer_portal_links.audience` CHECK gains `'all'`, now the default for
  `mint_customer_portal_link` (v3). An `'all'` portal shows ONE statement —
  the union of jobs where the company is the customer and where it is the GC,
  deduped by job id. Existing `'customer'`/`'gc'` links keep working and
  become the "Separate views" scoped links (PR B surfaces creating them).
- **Custom addresses** (migration `20260821234000`):
  `customer_portal_slugs` (one slug per customer, survives token rotation,
  `locked_at` on first share) + append-only `customer_portal_slug_events`
  (created/changed/locked → modal History in PR B). RPCs
  `set_customer_portal_slug` (friendly format/uniqueness errors) and
  `mark_customer_portal_slug_shared` (idempotent lock, called on first Copy).
- **Edge fn `customer-portal`**: accepts `?slug=` (→ `customer_portal_slugs`
  → the active `'all'` link; no mint-on-demand — a turned-off portal stays
  off; first public resolve locks the slug server-side). Merged payload rows
  carry `asGc` + `ownerName`; bill building extracted to the dependency-free
  `_shared/portalMergedBills.ts` (unit-tested from
  `src/lib/portal/portalMergedBills.test.ts`). Payload gains `requestToken`
  so slug-opened pages can submit visit/bid forms. **Redeploy required.**
- **Client**: new public route `/p/:slug` → `CustomerPortal` (fetches by slug;
  `/portal?t=` untouched and permanent). Statement rows with `asGc` render a
  copper **AS GC** chip + "owner: «name»" on the address line (pinned-light
  page, literals allowed). `src/lib/portal/portalShortOrigin.ts` holds the
  short-origin constant (`https://pipetooling.com/p/` until the
  my.clickplumbing.com DNS redirect goes live). `portalPayload.ts` parser
  extended (asGc/ownerName/requestToken/audience 'all') with tests.

Deploy notes: `supabase db push` after merge, then
