# v2.2667 — Sub portal: the Work & Pay statement train (2026-09-02)

The customer portal's sibling for subcontractors: a private, no-login capability link per roster person showing their jobs (Sub Labor sheets with line items), pay (ledger with sub-visible memos, all-time recap), pay timing, sign-to-accept work offers, and paperwork status. Bilingual EN/ES, print-paginated. Owner-approved mockups drove the build (portal statement + eight office-surface mocks).

## DB (migrations `20260902210000` / `220000` / `230000` — fragments in docs/migrations/)

- **Link spine**: `sub_portal_links` (person-keyed, raw token, one active per person) + `sub_portal_slugs`/`_slug_events`; RPCs `mint_sub_portal_link` / `revoke_sub_portal_link` / `set_sub_portal_slug` / `mark_sub_portal_slug_shared`. Slug uniqueness spans `customer_portal_slugs` (one printed `my.clickplumbing.com` namespace; `set_customer_portal_slug` re-created with the cross-check — body copied from `20260821234000`, not the baseline). `public_page_views.surface` gains `'sub_portal'`.
- **Sheet portal fields**: `people_labor_jobs.portal_status/payable_after/pay_hold_reason`, `people_labor_job_payments.hidden_from_sub`; office RPCs `set_sub_sheet_portal_fields` / `set_sub_payment_visibility` (pre-regen client calls these).
- **Sign-to-accept**: `step_commitments.offer_scope_snapshot` (frozen at offer), `offer_expires_at`, and the signature record of truth (`signed_at`, `signer_printed_name/_signature_mode/_signature_storage_path/_consented_at/_ip/_user_agent` — lien precedent, plus the IP/UA audit the lien lane skipped).

## Edge functions (deploy manually: `sub-portal`, `submit-sub-portal`; both `verify_jwt = false`)

- `sub-portal` GET: token/slug → statement payload; junction-first sheet scoping; memos dropped when hidden (amount always shows); paperwork STATUS only; pay-run settings from `app_settings.sub_pay_run_day` / `sub_pay_explainer`. Shared pure builder `_shared/subPortalStatement.ts`, vitest-covered from `src/lib/subPortal/subPortalStatement.test.ts`.
- `submit-sub-portal` POST: `availability` (rate-limited, dispatch intake), `accept_offer` (signature validate/upload → `offered→accepted` + stamps in one update; compensating PNG delete; dispatch note), `decline_offer` (reason required), `sign_link` (fresh 14-day `/contract/accept` token for the sub's own unsigned docs — send-contract-for-signature mint pattern, no email).
