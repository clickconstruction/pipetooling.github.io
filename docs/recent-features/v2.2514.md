# v2.2514 — Takeoff 3D: size attribution + vertical allowances + mirrored prices (2026-08-30)

Backtest BT-1 (Take 5 6811 San Pedro, won $110,747) exposed the gaps: the human
reference carried 3.5× the twin's water feet, ~9× its fittings, all size-split.
This release closes the structural half:

- **Kernel** (`src/lib/takeoffPlacement.ts`): `deriveFittings` gains a `systemOf`
  param so size-split lineTypes join branches across sizes within a system (2"
  branch tees into 3" main; fitting named by branch size; dedupe by system);
  new `VerticalAllowance` type + `expandVerticalAllowances` (explicit vertical
  footage + implied fittings, every height naming its source); new
  `buildToolingRows` (the paste-ready ESTIMATE view: drawn + allowances,
  size-split, /Tooling row names). 6 new unit tests (31 total).
- **Assembler** (`scripts/placement-engine/assemble.ts`): manifest lines take
  `size`; size-variant lineTypes minted on the same system canvas; `verticals`
  expanded + itemized; writes `<out>.tooling.txt`.
- **Doctrine**: four new PLACEMENT.md chapters (third dimension, size
  attribution, fitting allowances, scope-call standards); briefs regenerated,
  twin-mcp deployed.
- **Robot price book**: 36 entries mirrored from b298's actual won pricing
  (per-size pipe ft rates, per-size fittings, oil interceptor, cleanouts,
  point-of-use heaters…), named to MATCH tooling rows for future auto-fill.
- **Tested by rerun**: BT-1 reassembled with sizes + allowances — water
  233.2 ft size-split vs reference 306.8 (was 88 lump; the 1/2" bucket lands
  104.9 vs 100.2), waste+vent 226.7 vs 349 (was 56), fittings 67 vs 120 (was 13).
