# v2.2581 — AR Customers view: two-line customer cell, full names visible (2026-09-01)

Owner report: in the AR drill-down's Customers view the name column crammed the
Comm/Res segment tag, the customer name, and the chase pill ("Owes a call") onto
one line inside a `minmax(140px, 190px)` grid column — long names truncated to a
few characters ("Southe…").

`DashboardArCustomersView.customerRow` now stacks that cell into two lines:

- **Line 1**: the customer name alone (full column width, ellipsis + `title`
  tooltip for anything still too long).
- **Line 2**: the Comm/Res tag + the `rowBadge` chase pill.
- The second line renders only when there is a tag or a pill — rows like
  "No customer on the job" stay single-line.

Grid columns, bars, pace stats, and the expansion are unchanged; no schema or
kernel changes (`arCustomerRollup` / `arCustomerChase` untouched).
