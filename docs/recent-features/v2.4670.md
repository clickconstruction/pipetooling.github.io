# v2.4670 — Help: the "it" warning names only the sentences you wrote (2026-10-06)

[v2.4660](v2.4660.md) added `npm run check:pronouns`, a warning on help-guide sentences that open on a bare pronoun pointing back. It printed every such sentence in every guide a change touched. The guides hold 3,442 of them, so a writer who fixed one sentence in *build a submittal package* saw 149 they never wrote. PUNCHLIST asked for this narrower follow-up so the signal stays. No guide is touched, nothing on a screen changes.

## What changed

- **`src/lib/pronounOpeners.ts`** gains two helpers:
  - `changedLinesFromDiff` reads the lines a change wrote from `git diff -U0`: each hunk's new side. A new guide counts as every line, and a hunk that only deletes counts as none.
  - `openersOnChangedLines` splits the findings into those on written lines and a count of the rest.
- **`scripts/check-pronoun-openers.ts`**:
  - lists only the findings on the lines the change wrote;
  - gives each guide one line, like *1 on the lines this change wrote · 149 more on unchanged lines*;
  - annotates only those findings in GitHub Actions;
  - with `npm run check:pronouns -- --all`, lists every finding as before.
  A paragraph is one line in a guide's file, so editing one sentence brings in the rest of its paragraph. It still always exits 0.
- **`plainWords.ts`**'s header says the warning reads the lines a change writes.

## Verify

`npx vitest run src/lib/pronounOpeners`. A throwaway local commit added one pronoun sentence to *build a submittal package*:
- the default run listed that one sentence and counted 149 more;
- `--all` listed 150;
- under `GITHUB_ACTIONS=true` only that one line was annotated.
