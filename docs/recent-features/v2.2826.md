# v2.2826 — Job Summary: Scatter view (2026-09-05)

PR 6 of the Job Summary analysis plan (artifact 9c02d29a), stacked on v2.2825.

## Client only — no migration

- [`jobSummaryScatter.ts`](../../src/lib/jobs/jobSummaryScatter.ts) (new kernel): `buildJobSummaryScatter(rows, colorBy, ctx)` → points (jobs with a known true margin and revenue; the rest counted in `skipped`), series ranked by count in a **fixed hue order** (blue, amber, teal, purple, green, pink — the dataviz rule: hues by rank, never cycled; a 7th key folds into gray "Other"), median revenue / margin, `bigThin` (above median size, below median margin, sorted by `shortfallUsd` = revenue × (median margin − margin)). Color keys reuse `jobSummaryCutKey` (service type / GC / lead tech). Two tests.
- [`jobSummaryLedgerView.ts`](../../src/lib/jobs/jobSummaryLedgerView.ts): view mode `'scatter'`; prefs `scatterColorBy` (trade | gc | tech) and `scatterSizeBy` (hours | days | none).
- [`JobSummaryScatterView.tsx`](../../src/components/jobs/JobSummaryScatterView.tsx) (new): Color by / Size by controls; SVG (square-root x-scale so the many small jobs don't crush into the left edge; y clamped to the data with −40…80 minimum; median dashed lines; target line with the under-count; hover dims the rest; `<title>` per bubble; click → the job); legend with counts; the Big and thin tile + table (revenue, hours, true %, short; hovering a row lights its bubble; click opens the job). Money-gated: without money the view explains itself and stays empty.
- Toolbar: Scatter in the View chips; Show applies (`showView`), Target applies (`marginView`), Compare to does not. Tab renders the view with the `onOpenJob` door (search + Jobs view + Show = All).
- Help guide: new `find-the-big-jobs-with-thin-margins.md`.
