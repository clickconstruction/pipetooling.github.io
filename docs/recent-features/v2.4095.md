# v2.4095 — The home-screen icon stands clear of the glass (2026-09-28)

Owner-reported: on his iPhone (iOS 26) the ClickTooling web-clip icon looked fuzzy toward the bottom while every native icon was sharp. Static asset + script; no app code, no migration.

## What was going on

- The shipped `public/apple-touch-icon.png` was not the problem: it was byte-identical to a fresh Chromium render of `favicon.svg` at 180 px, with clean one-pixel anti-aliasing, and 180 px is the exact home-screen size on a 3× iPhone.
- The phone was. In the owner's screenshot the gear — one flat ink, symmetric top to bottom — read at luminance ~30 at the top tooth and ~75 at the bottom tooth, with a sharp ~2 px edge at the top and a ~10 px ramp at the bottom. iOS 26 composites its Liquid Glass material over a flat web-clip icon (native apps ship layered Icon Composer icons, so the glass sits above the art); the lens band along the lower edge lifts dark ink to grey and smears it. The bottom tooth sat 12% from the edge, inside the band. There is no opt-out for web clips.

## What shipped

- **`scripts/generate-app-icon.mjs`** (`npm run gen-app-icon`) — renders `public/favicon.svg` with Playwright's Chromium (already installed for the e2e suite) to `public/apple-touch-icon.png`: corners squared (iOS masks the tile; transparency renders black), the mark's outer group rescaled from the SVG's 0.72 to `MARK_SCALE` 0.62 of the tile (bottom tooth now 19% from the edge), 1024 px. The script refuses to run if the SVG's transform line it rewrites has moved.
- **`public/apple-touch-icon.png`** — regenerated: 1024×1024 opaque RGB, 25 KB. Same filename, so the help share-card shell, the web-push icon in `sw.ts` and the manifest re-point on their own.
- **`public/favicon.svg`** — comment only: it no longer claims the PNG is "this same art at 180". The favicon itself (browser tabs, no glass) and the CountTooling / Takeoff Tooling marks keep the 0.72 framing.
- **Docs** — the `public/` tree in [`PROJECT_DOCUMENTATION.md`](../PROJECT_DOCUMENTATION.md).

## To see it

A phone that already has the icon keeps the old bitmap; remove it and Add to Home Screen again. A ten-second check on any iOS 26 phone that the smear is the glass: Settings → Accessibility → Display & Text Size → Reduce Transparency.
