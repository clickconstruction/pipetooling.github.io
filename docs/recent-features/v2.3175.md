# v2.3175 — Price requests on a bid: the table under Plans in Edit Bid (2026-09-09)

Migration `20260909001806_bid_rfqs_outside_links.sql` — **push after this client deploys** (the client reads the legacy shape until then and hides "Add a request" behind a one-line notice). Owner approved the design 2026-09-08 (artifact *Price Requests on a Bid*), with one change from the first draft: the date column is **Requested** (the day the request went out), with needed-by folded under it.

## The ask

"For every bid, in the edit bid modal, I would like to add a table below plans an estimator can add to for RFQs where the estimator can choose (or add) a supply house and link their RFQ and a supply house could have multiple RFQs and we would like to add a link for at least two columns."

## What shipped

- **[`BidPriceRequestsTable`](../../src/components/bids/BidPriceRequestsTable.tsx)** (new) — rendered by `BidFormModal` under the Job Plans / CountTooling Plans row (saved bids only; a new bid has no id yet). One row per request, grouped under its supply house (first row carries the house name and default rep; later ones read "↳ another request"). Columns: **Supply house · Requested · Request · Quote · actions**. The header counts houses, requests and quotes in, and links to the desk on Pricing.
  - **Requested** — the day it went out (`created_at` for app rows, `requested_on` for outside ones) with who asked and the needed-by beneath: green tick once a quote is in, amber while waiting, amber "late" past the date.
  - **Request** — app rows: the vendor's quote page (`https://clicktooling.com/q/<token>`, the same link the desk copies) tagged *sent by app*, with viewed / not viewed / closed; outside rows: the pasted link labelled by host ("Request (Drive)") tagged *sent outside*.
  - **Quote** — a quote plugged in on Pricing shows "Quote · N lines" (opens Pricing) with received / valid-to; a pasted link shows "Quote (Drive)"; empty invites a paste (outside rows) or says "plug it in on Pricing when it lands" (app rows).
  - **Actions** — app rows: Copy link + Desk / Compare (opens Pricing); outside rows: Edit / Remove (confirm; nothing is sent to the vendor).
  - **+ Add a request** — for requests sent by email or phone. Picks a house from the supply-house roster (the bid's trade first via `housesForBidTrade`, "show all · N other-trade houses hidden", default rep shown, "no rep on file" flagged) and can **add a new house in place**; a date (defaults to today), a request link and a quote link (both optional, both validated as web links). It never sends — the app's own requests keep going through Send price requests.
- **[`bidPriceRequests.ts`](../../src/lib/bids/bidPriceRequests.ts)** (new kernel, 12 tests) — grouping (houses alphabetical, newest request first, drafts skipped, house-less rows kept by the name they carried), requested date per row kind, needed-by state, the quote cell (plugged-in beats pasted), vendor page URL, link host labels, link normalization (`mailto:`/other schemes rejected; bare domains get `https://`), and outside-row validation.
- **Migration** — `bid_rfqs.sent_via` (`app` | `outside`, default `app`), `requested_on` (date), `request_url`, `quote_url`; checks that `sent_via` is one of the two and that outside rows carry no token. Existing RLS (pricing sharers: office roles + estimator) covers writes. [Fragment](../migrations/20260909001806_bid_rfqs_outside_links.md).
- **Pricing desk** (`RfqDeskModal`, `rfqDesk.ts`) — outside rows appear beside the app's, tagged *sent outside the app*, with their request / quote links and "Quote in" / "Waiting on the vendor" instead of the email trail; `canNudge` refuses them ("nudge from your own email"); no Copy link / Close link. The desk's select widens to the new columns with a fallback to the pre-push shape, and reads the house name through `supply_houses` for rows that never had a `sent_to`.
