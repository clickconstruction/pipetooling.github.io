**Three things a mover should know.**

- **Effect order.** The form's nine effects now run together at the hook's position. Before, the job-account lookup ran ahead of the tab's mount effects and the job search ran after the aging windows' effects. None of them reads what the others write, so the order between the two groups does not matter; the order inside the hook is the order they were written.

- **One dependency added.** The focus effect names `agingCellFormFocusRef` in its dependencies now that the ref arrives from the host. A ref's identity never changes, so the effect runs when it always did.
