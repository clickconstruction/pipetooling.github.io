# v2.6282 — Documents → Photos: Open the job closes the viewer (punch list #232, PR 4) (2026-11-01)

The live walk of v2.6270 on clicktooling.com found one wrinkle: **Open the job** in the photo viewer (`UploadedPhotoViewer`) opened the job window through `useJobDetailModal`, but the viewer's shell stacks above the job window, so the window opened underneath it and the person saw the same photo until they pressed Close. `DocumentsPhotosTab`'s `openJob` now sets the open index to null before it opens the job (or navigates to `/jobs?jobDetail=<id>` where no job-detail context is mounted); the row's job press, where no viewer is open, is unchanged. The render smoke `DocumentsPhotosTab.render.test.tsx` holds it: open the viewer, press Open the job, the viewer is gone.
