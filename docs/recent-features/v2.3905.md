## Why

`DashboardMyTimeDayEditorModal.tsx` writes `clock_sessions` — payroll hours — and the functions that decide what a save writes and which clusters it writes sat at module scope in the component, unexported and untested. The map ranked them first: `canSave`, the dirty gate and every branch of the persist ladder hang off `buildPayloads`, and the ladder's move to `lib/` (step 6) wants them pinned before it starts.

## Found on the way (not changed)

`noteOnlyApprovedSafe` can never be true for a cluster of two or more rows: it wants a single payload, and a single-payload split has two boundaries where `boundariesMatchOriginalRows` wants one per row seam. So a note-only edit on an approved multi-row cluster still raises the approved-hours confirm, and the ladder's branch 4 "boundaries match original rows" arm is unreachable. The tests pin today's behavior; whether the confirm should show there is an owner call.
