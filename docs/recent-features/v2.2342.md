# v2.2342 — Settings → Usage: the measurement readout (dev only) (2026-08-26)

Owner request: one place to see all the CX-measurement counting, mockup-first
(approved on the design canvas), with a by-role → by-person drill-down.

- **Migration `20260826161242`**: four SECURITY DEFINER reader RPCs, each
  self-gating on `is_dev()` (RAISE otherwise), EXECUTE granted to
  authenticated only (revoked from public/anon), `p_days` clamped 1..365:
  - `usage_page_minutes` — role × page minutes + distinct people
    (`user_app_activity_page_daily` ⋈ `users`).
  - `usage_user_minutes` — user × page minutes + active days (name falls back
    to email when blank) — powers the People view.
  - `usage_nav_clicks` — role × control × target clicks (`ui_nav_clicks`).
  - `usage_customer_views` — weekly portal loads (`public_page_views`) UNION
    weekly estimate opens (`estimate_customer_events.public_link_view`).
  Aggregate shapes were validated read-only against prod before the migration
  was written. Details: `docs/migrations/20260826161242_usage_dashboard_rpcs.md`.
- **Kernel `src/lib/usageDashboard.ts`** (9 tests): role-filtered top pages,
  control totals with friendly labels, dock-section ranking, Needs You stats
  (actions/skips/mode switches), quiet-pages list (<30 min), weekly customer
  series, and `peopleBreakdown` (role → person → top pages, bars pre-scaled).
- **`SettingsUsageTab`** in a new dev-only `settings-usage` group (System
  zone, between Company and Data & recovery — `settingsGroups.ts`):
  Overview view = four panels (time by page with role filter chips +
  show-all, clicks by control + dock ranking, customer opens with weekly
  mini-bars, quiet pages + Needs You engagement); People view = role groups →
  expandable persons → their top pages. Range chips 7/30/60. Every panel
  degrades to a quiet note when its series is empty, plus one honest error
  line when the RPCs are missing entirely (verified pre-deploy).
- Charts are plain CSS bars on theme tokens; saturated fills only
  (blue time / violet clicks / green-blue customer bars).
