# v2.3215 — Edit Bid: the Project link moves to the top right, small (2026-09-10)

Client only; no migration.

## Why

The linked **Project** (the job several bids and estimates roll up into) sat as a full-width field directly under Project Name on every bid form, at the same visual weight as the fields people fill on every bid. It is rarely used and it is an overarching thing about the bid, not a detail of it. Grace: "moved up to the top-right and made small since it is rarely used and an overarching concept."

## What shipped

- `BidFormModal` header: the right cell now holds a compact **Project** control — a tiny uppercase label over a small `SearchableSelect` (reads *Not linked*, muted, until a project is picked; the one-tap *Suggested: link to …* button still appears under it when the free-text name matches a project). On the standalone modal the ✕ sits to its right; embedded in the Bid window (Bid · Edit tabs) it is alone at the top right. On phones the label hides and the control narrows.
- `SearchableSelect` gains `triggerStyle` — style overrides merged onto the closed trigger button — so a caller can size the control without a second component. Existing callers unchanged.
- The full-width Project block under Project Name is gone; nothing else in the hero grid moved.
- Help guide `link-bids-and-estimates-to-a-project.md` points at the new spot.
