# v2.7964 — Lien desk: scan a divider to enter that envelope's certified mail number (2026-11-19)

## Why

The owner, 2026-11-19, of the divider in front of each envelope: "Do you think it would be smart for us to offer a QR code to scan on to that page so that as soon as someone got a certified mail tracking number, they could enter it right there into the app?" Then: "Yes, build it".

The notice run's sheet has carried a code for each row since v2.7328 (`lienRunMailCode`). The copies' mail sheet and dividers had none, so a number went from the label to the sheet's boxes by hand and from there into the app later, with the lien and the envelope found by eye.

## What changed

- **A code on each divider** (`drawCode` in `lienServePdf.ts`, 84 points square, right of the ticks) with *Scan once this envelope is mailed.* It opens `lienServeMailLink(jobId, recipient)`: `/lien-desk?copies=<job id>&to=owner|contractor`.
- **A code on the mail sheet**, in the steps box (60 points), with *Scan to enter the numbers*. It opens `/lien-desk?copies=1`, the list.
- **The link names a job and whose envelope and nothing else.** The desk asks for a sign-in, so a page left on a desk gives nothing away.
- **The door** (`lienDeskRoute.ts`: `copies` on the desk's address, consumed once by `LienDeskPage` like `scans`): the Board opens *Filed liens: copies to mail* on the landing `lienServeCodeLanding` gives, one envelope's number box with the cursor in it, or the head of the mail numbers. The office alone, as every door to that window is.
- **The day is said before a number is typed.** A lien's first number ticks **Mailed** and writes the **Mailed on** day at once, and a code is scanned the moment a label is in hand. So the lien a code opened says, above its number boxes, *The first number marks this lien mailed on Nov 19. Mailed another day? Change Mailed on at the top first.* (`LIEN_SERVE_NUMBERS_WORDS.codeDay`, on a landing with `fromCode`, while the lien is not mailed).
- The codes are drawn as filled runs, not a picture, so they print sharp. An address too long for a code draws none, and no words about one.
- The five boxes under each line of the mail sheet stay: paper is the backup.

## Not in this change

The phone's camera reading the label's barcode into the box. The number is still typed, or scanned with a handheld scanner.

## Tests

`lienDeskRoute.test.ts`: the door written and read, an unknown reader, the list. `lienServeStage.test.ts`: the landing a code asks for. `lienServePackets.test.ts`: the link, and each sheet line's own. `lienServePdf.test.ts`: the sheet's code and a divider's read back off the drawing, module for module, against `qrMatrix`, and none for an empty address. `LienServeWindow.render.test.tsx`: the cursor and the day's line on a code's landing, and no line on any other.

Checked outside the suite: the two codes on a rendered page read back to their links with the project's own reader (`@zxing/library`), and on the dev server a divider's link opened the window with the cursor in that envelope's empty number box and the day's line above it. Nothing was typed.
