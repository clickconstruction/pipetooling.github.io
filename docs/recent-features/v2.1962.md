# v2.1962 — Roadmap picker cleanup + archived member names (2026-08-21)

Two user-reported roadmap chrome items.

- **"New roadmap" inside the picker**: `ChecklistTechTreeRoadmapBar` drops
  the standalone button; the select gains a disabled divider +
  `＋ New roadmap…` sentinel option (`__new__`) that calls
  `onCreateRoadmap()` without changing the controlled selection. The select
  also drops `minWidth: 200` for natural width (sizes to its longest
  option).
- **Members modal UUID bug**: members whose accounts are archived rendered
  as raw user ids — the tab's `users` query excludes `archived_at` rows.
  `ChecklistTechTreeRoadmapMembersModal` now lazily fetches names for
  member ids missing from the list and labels them "(archived)"
  ("former member" if the row is gone entirely); never renders a raw UUID.
