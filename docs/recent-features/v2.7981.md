# v2.7981 — Maps: every Google map on the screen hears a refused key (2026-11-19)

Punch list [#387](../../to-dos/painted-maps-on-google.md), ahead of step 2. A painted map's Google canvas needs the same doors to Leaflet the pins canvas has, so they move to one place first. One of them is also mended on the way. Client only: no migration and no function.

## The wrinkle

A refused key does not fail Google's script. Google paints a grey map and calls one global, `window.gm_authFailure`. `PinsMapGoogleCanvas` put its own function there when it mounted and put the old one back when it left.

A global holds one function. With two Google maps on the screen, only the one that mounted last was told, and the first stayed a grey Google map. If the first then left before the second, it put back the function from before either, and the second was cut off too.

Seven maps draw on Google and they rarely share a screen, so this was not seen. A painted map's window opens over whatever asked for it, and the page behind can have a Google map of its own. That is the case step 2 makes.

## What changed

- **`src/lib/map/googleAuthFailure.ts`** (tested): the global is set once and every canvas asks to be told (`onGoogleAuthFailure`). A canvas takes only its own listener away, so leaving in any order is safe. A function that was on the global before is still told, and one refusal is told once however the functions call each other.
- **`src/hooks/useGoogleCanvasDoors.ts`**: the load timeout, Google's own word and the paint clock for one canvas, with `useFrameInView` and `useStampedTheme`. Moved from the pins canvas as they were. The clock still counts only while the frame is in the window (v2.7876).
- **`src/components/map/GoogleCanvasBoundary.tsx`**: the boundary that catches an exception while a canvas draws, moved the same way.
- **`PinsMapGoogleCanvas`** reads all three and keeps nothing of its own. Its words to the screen are the same four reasons, letter for letter.

## Not changed

- The 10 s load timeout, the 8 s paint clock, the reasons' words, and the frame's rule that a failure is kept for the page.
- `PermitSkimGoogleStill` still sets the global by hand, calling the function it found. It works beside the new module, which a test stands in for. Moving it is a follow-up, left alone here because the Permits screens are being worked on.
