# v2.3295 — Bids → Labor: DIRECT COSTS as one list with a kind chip (PR 4b of the Labor refresh) (2026-09-11)

Client only. The second half of rung 4 in [`to-dos/bids-labor-refresh/`](../../to-dos/bids-labor-refresh/README.md).

## What shipped

- [`BidsDirectCostsSection`](../../src/components/bids/BidsDirectCostsSection.tsx) (+3 render tests) replaces Region L5's five cloned amber sections (~366 lines of JSX) with one list: a kind chip (`equipment` · `permit` · `sub` · `waste` · `other`), the note, the three stage amounts, remove; a kind picker beside **+ Add**; one **Other direct total** line with the per-kind words; the empty state is one sentence. The computed **driving** line sits on top, read-only, in crew-day words (*88 crew-days · 176 trips (8 h each) · 41 mi · $0.70/mi*), off `computeBidCostBreakdown` with the tab's $/mile and hours-per-trip boxes.
- [`costEstimateDirectCosts.ts`](../../src/lib/bids/costEstimateDirectCosts.ts): `DIRECT_COST_KIND_LABELS` (the old section names, kept for aria labels and chip titles) and `flattenDirectCostTables` (+1 test) — kind order, then each table's sequence.
- [`BidsLaborTab`](../../src/components/bids/BidsLaborTab.tsx): the five tables' existing add / update / remove handlers are wired through a `directCostHandlers[kind]` map, so **the tables stay** and every write goes where it always did; cell save-state keys are `${kind}:${row.id}:${stage}` (`sub:` replaces `subcontractor:`). Renders for both Old and New.

## Not in this PR

Changing a row's kind in place (it would be a delete + insert across tables — add when someone asks); driving *from* crew-days × trips per day (the to-do's deferred decision).

## Verified

Render + kernel tests; typecheck; lint; theme. Live on dev against prod (BP398): a sub line added from the list lands in `cost_estimate_subcontractor_rows`, edits autosave, remove deletes it; the New view's Other direct tile and bottom line follow — see the PR comment.
