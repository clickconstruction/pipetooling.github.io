# v2.7135 — legal-portal under the 5 MB deploy limit (2026-11-13)

On 2026-11-12, while deploying v2.6986, `supabase functions deploy legal-portal` was refused with HTTP 413: "Function source code exceeds the maximum deployment size (5 MB)". The CLI uploaded 336 files, about 4.74 MB. On 2026-11-13, on a newer main, it uploaded 257 files (4.21 MB) and went through, so the margin had come back by chance.

## The cause

`legal-portal` imported `_shared/customerSampleFixtures.ts` for one function, `sampleLegalPortalResponse`, the answer to the sample token. That file holds every portal's sample, and its imports (`gcPortal.ts`, a type import of `gcCustomerSchedule.ts`) reach the GC kernels copy and, through 33 type imports in that copy, `src/types/database.ts` (1.46 MB). The CLI uploads type-only imports too. About 4.0 of the 4.21 MB came in through that one import.

## What changed

- **`_shared/customerSampleLegal.ts`**: the legal sample (`SAMPLE_FIRM`, `sampleStatutoryFifteenth`, `sampleLegalPortalResponse` and the helpers only they use), moved verbatim with a scripted cut, and the `SamplePortalCompany` type. Its one import is `ymdPlusDays` from `customerSample.ts`.
- **`_shared/customerSampleFixtures.ts`** re-exports all of it, so the app, the tests and the other portals import as before.
- **`legal-portal`** imports the sample from the new file: 23 files, 0.22 MB.
- **`scripts/lib/edgeUploadGraph.mjs`**: what a deploy uploads for each function, largest first (`node scripts/lib/edgeUploadGraph.mjs [slug …]`). It matched the CLI's own `--debug` list for legal-portal file for file. `src/lib/edgeUploadGraph.test.ts` pins the walk and holds legal-portal under 0.5 MB, clear of the fixtures, the kernel copy and the generated types.

## Still near the limit (2026-11-13)

`dev-mcp` 4.71 MB (it deployed at about that size on 2026-11-12; `src/types/database.ts` arrives through `devMcpBidLabor.ts` → the kernel copy), then the eight functions that serve a portal sample through `customerSampleFixtures.ts`, about 4.04 to 4.11 MB each: `customer-portal`, `sub-portal`, `get-contract-for-signer`, `get-submittal-room`, `get-estimate-for-customer`, `get-bid-proposal-room`, `get-job-contract`, `get-rfq-quote-page`; then `photo-save` 4.01, `drive-link` 3.92, `submit-portal-request` 3.88, `gc-customer-email` 3.82 and `gc-trade-portal` 3.81. The shared cause is the kernel copy's type imports of the generated database types.
