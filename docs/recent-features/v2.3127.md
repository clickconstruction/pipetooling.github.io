# v2.3127 — Stage Plan PR 3: the Multiple Segment Generator carries kinds (2026-09-08)

Third PR of the train in [`to-dos/stage-plan/`](../../to-dos/stage-plan/README.md). Client only. The owner's line: "the Multiple Segment Generator will need to be updated to accommodate this."

## Kernel — [`segmentGenerator.ts`](../../src/lib/jobs/segmentGenerator.ts)

- `SegmentGeneratorRow` gains `kind` (`order` / `any` / null) and `amount`. **Order rows are shares of the total** (pct); **Any and plain rows carry their own amount, outside the split.** `segmentGeneratorAllocatedPct` counts Order rows only; `segmentGeneratorDollarsByRowId` gives own-amount rows their amount and still lands the cents remainder on the last Order row.
- Presets carry `kind: 'order'` and a `hint` ("4 in order" / "3 in order"); `CHANGE_ORDER_ROW` is the **+ Change order** preset (Any, no price yet).
- New `segmentGeneratorTotals` → `inOrderDollars` / `outsideDollars` / `jobTotalDollars` and the named-row counts by kind — the allocation line and the summary line.
- `SegmentGeneratorPayloadLine.stage_kind`: Add to Job appends each line with its kind (the modal's `addGeneratedSegmentsToJob` spreads the line onto the `FixtureRow`, so nothing else changes).

## Modal — [`MultipleSegmentGeneratorModal.tsx`](../../src/components/jobs/MultipleSegmentGeneratorModal.tsx)

- A **Stage** column with the shared `StageKindSelector` on every row; a small badge at the left (the row's number among Order rows, a diamond, a dashed circle). Flipping a row out of the split keeps its current dollars as its own amount; flipping it back clears the amount.
- Order rows: the `%` input and a computed value. Any / plain rows: a dashed `—` where the percent was and a `$` amount input.
- Preset chips carry their hint; a preset replaces the split and keeps any change orders / plain lines already typed. **+ Change order** appends an Any row (dropping untouched blank rows).
- Allocation line: `100% allocated · $41,550.00 in order · $1,850.00 outside the split` (amber with the usual nudge when the Order rows don't total 100%; "No split" when there are none). Summary line: `4 in order · numbered top to bottom  1 any time · its own price, not a share  1 plain line · bills with the final draw  Job total $43,400.00`.
