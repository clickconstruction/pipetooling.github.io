# v2.2393 — Workbench: per-row Apply margin, ⓘ-only breakdown, currency price cells (2026-08-27)

Wendi's feedback round on the New (Workbench) pricing view, all in
`BidsPricingTab.tsx`:

- **Apply margin column** ("are we able to bring the apply margin button over
  to the new pricing sheet?"): the Old grid's per-row margin chips (v2.1772)
  now render in the Workbench grid too — the most recent margin as a one-tap
  pill plus the "…" picker (recents with price previews + custom). Reuses
  `applyMarginToSingleRow`, `recentMargins`, and the existing picker modal
  verbatim; always on in the New view (no Margin-mode toggle there). The
  single-row apply now also drops the row from any pending solver preview
  (mirroring `commitWorkbenchTypedPrice`) so a later Apply can't overwrite a
  just-applied price.
- **Breakdown is a button, not the row** ("this window keeps popping up when i
  dont ask it to"): the `<tr>` no longer opens the Margin-breakdown modal on
  click; a ⓘ button in a new trailing column is the only opener. Clicks that
  miss an input while rapid-typing prices no longer interrupt.
- **Sale price/unit reads as currency** and **typing overwrites**: idle cells
  show `$1,410.00` (`formatCurrency`); focus seeds the raw number into
  `wbPriceDrafts` and selects it. The select-all now survives slow clicks —
  `onMouseDown` marks a first-focus, `onMouseUp` swallows that one caret drop
  (the old deferred `select()` lost to any mouseup that landed after it, which
  is why typing appended to the stale "0"). Same guard on the
  Revenue/Profit/Margin solve cells.

No schema changes. Help guide `price-a-bid-with-the-workbench.md` updated
(Apply margin + ⓘ breakdown paragraphs).
