## Why the search text stays with the page

The map's list of cuts says this one carries "its state with it", but moving the text into the section would change what people see. While the Hours tab loads, the page swaps its whole content for *Loading…*. That happens on every week change and every return to the tab, and it unmounts the section. The text lives in the page-level hook, so today it survives that, and a search for someone stays put while you step through weeks. Only the lists derived from it moved.
