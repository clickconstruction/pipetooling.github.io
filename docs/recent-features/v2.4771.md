## What changed

- **The precinct travels with the property record.** `LIEN_BOOK_ADDRESS_COLUMNS` (and so the matter's address columns) add `jp_precinct` and `jp_precinct_note`; the book's job (`LienBookJob.precinct` / `precinctNote`), the packet's property line (`LegalPropertyLine.precinct` / `precinctNote`) and the payer (`account.customerPrecinct`, from its primary record) carry them. Until the function is redeployed the page reads them as blank, as before.
- **The Lien grid's Court column** reads *Guadalupe · JP Pct 2* in place of the red `?`; a property on a line reads *JP Pct 2 or 3 — on the line*.
- **Where to file** on the matter and the printed packet read *Guadalupe County · Justice Court, Precinct 2* for the work and for the defendant, each from its own record; the `?` stays only where the map has not placed one.
- **The property record** (`CustomerPropertyRecordPanel`) gains a **Justice precinct** field under the county, with its source beneath: *from the office's court map · type over it to settle it by hand*, *typed by hand · the map never changes it*, or *not yet …*. A typed value saves as `hand` and clears the on-the-line note; a map value passes through untouched; an empty one clears all three (`payloadFromDraft`, `precinctSourceWords`). `PropertyRecordFields` carries the two fields as optional, so older callers are unchanged.
- **The sample** matter's property carries precinct 2, so the sample portal shows the whole thing.

## Is this the best we can do?

- **One record, every reader.** The precinct sits on the property record beside the county and the parcel, so the grid, the matter, the print and the office's own sheet read one answer.
- **The map fills, a person settles.** The nightly writes `map`; a person's typing writes `hand`, which the map never overwrites — the on-the-line note is the question, the typed value is the answer.
- **Not done: the Legal desk's gap row.** The desk's preview is the firm's view, so the red `?` already shows the office what the firm sees; a gap row in the attorney-ready check can come once the layer is drawn and the misses are few.
