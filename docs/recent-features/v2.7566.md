# v2.7566 — Job notes: the tag box is easier on a phone (2026-11-17)

Punch list #375, PR A of six: the easier box. The owner asked on 2026-11-16 for tagging in task notes, and for the box to be more fluid on a phone. This PR is the box alone, shared code, so job notes get it today and task notes will be born with it. Client only: no migration, no edge function.

## What a person sees

- **The names are presses.** Typing `@` opens a row of name presses at the box, each at least 44 px high with what the person does under the name. The small list with its group headings is gone. A press is taken on `pointerdown` with its default prevented, so the box keeps its focus and a phone's keyboard stays up.
- **The row runs through a space.** `@chris b` still offers Chris Bell and Chris Bellamy. `@will call` offers nobody, and letters that are nobody's name, as in `@home`, show no row at all.
- **The tag is marked in the words.** A layer under a see-through box tints each live `@Full Name`, and underlines the `@` being typed while names fit it.
- **One Backspace** right after a tag takes the whole name off. The *Will tag* line and its × stay.
- **The asker is offered in an answer box** before a letter is typed, after the word *Tag*. A job's own box offers nobody until `@`, since a crew can be ten names.
- **After a pick the box shows the name.** A one-line box that had slid sideways now slides to its end.

## The rule that did not change

The owner's call 0 of 2026-11-16: a tag is a tap or Enter, never a typed word. Typing a full name makes no tag. Changing a letter inside a tagged name takes the tag off, and typing it back does not bring it back.

## How it is built

- **`src/lib/jobs/noteTags.ts`**, 70 tests: `tagTypingAtCaret` reads the `@` at the caret by shape, through spaces. `tagNameQueryAtCaret` is the second function the card planned, beside `tagQueryAtCaret`: past a space it stays a query only while the words start somebody's full name, and it leaves a made tag alone. `nameMatchesQuery` fits a spaced query to the start of the whole name. `insertPick` takes the open row's `@`. `backspaceTag` is the Backspace rule, and `backspacedTag` reads the same from a change. `draftMarkParts` cuts the words into runs for the layer.
- **`useNoteTagBox`** (`NoteTagBox.tsx`): the presses, the `offer` option, the picks pruned to the names still whole in the words, and a new `mark` node.
- **`NoteTagMarkLayer.tsx`** (new): the layer. It copies the box's font and padding from its computed style, sits over the box's own text area, and follows `scrollLeft` on a one-line box and `scrollTop` on a taller one.
- **The four boxes** draw `mark` right before their input and put the input over it: the Pipeline row's box, the floating window's, the answer box, and the job window's taller box, whose background moved to a wrapper so the box can be see-through.

## A phone keyboard that names no key

Some Android keyboards report every key as *Unidentified*, so the Backspace cannot be caught on the key. For those the hook reads the change instead: one character gone right after a live tag takes the whole tag. A named key never takes this path, so a forward Delete is an ordinary Delete.
