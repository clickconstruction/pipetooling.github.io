# v2.4565 — Lien screens: four labels say what happens (2026-10-05)

Client only; no migration, no edge function. Rows 11, 14, 20 and 22 of the lien defects card (punch list #83, [`to-dos/lien-defects.md`](../../to-dos/lien-defects.md)): four places where the words and the code disagreed. One PR because each is a line.

## What changed

- **Row 20 — the Pipeline row's blue box.** The release icon's tooltip reads *This job has an issued lien release*. [`useStagesRowFlags.ts`](../../src/hooks/useStagesRowFlags.ts) counted every live row of `job_lien_releases`, an autosaved draft included. The read now takes `status` and leaves drafts out, so the box means what it says. Here the code moved to the words.
- **Row 11 — Payment forecast, *Send notice…*.** The tooltip named the Lien instruments window. The button has opened the Lien desk on that job since v2.3405. The tooltip (and the prop's comment) in [`ForecastWorkMonthsPanel.tsx`](../../src/components/jobs/ForecastWorkMonthsPanel.tsx) say so.
- **Row 22 — Legal desk.** The header said *Settings → Jobs & dispatch*; the section is *Jobs & billing* (`settingsGroups.ts`), as the sheet lower in the same window already said. [`LegalDeskModal.tsx`](../../src/components/jobs/legal/LegalDeskModal.tsx).
- **Row 14 — the job's Lien window, Mechanic's lien.** The line under the checklist said each ✗ item *links back* to its fix. The items are plain text. The line in [`LienFilingTabs.tsx`](../../src/components/jobs/LienFilingTabs.tsx) now says where each fix lives and promises no link.
