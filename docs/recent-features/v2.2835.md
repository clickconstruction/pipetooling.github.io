# v2.2835 — People → Feedback refresh: one table, one feed (2026-09-05)

Owner disliked the v2.2824 tab's look and flow (boxed header with a checkbox under the tab's own header; five pills; **Who's due** as a button → modal → 22 rows each repeating "disabled in settings"). Proposal eb722fda option A, approved: one page.

- **Status strip** ([`FeedbackStatusStrip`](../../src/components/team-feedback/FeedbackStatusStrip.tsx)): a real `role="switch"` for `team_feedback_settings.enabled`, one sentence for the state (on: "Everyone who clocks out is dealt the deck every N days"; off: "Nobody is dealt the deck… Last deck: never"), three counts (due now · rated this month · words this month), **Try the deck** as the primary button, a gear.
- **One people table** ([`FeedbackPeopleTable`](../../src/components/team-feedback/FeedbackPeopleTable.tsx)) over the kernel [`feedbackTabRows.ts`](../../src/lib/people/feedbackTabRows.ts) (tested): one row per active account — **Deck** chip (`deckStateFor` over the existing `computeTeamFeedbackEligibilityDetail`: Off · Due now · Never dealt · due · Done/Skipped · Nd ago · Snoozed → date), **Crew** mini bars with the office lane faded under each (`summarizeCrewSubject`), a `split on Drive` chip at a 15-point gap, `N crew · M office`, words count. Filters with counts: **Clocks out** (default — anyone with an approved job session in 90 days via `list_team_member_recent_jobs`, plus anyone already rated or with words), **Due now** (hidden when off), **Has words**, **Everyone**; search by name or role. Rows sort due → snoozed → done → off, then name. Cards under 640px.
- **Person drawer** ([`FeedbackPersonDrawer`](../../src/components/team-feedback/FeedbackPersonDrawer.tsx)): crew over office lanes, crew notes, their own open words, the dev-only **Who rated** list, and **Reset cycle** (`resetTeamFeedbackUserStateEligibilityForDev`; shown only when on and the person is not already due). Escape / backdrop closes.
- **Open words feed** ([`OpenWordsFeed`](../../src/components/team-feedback/OpenWordsFeed.tsx)): newest first, **Unread · n / All · n** with a device-local read marker (`people.feedbackWordsReadAt.v1`), **Mark all read**, writer's name opens their drawer.
- **Gear drawer** ([`FeedbackSettingsDrawer`](../../src/components/team-feedback/FeedbackSettingsDrawer.tsx)): the existing `CrewFeedbackSettingsForm` plus `RetiredQuestionsPanel` folded in a `<details>`.
- **Settings → People & accounts**: `TeamFeedbackDevSettingsBlock layout="settings"` is now a one-line pointer to People → Feedback — one home for the switch.
- **Deleted**: `TeamFeedbackEligibilityOverview` (its state logic became `deckStateFor`), `CrewRatingsPanel`, `OpenWordsPanel`. No migration; the six loads run in one `Promise.all`.
- Docs: `ACCESS_CONTROL.md`, `PEOPLE_TABS_ARCHITECTURE.md`, `SETTINGS_TABS_ARCHITECTURE.md`.
