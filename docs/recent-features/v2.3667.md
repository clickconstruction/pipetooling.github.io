# v2.3667 — Property kind in one click: Residential or Commercial, asked where it matters (2026-09-21)

Client only; no migration, no edge function. Mock-up with the before and after: the Claude artifact *Property Kind, One Click*. Approved as drawn.

## Why

The owner, on the claims table shipped in [v2.3665](./v2.3665.md): *"Where it says kind unknown, set it opens up the job modal, but I don't see an easy place for a user to set a commercial or residential property."* There was none. Edit Job's **Property record** row was an address picker — it chose *which* `customer_addresses` row the job sits at and said *✓ lien-ready* (`customerAddressLienReady` does not read the kind). The kind itself (`customer_addresses.property_kind`, which `lien_notice_deadline` reads) could only be set on the customer's property sheet: Customers → the customer → Properties → the property → Property record. Two doors promised otherwise and dropped the user at the top of Edit Job: v2.3665's *set it ›* and the Lien desk's older *Set property kind ›*, whose tooltip said "Edit Job → Property record: residential or commercial".

## What shipped

- **Kernel** — [`propertyKind.ts`](../../src/lib/jobs/propertyKind.ts) (4 tests): `normalizePropertyKind`, `propertyKindWords` (the lien screens say *commercial*, the property sheet says *Non-residential* — each screen keeps its word), `propertyKindPatch` (a non-residential pick clears `homestead`, as the sheet does), `jobsSharingProperty` + `sharedPropertyWords`. IO in [`propertyKindWrite.ts`](../../src/lib/jobs/propertyKindWrite.ts): `savePropertyKind`, `savePropertyHomestead` — the same column the sheet writes, so there is one truth.
- **[`PropertyKindSwitch.tsx`](../../src/components/jobs/PropertyKindSwitch.tsx)** — a two-part switch: amber while unanswered, the picked half filled (literal fill, v2.3656), `voice` for the word, `allowClear` where a screen offers un-setting.
- **[`GcOnNoticeModal.tsx`](../../src/components/jobs/GcOnNoticeModal.tsx)** — Step 2's Job cell: unanswered → the switch (office roles); answered → *residential · change*; jobs at the same `customer_address_id` say *same property as 273*. A pick saves, then `refetch()` brings the RPC's new § 53.056 dates — nothing is recomputed client-side. A job with no saved property has nowhere to keep the answer: *link a property ›* opens Edit Job on the row. The amber callout counts what is left and leaves at zero (it already did).
- **Edit Job** — [`JobFormEditFactRows.tsx`](../../src/components/jobs/JobFormEditFactRows.tsx): the Property record row carries a *kind not set* chip (`valueTail`) and, opened, a **Property kind** block — the switch in the sheet's words, **Homestead** beside Residential, and *Saved on the property as you pick, not on the job*. It saves immediately, like the row's **Use**, not with the form. [`JobFormModal.tsx`](../../src/components/jobs/JobFormModal.tsx) loads `property_kind, homestead` with the candidates and patches them on save; a caller that does not load the kind gets no control.
- **The door** — `OpenEditJobOptions.propertyRecordFocus` (through `JobFormModalContext` → the opener bridge → `JobDetailModalContext` → `JobWindowModal` → `JobFormModal` → the fact rows): the row opens, the block scrolls to the middle and is ringed for four seconds. The properties load after the window mounts, so the scroll fires from the block's callback ref, with a fallback to the row when no property is linked. Both lien modals' `onOpenEditJob(jobId, focus?)` pass it; the Lien desk's *Set property kind ›* is the one-line change there.
- Guides: *send lien notices from the Lien desk* (the row asks; same property; link a property) and *file a lien and never miss its deadlines* (Residential or not — on the Property record row).

## Not done, on purpose

- No *set all N* on the callout: these are different properties, and a wrong kind silently moves a legal deadline.
- No guess from the appraisal roll — a later pass, as a suggestion, never a silent fill.
- The Lien desk's gate 3 keeps its door rather than an inline switch; that pane is mid-rework in another session.
- One word for both screens (*Commercial* vs *Non-residential*) is the owner's call and still open.

## Verified
