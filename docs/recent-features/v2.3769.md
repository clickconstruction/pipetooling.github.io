# v2.3769 — A task sent from a job wears the job as a chip on every list (2026-09-23)

The follow-up v2.3751 left open (mock-up option "+", drawn as a before/after page in the session). Client only, no migration, nothing stored changes.

## What shipped

- **Kernel** [`src/lib/checklistJobChip.ts`](../../src/lib/checklistJobChip.ts): `isJobDoorLink(url)` (the path is `/jobs` and `jobDetail` is set — absolute or relative, whatever else the query carries), `splitJobLinkLabel("1016 · Mission faucet")` → the number badge and the name (`— · Job` → no badge), `dashAfterTokenLength(rest)` — the length of the ` — ` the doors store after the token, so the display can skip it. Unit tests for all three, with the two non-matches spelled out (the vehicle marker's fleet link, a Drive link).
- **The renderer** [`ChecklistTitleWithLinks.tsx`](../../src/components/ChecklistTitleWithLinks.tsx): a named token whose link is a job door renders as `JobChip` — an inline-flex anchor (number badge in the no-trade pill style, the name, a violet ↗; `data-testid="checklist-job-chip"`), `textDecoration: none` so a done row's strike-through stays on the task text, `whiteSpace: nowrap` so it never breaks inside itself and a long name truncates with the badge still visible. The dash after it is dropped and a space keeps the chip and the task apart. Every other token — `[n]`, a named token with any other link, the `{{1:vehicle}}` marker — renders exactly as before. Three render tests.
- **The badge is the plain number.** The stored title carries no trade and no task list holds a job cache, so of the three ways drawn (plain number; lookup from jobs already in memory; a fetch per list) the first is what shipped — the second has nothing to look up in and the third adds a request per list for a color.
- Because the renderer is shared, the chip lands on nine surfaces at once: Checklist → Today (row and phone card), the Checklist page's instance cards, Manage, the history ledger, Dashboard → My Inbox, the Dispatch and Estimator inbox sections, Dispatch → dismissed items, People → Review.
- **Help guide** `give-someone-a-task`: the *Send a job as a task* section now says the job shows as a chip on the lists.
