# v2.2263 — Review tab mobile polish (2026-08-25)

Owner phone screenshots (dark mode, 375px) drove three fixes in
`src/pages/Checklist.tsx`:

- **Goals segmented bar wraps** — `flexWrap: 'wrap'`, segments
  `flex: '1 0 12px'` (height moves onto the segment; `rowGap: 6` clears the
  amber current-stage outline between rows). At 50+ stages the one-line bar
  exceeded phone width and dragged the page sideways; desktop still renders a
  single full-width row. Verified: no element crosses the viewport edge at
  375px (the page-level tab bar's own horizontal scroller excepted, by design).
- **Sign-off fold title** "Checklist review — sign off completed work" →
  **"Review: completed work"** (wrapped to two lines on phones).
- **`outstandingAgeChip` fallback**: tasks scheduled today rendered a raw
  `(2026-08-24)`; now `compactTimeAgo(checklist_items.created_at)` — "2h ago" /
  "just now" — falling back to "today" when created_at is absent. The `Nd`
  severity chips for genuinely old tasks are unchanged.
