# v2.6618 — The punch list opens with a Shortlist: every open card by group, smallest first (2026-11-06)

Taunya asked, after reading the open punch list sorted small to large inside each group in a chat on 2026-11-06, to "save this as the shortlist to the top of the punchlist" so asking for "the punch list shortlist" brings it up. A pasted copy would be stale by the next retired card, so the Shortlist is a view of the cards, read from the free-text `size` each one already carries.

## What changed

- **`src/lib/todos/punchListShortlist.ts`** (pure, unit-tested): `sizeBucket(size)` reads one of `XS · S · M · L · XL` out of a card's size words — a *left:* / *leftover* clause wins (`…, eight built; left: PR 7 (S)` is S); else the biggest letter outside parentheses with a conditional clause skipped (`L as a train of six (M · M · S)` is L, `S (PR 1) + M (PR 2)` is M, `S (A) + M (B); C would be L` is M); a letter only inside parentheses still counts; no letter at all is unsized. `shortlistFrom(items)` groups the open rows (the pointer cards out) in the board's order, each group smallest first then by number, with the counts per bucket; `renderShortlistMarkdown` writes the counts and one `# · Size · Item` table per group.
- **`src/components/punchList/PunchListShortlist.tsx`**: the section at the top of `/punch-list` (`id="shortlist"`, so `/punch-list#shortlist` lands on it), under the filters and above Flagged: the open count and the counts line, the blurb, *Hide the shortlist* / *Show the shortlist* remembered per device (`pt-punch-shortlist`, storage wrapped), then each group with its swatch and a two-column list on a wide screen — `#n` as a jump to the row's anchor, the letter in a chip whose title carries the footer's working estimate and the card's own words, the name. The page's Do / Later / Drop filter and the mock-up toggle narrow it the same way they narrow the rows. `GROUP_COLOR` moved from the page into `punchListView.ts` so the section and the rows share the swatches; the footer's sizes sentence points at the Shortlist.
- **`scripts/punch-list-shortlist.ts`** as `npm run shortlist`: the same list as markdown for a chat, read from `to-dos/` the way the board is; writes nothing.
- `to-dos/README.md` says how the letter is read, so a card's author writes the whole card's letter first and names what is left when most of it shipped.

## The read on 2026-11-06

88 cards, 87 open: 5 XS · 17 S · 45 M · 16 L · 3 XL, and one unsized — #176, whose size lists five changes with no letter. The hand sort in the chat had called four cards one step larger by adding their parts up (#239, #208, #125 and #269) and guessed L for #176; the kernel takes the biggest part the card names instead, which is the rule the card's own words support, and leaves a guess to the card's author.
