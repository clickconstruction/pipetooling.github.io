# v2.5996 — A voice note drafts again: the request Anthropic accepts (2026-10-27)

Punch list #186, item 1. With the owner's key saved (2026-10-27 3:02 PM) and v2.5991's **Test the key** answering *The key works* in 1.1 seconds, the first live draft still came back 502, now with its reason: `invalid_request_error: output_config.format.schema: For 'integer' type, properties maximum, minimum are not supported`. Structured output takes a subset of JSON Schema, and `DRAFT_SCHEMA`'s line percent carried `minimum: 0` and `maximum: 100`. Every draft since v2.5916 had failed on it and fallen back to the spoken words in Notes; the tests never called the API.

## The fix

`_shared/reportDraft.ts`: the percent is `{ type: 'integer', description: 'The percent the line is at, a whole number from 0 to 100.' }`. The range was already enforced where it matters: `readDraft` clamps every number to 0..100 and drops a line not in the request, and the form's `applyDraft` moves only open lines. Nothing else changes.

## Tests

`reportDraftEdge.test.ts`: the schema holds none of the keywords structured output refuses (`minimum`, `maximum`, the exclusive pair, `multipleOf`, the length, pattern and item counts), and a percent of −5 still comes back as 0.
