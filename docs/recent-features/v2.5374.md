# v2.5374 — Lien desk: the checklist comes alive, the lanes, and the run’s bar on the desk (run train, PR 5) (2026-10-12)

Run train, PR 5 (v2.5369 kernels, v2.5370 journey, v2.5371 cards, v2.5373 foot). Three things, and a cleanup.

- **The checklist, live** (`.lienRunChecklist`, `run-checklist`): once the packet printed (`printedAt`), the run draws the printed sheet's rows above the cards from `runChecklistRows()`: one per paper envelope (email copies have none), the glyph, *N · who*, what is inside and the address, the lane's three boxes (*stuffed · slip on · mailed*; *in the truck · handed over* by hand; *label on · picked up* by courier) as the window's own ticks, and the number box. A number typed there goes through the same `setEnvelope` as the card's box, so the card, the chip, the journey and the record all see it; the row turns green when it has its number; the heading counts (*2 of 3 have their number*, `runChecklistWords`).
- **The lanes** (`.lienRunLanes`, `run-lane-<lane>`): once printed, when the envelopes travel more than one way, each way is a line under the journey — *Certified · Printed → Mailed 1 of 2 → Recorded · envelopes 1, 2*, *By hand · Printed → Handed over → Recorded · envelope 3* — from the same stage states. One way, no lanes.
- **The door's bar** (`runDoorPill` in `lienDeskRun.ts`): the desk's *Send the run · N* / *Record the mailing · N* button carries a bar (green for printed, amber for the ready notices the leader has not signed) and the words *1 sealed · 1 ready · 1 waits on Robert*, from the desk's own counts and `lienChipSigned` over the Ready pile. The words and the bar are `aria-hidden`, so the button's name stays *Send the run · N*.
- **Cleanup**: the `.lienRunTable` and `.lienRunFootHint` rules (dead since v2.5371 and v2.5373) are gone from `index.css`.

Tests: two run render tests for the checklist and the lanes (the number typed on the sheet is the card's number; nothing before the print), the pill's kernel test, the desk's render suite unchanged (103 green between the two modals). The help guide's *Sending the run* section is rewritten for the shape the run has now, and the glossary's *Lien desk* entry says where the three steps went.
