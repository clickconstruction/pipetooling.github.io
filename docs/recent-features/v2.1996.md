# v2.1996 — Order modal autosave (2026-08-21)

User request: autosave for the Order stages & tasks modal.

- Every `dragEnd` persists immediately through the existing `onSave`
  (parent still diffs via `computeStageOrderUpdates` /
  `computeTaskOrderUpdates`, so each drop writes only changed rows, and its
  `load()` refreshes the view behind the modal live).
- Saves are serialized last-write-wins via refs: a drag landing mid-save
  marks pending and the finishing save immediately re-persists the latest
  orders — never interleaved, never lost.
- Footer becomes a status chip (Saving… / ✓ Saved / retry hint) + a single
  Done button; rows stay draggable during saves. Guide step updated.
