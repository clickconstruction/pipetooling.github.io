# v2.5348 — The code that keeps a copy of each sent email passes its type check again (2026-10-12)

A type-only fix to [`_shared/fileSentCopy.ts`](../../supabase/functions/_shared/fileSentCopy.ts), the helper that files a sent email in `sent_documents` ([`SENT_COPIES.md`](../SENT_COPIES.md)). No migration and no screen. Nothing behaves differently.

- **The fault**: on `main`, `deno check` of every function that bundles the helper failed with the same two errors in it. That is 52 of the 150 functions, most of them through `_shared/resendSendEmail.ts`. The errors were TS2345 at `crypto.subtle.digest('SHA-256', bytes)` and TS2769 at `fetch(…, { body: bytes })`. Since TypeScript 5.7 a typed array carries its buffer's type, and under the TypeScript that ships with Deno 2.9 (6.0) a `Uint8Array<ArrayBufferLike>` is neither a `BufferSource` nor a `BodyInit`. `supabase functions deploy` does not type-check, so nothing failed at runtime.
- **The fix**: a local `ownBuffer(bytes)` copies the bytes into a plain `ArrayBuffer` of their own. `sha256Hex` hands that copy to WebCrypto and `put` hands it to `fetch`. It is the same helper #5452 adds to `src/lib/quo/webhook.ts`. The bytes stored, the page's hash and the row are unchanged.
- **Checked**:
  - `deno check --no-lock` of `gc-customer-email` and `gc-trade-email` went from 2 errors to 0.
  - Each of the 52 importers lost exactly those 2 errors. 41 now pass clean. 11 still fail on errors of their own in their `index.ts`, untouched here: `accept-estimate`, `mercury-webhook`, `send-physical-invoice-email`, `send-report-email`, `send-rfq-email`, `send-stripe-invoice`, `share-job-contract`, `sign-bid-room`, `stripe-webhook`, `submit-portal-request` and `test-email`.
  - Main's helper and the fixed one were run over the same email with `fetch` stubbed, three ways: everything stored, the page refused, one attachment refused. Every request matched byte for byte: URL, headers, stored bytes, the row and its `copy_hash`. Only the body's type changed, from `Uint8Array` to `ArrayBuffer`.
  - The sent-copies tests (`src/lib/sent`) pass.
- **Deploy**: a type-only change needs no redeploy, and the next deploy of each function picks it up. Until then `npm run check:edge-drift` and the Edge function drift workflow name the 52 as behind `main` on `_shared/fileSentCopy.ts`.
