- [`src/lib/people/fetchActiveUsers.ts`](../../src/lib/people/fetchActiveUsers.ts) — the matching server-side query: `activeUsersQuery(columns, { includeDev?, roles?, orderByName? })` returns the thenable builder (`await` it or hand it to `withSupabaseRetry`); `fetchActiveUsers<T>` awaits and casts. Always `archived_at IS NULL AND is_digital_twin = false`; `roles` restricts (dev unioned in with `includeDev`), otherwise `role <> 'dev'` unless `includeDev`.
