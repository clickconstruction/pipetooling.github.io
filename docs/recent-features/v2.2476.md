# v2.2476 — Bid Room live-E2E fixes: CO publish, unsplit outcomes, event telemetry (2026-08-29)

The owner asked "have you tested everything we have built?" — honest answer was no, so the
full Bid Room + Estimate Options loops ran live against prod (ZZ Test / ZZ Twin Test 1 /
LIVE TEST estimates, restored or flagged after). The rails that passed passed convincingly;
four real defects surfaced, all fixed here or in v2.2475:

1. **`doc_kind` check** (shipped separately as v2.2475/#2183): every room signature failed
   at the estimates INSERT.
2. **CO publish was impossible** — the "Publish to bid room" door did a client-side
   draft→sent UPDATE, which `estimates_update_draft`'s WITH CHECK (status must stay draft)
   rightly refuses. New SECURITY DEFINER RPC **`publish_co_to_bid_room`** (migration
   `20260829012943`; role-checked inside, validates CO/room/bid linkage; the read-only
   statement trigger covers training mode) + the door now calls it. Also widens the room
   events CHECK for `document_published`.
3. **`estimates_sent_requires_token`** (baseline) rejected room COs — they deliberately
   have no per-CO token; the room link is the credential. Migration `20260829013236`:
   sent ⇒ token OR room.
4. **Unsplit bids got no outcome writes** — `planRoomOutcome` grouped packets from
   `bid_versions`; a bid with none (the common single-GC case) signed or declined into
   thin air. The kernel now lands the outcome on `bids.outcome` directly (same decided
   rules; +1 parity test), and a decline records the GC's `loss_category` at bid level.
5. **`insertEstimateCustomerEvent` never worked** — the shared helper referenced bare
   `req` instead of `opts.req`: a runtime ReferenceError swallowed by its own best-effort
   catch, so option_viewed telemetry (v2.2462) and accept-estimate's repeat-accept audit
   have been silently no-opping since birth. One-word fix; `log-estimate-option-view` and
   `accept-estimate` redeployed. (Deno functions sit outside tsc's include — the earlier
   eslint noise over supabase/functions was hiding a real no-undef.)

**Verified live after the fixes**: publish & send (room, rev, email with the option

scenario), option telemetry with IP, signing the alternate (freeze to $41,700, packet
