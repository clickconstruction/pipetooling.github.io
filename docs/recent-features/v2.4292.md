# v2.4292 — Submittals from the takeoff: the product is the fixture’s parts, not one line (2026-10-01)

Found on BP375 SPACEX BA-02N after v2.4107: the pick list named one line per fixture as the product, chosen by a part-type bonus then the priciest line. LAV2 came out as the BrassCraft angle stop (its part type is "Sink", which the rule read as the fixture; the lavatory and faucet have no type); WC 1&2 and UR 1&2 came out as their flush valves (no line typed as a fixture, and the valve costs more than the china). Mock-up: artifact `JkwHjwTBYFUfefuDcFcDvU`.

- **Kernel** ([`takeoffCandidates.ts`](../../src/lib/submittals/takeoffCandidates.ts)): `productLineOf` is gone. `productPiecesOf` lists every priced line under a fixture in takeoff order (`TakeoffLine.sequenceOrder`, keyed by the line id), each a `ProductPiece` with its label (maker first), part type, house and `trim`; `TRIM_NAME` reads trim off the NAME — stops (incl. BrassCraft's "…ANG" / "LOOSEKEY"), supplies, P-traps (not trap primers), tailpieces, flanges, escutcheons, grid drains, wax, bolts, risers; bundles are never trim. `defaultProductKeys` = every non-trim piece (the first line when all are trim); `productFromPieces` joins the labels with " + " and takes the part and house of the first on piece that has them; `withProductKeys` recomputes a candidate. A candidate carries `pieces`, `storedProductKeys`, `productKeys`. The group (fixtures / no part / pipe) reads the first default piece.
- **Remembered**: `bid_submittal_takeoff_choices.product_line_ids uuid[]` — `20261001151153_submittal_takeoff_product_pieces.sql` ([doc](../migrations/20261001151153_submittal_takeoff_product_pieces.md)); NULL = the rule, '{}' = none on (built as Missing); stale ids are dropped and an all-stale choice falls back to the rule. `loadTakeoffCandidates` reads it (and the lines' `id`, `sequence_order`, ordered); `saveTakeoffChoices(…, productKeys)` writes it only for fixtures switched in the picker.
- **Picker** ([`SubmittalTakeoffPicker.tsx`](../../src/components/bids/SubmittalTakeoffPicker.tsx)): a chip per piece under any fixture with more than one (aria-pressed; trim chips dashed with "· trim"; full name and house in the title); every count, the bar, the split rows and Confirm read the product as switched; `onConfirm(rows, ticks, splits, productKeys)`.
