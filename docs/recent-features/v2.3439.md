# v2.3439 — Needs You: a card when field capacity has run under 60% three weeks in a row (2026-09-14)

Client only; no migration, no edge function. Item 3 of [`to-dos/job-summary-follow-ups.md`](../../to-dos/job-summary-follow-ups.md) — the Capacity view (v2.2828) counts `weeksUnder60` but nothing on the Dashboard said so.

## What shipped

- **Kernel** [`jobSummaryCapacity.ts`](../../src/lib/jobs/jobSummaryCapacity.ts): `CAPACITY_UNDER_PCT` (60) · `CAPACITY_UNDER_WEEKS` (3) · `capacityNudgeWindow(todayYmd, weeks)` — the three complete Mon–Sun weeks before the week holding today (the current partial week never counts) · `capacityUnderStreak(series, { thresholdPct, weeks })` → `CapacityUnderStreak` (`weeks[]` oldest first with utilization / field / available hours, totals, `source`, `crewNow`) or null when any of the last three rated weeks cleared the line or fewer than three could be rated (no roster and nobody clocked → unknown, not low). Three tests.
- **Hook** [`useCapacityUnderNudge.ts`](../../src/hooks/useCapacityUnderNudge.ts): loads only those three weeks — `loadJobDayLedger({ leadDays: 0 })` behind the per-user `loadJobDayLedgerCached` sessionStorage cache (the loader the Capacity view reads, so the two agree) plus the same `people` roster query as `useFieldRoster`; `buildCapacitySeries` → `capacityUnderStreak`. Null while loading or on error; refreshes on `clock-session-changed`.
- **Card** [`dashboardNeedsYou.ts`](../../src/lib/dashboardNeedsYou.ts): key `capacity-under`, tier 50 (people/planning), amber, kicker *Capacity*; title *Field capacity has run under 60% three weeks running*; detail names the three weeks with their percentages (*48% · 52% · 41% for the weeks of Aug 24, Aug 31 and Sep 7*), the hours (*113 of 240 available field hours*) and the basis (*a field roster of N* / *who clocked in, since the roster could not be read*); figure = the latest week's %; **Open Capacity** → `/jobs?tab=job-summary&view=capacity`. Inputs `capacityUnderEnabled` / `capacityUnder` (optional — Quickfill passes nothing). Two tests.
- **Dashboard** [`DashboardPinnedQuickRow.tsx`](../../src/components/dashboard/DashboardPinnedQuickRow.tsx): enabled for `officeEligible` (dev · master · assistant · controller — the roles the Jobs page shows Job Summary to; primary and superintendent never see the tab), like the stale-open card.
- Guide *work the Needs you list on the dashboard*: the new card under the jobs group.

Kernel + Needs You suites, drift tests, typecheck, lint, theme check.
