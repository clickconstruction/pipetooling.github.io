# v2.8198 — Prospects: a State roll tab shows the state’s licensed plumbers near us (2026-11-21)

Punch list #411, the last piece of step one in [`to-dos/state-roll/`](../../to-dos/state-roll/README.md), after the tables of [v2.8159](./v2.8159.md) and the pull of [v2.8164](./v2.8164.md). The first screen: until now the kept roll was on prod and nobody could see it. No migration.

## Why

Taunya asked on 2026-11-20 for a way to find experienced, licensed plumbers from the state's public roll, and on 2026-11-21 asked for it all under a new tab. The roll has been kept since the first pull that day. This is the tab, with the one view that needs no judgement yet: what is kept, and whether the weekly read is working.

## What changed

- **`src/pages/Prospects.tsx`**: a sixth pill, **State roll**, at `?tab=roll`. It shows to `teamProspectsAccess`, the Hiring switch itself, which is the gate the tables keep. A shared Hiring column does not open it, and an address that names the tab without the switch lands on the calling deck.
- **`src/components/prospects/StateRollTab.tsx`**, the Pulls view.
  - A line naming the counties kept, and a note that the state gives no phone, address or email.
  - Four counts: journeymen, masters (a responsible master among them), tradesmen, and how many hold a lapsed license.
  - A card a state file: when it was last read, how many rows were kept of how many in the file, and what that read changed.
  - A card whose newest read failed keeps its last clean read and gives the reason in red.
  - **Pull 4 files** reads every file in turn, one request at a time. It goes on past a file that fails, then lists each with its reason (`batchOutcomeWords`).
  - Before any pull, an empty state that names the press.
- **`src/lib/licenseRoll/rollPulls.ts`**: the view's lines and sentences, pure, each value marked with `val`.
- **`src/lib/licenseRoll/rollPullsIo.ts`**: the reads and the press. The counts are head requests, so no person's row is read.
- **The guide** `see-the-state-roll-of-licensed-plumbers`.
- `PROJECT_DOCUMENTATION.md`, `GLOSSARY.md`, `ACCESS_CONTROL.md`, `PROSPECTS_TABS_ARCHITECTURE.md` and `twins/APP_DIRECTORY.md` carry the tab.

## Values in place

Every count and day on the view stands apart from its words: the tiles' counts, and on a card one fact a line (`ValueLines`) with the values in a column. All of them are worked out by the app, so each is plain bold (`WorkedOutValue`). Nothing on this view can be changed by a press on a value.
