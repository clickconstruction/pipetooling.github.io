# v2.7059 — Tasks: say where the work is when you give a task (2026-11-12)

Punch list #328, PR 2 of 8. v2.7058 gave a task its place columns. This is the giver's side: the row that sets them.

## What changed

- **The Place row** (`src/components/checklist/TaskPlaceRow.tsx`), in the Add window under the people and in the Edit window above Done when. It holds the places tasks already carry, as chips, and **＋ New place**. One press on a chip and the task has that place. A second press takes it off. Nothing is pressed by default.
- **The chips keep no list.** `loadRecentTaskPlaces` (`src/lib/tasks/taskPlaceIo.ts`) reads the tasks that have a place, and `recentTaskPlaces` offers one chip a name, newest first. RLS decides which tasks a person may read, so a helper's chips are the places on the helper's own tasks. A read that fails is no chips, never a broken window.
- **Where is it?** (`TaskPlaceSheet.tsx`): the box map's view from above and its ring (`OnSiteMap`, which gains an optional hint, empty words and start zoom). **Use where I am** takes one reading on that press, flies the map to it and says *Found you. Your phone is sure within 20 ft.* A reading wider than about 150 ft asks for the ring instead of being taken. A ring dragged off the reading drops the phone's margin, since the place is then the giver's own call. A refusal says what to do and the map still sets the place.
- **Where the map opens**: on the place being moved, else the last place anyone set, else the office. With none of the three and no reading, it opens on the whole country after a short wait, and **Use this place** waits for a drag, so the middle of the map is never saved as a place by accident.
- **What a save writes.** The Add window writes the six columns only when a place is set, so a task with none sends the row it always sent. The Edit window writes them only when the place changed, so an edit to the title leaves who placed it and when alone.

## Found on the walk

With location refused, the sheet had no map to drag, because the office's address was read only when the sheet opened and had not arrived. The row now reads it when the window opens, and the wide view covers the case where there is no office on record at all.

## Deploy
