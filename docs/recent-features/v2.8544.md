# v2.8544 — Cards and footers for the team: a ZZ test person is left out (2026-11-24)

A small fix from the live walk of punch list #313 on 2026-11-24. No migration, no edge function.

## What was wrong

The walk saved a photo on a ZZ Test person, to try **Save the photo**. Nothing takes a photo off (punch list #443). So that person stood *Ready* in *Cards and footers for the team* and started ticked, and the batch press counted a card for them. The read behind the list leaves out a sample, a twin, a walk tester and a subcontractor by their flags. A ZZ test person carries no flag, only the name.

## What changed

- `src/lib/brandKit/team.ts`: `isZzTestPerson(facts)`, new and pure, is true when the account's name or the name set for the card starts with ZZ (`isZzTestName`, the app's one rule for a test record). `teamCards` leaves such a person out before it builds the rows, so the list, the ticks and both batch presses never count one.
- `src/lib/brandKit/cardIo.ts`: the read is unchanged. Its note says where the ZZ rule sits.

## What did not change

One person's own window, from People → Users or from Settings, still opens for a ZZ test person. That is how a walk tries a save.

## Tests

`team.test.ts`: a ZZ test person with a photo and an email is not in the list and is not ticked, by the account's name and by the card's name, and a real name that starts with one Z stays.

## Not walked

Not seen on the live page yet. The look: People → Users → *Cards and footers for the team*, and the ZZ Test person with a photo is not listed.
