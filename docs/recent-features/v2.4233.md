# v2.4233 — Plain words is the convention: new and changed only (2026-09-30)

Punch list #58, item 3 — the owner's call, 2026-09-30: "yes, make it the convention, new and changed only", after items 1 and 2 ([v2.4228](v2.4228.md), [v2.4229](v2.4229.md)). No migration, no edge function, nothing on a screen changes. The row retires with this PR.

## What changed

- **One home for the rules** — [`src/lib/plainWords.ts`](../../src/lib/plainWords.ts): the six rules in its header (they lived in the to-do), and the two mechanical ones as code — `plainWordsSentences`, `plainWordsFailures(text)` for a stop or a Next line, and `helpGuideProseLines` / `helpGuidePlainWordsFailures(source)` for a guide (the frontmatter, headings and `:::example` panels left out; a token read as its label; an italic span read as one quoted word). `submittalTour.test.ts` and `workbenchHelp.test.ts` import them instead of carrying their own copies; their verb, trade-word and shape cases stay their own. Tests in `plainWords.test.ts`.
- **Every guide not on the legacy list is held** — [`helpGuidePlainWords.test.ts`](../../src/lib/helpGuidePlainWords.test.ts) runs the rules over every guide whose slug is not in **`LEGACY_PLAIN_WORDS_GUIDES`** ([`plainWordsLegacy.ts`](../../src/lib/plainWordsLegacy.ts): the 302 guides written before the rules; *build a submittal package* is the one not on it). A new guide is held from its first commit. The list never widens; a row that names no guide fails.
- **A touched guide leaves the list** — `npm run check:plain-words` ([`scripts/check-plain-words.ts`](../../scripts/check-plain-words.ts), in `ci.yml` and `deploy.yml` beside `check:todos`) diffs the change against its base (the merge's first parent in CI, the merge base with `origin/main` locally; a push to main has nothing to compare) and fails when a changed guide is still on the legacy list, or fails the rules. So the rule is mechanical: rewrite the guide, remove its row.
- **`CLAUDE.md`** → *Help guides ship with features* carries the clause. The to-do's own rules section is deleted with the to-do; `to-dos/README.md` carries the Closed line.

## What is left

The owner also asked to go back through the 302 older guides. That is a sweep, a few guides per PR on quiet days, each PR removing its rows from the legacy list — no to-do, since the list itself is the queue (`npm run check:plain-words` and the test say what is left).
