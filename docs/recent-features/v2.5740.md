# v2.5740 — Messages: the walk starts when asked (2026-10-22)

Punch list #142 (the walk kit), a fix to PR 8 found on the first run: `npm run walk` printed nothing and exited 0.

- **Why**: `scripts/walk/run.ts` ran `main` only when `process.argv[1]` was the script, the plain-node shape. Under vite-node the script is stripped from `argv` altogether: `argv[1]` is vite-node itself and the flags follow it, so the guard never matched and the module loaded without running.
- **The fix**: the guard runs `main(process.argv.slice(2))` when `argv[1]` is vite-node or the script itself. Under vitest, which imports `main` for the driver test, `argv[1]` is vitest, so nothing runs on import, as before.
- **Checked on prod**: `npm run walk -- --cleanup-only` reaches the deployed `walk` function and answers *nothing to clean*; the full run's report is in this fragment's PR.
