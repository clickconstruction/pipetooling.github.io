# v2.8405 — Working hours: Job Mode tells a salaried person their hours (2026-11-23)

Punch list #429, the last piece. The Dashboard's My Time section draws the line at its foot with `asks={!disableDayEditor}`, so a salaried person reads the working hours the office set. Job Mode's own card, `DashboardMyTimeCard`, left the line out for anyone salaried (`isSalary ? null : …`). That was written before working hours existed, when the line only asked.

The card now draws `MyTimeCanWorkLine` with `asks={!isSalary}`:

- A salaried person with working hours in force reads them with no press, then *The office sets these hours.*
- A salaried person with none sees nothing, as before.
- An hourly person is unchanged: their hours if the office set them, the question otherwise.

The line reads `person_available_hours` for a salaried person now too, the same one read the Dashboard makes.
