# v2.1943 — Forecast bucket tiles click-to-filter (2026-08-20)

The Payment forecast's (v2.1925) bucket tiles become toggle buttons: clicking
one narrows the row lists to just that bucket (2px accent outline +
`aria-pressed` on the active tile, "Showing only <bucket> · Show all" status
line); clicking again or Show all restores every bucket. Empty tiles are
disabled while inactive. Intro copy now says tiles are clickable. Render
smoke extended (`BilledPaymentForecastModal.render.test.tsx`, tile click →
filtered list → Show all). No migration; help guide unchanged (the forecast
section already describes bucket → rows drill-down behavior generically).
