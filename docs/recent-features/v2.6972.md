# v2.6972 — Rows the system numbers, on the screen: evidence numbers, Ev #41 as a door, Number them, the Case view (2026-11-11)

Punch list #315, upgrade 2, PR 2. Builds on v2.6971's counters, `exhibit_no` and `dev_case_write`.

## What changed

- **Evidence numbers** (`PersonFilePanel.tsx`): a record wears *Ev #81* beside its title on the Evidence view and on its Timeline line, unless the title already opens with that number (`exhibitBesideTitle`). The numbers are read on their own (`loadExhibitNumbers`), so a read that fails takes only the chips out.
- **Ev #41 is a door**: in an entry's words *Ev #41* (the `#` is required) is a press that opens the Evidence view on the record, lit. The number names a record by the file's number, or by the number an old title wears when exactly one record wears it, so the doors work on a file before anyone numbers its old records. A number nobody wears stays words. `splitByDoors` in `hrDocCitations.ts` splits a line into words, narrative citations and evidence numbers.
- **Number the old records**: while records have no number from the file, the Evidence view carries a strip. *See what numbering would do* reads the backfill's dry run and says it in sentences, lists each clash with the records that wear the number, and offers to number the titles with none after the highest. **Number N records** runs it. Nothing is guessed and no title changes.
- **The Case view** (`PersonCaseView.tsx`, a tab beside Documents, counted by its open items): the open items by number with who has each, *Close…* (Done or Dropped, the reason required), *Hand over…*, the closed ones folded with *Open again*, **+ Add an item** (the number left to the file, or typed for an item people already call by one), and the log newest first with *Add the line*. Every write goes through `dev_case_write` (`personCaseIo.ts`); a refusal keeps the form open and says why.
- **Help**: `keep-private-employee-files` gains *Evidence numbers* and *Keep a case's open items and log*.

## Is this the best we can do?

The map put the number beside every title. On a file whose titles already say *Ev #41* that would print the number twice on eighty rows, so the chip is drawn only where the title does not already carry it. And the doors read an old title's number when it is unique, so *Ev #41* in the entries already written opens the right record without the backfill.
