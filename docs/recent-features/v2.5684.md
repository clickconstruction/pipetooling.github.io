## What shipped

- **One button in the preview's wording editor.** The alternate lines on the letter preview are click-to-edit (`data-cl-edit` → `altTextEditor` in [`BidsCoverLetterTab`](../../src/components/bids/BidsCoverLetterTab.tsx)); beside Save / Cancel / Reset to auto the editor now offers **Take off this letter**, with a one-line caption saying exactly what it will do and how to bring the alternate back.
- **Shown only on alternates.** The `takeOff` closure answers null for the heading, for a base section and for an option's own line — the button exists only where the line is an offer. For the three kinds it routes to the write each already had: an offered price (`<version|none>:<pricingId>` key) → the tab's `setScenarioOffered(p, false)`; a with-and-without group (`group:<tag>`) → `cover_letter_alt_texts.groups[key].offered = false`, the same write as its Step 1 checkbox; an in-lieu packet (a bare version id) → `toggleVersionInclude`, the same write as its checkbox. Nothing new is stored; the Step 1 row unticks or reads *not offered*, so the way back stays visible, and the bid room follows the shared flag.
- **The render smoke** `BidsCoverLetterTab.takeOff.render.test.tsx` holds the editor: exactly one button on a group alternate's editor, pressing it writes `offered: false` and closes the editor, Cancel writes nothing.
- **The guides**: *use the cover letter studio* gains the "Drop an alternate from the preview" bullet; *offer an alternate on a bid* names the button beside its ✎ line.
