# v2.3461 — Pipeline: click a stage to open Bill; the words line reads "Worked Aug 11 · 100% Aug 20" (2026-09-15)

Client only; no migration, no edge function. Owner's second pass on the Progress & payment cell after v2.3459.

## What changed

- **Every stage chip and the bar open Bill → ① Line Items** ([`StagesStageBar.tsx`](../../src/components/jobs/StagesStageBar.tsx)): the bar takes `onStageClick`; with it each chip renders as a `<button>` inside its list item and the whole bar sits in an unstyled full-width `<button>` (the `role="img"` bar with its accessible name is unchanged inside). Tooltips gain *Open Bill → ① Line Items*. Without the prop the bar renders exactly as before (deck embeds, tests). `StagesProgressPaymentCell` renames `onSetStagesClick` → `onStageClick`; the six callers (unified table ×3, job table, card list ×2) pass the same `openEdit(j, { fixturesSectionHighlight: true })`. The row's thread toggle already ignores clicks inside buttons.
- **The *Set stages* link (v2.3421) is gone**, and with it `offerSetStages` on `ProgressPaymentView` — the bar is the door now, on every row, not only on unrecognized multi-line jobs.
- **The words line** ([`progressPaymentCell.ts`](../../src/lib/jobs/progressPaymentCell.ts)): `crewClause(…, { names: false })` reads *worked Fri* / *worked today* (past tense, no "on site"); `percentClause(…, { source: false })` drops the source word (*100% Aug 20*, *40%*); `capFirst` starts the printed line with a capital. So `on site Aug 11 · 100% typed Aug 20` prints as **`Worked Aug 11 · 100% Aug 20`**, `nobody clocked in · no % yet` as `Nobody clocked in · no % yet`. `words.full` (tooltip, accessible name) is unchanged — names, source word and money.

## Verified

Kernel suite and the bar / cell / table render smokes updated and green (two new bar tests: clicks on a chip and on the bar call the handler; no buttons without it); typecheck, lint, theme check. Live on the dev server: the chips and bar carry the pointer and open Edit Job on ① Line Items; the row's activity thread does not toggle on that click; the screenshot's row reads `Worked Jul 22 · 90% Aug 7`.
