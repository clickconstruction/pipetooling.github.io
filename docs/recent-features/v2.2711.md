# v2.2711 — Job Summary Timeline: how many jobs are running at once, over time (2026-09-03)

Owner ask after the Days view: "a Gantt-like version that shows all the jobs and when they start, and how many jobs we're running at a given time, over time." Three mock-ups (artifact 86bb2a36); owner picked **C** — lead with the load curve, jobs on demand. Built as a third View inside Job Summary (Jobs · Days · Timeline) on the same job day ledger, with the leans applied: worked-span default with a 7-day gap rule, status span one click away, jobs only.

## Client only — no migration

- **Kernel** [`lib/jobs/jobRunningTimeline.ts`](../../src/lib/jobs/jobRunningTimeline.ts) (+9 tests): `buildWorkedSpans` (per job, approved field days merged into segments; a pause longer than `gapDays` splits the run; an open job touched within the gap extends to today), `buildStatusSpans` (Working → Billed/Paid from `job_status_events`, clipped to the window, open runs to today), `buildRunningSeries` (per-day counts split by today's bucket working / billed / paid, trailing 7-day mean, peak, today, average over calendar days), `summarizeJobRuns` (jobs, open, finished, median run days), `monthTicks`, `jobRunBucket` (paid / billed / else working).
- **Ledger** [`jobDayLedger.ts`](../../src/lib/jobs/jobDayLedger.ts) + loader: job labels now carry `status`; new `statusSpansByJob` from `job_status_events` (first working/RTB/billed/paid move → first billed/paid move after it), both serialized; session cache key bumped to `jobDayLedger:v3:`.
- **View** [`components/jobs/JobSummaryTimelineView.tsx`](../../src/components/jobs/JobSummaryTimelineView.tsx): Running = / Gap controls, five tiles, the stacked area SVG (paid under billed under working, 7-day average line, month ticks, today marker, peak dot, per-day `<title>` tooltips, click → Session notes pinned to the day), legend, and a collapsed "The N jobs behind this curve" panel drawing one bar per job (segments colored by bucket, *open* marker). View mode `timeline` added to the prefs kernel; the toolbar hides Show / Overhead / totals / hygiene outside the Jobs view.
