# v2.5327 — Messages: the threads read the database’s own shapes, behind the scenes (2026-10-12)

With the spine's tables in the generated types (#5482), the Messages loaders drop their written-out rows.
`ContactRow`, `ContactChannelRow` and `ContactJobRow` (`src/lib/contacts/load.ts`) and `MessageRow`
(`src/lib/messages/load.ts`) are each a `Pick<Tables<'…'>, …>` of the columns the mappers read, so a renamed or retyped
column fails the typecheck and the fixtures need no column they never read. `MessageRow` keeps cut 5's optional
`duration_seconds` until its migration. No behavior changes.
