- **`messages-email` takes `files`** (`parseEmailFiles`): each from the job's Drive, a file that came in, a sent copy's file, a paper the app makes, or this computer, and how it goes: the file, a link, or a photo on the email. The function's `files.ts`:
  - `readFiles`, before the line is written: a Drive file must sit inside the tied job's folder; a file that came in, a sent copy's file and our contract must be where their rows say. Each that goes as the file is read whole from Drive, `message-attachments`, `sent-documents` or `gc-owner-contracts`, held to 10 MB a file and 20 MB together. A file from this computer goes into the job's Team only (Sent by us, or Photos) first. A refusal names the file and why, and nothing is written.
  - `placeFiles`, once the line has its id: a link opens their portal at its page when their portal has it (a trade partner's portal link, a customer's portal where their GC jobs show), else our link to the Drive file (`makeDriveLink`). Each file sent as the file is copied under `out/<line>/` in `message-attachments`. Every file is a `message_attachments` row with `sent_as`, `url`, `drive_link_id` and `drive_file_id`.
  - `takeBack`: when the email does not go, our links and the copies go with the line and its rows.
