# v2.2886 — A bid room starts with "Get the link": no forced email; Copy link before the first send (2026-09-05)

Journey-map Tier-2 #31 ("Signable bid rooms: 0 ever minted despite five shipped phases", C15 — J35-F1/F2). The room panel's only first action was **✍ Publish & send room link**, and `publishAndSend` validated the GC email *before* calling `publish()` — so a room could not exist without the app emailing the GC, and Copy link (the link *is* the product) was unreachable until then. Estimators who email from their own client had no door; v2.2716's **Setup bid room** button opened the same fused panel.

## Live recount (2026-09-05, read-only via the app client on the dev server)

`bid_proposal_rooms` **2** (created 2026-09-03 and 2026-09-04; both carry a `recipient_email` — both minted through the forced-email path) · `bid_proposal_room_revisions` **2** · `bid_proposal_room_events` **9** (`link_sent` ×2, `room_view` ×3, `option_viewed` ×3, `signed` ×1). So: two real rooms since the J35 snapshot's 0/0/0, one of them signed — the door works once someone gets through it; the forced email was the friction, not the product.

## What changed

- **Kernel** `src/lib/bids/bidRoomPanelActions.ts` — `bidRoomPanelActions({ hasRoom, published, everSent, hasEmail, answered })` → `{ primary, send, showLink, closeRoom }`; `looksLikeEmail`. 9 tests (`bidRoomPanelActions.test.ts`) incl. the full 5-bit matrix.
  - not published → primary **✍ Get the link** (`get_link`), **Send to GC** (`publish_and_send`, enabled by `hasEmail`)
  - published → primary **Publish update** (`publish_update`), **Send to GC** / **Email link again** (`send_only`)
  - answered → no publish / send; `showLink` stays true
  - `showLink` ≡ `published` — the old `everSent` / fused-send gate is gone.
- **`BidRoomPanel.tsx`** — `publishAndSend` + `sendOnly` collapse into `getLink()` (publish, then copy the link to the clipboard; the panel also shows the URL in a `Link` row) and `send()` (publishes rev 1 first only when no revision exists; otherwise sends the current link as-is — publishing is its own button). `onFirstLinkSent` fires on the first *app* send only, never on Get the link, so the sent-stamp keeps meaning "the app emailed it". Two rows now: link actions (primary · Copy link · Open ↗ · Close room) above the email row (address · Send to GC).
  - **Copy link** copies the bare `/bid-room?t=<token>` — the same URL the email carries, no preview marker.
  - **Open ↗** (new) is an anchor to `withPreviewFlag(link)` (`?preview=1`, `publicViewCounting`) in a new tab — the office's own opens never count as GC views (#37, unchanged server side).
- **Telemetry** — minting a room records `recordNavClick(user, role, 'bid_room_published', '#sent_by_app:1|0')` into `ui_nav_clicks`. `bid_proposal_room_events.event_type` is CHECK-constrained to the five GC-side kinds (`room_view` / `option_viewed` / `link_sent` / `signed` / `declined`), so a `bid_room_published` row there would need a migration; the nav-click ledger is the house home for staff-action counters (`portal_link_minted`, `rfq_link_minted`, `change_order_bridged`). Read it at Settings → Usage → nav clicks.
- **Render smoke** `BidRoomPanel.render.test.tsx` (new, table-aware supabase stub): no room → Get the link primary, Send to GC disabled until an address is typed, no link controls; published-never-sent → Copy link + Open ↗ (href carries `preview=1`, the Link row does not), Publish update, Send to GC (not "Email link again"), Close room.
- **Docs** — `docs/BIDS_SYSTEM.md` gains a *Bid room (signable link)* subsection under Cover Letter Tab (the panel had no home there); help guide *send a bid for signature* rewritten around Get the link → Send to GC, with an example for the estimator who emails from Outlook and a note that the chip's "not sent" means not sent *from the app*.

## Not changed

- `get-bid-proposal-room` / `send-bid-room-link` / `sign-bid-room` — no edge function change, nothing to deploy. #37's staff/preview skip (PR #2615) stands.
- No migration. `bidRoomState.ts` chip wording ("rev 1 · not sent") stands — it is truth 2 (app send), and the guide now says so.
- `Estimates.tsx` CO → room path (requires an open room) untouched; `BidFormModal` (#2597) untouched.
