# v2.2846 — Subs: Active or on the bench (2026-09-05)

Owner: "better distinguish which subs are active versus inactive; an inactive sub might come back." Mockup artifact 4e1326f2; owner picked **C** (explicit bench + last-worked evidence + nudges). PR 1 of 2.

- **Kernel** `src/lib/people/subBench.ts` (+test): `subBenchStatus({ endDate, startDate, createdYmd, notes, lastWorkedYmd }, todayYmd)` → `{ kind: 'active' | 'bench', since, reason, lastWorkedYmd, lastWorkedLine, tone, nudge }`. Bench = `people.end_date` set. Tones: green < 60 days since work, amber < 180, gray after (never-worked: amber while < 60 days on the roster, then gray). Nudges: active + quiet ≥ 90 days (or never worked ≥ 60 days after being added) → `bench` ("Quiet for 4 months"); benched + work dated after the bench date → `reactivate` ("New work on Sep 4"). `compareSubsForBench` keeps money-first ordering among active rows, then most recently worked; bench rows after.
- **Storage** reuses the roster row, no migration: Bench… writes `end_date` + appends `[bench YYYY-MM-DD] reason` to `people.notes`; Reactivate clears `end_date`, stamps `start_date = today`, appends `[back YYYY-MM-DD]`. `currentBenchReason` parses the newest bench line not followed by a back line.
- **Subs HQ** `subsHqRows.ts`: `SubsHqRow.lastWorkedYmd` from attributed sheets' `job_date` / `paid_at` and commitments' `accepted_at` (new optional inputs `jobDateYmd`, `paidAtYmd`, `acceptedAtYmd`); the tab now selects those columns plus `people.start_date, end_date, notes, created_at`.
- **Tab** `PeopleSubsTab.tsx`: pills Active / On the bench / All (Active default); new **Status** column after Sub (dot + Active / Bench since, Bench… or Reactivate button, reason in quotes, last-worked line, amber nudge chip); inline Bench form (date ≤ today, one-line reason ≤ 140 chars); bench rows at 72 % opacity; "All" shows an "On the bench · N" section row; empty-bench message.
- Guide `manage-subs-end-to-end.md` § 2 gains "Active or on the bench".

**PR 2 (next):** benched subs hidden by default in the dispatch offer pickers and the sub-sheet Assign… list (with a "show bench" toggle), compliance nags paused for benched subs, a gray Bench chip on the Users tab row, Bench/Reactivate from the Person Desk.
