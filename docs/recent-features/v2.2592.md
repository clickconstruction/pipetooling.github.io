# v2.2592 — Estimate draft autosave (2026-09-01)

User request (taunya, 2026-09-01): she leaves a draft mid-edit to chase information, comes
back, hard-reloads out of habit, and the in-memory editor state is gone. Draft estimates /
change orders now autosave.

**Approach — reuse, not reinvent**: [`src/pages/Estimates.tsx`](../../src/pages/Estimates.tsx)
now drives the Edit-Job autosave engine
([`useJobFormAutosaveSlice`](../../src/components/jobs/useJobFormAutosaveSlice.ts), v2.1078)
as a single slice over the whole draft:

- **One payload builder** — `buildDraftPersistPayload()` extracted from `saveDraft`; the
  slice's dirty-check JSON is `JSON.stringify` of the exact UPDATE payload, so dirty can
  never disagree with what a save writes.
- **Quiet, reload-skipping saves** — `saveDraft({quiet, skipReload})`: autosave must NOT run
  the trailing `load()` (it re-seeds the whole editor — lines, options, viewed option — and
  would clobber typing in flight). Manual Save keeps the reload.
- **Hydration-safe baseline** — the hook's `jobId` gates on `!loading`, so the baseline is
  captured only after `load()` fully hydrates (the accept-notify default fetch awaits
  mid-hydration; baselining early would mark the hydration itself dirty).
- **Debounce 1.5s**; `enabled` gates on `!saving && !sending` and on the Supporting-document
  URL being valid (an invalid https link never persists — the hook's dirty-but-disabled
  semantics, same as the Jobs identity slice).
- **visibilitychange flush** — her exact loss scenario is "ran off to look something up":
  the pending debounce flushes the moment the tab hides.
- **Status text** next to Save draft: Autosaving… / Autosaved / "Autosave failed — press
  Save draft" (`aria-live=polite`).
- The v2.2457 customer-link autosave effect stays (it wants the `load()` refresh); a
  same-burst double-write is idempotent.
- Live-tested against prod draft #3: typed marker → Autosaved → hard reload → marker
  survived → cleanup autosaved.

Help guide: `src/content/help/trust-estimate-drafts-to-save-themselves.md`.
