# v2.5494 — Messages: the email reader can read the team inbox too (2026-10-13)

Residential Messages, R6's reader (`to-dos/gc-mode/messages/RESIDENTIAL_BUILD_PLAN.md` → R6, the second PR, on branch
spike/gc-mode). Stacked on #5642 (R6 PR 4, which puts `boxes.ts` in the edge copy). No migration. The lead deploys
`gmail-sync`.

- `emailIn/readerBoxes.ts` (new, in the edge copy): `readerBoxes(settings, GMAIL_IMPERSONATE_USER)` gives the boxes to
  read.
  - bids@ comes from the secret, else Settings' bids address.
  - The team box comes from `messages_boxes_v1.team.address` alone. It is left out while that is empty, not an address,
    or bids@'s own.
  - `boxWords` names a box on a line ("team@").
- `gmail-sync` reads each box on its own.
  - Each box has its own token as that Workspace user, its own `gmail_sync_state` row by `mailbox` and its own label.
  - The team row is made on its first run at its newest point, with no `id`, as `gmail_sync_state_id_is_bids` holds.
  - Each box has its own try. A failing box writes its own `last_error`, and the other still reads. The answer is 500
    with each box's result when one failed.
  - Each line's row carries `mailbox`, and "ours" holds both box addresses.
  - With no team address, the run is bids@ alone, as before.
- `emailReaderIo.ts` reads every `gmail_sync_state` row by its mailbox. Before this it asked for exactly one row, which
  would fail once a team row exists.
- Settings → Phone and texts → **Read bids@** shows a second line once the team box has been read:
  `teamBoxHealthWords`, *The team box: Last read …*.
- The guide *turn on reading the bids inbox* gains *The team inbox*. `docs/EDGE_FUNCTIONS.md` → gmail-sync gains
  *Two boxes*.

  - A reply going from the box they wrote to is messages-email's PR next, and it flips `SENDS_FROM_BOXES`.
  - One email sent to both boxes lands twice until a Message-ID column, a later migration if it ever matters.
  - A Boxes card on Settings that holds the two addresses is a separate piece. Until it exists a dev types the row.
