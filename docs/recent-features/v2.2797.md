# v2.2797 — Contract Forms PR 3: fill on the document (2026-09-04)

The signer's side of Contract Forms. A `person_contract_documents` row with `form_template_id` opens on `/contract/accept?t=…` as the **real page with inputs at the dev-placed boxes**; on submit the answers are written into the PDF, flattened, and filed privately. Plan: `docs/CONTRACT_FORMS_PLAN.md`; spec: `docs/CONTRACT_FORMS.md`.

- **`get-contract-for-signer`**: selects `form_template_id, person_id`; for a form row returns `form: { schema, templateUrl (15-minute signed URL into the private contract-form-templates bucket), revisionLabel, person { name, email, phone } (roster prefill), todayLabel }`. 503 when the template PDF cannot be signed-URL'd.
- **`accept-contract`**: accepts `formValues` (+ `formLang`); for a form row validates them against the template schema (`validateFormValues`, 400 `form_invalid` with the problems), downloads the template, builds the fill plan with the signature (typed → Great Vibes fetched from `APP_ORIGIN/fonts/…`, drawn → the PNG), `fillFormPdf` + flatten, uploads `contract-form-pdfs/<docId>/signed.pdf`, and writes `form_values` (non-sensitive only), `form_hints` (last four of each sensitive answer), `form_pdf_storage_path`, `form_source = 'portal'` alongside the usual signed fields. Any failure after the signature PNG upload removes the PNG (and the PDF if already filed).
- **`send-contract-for-signature`**, **`get-contract-signing-link-for-self`**: a form row counts as having signing content (no body needed).
- **`ContractAccept.tsx`**: form rows render `ContractFormFill` in place of the body; roster prefill via `applyPrefill`; client-side `validateFormValues` before submit (errors mapped onto boxes by `errorsByBox`); the signing form's heading / disclosure / agree / submit strings switch to the form wording (bilingual).
- **`ContractFormFill`** (`src/components/contracts/formFill/`): fetches the template, renders every page (pdf.js `PdfPageCanvas`) at a fit-to-width scale with **`FormFillOverlay`** — text and masked-digit inputs, checkbox buttons (exactly-one groups swap), constants and today's date as static text, the typed signature previewed in cursive in the signature box. Under 760 px a **lens** magnifies the current box (label, help, sensitive note, input or the group's choices) with Back / Next, progress "n of m filled", a "rarely needed" expander, and an English / Español toggle (`labelEs` / `helpEs` + a small chrome dictionary).
- **`formFillState.ts`** (+ tests): `fillableBoxes`, `lensSequence`, `boxLabel` / `boxHelp`, `displayValue` (mask formatting; sensitive → dots plus last two off-focus), `acceptDigitsInput`, `toggleCheckbox`, `setOneOfValue`, `fillProgress`, `errorsByBox`, `fitScale`, `fillString`.
- Guide: `fill-and-sign-a-form-on-my-phone.md` (subs and helpers).
- Deploy: redeploy `get-contract-for-signer`, `accept-contract`, `send-contract-for-signature`, `get-contract-signing-link-for-self`. No migration.
