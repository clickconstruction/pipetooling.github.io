# v2.4948 — Bids: a History button shows what changed on a bid (2026-10-08)

Punch list #73, PR 2 ([`to-dos/bid-history`](../../to-dos/bid-history/README.md)): the reader. PR 1 (v2.4598) keeps every change on a bid in `bid_changes`, and PR 1b (v2.4736) tags the bulk paths. Nothing read either until now. The owner answered the card's five calls on 2026-10-08 (in its front matter); this PR is built on them. Migration `20261009060000_list_bid_history.sql` ([doc](../migrations/20261009060000_list_bid_history.md)); no edge function.

## The change

- **`list_bid_history`**, SECURITY INVOKER. It returns the ledger's rows for the bid and every bid adopted into it, each with its bid number, plus the delete archive's removed rows the ledger lacks. Under the archive's own rule, those reach a dev only.
- **The kernel** [`bidHistory.ts`](../../src/lib/bids/bidHistory.ts):
  - **actions, not rows**: the same bid, author, tag and source, each row within five seconds of the last, so an import of 23 rows is one action;
  - captions: from the tag (*Imported 23 rows from CountTooling*, *Set aside 2 labor rows no fixture claims*), else from what the rows did (*Removed SUMP and what hung on it*, *Changed 3 prices*, *Edit Bid · value and due*);
  - one line per row (*Lav-1 · price · $9,800 → $10,300*), and the tab each change belongs to;
  - the filters (tab, person, the app) and the search;
  - day headings in the company's time.
  - The owner left Edit Bid's default columns to the builder: `BID_HISTORY_DEFAULT_BID_COLUMNS` (project, address, GC, estimator, account man, due, sent, value, agreed value, outcome, loss reason, notes, the three cover-letter texts). The rest count as *N other fields*.
- **The window** ([`BidHistoryWindow.tsx`](../../src/components/bids/BidHistoryWindow.tsx)): read only, newest first under each day.
  - Each action shows its caption, its time, and who · tab, plus the bid number when an adopted bid is in it.
  - It opens to its rows, with chips for tab and person and a search box.
  - It says when history began for the bid, and marks a row from the delete archive.
  - It is a window (a sheet on a phone), not the side pane the mock-up drew: on 2026-10-02 the GC window was moved off the side because a pane beside the road squeezed the rows.
- **The door** ([`BidHistoryDoor.tsx`](../../src/components/bids/BidHistoryDoor.tsx)): a small **History** button after the mark controls in `BidWorkflowTabTitleWithPreview`, so every bid tab has it. Nothing loads until it is pressed. The window goes to the page's body, as the mark cards do.

Put back is PR 4; the under-cell lines and the always-on switch are PR 3.
