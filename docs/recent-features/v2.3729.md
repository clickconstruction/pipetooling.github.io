## What the pass found

[`trialTally.ts`](../../src/lib/hiring/trialTally.ts) now keeps each leader's latest word of any kind: a skip as the latest word marks the line `skipped` (*skipped the card*), not waiting, and the nudge does not name them. An earlier answer still counts when the latest word is a skip. One test (12 now).
