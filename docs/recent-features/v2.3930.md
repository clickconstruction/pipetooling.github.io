## The fix

`PersonOffsetFormModal` reports its refusals only through `onError`, and the page handed it a write-only state setter — so on this path "Amount must be a positive number", "Select a person" and a failed save were never shown. They are a toast now (`onOffsetError` → `showToast(msg, 'error')`), the same way the Dashboard's stale-tally follow-up shows them.
