# v2.3599 — PO codes: what they said they need, written down and read back (2026-09-18)

PR 1 of `to-dos/po-generator-stated-need` (option A). No migration, no RPC change, no RLS change — `material_po_generator_entries.notes` was already the column and both doors already wrote it.

## Why

When the office mints a counter PO code the tech has just said what it is for, and nothing wrote that down. The desktop form's box read "Optional notes…", the phone form's placeholder already hinted at material, and the only reader was the ledger itself: the text to the tech omitted the note, and the invoice form's PO check said whether the code existed and nothing else. So the office learned what was bought weeks later, on the invoice.

## The change

- **`src/lib/materials/poCodeStatedNeed.ts`** (new) — the wording in one place: `STATED_NEED_LABEL` ("What they said they need"), `STATED_NEED_COLUMN` ("Said they need"), `STATED_NEED_PLACEHOLDER`; and `poCodeSummaryLine()` — the Copy / SMS line with the claim last, unchanged when there is none. +4 tests.
- **`MaterialsPoGeneratorTab.tsx`** — the field is labelled and placeholdered from the kernel; the ledger column reads *Said they need*.
- **`DispatchModePo.tsx`** — step 4 likewise; `PoResult` carries `statedNeed`; the result screen shows it under the person line; `resultSummary` is `poCodeSummaryLine`, so **Copy** and **Text to …** carry the claim.
- **`supplyHouseInvoiceForm.ts`** — `PoLedgerEntry` / `PoLedgerEntriesByCode`, `poLedgerCodes()` (the code set the existing checks read), and `poLedgerEntryCard(hint, entries)`: a card for an `on_ledger` hint — job label, `for <person> · <day> · by <minter>`, the claim or null. +5 tests.
- **`SupplyHousesTab.tsx`** — the house's ledger query selects the row (job, for-user, created-by, notes) instead of `po_code` alone; state is the map by code and the set is derived; the invoice form renders the card under the hint (`data-invoice-po-entry`), with *Nothing written down when the code was minted.* for a matched row with no claim.
- Guides *raise a purchase order* and *run the day from your phone with Dispatch Mode*; GLOSSARY → PO Generator ledger.
