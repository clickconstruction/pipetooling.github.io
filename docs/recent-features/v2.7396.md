# v2.7396 — Stickers: the first scan reads the name off the sticker (2026-11-15)

Punch list #329, design section 10, PR 9 of its four (`to-dos/stickers-before-boxes/README.md`), on Taunya's go of 2026-11-15 for PRs 8 to 10. Client only: no migration, no edge function. `sticker_by_code` and `box_sticker_facts` have answered `box_name` since v2.7312, and `place_sticker` has named a new box by its sticker's name since then.

## What changed

- **`stickers.ts`**: `StickerFacts.boxName`, read from the function's `box_name` in capitals. `stickerSayName`, `stickerNameIs`. `placingVerdict` says *this sticker* for a named one, so *Marcus put this sticker on G78 a minute ago* names the box once.
- **`stickerPlace.ts`**: `stickerOpening` is how the sheet opens. A name the site has no live box of opens **It is a new box** on that name. A name the site has opens **It is on a box I know** with that box picked, and `twinName` is the next letter at the spot (`nextTwinName`, PR 7: G78B, or G78C when G78B stands). A numbered sticker opens as before, the boxes deciding. `stickerNewTitle` takes the sticker, *Sticker G78 is new*. `stickerMarksWords` is what a row says of its stickers: nothing for a sticker printed with the box's own name, *sticker reads G78* for one printed with another, the number for a numbered one. `stickerMarksByBoxOf`, `matchStickerWords`, `stickerReadsOtherWords`, `nameIsHereWords`, `twinNoteWords`. `placeOutcome` says a named sticker's result without the name twice: *G78 is made, with its sticker on it.*, *G78B is made, with sticker G78 on it.*
- **`StickerNewSheet.tsx`**: the name on the tape large with the number small beside it. On a name the site has: one line, *G12 is a box on this site already.*, the box searched for and picked, the press *Put 0159 on G12*, and **It is a different box**, which opens the new box on the next letter with *The sticker reads G78. This box will be G78B, and a scan will say so.* The search and the pick are the person's once they touch them. On the new box a named sticker has no chip beside the name.
- **`stickerPlaceIo.ts`** reads `box_name` with the stickers on boxes, and **`useJobStickers`** hands `marksByBox` beside the numbers.
- **`TallyOnSiteTab.tsx`** and **`JobsMaterialsTab.tsx`**: a box's row and header read `stickerMarksWords`, so *G78 · 0159* is *G78* for a sticker of its own name. A scan that opens a box through a sticker whose tape reads another name says *This sticker reads G78. The box is G78B.* as the box opens.
- The site guide's **Stick a sticker on a box**, the office guide's sticker section, the map and the Glossary.

## The picks

- **The press keeps the number**: *Put 0159 on G12*, as section 10 writes it. On the one screen that is about a single sticker, the number says which sticker goes on.
- **A sticker of its own name says nothing on a row.** Section 10: the number shows only where it carries news. The match list still marks a box with *no sticker* by whether it has one, so a box whose only sticker is its own reads neither.
- **The name on the tape decides the branch**, not whether the site has boxes with no sticker. A site in the middle of a walk has both, and the tape says which this is.
- **Signed out, a blank named sticker still reads its number**: *Sticker 0147 is not on a box yet.* That page is the edge function `box-read`'s answer, and changing it is a deploy that needs Taunya's go by name. It shows no contents either way.
