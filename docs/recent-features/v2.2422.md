# v2.2422 — Alternates block redesign + inline renaming (2026-08-28)

Owner-approved via the "Alternates on the Letter" mockup artifact (2 rounds, 2026-08-28).
The old block flattened alternate SCOPES and alternate PRICES into one absolute-first list
and leaked internal scenario names ("PEX in lieu of copper · Default: $41,700.00").

**Letter rendering** (`coverLetterSamePage.ts` + `bidDocuments/coverLetter.ts`):

- `CoverLetterAlternateItem` is now delta-first (`deltaText` "Deduct $X" / "Add $X" /
  "no change" bold, absolute amount in parens) and gains `options[]` — offered prices nested
  under their scope as "— or <label>: Deduct $X ($Y)" lines.
- `formatAlternateDelta` → `formatAlternateDeltaText`: Add/Deduct wording ("reduced/added"
  dropped per owner), "no change" for a matching price, null only when there is no headline.
- `buildAlternatesBlock` groups option sections (offeredPricingId) under their scope
  alternate by `bidVersionId`; options on the BASE scope (or orphans) print as standalone
  bare "Alternate N" items. Scope alternates are numbered "Alternate N — <name>"; a saved
  click-to-edit label prints verbatim (no forced number).
- An option's "— or" label comes ONLY from `cover_letter_alt_texts` — internal scenario
  names never auto-print.

**Panel** (`BidsCoverLetterTab`): every version name and price-option name in the step-1
checklist gains a ✎ → inline rename. A version rename writes `bid_versions.name`; an option
rename writes `price_book_versions.name` AND stores the same string as the letter label for
that offered price (one name everywhere). Option rows changed from `<label>` to `<div>` so
the ✎ doesn't fight the checkbox.

**"In the letter:" strip**: offered prices fold into their scope's entry — "PEX in lieu of
copper (alternate, 2 prices)" — instead of repeating the version name per price.

41 kernel/renderer tests updated/added; verified live on BP398 (offer → bare "— or", rename
"Default" → "Standard-grade fixtures" → named "— or" line, "no change" lead on the
same-price alternate).
