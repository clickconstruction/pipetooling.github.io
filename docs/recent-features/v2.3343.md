# v2.3343 — Cash App reconcile: the memo rule ignores withheld (minus-prefixed) amounts (2026-09-11)

Client only. Found on the first live re-match after v2.3333: the memo `-500 for motorcycle 1809.20 paid via cashapp` correctly backed the $1,809.20 send, but its `-500` (money withheld for the motorcycle) also claimed an unrelated $500 send four days later.

**Change**: `memoAmounts` in [`matchCashAppTransactions.ts`](../../src/lib/cashapp/matchCashAppTransactions.ts) skips a number written with a minus in front (`-500`, `- 500`). Arithmetic memos still read both sides (`969.89 - 500 = 369.89` → 969.89 and 369.89). Tests updated (+1).

**Data**: the one misfiled row in prod (Malachi, 2026-04-10, $500, `#D-NVXLQVXQ`) was put back to review by hand before this shipped; after a re-match it stays there.
