# v2.4525 — Pipeline: the automatic checks read the new section headers (2026-10-04)

Tests only; no client change, no migration, no edge function. The E2E Smoke workflow failed on every `main` run from v2.4512 on, and every failure was on `/jobs?tab=stages`.

## Why it failed

v2.4512 replaced the six Pipeline section headers with `StagesSectionBandTitle`: the name, the count in a pill (`.stagesBandCount`) and the dollars (`.stagesBandTotal`). The header's text went from *Working (29) - $391.8k* to *Working 29 $391.8k*. Two specs still waited for `/Working \(\d+\)/` in `main` as their "the board has loaded" marker, so they timed out on a page that had loaded fine:

- [`e2e/stages-board.spec.ts`](../../e2e/stages-board.spec.ts): the section-totals test, and the Total by Name test behind the same wait.
- [`e2e/viewport-smoke.spec.ts`](../../e2e/viewport-smoke.spec.ts): the 375, 760 and 900 px overflow checks on the Stages page, and *Stages tables scroll inside their own wrappers*.

## What changed

- **The marker is the count pill.** Both specs wait for `#stages-working .stagesBandCount` to read `/^\d+$/`. The pill reads "…" until the section's count lands, so a number there carries the old marker's meaning: the Working section has rendered with its count. A selector on the header also cannot be satisfied by the stage bar, which draws *Working* and a count of its own.
- **The totals test reads the dollars too.** It now checks `#stages-working .stagesBandTotal` starts with `$` and a digit, which the old regex never did despite the test's name.
- **`viewport-smoke`'s page list** takes an optional `within` selector per page; a page without one still looks for its marker in `main`.
- **The phone board** hides the section headers with CSS and keeps them in the DOM, so the same selector serves the 375 px checks.
- [`docs/E2E_SMOKE.md`](../E2E_SMOKE.md) rule 6: grep `e2e/` for a surface's visible text as well as its accessible name. This header kept every accessible name and changed only its text.

## Verified

The whole suite against production with the repointed specs: 46 passed, 1 skipped (the quarantined always-mounted spec).
