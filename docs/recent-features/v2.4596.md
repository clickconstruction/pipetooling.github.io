# v2.4596 — Contracts: the customer portal and the copy you email name both signers (2026-10-05)

Punch list #64, PR B of two, stacked on [v2.4590](v2.4590.md). PR A put the names into one kernel at `supabase/functions/_shared/jobContractSigners.ts` and fixed every reader in the app. This PR is the edge side: three functions read the same kernel. No table change, no migration.

## The change

- **`customer-portal`** (item 6). *Your agreements* selects the frame columns (`recipient_name, signer_consented_at, co_signer_name, co_signed_at, co_signer_printed_name`). `signerName` is `signerNamesLine`, so a signed two-frame agreement reads *✍ Signed by Sam Owner and Alex Owner · …*. A part-signed one gains `signingProgress` from `framesWaitingLine`. The page shows *Sam Owner signed · waiting on Alex Owner* there in place of *Waiting for your signature*, which was wrong for the spouse who had already signed. `portalPayload.ts` parses the field as optional.
- **`share-job-contract`**. *Email a copy…* says *signed by Sam Owner and Alex Owner*. A separate `signedBy` carries the email's words. `signerName` stays the first frame's printed name for the rebuilt PDF, which prints each frame's own name.
- **`legal-portal`**. The contract select adds the frame columns. The firm's page runs the coverage kernel, which names both since v2.4590.

## Deploy

After the merge: `customer-portal`, `share-job-contract` and `legal-portal`. Each reads either order safely. Before the deploy the portal, the email and the firm's page name the first signer, as before. A client from before this PR ignores `signingProgress`.

## Verify after deploy

Run this once after the three deploys, on a job with a two-signer agreement, together with v2.4590's *Verify after merge* list:

1. **The customer portal.** Open the job's customer link, then *Your agreements*. A signed agreement reads *✍ Signed by both names · date*. A part-signed one reads *first name signed · waiting on second name* in place of *Waiting for your signature*.
2. **The copy email.** In the Contract window, press *Email a copy…* and send it to your own address only. The email says *signed by both names on date*.
3. **The firm's page.** On a matter that includes the job, the law firm's page reads *Signed … by both names*.
4. **One signer.** Each of these reads as it did before on a one-signer agreement.
