# v2.2145 — Quickfill "Jobs Cleanup": unlinked sub labor + the Pipeline's money cards (2026-08-23)

Owner ask (mockup approved as built: https://claude.ai/code/artifact/53e9ce88-4e03-4e14-98b0-3b5543b722a8): a Quickfill station that (1) surfaces every sub labor sheet not attached to a job as an easy click into its Edit form, and (2) carries all of the Pipeline's "Today's Money Opportunities" cards.

- **Shared cards component** — the Today's Money Opportunities box moved verbatim out of [`PipelineOverview.tsx`](../../src/components/jobs/PipelineOverview.tsx) into [`PipelineMoneyOpportunities.tsx`](../../src/components/jobs/PipelineMoneyOpportunities.tsx) (moves grid, statement-round cards, chase card, fix-ups card; `headerNote` / `emptyText` props). The Pipeline renders it unchanged; Quickfill renders the same component with `fixups={[]}` (its Missing job info station already has those) — copy and tones live once.
- **Standalone inputs** — new hook [`usePipelineMoneyOpportunities`](../../src/hooks/usePipelineMoneyOpportunities.ts): `fetchStagesHeaderStats(null)` (stats + lean billed rows), `useArBankUnallocatedCount`, the pay-speed / promised-date / chase-touch RPCs → `summarizePaymentChase(buildPaymentChaseQueue(…))`, and the GC statement round (`buildGcReviewRollup` over lean rows + certifications + round marks + senders → `buildStatementRound` / `summarizeStatementRound`). Role gates mirror the Stages tab (AR: dev/master/assistant-like/primary; chase + rounds: office roles). Every extra is fail-soft.
- **Deep link** — new [`stagesMoneyMoveLink.ts`](../../src/lib/jobs/stagesMoneyMoveLink.ts) (`?stagesMove=capable|chase90|fixDates|ar|chase|gcRoundCertify|gcRoundStart`, + tests); `Jobs.tsx` routes it (same `jobsListLoading` handle gate as the other stages deep links) to the new `JobsStagesTabHandle.openMoneyMove(key)`, which runs the exact PipelineOverview callbacks (clear live search → open the Capable list / apply the 90+ or no-line filter + focus Billed / AR modal / chase modal / GC Review certify or start round).
- **Unlinked sheets** — new kernel [`subLaborUnlinked.ts`](../../src/lib/jobs/subLaborUnlinked.ts) (+ tests): a sheet is unlinked when its typed `job_number` resolves to no job via `resolveSubLaborJobByNumber` (blank, or HCP / Click # / effective-number mismatch — the Edit form's own rule); rows carry contractor, typed number, address, date, total / paid / backcharges / due (same math as the Edit header); newest first. Linked sheets never appear; nothing re-links automatically; paid sheets still count.
- **Section** [`QuickfillJobsCleanupSection.tsx`](../../src/components/quickfill/QuickfillJobsCleanupSection.tsx): sheets via `fetchAllRows` over `people_labor_jobs` + lean `jobs_ledger` (resolution), then items + payments only for the candidates; **Link job** → `/jobs?tab=sub_sheet_ledger&editLabor=<sheet id>` (the existing router already opens by id). Metric = sheets + cards. Registered in `Quickfill.tsx` (`jobs-cleanup`, default banner, wiring case); `normalizeQuickfillSectionOrderFromValueText` gains `SECTION_INSERT_AFTER` so a section added after an org saved its order lands beside its default neighbor (after Missing job info) instead of the tail.
- Help: `quickfill.md`. Verified live on prod data: 14 unlinked sheets ($16,433 · $4,200 due) + 6 cards = "20 open"; "Show 90+" → Pipeline Billed filtered to 3 rows; "Link job" → Edit Sub Labor for the Airfordable sheet.

Client-only; no migration.
