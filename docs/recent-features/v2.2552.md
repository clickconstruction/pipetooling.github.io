# v2.2552 — twin-census T2 path census + BT-15 scope-mismatch rule (2026-08-31)

Census Toolkit Plan tool T2: `scripts/twin-census/path_census.py` — traced
footage from vector plan sets. Buckets every stroked path by CAD pen
(gray, width) with CTM-tracked coordinates, chains a pen's strokes into
runs (endpoint union-find), filters symbol/margin/border chains, and
reports per-run footage at a grid-calibrated scale (grid-label spacing vs
stated bay size). Pen→system assignment is a one-look visual overlay per
set (72dpi render, 1px = 1pt).

Validation on TSAOG decoded four pens (sanitary, CW water, fire,
storm/RD) and — more importantly — exposed that **BT-15 was scored
against the wrong package**: the fetched 134-page set is the core/shell
campus CDs (zero fixtures), while the reference $404k bid priced the
TSAOG tenant fit-out (42 fixtures, demo, ~3,400 ft of pipe). BT-15's
−28% and its market-band interpretation are void; flag stamped on b421.

New backtest protocol rule: **at unseal, line-compare the reference
takeoff's fixture tags against the fetched plan set** — any reference
fixture absent from the set means scope mismatch; stop scoring. (This is
tool T4's first check, adopted as doctrine ahead of its build.)
