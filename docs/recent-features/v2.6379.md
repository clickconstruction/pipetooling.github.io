# v2.6379 — The Development page’s fifth tile says what is not yet billed, and the GC contact is set on the page (2026-11-02)

The Gray Fox design spike (`to-dos/developments/SPIKE_GRAYFOX.md`), PR 3 of four, on v2.6378: candidates F and H of the notes. On Gray Fox the fifth tile read *Open on bills · $0 · nothing unpaid* while $186,116.84 of the site's price was still to bill, and the GC contact line read *none yet · add one* with a door to the newest bid's Edit tab, where fifteen bids each needed the same three fields typed. No migration: the GC contact stays the three columns on `bids`.

## Change

- **Not yet billed (F).** `src/lib/developments/siteMoney.ts`'s `unbilledTileWords(model, openOnBillsUsd, money)` answers null while a bill is open or nothing is left, else the tile's words: cap *Not yet billed*, the value the band's left, the sub *$3,200 done, not billed · 5 jobs with money left* (the done-not-billed part only when it is more than zero; the jobs are the live section rows with money left). `DevelopmentPage.tsx` draws that tile, amber, in the fifth cell when the words come, else the *Open on bills* tile as before. `src/lib/developments/countCards.ts`: the `openOnBills` card's empty branch gains a *Waiting, not yet billed* group, the waiting jobs with `revenue − payments_made > 0`, biggest first, each `$X left`, under the head *$186,116.84 not yet billed* (or *Nothing billed is unpaid* with no money shown).
- **The GC contact on the page (H).** `src/lib/developments/gcContact.ts`: `gcContactTargets(bids, current)` picks the bids the write goes onto (a blank name, or the name that equals the current contact's, case ignored); `gcContactDraftProblem` and `gcContactValues` check and trim the draft; `gcContactDoneWords`. `gcContactWrites.ts`: `putGcContactOnBids(ids, v)` is one update over the ids that refuses on zero rows and returns the count, `restoreGcContacts(before)` writes each bid's three fields back. `DevelopmentGcContactSheet.tsx` (`gc-contact-sheet`): the name, phone and email, the primary press `countedLabel('Put it on' | 'Change it on', n, 'bid')`, a caption with the count written and the count kept, Escape closes. On the page (office only, a site with bids): *none yet · add one* (`gc-contact-add`) and **Change ›** beside a contact open the sheet; the write's toast offers **Put it back**. The old door to the newest bid stays for a site with no bid.
