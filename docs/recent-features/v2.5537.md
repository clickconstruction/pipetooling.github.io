# v2.5537 — GC projects and Messages sit in the middle of a wide screen (2026-10-14)

The owner's screenshots of 2026-10-14: on a 2,000 px screen the Bid Board's column sits in the middle (its `.pageWrap` is `width: 100%` with `maxWidth: 1400px; margin: 0 auto`), while GC projects hugged the left edge beside it. Its outer `div` was `display: grid; maxWidth: 1100` with no auto margins, so the cap held it to the left of the column. `/messages` (`Messages.tsx`) was born from the same line. No migration, no edge function.

- **`GcProjects.tsx`** and **`Messages.tsx`**: the outer `div` gains `width: '100%'`, `boxSizing: 'border-box'` and `margin: '0 auto'` beside its `maxWidth: 1100` (and a `data-gc-page` / `data-messages-page` hook for the smoke). The width matters: in Layout's flex column an item with auto cross-axis margins is not stretched, so without `width: 100%` the grid would shrink to its content instead of filling the cap. Under 1,100 px nothing changes; the padding is inside the cap now (`border-box`), so the page's edge gutter reads the same.
- **Tests**: `GcProjects.render.test.tsx` (+1, *the page sits in the middle of a wide screen*: the cap, the width and both auto margins on the page `div`); `Messages.render.test.tsx` (+1, the same on `/messages`).

Left alone: the Banking page (`Banking.tsx`, `maxWidth: 1200`, no auto margins) hugs the left edge the same way; the owner's ask named the two pages.
