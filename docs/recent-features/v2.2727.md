## Guide

- [`src/content/help/onboard-a-new-subcontractor.md`](../../src/content/help/onboard-a-new-subcontractor.md) — `category: Office`, roles dev / master_technician / assistant / controller, `order: 74` (just ahead of `send-one-contract-to-one-person`). Four numbered stops: **roster** (Prospects → Hiring → Hire "Add to roster", or People → Users → Manage accounts → Invite via email / Manually add user), **paperwork** (People → Contracts → Assign packets → Subs → Send; "Remind on Dashboard after clock-in" → the Required Signatures prompt), **insurance and tax documents** (already-signed document on the Contracts row, then type + expiry on People → Subs → Documents → compliance badges), **first job** (per-step work order or add to a job). Closes with a "Where everything is" table and a sample first-week timeline.
- Explains the Master Subcontract §17 insurance election (Option A own coverage / Option B 10% risk charge) and the DWC-83 waiver path so the office knows which documents to expect from each sub.
