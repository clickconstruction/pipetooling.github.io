# v2.6861 — Permits: New Braunfels, San Marcos and Seguin (punch list #292, revision 4) (2026-11-10)

The rest of the owner's four cities. Each publishes its permits as a layer on a city map server, so one more door reads all three.

## What changed

- **`_shared/permitCities.ts`**: `mapLayerReader` is a `FeedReader` over an ArcGIS feature layer: a `where` for the kept kinds applied for or issued since a day, the layer's own page size (`pageSize`, 1,000), the point asked for in degrees and carried as `_lat` and `_lng`, a refusal read from the layer's `error`. `dayFromMs` reads a layer's millisecond date as the day it names; `rawOf` keeps the record with its dates as days and without the layer's bookkeeping columns.
  - **New Braunfels** (`nb-permits`, the Permits layer of the city's open-data service): `classifyNewBraunfels` reads the type and the subtype (a copied subtype ends in "(clone)"); who pulled it is the contractor once the city has one, else the applicant; the owner's name stays on the row.
  - **San Marcos** (`sm-permits`, the city's building-permits layer): `classifySanMarcos` reads the type with the land use, so apartments filed as New Residential on multi-family land are commercial work; square feet and a project name, no name of a person or a company.
  - **Seguin** (`seguin-permits`, the city's permits layer): `classifySeguin` reads the start of the description; the layer's name column is the desk that issued the permit, so the row names no one; the city's link to its own page for the permit stays on the row.
- **`permit-pull`** pages by `min(2000, feed.pageSize)`, so a layer that hands over 1,000 rows is not taken for a short last page.
- **`permitPublic.permitOwnPage(raw)`** and the building sheet's **Open this permit at the city**, shown when the feed's row carries an https address (Seguin's `USER_URL`, Austin's `link`).
- Each of the three has its county clerk's deed search on its card: Comal County's land records site, Hays County's self-service records search and Guadalupe County's ROAM search, each found from the clerk's own page or the county's own address and tested the day it was added.
- The guide lists the five cities and what each one publishes.
- No migration.
