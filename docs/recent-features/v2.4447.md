# v2.4447 — Every window sits below the iPhone clock (2026-10-02)

No migration, no edge function. The sweep [v2.4444](v2.4444.md) left open (*Not done — the larger class*), after [v2.4397](v2.4397.md) fixed the Lien desk. A mechanical sweep: it merges alone, and on a rebase conflict the script is run again, never hand-resolved.

## The rule

The page is `viewport-fit=cover`, so on an iPhone with the app on its Home Screen a `position: fixed` layer over the whole screen starts under the status bar (47–62 px). Two parts, one script ([`window-below-status-bar.mjs`](../../scripts/codemods/window-below-status-bar.mjs)):

1. **The layer pads its top by `var(--app-top-chrome, 0px)`.** The dim still covers the status bar; whatever is inside starts below it. One `padding` string (`'1rem'` → `'calc(1rem + var(--app-top-chrome, 0px)) 1rem 1rem'`), or `paddingTop` alone when the layer had no padding. Never `padding` beside `paddingTop` in one style object.
2. **A panel whose height is in `vh` is clamped to the padded layer**: `'90vh'` → `'min(90vh, 100%)'`, `'min(90vh, 720px)'` → `'min(90vh, 720px, 100%)'`. A percentage on a direct child of a fixed layer is the room left inside the padding, so the panel cannot grow back under the bar, and a sheet from the bottom or a top-anchored card cannot be pushed off the other edge. `.roadmap-task-card` and the Job window already worked this way.

Why padding alone is not enough: a centred card taller than the room left overflows both ways, so a `94vh` card on an 844 px screen still reached 29 px under a 59 px bar; a top-anchored `calc(100vh - 6rem)` card would have lost its last 59 px off the bottom instead.

## The check

`npm run check:status-bar` (`--check`) runs in `ci.yml` and `deploy.yml` beside the other window checks. It fails on a full-screen fixed layer with no top inset, on a `vh` height directly inside one, on a fixed full-screen CSS rule with none, and on a layer that holds only hand-placed things (padding moves nothing there, so it wants a reason). `--list` prints every layer and how it stands; with no flag the script rewrites what it can read. The rule's one sentence is in [`AI_CONTEXT.md`](../AI_CONTEXT.md) → *Windows (modals)*.
