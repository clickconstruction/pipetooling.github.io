# v2.2527 — Robots tab group: Robot Board + Audits merge under one 🤖 tab (2026-08-31)

The Bids top strip carried two robot tabs (`🤖 Robot Board · N`, `Audits · N`). They
now share one icon-only **🤖** group tab, following the Followup group precedent
(v2.1387/v2.2473):

- **Top-strip button**: label is just the 🤖 icon; its badge is the *actionable*
  number (pending audits, `useBidAuditsPendingCount`), dropped when zero. Shows when
  there are robot bids **or** audits; hidden for everyone else, as before.
- **Lenses inside**: `Robot Board · N` and `Audits · N` render as the same
  segmented-control chrome as the Followup lenses, each keeping its original
  visibility gate and tooltip. The bar only appears when both lenses exist.
- **Landing rule**: entering the group selects Audits when any are pending (or it is
  the only lens), else Robot Board; re-clicking while inside keeps the current lens.
- **No key changes**: `robot-board` and `audits` stay valid `activeTab`/URL keys, so
  the v2.2500 twin-bid deep links and audit notification links land unchanged. The
  group button's `data-tabkey` tracks the active lens so `ScrollableTabStrip`
  auto-scroll still finds it.
- Content components untouched (`BidsBidBoardTab` with `robotBids`, `BidsAuditsTab`).

Docs: help guide `read-the-bid-board.md` Robot Board section updated;
`PROJECT_DOCUMENTATION.md` §13 line mentions the group.
