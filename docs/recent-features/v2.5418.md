A pure kernel with its test. No screen, no migration, no edge function; `compose.ts`, `quo/send.ts` and `followUp/newLane.ts` are untouched, and `messages.mailbox` and the STOP per box are R6's SQL.

- **`src/lib/messages/boxes.ts`:**
  - `Mailbox` (`team` · `bids`), the same union `followUp/newLane.ts` declares in #5562, which imports it from here once both land. `BOXES` says who each box is for: team holds customers, leads, subs and candidates; bids holds trades, architects and supply houses. The owner's open call on team@ against office@ is one comment there.
  - The addresses and numbers are `BoxSettings`, the caller's, read from one `app_settings` key, `messages_boxes_v1` (`BOXES_SETTINGS_KEY`), JSON `{ team, bids }` of `{ address, phone, numberId }`. Today one secret each holds the single company number and mailbox (`QUO_PHONE_NUMBER_ID`, `QUO_COMPANY_MAILBOX`).
  - `boxForKind(kind)` takes the kind as a string, so it reads #5565's seven kinds before they land; an unknown sender has no box. `boxForNew(contact)` is the kind's box, else team. `boxForReply(wroteTo, contact)` is the box they last wrote to, whatever their kind, so a GC customer who wrote to bids@ hears back from bids@ and the next conversation we start goes from team.
  - `fromWords(box, channel, settings, company)`: *from team@…* or *from the company number 512-555-0144* (*the bids number* for bids), then the company, one piece each. `phoneWords` writes the area code out of parentheses so the line passes `plainWordsFailures`.
  - `boxOfInbound(line, settings)`: the line's `mailbox` once R6's SQL fills it, else the Quo number id it came to, else the address it was sent to (a display name allowed), else null, which #5562's New lane reads as the team line.
  - `stopScope(channel, word, to, at)` and `stoppedOn(channel, box)`: a STOP to one of our numbers silences that number for the person and never the other, as carriers scope it to the pair; a START reopens the one it came to; a word to a number it cannot place reaches both, so a STOP is never missed. It returns the channel's whole `opted_out_by_box` (the lead's lean for R6's column: jsonb keyed by box). A box with no entry reads the older `opted_out_at`, which stops every box.
