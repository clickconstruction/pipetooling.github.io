# v2.5791 — Lien desk: the master signs on anyone’s screen with his signing code (2026-10-23)

Punch list #150 (`to-dos/lien-sign-on-any-screen/`), PR 2 of 2; PR 1 is v2.5788 (the code in Settings, the table, the RPCs, the guard rule). The owner's screenshots: a dev pressed *Approve* and got a block that typed *his* name in cursive over the master's license, and the guard would have taken the press. This PR makes the line the master's whenever the screen is not his own, and gives his code a field there.

## What changed

- **[`LienNoticeSignLine`](../../src/components/jobs/LienNoticeSignLine.tsx):** a third mode, `code`, behind `codeSigner` (his first name and whether his code can be taken: `ready · none · locked · not_live · loading`). His name waits in cursive, the tag reads *Malachi signs here with his code*, a password field for four to six digits sits under the rule with *Four to six digits, his alone. The record names this screen.* or the last wrong-code answer (`codeProblem`), and *Draw instead* / *Code instead* switch. With no code, a locked code or the database side not live, the pad leads and the line says why (`lienSignLineCodeWords`); the status arriving later moves an untouched pad to the code once. The handle gains `code()`; `isEmpty()` is true under four digits.
- **[`LienDeskModal`](../../src/components/jobs/LienDeskModal.tsx):** `otherScreen` = the job has a master and he is not `authUserId`. Then `signerName` is his, the line gets `codeSigner` (his status read through `lienSignCodeStatus`, re-read after a lock or a missing code), the press hands a code to `signLienDeskItemWithCode` (a wrong code lands under the field with the tries left, and throws so the toast says it too) and a drawing to `signLienDeskItem` as *his* drawing on this screen (`signer` = the master, `onDevice` = the viewer — before this a drawing on the dev's screen was recorded as the dev's). The office's awaiting footer (assistant · controller) carries the same line and a green **Sign and approve ▸** above *Leader here, Approve ▸*. The Ready pile's confirm group takes a code signature beside a pen record: *Your signing code signed this notice on Robert’s screen · Oct 23 … Not you? Press Not me, then change your code under Settings, Your account.* with **Yes, it was me ▸** / **Not me** over the pen train's `confirmLienPenSignature` / `disownLienPenSignature` (the guard accepts both for mode `code` since v2.5788). The chip reads *signed by code Oct 23 · on Robert’s screen* ([`lienFootChip.ts`](../../src/lib/jobs/lienFootChip.ts), `onDeviceName`).
- **Do now ([`lienNextUp.ts`](../../src/lib/jobs/lienNextUp.ts)):** a code signature he has not confirmed is his own row, *Signed with your code Oct 23 · on Robert’s screen*, under *Signed with your code, as recorded* (*Signed by pen or code, as recorded* when both kinds wait).
- **`notify-lien-approval`** (`kind: 'code_used'`, [`docs/EDGE_FUNCTIONS.md`](../EDGE_FUNCTIONS.md)): the screen's sign-in calls it best-effort after the RPC answers ok; it tells the signer alone — *Your signing code signed a lien notice · 804 · Summit GC- Auto Zone · $9,006 · signed Oct 23 · on Robert’s screen*, the tap landing on the notice in Ready, the email ending *If that was not you, change your code under Settings, Your account.* (`lienCodeUsedPush` in `_shared/lienApprovalPush.ts`). A code typed on his own screen sends nothing. **Deploy after merge.**
- **Guide** *send lien notices from the Lien desk*: **Signing on someone else's screen** replaces the placeholder paragraph under *Your signing code*.

## Is this the best we can do?

- **The line never shows the wrong name again.** On another's screen the cursive is the master's, the tag names him, and a press without his code or his ink does nothing but say so. The trap the findings opened with is closed on every role's footer.
- **One block, three honest records.** His code (*Typed by Malachi with his signing code … on Robert’s screen*), his hand (*Drawn by Malachi … on Robert’s screen*), or the office's word — each sentence says what happened, and the first two are his own acts.
- **He hears about every use, and can undo it in one press.** A code that was watched or guessed is cleared by him with *Not me* and changed in Settings; the approval stands, the run holds the notice. The owner's concern on record, answered without a text to his phone.
- **Not done here:** the run window's amber card (*Leader here, sign ▸*) and the office's Ready footer still offer his hand and the pen record only; the code field there is a follow-up. *Only you can approve · 3* on a dev's desk for another master's jobs is still worded as *you*; a residual.
