# v2.8483 — Takeoffs: a long assembly name no longer pushes Line total off the sheet (2026-11-24)

A fault found on the live look at v2.8476, the same day. No migration, no edge function.

## What was wrong

On **Bids → Takeoffs**, the small grey line under a part's name says its type and, where the line came from an assembly, the assembly's name: *Part · Sink · the assembly's name*. The line is one unbroken run with dots at its end, and its style said `minWidth: 0`. In a table that changes nothing: a column is as wide as its widest unbroken line. So a long assembly name set the Part column's width, and with it the table's.

Seen on the live site on a ZZ test bid, signed in with the dev link, read only: at a 1,400 px window the Part column was 508 px and the table 917 px in an 884 px box. v2.8476's box noticed the overflow and fell to its last fit, so all 12 deletes took a press, but Line total sat under the pinned presses until the box was scrolled sideways. Before v2.8476 the same table ran under the rail at 1,400 px too, which is the estimator's report at a width where the harness rows fit.

The page did not scroll sideways before or after.

## What changed

- The sub-line has `width: 0` beside its `flex: 1`. With no width of its own it asks the column for nothing, takes what the column has and shortens with the dots. Its whole text is its hover (`title`), which it did not have.
- In a roomy table the Part column now takes 38% of the table (`.takeoffLinesBox[data-fit='roomy'] thead th:nth-child(2)`). A text field asks for 260 px and no more, so the column stood at 284 px in any window and every spare pixel went to the columns beside it. At 1,400 px it is 336 px, and 464 with the rail hidden. This is a change to the wide look: the part's name shows more of itself, and the Fixture and Unit price columns give up the width (193 to 163 and 179 to 158 at 1,400).

## What it leaves

- The sub-line shows about half of a 75-letter name at 1,400 px. The rest is on its hover, which a touch screen does not have.
- Any other unbroken run in a cell can do the same. The ones in the row today are short: the Sold in chip, *In N assemblies*, the lowest house's name, the line total.
- Chromium only.

## Tests

`BidsTakeoffTab.render.test.tsx` gains a smoke: a line from an assembly with a long name draws its sub-line unbroken with no width of its own and its whole text on its hover.
