# v2.3792 — Pipeline dates say how far away they are (2026-09-23)

The last open wording call from Taunya's "when is the job scheduled" train (v2.3752 · v2.3785 · v2.3788). Grace kept the `T+2` idea — it says *how far*, not just *when* — and picked option A of the mock-up's *Best of both*: the calendar date on the label line, the distance from today in words under it, ahead of the fact. Client only, no migration.

## The change

- **[`stagesScheduleStrip.ts`](../../src/lib/jobs/stagesScheduleStrip.ts)** — `stripDistancePhrase(ymd, today)`: the app's `formatRelativeDayPhrase` words (today · yesterday · tomorrow · N days ago · in N days) up to 13 days, then *N weeks* and past twelve weeks *N months*, so line two never outgrows the 112 px column. The line-part helpers take `todayYmd` and put the distance first: NEXT *Wed Sep 23* / *tomorrow · 8–10 AM*; ENDS *Fri Sep 25* / *in 3 days · 3 visits* (a one-day plan stays *same day* — the NEXT line already carries the distance); LAST *Thu Sep 17* / *6 days ago · worked*; DONE *Mon Sep 21* / *yesterday · last visit*. New `stripBillParts` (**PAID** when a payment is among the latest day's events, else **BILL**, fact *sent* / *billed* / *paid*) and `stripFieldParts` (the Job Summary header's old `j:` — the later of worked and booked).
- **[`stagesJobReferenceDates.ts`](../../src/lib/stagesJobReferenceDates.ts)** — `BillingActivityDetail` carries `labels` (the events on the latest day) so the words can name the event; the tooltip is unchanged.
- **[`jobsStagesRowShared.tsx`](../../src/components/jobs/jobsStagesRowShared.tsx)** — the `b: T+2 (mon)` button becomes a BILL / PAID line in the same shape as the strip's lines, drawn only when there is a billing event (the empty `b: —` line is gone); the click still shows the explanation toast, now with the event and the old code. The `j:` code joins the strip's hover title.
- **[`JobsStagesCardList.tsx`](../../src/components/jobs/JobsStagesCardList.tsx)** — the `bill T+2 (mon)` chip reads *billed 2 days ago* / *paid today*; the plan arrow reads *→ Fri Sep 25 · in 3 days*.
- **The phone rows** (punch list #30's stage picker, which replaced the cards on a phone) — [`jobNextLine.ts`](../../src/lib/jobs/jobNextLine.ts) prints the caller's billing words as given; [`JobsStagesTab.tsx`](../../src/components/jobs/JobsStagesTab.tsx) hands it *billed 2 days ago* / *paid today* instead of `T+2 (mon)`, so a row reads *NEXT Thu Sep 24 1–4 PM · Abraham · billed yesterday*.
- **[`JobsJobSummaryTab.tsx`](../../src/components/jobs/JobsJobSummaryTab.tsx)** — the expanded header's `j:` / `b:` lines become **FIELD** *Tue Sep 22 · yesterday · worked* and **BILL** *Mon Sep 21 · 2 days ago · sent*; the codes are in the hover.
- Guide *see what days a job is on people's calendars*, GLOSSARY (`j:` / `b:` entry), `JOBS_STAGES_TAB_ARCHITECTURE.md`, `JOBS_TABS_ARCHITECTURE.md`.

## Not changed

The Job Detail window's billing row (it reads `deriveRecordedBillingActivityDetail`, which gains `labels` but renders as before) and the Glossary's T±n definition, which still describes the hover codes.
