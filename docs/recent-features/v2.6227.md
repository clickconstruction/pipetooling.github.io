# v2.6227 — Two law firms can share a county, with one first call (2026-10-31)

Punch list #222 (`to-dos/legal-firm-coverage-zones/README.md`), PR 3 of four. Taunya, 2026-10-30: *it is okay if multiple firms have the same coverage zones.* One migration, pushed right after the merge (`docs/migrations/20261031160000_legal_firm_shared_counties.md`); no edge function changes.

- **The ground.** `legal_firm_counties` holds one live row per firm per county with a `first_call` flag, at most one per county. `legal_save_county_coverage` is the one write: every county read before any is written, a stale county refused, nothing written on any refusal. SQL bed `legal-firm-coverage`.
- **`src/lib/legal/firmCounties.ts`** — `Coverage` (county → `{ first, also }`) beside `CountyAssignments`, which every reader that only needs the firm the desk picks keeps reading, now each county's first call (`firstCalls`). `savedCoverage` reads the rows (a row without the flag is first call; with none flagged, the longest-standing leads); `pressCounty` works on coverage (own clears, free colors, held asks; the first call coming off hands it to the firm that also covers); `answerHeld` (`share` · `first_call` · `move`), `makeFirstCall`, `countyChanges` over covers, `countySavePayload`, `heldQuestion` / `heldChoices` / `heldDoneWords`, `countiesLine` marking `(also)`. `assignmentsFromCountiesByFirm` retired; `coverageFromCountiesByFirm` reads the portal's counts-only payload. `firmAreaPresets.ts` and `firmWindowCoverage.ts` (rows read `first` or `also`; a case under review in a shared county counts for its first call) follow.
- **`src/lib/legal/firmCountiesSave.ts`** — `saveCountyChanges` calls the function; `stale` is the conflict, the missing function before the push reads as a database update.
- **`LegalCountyHeldSheet.tsx`** (new) — the three answers and *Leave it*, used by the Settings card, Firms… and the firm window.
- **The desk.** `useLegalMatters.coverage`; `firmForAccount` takes `also` and lists a sharing firm as a switch (`shared`), with `share` on the result; the chip's tail reads *· Snell also covers* or *· Alamo is first call*, the venue line names both. `LegalReleaseFirmChooser.tsx` (new) lists every firm that could take the account in the release sheet, its role, fee and what Click keeps; the pick is the header's switch.
- **The map.** `LegalFirmCountyMap` takes `also`: a shared county is the first call's fill striped in the other firm's ink (fill on fill vanished in dark mode, checked live), its label haloed, a *Shared by two firms* swatch in the legend; with a firm lit, a county it shares is not faint. The desk's Map legend and the contents card name the sharing; the portal's **Who covers what** names a shared county on both firms' rows.
- **The window.** A shared county's row reads *also covers · Alamo first call* and counts only the cases already with the firm; editing offers *Make first call*. A refusal keeps the draft; only a conflict reloads and closes.
- Guides `set-which-law-firm-covers-each-county` and `review-a-collections-account-before-it-goes-to-your-attorney` say what sharing and first call mean and where the switch is.
