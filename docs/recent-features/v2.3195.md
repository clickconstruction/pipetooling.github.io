## What shipped

- **[`BidPriceRequestsTable`](../../src/components/bids/BidPriceRequestsTable.tsx)**: columns are **Supply house · Requested · Request link · (actions)**. The Quote column, `quoteCell`, and the editor's quote-link input are gone; the empty-state `colSpan` is 4; the phone `minWidth` drops to 520. The editor's request field is a `type="url"` input with a `https://…` placeholder and the hint "the link to the request you sent — a Drive copy, a PDF". An outside row's request now renders as the address itself (`linkDisplayText`: scheme and `www.` stripped, cut at 44 characters with an ellipsis, full URL in `title`), the host label and the *sent outside* tag beneath; app rows keep **Vendor page** + *sent by app* + viewed / not viewed.
- The draft still carries `quoteUrl` from the row on edit, so editing a row that already had a quote link keeps it (nothing is silently cleared); a new outside row saves with `quote_url = null`. `validateOutsideRequest` is unchanged.
- **[`bidPriceRequests.ts`](../../src/lib/bids/bidPriceRequests.ts)** gains `linkDisplayText` (+1 test). The desk (`RfqDeskModal`) and the header summary ("N requests · M quotes in") are untouched.
