# v2.2958 — Test-gap audit: six money-adjacent kernels get their first tests (2026-09-06)

Fourth and last audit of the Plan B series (RLS v2.2954, docs drift v2.2956, help guides v2.2957). Tests only — no kernel, client, migration or edge-function change.

## What was checked

Every module under `src/lib/` without a colocated `*.test.ts`: 319 of 1,206. Of those, 140 are pure (no Supabase, React, DOM, PDF or fetch imports) — the rest are IO wrappers the kernel pattern deliberately leaves thin. The pure list was ranked by size and by what a wrong answer costs.

## What shipped

Colocated tests (63 cases) for the six untested pure kernels where a regression would touch pay, the bank feed, or the schedule:

| Kernel | Cases | What they pin |
|---|---|---|
| `parseCsv` | 10 | quoted commas, doubled quotes, embedded newlines, CRLF, BOM, no trailing newline, empty cells, blank-line shape |
| `parseBankingImportCsv` | 11 | QuickBooks register layout (title row account + ending balance, Payment → negative, Deposit → positive, totals row skipped with a warning), single Amount column, Debit/Credit aliases, account-name fallback, missing header, unreadable amounts and dates |
| `peopleHoursProportionalScale` | 9 | the scaler's real contract — every session gets `MIN_SEGMENT_MS` first, the remainder splits by the old ratio, the day lands on the target to the millisecond, packed contiguously from the first clock-in; open sessions ignored; null for a zero/NaN/too-small target; the day filter drops other people, other days, rejected and revoked; job/bid label maps |
| `dayJobMixPercentages` | 12 | second math (floor, open-to-now, never negative), allocation keys, grouping by job/bid with rejected/revoked/zero-length dropped, sort and pct-sums-to-1, re-normalisation, largest-remainder second allocation |
| `jobScheduleOverlap` | 10 | the 4 AM–8 PM wall at both edges, the 30-minute floor, `HH:MM[:SS]` parsing with a 0 fallback, half-open overlap (abutting blocks do not overlap), internal-overlap scan, candidate-vs-existing with excluded ids |
| `resolveCalendarWorkday` | 11 | time off wins (inclusive dates), continuous vs split templates, CDT/CST from the work date, company-zone fallback, weekend exclusion unless overridden, override fields layered over template defaults, midnight wrap, nothing → none |

Two expectations were wrong on the first run and the kernels were right: an unquoted "$15,970.50" in a fixture split on its own comma (real exports quote it), and the hours scaler is minimum-first-then-proportional by design, not strictly proportional. Both tests now document the actual contract.
