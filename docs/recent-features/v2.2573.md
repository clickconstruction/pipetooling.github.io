# v2.2573 — Robot audits join the Dashboard Needs-you card (2026-09-01)

The twin program's bottleneck is human audit throughput (23 pending at time of
writing), but the queue only announced itself inside Bids. Now the auditing
roles see it where their day starts:

- **New `robot-audits` Needs-you item** (`src/lib/dashboardNeedsYou.ts`, amber,
  people/planning tier 50): "N robot bids are waiting on your audit", figure =
  remaining count, action **Open Audits** → `/bids?tab=audits`. Persistent by
  the card's normal semantics — it renders while the count is nonzero and
  drains away at zero.
- **Wiring** in `DashboardPinnedQuickRow.tsx`: reuses `useBidAuditsPendingCount`
  (v2.2517), so the sealed-shadow hold (v2.2553) carries over — pending audits
  whose reference bid hasn't been sent are not counted, exactly like the Bids
  tab badge. Gated to `dev` + `estimator` (the auditing roles); Job Mode's
  `hideBanners` mount and Quickfill's card pass `robotAuditsEnabled: false`.
- Kernel tests cover gating, singular/plural copy, the 99+ cap, and tier
  ordering; help guide `audit-a-robot-bid.md` now opens with the Dashboard
  path.

No migration; no edge-function change.
