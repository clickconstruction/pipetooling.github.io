# v2.4607 — Help: the plain-words check reads a table row by its own words (2026-10-05)

Punch list #75, the plain-words sweep. The checker in [`src/lib/plainWords.ts`](../../src/lib/plainWords.ts) read a table row as one line of prose, so its `|` cell walls counted as words. *Share a sub their portal*'s 19-word row *Waiting on customer + a payable after date* counted 22 and failed. A cell holding only `—`, in *get started as a leader*'s roles table, failed as glue. Rewriting a row to satisfy a miscount is what the sweep must never do, so the checker changes instead. No migration, no edge function, nothing on a screen changes.

## What changed

- `helpGuideLineForCounting` drops a table row's pipes before counting. A row is still held to 20 words, and its cells count together unless a full stop splits them.
- `helpGuideLineForGlue` reads a table cell that holds only `—` as empty. A dash among a cell's words is still glue.
- The rules' header in `plainWords.ts` and the held / not-held sentence in `helpGuidePlainWords.test.ts` say so.
- `plainWords.test.ts` +2: the 19-word row that counted 22, and the placeholder cell. Both fail on the old checker.
