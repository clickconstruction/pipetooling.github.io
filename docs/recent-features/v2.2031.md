(last green: 00:23), always on the same spec: `e2e/deep-links.spec.ts` →
"?editLabor= with an unknown HCP opens New Sub Labor seeded with it". This is the
exact failure mode `docs/E2E_SMOKE.md` rule 6 warns about (a stranded spec keeping

  asserted `input[value="ZZE2E"]` and timed out 3/3 retries; the modal heading
  assertion before it always passed.
- **Not the guided tour:** the failure predates v2.2021 by a week; suspicion fell
  there only because the suite is non-gating and nobody had traced the first red run.
- **Fix (test-only):** the spec now pins the v2.1616 contract — modal opens, the
  picker trigger ("Search job # / name / address / customer") is visible and unset,
