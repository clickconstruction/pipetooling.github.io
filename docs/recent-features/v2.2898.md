# v2.2898 — "The week" means one thing per family: the report opens on the close week, scopes are labeled, Quickfill shows what's still open for the close (2026-09-05)

Journey map Tier-2 #18 (cluster C3 — "week anchors and scopes disagree by construction"; J5-3, J5-8, J5-10, J7-2, J34-F3). Client only; no migration, no edge function.

## Anchor decisions

- **Two week families, one helper file each.** Pay week = Sun–Sat (`payWeekAnchor.ts`, v2.2858). Close week = Mon–Sun Central, default **previous complete week** — new [`src/lib/closeWeekAnchor.ts`](../../src/lib/closeWeekAnchor.ts) (`closeWeekMonday`, `closeWeekContaining`, `previousCompleteCloseWeek[Monday]`, `resolveWeeklyMoneyReportWeek`, `isDefaultCloseWeek`, `closeWeekStillRunning`, `formatCloseWeekLabel`, `moneyfillHref` / `parseCloseWeekParam` / `MONEYFILL_WEEK_PARAM`). `moneyfillWeekClose.previousCompleteWeekMonday` now delegates to it (one implementation; its many callers untouched).
- **The report moved, not Moneyfill.** [`JobsWeeklyMoneyModal`](../../src/components/jobs/JobsWeeklyMoneyModal.tsx) opened on the *current* week while Moneyfill opened on the previous complete one — the two halves of one close disagreed by seven days on every cold open. The modal now resolves its week through `resolveWeeklyMoneyReportWeek(initialMondayYmd)`: a pinned week (`?stagesMoneyWeek=`, v2.2890) wins; a bare open (Section-tools menu, `?stagesMoney=1`) lands on the close week. The header carries a "· close week" / "· still running" suffix, and the confidence footer's "work Moneyfill to zero" link is pinned to the report's week (`/moneyfill?week=<monday>`).
- **Moneyfill accepts `?week=<ymd>`** ([`Moneyfill.tsx`](../../src/pages/Moneyfill.tsx)); the picker header shows "still running" when the picked week hasn't ended.

## Bank transfers: the section side moved

- The chip stays week-scoped (it feeds the report's confidence footer). The **section** now says so: the heading gains "— last 90 days, not just this week", each header chip carries a "week of … only" title, and a one-line `noncardScopeNote` (in `moneyfillWeekClose.ts`, tested) reconciles both numbers on the surface: *"The Bank transfers chip above counts only the week of Aug 24 – 30: 2 transfers · $11,980. This list is everything still unlabeled from the last 90 days (31 · $177,000) — older transfers belong to earlier weeks' closes."*

## Quickfill "Close week" chip — no second mark system

- New kernel [`src/lib/quickfill/closeWeekChip.ts`](../../src/lib/quickfill/closeWeekChip.ts): `CLOSE_WEEK_STATION_QUEUES` maps four stations to Moneyfill queues — `banking-sorting` → card-charges + bank-transfers, `people-hours-new` → pending-approval, `unassigned-field-time` → time-no-job, `supply-houses` → supply-invoices. `closeWeekChipModel(sectionId, counts, weekMonday, role)` sums them → `loading` / `unknown` (a missing or null queue is never a false "clear") / `clear` / `open` ("Close week: $239 open", count when the queue is count-only). `canOpenMoneyfill(role)` mirrors Moneyfill's route gate; every other role gets the `inert` model — one line "Feeds the weekly close" with a title explaining the daily mark, **no link** (the assistant is not invited into a page that redirects her).
- [`Quickfill.tsx`](../../src/pages/Quickfill.tsx): one `fetchWeekCloseCounts(previousCompleteCloseWeekMonday())` per page load, dev/controller only; `QuickfillSectionWrapper` gains `closeWeek` / `onCloseWeekOpen` props and renders `CloseWeekChip` in the full header, the desktop collapsed strip and the narrow collapsed box — so a marked-green station with open close-week dollars shows the amber chip inside the green bar. Nothing is written; the chip only reads.

## Prospect card: label, not grouping

- [`prospectListGrouping.ts`](../../src/lib/prospects/prospectListGrouping.ts): the section buckets on `last_contact` (any touch — designed-in, v2.2453) while the card phrase read the last CALL. `lastTouchLabel` now appends the bucket's clock whenever it is newer than the call by a day or more — `"didn't answer 187d ago · noted 12d ago"` — and stays a single clock when the call is the latest touch or `last_contact` is stale. Section labels name their clock: "Recently contacted — any touch in the last 30 days", "Going cold — last touch 30–90 days ago", "Cold — no touch in 90+ days".

## Telemetry

- `week_close_opened` via `recordNavClick`: Moneyfill's "See the week's report" button records `report <monday>`; a station chip records `#<station> <monday>` (`weekCloseOpenedTarget`); `from_path` separates the doors.
