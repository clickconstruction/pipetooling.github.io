# v2.2291 — Steady camera: stage add/delete no longer reflows the Map (2026-08-25)

Owner report: adding a stage via right-click zoomed the map out and the user
had to zoom back in before adding the next one.

Two compounding causes in `ChecklistTechTreeTab`:

1. The group-set effect bumped `organizeVersion` on **every** add/remove —
   and the organizeVersion effect calls `fitView` (the zoom-out) — and wiped
   all `manualGroupPositions` (discarding hand-dragged nodes).
2. `structuralKey` changing invalidated the layout cache → full dagre pass →
   every node re-positioned. One render after an add, the auto-collapse of
   the new empty stage re-keyed the layout *again* with no group delta,
   forcing a second full pass (which teleported toolbar-added stages to
   dagre's margin).

## Fix

- **Incremental layout patching** in the layout memo: when the structural
  delta is purely added/removed groups (plus edges touching them), the cached
  layout is patched in place — survivors keep exact positions *and* their
  dagre-routed edge waypoints. New stages: pointer position (right-click /
  connector-drag, via the existing manual-position ref) or the center of the
  current viewport (toolbar; previously dagre placed it wherever).
- **Anticipated re-key**: the patch pre-computes the structuralKey as it will
  look once the new stage auto-collapses and accepts it as a cache hit
  (`patchedAltKeyRef`) — no second layout pass.
- The group-set effect no longer wipes manual positions or bumps
  organizeVersion on incremental changes (initial data population still bumps
  → initial fit). Hand-dragged positions now survive adds/deletes.
- **Glow**: the just-placed stage wears a 2.5s blue ring (`justAdded` in
  GroupNodeData) so it's findable without any camera move.
- Unchanged: Organize (cache cleared → full dagre + fitView), collapse/expand
  re-layout, link add/remove re-layout, initial-load fit.

Verified live on prod data (65-stage Farm 1 map, zoomed to a corner):
right-click add → camera transform byte-identical, survivor node screen-x
unchanged, stage centered on the pointer (±1px), glow on; toolbar add →
dead-center of viewport (±1px); delete → camera + survivors unchanged;
Organize → full re-layout + refit still fires. Test stages removed.
