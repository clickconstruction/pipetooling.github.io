# v2.2881 — twin-mcp: `put_substrate`, `seed_audit_questions`, `get_reference_rows` (2026-09-05)

The second 2026-09-05 batch (R2-BT-14/16/27, first on v1.3.5) hit the same three classifier-blocked client-side lanes in every run — the last pipeline steps without harness verbs. Edge only (`twin-mcp` v1.3.6 — deploy after merge; `briefs.ts` unchanged).

- **`put_substrate(bid, substrate, version?)`** — STG-2's `bids_plan_substrates` insert as a fenced verb: twin's own bid only, 1 MB cap, latest-row-wins (a corrected substrate is just another call), `[pipeline STG-2]` ledger stamp, `created_by` = the twin. `get_plan_brief`'s no-substrate message now routes here instead of "insert with your own session".
- **`seed_audit_questions(bid, questions)`** — up to 20 `bid_audit_notes` rows (`kind='question'`, author = the twin) on the bid's newest `bid_audits` row (opened `pending` if missing). Sections validated (counts/footage/pricing/scope/general, default general); the response warns per question missing a `sheet_ref` anchor — the v2.2535 anchoring rule, enforced by nag.
- **`get_reference_rows(bid)`** — the post-unseal read for the T4 scope-match line-compare. Takes the twin SHELL (never the reference directly), resolves `twin_source_bid_id`, and is **refused while no scorecard exists** for that shell (`twin_run_scores` row, or a scored `twin_shadow_runs` row) — blind-safe by construction, the read-direction mirror of `score_backtest`'s LOCK gate. Returns the reference's count rows with assigned unit prices (`override ?? entry price`). R2-BT-16 shipped with `scope_verdict: unknown` solely because this read had no lane; a human or a later twin session can now run the compare and amend.
