## Read closer than the card

- **The unique index is an ordinary index.** The card asked for a partial unique index, one usual per kind per contact. `name_contact` folds a named number into the record's own contact by moving its channel rows, and a unique index would refuse the fold whenever both sides carry a usual (the very case Who is this? asks about). The function keeps one usual per kind; the readers take the newest `usual_at` when a fold brings two together.
- **The tick is on by default, as drawn, but only a pick stars.** A plain *Send as text* to the rule's own number never writes a usual: the office never opened the menu, so nothing was decided.
- **The tech's gate** (call 2's widening to the tech's own destinations' customers) and the chip on the Tell the customer sheet and On my way are PR 2's; `contact_channel_make_usual` is the office team's in this PR.
- **Today's sends naming the number a held row would go to** (call 3's second half) is not drawn here; the run reads the usual, which is the half that changes where a text goes.
