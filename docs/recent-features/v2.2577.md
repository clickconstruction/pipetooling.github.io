# v2.2577 — Supply house form: side labels, compact height (2026-09-01)

Follow-up to v2.2575 (scroll fix). Owner picked the "side labels" direction from
mockups: `SupplyHouseForm` now lays each field as a row — 160px right-aligned
label beside the input — instead of label-above-field, cutting the form from
~870px to ~630px tall so it fits a laptop viewport with no scrolling. The modal
variant widens from 480 to 560px to make room.

- New local `FieldRow` component renders both layouts; `useNarrowViewport640`
  picks: ≤640px viewports keep the original stacked layout (side labels would
  eat half a phone's width). The modal keeps its v2.2575 maxHeight/overflow
  scroll as the safety net.
- Monthly payment date input narrows to 180px on wide viewports (it holds a
  1–31 day). Both call sites unchanged: modal (`SupplyHousesTab`) and inline
  (`Materials.tsx` legacy section) render through the same rows.

Verified live at 1280×800 (side labels, no scroll, Update visible) and 375×812
(stacked, scrolls, Update reachable). One file: `src/components/SupplyHouseForm.tsx`.
