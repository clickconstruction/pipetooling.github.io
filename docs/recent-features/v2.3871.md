# v2.3871 — Edit Job: the labor figures come from the same math the Job window uses — `useJobFormLabor` (2026-09-26)

Client only; no migration, no edge function, no screen change. Punch list **#46** row 4 (`to-dos/decomposition-queue.md`): the Job form map's order #1 (`docs/JOB_FORM_MODAL_ARCHITECTURE.md` → the labor loader).

## Why

`JobFormModal` held a 116-line effect that loaded the job's team-labor row and its sub-labor sheets for the cost block and the delete gate. The sub half was a hand copy of `laborJobSubCost` (`_shared/subLaborCost.ts`, tested — the kernel the Job window's profit band and the dev MCP server read) and of the read `useJobDetailSubLaborCost` already makes; the map flagged it **inline drive-cost math, untested here**.

## What shipped

- **[`src/hooks/useJobFormLabor.ts`](../../src/hooks/useJobFormLabor.ts)** — `useJobFormLabor(jobId)` returns the six names the form used (`editJobTeamLaborLoading` / `Row` / `Error`, `editJobSubLaborLoading` / `Data` / `Error`), so the cost block, the charts panel, the delete gate and the Job window hand-off are untouched. The team half is the same read (`loadTeamLaborData` under `withSupabaseRetry`, then the job's row). The sub half rides `useJobDetailSubLaborCost` and sums through the new **[`src/lib/jobs/subLaborSummary.ts`](../../src/lib/jobs/subLaborSummary.ts)** — `subLaborSummary(inputs)`: the sheet count and the sum of `laborJobSubCost` per sheet, null until loaded. The hook is keyed on the job id alone: the old effect also re-ran on the job's number, a leftover from before v2.3060 read sheets by their job link.
- **The form**: the six `useState`s and the effect are one destructure; `loadTeamLaborData` and `laborItemsSubtotal` leave its imports. `JobFormModal.tsx`: 5,479 → 5,357 lines. Behavior-neutral — the same rows, the same formula (now the shared one).
- **Tests** — `subLaborSummary.test.ts` (2): null until loaded, 0 / $0 with no sheets, and the count and sum against the kernel with the hand formula's numbers pinned ($300 of lines + $17 of drive on a rated sheet; mileage only on a rate-less one). `useJobFormLabor.render.test.tsx` (3): no job → nothing loads; a job → its own team row and a 0 / 0 sub summary through the stubbed reads; a failed team read → error, row cleared, the sub half still answers.
- The map's loader rows and Costs region say done; the queue's row 4 names the three inline overlays next.
