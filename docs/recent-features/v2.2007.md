# v2.2007 — Partnership ledger notes: click-to-place + live draft preview (2026-08-21)

Owner request on the v2.2000 note composer: "click on the space between any two lines and have the date selected there, and as I am typing a note see what I am typing being auto generated." Client-only — no migration.

**Kernel** ([`partnerLedgerJournal.ts`](../../src/lib/partnerLedger/partnerLedgerJournal.ts)): `DRAFT_NOTE_PREVIEW_ID` + `withDraftNotePreview(notes, editingNoteId, draft)` — substitutes the open composer draft into the notes list so the ledger renders a ghost row where the note will land; a new note appends the preview, editing an existing note replaces that note's row (the ghost moves live as the draft date changes). 4 tests.

**UI** ([`PartnershipLedgerTab.tsx`](../../src/components/partnerships/PartnershipLedgerTab.tsx)):
- **Ghost row**: while the composer is open, the draft renders in the ledger at its date — italic memo as typed (muted "(your note)" when empty), dashed borders, a "draft" chip, live "partner sees" chip, 0.75 opacity. Clicking it focuses the memo input. Nothing persists until Save.
- **Click-to-place**: posting/pending rows become date targets while the composer is open — hover shows the same amber insertion line the drag-to-date affordance uses (`cursor: copy`), click loads that row's date into the draft and refocuses the memo input. Since a note on date D renders above D's rows, the note lands where clicked (top of the date group when several rows share the date — the ghost makes that visible). Saved note rows keep click-to-edit; drag-to-date unchanged.
- Memo input autofocuses when the composer opens; composer tip rewritten for the new flow.

Partner side untouched — preview is composer-time office UX only.
