# v2.5409 — The law firm's portal passes its own type check again (2026-10-12)

A type-only fix to `legal-portal`, one of the 24 edge functions a `deno check` sweep of all 151 found failing on 2026-10-12, and the one with the most errors (15). No migration and no screen. Nothing behaves differently.

- **Selects the checker cannot read** (TS2352 ×13):
  - `MATTER_COUNSEL_SELECT` in `_shared/legalMatterShape.ts` builds each column list with `.join(', ')`, so each is typed `string`, not a literal. `readMatters` takes `cols: string` too.
  - supabase-js parses a select's columns at the type level, and a list typed `string` gives up by design (`ParseQuery`: `string extends Query ? GenericStringError`). So the rows of those 13 selects (the matters, their jobs, bills, payments, customers, contact people, addresses, contracts, estimates, demand letters, filings, the jobs' addresses and their owners) were typed `GenericStringError`, and each `(res.data ?? []) as Row[]` was refused.
  - Those selects name their row now, `.select<string, Row>(…)`, through `select`'s own second type parameter. `Row` is the function's `Record<string, unknown>`, which is what every reader already takes.
- **A spread that drops the index** (TS2339 ×2): `jobsWithDetails` maps each job `Row` to `{ ...j, invoices, payments, gcCustomer, collections_by_name }`. TypeScript drops an index signature when properties follow a spread, so `j.collections_note` and `j.id`, in the loop that blanks a held collections note, were refused. Both columns are in `MATTER_COUNSEL_SELECT.jobs`. `jobsWithDetails` is typed `Row[]`, which `shapeMatterForCounsel` takes.
- **No missing columns**: a select the checker cannot read cannot warn of a column that does not exist either. So every column the function selects, the lien book's and the entries' lists included, was checked against `src/types/database.ts`, and each exists.
- **Checked**:
  - `deno check --no-lock --node-modules-dir=none` (deno 2.9.6, TypeScript 6.0.3): 15 errors on `main`, 0 here.
  - The file, main's and this one, compiled by TypeScript's `transpileModule` with comments dropped, gives byte-identical JavaScript.
- **Deploy**: redeploy `legal-portal` once merged. The code that runs does not change, but until then `npm run check:edge-drift` and the Edge function drift workflow name it as behind `main`.
