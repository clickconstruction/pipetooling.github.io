# v2.4735 — Lien window: change the last day of work from its timeline (2026-10-06)

Client only; no migration, no edge function. The owner (2026-10-06, a screenshot of Deadlines and of *Liens on job 186*): *right now in All Filings there is the ability to set it [the last day of work] … I would like to offer it on this modal in deadlines as well so a user can make changes*, and, mid-build, *when I set the day, I also want to see the confirmation modal that shows what changes the other page offers*. Mock-up and critique: artifact XTwGvgJHoaJJpERH5MHMuf (the first draft drew the line under every timeline and was cut to a door; a pencil icon was cut because icons on the strip mean status; the mock-up's own deadline math and its grid row were checked against the app and redrawn).

## What changed

- **The window read only the clock hours and the creation day.** `LienInstrumentsModal` built its timeline (`buildLienTimelineFromWindow`) without `lien_last_work_on`, so a day set by hand in All filings never reached it. The job it passes now carries the column, from the job merged with whatever this window saved (`lastWorkPatch`).
- **`LienTimelineStrip` `onChangeLastWork`**: a *change ›* under the LAST WORK stop (row and list layouts, `data-lien-timeline-last-work-door`). The window passes it for office roles (`isLienOffice`) while the line is closed; a phone gets *Change the last day of work ›* under the folded steps.
- **`LienLastWorkDayLine`** takes `startEditing` and `onCancel`. The window draws it under the timeline only when the door is pressed, already editing, with the window's work months, its notices' months and the property kind, so *Save the day* opens the same `LienLastWorkDayConfirm` (v2.4717) with its table. A save re-reads the job's five last-work columns, folds the line away and calls `onLastWorkSaved`.
- **The Deadlines grid**: the work tick's label (`Jun 4`, `Aug · no hours`) is a door (`lien-cal-work-door`, `LienDeskCalendarTab` `onOpenLastWork`) for office roles; it opens the window with `openLastWork`.
- **The grid moves after a save**: the window's `onLastWorkSaved` and the desk's own last-day line (`onCalendarChanged('last_work')`) now bump the Pipeline's lien clocks (`setLienClocksRefresh`) as well as the desk. Before, a day set in All filings left the Deadlines row in its old group until the next load.
