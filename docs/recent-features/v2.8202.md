# v2.8202 — State roll: the weekly read keeps our own team’s licenses, wherever they live (2026-11-21)

Punch list #411, the first half of step two in [`to-dos/state-roll/`](../../to-dos/state-roll/README.md): the ground under Our own. A change to the edge function [`license-roll-pull`](../EDGE_FUNCTIONS.md#license-roll-pull) and its kernel, and one migration that schedules a fifth file, [`20261121210000_license_roll_pull_cron_apprentice`](../migrations/20261121210000_license_roll_pull_cron_apprentice.md). No screen changes.

## Why

Our own is the view that lines our teammates' and subs' licenses up with what the state says. The roll kept so far holds only people who live in our five counties, and no apprentices. A teammate who lives a county over, or who is an apprentice, had no row to be checked against.

## What changed

- **`supabase/functions/_shared/licenseRoll.ts`**
  - `rollNumberKey` writes a license number as it is compared: digits only, no leading zeros. The state writes `012345`; our records write `#12345` or `J-12345`.
  - `ownPlumbingNumbers` sorts our own plumbing numbers by the class of state file each would be found in. A master's number is looked for in both master files, since a responsible master is a master.
  - `planRollPull` compares a row's number to ours through `rollNumberKey`.
  - `TSBPE_OWN_ONLY_FILES` names the apprentice file, `PA`: read for our own numbers, with no county kept.
- **`supabase/functions/license-roll-pull/index.ts`**
  - `readOwnNumbers` reads the license text of every row on People → Licenses (`person_licenses.license_type`) and every roster row's license line (`people.license`, where a sub's sits), and makes each out with the app's own reader, `parseLicenseType`. It reads the text alone, never a name.
  - A row whose number is ours is kept whatever the county, marked `ours`.
  - `PA` is a file it will pull. For it the counties are left empty, so only ours is kept.
- **`scripts/edge-kernels.mjs`**: the function joins the list of those that import the shared kernel copy, since `parseLicenseType` lives there.
- **The migration**: a fifth Monday job, `license-roll-pull-pa`, at 12:50 UTC.

## Rules it settles

- **Ours is kept whatever the county, and stops being kept when it stops being ours.** A row kept only for being ours is taken off on the next pull once the number is gone from our records.
- **No apprentice is kept but our own.** The state's file gives no age.
- **The match is by number, never by name.** A teammate whose license has no number on People → Licenses is not matched. Our own will say so and offer the fix.
- **Left off still wins.** A person left off is not kept even when the number is ours.
