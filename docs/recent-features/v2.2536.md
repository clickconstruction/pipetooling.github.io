# v2.2536 — Robot Board jump bounce fix (2026-08-31)

`applyBidBoardDeepLinkToBid` set `activeTab('robot-board')` in React state but left
`?tab=` untouched; the URL-sync effect re-runs on every searchParams change (the
`bidId` cleanup) and its generic tail snaps `activeTab` back to whatever `?tab=` says.
Result: with a `tab` param in the URL (any pill click puts one there), a robot-bid
landing flashed the Robot Board then bounced to the board named in the URL. Reported
live on b351's colorful 🤖; reproduced with `?tab=bid-board`.

Fix: the landing now writes the destination tab into the URL in the same
`setSearchParams` that clears `bidId` (only when a `tab` param is present), so the
effect's re-run agrees with the state. Covers the v2.2500 deep links and the
comparison modal's "Open on Robot Board".
