# v2.6366 — Materials on site: print a manifest to laminate and hang on each cage and box (punch list #209) (2026-11-02)

Punch list #209, a leftover the owner asked for on 2026-11-02, in his words: *an additional print-out where a user can print out the manifest for all or specific boxes and have it show the date the manifest was created, the date a material was last recorded, and lines at the bottom for people who want to fill in other materials that are being added … a document we could attach to boxes and pallets and crates and cages in laminated or insulated document holders to formalise what is on site.* No migration, no edge function.

## Decisions

- **One page per container, not one list.** Each page hangs on its own box, so a list for the whole job would be cut up by hand. The picker is how *all or specific* is answered: open on every box, leave some out.
- **Unsorted prints no page.** It is the job's row a delivery lands in, not a container a paper hangs on. A pallet of unsorted material gets a stencil through Add a container and then a page.
- **A plain print, no sent copy.** The surface's other paper, the label, files none (`docs/SENT_COPIES.md`), so the manifest follows it and sits beside it on `sentCopiesCoverage.test.ts`'s `NOT_A_SEND` list with that reason. Filing the manifest as a sent copy, so the office can see which paper a box carries, is a follow-up if the week of use asks for it.
- **The items are what is on hand.** A line counted to zero, or one with only a Can't find owed, is off the paper: the paper is what is in the box, and the office reads the shortfall on Missing.
- **Last recorded is the container's newest row on either side**, so a move out of the box and a count both move the date; the label's *last counted* is a different question and stays on the label.
- **The office's page prints; the phone links.** The phone's On site tab prints nothing itself (the label link already opens the office page), so the manifest link does the same, and no second print path is built for a phone.

## Left
