## What changed

- **`model-config` `test`**: one tiny call with the saved key, asked exactly the way a draft asks: `DRAFT_MODEL` and `DRAFT_BETAS`, now shared from `_shared/modelKey.ts` with `report-draft`, `fallbacks: "default"`, effort `low`. It answers `test: { ok: true, model, seconds }` or `{ ok: false, status, why }`, the function's own call never failing for a refusal.
- **`modelRefusalWhy`** (`_shared/modelKey.ts`, pure): Anthropic's error type and message from the SDK's body (`APIError.error.error`), else the error's own message; anything shaped like a key is cut. `report-draft`'s 502 now carries it as `why` and logs it.
- **The card**: **Test the key** beside Save and Forget once a key is set; *The key works. Claude answered in 1.4 seconds.* in green, or *Anthropic refused it.* with the reason in red and the two usual causes under it, the Billing page's credits and a key with no workspace. A new key clears the last result.
- **Words**: the card's *where* line and the guide *turn on drafted field reports* point to platform.claude.com's API keys page and say to pick a workspace (a key with none needs an `anthropic-workspace-id` header the function does not send), and to add credits on a new account. The guide gains § Test the key.
