# v2.2543 — get_shadow_queue honors robot-bid requests (2026-08-31)

Closes the loop from v2.2542's request queue into fleet Phase 1 (twin-mcp v1.3.1,
deployed):

- `get_shadow_queue` now runs two queries — the recent-window one plus an
  unbounded requested one (`robot_requested_at IS NOT NULL`, unsent, plans, not
  ZZ) — merged requested-first, oldest ask on top. Requested entries carry
  `requested / requested_at / requested_by` (name resolved from users) and a
  top-level `requested` count; a human ask never ages out of the lookback window.
- `open_shadow` stamps `twin_source_bid_id` on the ZZ Shadow bid, so the Bid
  Board robot icon flips colorful the moment a shadow opens (it previously only
  did so for backtests via open_backtest).

Verified live post-deploy: queue returns b391 first with
`requested_by: "Robert"`. `docs/EDGE_FUNCTIONS.md` twin-mcp section updated.
