# v2.2016 — Checklist Review: Outstanding rows get activity threads + severity ages (2026-08-21)

Redesigns the task rows inside **Review → Outstanding by person** (the last
old-style list on the tab) and wires them to the v2.1842 activity spine.

- **Shared component**: the Manage tab's activity panel (v2.2010) moved to
  [`src/components/checklist/ChecklistItemActivity.tsx`](../../src/components/checklist/ChecklistItemActivity.tsx)
  (was in-file `ManageCardActivity`; cap const renamed
  `ITEM_ACTIVITY_INSTANCE_CAP`). New `footerActions` slot renders extra links
  under the composer. Manage and Review now render the same component — one
  write path, one dataset.
- **Row redesign** (`OutstandingByPersonSortableRow`): Edit + Forward left the
  always-visible icon strip (drag / ✓ complete / 🗑 delete remain, per owner
  direction "delete stays on the left"); the row body is a `role="button"`
  toggle that expands `ChecklistItemActivity` inline, with Edit · Forward as
  dev-only footer links in the panel. Disc bullets dropped (`list-style:
  none`) — the checkbox column is the marker now.
- **Age severity** (`ageSeverity(days)` in `src/lib/checklistTeamBoard.ts`,
  tested): `ok` &lt; 7d (gray) · `warn` 7–30d (amber) · `late` &gt; 30d (red).
  Applied to row chips (`outstandingAgeChip`) and the person header's
  "oldest N days" text — previously every chip was red.
- **Notes counts**: after `loadOutstanding`, a non-blocking chunked query
  counts `comment` events per listed instance → 💬 chips on rows and a
  "💬 N notes" total in the person header. `checklist_items` embed now also
  selects `created_at, created_by_user_id` (the activity panel's creation
  stamp).

Help guide: `see-a-tasks-full-history-and-notes.md` gained a Review section.
Design mockups + plan (variant A "Quiet rows" chosen, with the owner's
edit/forward-to-the-middle amendment): artifact "Checklist Review Redesign".
