# v2.6800 — Tape labels, step one: the labels as a CSV, and Copy the label code at the cage (punch list #294, PR 4) (2026-11-09)

The owner will print the box labels on two Brother P-touch tape printers (a PT-E720BT and a PT-D610BT) for boxes that sit in the sun ([`to-dos/prts-box-page/README.md`](../../to-dos/prts-box-page/README.md), section 7). This is the smallest step, so the office can print from Brother's own editor the day the printers arrive; PR 5 lays the strip out in the app.

## What changed

- **`src/lib/materials/labelsCsv.ts`** (pure, tested): every live cage, box or pile in stencil order, never Unsorted or a retired box, as `Stencil, Kind, Place, Where, Code, Address, QR` (the code with its dash, the address as a person types it, the bare text the QR carries); the file named by the job and the day. The Labels window on Jobs → Materials gains **Export the labels as a CSV** beside Print, through the same download the photo share uses.
- **The phone**: under a box's Paper for the box, **Copy the label code** puts `PRTS.CO/B/4F2A-9C18` on the clipboard (`boxClipboardWords`) with a toast saying so, for a QR typed into Brother's phone app over Bluetooth at the cage; the printer's own QR reads the dash either way. A copy that fails says why.
- The guide's Scan a label section, `MATERIALS_ON_SITE_ARCHITECTURE.md`, `APP_DIRECTORY.md`.
