# v2.3501 — Supply house credits, step 2: the two edges a credit must not reach (2026-09-16)

Client only. **No migration, no user-visible change today** — negatives are still impossible until v2.3502. Second of four PRs from [`to-dos/supply-house-credits/README.md`](../../to-dos/supply-house-credits/README.md).

v2.3500 taught the money screens to carry a credit alongside an owed figure. Two paths cannot be taught that way, because they take the amount somewhere it stops being a supply-house document. Both refuse instead, with a sentence.

## Kernel — [`supplyHouseDocument.ts`](../../src/lib/supplyHouseDocument.ts)

`isSupplyCredit(amount)` plus the two refusal sentences, so the rule and its wording have one home. Uses the same 0.005 epsilon as the rest of this surface, so a rounding-sized negative is a zero, not a credit.

## The two edges

- **A project step line item** — [`Workflow.tsx`](../../src/pages/Workflow.tsx) and [`projectsForecastStageLineItems.ts`](../../src/lib/projectsForecastStageLineItems.ts) both copy `inv.amount` into `workflow_step_line_items` and build a memo string from it. That table has no idea a credit exists, and its FK back to the invoice is `ON DELETE SET NULL`, so a copied negative would outlive the document it came from. Both now stop before the insert.
- **A card charge link** — [`MercuryTransactionInvoiceLinkModal.tsx`](../../src/components/MercuryTransactionInvoiceLinkModal.tsx). Since v2.2692 an invoice-linked card charge is counted once, through the invoice; linking a charge to a *credit* would drop the charge from parts cost and then apply the credit's negative allocation, taking the same money off the job twice. The row now renders dimmed with its tick disabled and reads *Credit memo — cannot be linked*, and `handleSave` filters credits out of the write as well, so a link made some other way is never written back.

## Tests

Four cases on the kernel, including the epsilon boundary and the null/undefined shapes PostgREST hands back.

`npm run typecheck`, `npm run lint` and the touched suites green. Nothing to see live yet: with the constraint still shut there is no credit in the database to refuse.
