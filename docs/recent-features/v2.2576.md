# v2.2576 — Pipeline invoice rows: Edit/Job-detail icon pair → one big Edit button (2026-09-01)

Owner request (screenshot of Jobs → Pipeline, Ready to Bill): standalone invoice
rows still carried the old Edit-pencil + Job-detail-briefcase icon pair that
v2.1686 retired on job-backed rows. The `kind: 'invoice'` branch of
`JobsStagesUnifiedTable` now mirrors the job branch exactly:

- **One big Edit button** (full-width outline, `title="Open the Edit tab for
  this job"`) above the icon row, replacing the two icons; Share moves to the
  front of the icon row (Share → Plumbing Tooling → Lien Tooling → AIA), same
  order as job rows.
- **Job name becomes the detail-opening link** (`renderStagesOpenDetailJobName`,
  blue underline + `StagesSearchMark`) instead of plain `formatJobNameTwoLines`
  text — Job detail stays a click away, the same rationale v2.1686 recorded for
  job rows. The thread-expand chevron keeps riding the name line (invoice rows
  have no wide-viewport activity box, so it is not gated on viewport width).

No behavior/props changes for job-backed rows or the mobile card list (cards
already route View job / Edit job through the ⋯ sheet). `openStagesDetailJobModal`
stays in `JobsStagesUnifiedTableProps` (the card list uses it); only the unused
destructure and the now-unused `formatJobNameTwoLines` import were dropped.

Verified live (dev login, prod data): all 7 invoice-bearing rows show the Edit
button, neither icon remains, the name link opens the Job tab and the Edit
button opens the Edit tab of the job window.
