## What changed — per item

1. **`/duplicates` defaults to exact-name matches; near-matches gate on numbers (J29-F2, J29-N1) — done.** New kernel [`duplicateParts.ts`](../../src/lib/materials/duplicateParts.ts) (+ 13 tests): `exactDuplicateGroups` buckets by `normalizePartName` (trim + case-fold + whitespace collapse); `nearDuplicateGroups` runs the 80% Levenshtein union-find **inside numeric buckets only** — `numericTokens("1-1/2 X 1-1/4 …") = ['1-1/2','1-1/4']`, so two names must agree on every number they carry (sizes, lengths, model numbers) before they can pair. The 37-row PEX chain is gone; a typo / suffix variant still groups. `Duplicates.tsx` drops its in-file union-find, computes groups in a `useMemo`, and the checkbox flips to opt-in **"Show near-matches (80%+ similar, same numbers)"**; group headers read *N with the same name* / *N near-matches*; the empty state says what to tick. The old "Only show 100% name match" filter kept only groups whose *whole* transitive closure was exact — exact pairs inside a size family were invisible; they now show by default.
2. **Three PO-named tabs get a signpost — copy, not hide (J29-F1) — done.** New [`MaterialsPoLaneSignpost.tsx`](../../src/components/materials/MaterialsPoLaneSignpost.tsx) renders one muted line atop **PO Generator** ("Counter PO numbers start here … PO Builder and Purchase Orders are the line-item lane; they don't mint codes"), **PO Builder** and **Purchase Orders** ("Line-item POs from PO Builder and bid takeoffs (a takeoff's POs feed that bid's material cost estimate). Counter PO numbers live in PO Generator"). On the two line-item tabs "PO Generator" is a link (`onOpenPoGenerator`, wired in `Materials.tsx` for dev / master / assistant-like — estimators, who cannot open that tab, see plain text). No tab hidden: the lane's drafts are wired into three bids' cost estimates today (2b live recheck #1).
3. **"Supply Houses" named three surfaces (J29-F3) — done.** Parts Book toolbar button → **Price coverage** (with a title tooltip); its modal heading → **Price coverage by supply house**. The tab keeps "Supply Houses". Estimators / primaries / superintendents still reach supply-house add/edit through the modal (quirk 16 in `MATERIALS_TABS_ARCHITECTURE.md`, unchanged).
4. **"0 months ago" for a 28–29-day gap (J29-F6, J29-N3) — done, in four kernels.** `if (diffWeeks < 4)` → `if (diffDays < 30)` in `compactTimeAgo` and `longTimeAgoPhrase` ([`subcontractorLastActivityCompact.ts`](../../src/lib/subcontractorLastActivityCompact.ts) — Supply Houses "Updated"/"Paid", Checklist "created …", mobile Last Activity) **and** in the two siblings with the same arithmetic, `formatTimeSince` (`dashboardJobRowActivity.ts`, Dashboard "Open …" chips) and `formatTimeSinceAgo` (`formatTimeSinceAgo.ts`, Purchase Orders tab). 28–29 days read *4 weeks ago* / *4w ago*; day 30 is *1 month ago*. Tests pin 27 / 28 / 29 / 30 days in all four.
