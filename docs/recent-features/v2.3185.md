# v2.3185 — People → Users on a phone: the directory, with a swipe strip (2026-09-09)

Client only — no migration, no edge function. Owner's ask: "On the People Users page on small viewports and mobile this tab doesn't look great, can you help me visually refresh it?" Two mock-up rounds (artifacts *People Users on a Phone* — A two-line rows / B cards / C directory — then *Users Directory, Refined* — C1 mask icon / C2 avatar / C3 swipe); the owner picked **C3** and kept the one-tap imitate. Measured before: at 390px the sticky toolbar was 290px tall (a third of the screen), a row 140–214px, 3–4 people per screen.

## What shipped (narrow viewports only — `narrowViewport`, ≤640px; desktop untouched)

- **[`UsersTabPhoneRow`](../../src/components/people/UsersTabPhoneRow.tsx)** (new): 46px row — initial avatar with a 2px status ring (red / amber / green from `rail.attention`; a hollow dashed circle for roster-only rows, 🤖 for a twin account by its `@twins.` email), the name (+ the account note under it, and "no login" for roster rows), `⏱ N` when sessions wait, `Needs you N` (counted paperwork / account needs; hours never count, as on the desktop pill), a chevron. **Tap** opens the Person Desk. **Swipe left** (pointer events; `touch-action: pan-y` so vertical touches scroll; a touch is classified horizontal or vertical once it clears 6px) slides the row over a strip of 66px actions: **Desk**, **Imitate** (dev + account + prod-host or localhost — one tap, no confirm, the same `loginAsUser` door as the desktop icons), **More** (the row's ⋯ items — invite / edit / link / combine / archive — rendered under the row). A third of the strip's width flips the state; less springs back. One row open at a time (the tab owns `swipeOpenId`); tapping an open row closes it. Keyboard: ArrowLeft opens the strip, ArrowRight closes, Enter / Space = desk; strip buttons are tabbable only while open.
- **[`usersTabPhone.ts`](../../src/lib/people/usersTabPhone.ts)** (pure, 10 tests): `USERS_TAB_PHONE_FILTERS` (Everyone · Needs you · Hours · No login · Field · Office — the two phone filters beside Everyone, counted), `countUsersTabFilter`, `personInitial`, `isTwinEmail`, `needsYouCount`, `classifySwipe`, `swipeOffset`, `swipeSettles`, `phoneRowNote`.
- **[`PeopleUsersTab`](../../src/components/people/PeopleUsersTab.tsx)** narrow branch: toolbar = search + **+ Add** + **⋯** (Team leads · Accounts · dev · Archived (N)), **not sticky** so group headers can pin instead; filter chips in one `overflow-x: auto` row with counts on Needs you / Hours (all groups' rails read once per render). Groups render as cards (`overflow: clip`, so the sticky header works and corners still round): uppercase kind label + count, **+ Add** as a text link, rows, and the same "+ N more without a login" fold. Imitate on a phone = `imitateOnPhone` (prod host → `appUrl('/dashboard')`, localhost → the origin).
- Smokes (`UsersTabPhoneRow.render.test.tsx`, 5): the row's text and desk tap; the open strip's Desk · Imitate · More, Imitate firing once and closing the strip; More's menu; roster-only / twin rendering; ArrowLeft / ArrowRight.
