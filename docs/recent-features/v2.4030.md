# v2.4030 — Bid Board: the Reply book (2026-09-28)

Client only; no migration, no edge function. Owner ask, 2026-09-28: *"The estimators would like to share information, especially generic responses, between each other… a button that opens a modal where people with access to the bid board have a place to post things like this and only devs and the person who submitted it can edit or delete."* PR 2 of 2, after [v2.4025](v2.4025.md) (the table).

## What shipped

- **The button** — `BidsBidBoardTab`'s tools row: search · Archived · **Reply book (N)** · Customer review. The board calls `useBidReplyBook`, so the count and the window read one list.
- **`src/components/bids/BidReplyBookModal.tsx`** — the window: search, kind chips with counts, a card per reply (what it is for, its kind, the wording, who posted it and when), **Copy**, and an add / change form. Esc peels the form, then the window; typed wording is asked about before it is dropped.
- **`src/hooks/useBidReplyBook.ts`** — one ordered, ranged read (the newest 500) and the three writes, each changing the list in hand.
- **`src/lib/bids/bidReplyBook.ts`** — the rules: kinds, search, who may post and change, what a draft must hold, the copy text, the byline.
- Help guide `use-the-reply-book`; `read-the-bid-board` names the button.

## Decided here (the first mock-up was the ask word for word; these are what a second look changed)

- **Copy is the point.** A list of posts is a bulletin board; every card's main button is Copy.
- **The copy is signed by whoever copies it.** The example ends "Thank you, Wendi". The form takes a pasted closing off what is saved and says so; the card shows the viewer's own name where it will go.
- **A reply says what it is for**, has a kind, and the window has a search — thirty posts are otherwise thirty paragraphs.
- **Edit and Delete are drawn only where they work** — the author's own replies (a blue edge, "You") and everything for a dev. The database holds the same rule; a change it refuses comes back as no row and no error, and the hook reports that as refused rather than done.
- **The phone row stays one row** (owner call, v2.1355): Reply book and Customer review are icons under 660 px. With the words, a fourth button left the search about 35 px.
- **Training mode copies and nothing else.**

## Left

- The book opens from the Bid Board only. The Bid window and Followup, where the letters are written, could open the same window (`BidReplyBookModal` takes the book and `onClose`).
- Most-copied first needs a count the table does not keep.
