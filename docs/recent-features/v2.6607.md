## Decisions

- **Last week, not this week.** Monday's card is the previous complete pay week, read as of its Saturday, so the email and Friday's sheet say the same week.
- **A person with no card gets no email**, and the run names them as skipped in the last run's `gaps`, never a blank card.
- **The switch ships off**, as the Bridge's does; nothing mails until a dev turns it on after reading a preview.
