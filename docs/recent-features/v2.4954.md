# v2.4954 — Bids: Put back sets a value back to what it was (2026-10-08)

Punch list #73, PR 4 ([`to-dos/bid-history`](../../to-dos/bid-history/README.md)): Put back for a value. PR 2 (v2.4948) reads a bid's history and PR 3 (v2.4952) shows a cell's past. This puts a past value back. Migration `20261009110000_put_back_bid_change.sql` ([doc](../migrations/20261009110000_put_back_bid_change.md)); no edge function.

## The change

- **`put_back_bid_change(p_change_id, p_column)`**, SECURITY INVOKER: writes a ledger change's old value back for one column (or every column it touched) under the caller's own policies. The owner's call 3 is the table's own rule: whoever can edit the bid. It tags the request `put-back` so the trigger records the write as the caller's change. It refuses a removal, a removed row and a caller without rights in plain sentences, and returns the values before and after.
- **The kernel** [`bidHistoryPutBack.ts`](../../src/lib/bids/bidHistoryPutBack.ts): which line offers Put back (a changed value, from the ledger, on the open bid; not an addition, a removal, the archive or an adopted bid's row), the button's name (*Put back Lav-1 price to $9,800*), and the words after (*Lav-1 price is $9,800 again.*, *was already*, the function's refusal, or *Put back is not ready yet.* before the push).
- **The window** ([`BidHistoryWindow.tsx`](../../src/components/bids/BidHistoryWindow.tsx)): a **Put back** button on each such line, the result under that line, then the history reads again without blanking the list. It sends `BID_HISTORY_PUT_BACK_EVENT`.
- **The tabs**: `Bids.tsx` hears the event and reads the open bid again: counts, takeoff lines and labor (`refreshAfterCountsChange`), the prices (`loadBidPricingAssignments` + `loadPricingDataForBid`), and the bid list for an Edit Bid value. Past values re-reads too.
- **The caption**: a put back reads *Put back Lav-1 price* in the history (`put-back` in `BID_ACTIONS`; not one of the app's own actions).

## Not in this PR

- A removed row put back (`restore_deleted_record`): it waits on Grace's call on who sees the archive's removed rows.
- Put back under a cell: `latest_bid_cell_history` returns no change ids. The cell's *+N more* opens the window, where Put back is.
- The Cover Letter's schedule of values and payment lines read again when their tab opens, not on the event.
- Undo a whole action (PR 5).
