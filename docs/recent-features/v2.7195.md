# v2.7195 — Materials on site: a label prints the letter and number alone (2026-11-13)

The owner's ask of 2026-11-13: a label should print the letter and number alone, without the words typed after them, so the label does not depend on the rest of the name and can stay on more things. A label printed the box's whole name in large type, so a name that said what was inside put that on the tape, and the tape was wrong as soon as the box held something else.

## What changed

- **The rule** (`src/lib/materials/labels.ts`, pure): `labelPlate` reads the letters and number a name starts with, `G12` of `G12 COPPER 90`. One letter after the number stays, since `G24` and `G24B` are two boxes. `labelPrintNames` answers what each box of a list prints. Two names print whole: a name with no letters and number (`CONCRETE MIX`), and a name whose short form another live box in the list shares, so no two labels read the same. `shortenedLabelsNote` words the line that says which labels print shorter.
- **Where it prints** (`LabelsPrintModal.tsx`): the tape strip through the print window, the strip drawn for the P-touch over USB (`TapeStripBitmap`), and the paper sheet. The names are read against every box the window was given, also when one box is printed alone.
- **The CSV** (`labelsCsv.ts`): the Stencil cell is what the label prints, since the file feeds Brother's editor.
- **What does not change**: the chips in Print labels and the window's title keep the whole name, so the office sees which box it is printing. The QR, the code under it and *Scan for what is inside* are as before. The manifest keeps the whole name. No name in the database is touched.
