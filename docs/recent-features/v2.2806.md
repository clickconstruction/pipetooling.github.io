# v2.2806 — twin-mcp: `next_backtest` dispatcher, `get_work_state` scoped to the bid, STG-2 is the twin's (2026-09-05)

The first blind round-2 run (R2-BT-1, b465, −10.8 % gate-eligible, one subagent, 45 min) came back with a stumble list. Three items blocked running several agents at once; this PR fixes them. Edge only (deploy after merge); `briefs.ts` regenerated because `estimator.md` changed.

- **`next_backtest(candidates, round?, axis?)`** — the dispatcher. The kickoff's wave table goes in as `[{bid, axis, label}]`; the verb opens the first reference with no shell for this round and returns it as the caller's. The claim *is* the shell: `openBacktestShell` (factored out of `open_backtest`, which now calls it too) re-reads after insert and a same-instant duplicate deletes itself in favour of the earliest-created row, so parallel agents never share a bid. `done: true` when the list is exhausted. Optional axis substring filter so one agent per axis is a one-liner.
- **`get_work_state` over-share fixed.** `ct_takeoff` returned *every* CountTooling project of the twin plus the notes ledger of the most recently touched one — on R2-BT-1 that was an unrelated bid's ledger. It now returns only the project(s) stamped with this bid (`external_ref` = bid tag, or the ZZ name) and that project's ledger, or a plain "no project stamped with bNNN yet".
- **Substrate is the twin's job, said plainly.** `get_plan_brief` with no substrate used to point at "the extractor (or operator)"; there is none — EXTRACTOR.md is the twin's manual. The message and `estimator.md` §8 step 2 now say: fetch, extract, insert `bids_plan_substrates`, call again.
- Kickoff `docs/twins/kickoffs/2026-09-05-wendi-blind-rebid.md`: STG-0 claims through the dispatcher, STG-2 spelled out, operator note for running one agent per axis.

Stumbles from R2-BT-1 left for later: `mint_session` returns text not JSON; control characters in responses; robot-book gaps (gas above 1-1/2", 2-1/2" RPZ, PEX-tier fittings, insulation); `scorecard.ts` needs tag aliasing (FD vs FD-1); the doc path `src/lib/bids/takeoffPlacement.ts` is really `src/lib/takeoffPlacement.ts`.
