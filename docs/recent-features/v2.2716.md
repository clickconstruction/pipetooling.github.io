# v2.2716 — "Setup bid room" beside Mark sent today (2026-09-03)

**Why.** The Bid Room's entry point was a dashed, footnote-styled box under Mark sent with a grey "Set up" link; the owner, looking straight at it, asked where the bid room was.

**What.** While a GC has no room yet, the Cover Letter shows a solid blue **✍ Setup bid room** button beside **Mark sent today** (both layouts: the single-GC studio and the per-GC packets). Pressing it opens the room panel under the row (email, Publish & send, revision note, Docs link). Once a room exists, the button disappears and the panel stays in place with its state chip and **Manage**; its border is solid now, not dashed.

**How.** `BidRoomPanel` gained a controlled mode — `open` / `onOpenChange` plus `onRoomPresence(hasRoom)` — and hides itself while there is no room and nothing is open; the tab keeps per-GC open/presence maps keyed `bidId:gcKey`. `BidRoomSetupButton` is exported from the same file. Presence reports go through a ref so the parent's callback identity never re-triggers the room load. Uncontrolled callers (none today) keep the old inline "Set up" header button. Help guide `send-a-bid-for-signature` updated.
