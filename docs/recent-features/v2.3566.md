# v2.3566 — Punch list: the Opinion column (2026-09-17)

The owner, 2026-09-17: *"go through the punch list and add a column where you give me your opinion on if we should add it, and no more than a sentence of the benefit or cost."*

## The field

One optional front-matter line per to-do, beside `size` and `blocker`:

```yaml
opinion: build — 35 hand-rolled tel: links with five sanitizers is a bug farm; one script PR ends it.
```

The verdict word is one of **build · later · drop · your call** (case-insensitive; a parenthetical after it — `build (PR 3)` — stays with the sentence). Everything after the dash is the one sentence. It is a repo field like the rest of the front matter, so anyone with repo access changes it in a PR, and `npm run check:todo-drift -- --fix` carries it to both views: the board on `/punch-list` and the index in `to-dos/README.md`, which gains an *Opinion* column.

## The board

Each card's meta column shows **Opinion** under *Size* and *Blocks*: a verdict chip (green *build*, amber *later*, red *drop*, grey *your call*) and the sentence. Rows with no `opinion:` line show nothing there.
