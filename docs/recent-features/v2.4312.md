# v2.4312 — Edit Job → Bill: line item names read whole on a phone (2026-10-01)

Seen live 2026-10-01 on job 892 PLUM *Megan Connell* at the mobile preset (375 px): Edit Job → Bill → ① Line Items gave each line's name 44 px of text, so names wrapped a few letters a line (*Ro / ug / h In*, *Top / Out*, *Tri / m / Set*). The name shared one table row with the badge, ▲▼, the ×/$ boxes and the trash. Under 640 px the ×/$ columns were content-sized (v2.1233), and the name took the full row only while it held focus (v2.1229). No migration, no edge function.

## What changed

- **Every line stacks under 640 px** ([`JobFormFixturesSection.tsx`](../../src/components/jobs/JobFormFixturesSection.tsx)). The name cell spans all three columns. The ×/$ boxes and the trash sit on a line under the name in the same cell (`data-testid="line-numbers"`, `.jobLineNumbers`), then the In order / Any time switch keeps its own row. The ×/$ boxes are as wide as the longest value (`maxCountChars` / `maxPriceChars`), the same on every row, so they line up down the list. v2.1229's focus expansion (`nameFocusRowId`, the hold / collapse timers, the second `<tr>`) and the narrow `<colgroup>` widths are gone, so nothing moves on focus. The placeholder stays *Line item N* on a phone.
- **The ▲▼ column stands beside both lines** (`.jobLineMove`), so on touch each arrow is half of ~94 px: 32 × 47 px. The badge centres on the same two lines.
- **44 px on touch** (`@media (pointer: coarse)` in [`index.css`](../../src/index.css), scoped to `.jobLineItems--stacked`): the name box (its padding, not a min-height, so one line reads centred), the pencil (44 × 42 inside the box), the ×/$ boxes and the trash (44 × 44). The inputs stay 14 px; iOS focus-zoom is already off app-wide (`maximum-scale=1` in `index.html`).
- **`--job-line-move`** carries the ▲▼ column's width plus its gap (22 px, 36 px on touch) to the lines under a row (Pays, the stage switch, a discount's readout), so they start under the name box. Desktop falls back to the old 22 px.
- **Discount rows** ([`JobFormDiscountRow.tsx`](../../src/components/jobs/JobFormDiscountRow.tsx)) stack the same way on a phone. The entry, its twin and the trash move into the name's column (`data-testid="discount-entry-line"`), the trash keeps to the right edge under the work rows' trash, and the badge and ▲▼ stand beside both lines. The entry box and the twin are 44 px on touch. Desktop keeps its 34 px gutter.
- Desktop (641 px and up) is unchanged: one row, the count and price in their own columns at the fixed widths.
