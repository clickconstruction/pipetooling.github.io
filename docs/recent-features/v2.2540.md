# v2.2540 — Dispatch NCNS: no-call-no-show from the assign-job picker (2026-08-31)

Owner request (picker-footer only, deliberately not on the empty-cell "off"
pills). A quieter "No call, no show" link joins "Not coming in today" in the
Add-job-to-schedule footer; its sterner confirm files the incident and takes an
optional what-happened note.

- **Reuses the existing NCNS spine** — `record_ncns_and_reject_sessions_for_day`
  (attendance incident + reject clock sessions + unwind approved hours; the
  My Time day editor's RPC since the baseline). **Order matters and is load-
  bearing**: the RPC runs while the schedule blocks still exist (with zero
  sessions it accepts only as "scheduled, no clock time"), and on ANY refusal
  (open session / already recorded / access denied) nothing else happens.
  After the incident lands: blocks removed + a `user_time_off` day written with
  the new `NO_CALL_NO_SHOW_NOTE` ('No call, no show').
- **Distinct board chip**: `userTimeOffByCell` gains an `ncns` variant (label
  NCNS, solid-red chip in `ScheduleDispatchTimeOffChip`), outranking
  `not_coming_in` when both overlap a day. Chip stays clickable for undo in
  both grid sites.
- **Honest undo**: `ScheduleDispatchUndoNotComingInModal` gains `isNcns` —
  clearing the schedule mark never deletes the attendance incident (copy says
  so; removing an incident stays a payroll-side action). Wired in both
  `ScheduleDispatchHubPage` and `ScheduleDispatchJobWeek` (variant looked up
  from the cell map at request time).
- **Migration `20260831194854_ncns_dispatch_undo_note.sql`**: widens
  `pay_staff_remove_not_coming_in_for_user_day`'s delete predicate to
  `note IN ('Not coming in', 'No call, no show')` — full baseline body,
  predicate change only.
- **Gating**: link renders for dev / master_technician / assistant-like
  (mirrors the day editor's NCNS gate); the RPC enforces payroll-or-team-lead
  regardless.
- `recordNotComingInForUserAsStaff` gains an optional `note` param.
- Tests: `userTimeOffByCell` NCNS variant + rank; help guide
  `schedule-dispatch.md` gains a "No call, no show" section.
