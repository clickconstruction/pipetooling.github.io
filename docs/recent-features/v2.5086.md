# v2.5086 — Lien desk: the run holds an unsigned notice, and the leader can sign it on your screen (2026-10-09)

Lien desk signing, PR 3 of 3, first half (v2.5077 the columns and the papers, v2.5082 Sign and approve ▸). Taunya's moment at the printer, now caught before it: a notice the leader has not signed cannot reach the stack. The hold machinery is v2.4971's; *unsigned* is one more reason in it. The second half (*Only you can sign* on Do now, the Dashboard's Needs you line, the list rows' word) follows as its own PR.

## What changed

- **[`lienRunPaper.ts`](../../src/lib/jobs/lienRunPaper.ts) `runEnvelopeHold`:** an envelope holding a notice whose builder said `signature: null` is held — *Unsigned: the leader signs it from his phone, or draws it here with Leader here, sign ▸.* — after the address and the $0 reasons. A notice whose builder said nothing (`signature` undefined, the test fixtures and any older caller) is not held for it. The sheet lists it in red with the others; the packet and the faces print only the signed; `runMailing` renumbers so the sheet, the dividers and the window agree.
- **[`lienDeskRun.ts`](../../src/lib/jobs/lienDeskRun.ts):** `runNoticeProblems` gains `RUN_UNSIGNED_PROBLEM`, so *Record the run* refuses while a notice is unsigned, as it does for a missing address. `RunNotice` carries the job's `leader` (`RunBuildOpts.leaderFor`, the desk's `leaderNameFor`, Put a GC on notice's `signerNameFor` before its comma) and the row's `rowFields`, what a signature made from the run binds to.
- **The run window (`LienDeskRunModal`):** a `viewer` prop (who is at this screen: `authUserId`, `authName`, from both hosts). On a held row with an unsigned notice and a known leader, **Leader here, sign ▸** opens the sheet: `LienNoticeSignLine` with `allowPress={false}` (a press on this screen would be the viewer's act, so only the pad), the line *Robert Douglas draws on this screen. The record names Taunya as whose screen it was.*, **Sign ▸** and **Cancel**. `signHere` signs every unsigned notice in the envelope with the one drawing (`signLienDeskItem`, `onDevice` = the viewer, `approve: false`), dresses them in the window's own list with `lienNoticeSignatureAfterSigning`, and tells the host to re-read. The explainer's hold words name *unsigned*.
