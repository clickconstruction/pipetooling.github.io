# v2.7094 — Help guides use made-up names in their examples (2026-11-12)

The repo is public and the guides ship on the public site. Their examples held names, streets and emails that read like real customers, builders, owners and job sites. v2.7087 replaced the same strings in the test fixtures. This is the same list run over the help guides.

## What changed

- **Names only**, in 76 guides under `src/content/help/` (309 replacements). The list is the one v2.7087 used, so a name reads the same in a guide and in the test that covers its screen. The list is kept outside the repo, because it holds the old strings.
- **One caption by hand.** The GC Review recording in *send a GC our lien waiver* named two builders in its caption. The caption now says *one GC* and *another GC*, so it does not name a builder the recording does not show.
- No step, button name, link, heading or frontmatter line changed. No code, no migration, no edge function.

## Not done here

- **Screen recordings.** A `{{gif:…}}` recording in `public/help/` may show an older name on screen. They are listed in the PR and not re-recorded.
- **Other areas.** Release notes, code comments, to-do cards and the developer docs each get their own sweep.
- **Git history** still holds the old strings.
