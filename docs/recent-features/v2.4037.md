## What was removed from [`lib/myTimeDayPersist.ts`](../../src/lib/myTimeDayPersist.ts)

1. **Branch 4's "boundaries match original rows" arm** (per-row note updates for one part over several rows). One payload means two boundaries; several rows have three or more; the lengths never matched (quirk 18).
2. **Branch 4's metadata throw.** A one-payload block without shared metadata always entered the partition, which writes or refuses first. Branch 4's multi-row half now reads: not shared → partition (write or refuse), shared → replace RPC. `partitionPersisted` and the always-true `split.boundaries.length === 2` test go with it.
3. **Branch 5's draft throw.** The draft guard before branch 3 throws the same message for any draft with more than one payload.
4. **Branch 9's metadata throw.** Branch 9 is reached only when branch 8's `c.length > 1 && !shared` is false with several rows, so metadata is shared.
5. **The `payloads.length < 1` half of the first guard.** `buildPayloads` returns null or at least one payload.

The sixth finding (branch 8 writing with as many parts as rows) became reachable in v2.4023, but only to refuse; nothing to remove. The unused `boundariesMatchOriginalRows` import goes.
