# v2.2033 — Portal links unfurl: OG card + Cloudflare Worker shell (2026-08-21)

Makes texted `my.clickplumbing.com/<slug>` links render a rich branded card
in iMessage/WhatsApp/Slack instead of a bare URL.

- **Why bare before**: the short domain 301'd straight through, so preview
  fetchers landed on the SPA at `pipetooling.com/p/…` — served with HTTP 404
  (GitHub Pages deep link) and no Open Graph tags. Most unfurlers show
  nothing for that.
- **Cloudflare Worker `portal-link-shell`** (clickplumbing.com zone, route
  `my.clickplumbing.com/*`; reference copy + full rationale in
  [`scripts/cloudflare/portal-link-shell.worker.js`](../../scripts/cloudflare/portal-link-shell.worker.js)):
  returns a 200 HTML shell with OG tags — title personalized by prettifying
  the slug (`knight-contracting` → "Knight Contracting · Click Plumbing &
  Electrical"; pure string transform, no data access, previews never show
  balances) — then meta-refresh + JS bounce to `pipetooling.com/p/<slug>`.
  `noindex` meta + `X-Robots-Tag` keep customer slugs out of search engines.
  The old "portal short links" Redirect Rule was deleted (Redirect Rules run
  before Workers and would have shadowed the route).
- **This PR's repo assets**: `public/portal-og-card.png` (1200×630 statement-
  letterhead card: CLICK. wordmark, "Your account, any time", benefits line)
  and `public/portal-og-icon.png` (square mark), referenced absolutely by the
  Worker. Canvas-composed to match the portal page's ink/paper/copper.
- Worker edits happen in the Cloudflare dashboard — keep the reference copy
  in sync.
