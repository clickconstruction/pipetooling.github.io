# v2.2418 — Edit Bid Save gated while logging a contact (2026-08-28)

QA repro (2026-08-28): open Edit Bid → **Log contact…**, half-fill the editor
(method/time/note), press the form's **Save** — the whole form submits, the modal closes,
and the pending contact is silently discarded.

Fix (smallest-change option): the open state of the inline editor now surfaces from
`BidLogContactControl` via a new optional `onOpenChange` prop (reported from a
`useEffect` on `open`, with an unmount cleanup so the parent is always released).
`BidFormModal` holds it as `loggingContact` and:

- disables both **Save** and **Save and Open Counts** while the editor is open, with
  title "Finish or cancel the contact you're logging first";
- guards the `<form onSubmit>` too — Enter-key implicit submission bypasses a disabled
  submit button in some paths, so the handler `preventDefault`s while `loggingContact`.

No behavior change when the editor is closed. Help guide `follow-up-with-builders.md`
notes the guard in its Log contact… sentence.
