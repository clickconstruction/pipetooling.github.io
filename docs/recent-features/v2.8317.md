# v2.8317 — State roll: the dev seat's check_license reads a plumbing number (2026-11-22)

Punch list #411, the last piece of step two in [`to-dos/state-roll/`](../../to-dos/state-roll/README.md). `dev-mcp` 0.128.0. No migration, no new verb, no screen.

## What was wrong

`check_license` refused a plumbing number. Its words said the plumbing board keeps no open list, so a person had to use the board's search, which asks for a robot check. The same claim sat in the comments of `src/lib/logbook/licenseText.ts`. The board does publish its licenses, as free files, and `license-roll-pull` has read them every week since [v2.8164](./v2.8164.md).

## What changed

- **`supabase/functions/_shared/licenseRollCheck.ts`** (new, pure, 11 tests in `src/lib/licenseRoll/licenseRollCheck.test.ts`)
  - `tsbpeFilesForLevel` names the board's file a license of each level is found in: `PA` for an apprentice, `TP` for a tradesman, `JP` for a journeyman, and both `MP` and `RMP` for a master, who may be on either.
  - `tsbpeAnswer` finds the number in the rows read. It compares numbers as `rollNumberKey` writes them, so `J-000412`, `#412` and the board's `000412` are one number. It never matches by a name.
  - A master on both master files is answered by the row that is current, and both are listed.
  - The answer carries the holder, the level, current or expired, the day issued, the expiry and the endorsements. A master who contracts with the public also carries the company and the day the insurance on file ends.
  - It gives no ZIP, county, address or phone. The check is of a number, not of where a person lives.
  - A miss names the files read. For the two zipped files it adds that the board refreshes them about weekly.
- **`supabase/functions/dev-mcp/index.ts`**: for `trade: 'plumbing'` the case fetches each file of the level, unzips the two the board zips, and reads it with `tsbpeRows`, the pull's own reader.
  - A read gives up after 30 seconds, with the wait named.
  - A file of under 200 rows is refused as too few to be the roll, the line the pull holds.
  - A layout the board changed is refused with the column named.
  - The case reads the board alone. It reads and writes no table, and nothing is kept.
- **`src/lib/logbook/licenseText.ts`** and its generated copy: the comments no longer say the board has no open list.

## What is not here

The edit window on People → Licenses still offers the board's search for a plumbing license. A page cannot read the board's files: each is the whole state at one level. A check from that window would need a door on the server, and the Our own view already lays every plumbing license we hold beside the state's row.
