# v2.5058 — Division 22 codes: see every rule and section (2026-10-09)

This is PR 3 of the Division 22 rules manager train (`to-dos/division-22-rules-manager.md`): the manager's read side, with no writes. It is built on the kernel (v2.5054) and needs no migration.

## What changed

**`SpecSectionAuditModal`** (Bids → Pricing → Share ▾ → **Division 22 codes**) gets three tabs (`role="tablist"`). The window opens on **Names**, which is today's audit, unchanged.

- **Rules** (`SpecSectionRulesTab`): every section in code order, with its rules in deciding order and the no-code rules last.
  - Each rule shows the audit window's wording (*starts with WC-*) and its order with the band (*order 100 · patterns*).
  - It also shows its standing from `ruleStandings`. That reads *Decides N names on M bids* (a fold-out lists the most-bid names), or *Never decides: "…" gets its names first*, or *Catches no name yet*.
  - A section with no rules says *No rule files names here yet*.
  - **Find a rule or a section** narrows the list by pattern, code or title.
- **Sections** (`SpecSectionSectionsTab`): a table of each section's rules, names and bids (`sectionTallies`), with the no-code line last.
- **The ledger loads sorted, priority then age.** That holds for the first load and for the reload after a pin, so equal orders decide the same way on every load. Prod has no equal orders today.
- **Kernel**: `sectionTallies(groups, standings)` totals each section.
- **Docs**: the guide *send a bid pricing package* names the three tabs, and `docs/GLOSSARY.md` gains *Division 22 codes (the rules ledger)*, the window's first doc home.
