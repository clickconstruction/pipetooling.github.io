## Why

It lived inside the 4,223-line tab as a closure over sixteen of the tab's reads and one state setter, so no test could call it. It was read only through the mounted tab.

5. **The same tests, and the same HTML.** The smoke passes as it did. The page's HTML matches main's **byte for byte in all 35 states**.

Nothing else in the tab changed but one import: `computeBidCostBreakdown` is no longer read there. The tab is 4,191 lines, from 4,223.
