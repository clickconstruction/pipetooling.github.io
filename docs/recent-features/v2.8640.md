# v2.8640 — New Job and Edit Job: the address box asks when the map puts a new address at the same spot as one on file (2026-11-26)

Punch list #439, piece 2 of seven, its last part. Client only: no migration, no edge function. It writes to `address_place_answers`, the table v2.8529 made, through that table's own policies.

## What was there

v2.8520 asks about a typed address that is a letter off one on file. It reads words only, so it stays quiet about a unit, a building or different words. v2.8529 pairs those up from the map, but only once both addresses are on a job, in **Addresses that look alike**. A person typing a new address at a spot the company already has was told nothing.

## What changed

- **The question.** An address that is not on file, with a map point at the same spot as an address that is, asks after the box is left: **Is this the same place?** One line says how many jobs and bids are on file there, how far, and under which address. The two spellings sit under it with the differing words marked.
- **Three presses.** **Same place, use that spelling** rewrites the field to the address on file and keeps no answer, since the two then share one key. **Same place, keep mine** and **Not the same** keep the answer in `address_place_answers` and change no address.
- **Asked once.** The answer is the list's own answer, under the pair's two cleaned keys. So the pair is not asked again, in the form or in **Addresses that look alike**.
- **After keep mine** a green line under the box reads *Kept as the same place as …*, with what is there.
- **A refused answer** says its reason under the presses, and the question stays.
- **Who is asked.** The office only: dev, master, assistant, controller, the roles the table lets write. Nobody is asked whose answer would be refused.
- **Never a gate.** Nothing here blocks a save, and it stays quiet while the box has the focus.

## How it is built

- `src/lib/addresses/sameSpotOnFile.ts` (pure). `sameSpotOnFile` answers the addresses on file to ask about, the nearest first, by the list's own reach: 75 m when the two are written alike (`writtenAlike`), 40 m for different words, and nothing at a point four or more addresses share, the typed one counted. It leaves out a pair already answered and an address the answers already join to the typed one (`samePlaceKeys`). `samePlaceOnFile` is the quiet line's read. `mayAnswerPlace` is the role rule.
- `src/hooks/useSameSpotOnFile.ts`. It reads only once the typed address has a point, is not on file and the list is loaded: the map's points in a box of a thousandth of a degree around the typed point (`address_geocodes`, five hundred rows at most) and every kept answer, kept a minute. A failed read answers nothing. An answer kept joins the kept list at once.
- `JobFormAddressPin.tsx` hands its point up through `onPoint`, from the cache and from a look-up. The cache read asks for `lng` beside `lat`. `JobFormIdentityFields.tsx` keeps the point under the address's map key and hands it down only while the box still holds that address.
- `JobFormAddressSameSpot.tsx` draws the question and the quiet line. `JobFormAddressOnFile.tsx` shows it when the address is neither on file nor a slip still to answer.
- `useAddressLookAlikes.ts` exports `readAnswers` and `answerPlaceKeys`, which `answerLookAlike` now calls.

## Design calls

- **The same pairs as the list.** The form asks about exactly what the list would show after the save, by the same reach and the same pile rule. A second rule here would ask about pairs the list never shows, or miss ones it does.
- **A slip comes first.** An address a letter off one on file gets v2.8520's question. **Keep mine** there settles that address, and the form does not ask about the same one again as a place.
- **One at a time, the nearest first.** With two neighbours at a spot, the second is asked after the first is answered.
- **A small read.** The list reads every map point. The form reads a box around one point, since it runs under someone filling a form.
- **An answer for an address no job has yet.** If the form is then closed with **Discard**, the row joins a key nothing is written under, which reads as nothing, as v2.8542 found for a fixed pair.
- **No Undo here.** Once the job is saved the pair shows answered in **Addresses that look alike**, with **Undo**.
