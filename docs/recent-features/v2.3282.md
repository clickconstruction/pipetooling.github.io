# v2.3282 — Floaty: catch him, then slingshot him through a floating ring (2026-09-11)

Client only — no migration, no edge function. Prototype (approved, then tuned by the owner): https://claude.ai/code/artifact/f34b358f-263f-4c21-aa24-990b4e968abf

## Why

Owner: Wendi (estimator) loves the Settings-managed visitor from v2.2074. Make him reactive — catch him and he stays; then "Angry Birds style", pull him back and shoot him through a target with a line showing the flight path. Iterated in the prototype to: a plain **floating ring** (not a hoop — "reduce the number of things"), an **aim-preview length knob** (shorter = riskier), the **almost-in shot rattling back at the shooter**, shots **from underneath counting**, and the owner's collision spec — *his image edge is the real edge; the ring has two collision points, far left and far right*. Every number the prototype exposed had to ship as an admin setting, not a constant.

## What shipped

**Config** ([`easterEggsConfig.ts`](../../src/lib/easterEggsConfig.ts)): each egg row in `easter_eggs_v1` grows `tuning` `{ oddsOneIn, playSec, fleeScale, fleeRampPerDay }` and `catch` `{ enabled, holdSec, shots, power, gravity, aimPreviewSec, ringScale }`. Pre-v2.3282 rows parse to the defaults (owner-tuned: 1-in-15 · 7s · flee 0.7× · +0.3× by 6pm · catch on · holds 20s · 1 shot · power 9 · gravity 1500 · aim 0.8s · ring 1.00×), so the live Wendi config gains the game without a rewrite. `EASTER_EGG_KNOBS` is the single list of sliders + ranges; `clampKnob` snaps parsed values to each knob's grid. `rollEggAppearance` takes per-egg odds. **He gets faster through the day** (owner add-on during the build): `fleeScaleAtMinute(tuning, minutesIntoDay)` adds `fleeRampPerDay` linearly across the company work window 6am → 6pm (`APP_CALENDAR_TZ`), flat outside it, ceiling 1.8×; the host fixes each visit's flee at mount from `startOfYmdInAppTzMs(todayYmdInAppTz())`, so a new company day starts him slow again.

**Kernels** (pure; tests in the matching `*.test.ts` files):
- [`easterEggRing.ts`](../../src/lib/easterEggRing.ts) — `placeRing` (360–620px away, always inside a full pull, ring scaled), `launchFromPull` (velocity = pull × power; he launches from the pulled-back point), `aimArc` (dots for `aimPreviewSec` of flight), `stepFlight` (gravity in 3 substeps; the ring is **two collision points**; contact = the injected silhouette test; inside-edge hit → restitution 0.8 + a kick back toward the shooter, outside hit → 0.5; **crossing the rim line between the points scores from either direction**), `flightGone`.
- [`easterEggSilhouette.ts`](../../src/lib/easterEggSilhouette.ts) — the sprite's alpha mask at 110×130 (`loadSpriteMask` is the one canvas IO; `maskFromRgba`, `spriteLocalPoint` (undoes rotate/scaleX/scale about the box centre), `maskSolid` (ellipse fallback until the mask loads), `makeTouching` (3px dilation so the ring point has thickness)).
- [`easterEggMotion.ts`](../../src/lib/easterEggMotion.ts) — `EggInput` gains optional `playMs` and `fleeScale`; defaults unchanged.

**Runtime** ([`FloatingEasterEgg.tsx`](../../src/components/FloatingEasterEgg.tsx)): the visit component now runs a small state machine over the kernels from the same single rAF loop — `kernel` (enter/play/leave as before) → press on him in play (`pointer-events: auto` only then, and only with catch on) → `caught` (ring placed, breathes, wriggles free after `holdSec`) → `aim` (rubber band + dotted arc; a plain click just holds him) → `flight` (ring clank wiggle on contact; swish pulses the ring green, he drops through and fades, visit ends) → a miss returns him for another shot while `shots` last. Layers: arc/band SVG and the ring at z 8999, the sprite at 9000, a small caption at 9001 — all `pointer-events: none` except the catchable sprite, all print-hidden. Saturated ring/arc colours are literal on purpose (status/action hues per the theme rule); the caption uses tokens. The host passes each egg's `tuning` + `catch`; the preview event may carry the card's unsaved config so a dev feels a slider before it saves.

**Settings** ([`EasterEggsSettingsBlock.tsx`](../../src/components/settings/EasterEggsSettingsBlock.tsx)): the card's summary line is now live (`daily debut + 1-in-15 · plays 7s · flees 0.70× · catch & ring: 1 shot, holds 20s`); a **Tuning…** toggle opens two slider groups — *The visit* (Appears 1 in, Plays for, Flee speed, Faster through the day) and *Catch & ring* (on/off checkbox, Holds after catch, Shots per catch, Sling power, Gravity, Aim preview, Ring width) — plus *Reset to defaults*. Sliders draft locally and save once on release (pointer up / key up / blur). Preview here now plays the current sliders.

**Help**: new guide [`easter-eggs.md`](../../src/content/help/easter-eggs.md) (dev) — targeting, the knobs, what the person sees.
