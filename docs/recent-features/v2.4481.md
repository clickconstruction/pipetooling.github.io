## What was wrong

## What changed

- **The kernel** ([`robotOffer.ts`](../../src/lib/submittals/robotOffer.ts)): `staleAsk(kind, requestedAt, seat, now, day)`. An ask is stale when no seat is live, or when it has waited more than a day (`ASK_STALE_AFTER_MS`). It returns the head (*You asked the robot on Sep 28. No robot has run in 12 days.* — or, with a live seat, the seat's own line and *It has not picked this up.*), what to do by hand for that chore, and a short suffix. null while the wait is ordinary.
- **The schedule card** ([`BidsSubmittalsTab`](../../src/components/bids/BidsSubmittalsTab.tsx)): a stale ask reads the head on amber, the by-hand sentence under it, *Take the ask back* where Cancel was, and *Type or paste the schedule* as the blue button. A fresh ask with a robot awake reads as before.
- **A vendor PDF and a reviewer's file** waiting on the robot: the task line gains the suffix (*· asked Sep 29 · no robot has run in 12 days*).
