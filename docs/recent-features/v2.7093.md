# v2.7093 — Roadmap: Add task has the New task window's rows (2026-11-13)

Punch list #331, PR 4 of 4, the last. The roadmap's **Add task** window (`ChecklistTechTreeAddTaskModal`, the **+** on a stage) was a title box, a Done when… box, a tick box, the Place row and a list of everyone with its own search. It now draws the same rows as the New task and Edit task windows. No migration.

## What changed

- **The rows:** the words, **For** as faces with a face for each crew and **Someone else** for the full list, **Where** as the place shelf with the Photo press, and **Add** with the two things a roadmap task carries, *Done when…* and *Photo at the finish*.
- **No When row.** A roadmap task lands on each person's list when its stage unlocks. `TaskFormRows` takes `hideWhen`, `hideWhere` and `addKeys`, so a window draws only the rows it has.
- **The sentence** (`roadmapTaskSentence`): *It joins the stage North fence. Theo gets it when the stage unlocks. It has 2 Done when… lines and asks for a photo at the finish.* With nobody picked it says *Nobody has it yet.*, since a roadmap task may wait for its person.
- **The button** reads **Add task**, dead until the task is typed. Cancel is gone; the × closes, and a press on the backdrop still closes unless a save is under way.
- **The giver's photo of the spot** can now be taken when the task is added. `onSave` hands it to the roadmap, which files it under the new task's id (`putTaskSpotPhoto`, kind `roadmap`). If the photo does not save, the task still stands and the page says to add it from the task's card.
- **Nobody is picked as it opens**, as before, and a pick adds a person beside the others.
- **The layers:** the window sits at `ROADMAP_TASK_WINDOW_Z` and passes `ROADMAP_TASK_PICKER_Z` through the rows to the place sheet. A walk of this window found *Where is it?* opening behind it. That fix is in the place train (the v2.7064 fragment).
- The window's unused edit mode keeps the words and the faces only.

## What it no longer has

The old list of everyone marked a person picked through a crew with that crew's name, and offered *↵ add* on a single search match. The shared list has neither. The crew's own face shows whether all or some of it is picked.
