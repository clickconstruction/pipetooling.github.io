The PR names each card that changes"*, pick **Yes, mend it**. A kernel and its tests. No migration, no edge function.

**The fault.** `mockupsFor` in `src/lib/todos/todoBoard.ts` gives a folder card every `.html` in its folder. A card's pictures page, `pictures.html`, is such a file. `mockupState` reads *has* when one exists. So a card with a pictures page and no drawing stopped reading *waiting on a mock-up*. The pictures page shows the built screen, or today's beside the card's drawing. It is not the drawing a card waits on.

**The mend.** `mockupsFor` leaves out the page `picturesFilesFor` names: `pictures.html` for a folder card, `<slug>-pictures.html` for a flat one. A page that only starts with the word, such as `pictures-of-the-plan.html`, is still a mock-up.

**The door stays.** The pictures page reached a card's links line only as one of its mock-ups. So `linkChips` now draws it as a chip of its own, **pictures**, after the mock-ups. And the by-number row's one door, `mockupDoor`, opens the pictures page under the name *pictures* when the card has no mock-up.
