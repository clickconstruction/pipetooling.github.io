# v2.2359 — The Pricing Tape: floating tape calculator on Bids → Pricing (2026-08-26)

Estimators do constant side-math while pricing (quotes, submittals, margin checks) with a desk calculator or phone — and stray keystrokes land in live Sale Price inputs. The Pricing Tape gives that math a home on the page.

- **Resting state**: a 52px floating icon, fixed bottom-right of Bids → Pricing (desktop only, `useNarrowViewport640` hides it on phones). Click → the panel unfolds and arms. `—` or double-Esc tucks it back. Open/closed persists per device (`pipetooling_pricing_tape_open_v1`).
- **Armed focus model**: while armed (amber ring + "keys land here" chip), a window keydown handler routes digits/operators/Enter/Backspace/C to the calculator — guarded against modifiers and typing surfaces (`INPUT`/`TEXTAREA`/`SELECT`/contenteditable). Clicking anywhere outside disarms instantly; Esc disarms first, closes second.
- **Tape ledger**: every `=` appends `{expr, result, at, note?}`; rendered with live "4m ago · 3:52 PM" timestamps (30s refresh tick), newest at bottom, top fade via CSS mask. Click a line to roll its result back into the display. Capped at 200 lines, persisted per device (`pipetooling_pricing_tape_v1`).
- **Notes**: letters typed right after `=` open an inline note input on the freshest line (x = multiply-chain and c = clear keep their calculator meanings); ✎ on hover edits any line. Search matches notes, expressions, results (comma-insensitive), and timestamp text.
- **Clipboard**: native `paste` event while armed (no permission prompt). One number lands as typed (money formats understood); multiple numbers sum into one transparent `(pasted)` tape line — part codes (`WH-1`) excluded via lookbehind, `(617.97)` accounting negatives subtract. Click the big result to copy it out.
- **Math model**: strict left-to-right (desk-calculator semantics, no precedence), divide-by-zero renders `—`.

Files: kernel `src/lib/tapeCalculator.ts` (+ `tapeCalculator.test.ts`, 24 tests), widget `src/components/bids/BidsPricingCalculator.tsx` (mounted in `src/pages/Bids.tsx` pricing branch, zIndex 900 — SectionDock's shelf, under all modals), help guide `src/content/help/use-the-pricing-calculator.md`.
