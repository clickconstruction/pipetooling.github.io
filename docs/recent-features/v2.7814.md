# v2.7814 — Time on a painted map (2026-11-18)

Punch list #395, step 6 of 7. `PaintedMapCanvas` is its own Leaflet map with its own drawing tools, so it takes the pieces and not the frame, as `OnSiteMap` did: `useMapTime`, `MapViewControl` and `MapTimeRow`.

## What changed

- **A new prop, `time`.** A caller that is only showing a map hands `{ name }`, and the canvas then wears **Time** beside **From above** and **Streets**. The painting window hands it in its `view` mode, with the map's own name for the row.
- **Reading only.** The press and the row are absent while a line (`draft`) or a place (`dot`) is being drawn, on a `still`, and on a map with nothing on it yet. Drawing that begins while Time is on turns Time off first. So no corner is ever set against ground that has since changed, and the magnifying glass only ever draws today's picture.
- **Time moves nothing.** The map is already framed on its lines. Time swaps the tile layer under them, and the row says *The lines are today's.* beside a date. The spot the archive is asked about is the middle of what the map opened on.
- **The public page.** `/way` hands no `time`, so an outside reader has the two views and nothing else.
- **The presses.** The canvas's own two buttons become the shared `MapViewControl`, which now takes the word a map uses for its photograph (`satelliteLabel`, *From above* here).
