# v2.7501 — Plan sets: a sheet count on a set, and sheets in hand on the plans by date (2026-11-16)

Punch list #367, PR 5, the last of the train. The owner's hand chart counted the sheets in hand at the bid and the sheets in the current sets. The app did not know how many sheets a set has: `plan_sets.file_count` counts the files in a Drive folder, and one PDF can hold sixty sheets. The column is `plan_sets.sheet_count`, from migration `20261117070000` (v2.7496).

## Where the count is typed

- **Adding a set**: a **Sheets** box in the set's form (`PlanSetForm`), on the Development page's parts table and on a job's Documents tab alike. It is optional. Words that are not a whole number are refused with *The sheet count is a whole number, like 64.* (`sheetCountOf`, `newSetDraftProblem`).
- **A set already saved**: its card on the By date view offers **Set the sheet count**, or **Change the sheet count** once it has one. The press asks in the prompt window; an empty answer clears the count. The write is `updateSheetCount` on the plans io, read back so a refusal is an error with its reason.

Whoever can write plans can type it: dev, the leaders, the assistants, the controller, the estimators.

## Where it shows

- A set's card on the By date view: **Sheets · 118 sheets**.
- A fifth figure, **Sheets in hand** (`plansByDateSheets`): the sum of the counts of the sets the parts build from. Its sub line says what was in hand at the bid, which is, part by part, the newest set dated on or before the day the bid was sent. It also says how many of the sets being built from nobody has counted, so a low number is never read as the whole truth.
- The figure is drawn only once some set on the site has a count. Its card lists the sets being built from, each with its count or *not counted yet*.
- The figures row wraps at a sensible width now that it can hold five, on the screen and on the print.

## Safe either side of the push

The parts read selects every column, so the count arrives by itself once the column exists. The insert sends `sheet_count` only when a count was typed, as it does for *What changed*.

## Verify after deploy

Looked at with made-up rows at 375, 768 and 1280 px, light and dark, in a headless browser. Not walked on a live site. Add a set with a count, see it on the set's card, change it from the card, clear it with an empty answer, and see the figure follow.
