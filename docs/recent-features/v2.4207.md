# v2.4207 — Submittals: a step's title jumps into it, the same as its pill (2026-09-30)

No migration, no edge function. After v2.4201 the owner asked what the road's step titles would look like if they jumped the way the pills do; drawn as [`road-title-jump-before-after.html`](../../to-dos/submittals/road-title-jump-before-after.html) (the After panel is this) and built on the owner's call: "build it the After way."

- **The title jumps.** `RoadSection` takes `onJump` beside `onToggle`; the title button calls `jumpToSection(key)`, which finds the journey's stage and runs `goToStage(stage, { scroll: 'ifNeeded' })` — the section opens, and a frame later its controls ring (`submittal-journey-flash`). **The page moves only when it must**: `goToStage` reads the control's rect and scrolls only when it sits outside the viewport — to centre, since the nearest edge is where a phone's tab bar sits (the first cut used `nearest` and left New revision under it on BP398); a pill keeps `scroll: 'center'`. A stage with no controls yet rings its section.
- **The caret folds.** A jump only opens, so the ▴ / ▾ after the title is its own button (`road-<n>-caret`, *Fold step N* / *Unfold step N*, `aria-expanded`) calling `toggleSection`; the title (`road-<n>-title`) no longer toggles.
