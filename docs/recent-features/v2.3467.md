# v2.3467 — Submittals stage 2c: the package PDF (2026-09-14)

Client only; no migration, no edge function. Stage 2's last PR ([`to-dos/submittals/README.md`](../../to-dos/submittals/README.md) → PR 2c): the revision's rows rendered as one PDF — the cover table, then every row's cut-sheet pages copied out of the dropped vendor PDFs and stamped.

## What shipped

- **Kernel** [`src/lib/submittals/submittalPackage.ts`](../../src/lib/submittals/submittalPackage.ts): `planPackage` (sheets laid out behind the cover in row order; the package page each starts on; the rows still owing a sheet — a *missing* row never owes one), `buildCoverModel` (the cover's words: title `SUBMITTAL · Rev N`, the meta line, the counts line, the seven-column table with *p. 3–4* / *to follow*, the notes — sheets to follow, the accessories sentence, the revision note), `renderCoverPdf` (jsPDF, landscape letter, the test-report letterhead: company name, tagline, phone; paginates the table with a repeated head; *cover N of M* footer), `buildSubmittalPackage` (pdf-lib: cover pages, then each sheet's pages, stamped `TAG · STATUS` top-right in the status's ink and footed *Tag · product · sheet page i of n*; a file that will not load or pages out of range are skipped and named), `packageFileName`. Tests in the `demandLetterPacket.test.ts` style (plan, model, merge page counts and manifest, skips).
- **The tab**: **Build package** (any revision with rows) → settings from `fetchTestReportSettings`, the plan, the cover (rendered twice only when the cover ran past a page, so the sheet page numbers are right), only the vendor files the rows use are downloaded from the bucket, the merge, stored at `<bid>/<rev>/package-rev<N>.pdf` (upsert), `bid_submittals.package_path` set, a 300-second client-minted signed link opened in a new tab (the fresh blob as the fallback); the toast counts pages and sheets and names the rows still owing one. **Open package** when a path exists; **Rebuild package** replaces it. The revision line reads *package built*.
- Nothing is sent or shared: the estimator downloads or prints it, or attaches it to her own email until stage 4's Share.
- **Guide**: [`build-a-submittal-package.md`](../../src/content/help/build-a-submittal-package.md) gains "Build the package".

## Why no `open-submittal-pdf` here

The plan named a function for the signed link; staff already hold SELECT on the bucket (v2.3465), so the client mints the link the way Documents → Jobs does for test reports (v2.3331). The function is still stage 4's, for the GC's token page — outsiders never hold a bucket policy.
