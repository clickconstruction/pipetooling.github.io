# v2.3734 — Send the run: each envelope is a card on a phone (2026-09-22)

Found on the first live run of *Put a GC on notice* on test data (punch list #16, below). Client only, no migration.

## What was wrong

At 375 px the run modal's envelope table (v2.3720) was 421 px wide inside a 343 px box: the *Tracking #* column sat off the right edge (reachable only by scrolling the table sideways), the job label column collapsed to one word per line, and the footer's hint wrapped in a narrow column between the two buttons. Tablet and desktop were fine.

## The change

- **[`LienDeskRunModal.tsx`](../../src/components/jobs/LienDeskRunModal.tsx)** — the cells' paddings and borders move from inline styles to classes (`lienRunTable`, `lienRunEnvelope` / `lienRunWho` / `lienRunMethod` / `lienRunTracking`, `lienRunCopy` / `lienRunJob` / `lienRunMonths` / `lienRunFor`, `lienRunFoot` / `lienRunFootHint`), and the Method and Tracking cells carry `data-label`. Nothing else in the markup or the tests changes.
- **[`index.css`](../../src/index.css)** — the same paddings as rules, and under `@media (max-width: 640px)`: the table, rows and cells display as blocks; the header row hides; each envelope row is a bordered card; `td[data-label]::before` prints the small caps label; the select is full width; the footer hint takes the whole first line, the buttons follow.
