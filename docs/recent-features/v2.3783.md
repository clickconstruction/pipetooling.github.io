# v2.3783 — Quickfill on a phone is a round: the sections as rows, one section per screen (2026-09-23)

Client only, no migration. The desktop page is untouched.

## What changed

- **Kernel `src/lib/quickfill/round.ts`** (9 tests): `sectionRhythmDays(markedAts)` — the median gap of a section's last five marks, whole days, at least one; null under three marks. `roundState(lastMarkedAt, rhythm, now)` → `fresh` (≤ 12 h) · `not_yet` · `due_today` · `due` (with days over) · `never`, falling back to the strip's flat 12 h / 30 h rule without a rhythm. `roundRows(sections, marks, events, liveCount, now)` → rows with state, the count and its source (`open` from the page's live reporters, else `last_look` from the newest mark event's `outstanding_count`, else none), sorted due → due today → not yet → fresh, org order inside, the personal doors last. `roundQueue` (the due and due-today rows), `nextInRound`, `roundHeadline`, `describeRoundRow` ("every 7 d · 12 d over · Taunya").
- **`QuickfillRoundList`** — the headline and *Round · N ›* (or *Round done ✓*), a 16 px search, the rows. **`QuickfillRoundScreen`** — ‹ · name · n of N, the section's banner question, the count line with 📈 history, the section's own body, and a sticky bar at the thumb: Skip · *Looked · N open · next →* (personal doors and the note-first sections get *next* / *Mark inside* only).
- **`Quickfill.tsx`**: at ≤ 640 px (`roundActive`) the page renders the list, or the screen when the URL carries a station (`/quickfill#<sectionId>` — the existing deep link, whose effect still force-expands the section). The mark events of the last 60 days load once per phone visit and again after each mark (one query, `quickfill_section_mark_events`). *Looked* is `markSectionUpToDate` — the org-wide mark, with the live count the mounted body reports — then `nextInRound`. A `QuickfillRoundScreenContext` flag makes `QuickfillSectionWrapper` render its body only inside the screen (the id stays for the deep link). The desktop layout — dock, strip, search, all sections, the dev panel — is the other branch, unchanged.
- **`index.css`**: inside `.quickfillRoundScreen` every input, select and textarea is 16 px.
- Help guide `quickfill` (a phone section), GLOSSARY *Quickfill as a round*.
