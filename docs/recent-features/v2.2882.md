# v2.2882 — Role gates say something: one "not for your role" convention replaces silent rewrites, blank pages and RPC strings (2026-09-05)

Journey-map Phase 4, Tier-2 #29 ("Role gates that say nothing", cluster C25 — J8-F7, J7-5, J5-6, J4-8, J5-11, J10-F12; keeps J24-F8, J25-F8, J6-10). Client-only; no migration.

## Mechanism

**Before.** Every in-page role gate was one of three silent shapes: a `setSearchParams(…, { replace: true })` rewrite to another tab (an assistant following the owner's Crew P&L link simply arrived on Reports — J8-F7; a superintendent on six Bids tabs — J10-F12), a render branch gated on an access flag that returned nothing (People's Pay tabs: tab strip, then a blank page — J7-5), or a report shell that opened and printed the RPC's refusal verbatim (`?stagesMoney=1` → "Failed to load weekly money movement: not allowed" — J5-6). Plus one dead branch (`stagesSectionToolsMenu.ts` allowed `primary` to open Accounts Receivable; primaries never reach the Pipeline board and Layout bounces them off `/accounts-receivable` — J4-8) and an impersonation landing hijacked by Dispatch Mode's return-after-away jump (J5-11).

**After.** One pure kernel + one hook.

- [`src/lib/roleGate.ts`](../../src/lib/roleGate.ts) — `roleGateRedirect({ from, role, surface })` → `{ to, toTab, landingLabel, toast, quiet }`. Seven surfaces (`crew-pnl`, `team-labor`, `jobs-tab`, `payroll`, `hours`, `pipeline-money`, `bids-office-tab`); each has a subject + audience, the landing is always a same-page tab the role can open, and the sentence is `"<subject> is for <audience> — you're on <landing>."` (`"This page is for the office — you're on Reports."` for the generic tab gates). `quiet` is true for sub-like roles (`isSubcontractorLikeRole`) — J24-F8's silent bounces are a protected strength, so helpers land with no toast. `roleHomePath(role)` (estimator → `/bids`, else `/dashboard`) mirrors Layout's route guard. `roleGateRefusalMessage(error, subject)` renders `"You don't have access to this report."` for a server-kind error that is a role refusal — RLS `42501`, or the RPCs' own `RAISE EXCEPTION '…not allowed'` (`P0001`) — decided from the v2.2836 `DatabaseError.kind` first; `null` otherwise so callers fall through to `formatErrorMessage`.
- [`src/hooks/useRoleGate.ts`](../../src/hooks/useRoleGate.ts) — `useRoleGate(role, userId).bounce(surface, from)`: runs the kernel, toasts once (7 s, `info`; nothing when `quiet`), records `ui_nav_clicks` `control = 'role_gate_redirect'`, `target = <refused link>` via `recordNavClick`, and returns the decision so the caller applies its own navigation. A 1.5 s per-link dedupe absorbs the effect re-run the rewrite itself triggers.

`usePeopleAccess` now returns `accessResolved`; the People URL gates fire only after it flips (every flag starts `false`, so the old `employment` gate bounced a dev's cold deep link to Users — the same race the `scoreboard` comment describes). Before it resolves the tab is set and the flag-gated render site simply waits.

## Not changed

- Layout's route guard (`isPathAllowedForRole` → `/dashboard` / `/bids`) — helpers' silent bounces are J24-F8 (keep); primary/superintendent route-level bounces are C21/C26 territory.
- Prospects non-holder landing on Customers (J25-F8 keep); partner Job Summary fence (J6-10 keep).
- Bids dev-only tabs (`robot-queue`, `bid-costs`) — hidden dev tools, not role gates people are linked to.
- `CREW_PNL_DATA_FLOW.md` "estimators see Crew P&L" (J8-D1) — docs row in C26.

## Telemetry

`ui_nav_clicks` rows with `control = 'role_gate_redirect'`, `target = <refused link>` (e.g. `/jobs?tab=teams-summary`), `role`, `from_path` — which links people follow that aren't for their role, by role. Sub-like roles are recorded too (quietly).
