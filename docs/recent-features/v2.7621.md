**What each takes.** Every piece is a function of its props and holds no state. The three render helpers read the page's state through their closure; each read is a prop now, and each press is a callback the page fills with the handler the helper called before (`selectProspectForList`, `openBenchModal`, `openEditModalForProspect`, `handleSendBack`, `handleDeleteFromList`, `openAddSub`, `setTradeFilter`, `setPlansFor`). The page still decides when a panel shows: the lane, and the read answered or failed.

**One state stayed on purpose.** Which folds of the Subs list are open (`subsSectionOpen`) stays in the page and goes down as `sectionOpen` with `onToggleSection`. The list unmounts when the caller leaves the tab; state inside it would close every fold on the way back, which the page does not do today.

**The two tone tables moved with their only readers:** `NEED_TONE_COLOR` into `SubsNeedsPanel`, `STAGE_TONE_STYLE` into `SubsLaneList`.

**Size.** `Prospects.tsx` went from 5,284 lines to 4,963, and dropped 36 imports it no longer reads.
