# v2.3238 — Edit Job: the status strip moves up under Stages (2026-09-10)

Client only; no migration.

## Why

The tappable status strip (Waiting → Working → Ready to bill → Billed → Paid, plus the Collections flag; v2.1773) sat above the footer at the very bottom of the Edit tab — below the fact rows, customer, GC, links, fixtures, billing and costs. On a phone that is a long scroll to find the one row that says what state the job is in. Grace, pointing at the space under the address and the *Stages · none yet* line: "at the bottom there are pipeline stages, I would like those moved to here."

## What shipped

- `JobFormModal`: the `JobStatusStepper` mount moves out of the footer area into the edit-mode fragment, directly under `JobFormStagesGroup` (the Stages read-out) and above `JobFormEditFactRows` (Account man, Team, …). Same props, same `onChanged` → the window's save callback. The fragment already renders only in the Edit region, so the old `embeddedRegion === 'edit'` guard is no longer needed there; the Bill tab still never shows it.
- Help guide `edit-job-autosave.md`: "Near the top of the Edit tab, right under the Stages line" instead of "At the bottom of the Edit tab".

## Notes for the next session

- The Stages read-out and the status strip now sit together: plan stages above, billing status below. If that pairing reads as one thing, the two could share a card.
