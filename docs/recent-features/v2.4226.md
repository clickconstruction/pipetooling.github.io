# v2.4226 — Map card render tests blank the Google Maps key, so a dev's `.env.local` cannot flip them (2026-09-30)

No migration, no edge function. Test-only.

## What changed

- `BidBoardMapCard`, `JobsMapCard` and `DashboardJobsMapCard` render tests called `vi.unstubAllEnvs()` in `beforeEach`, which restores the real env — so a worktree whose `.env.local` sets `VITE_GOOGLE_MAPS_BROWSER_KEY` (per-worktree since 2026-09-26) took the Google canvas path and 25 tests failed looking for the OpenStreetMap canvas's pins. Each `beforeEach` now follows the unstub with `vi.stubEnv('VITE_GOOGLE_MAPS_BROWSER_KEY', '')`; the tests that want Google still stub `'test-key'` / `'AIza-test'` themselves. `ClockedInMapModal` already blanked the key.
