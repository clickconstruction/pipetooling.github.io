# v2.5508 — Messages: the Text tab says when texts are off (2026-10-13)

From cc's prod walk after cut 5's switch (#5646, v2.5440): the switch moved the send window from the `TEXTS_ON`
constant to `useTextsOn`, but the reply box still offered the Text tab, the quick replies and **Send text…** with the
switch off (as the row ships), so an office user wrote a text the window would only hold. The box now says so first.

- **The box** (`reply/ReplyBox.tsx`): while `useTextsOn` reads `false` and the shown kind is `text`, the box draws
  `TEXTS_WAIT` (`data-reply-texts-wait`, `role="status"`, the send window's amber) in place of the quick replies strip,
  the textarea, the count, the files and the send row. The kinds row stays, so Email and Note are one press away; the
  words typed under another kind are kept. A settling note forces Note, so it never waits.
- **Both boxes**: the job window's Note · Text · Email box (`JobCustomerBox`) is the same `ReplyBox` with `kinds` of
  one, so its Text box draws the line too and its Email box writes as before.
- **The read** (`reply/useTextsOn.ts`) is now `boolean | null`: null until the row comes back, false when the read
  fails. The box draws as before while it is null, so a box opened once texts are on does not flash the line; the send
  window holds a text on anything but `true`, as it did.
- **The words** (`TEXTS_WAIT` in `replyIo.ts`): "Texts wait until Send texts is switched on in Settings → Phone and
  texts. Send this as an email, or come back to it then." They name the switch the owner or a dev flips, where the old
  words named the phone. The send window draws the same constant.
- **Guides**: `reply-to-a-person-from-their-thread` and `text-a-customer-from-the-job` say texts wait on **Send texts**
  and that the Text tab says so in place of the box.
- **Smokes**: `ReplyBox.textsOn.render.test.tsx` holds the thread box and the job window's box off, on and still
  reading. The box's other smokes hold the switch on, and `SendWindow.textsOn` reaches its held text from an email's
  window moved to Text, since the box no longer offers one.
