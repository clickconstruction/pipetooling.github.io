Owner Billing's O2a in the GC mode real build (`to-dos/gc-mode/OWNER_BILLING_REAL_BUILD.md` → *Kernels that move over with their tests*, on branch `spike/gc-mode`). - **New files:** `ownerBillingInterest.ts` (interest on late bills), `ownerBillingRemind.ts` (reminding a customer to pay) and `ownerBillingFinish.ts` (`ownerFinishRisk`, which reads the schedule's kernels; nothing in `schedule/` reads billing).

- **`types.ts` gains Owner Billing's shapes.** `OwnerBilling`, `OwnerPayAppSent`, `OwnerRetainageStep`, `OwnerInterestBill` and `ChangeOrderReason` are new. `GcProject`, `GcCustomer` and `ChangeOrder` are rewritten with the fields these kernels read. `schedule/testState.ts` is regenerated by `schedule-test-state.ts --with owner-billing-o2a.lift.json`, and the schedule's `moves.direct.test.ts` gives its change order the two new fields (Helper 1's OK).
- **Tests.** Six prototype tests that read only these kernels move as `ownerBilling.test.ts`. `ownerBilling.direct.test.ts` pins the prototype's own answer for 18 more calls on the made-up jobs. `ownerPayApp` and what reads the Building lane's kernels wait for O2b.
