# v2.2524 — Sign-in magic-link fallback after failed password attempts (2026-08-31)

Ported from CountTooling's `features/auth-magic-link.js` (owner request). The
v2.2330 posture stands — still no "Forgot password?" link, `/reset-password`
stays unlinked, recovery stays office-directed — but a user who fails the
password twice can now email themselves a one-time sign-in link instead of
calling the office.

- **New kernel `src/lib/signInMagicLink.ts`** (+ tests): per-normalized-email
  consecutive-failure counter (`recordFailedSignIn` / `shouldOfferMagicLink`,
  threshold 2 — per-email so a typo'd address's failures don't qualify the
  corrected one), `MAGIC_LINK_RESEND_COOLDOWN_S` (60s, GoTrue's email rate
  limit), and `friendlyOtpError` — GoTrue's "Signups not allowed for otp"
  really means "no account with that email" (invite-only + `shouldCreateUser:
  false`), so it's translated to say that; network/rate-limit/banned get plain
  words too. Enumeration-hardening deliberately traded away, same call CT made.
- **`SignIn.tsx`**: failed `signInWithPassword` records against the entered
  email; at 2 failures a blue offer box appears ("Trouble signing in? We can
  email you a one-time sign-in link instead"). Send is
  `supabase.auth.signInWithOtp({ shouldCreateUser: false, emailRedirectTo:
  origin + '/dashboard' })` — the emailed link is consumed by supabase-js
  `detectSessionInUrl`, the same lane the office's send-sign-in-email links
  already use (redirect allowlist already covers clicktooling.com + localhost
  dev ports). Sent state shows the open-on-THIS-device warning, a 60s-held
  Resend, and "Back to password sign-in" (offer stays visible — the email
  already qualified). Typing a different email hides the offer until that
  email qualifies.
- NOT reused: the `send-sign-in-email` edge function — it requires an
  authenticated (office) caller; the anonymous fallback goes through GoTrue's
  own `/otp` endpoint and the auth mailer's custom Resend SMTP.
- **Render tests** (`SignIn.render.test.tsx`): offer-at-2 threshold, per-email
  gating, `signInWithOtp` payload shape, held Resend, back-to-form, and the
  no-account error translation.
- **Help guide** `src/content/help/sign-in-when-my-password-wont-work.md`
  (all roles).
- `authPublicLanding.css`: offer box + sent panel styles (light-pinned public
  surface, matches the file's literal-hex idiom).
