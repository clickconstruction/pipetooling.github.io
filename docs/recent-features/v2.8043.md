# v2.8043 — Gear menu: Fix Mode is now Tell the dev, and Pin Mode is now Pin bar (2026-11-20)

The owner's walk of the app on an iPhone, 2026-11-20: *"I am thinking about whether to change 'Fix Mode' to a different word pairing as the button being active isn't really a mode."* The gear menu ticked five rows that all ended in Mode. Two of them only show or hide one thing.

## The decision

The owner was shown the menu as it was and four ways to name it, and chose: the wrench's switch is **Tell the dev**, the feature's own name, and the pin footer's switch is **Pin bar**. Each row carries the icon of the thing it shows. A grey band under the page modes sets the two apart, so *Mode* means one thing in this menu: a row that changes the page.

| Row before | Row now | What it does |
|---|---|---|
| Fix Mode | 🔧 Tell the dev | Shows or hides the wrench: in the header, in a window's title row and on an error line. |
| Pin Mode | 📌 Pin bar | Shows or hides the bar at the bottom of a pinnable page. Pinned pages work either way. |

Job Mode, Dispatch Mode, Task Mode and Dark Mode keep their names. Dark Mode is the phone's own name for the theme.

## What changed

- **One home for the words**: [`gearSwitchWords.ts`](../../src/lib/gearSwitchWords.ts) holds the two labels, the tip each row shows (*Hide the pin bar*, *Show the wrench that sends a note to the dev*) and the name a screen reader says. Two screens draw the rows, so neither writes the words itself.
- **The gear menu** (`Layout.tsx`): a 7 px band in `var(--bg-muted)` after Task Mode, then the two rows with their icons, then Dark Mode. `PinIcon` takes a size.
- **The phone dock's More sheet** (`PhoneDockMoreSheet.tsx`): a row may carry `group: 'show'` and an icon. The sheet lists the page modes under **Modes** and the pin bar, Tell the dev and Dark Mode under **Show**. It listed all of them under Modes before.
- **The Dashboard's line** while the pin bar is on now says *The pin bar is on*.
- **The words a person reads** say *pin bar*, not *pin footer*: the guides `pin-mode` (its title is now *turn on the pin bar to pin pages*; its address is unchanged), `settings-basics`, `see-which-bills-went-out`, `task-mode` and `tell-the-dev-about-a-page`.

## What did not change

- **Nobody's setting.** The stored keys keep the old word: `pt_fix_mode_<user>` and the pin switch's key in `pinModeToggle.ts`. A wrench that was hidden stays hidden.
- **The code's names.** `useFixMode`, `fixMode.ts`, `usePinModeEnabled` and `pinModeToggle.ts` keep theirs. Their comments say what the row reads now.
- **The comment *Never pin (Pin Mode pins a page)*** in `taskPlace.ts` and `paintedMap.ts`. `taskPlace.ts` is copied into the edge functions' kernels, and a comment is not worth a redeploy.

## Known and accepted

On a narrow phone the header has no room for the wrench, so the wrench is the gear menu's first row, named Tell the dev (v2.7781). That menu now holds two rows with the name: the press that opens the box, and the ticked switch under the band. The owner saw this in the mock-up and chose the name. The guide says which row is which, and the switch's screen-reader name is *Show the Tell the dev wrench* so the two are told apart there.
