# v2.2167 — Review → Goals ledger: stage rows wrap on phones and unfold to their tasks (2026-08-23)

Owner's phone screenshot of the Review tab's Goals stage ledger: titles collapsed to one letter at 375px ("c", "m"), and nothing in the ledger could be tapped — no way to see a stage's tasks. Mockup ("Stages that open", variant built as shown) → this.

- **Rows** (`.goal-stage-row` in `index.css`): a CSS-grid `<button>` — phone: number · full title (wraps) · done/total + chevron on line 1, state chips + a flexible progress bar on line 2; from 640px: the original one-liner with the chevron appended (chips right-aligned next to the 110px bar). Rows with no tasks (milestones / not-planned-yet / empty) render without a chevron and aren't tappable.
- **Unfold**: tapping a stage row sets `expandedStageId` (one at a time, reset when the goal collapses; `aria-expanded`) and renders `.goal-stage-tasks` — per task: number (`6.2`), ✓/○, full title (done tasks struck + muted), then a sub-line with **★ pinned** or **⚡ next up**, assignee names or *unassigned*, and the live bridge chip (on list / in review / signed off). Tapping a task opens the existing **Where this task fits** sheet (`RoadmapTaskContextModal` via `setRoadmapContextTaskId`) — no new modal.
- **Kernel** [`src/lib/roadmapGoalsLedger.ts`](../../src/lib/roadmapGoalsLedger.ts) (`goalsLedgerTaskRows`, +3 tests): per-roadmap task rows keyed by stage — numbers via `roadmapStageNumbers`, ⚡ via `nextUpPicks`, chips via `bridgeChipFor`, names via a `nameById` map — so the ledger can't disagree with Map/Plan.
- **Loader**: the Goals loader's task select gains `title, sort_index, pinned_at`; two small extra reads (`users` names, `checklist_items` bridge rows) — all in the same effect; `goalTaskRows` state alongside `goalStageRows`. No migration.
- Help: `review-my-teams-completed-tasks.md` → "Goals on the board" gains the unfold paragraph.
- Verified live (Playwright, iPhone 13 viewport + 1280 desktop, dev-login): Farm 1 ledger rows wrap; stage 6 unfolds to 6.1 ✓ / 6.2 ★ pinned · on list / 6.3 ⚡ next up; task tap opens the context sheet.
