# v2.3854 — Bids → Cover Letter: each GC version keeps its own price (2026-09-26)

Client only; no migration, no edge function. Found 2026-09-25 while reproducing the app-map sweep's flags; never filed until now.

## Why

v2.2013 added an effect to [`useBidPricingEngine`](../../src/hooks/useBidPricingEngine.ts): entering the Cover Letter tab re-aligns the working pricing to the saved ★ (`bids.selected_price_book_version_id`), so viewing a scenario on the Workbench never changes what the letter shows. v2.2117 then made the ★ per version (`bid_versions.starred_price_book_version_id`), with the bid-level column only mirroring the active version's ★ when one is starred — but `switchActiveVersion` never rewrites the bid-level column. After a switch from GC version A to B, the column still named A's ★, and the effect adopted it whenever that id was among the bid's pricings (which, holding every version's copies, it always was). Reproduced with the real engine: on `ver-B`, which has its own base price `pbv-B1`, a trip to Cover Letter moved the working pricing to `pbv-A1` — another GC's price. A version with no pricing of its own got A's the same way, and on returning to Pricing that tripped `BidsPricingTab`'s documented unscoped fallback (v2.2404 / v2.2409), showing other GCs' price cards priced on this version's counts.

## What shipped

- **`coverLetterPricingTarget`** in [`src/lib/bids/pickActiveVersion.ts`](../../src/lib/bids/pickActiveVersion.ts) — where the Cover Letter moves the working pricing, or null to leave it. Split bid: the active version's own ★, else the bid-level saved id only when it is one of this version's pricings; with no ★ there, keep the current pricing if it is the version's own, else the version's first, else leave it (never borrow another GC's). Unsplit bid: the saved id when it is one of the bid's unsplit copies (as before). 8 new cases in `pickActiveVersion.test.ts`.
- **The effect** reads the active version from the bid-tagged ref (`resolveTaggedVersion`) and the versions' ★s, and re-runs on version and `bidVersions` changes.
- **[`useBidPricingEngine.coverLetterStar.render.test.tsx`](../../src/hooks/useBidPricingEngine.coverLetterStar.render.test.tsx)** drives the real hook (filter-aware Supabase mock, `VITE_SUPABASE_URL=http://127.0.0.1:9`): two GC versions with their own pricing, switch to B, visit Cover Letter — stays `pbv-B1`; B's own ★ wins over a viewed scenario; a version with no pricing stays empty; the v2.2013 same-version re-align still happens. The first three failed on the old effect with `pbv-A1`.
- `docs/BIDS_PRICING_LABOR_TABS_ARCHITECTURE.md` names the effect's rule and the new seam test.
