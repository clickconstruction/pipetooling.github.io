# v2.2614 — The property ledger: legal info on customer addresses (2026-09-01)

Phase 1 of the Lien Instruments plan (owner-approved artifact, 2026-09-01):
the data foundation the in-app demand letter and mechanic's lien affidavit
will stand on.

- **Migration `20260901231430_customer_address_lien_property.sql`** — legal
  columns on `customer_addresses` (county, legal_description, property_kind,
  homestead, owner_mode/name/company/mailing_address) +
  `jobs_ledger.customer_address_id` FK. See the migration doc fragment.
- **Kernels** (unit-tested): `src/lib/txCountyLookup.ts` (curated Central-TX
  city→county suggestions + County Appraisal District search URLs — a
  suggestion, always human-confirmed) and `src/lib/jobs/lienProperty.ts`
  (`resolveLienProperty` precedence: per-job `job_property_owners` override →
  linked address row's owner → nothing guessed; `customerAddressLienReady` /
  `customerAddressLienGaps`; `suggestCustomerAddressForJob` normalized-address
  match, same rule as the duplicate-address finder).
- **Edit Customer → Additional addresses**: each row gains a "Property legal
  info" disclosure — county (with use-suggestion button + CAD ↗ link), legal
  description, residential/non-residential + homestead (with the § 53.254
  tooltip), owner mode/name/company/mailing address — and a ✓ lien-ready chip
  (or "N lien fields missing" with the gap list).
- **LienReleaseModal**: shows the job's linked property record (lien-ready
  state or gaps); when unlinked, offers a picker over the job customer's + GC's
  address rows with the address-match suggestion and a one-click Link (writes
  `jobs_ledger.customer_address_id`). Owner resolution for the release's
  "check from" now runs through `resolveLienProperty`.
- Job selects use `*` on `jobs_ledger`, so the new column flows to the board
  and detail fetches without select changes.

Deferred (noted in the plan): a property picker inside JobFormModal's identity
slice — linking currently happens from the lien surface, where it's needed.
Next: phase 2 (demand letter) builds on this record.
