## The command — [`scripts/pay-person.ts`](../../scripts/pay-person.ts)

```bash
npm run pay:person -- --person "Mike Z" --reason "…" --clear-hours 2026-03-22..2026-05-16 \
  --void-reports 2026-03-22..2026-05-16 --config hourly_wage=null,show_in_hours=false \
  --alias "Michael Zinna"=not_staff [--apply]
```

Dry run prints what it finds — each report with its hours, gross, paid and whether a payment is tied to a send — and what it would do. `--apply` runs hours, reports, config, alias in that order and prints the position after. With only `--person` it reads.
