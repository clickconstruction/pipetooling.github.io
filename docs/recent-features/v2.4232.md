# v2.4232 — Audits: the robots' questions, one at a time — the run-through (2026-09-30)

Punch list #63, PR 3 of 6 (after [v2.4256](v2.4256.md)). No migration, no edge function. The mock-up's draft 2, the questions half: the panel had stacked 16 cards with about 96 buttons before the first audit row; a question is long because it carries the plan context, so a tidier list would be 19 expand-taps — the answer is one question at a time.

## What shipped

- **`rulingRunThrough.ts`** (+8 tests): `buildRunThrough(view, rows, todayYmd)` — the order the owner picked: shared questions first (most-asked first), then today's on the company calendar day, newest first, then the older doctrine asks; each item carries its copies, the bids they were asked on, the label and the taps. `runThroughProgress` (*Question 3 of 19 · 2 answered · ~15 min left*), `sizeTodaySentence` (*Today: 19 questions, about fifteen minutes. Then 31 audits. 8 more open when you send.* — each clause only when it has a number), `questionsHeaderLine` (*12 asked today · 3 asked twice*), `questionLine` (the index's one line), `minutesWords`.
- **`RulingRunThroughSheet`** (+1 render test): a full-screen sheet; the question is the whole screen with its topic chip and *asked on 2 bids · b496 → ours b490 · b495 → ours b489*; numbered big buttons with the ★ first (*· the robot's pick*), *Something else…* as the last number opening the box; the keys — 1–4 pick, Enter takes the ★, → skips, Esc closes, never while typing; *Skip →*, *Not mine* (when the audience column exists) and *Dismiss* in the corner; the end screen lists what was saved and how many were skipped, with *Back to the queue*. The sheet keeps the list it opened with, so a reload mid-run never reshuffles it; it advances only when the write lands.
- **The panel** (`BidsAuditsTab`): above it the sentence that sizes today (questions · workable audits · sealed) and **Answer the N questions**; the header reads **Questions · N** (*standing rulings* stays in the tooltip and the guide — the owner's pick) with the counts line; the body is one line per question — the topic chip, the text cut to a line, *· N bids*, the ★ pick or *no pick* — showing four with **Show all N**; a line opens the sheet at that question. The plans-asks, pre-rule and operator lines are unchanged. The cards, their buttons and the per-card boxes are gone (`rulingDrafts` / `rulingFreeText` with them); the three writes (`answerRuling`, `bounceToOperator`, `dismissRulingQuestions`) are the sheet's callbacks.
- Guide *audit a robot bid* → the first section; GLOSSARY; the to-do's status.
