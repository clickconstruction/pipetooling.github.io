# v2.5336 — Pipeline: the job activity window loses the band of space under the address (2026-10-12)

The owner's screenshot of the job activity window (`JobsStagesActivityExpandModal`) on the Pipeline tab showed a rule under the address, a band of empty space, and the Sessions / esc to close / ✕ group floating in the middle of it.

- **Cause**: the job header block the window borrows from the thread view, `renderStagesThreadFullscreenJobHeader` in `jobsStagesRowShared.tsx`, drew a divider of its own (0.5rem padding, a bottom border, 0.5rem margin). Every host sets it inside a header row that already draws the rule — the activity window and the thread panel's fullscreen mode with a bottom border of their own, the job calendar window with none — so the window got two rules, about a rem of dead space, and a tall header whose right-hand group was centred in the band. The inner rule spanned only the left column, which is the short line in the screenshot.
- **Fix**: the shared block has no divider; each host owns its rule. `JobCalendarModal`'s header row gains the padding, margin and border the block used to carry, so it looks as it did.
- No kernel, no test change: the three hosts' render smokes (`JobsStagesActivityExpandModal`, `JobsStagesThreadPanel`, `jobsStagesRowShared.gcDoor`) pass unchanged.
