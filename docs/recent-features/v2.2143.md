# v2.2143 — Checklist note composer wraps on phones (2026-08-22)

Owner screenshot from Review → Outstanding by person on an iPhone: the Add-a-note box
was squeezed to ~88px ("Gcg" filled it) because the shared composer in
[`ChecklistItemActivity.tsx`](../../src/components/checklist/ChecklistItemActivity.tsx)
was one non-wrapping flex row — input + **Post** + **✓ Post & complete** — and the two
buttons don't shrink. Mockup (before/after, phone + desktop):
claude.ai/code/artifact/bf31ca68-0bdc-4dc4-94b4-b2fa45160329.

- **Wrapping row, no breakpoint**: the container is `flex-wrap: wrap`; the note box is
  `flex: 999 1 240px` (keeps ≥240px, takes all slack), the button group is
  `flex: 1 0 auto`. Wide enough → one line exactly as before; too narrow (phones, narrow
  desktop panels) → the group drops under the note and fills the row, each button
  `flex: 1 1 auto` so both are thumb-sized targets.
- **Auto-growing textarea** replaces the single-line input: `rows=1`, `minHeight 44`,
  grows with the text to `DRAFT_MAX_HEIGHT` (160px ≈ 5 lines) then scrolls; a
  `useEffect` on `draft` re-measures (and snaps back after a post clears it).
  Enter posts (unchanged), **Shift+Enter** inserts a newline; `enterKeyHint="send"`
  so iOS shows a Send key.
- Labels, colors, ordering, empty-draft **✓ Complete**, and the `footerActions`
  (Edit · Forward) slot are unchanged. One fix covers every host: Review → Outstanding
  by person, Today cards + Outstanding list, Manage cards, Vehicles tasks.

Help guide `see-a-tasks-full-history-and-notes.md` notes the wrap + Shift+Enter.
Client-only — no migration.
