# v2.4982 — Lien desk: a printed run is one row on Do now (2026-10-08)

Client only; no migration, no edge function. PR 2 of 3 for punch list #101 ([`to-dos/lien-printed-run/`](../../to-dos/lien-printed-run/README.md)), stacked on PR 1 (v2.4983, #5044).

## Why

On 2026-10-08 Do now listed 19 rows reading *In the mail · tracking owed*, each with **Add tracking**, all opening the same run window, and the rail's *Send the run* read 0 while they waited. The three approvals that needed the leader sat between them.

## What changed

- **Kernel** [`lienNextUp.ts`](../../src/lib/jobs/lienNextUp.ts): two or more printed notices fold into one row, `run:printed` — action `record_mailing` (*Record the mailing*), the target `{ open: 'run', gcId: null }`, a new optional `secondary` (*Take back…*, `takeBack: true`) and `jobs` (each job with its day, deadline order). It sits in the group of its earliest day and takes the worst severity. The title reads *19 notices printed Oct 7* (`lienPrintedDaysWords`: one day, a span, or none). One printed notice keeps its own *Add tracking* row. The run target's `gcId` is now nullable.
- **Steps** [`lienNextUpSteps.ts`](../../src/lib/jobs/lienNextUpSteps.ts): `record_mailing` stands on step 4; its card's fourth rung reads *Record the mailing — Printed Oct 7. Mailed? …*. `lienRunRungWords` writes the rung's tail: *ready*, *printed*, or *· 19 printed*.
- **View** [`LienDeskNextUp`](../../src/components/jobs/LienDeskNextUp.tsx): a run row wears a *Run* tag, draws its second button beside the first (stacked full width on a phone), and folds its jobs under **▸ The N jobs** (`data-lien-next-up-fold`), each a door to its job; `foldsOpen` opens every fold. New props `printed` and `foldsOpen`; the rail (`LienStepRail` in [`LienDeskSteps.tsx`](../../src/components/jobs/LienDeskSteps.tsx)) takes `printed`.
- **Desk** [`LienDeskModal`](../../src/components/jobs/LienDeskModal.tsx): the rail's fourth rung counts `ready + printed`; the find matches a run row by any job inside it and opens the folds; a target with `takeBack` opens the run with `openOnTakeBack` (new on [`LienDeskRunModal`](../../src/components/jobs/LienDeskRunModal.tsx)), so the confirm lives in one place. Do now's count drops with the fold (22 → 4 on the day).
- Guide [`send-lien-notices-from-the-lien-desk`](../../src/content/help/send-lien-notices-from-the-lien-desk.md): the run row and the rail's count.

## Not done

- The row says notices, not envelopes: counting envelopes needs the run built on every render of Do now, which the desk only does with the run open.
