# v2.3619 — A new app mark: the gear and wrench, now a C (2026-09-19)

Owner-directed, after the CountTooling and Takeoff Tooling marks were redrawn the same week. Client only; no migration.

## The change

- **The mark** — [`public/favicon.svg`](../../public/favicon.svg): the existing gear path, filled solid (a disc closes the centre hole), with the existing wrench path moved so its ring centre sits on the gear centre, rotated 45° and scaled 0.75, so the open jaw faces right and reads as a C. Dark `#161617` on the family yellow `#e8c547`, on the 512-box rounded tile (`rx` 112) the other two apps use. The gear stays: the owner judged every redraw weaker than it.
- **The iOS icon** — [`public/apple-touch-icon.png`](../../public/apple-touch-icon.png): the same art rendered full-bleed at 180 (iOS rounds it). Same filename, so the share-card shell (`helpShareCard.ts`), the web-push icon (`sw.ts`) and the manifest icon in `vite.config.ts` re-point on their own.
- **Not changed** — `public/og-card.png` (the share card) still carries the old orange mark and the orange wordmark; it is a piece of its own and a colour decision for another day. The app's orange theme colour is untouched.
- **Docs** — the `public/` tree in [`PROJECT_DOCUMENTATION.md`](../PROJECT_DOCUMENTATION.md) names both files.
