# v2.2695 — Job Summary refresh PR 2: the Days view (2026-09-03)

Second half of the approved Job Summary refresh (PR 1 = v2.2692). The owner's "how many simultaneous jobs on a day-by-day basis" ask, built inside Job Summary (owner lean: not a tenth Jobs tab) on the SAME job day ledger true profit charges from, so the per job-day overhead here is exactly the unit the Jobs view's day-share spends.

## Client only — no migration

- **Kernel** [`lib/jobs/jobDaysConcurrency.ts`](../../src/lib/jobs/jobDaysConcurrency.ts) (+7 tests): `buildJobDaysRows(ledger)` → one row per calendar day (distinct jobs, distinct people, field hours, pool $, per job-day = pool ÷ jobs or null, job slices most-hours-first with people); `summarizeJobDays` → calendar days, workdays (days with field hours), job-days, avg/median/max jobs per workday, overhead per job-day (pool on workdays ÷ job-days), unallocated pool on quiet days, histogram of workdays by jobs carried, field hours, people-days; `buildJobDaysChartSeries` → the top-N jobs by hours keep a color, the rest stack as "other"; `orderJobDaysRows` newest-first with quiet days optional.
- **View prefs**: `JobSummaryViewPrefs.view` ∈ `jobs | days` (default jobs; same localStorage key), `JOB_SUMMARY_VIEW_MODE_OPTIONS`.
- **Component** [`components/jobs/JobSummaryDaysView.tsx`](../../src/components/jobs/JobSummaryDaysView.tsx): tiles (workdays / jobs per workday / overhead per job-day / field hours + people-days / histogram), an SVG stacked-bars chart (bar = day's field hours by job; jobs-count labels under bars on windows ≤ 60 days; date ticks thin out on long windows; per-segment `<title>` tooltips), a "show days with nothing on them" toggle, and the day table (Day · Jobs · People · Field h · Pool · Per job-day (unallocated marker) · Worked chips with hours + people count, names on hover). Pool/per job-day columns follow the pay lockdown; counts and hours show for every office role. Job labels come from the ledger's all-jobs list (`effectiveJobLedgerNumber` + name).
- **Toolbar**: a leading **View** segmented control (Jobs | Days); Show / Overhead / the totals strip / hygiene chips are Jobs-only, Worked in is shared.
- **Tab**: renders `JobSummaryDaysView` in place of the ledger table when `view.prefs.view === 'days'`.
