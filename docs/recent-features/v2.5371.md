# v2.5371 — Lien desk: each envelope in the run is a card that shows its own steps (run train, PR 3) (2026-10-12)

Run train, PR 3 (v2.5369 the kernels, v2.5370 the journey). The run window's `<table className="lienRunTable">` becomes `.lienRunCards`, one `.lienRunCard` per envelope (`data-testid="run-envelope-N"` as before), laid out glyph · body · side:

- **The glyph** (`LienRunEnvelopeGlyph.tsx`): open while it waits or has not printed, sealed once printed, postmarked once it carries its number, a tick once a delivery scan comes (none yet). Amber while the card waits, green once sealed; the card's border (`data-tone`) says the same.
- **The body**: *Envelope N · who*, the address line with *Print this envelope ›*, the hold line (`run-held-N`), **the envelope's own steps** (`.lienRunSteps` from `runEnvelopeStage().stages`: Built, Checked, Signed, Printed, Mailed/Handed over/Emailed, Recorded; the current one blue, or amber with *· waits on Robert*), then the Leader here sign block and the courtesy tick exactly as before, then the copies inside as `.lienRunCopyRow`s (`run-row-<job>-<recipient>`, the combined parts, the months, *Copy for*, Preview ›, Print ›).
- **The side**: the method menu, **one chip** (`runEnvelopeChip`, new in `runEnvelopeStage.ts`: *Waiting on Robert's signature · Held · no mailing address · Prints here · Printed · number owed · Ready to record · 9407… · Emails when the run records · Recorded*), the number box with its shape hint (`run-tracking-shape-N`), and the chip's quiet next line (*Next: print, then type the number from the slip*). A hand delivery counts as mailed once it prints, as `recipientMailed` has said since v2.4119, so it reads *Ready to record* with or without a name.

Every control, aria-label and test id kept its name, so the run's 27 render tests pass unchanged but for the card heading keeping the word *Envelope*. The modal computes one `stageByKey` map per render and the journey reads it, so the journey and the cards cannot disagree. `.lienRunCard*`, `.lienRunStep*`, `.lienRunChip` in `index.css`; on a phone the side column drops under the card and a copy row stacks. The old `.lienRunTable` rules are now unused and come out in Run-4 with the step strip.

Tests: `runJourney.test.ts` gains the chip; the modal's render suite and the journey smoke pass. Looked at on a harness page that mounts the run modal with fixture notices at desktop and phone widths.
