# v2.4364 — GC Review on a phone: each bill is a short card (2026-10-01)

No migration, no edge function. Grace's call on *Decision 3 · GC Review on a phone* (board `DecisionGcPhone.dc.html` on https://claude.ai/artifact/8Tfh1JZydNQmPALe9HwmD8): *"I like your suggestion, please build it."* Found in the live walk behind [v2.4341](v2.4341.md): an opened GC's bills sat in a six-column table (Customer, Job, Billed on, Days, Remaining, Lien waivers) that ran 550 px wide in a 323 px window. The job's name and address broke a word a line, so one bill filled half the screen; *Remaining* was cut off; and the waiver chips, Loberg's amber *send it* among them, showed only after a sideways swipe that also slid the GC's own lines off.

## What changed

- **Cards on a phone** ([`JobsGcReviewModal.tsx`](../../src/components/jobs/JobsGcReviewModal.tsx), `groupDetail`): at ≤ 640 px (`useNarrowViewport640`) an opened GC draws `.gcReviewBills`, one `.gcReviewBill` per row: the job link (`onOpenJob`) beside *$X open*, the address, the when line, then the two waiver chips. Over 640 px the table is unchanged.
- **The card's words** ([`gcReviewBillCard.ts`](../../src/lib/jobs/gcReviewBillCard.ts), new kernel): `gcReviewBillCardWords` → `job` (*650 · ATI Schertz — As per plans*) and `when` (*Billed Jul 15, 2026 · 79 d*). The customer leads the when line only when the job's name does not already hold it (any case) and the job has one (not *—*), since names built from the estimate already read *customer — work*. An estimated date keeps its *(est.)*; a date still ahead drops the age; a row with no date reads *No bill date*. 6 unit tests.
- **One chip helper** (`waiverChipsFor`): the chips' code moved out of the table cell, so the table and the cards draw the same chips, calm as since [v2.4317](v2.4317.md).
- **Thumb-sized on touch** (`index.css`, `pointer: coarse`): the job link and each chip carry an invisible 44 px ring (`::after`), as the money card's tick boxes do since v2.4341, and the card's padding keeps each ring inside its own card, so a tap never lands on the next bill.
- **Guide**: *run your GC statement round* says that on a phone each bill is a short card.
