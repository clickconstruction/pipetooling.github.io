# v2.4751 — Legal portal: Homestead on one line (2026-10-07)

Client only. The owner (2026-10-06), on a screenshot of the live grid after [v2.4749](v2.4749.md): *I would like no homestead to be smaller text so it fits on one line.* The same screenshot showed *No GC · with the owner · 0 jobs · $0* in the rail under Something due.

## What changed

- `LegalPortalLienGrid`: the homestead line under *Residential* is 10.5 px and never wraps.
- `legalLienGridGcs`: the *No GC* entry is listed only when a job with no GC is in view, or when it is the chosen entry — the same rule the GCs already followed. Before, it was listed whenever the whole book held such a job, so under Something due it could read *0 jobs · $0*.

## Tests

`legalLienGridView.test.ts`: the No GC entry absent at 0 unless chosen.
