# v2.2548 — twin-census T1 vector census toolkit (2026-08-31)

Quantity-discipline tooling for the estimator-twin program (Census Toolkit
Plan, tool T1). New `scripts/twin-census/` (python3.11 + pypdf/Pillow,
read-only, no app/db surface):

- `vector_census.py` — content-stream interpreter (CTM tracking) that
  clusters SHX micro-strokes into components and hashes normalized shape
  geometry, so repeated words/symbols/boxes share an id and classify once.
- `contact_sheet.py` — labeled shape grids for one-read visual
  classification.
- `hex_detect.py` — merge-proof hexagon keynote detector (diagonal-edge
  V-corner geometry with direction validation; slope-ratio window rejects
  45° chair/table noise).

Validated on MPH LIVSTE (shadow b419 reference): 106/106 hex keynotes
detected dead-center at 600dpi, zero false positives; keyed-notes legends
decoded every tag into a full quantity census (24 sanitary drops, 27 vent
risers, 22 water drops, med-gas outlet counts, roof gas connections) where
the locked shadow run had typology-flagged estimates — and it surfaced
sheet P401 (roof gas) that the human review subset missed. Census stamped
on b419 for the pending audit comparison.

Key lessons banked in the folder README (title-block image stamps vs
vector drawing content, why exact-hash census can't count callouts, the
stacked tip-to-tip pair trap, average-vector tip classification).
