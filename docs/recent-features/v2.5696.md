PR 5 of punch list #139 (`to-dos/press-always-answers/README.md`), two words-level findings from the live walk the night the train merged (PR 4 v2.5695 is the walk's structural fix). No migration; no edge function change.

- **The lane names the customer** (`src/lib/messages/wentOutIo.ts`, `wentOut.ts`): a customer's own thread keeps its `contacts.name` null by the app's own-contact rule, so v2.5686's lane read every one as *A number nobody has named* — on a live day, both rows (Taunya's estimate texts to Evan and to Heron) did. The read embeds `customer:customers(name)` through `contacts_customer_id_fkey` and the kernel falls back to it (`customerName`), before the unnamed-number words.
- **`{job}` drops a default title's lead-in** (`src/lib/tellCustomer/tellCustomer.ts` `tellFills`): with no job name, the estimate's title fills `{job}`, and the app's default title is *Estimate for Evan Johnson*, so the line read *"Your estimate for Estimate for Evan Johnson is ready"* — the words the customer actually received today. A leading *Estimate for* is stripped from the title before it fills; a job name is untouched.
