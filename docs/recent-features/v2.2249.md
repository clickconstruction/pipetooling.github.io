# v2.2249 — Roadmap tab defaults to the Plan view (2026-08-24)

`ChecklistTechTreeTab` viewMode init: the fallback for a device with no
remembered choice flips from `'map'` to `'plan'` — field crews live in Plan;
Map is the desktop structure-editing surface. An explicit toggle (including
back to Map) still persists per device, and `?view=` deep links still win.

The localStorage key was bumped `roadmap_view_v1` → `roadmap_view_v2`
deliberately: it drops every device's remembered view exactly once so the whole
team lands on Plan after this ships, then choices re-accumulate under the new
key. Old `roadmap_view_v1` entries are ignored and left behind. The default
never writes itself to storage — only explicit toggles count as choices.
