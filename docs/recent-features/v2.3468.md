## What shipped

- **[`SubmittalSheetStrip`](../../src/components/bids/SubmittalSheetStrip.tsx)** (presentational; the tab owns the writes): per vendor file, **Show the pages** draws the thumbnails ([`pdfThumbnails.ts`](../../src/lib/submittals/pdfThumbnails.ts), pdf.js lazy, one JPEG data URL per page). Tap a page, then a row in the chooser (rows owing a sheet first, in amber; *missing* rows never appear) → the page joins that row's sheet; a chip's × takes it off; a page on two rows reads red with a *keep it for* door per row, and **Done** is held until it is settled. The footer reads `describeFooter` (*6 of 31 pages on rows · 25 not used*); **Done with this file** when pages landed, **Remove this file** when none; a trimmed file reads *· trimmed* and the quiet line *24 pages let go · Sep 15 · drop the file again if you need one*.
- **Kernels**: [`sheetAssignment.ts`](../../src/lib/submittals/sheetAssignment.ts) (the parked draft, finished: `assignPage` / `unassignPage` / `pagesForTag` / `conflicts` / `keptPages` / `unusedPages` / `tagsWithoutSheets` / `remapAfterTrim` / `describeFooter`; keyed by item id so two accessories never collide), [`sheetStripModel.ts`](../../src/lib/submittals/sheetStripModel.ts) (rows → assignment triples; a row's chip label), [`trimPdf.ts`](../../src/lib/submittals/trimPdf.ts) (`trimPdf(bytes, keep)` → the trimmed bytes + the old→new map; pdf-lib `copyPages` in the browser). `source_files` entries gain `dropped_pages`.
- **The tab**: `assignPageToItem` (a row's sheet lives in one file — a page from another file starts it over, with a toast), `unassignPageFromItem`, `doneWithFile` (download → `trimPdf` → upsert the same path → `remapAfterTrim` → every row on that file rewritten → the file record's `pages` / `trimmed_at` / `dropped_pages` → thumbnails invalidated), `removeFile` (storage remove; later files shift down one and their rows follow). The strip replaces the v2.3466 *Vendor files* chips; the typed page range in the row editor stays for a keyboard.
- **Guide**: [`build-a-submittal-package.md`](../../src/content/help/build-a-submittal-package.md) → "Attach the sheets" rewritten around the strip, "Done with a file" added.
