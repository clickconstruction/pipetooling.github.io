# v2.7390 — Box labels: the page shows the company's number from Settings (2026-11-15)

Taunya's word of 2026-11-15, after she saw v2.7379 live: the signed-out box page should use the company number, whatever Settings holds, as her picture of the page showed. No migration. One edge function changed: `box-read`, redeployed after the merge. The page itself did not change, since it draws the number the function answers.

## Why

v2.7379 built the page from her picture but kept the number the function had answered since v2.6910, the team box's text line. Her picture showed the company's own number. The page is the company's card to whoever scans a label on a site, so it shows the number the company gives out.

## What changed

- `box-read` reads the Phone of Settings' company block (`app_settings` `physical_invoice_issuer_v1`, the card *Physical invoice — company on PDF* under Settings → Jobs) and answers it as `office.phone`, and as `phone` on a retired box's 410.
- When that Phone is blank the order is what it was: the team box's line from Settings → Phone and texts, the `QUO_COMPANY_PHONE` secret, the letterhead's constant.
- Both settings are read in one request. A read that fails falls back the same way.
- The kernel holds the read as `boxPageCompanyPhone`, with `BOX_PAGE_COMPANY_KEY` pinned to the client's key by a test.

## What to know

**Ask for a bid**, **Text the office** and **Work with us** are text links to the same number the page shows. The company's number today is not one of the app's lines, so those texts do not land on the Messages page. They go wherever that number's texts go. From v2.6910 the texts went to the team line for that reason. Setting the company block's Phone to a line the app reads brings them back into Messages with no deploy.

## The order

The function alone changes what the page shows, so there is no client to wait for. `box-read` is deployed after the merge on Taunya's go and proved with a signed-out request for a ZZ Test box's code.

## Tests

`boxPage.test.ts` reads the Phone out of the company block's stored text, refuses a blank, a number that is not text and text that is not JSON, pins the key to the client's, and reads the function's source for the order it asks in.
