`plans_url` pointing at a Google Drive file (`file/d/<id>`, `open?id=`, `uc?id=`) was
un-fetchable — Drive files are rarely public, and the function fetched `plans_url` with a
plain unauthenticated `fetch` (Google 303s to a sign-in page). Found live filing the real
LIVSTE set (36 MB "MPH LIVSTE San Antonio Full Set.pdf") onto b403.

  one. Non-Drive URLs fetch unauthenticated as before. Failed uploads still degrade
  gracefully (`upload_note`), now with a "is the source shared with the service account?"
  hint on Drive-source 404s.

  silently drops the share if dismissed (observed live).

  without one) including this change; `docs/DRIVE_INTAKE_SETUP.md` → Using it documents
