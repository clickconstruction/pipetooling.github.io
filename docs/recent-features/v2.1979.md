# v2.1979 — Roadmap Timeline view (2026-08-21)

Third roadmap view (Map | Plan | **Timeline**), built to the approved v2
mockup: a Gantt whose x-axis is dependency **sequence** — the roadmap has no
dates, and invented ones rot.

- **Kernels** (`src/lib/roadmapTimeline.ts`, +8 tests): `timelineWaves`
  (topological depth over the prerequisite edges, cycle-guarded),
  `timelineRows` (staircase sort: wave then stage order; per-row progress,
  milestone = task-less, locked, done), `paceProjection` (serial-by-wave:
  remaining ÷ tasks-per-week; pace clamped ≥0.5), `approxDateLabel`
  ("≈ Nov" / "≈ Feb '27").
- **View** (`ChecklistRoadmapTimelineView.tsx`): CSS-only chart — wave
  column widths ∝ remaining work (floored), bar width ∝ stage remaining
  within its wave, green progress fills, dashed locked bars, ◆ milestone
  diamonds (violet token), amber FRONT line at the current wave's done
  fraction. Pace slider (1–20, persisted `roadmap_timeline_pace_v1`,
  default 5) drives ≈date labels per wave + the 🎯 goal chip. Tap a row →
  inline N.M task list → task card. No new deps, no migration.
- **Tab**: `viewMode` widens to `'map' | 'plan' | 'timeline'`
  (`roadmap_view_v1` persists it); Timeline gets the same props family as
  Plan. Mobile: `.roadmap-timeline-rail` collapses 200px → 52px badges
  (title hidden) and the chart scrolls horizontally.
- On the prod Farm roadmap the truth is stark and correctly rendered: all
  88 remaining tasks sit in wave "Now"; every later stage is a task-less
  milestone gate — so wave dates converge on the front's finish.
- Help guide `read-the-roadmap-timeline`. Future (noted in the mockup):
  observed-velocity default for the slider + optional per-stage target
  dates pinning bars to a real calendar axis.
