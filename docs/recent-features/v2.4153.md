## Design calls

- **The consequence is read back before Save**, never after: the owner's own line from the mock-up (*4 d after the lien flag — file first*). It is pure, from the row's lien date, so the popover needs no round trip.
- **One dot per GC group only when the jobs agree.** The to-do's open question (a GC pays several jobs on one check) resolves this way: the group row shows the GC's standing word when there is one; a disagreeing group shows the dashed dot, and saving from it gives every job the same date — the same write the statement round makes.
- **No drag.** The mock-up let a dot be dragged along the axis into the popover; a click does the same in fewer motions and is honest on a phone. Left out, not deferred.
- **Draft the N narrows, it does not select.** The run already takes every approved notice in the pile; the door lands the office on the right jobs and lets the desk's own steps (draft → approve → send) do the rest.
