# v2.7547 — Checklist: go through your old tasks one at a time (2026-11-16)

Punch list #369, step C5 of the Task Mode train (tool 4), stacked on C6 (v2.7546). No migration and no new call: every answer is a tool the earlier steps built.

## Why

Read through the dev seat on 2026-11-16, 12 of the 17 open one-time tasks were more than 80 days old. Steps C3, C4 and C6 gave each task its own way out, but a list of eight still meant opening eight rows and pressing More eight times.

## What changed

- **Go through them**, a quiet press beside *Still open · N*, once the list holds two tasks (`PASS_MIN_TASKS`).
- **One task at a time** (`TaskPassSheet`): *2 of 8*, the task's words, and its quiet line, *given Thu, Aug 20 · 88 days*. Under them its answers (`passAnswers`):
  - **Done** marks it done by the tick's own path.
  - **Still on it** opens Not today.
  - **Can't do it** and **No longer applies** open their own sheets.
  - **Skip** leaves the task as it is.
- **A task is offered only what it allows.** The answers come from More's own rule, so a roadmap task has no close and a repeating task has no day to move.
- **A tool's sheet closed with nothing done brings the same question back.** An answer that lands moves the pass on and counts.
- **It ends by saying what it came to** (`passSummary`): *You sorted 3. 5 are as they were.*, with **Back to my list**. Stopping early, with ×, keeps what was already answered.

## Do what is ready

The pass is the repo's batch rule drawn as questions. It acts on what is answered, leaves the rest alone, keeps going past an answer that fails and says so on the task in hand: *The task did not mark done. Try it from the list.*

## A re-read that does not blank the page

The tools read the day again after each act. That read went through `loadDay`, which shows the tab's *Loading…* line and takes every sheet off the screen for as long as the read lasts. In a pass that would blank the question after each answer. `rereadDay` reads the same lists without the loading line, and the tools and the New task window's save use it. It also ends the flash after **＋ Add a task for me** and **Follow-up** of v2.7537.

## How it is built

- `useTaskDoerActs` holds the pass: its own list taken when it starts, so a re-read under it cannot reorder what is being asked, an index and a count. `markDone` is handed in by the page.
- `stillOpenMeta` in `todayPage.ts`, a row's age as one line.
- `ChecklistOutstandingSection` takes `onGoThrough`.
