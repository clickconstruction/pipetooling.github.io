## What changed

- [`submittalJourney.ts`](../../src/lib/submittals/submittalJourney.ts): pill 2's label is `Rev N` once a revision exists. An older revision on screen reads its real state: shared, answered without a share, or replaced before it was shared; `share` is done only for a shared or reviewed revision, `review` is done when it holds answers.
- [`submittalTour.ts`](../../src/lib/submittals/submittalTour.ts): `stageAbout(stage, rev)` for the two sentences that name a number. `SUBMITTAL_STAGE_ABOUT` is still what a bid with no revision, or Rev 1, reads, and what the plain-words test holds; the new sentences are held to the same rules.
- [`submittalRevision.ts`](../../src/lib/submittals/submittalRevision.ts): `describeRevisionChip(rev, answeredAt?)` and `revisionAnsweredAt(rows, parts)`. Only a superseded revision changes its words; *superseded* stays for a draft replaced with nothing on it.
- [`submittalRoom.ts`](../../src/lib/submittals/submittalRoom.ts): `describeRoomLine` says *Not shared from the app* for a room with no share stamp and no opens (typing an answer makes the room so the answer has somewhere to live). `summarizeThread` reads the lines `enteredEntryBody` writes as the office's, or the robot's.
- [`BidsSubmittalsTab`](../../src/components/bids/BidsSubmittalsTab.tsx): the effect that reads the earlier revisions for the standing rows also keeps `answeredByRev`; the selected revision reads its own rows.
