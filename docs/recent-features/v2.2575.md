# v2.2575 — Supply house edit modal scrolls on short viewports (2026-09-01)

Live report (Taunya, assistant): "I need to be able to save info added into supply
houses. I can't scroll down to show the save button." The Add/Edit Supply House
modal (`SupplyHouseForm`, `variant='modal'`) centered a fixed-height dialog with no
`maxHeight`/`overflow`, so on a viewport shorter than the form (~866px with all
fields) the dialog overflowed both edges and neither the dialog nor the overlay
scrolled — Update/Cancel were unreachable.

Fix: the dialog wrapper gains `maxHeight: 'min(90vh, 100%)', overflow: 'auto'`,
matching the `PartFormModal` idiom in the same Materials area. Verified live at a
620px-tall viewport: dialog caps inside the viewport, scrolls internally, Update
lands in view.

One file, no schema/RPC changes: `src/components/SupplyHouseForm.tsx`.
