# v2.2567 — Stripe tag on the invoice-resend chip + confirm upgrade (2026-09-01)

Owner-approved mockup variants B + D (https://claude.ai/code/artifact/f9ed6e31-4640-4405-9911-1a0d6e809038).
The yellow Stripe-resend button never said who sends the email; in the Payment
follow-up modal "Never got it? Resend" could read as ClickTooling re-emailing
the bill.

- **`StripeInvoiceSendFromStripeButton`** is now a two-segment chip: an indigo

  dims the tag via opacity alongside the muted-yellow action segment.

  "Send Email invoice" — the tag now carries the "from Stripe" part. Call-site
  labels ("Resend", "Never got it? Resend") unchanged.
- Help guides updated: `chase-late-payments.md` explains the tag;
  `split-a-bill-…-multiple-cards.md` shows the new two-token button.
- **Confirm dialog upgrade (variant D)**: retitled "Have Stripe email this
  invoice?"; the buried "ClickTooling will not send the email" sentence promoted
  to a badged indigo "Sent by Stripe to {email}" row (`--bg-indigo-100` family,
  dark-safe); new reassurance line "it's the invoice email with the payment
  link — sending it again doesn't create a new bill or charge anything."
