# v2.6874 — The box label page says what ran out, and texts the office (punch list #294, PR 2) (2026-11-10)

The second half of direction B, the owner's pick on `to-dos/prts-box-page/landing-before-after.html`. v2.6868 redrew the signed-out box page from what `box-read` already answered. This one passes on what the function already held and dropped, and adds the office's number.

## What changed

- **`supabase/functions/_shared/boxPage.ts`** (the kernel the function and the client share, `src/lib/materials/boxPage.test.ts`):
  - `BoxPageLine.cannotFind`: the summary's `cannot_find_since_count`, carried only when it is above zero, so every older answer and test keeps its shape.
  - `boxPageGoneLines(lines, containerId, lastCountAt, now)`: the lines at zero a person would still look for. A line emptied by a press after the box's last count, or holding a Can't find since its own count. A line counted to zero drops out, as on the crew's screen (`linesOf`), and the next count of the box clears the rest, so an old cage grows no tail. A box never counted keeps a line `BOX_PAGE_GONE_DAYS` (14) after it emptied.
  - `BoxPagePayload.box.gone` and `BoxPagePayload.office` (`{ phone } | null`). `parseBoxPageResponse` reads an answer without them as none, so the new page draws against the old function.
- **`box-read`**: hands the kernel the instant of the box's last count and now, and `PORTAL_COMPANY.phone`, the letterhead's number `pay-link` already answers. The 410 for a retired box adds `stencil`, `kind` and `phone`. No new query: the summary it calls already answers every line at zero with its `last_touched_at` and `cannot_find_since_count`. Its `*_by` names are still never read.
- **`src/lib/materials/boxPage.ts`**: `boxPageCannotFindWords`; `boxPageDialNumber` (`+15125550142` from a ten or eleven digit number, null otherwise); `boxPageTextWords` (*Cage B3, 4F2A-9C18: *); `boxPageTextHref` (`sms:<number>?&body=<words>`) and `boxPageCallHref`. The retired view carries `stencil`, `boxKind` and `phone`.
- **`BoxPublicPage.tsx`**: the lines at zero list after what is on hand, on the note band, reading **None left**; a line's Can't find reads in amber under its maker; the part count stays what is on hand; a box with only lines at zero lists them in place of the empty words. **Something missing or wrong?** holds **Text the office about Cage B3**, a link, with *Or call* and the number; it draws only when the function answers a number a phone can dial. A retired label reads *Cage B3 was retired* and offers the same text.
- Guide (Scan a label), `docs/EDGE_FUNCTIONS.md` (box-read's response and 410), `docs/ACCESS_CONTROL.md` (what the signed-out page answers), `docs/MATERIALS_ON_SITE_ARCHITECTURE.md`, the card.
