# v2.8479 — Maps: the no map location line opens the list, with the reason and Try again (2026-11-24)

Punch list #408, step 3 of the train of three in [`to-dos/remember-unplaced-addresses.md`](../../to-dos/remember-unplaced-addresses.md). Step 2 (v2.8477) made the app remember an address no service could place. This is what a person reads about it, and the press that asks again.

## What changed

- **The count line is a press.** On the Dashboard and Pipeline map cards, *N jobs have no map location yet* is a link to `/map?unplaced=1` for a viewer who may open the Map page. Everyone else reads the plain words, since the Map page would bounce them. One component draws it, `UnplacedDoorLine`.
- **The Map page opens its list from that address.** `?unplaced=1` opens the address sheet and is taken off the address at once, so a reload or Back does not open it again.
- **The list says why and when.** Each row under *Could not be found* reads the reason, then *Checked Nov 20. The app asks again by itself on Dec 20.* Each day is drawn as a value. The days are in the app's zone. The second is the first plus `GEOCODE_MISS_STANDS_DAYS`.
- **Try again.** One call to `geocode-address-batch` for the one address with `retry: true`, so the function asks past its memory.
  - Placed: the row says so and the map reloads.
  - Still no match: the row says so and its day moves to the day the function answered with, `checked_at`. The function sends that day only when it kept the miss again (v2.8484).
  - Nothing was kept: the row says *Not placed*, that the app asks again on the next open, and the reason. That is Google or the Census not answering, or a training account's skipped write.
  - The ask itself failed: the row says the function's own reason.
  - While it asks, the press reads *Asking the map services…* and is dead.
- **Nothing left to fix** reads *Nothing waiting on an address.*, the good state, through `EmptyState`.
- **The record's name on the row opens the record**, as it did. That is the card's *Open the job*.

## Kernels

- `src/lib/map/unplacedMemory.ts`: the door's path, the day words, the checked sentence, `tryAgainOutcome` and `tryAgainWords`. Pure, with its test.
- `src/lib/map/unplacedTryAgainIo.ts`: the one call. It never throws.
