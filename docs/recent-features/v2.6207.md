# v2.6207 — A memo line on every plan set, in Edit Bid, on the Development page and from a robot (2026-10-30)

Feature, no migration; one edge function to deploy (`twin-mcp`). The owner on the Gun Dog page: *in the plan section I would like to be able to add a memo line … in the edit bid modal I would also like to be able to add a memo line … something that an agent could use to record what they think has changed on the plans* (punch list #208).

## What was already there

`bid_plan_sets.memo` (v2.6168) and the memo field on a **new** set in Edit Bid. A saved set's memo read but could not be changed, and the Development page's Plans look, which groups sets by link from `bids.plans_link` and `jobs.job_plans_link`, never read the rows at all.

## Change

- `src/lib/developments/plans.ts`: `PlanSet` gains `memo` and `memoRow`; `buildPlansView` takes `planSetRows` and puts the newest-touched row's memo on the set whose link it carries (`samePlanLink`, so a `?usp=` tail or a trailing slash still matches). `planSetMemoWrite(set)` says where a typed memo lands: the row, or a new row named *Plans* on the set's first bid; null for a set that hangs on jobs alone.
- `DevelopmentPage.tsx` reads the shown bids' set rows with `useBidPlanSetsByBid` and gives the Plans card a writer (estimator and up, the table's RLS); `DevelopmentSideCards.tsx` adds a Memo column with `PlanSetMemo`: words in place, a press opens a one-line box, Enter or Save keeps it, Escape or Cancel leaves it.
- `BidPlanSetsField.tsx`: a saved row's memo is a press that opens the line; Enter or blur keeps it; *Add a memo* when empty.
- `twin-mcp` 1.10.0: `put_plan_memo(bid, memo, set?)` writes the memo on the set the robot reads (the row whose link is `bids.plans_link`) or the set named; a bid with a plans link and no row gets one. Same bid fence as `add_bid_note`. `docs/EDGE_FUNCTIONS.md` has the line.
- Guides *keep more than one set of plans on a bid* and *see everything on a development* name the press.

Deploy after the merge: `supabase functions deploy twin-mcp`.
