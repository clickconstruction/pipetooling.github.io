# v2.2526 — "PipeTooling" text sweep: in-app copy renamed ClickTooling (2026-08-31)

Follow-up to v2.2525 (app identity: title/manifest/og/push) and the
DOMAIN_CUTOVER.md "text sweep". Renames the remaining user-visible
"PipeTooling" strings in `src/` — UI copy, comments beside them, one render
test — plus the two edge functions whose email fallbacks must mirror client
defaults.

## Renamed to ClickTooling

- **Email template defaults** — `src/lib/settingsTemplates.ts` invitation /
  sign_in / login_as subjects+bodies, and the matching hard fallbacks in
  `supabase/functions/invite-user` and `supabase/functions/send-sign-in-email`
  (kept in sync by hand; **both functions need `supabase functions deploy`**).
  Settings → Templates placeholders too.
- **Invoice PDF surfaces** — the small gray "PipeTooling" page-bottom credit in
  `src/lib/physicalInvoicePdf.ts` (both layouts), and the shipped **Standard**
  footer preset first line → `ClickTooling — Click Plumbing and Electrical`
  (`src/lib/physicalInvoiceFooter.ts`; orgs with a saved override are
  unaffected — overrides only persist when they differ from the shipped body).
- **Stripe billing panels** — HostedStripeBillPanel ("Saved in / record /
  Applied in"), StripeInvoiceSendFromStripeButton, UnwindStripeOobPaymentModal,
  AgreedWriteDownModal, BilledReportShareModal, BankingStripeInvoicesPanel,
  DocumentsJobBilledInvoiceModal ("Invoice PDF (ClickTooling layout)"). These
  name the **app**, not the Stripe business identity — the name customers see
  on Stripe invoices/statements comes from the Stripe account profile, not
  these strings.
- **Bids** — "Open bid (ClickTooling) ↗" cross-app link label (+ its render
  test), BidsBuilderReviewTab "— ClickTooling Followup" generated line,
  PackageAndSendBidPricingModal send copy.
- **Pages & misc** — AcceptInvite "Welcome to ClickTooling", ContractAccept
  "Return to ClickTooling", PeopleContractsTab delete note, SupplyHouseShareModal,
  SettingsMyEmailScheduleSection, DigitalTwinsPanel.
- **Help guides** (11 files) — including the guide title
  `understand how ClickTooling works` and its cross-reference in
  settings-basics. Slugs/filenames unchanged.
- **Estimates sender label** — `ESTIMATE_EMAIL_FROM_LABEL` domain fixed to
  `team@noreply.clicktooling.com` (was still pipetooling.com).

## Deliberately kept as "PipeTooling"

- `src/sw.ts` push fallback title — already renamed by v2.2525 (PR #2258, in
  flight when this sweep was cut); left untouched to avoid a conflict.
- `ESTIMATE_EMAIL_FROM_LABEL` **display name** — mirrors the live `EMAIL_FROM`
  secret, whose display name is still "PipeTooling". Flip both together
  (comment at the constant says so).
- Release-note history (`src/content/releaseNotes/`, archive) and test
  fixtures quoting historical copy — frozen records.
- Functional identifiers: `pipetooling-*` localStorage keys, package name,
  repo/code identifiers, pipetooling.com URLs (permanent redirect domain).
