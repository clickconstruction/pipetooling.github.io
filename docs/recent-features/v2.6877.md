# v2.6877 — Permits: the map on a skim card is a Google map (punch list #302) (2026-11-10)

The owner, on the card's right-hand picture: *I would like this picture to be google maps instead of open street map.*

## What changed

- **`PermitSkimGoogleStill`** (new, lazy-loaded): a small live Google map held still through `@vis.gl/react-google-maps`, the library the Map lens uses: no controls, no gestures, no clicks, the permit at its centre. It takes no pointer, so the tile around it stays the link to Google Maps. One map serves the sitting; the next card moves its centre. A script that does not arrive in eight seconds, a rejected key (`gm_authFailure`) or an exception calls `onUnavailable`.
- **`PermitSkimLook`** picks the provider with `resolveDashboardMapProvider`, the Dashboard map's rule: Google when the app has a browser key and Google has not failed this sitting, else the OpenStreetMap tiles it drew before. Over a Google map the miles tag sits at the top, clear of Google's mark and terms.

## Why a live map and not a still

Google's still-image map was tried first and refused: the app's browser key is not allowed to call it (HTTP 403, *not authorized to use this service or API*). The key is allowed to draw live maps, which the Map lens already does.

## Walked

1360 and 375 wide on localhost: the tile is Google's, the mark sits bottom left and the terms bottom right, the miles tag top right, the pin in the middle. The render tests run with no key and draw the tiles as before.
