# v2.3155 — Shadow-coverage handoff prompt on Settings → Digital twins (2026-09-08)

Client only. No migration or edge-function change.

## Why

Shadow coverage today runs from the owner's machine (an hourly Claude Code routine on her key). She wants to be able to hand that seat to another person without a walkthrough: something copyable from the app that gets a new operator from zero to "the robots run on my machine" with nothing else.

## What shipped

- **`docs/twins/kickoffs/shadow-operator.md`** — the handoff, one file, the source of truth: what the role is (keep the robots running; never estimate, never see a number), one-time machine setup (clone, `npm install`, issue *their own* key on the Digital twins card labelled with their name, save it to `~/pt-twin-digest/twin.token`, the single allow rule `Bash(python3 scripts/twin/*)`, a door check with `scripts/twin/twin.py get_shadow_queue`), how to create the hourly routine (cron `15 7-18 * * 1-5`, click Run now once), the **routine prompt verbatim** (the same text the owner's routine runs: queue read → up to two Fable subagents at a time running the `/bid` skill with `Argument: /bid next` → report), what they will see and what to do about each case (coverage full, a sealed number, `unreadable` bids, a blocked agent, `/bid bNNN` for one bid now), and the owner's hard rules.
- **Card "↗ Hand shadow coverage to someone"** in `DigitalTwinsPanel` (dev only, between Connect a harness and Twin questions): a **Copy handoff prompt** button that copies the whole file, a two-line explanation (keys are per person and revoked on the same page — handing over never means sharing a key), and a collapsed preview. The markdown is imported with Vite's `?raw` from `docs/`, so editing the file is editing the card.

## Notes

The prompt pins every subagent to Fable, tells the operator never to print the key, and keeps the operator on the ZZ shells only. It assumes Claude Code on the operator's machine with the repo checked out; the twin-mcp door itself works from any MCP client (TWIN_HARNESS.md), but the routine and the `/bid` skill are Claude Code features.
