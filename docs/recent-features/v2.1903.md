# v2.1903 — Partnerships: the Timeline tab — money + infractions in one stream (2026-08-20)

Owner-approved mockup (prototype rev "timeline-mockup"): infractions shouldn't live on their own tab — they should read inline with the money. New **Timeline** tab on `/partnerships` (sits BESIDE the Ledger tab, which stays the strict money journal): one newest-first stream merging the partner's money journal (labor weeks, payouts, profit shares, attached charges — with running balances) with the accountability trails — **NCNS incidents** (from Write-ups' `attendance_incidents`), **work-order declines** with reasons (from `step_commitments`), **job check-offs** (`partner_confirmed_at`), **statement generations** with acknowledgment state, and **pending charges** (signed amount, no balance impact until attached). Filter chips: All · Money · Infractions · Jobs & statements. A **quick-add charge** row (backcharge / damage / utility overage + amount + date + note) writes ordinary `person_offsets` rows — so entries appear in People → Offsets identically and attach to the next generated statement like any other pending offset (owner requirement). Per-kind circular markers ($ % ! → ⚠ ✕ ✓ §) with semantic colors. Kernel [`partnerTimeline.ts`](../../src/lib/partnerLedger/partnerTimeline.ts) (merge/sort with money-first same-date convention, filters, charge labels; 9 tests). **Dev-only lens**: the partner's own dashboard never renders NCNS or declines — charges reach them only as statement deductions. Component [`PartnershipTimelineTab.tsx`](../../src/components/partnerships/PartnershipTimelineTab.tsx). Client-only — no migration.
