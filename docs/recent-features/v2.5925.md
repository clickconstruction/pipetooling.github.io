# v2.5925 — Print a lien waiver for a notary (2026-10-26)

The owner's ask on the Sign by his code canvas (claude.ai/artifact/USoqD1sAgUyVszvqouk662,
boards 4–5): a GC or title company sometimes wants a *notarized* waiver, so step 5 needs a
print-for-a-notary way whose signed, stamped copy comes back as a Google Drive link. Stacked on
v2.5924 (#6248); PR #6251.

## What changed

- **Migration `20261026203000_lien_release_notary.sql`**: two additive columns on
  `job_lien_releases` — `notary_printed_at`, `notary_copy_url`. No status CHECK exists, so the
  held state is kernel-named. **Push after merge.**
- **Kernel** ([`lienReleaseLifecycle.ts`](../../src/lib/jobs/lienReleaseLifecycle.ts)): status
  `out_for_notary` (not editable, amber chip *out for notary*; `lienReleaseSteps` folds 1–4 and
  keeps step 5 in hand, like a signature request) and signature mode `notary_paper` — the audit
  sentence reads *Signed in ink by Malachi Whites before a Notary Public of the State of Texas;
  the signed copy was filed in ClickTooling on …* and every rendering draws **no ink**: the scan
  is the signature ([`lienWaiverRelease.ts`](../../src/lib/jobsDocuments/lienWaiverRelease.ts)
  foot HTML + PDF foot).
- **The jurat** (`buildLienWaiverNotaryBlockHtml` + the PDF's `notary` block, behind the new
  `LienWaiverRenderOpts`): the venue block, *SUBSCRIBED AND SWORN TO BEFORE ME … by <signer>*,
  the notary's rule and commission line, and open space marked *(seal)* — deliberately never a
  drawn stamp box, which real notaries work around.
- **[`LienReleaseModal`](../../src/components/jobs/LienReleaseModal.tsx):** step 5's ways gain
  **🖨 Print for a notary** (mints `issued` first, so the date hold still bites — the dateHold
  matrix now runs six buttons); the print files a sent copy titled *for a notary*; the row then
  holds at `out_for_notary` with the amber panel: printed when, *Print it again*, *He signs it
  here instead* (back to `issued`), and the **When it comes back** link box — saving a https
  link stamps the row `signed` in mode `notary_paper` with the signer of record. Step 6's
  Attached line gains *Open the signed copy ↗*.
- **[`sendLienReleaseEmail.ts`](../../src/lib/sendLienReleaseEmail.ts):** the email's records
  line becomes *This release was signed in ink before a notary. The signed, notarized copy is
  here: <link>*, and the regenerated PDF carries the jurat with no pretend ink.
- **Guide** *send a GC our lien waiver* gains **Print it for a notary**, with the Texas-2022
  line so nobody prints one unasked.
