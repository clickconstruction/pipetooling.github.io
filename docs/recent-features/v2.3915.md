## Found while pinning

A linked copy gives a solo source block its group **before** it checks the overlap, so a copy refused for overlap leaves the source in a group of one. Nothing on the screen shows it — the card's linked float and accent both need more than one member. It is pinned as it is and recorded as quirk #21 on the map; putting the overlap check first is a behavior change and would be its own PR.
