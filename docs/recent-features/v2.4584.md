# v2.4584 — Demand letter: Print, Download and Email show what they are doing (2026-10-05)

Client only; no migration, no edge function. The owner, on the Lien window's demand letter: *"when a user clicks Download PDF · 6 documents it quickly flips. I would like it to feel more reactive where it shows a color for a few seconds with the button (staying the same size) says 'downloading...'"*

The packet builds in a fraction of a second, so the old *Building…* label was on screen too briefly to read and the button shrank while it showed.

Then, shown it working: *"give Print packet and Email the same treatment."*

- [`downloadFeedback.ts`](../../src/lib/jobs/downloadFeedback.ts): `DOWNLOADING_MIN_MS` (1,500), `DOWNLOADED_HOLD_MS` (2,000) and `remainingHoldMs(startedAt, now)`, what is left of the minimum once the work is done.
- [`useActionPhase`](../../src/hooks/useActionPhase.ts): `run(work)` holds `busy` for the minimum from the press, then `done`, then `idle`; work that returns false or throws goes straight back to `idle`. `flashDone()` is for work whose busy state is drawn elsewhere. Timers are cleared on unmount.
- [`ActionPhaseButton`](../../src/components/ActionPhaseButton.tsx): solid blue with a spinner while busy, solid green with a tick when done, `data-action` and `data-action-phase` on the button. The resting words stay in the layout, hidden, under the state's words, so the size never changes.
- [`LienInstrumentsModal.tsx`](../../src/components/jobs/LienInstrumentsModal.tsx), the demand letter's footer:
  - **Download PDF**: *Downloading…*, then *Downloaded*. The file is handed to the browser as soon as it is built; only the label holds.
  - **Print packet**: *Opening…*, then *Opened*. A blocked popup goes straight back to resting, with the toast as before.
  - **Email with the PDF…** opens the sheet as before. The sheet's **Send** shows a spinner and *Sending…* at its own width for as long as the send takes, with no added hold: the send is recorded the moment it returns, never after a wait. The sheet then closes and the footer's Email button shows *Emailed* for two seconds.
- Read in the browser on job 878: Print stayed 111.5 px and Download 224.7 px wide through idle, busy, done and idle.

Tests: `downloadFeedback.test.ts` (2), `useActionPhase.render.test.tsx` (3), three cases in `LienInstrumentsModal.render.test.tsx`.
