# v2.2354 — Workbench previews persist per price option (2026-08-26)

Estimator feedback (Wendi): unclear when to Apply/Discard, what "preview"
means, and whether navigating away is safe. It wasn't — `wbPreview` lived in
component state, so switching to any other tab unmounted `BidsPricingTab` and
silently destroyed previewed prices (both solver output AND hand-typed sale
prices — typing in the Workbench never saved directly).

- New kernel `src/lib/bids/workbenchPreviewStash.ts` (+ tests): sessionStorage
  stash keyed `bids_wb_preview_v1:<pricingVersionId>` — validating reader
  (drops non-finite entries, null on corrupt/empty), swallowing writer.
- `BidsPricingTab`: `setAndStashWbPreview(versionId, preview)` write-through at
  every preview mutation (solver solve, row typing, Apply, Discard); a restore
  effect keyed on `selectedPricingVersionId` swaps in each price option's own
  stash on first load, tab return, reload, and scenario switch. The old
  `setWbPreview(null)` discards in `viewWorkbenchScenario` /
  `handlePricingVersionChange` are gone — the per-version keying is what keeps
  a stale preview from Applying onto another scenario (the original reason for
  discarding).
- `applyWorkbenchPreview` now skips preview entries whose count row no longer
  exists (a stashed preview can outlive a row deleted in Counts).
- Strip copy: Apply button counts ("Apply 12"); the caption replaces
  "nothing saved yet" with "N previewed prices — saved only when you Apply ·
  they'll wait here if you leave". Scenario-switch toast: "Preview set aside —
  it'll be here when you view this price again." The row "preview" tag gets a
  tooltip pointing at Apply.
- The (i) beside the bid name renders on **every** bid (was multi-GC/price
  only): solo bids get the structure story collapsed to one "One GC · one
  price" line; all bids gain a "Previews & saving" section (with inline amber
  mini-example, and the "a GC can never see a preview" reassurance) between
  Price options and Labor & cost.
- Workbench tour step "Preview, then Apply" reworded; help guide
  `price-a-bid-with-the-workbench.md` "Preview first, then Apply" section
  rewritten ("Previews wait for you").
