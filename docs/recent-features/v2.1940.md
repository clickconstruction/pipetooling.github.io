# v2.1940 — Roadmap stage-number badges on Map and Plan (2026-08-20)

Part 1 of the stage-numbers pair (part 2 = the Order-stages reorder modal):
cross-referencing the Map canvas and the Plan list needed a shared handle.

- **Numbering model**: stage #N = position N in the roadmap's
  `checklist_tech_tree_groups.sort_index` order (already how groups load).
  Derived, never stored — dense 1..N per roadmap, top stage is always #1.
  Kernel: `stageNumbersByGroupId` in `src/lib/roadmapStageNumbers.ts` (+ test).
- **Badge**: `RoadmapStageNumberBadge` (new, `src/components/checklist/`) —
  neutral slate chip (`--text-slate-600` on `--surface`, flips per theme) so
  it never reads as done/unlocked/locked status. `corner` variant overhangs
  the Map cluster's top-left.
- **Map**: `GroupNodeData.stageNumber` + corner badge on every cluster card
  (`ChecklistTechTreeTab.tsx`).
- **Plan**: same badge before Now stage titles, Up next rows, and Goal
  milestone cards (`ChecklistRoadmapPlanView.tsx`). Plan keeps its momentum
  sort — numbers ride along for cross-referencing rather than forcing 1-2-3
  order.
