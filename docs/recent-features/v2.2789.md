# v2.2789 — Sub work orders from sheets, PR 4: the portal side (2026-09-04)

Fourth PR of the Sub Work Orders train. The sub's portal now shows everything a sheet work order carries and records what they confirm at signing.

- **Offer card** (`OfferCard` in [`SubPortal.tsx`](../../src/pages/SubPortal.tsx)): under the scope lines, a *Not included* list, the bond / special-provisions lines, and a collapsed *Also part of this work order* list naming each referenced document with its version date (or COI expiry). Sheet work orders title from the snapshot's sheet label. The signing block gains a *Please confirm* box: every acknowledgement must be ticked before **Accept & sign** goes through (client check + server check), and the disclosure sentence names the referenced Book documents with their versions (`signDisclosureRefs`).
- **Sheet card**: a collapsed *✍ What you agreed to* line when a signed sheet work order exists — signed date, signer, amount, scope lines, references, and the boxes they ticked.
- Shared statement builder [`_shared/subPortalStatement.ts`](../../supabase/functions/_shared/subPortalStatement.ts): `SubPortalOffer` gains `anchor`, `exclusions`, `references`, `acknowledgements`, `bond`, `specialProvisions`; `SubPortalSheet` gains `agreement`; new `parseScopeExtras` (defensive, Deno + Node) and `attachSheetAgreements` (newest signature per sheet; ticked list from `signer_acknowledgements`, snapshot fallback). Tested from `subPortalStatement.test.ts`.
- `sub-portal`: offers select adds `labor_job_id`; step names are looked up only for step-anchored rows; signed sheet orders (accepted / approved / settled) are fetched for the sub's sheets and attached. `submit-sub-portal` `accept_offer`: reads the snapshot's acknowledgements, requires all of them in `body.acknowledgements`, stamps `signer_acknowledgements` with the signature, appends the sheet label to the dispatch note. **Redeploy both.**
- Client: `subPortalPayload.ts` parses the new fields (new `subPortalPayload.test.ts`); 12 new EN/ES strings in `subPortalI18n.ts`; the demo fixture and the What-customers-see sample carry a sheet work order with references + acknowledgements and one signed agreement.
- Help: *share a sub their portal* → Sign to accept work.
