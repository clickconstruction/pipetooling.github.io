# v2.5354 — Messages: the bids@ reader is written, not yet switched on (2026-10-12)

Cut 6 (email in), PR 3 of 4: the `gmail-sync` edge function (`docs/EDGE_FUNCTIONS.md` → gmail-sync), over the kernels
(v2.5349) and the migration (v2.5350). Deployed by hand after merge; the switch `gmail_sync_on_v1` stays off until a dev
turns it on after the live test.

- **The reader**: the cron every 3 minutes, `X-Cron-Secret`, the switch read again. The first run keeps the box's
  history point and reads nothing older. Each run reads the Inbox's new messages since the last point, oldest first, up
  to 40; a message already labelled is passed over; a forwarded copy lands on its first sender with the forwarder's
  note as a team note; left-out mail stays unlabelled. The address finds its contact or makes the Who is this? row;
  the subject's job or the star ties the line; each file up to 25 MB is copied into `message-attachments`; then
  `email_write_line` writes once and the label **In ClickTooling** goes on, written or not. The point moves only past
  records taken whole (`historyWalk.ts`): a failure keeps it at the last one and writes `last_error`.
- **The token**: `_shared/googleToken.ts`, `driveUpload.ts`'s JWT path with the scopes given (`gmail.modify`), so no
  Drive function changes. `_shared/gmail.ts` holds the Gmail calls; none deletes, archives, moves or marks read.
- **Kernels**: `subjectJobs.ts` labels the jobs a subject may name (a bid's `BP523`, a GC project's `#42`, a Pipeline
  job's `JP1077` or `C88`) and `subjectNumbers` reads the numbers to look up. `forwarded.ts` reads a block's time with
  the app's own Chicago helper (`appTzWallTimeMs`, new in `src/utils/dateUtils.ts`), not a second daylight rule.
- **Registered**: the edge kernels' mirror (`scripts/edge-kernels.mjs`, with `gmail-sync` as an importer), the dev-mcp
  catalog, `config.toml`'s `verify_jwt = false`.

Redeploy after merge: `gmail-sync`, `dev-mcp` (its catalog), `customer-portal` and `gc-trade-portal` (their mirrored
kernels' headers name the new importer).
