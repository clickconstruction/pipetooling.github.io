# v2.2794 — Contract Forms PR 2: the Form Studio (2026-09-04)

Dev-only **Forms** tab in the Contract library modal (People → Contracts → Contract library): upload a PDF, place the entry boxes a signer fills, preview the filled page, publish as a Contract Book entry. Plan: `docs/CONTRACT_FORMS_PLAN.md`; spec: `docs/CONTRACT_FORMS.md`.

- **`FormStudio`** (`src/components/contracts/formStudio/FormStudio.tsx`): lists `contract_form_templates`; "New form from a PDF" reads the file with pdf-lib (`readPdfFields`), offers to import its fillable fields as boxes, uploads the PDF to the private `contract-form-templates` bucket, inserts the row, opens the editor. Delete goes through the confirm dialog.
- **`FormStudioEditor`**: pdf.js page canvas (`PdfPageCanvas`, lazy worker) with the **`FormBoxLayer`** over it (drag to move, corner handles to resize, shift-click multi-select, arrow-key nudge 0.5 pt / Shift 5, Delete) and the **`FormBoxInspector`** (key, type, bilingual label + help, required / sensitive / rarely-needed, PDF bind or per-segment binds, mask presets, group and one-of sets, prefill, constant text, date mode, font size, align, exact rect, sample value, order). Toolbar: add box by type, **Import PDF fields** (skips already-bound fields), **Merge → digits** (sibling cells → one masked number), Import / Export JSON, Replace PDF, samples toggle, **Preview filled PDF** (client-side `fillFormPdf` with Great Vibes + red outlines optional), Save, **Publish…** (packet, document name, audience default `sub`, version date).
- **`formStudioState.ts`** (+ tests): `addBox`, `updateBox`, `renameBoxKey`, `removeBox`, `duplicateBox`, `moveRect` / `setRect` with page clamping, `moveOrder` / `renumberOrders`, `mergeDraftedFields`, `promoteToDigits`, `parseSchemaJson`, `schemaSummary`, `bookEntryForForm`.
- **`formTemplateRepo.ts`**: list / create (upload + insert, cleanup on failure) / save / replace PDF / delete / signed URL / download / `publishFormTemplate` (marks published, creates or moves the one Book entry per template: `book_body_html` null, `tags ['form']`, `form_template_id` set).
- **Migration `20260904230000_contract_form_templates_doc_type.sql`**: `contract_form_templates.doc_type` (agreement | coi | w9 | license | other, default other); the resolver trigger now also stamps a form's doc type onto person copies still at the default, so a W-9 form's copies light the W-9 compliance pill without a manual type edit. Trigger also fires on `form_template_id` updates.
- Wiring: `ContractLibraryModal` gets `isDev` and the Forms tab; `PeopleContractsTab` + `People.tsx` thread `isDev`; contracts loaders select `form_template_id`; `hasContractSigningContent` and the quick-send book rows accept form entries (no body needed).
- Out-of-band (done 2026-09-04): buckets `contract-form-templates` and `contract-form-pdfs` (private) + the dev storage policy from `docs/CONTRACT_FORMS.md` § Storage. `src/types/database.ts` regenerated after PR 1's push.
- Help: `build-a-fillable-form.md` (dev).
