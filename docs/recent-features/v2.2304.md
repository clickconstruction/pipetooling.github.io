# v2.2304 — Task card: thumb dock + crew sun view (2026-08-25)

Redesign of `ChecklistTechTreeTaskCardModal` (mockup-approved, three panels:
editor phone / crew-in-the-sun phone / desktop —
https://claude.ai/code/artifact/97b5f60a-ede9-425b-bb35-11bf23df3372).
UI-only; props unchanged, no migration.

## Editor card (phone + desktop, identical anatomy)

- **Header**: crumb + task number + ✕ (now in the crumb row, the only header
  control). The title is the rename control — tap it (faint inline ✎ marks
  it); the boxed ☆/✎ icon buttons are gone.
- **Status line** under the title: ✓ done chip, bridge chip (on list /
  in review / signed off), ⏳ waiting note — read-only, no actions.
- **Thumb dock** (bottom, both screens): flex Mark done (48px) + 48px ★ Pin
  square (pressed = amber; the duplicate "★ pinned" chip is gone) + 48px 🗑.
  🗑 swaps the dock for the two-step confirm (full-height Delete permanently /
  Keep it) — delete no longer sits under the assign hint.
- Assignee chips grew to ~40px with a padded ✕; card radius 18px on desktop
  to match the sheet.

## Crew card (non-editors)

- Stripped for glare: 1.25rem/800 title, plain bold names line (no chips, no
  controls), thread, then **👍 On it / ⚠️ Problem** one-tap replies (post as
  real comments when bridged), then one giant filled green **✓ DONE** (58px).
- ⏳ waiting tasks show an amber explainer banner instead of a dead button.
- Done-but-locked shows an inert green ✓ Done slab.

## Optimistic DONE (both views)

`pressDone` flips the button immediately, runs the write behind it, and on
failure turns into "Tap to retry — not saved" — never a silent revert (field
crews on one bar of signal). Reopen is the undo.

Render smokes updated + extended (15 tests: crew quick replies, waiting
banner, dock delete confirm, tap-title rename). Live-verified on prod data:
done/reopen, pin round-trip, delete confirm/Keep it, rename via title —
all persisted. Owner asked for a live-site pass after deploy.
