# v2.2067 — Assigned Jobs mobile card redesign (2026-08-21)

Owner screenshot review of Abraham's phone (402pt viewport): the Assigned Jobs rows read as an unstructured stream — no card boundaries, a floating 40px phone glyph, the v2.1547 report-count badge overlapping the Leave Report button's corner, and the meta line cramped underneath it. Mockup (Current + 3 variants) → variant A picked: the My Schedule card idiom.

- **Mobile-only card layout** in [`DashboardAssignedJobsSection`](../../src/components/dashboard/DashboardAssignedJobsSection.tsx): each row becomes a bordered 12px-radius card; `leaveReportReminderForJobRow` drives a 4px amber left rail (same signal as My Schedule v2.1549) plus the amber Report-due button. Desktop layout untouched (the old flex-wrap block is kept verbatim behind the `isMobile` ternary).
- **Uniform 42px utility buttons** (call / Drive / pictures / plans) via new atoms in [`dashboardJobRowShared`](../../src/components/dashboard/dashboardJobRowShared.tsx) (`JOB_ROW_MOBILE_ICON_BUTTON_STYLE`, `jobCardMobileStyle`, `jobCardMobileActionButtonStyle`, `ReportFileGlyph`); `JobRowCallButton`/`JobRowMissingPhoneButton` gain a `boxed` prop.
- **Report count chip** ("▤ 3 reports", opens the job's reports) replaces the overlapping corner badge on mobile; [`DashboardLeaveReportButton`](../../src/components/dashboard/DashboardLeaveReportButton.tsx) gains `grow` (flex-1, 44px, radius 8) for the full-width button row next to Send to Billing.
- Meta footer keeps the existing kernels (`formatOpenAgeShort` + `subcontractorLastActivityMobileLine`) on their own quiet line.
- Gotcha fixed en route: mixing the `border` shorthand with a `borderLeft` longhand in one React style object drops the border entirely — `jobCardMobileStyle` uses four longhands (comment in place).
- Render test pins the amber rail + chip (`DashboardAssignedJobsSection.render.test.tsx`).

Verified live as Abraham (login-as-user on a 402×874 pane, light + dark): cards, chip, 44px buttons, and the amber rail all render; desktop unchanged. Client-only — no migration.
