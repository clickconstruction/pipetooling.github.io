# v2.2981 — Team board: "Looks right" acknowledgements and the ran-long threshold as an org default (2026-09-07)

Third PR of the Team train (board v2.2974, actions v2.2978). One migration (`20260907043410_team_board_acks.sql` — **`supabase db push` after merge**); no edge function.

## What shipped

- **`team_board_acks`** (new table; fragment `docs/migrations/20260907043410_team_board_acks.md`): one row per accepted `(kind, work_date, person_user_id, target_key)`, `kind` ∈ `over` | `unplanned`; delete = undo. Read any signed-in user; write dev / master / controller. `database.ts` carries the type by hand until the next gen-types run.
- **Kernel**: `buildTeamBoard({ acks })` — an accepted cell keeps its shape but `acked: true`: it leaves `exceptions`, `overCount` / `unplannedCount` (counted in `ackedCount` instead) and the row's `hasException`; `teamCellStanding` reads **Accepted**; `ranLong: null` turns the rule off. `teamAckKey` / `teamAckKindFor` (+3 tests).
- **Loader** reads the table soft (missing table = no acks) and hands `ackIdByKey` to the actions for undo.
- **Actions**: **Looks right** on ran-long and not-planned chips (chip, ledger row, exceptions list) inserts the row; **Undo accept** deletes it. Move to plan is hidden once accepted.
- **Threshold**: new `org_defaults` key `team.board.ran_long` (kind `ran_long`; values `off`, `1.25:1`, `1.5:1.5` standard, `2:2`) in the registry, so Settings → Company → **Defaults for everyone** gets the row for free (everyone / field / office). `ranLongRuleFromOrgValue` feeds the kernel; the tab's footer states the rule in force and the week's accepted count.
- Guides: `read-the-team-board` (Looks right + threshold), `set-defaults-for-everyone` (the new key).
