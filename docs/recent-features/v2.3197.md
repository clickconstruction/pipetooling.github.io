# v2.3197 — Pipeline activity box: a report pill beside + Add (2026-09-09)

Client only. Owner ask, looking at J892's row: "add a quick button to leave a report … next to +Add where we show the report icon and when clicked it opens the new report modal."

- [`JobsStagesActivityBox`](../../src/components/jobs/JobsStagesActivityBox.tsx): a second floating pill to the right of **+ Add** (one flex row, same height) — the document-with-lines icon (`JobsWorkedTodayReportIcon`), white on the box, blue border — `aria-label` "File a report on this job". Renders only when the row context carries `openNewReportForJob`.
- [`jobsStagesRowShared.tsx`](../../src/components/jobs/jobsStagesRowShared.tsx): `StagesRowRenderContext.openNewReportForJob?`; threaded like `openJobActivityExpand` through [`JobsStagesTable`](../../src/components/jobs/JobsStagesTable.tsx), [`JobsStagesUnifiedTable`](../../src/components/jobs/JobsStagesUnifiedTable.tsx) and both card lists.
- [`JobsStagesTab`](../../src/components/jobs/JobsStagesTab.tsx): one `NewReportModal` instance in the modal tail, `initialJob` = the row's job (`job_ledger`, the effective J number, name, address), `onSaved` → `loadJobs()` + `refreshJobThreadStatsForJobIds([id])` + the thread reload, so the "N Reports" chip and the box's feed pick the new report up. The six section call sites pass the opener.
- Since v2.3192 the modal shows the stage picker on a job with Order stages (J892 is one), so this pill is also the shortest path to a stage-weighted report from the office.
