# v2.5880 — The Bridge’s loaders take the Supabase client (2026-10-26)

A mechanical sweep ahead of the weekly send of the Monday sheet (the owner’s second Bridge ask of 2026-10-26, after v2.5879’s landing): every read the sheet needs can now run with a client passed in, so the edge function that builds the sheet on Monday morning can make the same reads as the service role. Nothing changes on screen.

- **The Bridge’s own loaders take `db` first** (`loadBridgeData`, `loadEarnedJobs`, the three saves, `loadBridgeVectorInputs`, `loadVectorSessions`, `loadVectorDaysInputs`, `loadBuildPaceInputs`, `loadBillPileJobs`, `loadDemandInputs`, `loadBridgeCalls` / `recordBridgeCall` / `answerBridgeCall`, `loadCollectDeskReads`, `loadCollectScorecardReads`, `loadMercuryCash`); the page and the banking nicknames modal pass `supabase`. `loadBillPileJobs` takes the ZZ test job ids instead of reading them itself; the page reads them once per user, as before.
- **Shared loaders keep every caller**: the body of each moved to a client-taking read file and the old file binds the app’s client — `overheadPoolSnapshotReads.ts` (`readOverheadPoolSnapshotInputs`, `readOverheadPoolSnapshot`), `overheadPartsBucketReads.ts`, `overheadOfficePartsReads.ts`, `overheadOfficeJobRead.ts`, `jobs/zzTestJobReads.ts`, `subLaborDueRows.ts` (from the hook `useSubLaborDueTotal`) and `dashboardFinancialsLoad.ts` (`loadDashboardFinancials`, the body of `useDashboardFinancials`; the hook now reads the ZZ ids first and keeps the state). `loadUnlinkedMoney` takes `db` first (three callers). `LEAN_STATS_ACTIVE_JOB_STATUSES` lives in `jobs/leanStatsStatuses.ts`, re-exported where it was.
- **Why**: `scripts/edge-kernels.mjs` refuses a file that imports the `supabase` singleton (`import.meta.env`); with the client a parameter every file under the sheet is copyable, and the retry and paging helpers (`errorHandling.ts`, `supabasePaging.ts`) carry no browser global. The copy itself, the sheet kernel and the function come in the next PRs.
- **Tests**: the four tests that mocked the old inner paths now mock the read files (`overheadPoolSnapshot.test.ts`, `loadReviewOverheadRates.test.ts`, `loadUnlinkedMoney.test.ts`, `useBilledTotal.render.test.tsx`); nothing else moved. No migration, no edge function, no guide.

## Verify

The Bridge, the Dashboard’s Financials and Overhead cards, People → Overhead and Review read as before; Banking’s account nicknames window still reads the bank.
