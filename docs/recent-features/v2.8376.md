## The sweep script

`scripts/codemods/small-cents-sweep.mjs`, parsed with the TypeScript compiler, mechanical and re-runnable. On a rebase conflict the script is run again on the new main.

It reads what a component draws: a JSX child, and the branches of a `? :`, `&&`, `||` or `??` inside one. Six rewrites, each of which leaves the characters on the screen as they were:

1. `$` and then `formatCurrency(x)` as JSX text becomes `<Money amount={x} />`. The `$` may end its line with the figure on the next.
2. A template or a `+` chain that is exactly `$` and `formatCurrency(x)` becomes `<Money amount={x} />`.
3. A template or a `+` chain with words around such an amount is wrapped in `<MoneyText text={…} />`.
4. A call to a function that returns money to the cent with its `$` is wrapped in `MoneyText`. The script reads the function's own body, in the file or in the file it is imported from: it must return a string, write a `$` and format to two places. A function that returns rows, a model or JSX is never one.
5. `$` and then `x.toFixed(2)`, or `x.toLocaleString` to two places, is wrapped in `MoneyText`.
6. `formatCurrency(x)` with no `$` before it, a column of bare figures, becomes `<Money amount={x} symbol="" />`, unless `x` reads as hours, a count or a percent.

`MoneyText` shrinks the cents of a figure that carries its `$` and nothing else, so wrapping words that hold no amount changes nothing.

Left alone on purpose:

- A string handed to a prop: a `title`, an `aria-label`, a toast, a confirm window's words, a CSV cell.
- `<option>`, an SVG `<title>` and SVG `<text>`. A chart's label takes `MoneyTspans` by hand.
- Anything inside a `data-theme="light"` wrapper, the public pages and portal cards, and the files in `SKIP_FILES` with their reasons: the estimate as a customer reads it and the partner's statement paper among them.
- A file that already has its own `Money`. The script lists it for a hand.

The name `formatCurrency` alone proves nothing. Five files carry their own copy that writes the `$` itself (Intl's currency style), and a component may be handed one as a prop. The script counts a call as the bare formatter only where it has read the function's body, in the file or in the file it is imported from. The first run did not, and dropped the `$` on those five; it was caught on a read of the diff, before the commit, and no test would have caught it. After a sweep the script also takes out a `formatCurrency` import, or a local copy, that nothing reads any more.

`--held` lists what a hand should look at: figures that read as hours, chart labels, and money handed to a prop.

## The check

`npm run check:small-cents`, in CI after `check:error-words`. It is the script with `--check --changed`: it reads the swept surfaces and fails a PR on the lines it writes there, never on an older line another PR landed. The swept surfaces are the files in `scripts/codemods/small-cents-swept/`, a path or a glob a line. A sweep adds one file of its own there, so two sweeps in flight never edit the same lines and merge in any order. `CLAUDE.md` names the rule on the *Values in place* line.

## Tests find an amount as before

An amount is two spans now, so `getByText('$1,250.00')` finds nothing. `src/test/moneyText.ts` is a matcher that reads an element's own text with each amount inside it as the plain text it was, and answers with the element `getByText` answered with before. `small-cents-sweep.mjs --tests` writes it into a test's matchers. 42 matchers in 13 test files took it here, only where a test failed.

A press with an amount in its name (*Keep $24.00*) read *Keep $24 .00* in the test DOM, which treats a span with no display as a block. The door's spans now say `display: inline`, which a browser already does, so `getByRole('button', { name })` finds such a press with no change to the test.
