# v2.3156 — The People board on a phone (2026-09-08)

Client only — no migration, no edge function. Owner's ask, after Taunya's report ("The tech area needs to be bigger. Trying to add and link jobs while driving is going to cause a wreck"): optimize the Schedule Dispatch **People** tab for the phone flow, since she prefers it to the phone-first Schedule tab — and keep a way to see the desktop view, at the very bottom of the page. Designed as before/after mock-ups first (artifact *People Board on a Phone*); the principles and options are recorded there and summarized here.

## The reading of the complaint

Her screenshot is the desktop week grid squeezed to a phone, mid single-block copy ("Adding a linked copy from 12:00 PM–4:00 PM. Click a team member's day cell… Press Esc to cancel"). The sticky Person column takes 40% of the width and — a real bug — was painted transparent on phones, so the scrolled-under Monday header bled through as "07) by lanes". The copy's tap target was a 40 × 20 px name pill or the sliver of cell under the last block, beside blocks that also react to a press. "The tech area" is the tech's row; "bigger" means "give me one obvious thing to tap per tech".

## What shipped

- **[`HubPeoplePhoneBoard`](../../src/components/schedule/HubPeoplePhoneBoard.tsx)** — what `HubPeoplePanel` renders on a narrow viewport (`useIsMobile`) instead of the week grid, when the page passes the per-device preference. Same props, same callbacks; nothing here writes.
  - **One day, full width.** A **day strip** (Mon–Fri, block counts, today ringed, the missing-note count on the focused day) picks the day; the week arrows in the shell still step weeks. The board opens on the URL's / today's day (`initialBoardYmd`) and re-lands when the week changes.
  - **A card per tech**: name (+ `(s)` salaried), the *Not coming in* / NCNS chip from `userTimeOffByCell`, one row per block that day (title · address · *linked with Paige* · short time), and a full-width **+ Add here** (`onAddJobToScheduleForCell` / `onEmptyCellClick`). No drag handles on the phone.
  - **Labeled toolbar**: **Add job** (`onRequestHubAddJob`), **Copy to techs** (`onStartLinkedCopyMode`, the two-stage flow), **⚡ Assign work** (the panel's `QuickAssignSheet`).
  - **Placement modes make the whole card the button**: single-block copy / move (`cardPlacementMode` → `onCardPlacementCellPick`), add-job placement (`hubAssignJobPlacement` → `onHubAssignJobCellPick`), two-stage linked copy (stage 1: block rows become checkboxes → `onLinkedCopyToggleBlock`; stage 2: cards → `onLinkedCopyApplyToPerson`, team bands → **Whole team** → `onLinkedCopyApplyToLane`), multi-cell fill (`onHubMultiCellAddToggle`, selected cards read *Selected · tap to take it off*). Each card says what will land — *Tap to add J927 · 12–4 here* / *Busy 8–5 · J000 Office · tap anyway* / *Already on J927 12–4* (the source, not tappable). A linked copy lands on its source day: the board switches to it when the mode starts and, if you move off it, the cards say so instead of misplacing.
  - **The mode bar** — a dark fixed bar just above the tab bar (offset by `DISPATCH_MODE_FOOTER_HEIGHT_PX` + safe area) with the mode in words (*Copying J927 · 12–4 to… · linked*, *Moving…*, *Adding J650 to…*, *Pick the blocks to copy · 2 selected · Next*) and **Cancel** / **Done** beside it. The page's three top banners stand down while the board is active (`phoneBoardActive`); the multi-cell **Choose job** footer is unchanged.
  - **The block sheet** (tap a row): **Open the job**, **Add / edit the note**, **Copy to techs**, **Move** (`onStartCardPlacement(block, 'move')` → cards are targets, any day), **Remove**.
  - **Copy to techs sheet** — a checklist of every other tech with their day as a 6 AM–6 PM ribbon and *free 12–4* / *busy 8–5* beside the name, team bands that toggle the crew, a **Linked crew — moves together** switch, and **Add to N techs** → the new page callback `onCopyBlockToPeople({ blockId, userIds, linked })`, which runs the same `insertScheduleDispatchCopiedLeg` loop the lane apply runs (`linkMode` linked / unlinked) and one summary toast.
  - **The bottom switch** — **▦ Show the desktop view** at the very bottom of the board renders the unchanged week grid; the grid's bottom on a phone offers **📱 Back to the phone view**. Page-owned state (`phonePeopleView`, `readPhonePeopleView` / `writePhonePeopleView`, key `pipetooling_dispatch_people_phone_view_v1`), so the banners and the panel agree; the Quickfill "tomorrow" embed never gets the board.
- **Kernel** [`phonePeopleBoard.ts`](../../src/lib/scheduleDispatch/phonePeopleBoard.ts) (13 tests): the view preference, time parsing / short ranges / ribbon spans, the day strip, `cardTargetState`, `modeBarText`, `availabilityLabel`, the captions.
- **Fixed regardless**: the phone's sticky Person cells and header now paint `var(--surface)` / `var(--bg-muted)` instead of transparent, so the desktop grid on a phone no longer shows the scrolled-under column through the names.
- **New shell/panel props** (both mounts): `phonePeopleView`, `onPhonePeopleViewChange`, `onCopyBlockToPeople`, `onCancelCardPlacement`, `onCancelHubAssignJobPlacement`, `onLinkedCopySetStage` — the last three were page-local before and are what the mode bar's Cancel / Next need.

## Not changed

Desktop rendering of the People grid; the Jobs and Day tabs; the Quickfill embed; every write path (the board only calls the page's existing handlers plus `onCopyBlockToPeople`, which reuses the copied-leg insert).

## Tests

`phonePeopleBoard.test.ts` (13), `HubPeoplePhoneBoard.render.test.tsx` (4: strip + cards + Add here + the switch + day change; copy mode targets incl. busy / source; block sheet → Copy to techs checklist → `onCopyBlockToPeople`; linked-copy stage 1 checkboxes and stage 2 person / team apply). `ScheduleDispatchHub.render.test.tsx` unchanged and green.

## Verify

1. Phone (or the browser at ≤ 640 px) → Schedule → People: the day strip and cards; tap **Wed** → that day's blocks; **+ Add here** → the Add job picker for that tech and day.
2. Tap a block → sheet → **Copy to techs** → tick Paige → **Add to 1 tech** → toast, and Paige's card gains the linked row.
3. **Copy to techs** in the toolbar → tick two blocks → **Next** → tap a tech card → the copies land; **Done**.
4. **▦ Show the desktop view** → the grid, with solid name pills; **📱 Back to the phone view** → the board; reload → the choice sticks.
