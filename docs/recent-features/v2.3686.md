# v2.3686 — Dev MCP keys: the card explains, in plain words, how to use a key in Claude (2026-09-21)

The owner, after the OAuth spike (`to-dos/mcp-servers.md`, PR 7's answer): *"Can you add a guide or an explanation in the dev MCP keys setting to explain to someone who is not technologically very literate how to do this in Claude?"* Client only; no migration, no edge function.

## What was wrong

The fresh-key panel said *Add this line to your shell profile (~/.zshrc), open a new terminal, and start Claude Code in the repo* — every word of it a term a non-technical person does not have. And it was found today that the owner's own Mac never had the line: `.mcp.json` had been sending the unexpanded `${PT_DEV_MCP_TOKEN}` placeholder, which the server reports as *Unknown or revoked dev key*.

## The change

- **[`DevMcpKeysCard`](../../src/components/settings/DevMcpKeysCard.tsx)** — the fresh-key panel is two numbered lists. *To use it in Claude Code on this Mac*: Copy setup command → open Terminal (⌘ Space, *Terminal*, Return), paste, Return, it answers *Saved* → quit Claude Code (⌘ Q), open it again in the PipeTooling folder, type *call whoami on dev-mcp*. *To use it on claude.ai, Claude Desktop or your phone*: Customize → Connectors → Add custom connector, the address, No sign-in, Request headers → `authorization` → Copy header value, Add; and what to do when the account has no *Request headers* section yet (the beta is per organization — Path 0 of the spike). The card's opening line links to the guide.
- **[`devMcpKeys.ts`](../../src/lib/devMcp/devMcpKeys.ts)** — `devMcpSetupCommand(key)`: one line that drops any old `export PT_DEV_MCP_TOKEN=` from `~/.zshrc`, appends the shell line, and echoes the next step; `devMcpConnectorHeader(key)`: `Bearer <key>`, because Claude sends the header value exactly as typed. Two tests. *Copy shell line* and *Copy key* stay for people who know what they want.
- **Guide *connect my coding agent to PipeTooling*** — *Set it up once per machine — in plain words* replaces the three terse steps, with an example panel on what the command did and what *command not found* means; a new section *From claude.ai, Claude Desktop or your phone*. Keywords gain terminal, setup command, request headers, custom connector, phone.
