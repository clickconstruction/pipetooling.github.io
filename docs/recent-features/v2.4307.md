## What prod said before building (read-only, 2026-10-01)

- `job_stage_windows` has 0 rows ever and `jobs_ledger_fixtures.progress_pct` is never set, so no line carries its own "done"; only the job's `pct_complete` exists (88 of 149 recent jobs). A per-line Done column would read *not scheduled* everywhere, so "done" is drawn as the job's % done marker across the line blocks, and *Done, not billed* as a figure.
- Bills made in the app in 90 days: 93 Ready to Bill bundles, 51 by picking lines, 22 part amounts, 5 whole amounts. 250 more were whole-job bills recorded from HouseCall Pro (`external_send_channel = housecallpro`) and never touch these controls. So the whole rest gets one button, picking lines stays on the card, and the slider moves one tap in.
- 90 of 126 priced recent jobs have one line, and none was split between payers, so a one-line job with nothing to tick shows no line list.
