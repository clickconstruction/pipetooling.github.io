# v2.3805 — Hiring, the helper try-out loop PR 6: the assistant's tab (2026-09-24)

PR 6 of [`to-dos/helper-tryout-loop`](../../to-dos/helper-tryout-loop/README.md) (punch list #24), the last of the three share PRs, stacked on PR 5 (v2.3802). Client only. With this the loop the owner asked for is whole: the assistant feeds one column, the masters answer by name at the helper's clock-out, the office reads the tally and presses Hire or Pass.

## The change

- **The Hiring pill opens for a share** ([`Prospects.tsx`](../../src/pages/Prospects.tsx)): [`useMyHiringShares`](../../src/hooks/useMyHiringShares.ts) reads the viewer's own `team_prospect_role_shares` rows; the pill, the `?tab=team` guard and the cold landing (`resolveProspectsLanding`, its `teamProspectsAccess` input now meaning "may open the board") take `teamProspectsAccess || shares`, and the board renders with `shared` when the viewer has no switch. The landing waits for the shares read as it waits for the auth row.
- **Kernel [`src/lib/hiring/sharedHiringTab.ts`](../../src/lib/hiring/sharedHiringTab.ts)** (4 tests): `stageAllowed` / `coerceStage` (Screen, Interview, Try-out; a `?stage=hire` or `review` deep link is ignored), `hiringTabPowers` (every office power false for a share: Passed, Advance to Hire, Hire / Pass / Keep trying, Delete, Merge, + Add role, the column ⋯, Unsorted, the Passed bucket, Sources, Talked today on a trial card), `boardIntro` (*Two columns were shared with you — …*).
- **The tab** ([`TeamProspectsTab.tsx`](../../src/components/prospects/TeamProspectsTab.tsx), `shared` prop): the stage strip filtered, the intro reworded, and each of those controls gated on the powers. What the client does not trim, the rows already do — the v2.3798 policies return only the shared columns and their `active / calling / trial` cards, so *also in* names only shared columns, the Role picker lists only them (Unsorted dropped), and a hired or passed card never arrives. The database still refuses anything the client failed to hide.
- Guide: `team-prospects.md` → *Who can see this* gains the share holder's paragraph. Docs: `ACCESS_CONTROL.md` § Hiring (the tab), `PROJECT_DOCUMENTATION.md` (the Prospects page), the to-do → *close* with the live checks that remain.
