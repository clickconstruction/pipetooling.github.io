# v2.4490 — AIA G702-G703: the job remembers its pay applications (2026-10-04)

The third piece of the AIA window's refresh, after [v2.4487](v2.4487.md) (the paper preview, the clean download) and [v2.4489](v2.4489.md) (the prefill). The owner, 2026-10-04: *"right now there is no box for previous applications, and we need to find a way to save or even upload previous applications so we can hold history"*; a sent application: *"no lock"*; then *"start the remember step"*. One migration (`20261004145511_job_pay_applications.sql`), no edge function. The owner, the same day, on applications already sent: *"I would like to be able to upload a Google Docs link to those files, and I would like for them to be able to show up in the job modal."* This PR saves applications and keeps a pasted link beside each; the job window's **Documents** tab that lists them is the next one.

## What was wrong

The window filled a workbook and kept nothing. The form had no box for G703 column D (*from previous application*) or G702 line 7 (*less previous certificates*), so both were 0 in every download: a job's second application asked for everything earned to date.

## The change

- **Two boxes.** `g703_e13_from_previous` (G703 E13) and `g702_h40_less_previous_certificates` (G702 H40) join `AIA_FIELD_DEFS`. `buildAiaPreview` reads them where it read two constants; the paper draws them as boxes; the fill writes them like any other field.
- **Kernel** [`aiaPayApplications.ts`](../../src/lib/aiaPayApplications.ts):
  - `payApplicationWriteFromForm(jobId, values)` — the row a save writes (the form, its two dates when they parse, the sheet's totals from `buildAiaPreview`), or the reason it cannot be saved (the application number must be a whole number 1–9999).
  - `carryForwardPayApplication(last, jobPrefill)` — a new application's starting form: the number is one past the last; who, what, the contract, the rates and the line's name and value carry as they were sent; previous work = the last one's previous work + its work that period; stored material carries; less previous certificates = the last one's line 6; its change orders join the previous months; this period is offered as the job's value created today less what was claimed, and left empty when that is not above zero.
  - `savedPayApplicationFromRow` (numerics the database sends as text; only the form's own keys, only strings and finite numbers), `nextApplicationNumber`, `previousPayApplication`, `sortPayApplications`, `payApplicationLabel`, `parseApplicationNumber`, `parseAiaDate`.
- **IO** [`aiaPayApplicationsIo.ts`](../../src/lib/aiaPayApplicationsIo.ts): `loadPayApplications` (a failed read is no applications), `savePayApplication(write, id)` (insert, or update the open row, which may change its number; a `23505` becomes `PayApplicationNumberTaken`), `deletePayApplication`.
- **The link.** *LINK TO THE FILE YOU SENT* under the list takes a pasted web address (a Google Drive or Docs link) and is saved in the row's `files` as `[{ kind: 'link', url }]`; **Open** beside it opens it in a new tab. `cleanPayApplicationLink` keeps only an `http(s)` address, so a save with anything else is refused with the reason, and a row read back never hands the page another scheme.
- **Window** [`AiaG702G703Modal.tsx`](../../src/components/jobs/AiaG702G703Modal.tsx): *APPLICATIONS ON THIS JOB* at the top of the form — a chip per saved application (`2 · 09/30/2026 · $17,280.00 due`) and **New · N**; a line under it says what is open. **Save** beside Generate; **Generate** downloads and then saves (a form with no number still downloads, and the toast says it was not kept). **Reset from job** reads **Reset to saved** on a saved application. **Delete** on a saved application asks first. Switching applications or closing with typed changes asks *Leave without saving?* (the app's confirm window).
- **Table** `job_pay_applications`: [`docs/migrations/20261004145511_job_pay_applications.md`](../migrations/20261004145511_job_pay_applications.md).

## Not in this PR

- The **Documents** tab on the job window, where a job's applications and their links show outside this window.
- Keeping the generated workbook itself (the row keeps the form, which redraws it).
- A note on a later application when an earlier one changes after it went out (the owner's call, still open).
- The lines from the bid's schedule of values, the list on the job, the bill, the Lien desk's retainage.
