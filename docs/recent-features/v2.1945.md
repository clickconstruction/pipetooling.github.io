# v2.1945 — Partnerships Job review: rows open the Job window (2026-08-21)

Owner request: reviewing a job for the §3 majority decision usually means looking at the job itself first. Each row's info block on [`PartnershipJobReviewTab.tsx`](../../src/components/partnerships/PartnershipJobReviewTab.tsx) is now a click/keyboard target (link-colored title, `role="button"`) that calls `useJobFormModal().openEditJob(job_id, { onSaved: reload })` — the same app-level opener the Jobs Pipeline rows use, which lands on the tabbed Job window's Edit tab via the v2.1675 bridge. `onSaved` reloads the review queue so hours shares stay fresh after an edit. Fail-soft: when the context is absent the row renders as before, unclickable. The majority toggle is untouched. Client-only — no migration.
