# v2.2078 — Update % done files a Status Report (2026-08-22)

Owner decision: the % stepper (v2.1806) and Leave Report were two doors that half-overlapped — the stepper moved `jobs_ledger.pct_complete` but left no report, so it didn't clear the Report-due reminder, didn't count in the reports chip, and didn't notify the office. Now both doors are ONE flow: **report → % mirror → Ready to Bill prompt at 100%**.

- **Kernel** [`stepperReportFieldValues.ts`](../../src/lib/reports/stepperReportFieldValues.ts) (+ tests): maps the stepper's (pct, note) onto the Status Report template's fields — pct to the `percent_0_100` / canonical "How complete is the job?" field (legacy "Who was on the job?" recognized), note to "What is the status of the job?" (falls back to the first non-percent long-text), everything else blank.
- **IO wrapper** [`submitStatusReportFromStepper.ts`](../../src/lib/reports/submitStatusReportFromStepper.ts): resolves the Status Report template (`findStatusReportTemplateId`), inserts the `reports` row (same shape as `NewReportModal`'s direct insert, incl. best-effort geolocation at a stepper-friendly 3.5s timeout), and fires the same best-effort `send-report-notification` + `send-report-email` fan-out as the modals.
- **[`FieldPctUpdateModal`](../../src/components/dashboard/FieldPctUpdateModal.tsx)**: save = submit report → `propagateReportPctToJob` (the v2.1833 mirror — thread note, Stages % box, My Schedule day deltas; v2.2063 error surfacing kept) → the existing `MarkJobReadyToBillPrompt` at 100% on a Working job, now using the mirror's **fresh** job status rather than the modal-open snapshot. Toast reads "Report saved — J949 is now 100% done."; note label says the save files a report.
- **Fallback**: if no Status Report template exists (or there's no auth user), the save drops to the legacy `set_job_pct_from_field` bare-% write so the field never strands.
- Free consequences of being a real report: clears the Report-due reminder (`my_last_report_at`), counts in the reports chip, appears in Job activity and the job's reports list.

Verified live against prod on the designated test job (ZZ Split Bill Test): report row created with the exact field mapping, pct mirrored 25→26 with a "from field report" thread note, no RTB prompt on a billed job. Help guide `update-percent-done-from-my-dashboard.md` updated. Client-only — no migration.
