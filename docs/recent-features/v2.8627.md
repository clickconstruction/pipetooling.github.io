# v2.8627 — Painted maps: the developer can reopen an ended link of a test map (2026-11-26)

Punch list #443, row 14: one of the eight take-backs that need a migration or an edge function, on the owner's answer of 2026-11-25 (*All eight*), its deploy on its own yes. No migration: one new action on `painted-map-link` and a press on the Share sheet.

## The press nothing took back

**End this link now** on a painted map's Share sheet sets `ended_at` on every open link of the map (`desk.end`). The address already sent is dead, the same code cannot be asked for again, and the rows stay. The table lets a client only read, and the function had no action that clears `ended_at`, so a link a walk ended stayed ended for good. The walk of #345 ended one on 2026-11-25 and threw its map away after.

## What changed

- **`painted-map-link`** gains `POST { action: 'desk.reopen', mapId, linkId }` → `{ ok, reopened, endsOn }`. The function reads the caller's role and the map's name itself: a developer alone; a map whose name starts with ZZ; an ended link that is not past its day (`paintedMapLinkReopenable`); under the map's open-link cap. Each refusal has its words in `PAINTED_MAP_LINK_WORDS` (`reopenNotDev`, `reopenNotTest`, `reopenNotEnded`, `reopenPastDay`, `tooMany`). Clearing `ended_at` and `ended_by` gives the same address back, since the code's hash was kept.
- `supabase/functions/_shared/paintedMapLink.ts`, the pure part both sides read: `paintedMapLinkReopenable` and the four words.
- `src/lib/paintedMap/paintedMapLinkReopen.ts`, the sheet's rule: a dev alone (`paintedMapLinkReopenDrawn`); the ended links not past their day, newest ended first (`paintedMapLinksToReopen`); the same refusals before the call (`paintedMapLinkReopenProblem`); the confirm, whose button reads **Reopen the link**; the line and the words after.
- `src/lib/paintedMap/paintedMapLinkIo.ts`: `reopenPaintedMapLink(mapId, linkId)`, one call, the function's refusal passed on in its words.
- `src/components/paintedMap/PaintedMapShareSheet.tsx`: for a dev, a fold *Ended links · N* under the link block lists each ended link not past its day with when it ended and the day it would end on, and **Reopen…**, dead with its reason on a map whose name does not start with ZZ. The confirm names the map and the act; after the reopen the sheet reads its links again and says the link is open again.
- `docs/EDGE_FUNCTIONS.md` names the action, `docs/ACCESS_CONTROL.md` and the glossary say who may reopen one.
