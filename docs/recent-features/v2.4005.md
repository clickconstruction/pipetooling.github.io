## Kept as they were, now pinned by tests

- Projections are dev / master only: nothing is read for another role, and the list empties if the role changes. The first read waits 100 ms after the workflow and the role are known.
- A save resolves the workflow first — from the page's state, else through `ensureWorkflow` — and only then checks the words. So with no workflow to be found, a blank form reports "Workflow not found", not "Step name and memo are required".
- A refused insert or update names the action, keeps the window open and does not re-read.
- **A delete's own error is not checked.** A refused delete reports nothing; the re-read that follows shows the row still there. The map's quirk 24 records it; it is a behaviour to fix on its own, not in a move.
- A projection with no step writes `step_id` and `placement` both null, whatever side was picked.
