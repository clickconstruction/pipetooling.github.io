## What shipped

- **`DashboardNeedsYouCard.tsx`** — the mode opens from `needsYouInitialMode` (the default is not written to the device; only a pick is). Walk's pointer is the round's order instead of an index: Skip sends the card to the back. The *Handled this visit* row under the card lists the session's acted and skipped items; a tap on one still on the list brings its card back, one the work cleared reads ✓ with no door. The trail lives in the card's state — it ends with the visit. Cards mode and the desktop are as they were; the Skip sequence on an unchanged list is the same one as before.
- **`usageDashboard.ts`, Settings → Usage** — `needsYouStats` counts `#revisit` clicks; the Needs You engagement line shows *brought back*.
- **The guide** *needs-you-card* says what Skip does now, what the trail is, and the phone default.

The card serves both the Dashboard and Dispatch Mode's Inbox tab (through `DashboardPinnedQuickRow`), so both get it.
