# v2.5097 — Nine home-screen icons to pick from, for a dev (2026-10-09)

Punch list #67, PR 2 (`to-dos/app-icon-glass.md`). The generator, the card and a candidate sheet; no app code, no migration, no edge function, and `public/` is untouched. The owner, 2026-10-09, after v2.4227: "it still does not look great, this needs to be improved." The card's next was the `TILE` option and, first, a sheet of candidates at 180 px with the glass approximated (the dark tile, heavier ink, a simpler mark, a lighter mark on dark), for the owner to pick from.

## What shipped

- **`TILE` and `MARK` in `scripts/generate-app-icon.mjs`.** `TILE` picks the tile and the mark's colour: `yellow` (the family tile, black ink, the default), `dark` (`#161617`, the favicon's own ink, with the gear in the yellow) and `dark-white` (the same tile, a white mark). `MARK` picks the weight: `now` (the default: gear, hub and the stroked wrench), `heavier` (the gear path stroked 24 in its 640-unit space, so the teeth fatten) and `simpler` (the hub and the wrench dropped, leaving the gear's own round hole). The wrench is cut in the tile colour. The ink is painted before the tile takes its colour, because the dark tile is the same hex as the favicon's ink. Four more needles are guarded beside the old three (`SVG_TILE`, `SVG_GEAR_END`, `SVG_HUB`, `SVG_WRENCH_OPEN`), and an unknown `TILE` or `MARK` throws with the list.
- **The default output is v2.4227's, byte for byte.** `npm run gen-app-icon` on this branch rewrites the five `public/apple-touch-icon*.png` with the same SHA-1s as main's (180 px: `60377978…`).
- **`npm run gen-app-icon -- --sheet`** renders the nine pairs at 180 px and writes `to-dos/app-icon-glass-candidates.html` (70 KB, self-contained: each PNG once, as a CSS background) and a 2× screenshot of it, `to-dos/app-icon-glass-candidates.png` (0.7 MB). The page has two parts. The first shows all nine on a light and a dark wallpaper at 60 CSS px, which is one to one with a 3× iPhone's home screen. The second shows each one up close at 90 CSS px, as the file and under the drawn glass, with its `TILE=… MARK=…` printed. The build already copies every `.html` under `to-dos/` into `dist/`, so after the deploy the page opens at `/to-dos/app-icon-glass-candidates.html`, and the card's Links line picks it up by name.
- **The drawn glass is CSS, and the page says it is a guess**: a white lift over the tile (dark ink reads grey), a 0.4% blur on the art, a band along the bottom 24% that blurs and brightens more, and a bright inset rim. The phone's own glass decides. The footer repeats the card's Reduce Transparency check.
- **The card**: group `gated`, the status and next naming the sheet, the blocker the owner's letter, and the plan's PR 2 / PR 3 lines.
