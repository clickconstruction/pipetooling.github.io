# v2.2611 — Lien prefill reads the owner of record (2026-09-01)

Phase 0 of the Lien Instruments plan: the external Lien Tooling prefill's
mechanic's-lien and release forms filled `owner-name`/`owner-address` from
`jobs_ledger.customer_name` + the property address, while the office-verified
`job_property_owners` row (whose `mailing_address` is explicitly lien-notice
material) sat unread.

- `buildLienToolingPrefillFromJob.ts`: new optional `ownerRecord` on the
  prefill context + `lienOwnerNameFromRecord` (company-first for
  building_owner, person-first for homeowner). Mechanic's lien owner block now
  uses the record's name and MAILING address (split via
  `splitJobAddressForPrefill`); release form uses the record's name. No record
  → behavior unchanged (customer at the property address).
- `LienToolingPrefillModal.tsx`: fetches the job's `job_property_owners` row
  on open (fail-soft) and passes it through.

Tests extended (4 new cases). No schema changes.
