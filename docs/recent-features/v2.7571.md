# v2.7571 — Lien desk: the By date view’s logic moved into its own file (2026-11-17)

The first cut of `src/components/jobs/LienDesk.tsx`, picked by the owner from a map of the file made the same day. A pure move: no behaviour changes.

**What moved.** The By date view's logic, lines 928–1237 of the file as it stood, is now the hook `useLienDeskBoard` in `src/components/jobs/useLienDeskBoard.ts`: the To do rows (`buildLienNextUp`), the Board (`buildLienBoard`), the public-property line and the two off-path bins, what a pressed bin or tile narrows the list to, the leader's Board and his one press for the lot, the row tags the list reads from the Board, the frame that pins the find box as the list comes up, and the reminder to the leader. Ten state values, fifteen memos and thirteen functions left the component. The desk calls the hook where the block stood and reads the same names back, so the rest of the file is untouched and still draws `LienBoard`, `LienDoNowBar` and `LienDeskNextUp` itself.

**What stayed.** The five window flags that sat in the middle of the block (`jobPath`, `publicReview`, `serveOpen`, `scansOpen`, `publicPutBack`) stay in the desk, because the windows they open are mounted there. The router `actOnNextUp`, the find box's state and the run's own state stay too.

**The four places the block met the desk's state.** The day tile's run press now calls `onOpenRun`, which the desk fills with the two setters the press called before. The title's press calls `bringBoard()` in place of `setBoardBring((n) => n + 1)`. The leader's switch is `toggleBoardMine`. The hook reads `shown` (By date is the view on screen) where the block read `kind === 'next'`.

**Two helpers became kernels.** `jobLabel` and `jobNumberOf` were private to the component and both sides need them, so they are `lienDeskJobLabel` and `lienDeskJobNumber` in `src/lib/jobs/lienJobLabel.ts`, with unit tests. The desk imports them under their old names.

**Size.** `LienDesk.tsx` went from 5,371 lines to 5,103, and from 112 `useState` calls to 102. The hook is 412 lines.

**Proof.** `LienDesk.render.test.tsx` (207 tests, 55 of them opening By date) passes with no edit, as do the page's two render tests, `LienBoard.render.test.tsx` and `LienDeskNextUp.render.test.tsx`. New: `useLienDeskBoard.render.test.tsx` (five tests on the hook alone: the empty view before data, the run tile by role, the leader's switch, the two presses with nothing waiting, a tile with no Board) and five tests on the two label kernels.

**Docs.** `docs/LIEN_DESK_ARCHITECTURE.md` records the cut above its twelve-step order, which predates the Board and is otherwise still open. Its line ranges remain anchored to the older file.
