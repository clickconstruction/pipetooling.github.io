# v2.3547 — Pricing tab decomposition, PR 2: the margin-breakdown dialog is its own component (2026-09-16)

Client only, behavior-preserving. PR 2 of the Pricing train in `to-dos/engineering-hygiene.md` — region P3 of [`docs/BIDS_PRICING_LABOR_TABS_ARCHITECTURE.md`](../BIDS_PRICING_LABOR_TABS_ARCHITECTURE.md), the map's "lowest-risk component move in either file" because the dialog reads a snapshot payload and nothing live.

## What moved

[`PricingMarginBreakdownModal.tsx`](../../src/components/bids/PricingMarginBreakdownModal.tsx) — the dialog behind a Pricing grid row: the v2.1324 two-column money table (per unit only when the count multiplies, "—" per unit on a fixed price with its note), the margin band tinted by `marginFlag`, the uncosted warning (map quirk 10), and the v2.2400 jump chips. The IIFE in the tab that derived profit, margin, the per-unit helper and the band colours moved with it, verbatim. `PricingBreakdownRow` moved too and is exported; the tab imports the type.

The tab keeps `pricingBreakdownRow` (the open state, set by `openRowBreakdown` in the grid) and turns its two navigation props into one optional `onJumpToTab(tab, { countRowId, fixture })`, present while a bid is selected — the same condition that showed the chips before. The dialog calls `onClose` before the jump, as the inline version did.

Numbers: `BidsPricingTab.tsx` 5,665 → 5,422 lines.
