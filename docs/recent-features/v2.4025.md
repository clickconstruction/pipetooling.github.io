Migration only; no client change, no edge function. Owner ask, 2026-09-28: the estimators answer GCs with the same few letters and want one place to share them — a button on the Bid Board opening a window where everyone with the board can post, and only the author or a dev can change or delete. PR 1 of 2; the window follows.

## Decided here

- **Who reads and posts** is the owner's words taken as said: everyone with the Bid Board, which is every role that opens Bids — primaries and superintendents included.
- **The author's name is not part of the wording.** The example that started this ends "Thank you, Wendi"; anyone else pasting it would send her name. A reply keeps `sign_with_sender`, and the copy is signed by whoever copies it.
- **The rule is in the database**, not only in what the window draws: the author is stamped by a trigger and cannot be reassigned, and the UPDATE / DELETE policies name the author or a dev.
- **Delete is a delete.** No archive column; the window asks first.
