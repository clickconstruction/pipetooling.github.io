# v2.7143 — Supply houses: the open house's row reads in dark theme (2026-11-13)

Materials → Supply houses. In dark theme the row of the house you opened was a near-white band under near-white words.

## What was wrong

`src/components/SupplyHousesTab.tsx` drew the open row with `background: isExpanded ? '#f0f9ff' : undefined`. The hex does not change with the theme, and the row's words do. Measured on the open row in dark:

| | Before | After |
| --- | --- | --- |
| Band | `#f0f9ff` | `#16324a` |
| Name, balance and Edit (`#f3f4f6`) | 1.03:1 | 12.01:1 |
| Due and Updated (`#9ca3af`) | 2.38:1 | 5.2:1 |

## The change

One value: `'#f0f9ff'` became `'var(--bg-sky-tint)'`. The token's light value is the same hex, so light theme is unchanged pixel for pixel. Nothing else in the tab, or in the cards it mounts for an open house, sets a raw light tint as a background.

## Why no check caught it

- **`node scripts/theme-tokenize.mjs --check src`** maps `#f0f9ff` to `--bg-sky-tint` and would have rewritten it. Its ternary pattern (`TERNARY_TAIL`) needs a quoted string on both sides of the colon, and this one ends in `undefined`, so the line was never read.
- **The lens's Check every screen** holds text to 3:1, but it reads each screen as it lands and presses nothing, and the invented world has no supply house, so there is no row to open.

## The same gap elsewhere, not fixed here

The tokenizer skips the same shape on eight more lines in six files, all a selected, hovered or dragged-over row with a raw `#eff6ff`: `DispatchNoteCombobox.tsx`, `BankingMercuryCategoryReviewTab.tsx`, `BankingMercuryUserReviewTab.tsx`, `BidSubmissionFollowupTab.tsx` (three), `BidsWorkingBoard.tsx` and `pages/Prospects.tsx`. Counting every mapped hex in a component's inline style that the check does not read (a ternary with an unquoted side, a template string, a colour held in a variable), there are 79 more lines in 52 files: 29 backgrounds, 35 text colours and 15 borders. Many are sound (a pale chip under its own dark words). Widening `TERNARY_TAIL` to take an unquoted side is a few lines, and it is a sweep, so it merges alone.

## Verified

Walked on the dev server as the dev in both themes, one house opened and closed, nothing saved. `node scripts/theme-tokenize.mjs --check src` passes.
