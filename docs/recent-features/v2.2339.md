# v2.2339 — Needs You dashboard card (Cards / Walk the list) (2026-08-26)

CX-audit Phase 3, owner-approved mockups: the four hook-driven attention
banners consolidate into one "Needs you" card so the dashboard's loose
notifications become one manipulable block. Held local for owner playtesting
before the PR went up.

- **Kernel `src/lib/dashboardNeedsYou.ts`**: `buildNeedsYouItems` — pure item
  builder mirroring the replaced banners' gating exactly (AR deposits: staff +
  count>0; own stale tally: any role + count>0; team stale tally: office +
  BOTH counts>0; lost bids: nudge non-null). Loading sources contribute no
  item; order is the old banner-stack order. Plus the per-user Cards/Walk
  localStorage preference helpers. 6 unit tests.
- **`DashboardNeedsYouCard`**: renders nothing when empty (like the banners).
  Cards mode = severity-railed rows (blue money / amber chores / gray hygiene)
  with a right-aligned figure and one action each. Walk mode = one item at a
  time with progress segments, kicker eyebrow, action + "Skip for now"
  (wraps), and Next/Then preview. Toggle bottom-right, persisted via
  `pipetooling_needs_you_mode_<uid>`. Telemetry: every action, skip, and mode
  change records control `needs-you` (targets `#<item-key>`, `#skip`,
  `#mode-*`) — the refresh proves itself in the click data from day one.
- **`DashboardPinnedQuickRow`**: the four banner renders
  (`DashboardArBankUnallocatedBanner`, `DashboardTallyStaleBanner`,
  `DashboardTallyStaleStaffBanner`, `DashboardLostBidsMissingReasonBanner`)
  replaced by the card; actions preserved 1:1 (AR toast+navigate, tally
  navigate, staff follow-up modal, why-we-lost navigate). The banner
  components stay in the repo (Quickfill still renders the staff one).
- **Not yet migrated (follow-ups)**: the self-gating banners — team reviews
  due, roadmap needs-a-person, job follow-ups, GC weekly certification,
  bulk-delete alert, claim-dev attempts — still render as banners below the
  card and fold in item-by-item.
- **No "Later"/snooze in cards mode** (v1): the banners never had dismissal;
  walk mode's Skip covers "not now" session-locally. Snooze semantics can come
  with the follow-ups if wanted.
- Tests: 6 kernel + 5 render smokes. Verified live at 1280 (light + dark,
  both modes, Skip rotation), 375 (rows wrap, no overflow).
