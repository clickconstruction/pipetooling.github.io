# v2.2075 — Edit modal adopts the When grammar (2026-08-22)

The last old-language checklist surface, brought in line with the v2.2058 Add
modal (owner: "this modal should be updated").

- **When control** with state derived from the stored item on open:
  `once` + start = today → *Today*; `once` otherwise → *On a date*;
  `day_of_week` → *Repeats/Weekly* (pills pre-pressed);
  `days_after_completion` → *Repeats/after-done*. *Today* doubles as a
  one-tap "bring this overdue item to today" reschedule.
- **Live summary sentence** (same `checklistScheduleSummary` kernel) plus an
  edit-specific line making v2.2057 visible: "Saving reshapes upcoming
  occurrences — completed ones and their notes stay put."
- **Assign to** → `SearchableMultiSelect` (replaces the 17-checkbox wall);
  **notify** → one Me + add-someone-else row; **Advanced** → dev reminder
  fields only, folded by default.
- Save maps `when`/`repeatMode` → the stored fields exactly like Add
  (`effRepeatType`/`effStartDate`; `show_until_completed` forced false and
  `repeat_end_date` cleared for repeats) and still runs
  `applyEditRegeneration`.

Live-verified: QuickFill opens as Repeats/Weekly with M-T-W-T pressed and a
correct sentence; a throwaway once-today item edited to Repeats/Wednesday
became `day_of_week [3]`, sticky flag false, 5 Wednesday occurrences —
today's original occurrence deliberately kept (past/today never yanked
mid-day, per the kernel's rules).
