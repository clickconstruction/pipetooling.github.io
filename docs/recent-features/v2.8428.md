# v2.8428 — Payments: a bill paid from a bank account through Stripe says so (2026-11-23)

Found on the Bills sent walk of 2026-11-23 (punch list #422), against Stripe's own dashboard. Edge function `stripe-webhook`. No migration.

## What was wrong

When Stripe says a bill was paid, `stripe-webhook` calls `mark_invoice_paid_from_stripe` with the bill's id and, for a customer's own payment, nothing else. The row was written with no `payment_type` and the note *Stripe*, and `paymentSourceFromFacts` worded every such row *Card · Stripe*. The walk found one that Stripe's record shows as an ACH direct debit: started on one evening, cleared a week later, a flat fee, and worded as a card on Bills sent, on the bill's record and on the Dashboard.

## What changed

- **The webhook asks how the bill was paid.** `stripePaidMethodType` retrieves the paying charge in the event's mode (`inv.charge`, else the payment intent's `latest_charge`) and reads `payment_method_details.type`.
- **`_shared/stripePaidMethod.ts`, new and pure, says what to pass.** A debit on a bank account passes `p_payment_type: 'Bank debit'` and `p_internal_note: 'Stripe'`. The note is passed because the paid function writes *Stripe* by itself only when the type, the reference and the note are all empty. A card, a wallet and anything else pass nothing.
- **A bill the office marked paid itself is left alone.** Its `pt_*` metadata names the payment, and the charge is not read.
- **Best effort.** No charge, no key for the mode, or no answer from Stripe: the payment is recorded as it always was, and is never held up.
- **The client reads the new type.** `instrumentWord('Bank debit')` is `bank debit`, and a Stripe row with it is *Bank debit · Stripe*, the source kind still `stripe-card`: Stripe's own payment, which the row's doors treat alike. In a sentence it reads *bank debit through Stripe*.
- **It is still Stripe's.** The note is *Stripe*, so `isStripePayment` holds: the Stripe chip counts it, By day paid shows its time, and Money in reads *Landed · Stripe*.

## What did not change

- No row already written. The one bank debit on record keeps *Card · Stripe*, and the guide says an older one does.
- `mark_invoice_paid_from_stripe`. It already takes a type and a note.
- A card payment's row, byte for byte.

## Cost

One more Stripe read for each paid bill, in the webhook, before the row is written.

## Tests

- `src/lib/jobs/stripePaidMethod.test.ts`, on the edge kernel: a bank debit named, a card passing nothing, the office's own payment left alone, and the edge side's type equal to the client's word and read back as *Bank debit · Stripe*.
- `billsAndPayments.test.ts`, `billsPaid.test.ts`, `billsPaidDays.test.ts`: the word, the sentence, the paid line, and the Stripe chip still counting it.
