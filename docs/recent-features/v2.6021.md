## What changed

- **The lien details** (`JobFormLienContractRow.tsx`): `hooks/useJobRetainage.ts` gives the job's figure (`retainageSourceFigure`, v2.6010). Where its source is a pay application the row shows *$5,840.00 · read from pay application 3* with *The latest saved pay application is the source. Change it in the AIA window.* and no box; a typed figure that drifted is mirrored once through the row's own save queue. Where there is no application the box is the office's, as before.
- **The mirror** (`lib/ar/retainageHeld.ts` `lienRetainageMirror`, `lib/ar/retainageHeldIo.ts` `mirrorLienRetainageFromApplications`): on a job with applications, `jobs_ledger.lien_retainage_held` is set to the kernel's figure — the latest application's retainage, the released figure while its bill is unpaid, 0 once paid or never held — so the Lien desk's SQL readers (`list_lien_retainage_windows`, which take the typed column) see the number the GC signed without a migration. Null on a job with no applications. Run after an application is saved, deleted or put back (`AiaG702G703Modal.tsx`, best effort) and by the lien details on a drifted open. An equal figure is not rewritten.
- **The Lien desk** (`LienDeskRetainagePane.tsx`): under *Retainage the notice claims*, a line reads the source (*Read from pay application 2, saved Oct 18* / *Read typed in the job's lien details*) and, once a release exists, *· Release: release billed · awaiting payment · bill #4* with *Open the job ›* (`onOpenJob`). `useJobRetainage` gains `releaseBillLabel` (`fallbackInvoiceNumber` over the release bill's sequence).
- **Tests**: `retainageHeld.test.ts` (+2: the mirror's figure through the release, null without applications), `JobFormLienContractRow.render.test.tsx` (+2: the read-only figure with no box and one mirror write on drift; no write when equal), `AiaG702G703Modal.render.test.tsx` (the mirror stubbed; the suite holds the save, delete and restore paths).
- **Guide** *send lien notices from the Lien desk* → *Retainage*: where the figure comes from, and the release. **Docs**: Glossary (the Retainage held entry), `BILLING_FLOWS.md`, `to-dos/README.md` (the Closed line).
