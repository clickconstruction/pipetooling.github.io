## The script

`scripts/codemods/lien-desk-view-names.mjs` made every change in this PR but the release note and this fragment. Cut a tree from `main`, run it, and the diff is this PR's (checked in a second worktree before the push). `--check` lists what a run would change and exits 1 when there is something, and a second run changes nothing.

- *Do now* and *All filings* name nothing else in the scope, so the script replaces them whole, in strings, JSX, comments and test names. *What to do now* on the Bridge and in a step brief is lower case and is not touched.
- *Deadlines* mostly means a last day. The script changes it only in the shapes that are the view: a label in quotes, bold or a button token, the word before *tab, view, grid, board, list, row, mark, door*, the word after *on, opens, to, at*, and the word in a list of the three. *Deadlines are per job and per work month* matches none of them. Every hit on `main` was read before a shape went in.
- **By hand, kept in the script as a list** (`SENTENCES`): 20 guide sentences that read oddly once swapped (*On To do the same press sits* is now *On the To do tab the same press sits*), the guides' search words, the sentences that tell the history, one comment whose name was split over two lines and one whose *the Deadlines* had none of the shapes. A sentence the list no longer finds is named at the end of the run, so a person reads it.
- **Scope**: `src`, `docs`, `supabase/functions`, `scripts`, `e2e`. Left out: release notes and these fragments (history), `docs/migrations`, `docs/prototypes`, counsel's memo, the `to-dos` cards (each belongs to its session, and the closed ones are history) and the generated twin brief.

## Not renamed, and why

- **Lien calendar.** The By date view's older name lives on in a guide's title and address (*see what is due on the lien calendar*), the search box's label (*Search the lien calendar*), a glossary heading and the kernels' names. It is not one of the three names, and the view is still a calendar.
- **`to-dos/`**: the phone card (#352) and the header tidy were told the names, and their next mock-ups and PRs use them.
- **`supabase/functions/twin-mcp/briefs.ts`**: generated from `docs/twins`. It was already a day of PRs behind on `main`, so a regen here would carry other people's words. The next `twin-mcp` deploy runs `node scripts/build-twin-mcp-briefs.mjs` as it always does.
- **The help recordings**: no lien guide's recording shows the desk's tabs.

## For a PR that lands after this one

A branch cut before this merge may add *Do now*, *Deadlines* (the view) or *All filings* again. After merging `main` into it, run `node scripts/codemods/lien-desk-view-names.mjs` once. On a conflict take `main`'s side of the file and run it.
