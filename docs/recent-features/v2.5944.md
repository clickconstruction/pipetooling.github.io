# v2.5944 — An evening call counts as today, not tomorrow (2026-10-26)

Found while landing punch list #184's sweeps: at 00:12 UTC on 2026-10-27 every PR's CI failed in `BilledAwaitingPaymentSection.render.test.tsx` (v2.5885), whose row read *leaned on -1d ago* where it expected *leaned on today*. It was not a flaky test. Two kernels took a chase touch's day from the first ten characters of its UTC `createdAt`, while *today* came from the company's calendar (`todayYmdInAppTz()`), so from 7 PM Central to midnight every touch logged that evening was tomorrow's. No migration, no edge function.

- **`lib/quickfill/leanRead.ts`** → `touchYmd`: the station's *leaned on today* / *leaned on Nd ago* / *no lean in Nd*, so the Need a lean / Waiting split, read one day off in the evening (a fresh lean read *-1d ago*, and still counted as waiting).
- **`lib/arCustomerChase.ts`** → `touchYmd`: the customer's last-touch line (*couldn't reach · Oct 27 (…) · Marisol* on the 26th, on the Dashboard's AR call card and the station's row) and the snooze and touch windows built from it.
- Both now use `calendarYmdInAppTzFromIso` (`src/utils/dateUtils.ts`), the helper `lib/jobs/paymentChase.ts` already used for the same touches; a bare `YYYY-MM-DD` keeps its own day.
- **Tests**: `leanRead.test.ts` +1 and `arCustomerChase.test.ts` +1 (a touch at 00:30 UTC on the 27th is the 26th's: *leaned on today*, *Sep 1 (today)*); the station's smoke pins its clock at 7:30 PM Central (`vi.setSystemTime`, Date only), so it runs the evening case on every run instead of passing by day and failing by night. With the kernels reverted the four tests fail; with the fix they pass.

**Is this the best we can do?** A search for a stored timestamp's day taken by slicing its text (`created_at.slice(0, 10)` and the regex spelling) finds 48 more places in `src/`. Some are `date` columns, where the slice is right; the rest show the same evening off-by-one. `check:timezone` refuses today taken from the UTC clock (v2.2703) but not this spelling. Teaching it to, with each site fixed or waived, is its own sweep; it is not built here.
