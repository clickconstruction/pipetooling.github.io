# v2.3540 — Lien desk: the cover note is page 1 of the paper while it is ticked (2026-09-16)

Client only; no migration, no edge function. Follows v2.3522 (the paper-first pane and the preview window).

## Why

Grace, on the new pane: *"I would like for this section to be what the customer is going to receive, so if someone selects cover note, I would like for the cover note to also appear in this preview."* The run already prints the cover note as its own page ahead of the notice (`runCoverNoteBlocks`, v2.3410) — the desk pane and the preview showed only the notice, so the paper on screen was not the paper in the envelope.

## What shipped

- **[`lienDeskRun.ts`](../../src/lib/jobs/lienDeskRun.ts)** — `runCoverNoteBlocks` takes a narrow `CoverPageInput` (label, months, fields, extras, coverNote, coverLetter) instead of a whole `RunNotice`, so the desk builds the same page from what it has. The run's call is unchanged.
- **[`LienDeskModal.tsx`](../../src/components/jobs/LienDeskModal.tsx)** — `coverBlocks` is the run's page for this item: the standard note while the footer's box is ticked, or the run's cover letter when Put a GC on notice wrote one (it replaces the note, as in the run). The pane renders it as *Page 1 of 2 · cover note* in its own light frame ahead of *Page 2 of 2 · the notice*; unticked, the notice reads *Page 1 of 1*. A muted clause on the last page's label says the job's unpaid invoice follows it in the packet.
- **[`lienNoticePreview.ts`](../../src/lib/jobs/lienNoticePreview.ts)** — `coverBlocks` on the preview input; the page renders the cover page first with page labels, a `page-break-after` before the notice when printed, and the side note says whether the cover note is on and how to change it.
- Guide *send lien notices from the Lien desk* → "Reading the notice before it goes" opens with the envelope, page by page.

## Verified

- Kernel: the cover page renders first as page 1 of 2 with the print page break and the side note; without one the notice is page 1 of 1 and the note says how to add it.
- Render smoke: the cover page carries *Re: 650 · ATI Schertz* and the routine-paper sentence while the box is ticked; unticking removes it and the notice reads page 1 of 1.
- Live on prod data (port 5191): job 258 shows the cover page above the notice, unticking the footer box drops it and relabels the notice.
- Typecheck, lint, theme check, tests.
