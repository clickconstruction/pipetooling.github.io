# v2.3314 — Routing numbers stay whole on the bank transfer card (2026-09-11)

Client only; follow-up to v2.3308 found on the live pass. `groupDigits` in [`src/lib/bankTransferDetails.ts`](../../src/lib/bankTransferDetails.ts) grouped any run of six or more digits into fours, so the nine-digit ABA routing number rendered as "0913 1122 9" on the portal card and the Accounts Receivable panel. Banks print routing numbers as one run; the split read as a typo. The threshold is now ten digits, so routing numbers pass through untouched and account numbers keep their groups. Copy buttons were always the raw value. Test updated.
