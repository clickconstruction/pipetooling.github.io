# v2.7944 — Checklist History: no repeating tasks reads as one plain line, not an empty grid (2026-11-19)

Client only; no migration, no edge function. The change v2.7754 set aside when it moved the History tab: that PR turned the bare line *No repeating tasks in this range.* into a named constant so `check:empty-words` would pass a moved line, and left the screen as it was.

## What was wrong

On a wide screen, `src/components/checklist/ChecklistHistoryTab.tsx` drew the grid's table whenever the screen was wide, rows or no rows. For a person whose picked months hold one-off tasks and no repeating task it drew the REPEATING label reading *0 tasks · rows start at each task's creation*, the table's head alone (Item, rate), the bare line, and then the one-off ledger. With no history at all it drew the same empty head above *No checklist history in the last 6 months.*

The state is the common one. Read on prod through the dev seat on 2026-11-19: eight repeating tasks exist, held by five people. Of the thirteen people in **View history for** with any task in the last six months, eight have one-offs and no repeating task.

## What shipped

- **`checklistHistoryNoRepeatingWords(monthsBack, showYear)`** in `src/lib/checklistEmptyWords.ts`, beside `checklistHistoryEmptyWords` and sharing its span and its press: *No repeating tasks in the last 6 months.* with **Show 12 months** (`HISTORY_MONTHS_MAX`), and `main` alone at twelve.
- **The tab** draws the REPEATING label and the grid only over a repeating row. With one-offs and no repeating task it draws that line with `EmptyState` (`compact`, in the one-off ledger's 46rem column so it centres over the list under it). With no history at all the empty head no longer draws above the existing empty words.
- **The REPEATING label goes with the grid.** Over no rows it read *0 tasks · rows start at each task's creation*: a count the line already gives and a note about rows that are not there. The line names the section itself, and ONE-OFF TASKS keeps its label under it.
- **`HISTORY_NO_REPEATING_WORDS`** left `src/lib/checklistHistorySplit.ts` with its import and its test; nothing else read it.
- The phone's ledger (`ChecklistHistoryLedger`) and `src/pages/Checklist.tsx` are untouched.

The first case holds the label where it does draw.
