# v2.4119 — Lien desk: the mailing — a printed pile, Record the mailing, tracking-number shape checks, envelope faces, and "add the number" on a sent notice (2026-09-29)

Migration `20260929054429_lien_desk_items_printed.sql` (`db push`; additive — `printed_at`, `printed_by` on `job_lien_desk_items`); no edge function. Mock-up: board 9 of the runway canvas (*Sending the run — before and after*). The owner asked whether an assistant sending a lien notice is told what to put on the letter, and whether saying "I'm sending it" then asks for the certified-mail tracking number so it lands where the affidavit will need it. The first half was already true: the run resolves the two statutory recipients and prints the packet in envelope order with a cover sheet listing every envelope. The second half had a hole — the run said *tracking numbers can be typed now or left for later*, and there was no later: a send recorded with a blank number could not be filled in, and nothing said it was missing.

## What changed

- **Printed is a state.** `markLienDeskItemsPrinted` stamps `printed_at` / `printed_by` when *Print the packet* runs (best-effort — a failure leaves the items where they were). `pileForItem` reads an approved item with a `printed_at` as the new pile **`printed`**, labelled *In the mail · tracking owed*, between *Ready to send* and *Held*; `PILE_ORDER`, `EMPTY_QUEUE` and the run's source (`ready` + `printed`) follow. The header chip shows the count like the others.
- **The run window (`LienDeskRunModal`)** — a steps strip (*1 · Print the packet ✓ → 2 · Mail them → 3 · Record the mailing*), a *Mailed on* date typed once (the sends' `sent_on`), an **Envelope faces** button, and under every tracking input a shape hint as you type: `trackingShape` reads a certified number as 20 digits (22 with the service prefix) — *✓ 20 digits · certified* in green, *18 digits — a certified number has 20* in red — a courier number as any text, email and hand as none. **Recording splits** (`runRecordSplit`): a notice with at least one mailed envelope (a number typed, or an email / hand copy) records now, the rest stay printed — the button reads *Record 2 mailed · 1 stays in the pile ▸* and the window stays open on the rest. With no number on any envelope the run records whole, as before, so an office that does not track is not stopped.
- **Envelope faces** (`runEnvelopeFacesHtml`): one 9.5 × 4.125 in page per envelope — the return address from the issuer, *CERTIFIED MAIL · RETURN RECEIPT REQUESTED* with an article-number blank (or the courier / hand-delivered line), the recipient block as the notice names it, *Envelope n of N*. Email envelopes print no face.
- **Add the number** (`LienTrackingOwedEditor`, `lib/jobs/lienSendTracking.ts`): `sendsTrackingOwed(sends)` finds the certified or courier sends with a blank number; the editor draws one input per owed recipient with the same shape hint, and Save writes the filing's `sends` back with the number filled (`withTracking`). Drawn on the desk's **Sent footer** and beside each notice in the Lien window's **Filings on this job**; the desk's Sent row subline reads *sent Sep 29 · tracking owed*.
- **The Dashboard** — `assessLienWatch` gains `trackingOwed` (live notice / retainage filings with an owed send); Needs You gets *N mailed notices have no tracking number* (amber, rank beside the serve-copy card), whose door lands on the desk's Sent pile (`liendeskPile=sent`).
- Guide *send lien notices from the Lien desk* (Sending the run, rewritten as the three steps), GLOSSARY (Lien desk piles), the desk's map, the migration fragment.

**Not done:** the camera reading the label's barcode and the receipt photo per envelope (the saved-copy link carries a receipt scan today); USPS delivery confirmation on the timeline (needs a USPS API account).
