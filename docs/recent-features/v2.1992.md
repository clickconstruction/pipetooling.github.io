# v2.1992 — Waiting to hear: one-tap outcome capture (2026-08-21)

PR 2 of the pending-chase train (PR 1: v2.1990 lens). The lens stops being read-only — the call gets logged where it happens.

- **Six action chips on the bid card** ([`BidsWaitingToHearLens`](../../src/components/bids/BidsWaitingToHearLens.tsx)): Left message · Still pending · Bid tab received · Rebid / RFQ · Won · Lost…. **Lost…** flips the row to the six `BID_LOSS_CATEGORIES` reason chips (+ back), so a loss learned on the chase call lands in `loss_category` immediately instead of joining the Why-we-lost backlog.
- **Writes mirror the builder call session** so bid history reads identically either way: every tap inserts a `bids_submission_entries` note (`Phone`, label from [`pendingChaseActionNote`](../../src/lib/bidPendingChase.ts) — won/lost/rebid/still-pending reuse `callSessionOutcomeLabel`, plus new "Chased — left a message / no answer" and "Bid tab received" labels) and stamps `bids.last_contact`; Won/Lost also patch `outcome` / `loss_reason` / `loss_category` (won clears stale loss fields, same as the call session).
- **Optimistic UI**: contact-only taps mark the bid fresh locally (`localTouches`), Won/Lost remove it from the queue (`localResolved`), the note box clears, and the lens auto-advances to the next needs-chase bid — the background `loadBids` reload then catches up. On write failure the optimistic layer reverts and the error surfaces.
- **Note box** ("what they said — saved with the next tap") folds into the entry text, and into `loss_reason` for Lost taps. A green **N chased this session** counter joins the header chips.
- Kernel: [`buildPendingChaseActionWrites`](../../src/lib/bidPendingChase.ts) + `pendingChaseActionNote` (+6 unit tests, 22 total in the kernel suite) — pure row-building, the component performs the writes, same split as `builderCallSession.ts`.
- Parent passes `authUserId` / `onError` / `onReloadBids` ([`Bids.tsx`](../../src/pages/Bids.tsx)). Help guide `follow-up-with-builders.md` updated. Client-only — no migration.
