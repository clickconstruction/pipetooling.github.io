# v2.2390 — Bid-name clicks open the tabbed Bid window (2026-08-27)

Wendi: "across bids, when I click on a bid name, it is pulling up the old
edit bid modal instead of the new one with the Bid/Edit in the top left."
Every bid-name link on the Bids page still called
`bidPreview.openBidPreviewFromBid` → the standalone `BidPreviewModal`; the
tabbed `BidWindowModal` was only reachable through Edit-bid buttons.

Changes (`Bids.tsx` + three bid-board components):

- `openEditBid` gains `opts.tab: 'bid' | 'edit'`; new `bidWindowInitialTab`
  state feeds `BidWindowModal`'s existing `initialTab` prop (window also keyed
  by `bidId:tab` so a fresh open honors the requested face).
- Bids.tsx passes its tabs `bidPreviewOnBidsPage` — the context spread with
  `openBidPreviewFromBid` overridden to `openEditBid(bid, { tab: 'bid' })`.
  One override covers all ten workflow-tab titles and the board links; the
  page's own two `onOpenPreviewBid` call sites use it too.
- The weekly-sent drill-down reached the context directly — an optional
  `openBid` prop now threads BidsBidBoardTab → EstimatingHealthSection →
  EstimatingPulseSection → `BidBoardWeeklySentCellModal`, preferred over the
  context when present.
- Off the Bids page nothing changes: Dashboard / global search / customer
  profile / Projects still use `openBidPreview(bidId)` → the standalone
  preview, per the flip guide (updated with the new bid-name rule).
