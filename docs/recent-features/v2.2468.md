# v2.2468 — The Bid Room, Phase 1: publish + the durable link (2026-08-28)

Signable Bids (owner-approved rev-3 plan, all ten decisions to the leans; proposal artifact
4563a0fb). The model: NOT frozen send-time documents — **one durable link per GC packet (the
bid room)** serving the latest *published* letter revision; the freeze moves to signature
time (Phase 2). Revisions are explicit publishes with notes (decision 6); the link never
dies (decision 8); the Google Docs letter rides along as the room's attachment.

This PR:

- **Migration `20260828215717`**: `bid_proposal_rooms` (bid × GC packet, plaintext
  portal-style token — the portal-links precedent, `customer_id` null = the bid's own GC,
  partial-unique per open room), `bid_proposal_room_revisions` (rev number, note, letter
  payload jsonb), `bid_proposal_room_events` (room_view / option_viewed / link_sent /
  signed / declined). Staff RLS mirrors the bids family; the GC side goes through
  service-role edge functions only. All three read-only appliers + the digital-twin fence.
- **Payload kernel** `src/lib/bids/bidRoomPayload.ts` (+9 tests) + `_shared` parse twin
  (+2 parity tests): letter-faithful content — ALL base sections merge into one "base"
  option (the letter's proposed amount), each offered alternate stands alone (decision 3),
  fixture/count lists + lump totals exactly as the letter prints (the letter never prices
  per line), inclusions/exclusions/terms, plum/elec brand by service type.
- **Staff panel** (`BidRoomPanel`) beside Mark sent on BOTH Cover Letter studio branches
  (per-GC packets and the version-less letter): Publish & send room link (GC CRM email

  First send fires the same Mark-sent stamping as the button next to it.
- **Public page `/bid-room?t=…`** (pinned light, orange accent): brand header, project +

  fixture lists), the selected option's scope table + total, inclusions/exclusions/terms,
  the Docs letter card. Option picks log `option_viewed`; every open logs `room_view`.
- **Edge functions** `get-bid-proposal-room` (public, token-validated; GET fetch + POST
