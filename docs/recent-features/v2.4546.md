# v2.4546 — Submittals: save one row's cut sheet as its own PDF (2026-10-05)

Client only; no migration, no edge function. The owner asked "is it easy on this tab to send someone a cut sheet?" It was not: the only PDFs the tab could hand over were the whole package and the reviewer's own file, and the GC's page offers the package alone. The row knew its pages (*✓ p.30–47* of the house's 75-page file) and had no door for them. The owner: "add it".

## What changed

- **Save PDF** sits under the pages in a row's *Cut sheet* cell, on any revision, draft or shared. It reads the vendor file, cuts the row's pages out and saves them to the device as *LAV-1 cut sheet.pdf* (the tag, less what a file name cannot hold; an untagged row is *Accessory cut sheet.pdf*). A toast says *Saved LAV-1 cut sheet.pdf · 18 pages. Attach it to your email or text.*
- **The same pages the package carries for the row** (`rowCutSheetPlan`, mirroring `packageSheets`): a row whose parts carry their own pages gives those, part by part, across vendor files if they differ; any other row gives its own. Nothing is stamped on them — they are the maker's pages as the house sent them.
- **Nothing is written and nothing is sent.** A row with no cut sheet has no door. While one is being cut its door reads *Saving…* and the others hold.

## Not built

A link that opens one row's cut sheet for someone outside the office (the way the package link works for the GC). It needs a server function and a rule for who may open it; the owner chose the file.

## How it is built

- [`src/lib/submittals/rowCutSheet.ts`](../../src/lib/submittals/rowCutSheet.ts) — `rowCutSheetPlan`, `cutSheetPageCount`, `cutSheetFileName`, and `buildRowCutSheet` (pdf-lib, loaded lazily; each vendor file read once; a page past the end of its file is skipped).
- [`SubmittalRowsTable.tsx`](../../src/components/bids/SubmittalRowsTable.tsx) — `onSaveSheet`, `savingSheetId`. [`BidsSubmittalsTab.tsx`](../../src/components/bids/BidsSubmittalsTab.tsx) — `saveRowCutSheet`, using the same `downloadFile` the package build uses.
