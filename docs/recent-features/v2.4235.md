# v2.4235 — Help: the first fifty guides in plain words (2026-09-30)

The sweep of the guides written before plain words became the convention ([v2.4233](v2.4233.md)); the owner, 2026-09-30: "I do want to go back through the old" guides. Batch 1 of 7 — the first fifty rows of `LEGACY_PLAIN_WORDS_GUIDES`, alphabetical, `add-a-customer` through `create-an-assembly-while-doing-a-takeoff`. No migration, no edge function, nothing on a screen changes.

## What changed

- **Fifty guides rewritten** by the rules in [`src/lib/plainWords.ts`](../../src/lib/plainWords.ts): one idea per sentence and none over 20 words; *you* + a verb and the control's exact name; a trade word explained beside itself the first time (GC, the general contractor; a takeoff, the count from the plans; a PO, a purchase order; a modal, a pop-up window; ITB, an invitation to bid); no dashes, semicolons, parentheses or `·` lists inside a sentence. Each guide's frontmatter, headings (one em dash became a colon), `:::example` panels, mock-UI tokens and markdown links are unchanged, checked mechanically against the previous text; every fact was kept, so the guides read longer, not shorter (34,380 → 35,713 words). A bold label the screen prints with a dash or a dot (*Hours · Paper · Acct*, *salary — counts as flat hours*) is quoted in italics, the rule's screen-text exemption.
- **Their fifty rows leave the legacy list** ([`plainWordsLegacy.ts`](../../src/lib/plainWordsLegacy.ts): 302 → 252), so `helpGuidePlainWords.test.ts` holds them from now on.
- **Two reader fixes found by the sweep** ([`plainWords.ts`](../../src/lib/plainWords.ts)): a `{{gif:…}}` token's file name carries dots and dashes, which the word counter did not strip; and a markdown link's target (`[read the bid board](?g=read-the-bid-board)`) tripped the parenthesis rule, so both readers now read a link as its text. Tests beside them.

## The batches

Alphabetical, fifty at a time, each removing one contiguous run of rows so parallel batches never conflict on the list. Batch 2 starts at `create-rename-and-share-a-roadmap`.
